---
title: "What is web unlocker?"
---

Web Unlocker is a universal scraping API. Send any URL, get back fully rendered HTML or the page as Markdown or JSON, with no browsers or proxies to manage.

It replaces the browser and proxy part of your scraping stack: rendering, proxy management and browser fingerprints are handled in a single API call. Static pages and JavaScript-heavy sites go through the same endpoint.

---

## What it solves

Modern websites are hard to scrape. A plain `curl` or `requests` call often returns a blank response or broken HTML because the content is loaded by JavaScript. Web Unlocker takes care of:

- **JavaScript rendering** — pages are loaded in a real browser and fully executed before content is captured
- **Smart IP rotation** — requests are routed through residential IPs with realistic browser fingerprints
- **Price tier targeting** — routes requests through the appropriate proxy tier for the target site

---

## What you get back

A successful request returns the page in one format. Choose it with the `format` query parameter:

| `format` | What you get |
| --- | --- |
| `html` (default) | The complete rendered DOM of the page |
| `markdown` | The page content as Markdown |
| `json` | A JSON object with the page URL, request metadata, and the HTML |

## How it works

Web Unlocker runs a real Chromium browser in the cloud for each task. When you send a URL:

1. A browser is launched with a residential IP and realistic browser fingerprint
2. The page is navigated, JavaScript is executed, and dynamic content is loaded
3. The rendered HTML is returned, or Markdown or JSON if you ask for it with `format`

You never manage infrastructure. There are no browsers to spin up, no proxy lists to maintain, and no rendering logic to build. Web Unlocker replaces a browser automation framework and a proxy provider with a single HTTP request.

---

## How to use it

Send a GET request with the target URL as a query parameter. The response is the fully rendered HTML.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

To get Markdown or JSON instead, add `format=markdown` or `format=json` to the query.

See the [Quickstart](/web-unlocker-quick-start) for examples in Python and JavaScript and for [error codes](/web-unlocker-quick-start#handling-errors), or [Use Cases](/web-unlocker-use-cases) for common integration patterns.
