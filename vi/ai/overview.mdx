Gologin cung cấp cho AI agent ba khả năng cần thiết để làm việc với web một cách ổn định:

1. **Đọc web** — thu thập dữ liệu từ bất kỳ trang nào, kể cả các trang nặng JavaScript và có cơ chế bảo vệ, thông qua Web Unlocker
2. **Tương tác với web** — mở các phiên trình duyệt thật với thao tác nhấp chuột, nhập liệu, điều hướng và cookie được lưu giữ lâu dài thông qua Cloud Browser
3. **Không bị phát hiện** — fingerprint chống phát hiện, proxy dân cư và quản lý danh tính theo profile

Các khả năng này có sẵn ở nhiều cấp độ tích hợp — hãy chọn cấp độ phù hợp với hệ thống của bạn.

## Các thành phần kết hợp với nhau như thế nào

```
┌─────────────────────────────────────────────────┐
│                  AI Agent                        │
│         (Claude, Codex, custom agent)            │
└──────┬──────────┬──────────┬────────────────────┘
       │          │          │
  MCP Server   AI Skills   CLI Tools / SDK
       │          │          │
       └──────────┴──────────┘
                  │
    ┌─────────────┴─────────────┐
    │                           │
Web Unlocker              Cloud Browser
(stateless scraping)    (stateful sessions)
    │                           │
    └─────────────┬─────────────┘
                  │
          Gologin Infrastructure
    (proxies, fingerprints, profiles)
```

- **Web Unlocker** xử lý việc đọc/trích xuất không lưu trạng thái — gửi một URL, nhận lại HTML đã được render
- **Cloud Browser** xử lý các tương tác có lưu trạng thái — mở phiên, nhấp chuột, nhập liệu, điều hướng, lưu giữ cookie
- **Local Orbita** xử lý các profile cục bộ lâu dài — làm nóng profile, quy trình đăng nhập, thao tác trên mạng xã hội/sàn thương mại điện tử — thông qua local runtime của Agent Browser CLI

Cả ba đều dùng chung hạ tầng Gologin: proxy dân cư, fingerprint chống phát hiện và quản lý profile.

## Bạn có thể xây dựng gì với công cụ này

### Nghiên cứu và tình báo cạnh tranh

Một AI agent theo dõi giá của đối thủ, các đợt ra mắt sản phẩm và thay đổi nội dung trên hàng chục website — hằng ngày, hoàn toàn tự động. Agent thu thập dữ liệu các trang của đối thủ thông qua Web Unlocker, trích xuất dữ liệu có cấu trúc, so sánh với bản chụp của ngày hôm trước và tạo bản tổng hợp hằng ngày. Không cần phiên trình duyệt, chỉ cần trích xuất không lưu trạng thái ở quy mô lớn.

```bash
# scrape 20 competitor pricing pages and get structured output
gologin-web-access batch-scrape \
  https://competitor1.com/pricing \
  https://competitor2.com/pricing \
  https://competitor3.com/pricing \
  --format json --summary --output ./today-prices.json

# detect what changed since last check
gologin-web-access batch-change-track \
  https://competitor1.com/pricing \
  https://competitor2.com/features \
  --format markdown --output ./changes.json
```

### Tìm kiếm và làm giàu dữ liệu khách hàng tiềm năng

Thu thập dữ liệu từ danh bạ doanh nghiệp, trang công ty trên LinkedIn, các trang đánh giá — sau đó đưa HTML vào Claude để trích xuất tên, email, số điện thoại, quy mô công ty và công nghệ đang sử dụng. Hoạt động như một công cụ trong vòng lặp của AI agent: agent quyết định trang nào cần thu thập, gọi công cụ và nhận lại dữ liệu có cấu trúc.

```bash
# search for leads
gologin-web-access search "saas companies series A 2026" --limit 20

# scrape and extract structured data from each result
gologin-web-access extract https://example.com/company/123 --schema ./lead-schema.json
```

### Quản lý nhiều tài khoản

Vận hành hơn 50 tài khoản mạng xã hội, tài khoản quảng cáo hoặc tài khoản người bán trên sàn thương mại điện tử — mỗi tài khoản có profile trình duyệt, fingerprint, proxy và cookie riêng. Local runtime của Agent Browser CLI quản lý các profile, làm nóng chúng bằng runbook và giữ cho các phiên luôn hoạt động giữa các lần agent gọi lệnh. Các lệnh profile và runbook chạy cục bộ mà không cần thêm cờ nào.

```bash
# create profiles for each account
gologin-agent-browser profile-create "FB Ads Account 1" --template ads
gologin-agent-browser profile-create "FB Ads Account 2" --template ads

# warm up profiles in batch
gologin-agent-browser batch ./warmup-runbook.json \
  --targets ./all-profiles.json --concurrency 5
```

### Tự động điền biểu mẫu và nhập dữ liệu

Một AI agent đăng nhập vào các bảng điều khiển nội bộ, điền biểu mẫu, gửi báo cáo, tải xuống các bản xuất dữ liệu — tất cả thông qua một phiên trình duyệt đám mây thật. Agent đọc trang dưới dạng snapshot, tìm đúng các trường theo ref, nhập giá trị, nhấp nút gửi và xác minh kết quả.

```bash
gologin-agent-browser open https://internal-dashboard.com/login --profile my_profile
gologin-agent-browser snapshot
gologin-agent-browser fill @e3 "username"
gologin-agent-browser fill @e5 "password"
gologin-agent-browser click @e7    # submit button
gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # verify login success
gologin-agent-browser screenshot ./logged-in.png
```

### Giám sát nội dung và cảnh báo

Theo dõi thay đổi trên các trang quy định của chính phủ, blog của đối thủ, trang tuyển dụng hoặc bất kỳ trang nào quan trọng với doanh nghiệp của bạn. Chạy hằng ngày bằng cron hoặc một agent theo lịch, so sánh với phiên bản trước và cảnh báo khi có thay đổi đáng kể.

```bash
# track changes on key pages
gologin-web-access change-track https://regulations.gov/new-rules --format markdown
gologin-web-access batch-change-track \
  https://competitor.com/blog \
  https://competitor.com/changelog \
  --output ./changes.json
```

### Pipeline thu thập dữ liệu web với AI

Xây dựng một pipeline hoàn chỉnh: crawl một website tài liệu, chuyển sang markdown, rồi đưa vào LLM để tóm tắt hoặc hỏi đáp. Dùng CLI cho phần trích xuất và code của riêng bạn cho phần LLM.

```bash
# crawl an entire docs site
gologin-web-access crawl https://docs.example.com \
  --format markdown --limit 100 --max-depth 3 --only-main-content \
  --output ./docs-corpus.json

# or map the site first, then selectively scrape
gologin-web-access map https://docs.example.com --limit 200
gologin-web-access batch-scrape url1 url2 url3 --format text --output ./selected.json
```

### Kiểm thử theo vị trí địa lý và QA bản địa hóa

Kiểm tra website của bạn hiển thị như thế nào từ các quốc gia khác nhau. Mở cùng một URL thông qua các profile được cấu hình proxy ở các khu vực địa lý khác nhau, chụp ảnh màn hình và so sánh.

```bash
# create geo-specific profiles
gologin-agent-browser profile-create "US Test" --template geo --proxy-country us
gologin-agent-browser profile-create "DE Test" --template geo --proxy-country de
gologin-agent-browser profile-create "JP Test" --template geo --proxy-country jp

# screenshot from each location
gologin-agent-browser open https://yoursite.com --profile us_profile_id
gologin-agent-browser screenshot ./us-view.png
gologin-agent-browser close
```

## Ví dụ bắt đầu nhanh

### Thu thập dữ liệu một trang (CLI)

```bash
npm install -g gologin-web-access
export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."

gologin-web-access read https://example.com
```

### Mở trình duyệt đám mây (CLI)

```bash
npm install -g gologin-agent-browser-cli
export GOLOGIN_TOKEN='your_token'

gologin-agent-browser open https://example.com
gologin-agent-browser snapshot
gologin-agent-browser click @e3
gologin-agent-browser close
```

### Cài đặt một AI Skill (Claude Code)

```bash
npx skills add GologinLabs/agent-skills@gologin-web-access-skill
```

Sau đó, bạn chỉ cần yêu cầu Claude Code thu thập dữ liệu một trang hoặc tương tác với một website — skill sẽ lo phần còn lại.

### Kết nối MCP (Claude Desktop)

Thêm vào `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "gologin-mcp": {
      "command": "npx",
      "args": ["gologin-mcp"],
      "env": { "API_TOKEN": "your-token" }
    }
  }
}
```

Sau đó hãy hỏi Claude: "Tạo một profile trình duyệt mới với proxy tại Hoa Kỳ."
