title: "Web Unlocker là gì?"
---

Web Unlocker là một API scraping đa năng. Bạn chỉ cần gửi một URL bất kỳ và nhận lại HTML đã được hiển thị đầy đủ, hoặc trang dưới dạng Markdown hoặc JSON — không cần quản lý hạ tầng, không bị chặn, không có yêu cầu thất bại.

Web Unlocker thay thế hoàn toàn bộ công cụ scraping của bạn: tự động hóa trình duyệt, quản lý proxy, tạo fingerprint, giải CAPTCHA — tất cả được xử lý chỉ trong một lệnh gọi API. Dù bạn scrape một trang tĩnh đơn giản hay một trang web dùng JavaScript và được bảo vệ chặt chẽ, cùng một endpoint vẫn xử lý được.

---

## Web Unlocker giải quyết vấn đề gì

Các website hiện đại rất khó scrape. Một lệnh gọi `curl` hoặc `requests` thông thường thường chỉ trả về trang xác minh, phản hồi trống hoặc HTML bị lỗi vì nội dung được tải bằng JavaScript. Web Unlocker tự động xử lý tất cả những vấn đề này:

- **Hiển thị JavaScript** — trang được tải trong một trình duyệt thật và thực thi đầy đủ trước khi nội dung được thu thập
- **Vượt cơ chế chống bot** — Cloudflare, DataDome, PerimeterX và các cơ chế bảo vệ tương tự được xử lý tự động
- **Xoay IP thông minh** — yêu cầu được định tuyến qua các IP dân cư sạch với browser fingerprint giống thật
- **Giải CAPTCHA** — các thử thách CAPTCHA phổ biến được giải quyết mà không cần can thiệp thủ công
- **Chọn proxy theo mức giá** — định tuyến yêu cầu qua nhóm proxy phù hợp với website mục tiêu

## Dữ liệu bạn nhận được

Một yêu cầu thành công sẽ trả về trang ở một định dạng. Bạn chọn định dạng bằng tham số truy vấn `format`:

| `format` | Bạn nhận được |
| --- | --- |
| `html` (mặc định) | Toàn bộ DOM đã hiển thị của trang |
| `markdown` | Nội dung trang dưới dạng Markdown |
| `json` | Một đối tượng JSON chứa URL của trang, metadata của yêu cầu và HTML |

## Cách hoạt động

Web Unlocker chạy một trình duyệt Chromium thật trên đám mây cho mỗi tác vụ. Khi bạn gửi một URL:

1. Một trình duyệt được khởi chạy với IP dân cư và browser fingerprint giống thật
2. Trang được truy cập, JavaScript được thực thi và nội dung động được tải
3. Các thử thách chống bot và CAPTCHA được xử lý tự động
4. HTML đã hiển thị được trả về, hoặc Markdown hay JSON nếu bạn yêu cầu bằng `format`

Bạn không cần quản lý hạ tầng. Không cần khởi chạy trình duyệt, không cần duy trì danh sách proxy và không cần xây dựng logic vượt chặn. Web Unlocker thay thế cả bộ công cụ scraping — framework tự động hóa trình duyệt, nhà cung cấp proxy, giải pháp chống bot — chỉ bằng một yêu cầu HTTP.

## Cách sử dụng

Gửi một yêu cầu GET với URL mục tiêu làm tham số truy vấn. Phản hồi là HTML đã được hiển thị đầy đủ.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Để nhận Markdown hoặc JSON, hãy thêm `format=markdown` hoặc `format=json` vào truy vấn.

Xem [Hướng dẫn bắt đầu nhanh](/vi/web-unlocker-quick-start) để có ví dụ bằng Python và JavaScript cũng như [mã lỗi](/vi/web-unlocker-quick-start#handling-errors), hoặc [Các trường hợp sử dụng](/vi/web-unlocker-use-cases) để tìm hiểu các mẫu tích hợp phổ biến.
