---
title: "Web Unlocker là gì?"
---

Web Unlocker là một API thu thập dữ liệu đa năng. Bạn chỉ cần gửi một URL bất kỳ và nhận lại HTML đã được hiển thị đầy đủ, hoặc trang dưới dạng Markdown hay JSON, mà không phải quản lý trình duyệt hay proxy.

Web Unlocker thay thế phần trình duyệt và proxy trong hệ thống thu thập dữ liệu của bạn: việc hiển thị trang, quản lý proxy và vân tay trình duyệt đều được xử lý trong một lệnh gọi API duy nhất. Trang tĩnh và các trang web dùng nhiều JavaScript đều đi qua cùng một endpoint.

---

## Giải quyết vấn đề gì

Các trang web hiện đại rất khó thu thập dữ liệu. Một lệnh gọi `curl` hoặc `requests` thông thường thường trả về phản hồi trống hoặc HTML bị lỗi vì nội dung được tải bằng JavaScript. Web Unlocker xử lý các việc sau:

- **Hiển thị JavaScript** — trang được tải trong một trình duyệt thật và thực thi đầy đủ trước khi nội dung được ghi lại
- **Xoay IP thông minh** — yêu cầu được chuyển qua các IP dân cư với vân tay trình duyệt chân thực
- **Chọn theo mức giá** — chuyển yêu cầu qua nhóm proxy phù hợp với trang web đích

---

## Bạn nhận lại gì

Một yêu cầu thành công trả về trang ở một định dạng. Bạn chọn định dạng bằng tham số truy vấn `format`:

| `format` | Bạn nhận được |
| --- | --- |
| `html` (mặc định) | Toàn bộ DOM đã được hiển thị của trang |
| `markdown` | Nội dung trang dưới dạng Markdown |
| `json` | Một đối tượng JSON chứa URL của trang, siêu dữ liệu yêu cầu và HTML |

## Web Unlocker so với proxy tự quản lý

Tự vận hành hạ tầng proxy vừa tốn kém vừa dễ lỗi. Web Unlocker xử lý mọi thứ dưới dạng dịch vụ được quản lý:

|  | Web Unlocker | Proxy tự quản lý |
| --- | --- | --- |
| Thiết lập | Một lệnh gọi API | Nhiều tuần xây dựng hạ tầng |
| Vân tay trình duyệt | Có sẵn | Tự xây dựng hoặc mua riêng |
| Xoay IP | Tự động | Quản lý nhóm IP thủ công |
| Bảo trì | Không cần | Liên tục |
| Thanh toán | Theo mỗi yêu cầu thành công | Chi phí cố định dù thành công hay không |

## Các trường hợp sử dụng phổ biến

- **Theo dõi giá** — theo dõi giá trên các trang thương mại điện tử
- **Nghiên cứu thị trường** — thu thập dữ liệu sản phẩm, đánh giá hoặc tin tuyển dụng ở quy mô lớn
- **Tổng hợp nội dung** — xây dựng nguồn tin hoặc nguồn dữ liệu từ các trang không có API
- **Pipeline AI** — đưa HTML đã hiển thị vào LLM để trích xuất hoặc tóm tắt

## Cách hoạt động

Web Unlocker chạy một trình duyệt Chromium thật trên đám mây cho mỗi tác vụ. Khi bạn gửi một URL:

1. Một trình duyệt được khởi chạy với IP dân cư và vân tay trình duyệt chân thực
2. Trang được truy cập, JavaScript được thực thi và nội dung động được tải
3. HTML đã hiển thị được trả về, hoặc Markdown hay JSON nếu bạn yêu cầu bằng `format`

Bạn không cần quản lý hạ tầng. Không cần khởi chạy trình duyệt, không cần duy trì danh sách proxy và không cần xây dựng logic hiển thị. Web Unlocker thay thế một framework tự động hóa trình duyệt và một nhà cung cấp proxy chỉ bằng một yêu cầu HTTP.

## Cách sử dụng

Gửi một yêu cầu GET với URL đích làm tham số truy vấn. Phản hồi là HTML đã được hiển thị đầy đủ.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Để nhận Markdown hoặc JSON thay thế, hãy thêm `format=markdown` hoặc `format=json` vào truy vấn.

Xem [Hướng dẫn nhanh](/vi/web-unlocker-quick-start) để có ví dụ bằng Python và JavaScript cũng như [mã lỗi](/vi/web-unlocker-quick-start#x%E1%BB%AD-l%C3%BD-l%E1%BB%97i), hoặc [Các trường hợp sử dụng](/vi/web-unlocker-use-cases) để biết các mẫu tích hợp phổ biến.
