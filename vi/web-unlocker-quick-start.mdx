Hướng dẫn này chỉ cách thu thập dữ liệu từ URL đầu tiên của bạn bằng Web Unlocker.

---

## Điều kiện cần có

- Một API key của Web Unlocker. Bạn có thể nhận key bằng biểu mẫu trên [trang Web Unlocker](https://gologin.com/web-unlocker/#web_unlocker_form). Key sẽ được gửi trong vòng một ngày làm việc, kèm các yêu cầu miễn phí để bạn thử nghiệm trên chính các trang mục tiêu của mình. Không cần thẻ thanh toán.
- Python 3.x, Node.js hoặc bất kỳ HTTP client nào

---

## Xác thực

Mọi yêu cầu đều cần có API key của bạn trong header `apikey`:

```
apikey: YOUR_API_KEY
```

URL gốc cho tất cả các yêu cầu API là:

```
https://parsing.webunlocker.gologin.com/v1
```

---

## Gửi yêu cầu đầu tiên

Gửi một yêu cầu GET với URL mục tiêu làm tham số truy vấn. Phản hồi là mã HTML đã được hiển thị đầy đủ của trang.

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.text)
```

### JavaScript (Node.js / Browser)

```javascript
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(html);
```

---

## Kết quả nhận được

Nội dung phản hồi là mã HTML thô đã được hiển thị của trang — giống với nội dung bạn thấy khi mở URL đó trong trình duyệt. Không có lớp bao JSON và không cần phân tích cú pháp thêm.

```html
<!DOCTYPE html>
<html>
  <head><title>Example Domain</title></head>
  <body>...</body>
</html>
```

### Các định dạng khác

Thêm tham số truy vấn `format` để nhận trang ở định dạng khác:

| `format` | Nội dung phản hồi |
|---|---|
| `html` | HTML của trang (mặc định) |
| `markdown` | Nội dung trang dưới dạng Markdown |
| `json` | Đối tượng JSON chứa URL, siêu dữ liệu của yêu cầu và HTML của trang |

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com&format=json" \
  -H "apikey: YOUR_API_KEY"
```

```json
{
  "success": true,
  "data": {
    "url": "https://example.com",
    "metadata": {
      "response_time_ms": 297,
      "status_code": 200
    },
    "html": "<!DOCTYPE html><html lang=\"en\">..."
  }
}
```

## Xử lý lỗi

Hãy kiểm tra mã trạng thái HTTP trước khi xử lý phản hồi:

| Trạng thái | Ý nghĩa | Nội dung phản hồi |
|---|---|---|
| `200` | Thành công | Trang ở định dạng bạn yêu cầu |
| `400` | Yêu cầu không hợp lệ, ví dụ thiếu tham số `url` | `{"success":false,"error":"Request failed"}` |
| `401` | Thiếu header `apikey` | `{"message":"Missing API key in request"}` |

Nếu nhận được trạng thái `429` hoặc `5xx`, hãy thử lại với cơ chế exponential backoff (tăng dần thời gian chờ giữa các lần thử).

```python
response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

if response.status_code == 200:
    html = response.text
else:
    print(f"Error {response.status_code}: {response.text}")
```

## Bắt đầu nhanh với CLI

Bạn cũng có thể thu thập dữ liệu trang bằng các công cụ CLI của Gologin mà không cần viết mã:

### Web Unlocker CLI

```bash
npm install -g gologin-webunlocker

GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker scrape https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker markdown https://example.com
```

### Gologin Web Access CLI (hợp nhất)

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."
gologin-web-access read https://example.com
gologin-web-access scrape-json https://example.com
gologin-web-access batch-scrape https://example.com/page/1 https://example.com/page/2 --format text
```

Xem [Web Unlocker SDK và CLI](/vi/scraping-api-sdk-and-cli) và [Web Access CLI](/vi/cli-tools/web-access) để biết thêm chi tiết.
