---
title: "Giao thức proxy"
---

Cả giao thức HTTP/HTTPS và SOCKS đều hoạt động tốt với hầu hết các trang web. Tuy nhiên, với những trang web có biện pháp chống bot nâng cao, proxy SOCKS5 hỗ trợ UDP thường được ưu tiên hơn nhờ tính linh hoạt.

Gologin hỗ trợ các giao thức proxy phổ biến nhất.

### HTTP / HTTPS

- Proxy HTTP được sử dụng rộng rãi cho lưu lượng web thông thường.
- Proxy HTTPS hỗ trợ kết nối được mã hóa bằng SSL/TLS và thường được dùng để duyệt web an toàn.

### SOCKS4 / SOCKS5

- Proxy SOCKS hỗ trợ nhiều loại giao thức mạng hơn.
- SOCKS5 là lựa chọn linh hoạt nhất và hỗ trợ cả kết nối TCP lẫn UDP.
- Vì vậy, proxy SOCKS5 thường được ưu tiên cho các tác vụ tự động hóa và thu thập dữ liệu.
