Gologin Agent Browser CLI biến các hồ sơ trình duyệt Gologin thành một môi trường chạy liên tục, có thể điều khiển bằng script cho AI agent. Các phiên chạy trong Gologin Cloud Browser hoặc trong Orbita trên chính máy của bạn. CLI cung cấp snapshot trang gọn nhẹ, tương tác dựa trên ref, bộ nhớ phiên và đầu ra thân thiện với shell.

Khác với việc tự viết mã Puppeteer/Playwright từ đầu, CLI này cung cấp cho agent sẵn một bộ lệnh để tự động hóa trình duyệt — không cần mã mẫu, không cần mã quản lý phiên.

---

## Môi trường chạy Cloud hoặc cục bộ

CLI có hai môi trường chạy với cùng một bộ lệnh. Cả hai đều dùng hồ sơ, dấu vân tay và proxy của Gologin, và một daemon giữ các phiên luôn hoạt động giữa các lần gọi CLI.

| | `cloud` (mặc định) | `local` |
|---|---|---|
| Nơi trình duyệt chạy | Gologin Cloud Browser | Orbita trên máy của bạn |
| ID hồ sơ | Tùy chọn: nếu không có, một hồ sơ cloud tạm thời sẽ được tạo | Bắt buộc |
| Phù hợp cho | Phiên song song, phiên từ xa, các máy không nên chạy trình duyệt | Làm nóng hồ sơ, đăng nhập lần đầu, cookie và trạng thái hồ sơ cục bộ, khớp với hệ điều hành của bạn |

Chọn môi trường chạy cho từng lệnh bằng `--runtime cloud|local|auto`, hoặc đặt `GOLOGIN_AGENT_BROWSER_RUNTIME` một lần:

```bash
gologin-agent-browser open https://example.com
gologin-agent-browser open https://example.com --runtime local --profile your_profile_id
```

Theo mặc định (`auto`), các lệnh về hồ sơ, runbook và job chạy cục bộ, còn tất cả lệnh khác chạy trên cloud. Sau khi mở một phiên cục bộ, hãy truyền `--runtime local` cho cả các lệnh tiếp theo. Xem [Môi trường chạy cục bộ](/vi/cli-tools/local-agent-browser) để biết các yêu cầu và những lệnh chỉ dành cho local.

## Cài đặt

```bash
npm install -g gologin-agent-browser-cli
```

Hoặc chạy mà không cần cài đặt toàn cục:

```bash
npx gologin-agent-browser-cli --help
```

Yêu cầu Node.js >= 18. Môi trường chạy cục bộ cần Node.js 20 trở lên.

## Thông tin xác thực

| Biến | Bắt buộc | Mô tả |
|---|---|---|
| `GOLOGIN_TOKEN` | Có (cho `open` và các lệnh API) | Mã thông báo API của Gologin |
| `GOLOGIN_PROFILE_ID` | Tùy chọn | ID hồ sơ mặc định |
| `GOLOGIN_AGENT_BROWSER_RUNTIME` | Tùy chọn | Môi trường chạy mặc định: `cloud`, `local` hoặc `auto` |
| `GOLOGIN_DAEMON_PORT` | Tùy chọn | Cổng của daemon (mặc định: `44777` cho cloud, `44778` cho local) |
| `GOLOGIN_CONNECT_BASE` | Tùy chọn | Endpoint của Cloud Browser (mặc định: `https://cloudbrowser.gologin.com/connect`) |
| `GOLOGIN_EXECUTABLE_PATH` | Tùy chọn | Đường dẫn đến tệp thực thi Orbita cho môi trường chạy cục bộ |

### Lấy mã thông báo

1. Đăng ký hoặc đăng nhập tại [gologin.com](https://gologin.com)
2. Mở **API & MCP** trong bảng điều khiển
3. Mở tab **API**
4. Nhấp **Mã thông báo mới**
5. Sao chép mã thông báo truy cập vừa được tạo

```bash
export GOLOGIN_TOKEN='your_gologin_token'
```

## Kiến trúc

Gồm hai phần:

1. **CLI `gologin-agent-browser`** — phân tích lệnh, chọn môi trường chạy, tự động khởi động daemon tương ứng và in ra kết quả gọn nhẹ
2. **Các daemon cục bộ chạy liên tục**, mỗi môi trường chạy một daemon — quản lý các phiên trình duyệt đang hoạt động, kết nối với Gologin Cloud Browser hoặc Orbita cục bộ qua `connectOverCDP` của Playwright, giữ trang đang hoạt động trong bộ nhớ, tạo snapshot, phân giải ref và theo dõi siêu dữ liệu phiên

Kênh truyền tải chỉ ở phạm vi cục bộ. Daemon cloud lắng nghe tại:
- Unix socket tại `${TMPDIR:-/tmp}/gologin-agent-browser.sock`
- HTTP localhost tại `127.0.0.1:${GOLOGIN_DAEMON_PORT:-44777}`

Trong môi trường chạy cloud, nếu bạn không cung cấp ID hồ sơ, daemon sẽ tạo một hồ sơ cloud Gologin tạm thời thông qua API.

## Cách ref hoạt động

`snapshot` in ra chế độ xem trang gọn nhẹ và gán các ref như `@e1`, `@e2`, `@e3` cho các phần tử có thể tương tác. Bạn thao tác trực tiếp trên chúng:

```bash
gologin-agent-browser snapshot
# output shows page content with refs like @e1, @e2, @e3...

gologin-agent-browser click @e3
gologin-agent-browser type @e5 "search query"
gologin-agent-browser fill @e7 "username"
```

Ref chỉ hoạt động theo kiểu cố gắng tối đa và nên được tạo lại sau khi điều hướng hoặc khi DOM thay đổi lớn. Các lệnh cũng chấp nhận bộ chọn CSS thay cho ref. Trên các trang động, `find` thường là lựa chọn dự phòng tốt hơn so với ref đã lỗi thời: lệnh này tìm phần tử trên trang đang hiển thị và thao tác với nó chỉ trong một bước.

```bash
gologin-agent-browser find label "Email" fill "user@example.com"
gologin-agent-browser find role button click --name "Submit"
```

## Bắt đầu nhanh

```bash
export GOLOGIN_TOKEN='your_token'

# open a page in cloud browser
gologin-agent-browser open https://example.com

# read the page as a compact snapshot
gologin-agent-browser snapshot

# interact with elements
gologin-agent-browser click @e3
gologin-agent-browser type @e5 "hello world"

# take a screenshot
gologin-agent-browser screenshot ./page.png

# close the session
gologin-agent-browser close
```

---

## Ví dụ vòng lặp của agent

Một vòng lặp điển hình của AI agent:

```
1. open <url>
2. snapshot          → agent reads page content
3. click/type/fill   → agent acts on refs
4. snapshot          → agent reads result
5. repeat 3-4 as needed
6. screenshot        → save artifact
7. close
```

## Tham chiếu đầy đủ các lệnh

### Chẩn đoán

| Lệnh | Mô tả |
|---|---|
| `doctor` | Kiểm tra tình trạng và khả năng kết nối của daemon |

### Quản lý phiên

| Lệnh | Mô tả |
|---|---|
| `open <url>` | Mở URL trong một phiên trình duyệt |
| `close` | Đóng phiên hiện tại (`--all` đóng mọi phiên của daemon này) |
| `sessions` | Liệt kê các phiên đang hoạt động (`--prune` xóa các phiên đã cũ) |
| `current` | Hiển thị thông tin phiên hiện tại |

### Đọc trang

| Lệnh | Mô tả |
|---|---|
| `snapshot` | Snapshot văn bản gọn nhẹ kèm ref của phần tử |
| `screenshot <path>` | Lưu ảnh chụp màn hình trang |
| `pdf <path>` | Lưu trang dưới dạng PDF |
| `get <kind> [target]` | Lấy các thuộc tính của trang |

### Tương tác

| Lệnh | Mô tả |
|---|---|
| `click <ref>` | Nhấp vào một phần tử |
| `dblclick <ref>` | Nhấp đúp |
| `type <ref> <text>` | Nhập văn bản (nối thêm) |
| `fill <ref> <text>` | Điền vào ô nhập liệu (thay thế nội dung) |
| `hover <ref>` | Di chuột lên phần tử |
| `select <ref> <value>` | Chọn một giá trị trong danh sách thả xuống |
| `check <ref>` / `uncheck <ref>` | Bật/tắt hộp kiểm |
| `focus <ref>` | Đặt tiêu điểm vào một phần tử |
| `find <by> <locator> <action> [value]` | Tìm một phần tử theo `role`, `text`, `label`, `placeholder`, `first`, `last` hoặc `nth` rồi `click`, `fill`, `type` hoặc `hover` phần tử đó, hoặc đọc `text` của nó |

### Bàn phím và cuộn trang

| Lệnh | Mô tả |
|---|---|
| `press <key> [target]` | Nhấn một phím trên bàn phím |
| `scroll <direction> [pixels]` | Cuộn trang |
| `scrollintoview <ref>` | Cuộn phần tử vào vùng nhìn thấy |

### Điều hướng

| Lệnh | Mô tả |
|---|---|
| `back` | Quay lại |
| `forward` | Đi tiếp |
| `reload` | Tải lại trang |
| `wait <target\|ms>` | Chờ phần tử hoặc hết thời gian chờ |

### Tab

| Lệnh | Mô tả |
|---|---|
| `tabs` | Liệt kê các tab đang mở |
| `tabopen [url]` | Mở một tab mới |
| `tabfocus <index>` | Chuyển sang một tab |
| `tabclose [index]` | Đóng một tab |

### Cookie và bộ nhớ lưu trữ

| Lệnh | Mô tả |
|---|---|

### Hồ sơ, proxy và Gologin API

Các lệnh này gọi Gologin API bằng mã thông báo của bạn và không cần daemon trình duyệt.

| Lệnh | Mô tả |
|---|---|
| `api <METHOD> <path>` | Gọi bất kỳ endpoint REST API nào của Gologin |
| `browser <action>` | Hồ sơ: liệt kê, lấy thông tin, tạo, cập nhật, xóa, cookie, proxy, khởi động và dừng trên cloud, nhập và xuất |
| `proxy <action>` | Proxy: liệt kê, thêm proxy Gologin, cập nhật, xóa, lưu lượng |
| `workspace`, `folder`, `share`, `template` | Không gian làm việc và thành viên, thư mục, chia sẻ, mẫu hồ sơ |
| `user`, `deleted-profile` | Thông tin tài khoản và mã thông báo dành cho nhà phát triển, khôi phục hồ sơ đã xóa |
| `cloud-usage` | Mức sử dụng Cloud Browser của một hồ sơ hoặc không gian làm việc |
| `profile-cloud`, `profile-cookies`, `profile-fingerprint`, `profile-proxy`, `profile-ua` | Lệnh tắt: khởi động hoặc dừng hồ sơ trên cloud, xuất hoặc nhập cookie của hồ sơ, làm mới dấu vân tay, thêm proxy, cập nhật user agent |

```bash
gologin-agent-browser browser list --page 1
gologin-agent-browser proxy add-gologin your_profile_id --country us --type residential
gologin-agent-browser cloud-usage --profile your_profile_id
gologin-agent-browser api GET /browser/your_profile_id
```

Thêm `--help` vào bất kỳ lệnh nào để in cách sử dụng của lệnh đó.

## Trường hợp sử dụng và ví dụ

### Kiểm tra xem trang web của bạn có vượt qua các bài kiểm tra anti-detect không

```bash
gologin-agent-browser open https://iphey.com/ --profile your_profile_id
gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # read the trust score
gologin-agent-browser screenshot ./iphey-result.png
gologin-agent-browser close
```

### Đăng nhập vào ứng dụng web và trích xuất dữ liệu bảng điều khiển

```bash
gologin-agent-browser open https://app.example.com/login
gologin-agent-browser snapshot

# agent reads snapshot, finds login form
gologin-agent-browser fill @e4 "user@company.com"
gologin-agent-browser fill @e6 "password"
gologin-agent-browser click @e8

gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # agent reads dashboard content

# navigate to the report page
gologin-agent-browser click @e12   # "Reports" link
gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # agent extracts report data
gologin-agent-browser screenshot ./report.png
gologin-agent-browser close
```

### Điền biểu mẫu nhiều bước

```bash
gologin-agent-browser open https://forms.example.com/apply

# step 1: personal info
gologin-agent-browser snapshot
gologin-agent-browser fill @e3 "John Doe"
gologin-agent-browser fill @e5 "john@example.com"
gologin-agent-browser select @e7 "United States"
gologin-agent-browser click @e9   # Next

# step 2: upload and submit
gologin-agent-browser wait 1000
gologin-agent-browser snapshot
gologin-agent-browser upload @e4 ./resume.pdf
gologin-agent-browser check @e6   # agree to terms
gologin-agent-browser click @e8   # Submit

gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # confirm success
gologin-agent-browser close
```

### Chụp ảnh màn hình các trang của đối thủ cạnh tranh

```bash
# use different profiles with different geos
for profile in us_profile de_profile jp_profile; do
  gologin-agent-browser open https://competitor.com --profile $profile
  gologin-agent-browser wait 3000
  gologin-agent-browser screenshot ./${profile}-homepage.png
  gologin-agent-browser close
done
```

### Tìm kiếm trên trang web chặn scraping

Một số trang web yêu cầu thực thi JavaScript, đăng nhập hoặc tương tác trước khi hiển thị kết quả. Hãy dùng trình duyệt để tìm kiếm:

```bash
gologin-agent-browser open https://protected-directory.com
gologin-agent-browser snapshot
gologin-agent-browser find placeholder "Search" fill "machine learning engineer San Francisco"
gologin-agent-browser press Enter
gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # agent reads search results
gologin-agent-browser screenshot ./search-results.png
gologin-agent-browser close
```

### Lưu và khôi phục trạng thái phiên

Xuất cookie và bộ nhớ lưu trữ để tái sử dụng giữa các phiên:

```bash
# after logging in
gologin-agent-browser cookies --output ./session-cookies.json
gologin-agent-browser storage-export ./session-storage.json
gologin-agent-browser close

# later, restore the session
gologin-agent-browser open https://app.example.com
gologin-agent-browser cookies-import ./session-cookies.json
gologin-agent-browser storage-import ./session-storage.json
gologin-agent-browser reload
gologin-agent-browser snapshot     # already logged in
```

## Phiên song song

Dùng các ID `--session` rõ ràng cho các tác vụ cloud độc lập. Dọn dẹp bằng `close --all` hoặc `sessions --prune --older-than-ms`.

## Quy tắc về proxy

- Hồ sơ được cấu hình sẵn: proxy được đặt trên hồ sơ thông qua bảng điều khiển hoặc API của Gologin, ví dụ `proxy add-gologin <profileId> --country us`
- Hồ sơ cloud tạm thời: không dùng proxy, hoặc dùng proxy của riêng bạn với `--proxy-host` và `--proxy-port` (cùng với `--proxy-mode http|socks4|socks5`, `--proxy-user`, `--proxy-pass`)
- Trong môi trường chạy cloud, `open` không chấp nhận `--proxy-country`. Để dùng lưu lượng proxy Gologin từ một quốc gia, hãy thêm proxy Gologin vào một hồ sơ và mở hồ sơ đó bằng `--profile`
- Trong môi trường chạy cục bộ, `open`, `profile-create` và `profile-update` chấp nhận `--proxy-country`
