<Note>
  Local Agent Browser CLI nay đã trở thành một phần của [Agent Browser CLI](/vi/cli-tools/agent-browser). Gói npm `gologin-local-agent-browser-cli` đã bị đánh dấu là lỗi thời: hãy cài đặt `gologin-agent-browser-cli` và dùng `--runtime local`. Các script gọi `gologin-local-agent-browser` vẫn hoạt động bình thường, xem [Chuyển từ Local Agent Browser CLI](#chuy%E1%BB%83n-t%E1%BB%AB-local-agent-browser-cli).
</Note>

Agent Browser CLI có hai runtime với cùng một bộ lệnh. Runtime `cloud` chạy các phiên trong Gologin Cloud Browser. Runtime `local` chạy các phiên trong Orbita, trình duyệt của Gologin, ngay trên máy của bạn. Trang này nói về runtime local. Snapshot, ref và các lệnh khác hoạt động như mô tả trong trang [Agent Browser CLI](/vi/cli-tools/agent-browser).

---

## Khi nào dùng local, khi nào dùng cloud

| Dùng `local` cho | Dùng `cloud` cho |
|---|---|
| Warmup profile | Nhiều phiên chạy song song |
| Đăng nhập lần đầu và các bước kiểm tra bạn tự thực hiện thủ công | Phiên trình duyệt từ xa |
| Tái sử dụng trạng thái và cookie cục bộ của profile | Máy không nên chạy Orbita |
| Cho trình duyệt khớp với hệ điều hành của máy tính bạn | Profile tạm thời, không cần profile ID |
| Runbook và tác vụ hàng loạt trên nhiều profile | Ảnh chụp màn hình và PDF từ trình duyệt từ xa |

---

## Yêu cầu

- Node.js 20 trở lên. Runtime local khởi chạy Orbita thông qua Gologin Node.js SDK, và SDK này cần Node.js 20.
- Gologin API token trong `GOLOGIN_TOKEN`. Xem [Lấy token](/vi/cli-tools/agent-browser#l%E1%BA%A5y-m%C3%A3-th%C3%B4ng-b%C3%A1o).
- Một profile ID cho mỗi phiên. Khác với runtime cloud, runtime local không tạo profile tạm thời.
- Orbita. Nếu chưa được cài đặt, Gologin SDK sẽ tải Orbita về `~/.gologin/browser` ở lần khởi chạy đầu tiên. Nếu Orbita nằm ở nơi khác, hãy đặt `GOLOGIN_EXECUTABLE_PATH`.

---

## Cài đặt

```bash
npm install -g gologin-agent-browser-cli
```

Gói này cài đặt hai lệnh:

- `gologin-agent-browser` chạy các phiên trình duyệt trên cloud, trừ khi bạn chọn local.
- `gologin-local-agent-browser` là bí danh tương thích, chạy các lệnh trong runtime local.

---

## Chọn runtime local

Thêm `--runtime local` vào lệnh, hoặc đặt runtime một lần cho toàn bộ shell:

```bash
# one command
gologin-agent-browser open https://example.com --runtime local --profile your_profile_id

# every command in this shell
export GOLOGIN_AGENT_BROWSER_RUNTIME=local
```

`--local` và `local` đặt ở đầu cũng dùng được: `gologin-agent-browser local open https://example.com --profile your_profile_id`.

<Warning>
  Các lệnh phiên như `snapshot`, `click` và `close` sẽ chạy trên runtime cloud trừ khi bạn chọn local. Sau khi mở một phiên local, hãy thêm `--runtime local` vào mọi lệnh tiếp theo, hoặc đặt `GOLOGIN_AGENT_BROWSER_RUNTIME=local`.
</Warning>

| `--runtime` | Chức năng |
|---|---|
| `local` | Các lệnh trình duyệt và profile chạy trong Orbita cục bộ |
| `cloud` | Các lệnh trình duyệt chạy trong Gologin Cloud Browser |
| `auto` (mặc định) | Các lệnh profile, runbook và job chạy cục bộ, còn lại chạy trên cloud |

Các lệnh Gologin API như `api`, `browser` và `proxy` luôn gọi trực tiếp API, bất kể runtime nào.

## Biến môi trường

| Biến | Mô tả |
|---|---|
| `GOLOGIN_TOKEN` | Gologin API token. Bắt buộc với `open` và các lệnh profile |
| `GOLOGIN_PROFILE_ID` | Profile ID mặc định |
| `GOLOGIN_AGENT_BROWSER_RUNTIME` | Runtime mặc định: `cloud`, `local` hoặc `auto` |
| `GOLOGIN_EXECUTABLE_PATH` | Đường dẫn đến tệp thực thi Orbita, nếu Orbita không nằm trong `~/.gologin/browser` |
| `GOLOGIN_HEADLESS` | `true` chạy Orbita không có cửa sổ. Mặc định: `false` |
| `GOLOGIN_DAEMON_PORT` | Cổng của daemon cục bộ. Mặc định: `44778` |
| `GOLOGIN_TMPDIR` | Thư mục chứa các tệp profile tạm thời |

Runtime local lưu cấu hình, danh sách profile và lịch sử job trong `~/.gologin-local-agent-browser/`, cùng thư mục mà CLI cũ đã dùng.

## Bắt đầu nhanh

```bash
export GOLOGIN_TOKEN='your_token'
export GOLOGIN_AGENT_BROWSER_RUNTIME=local

# open a profile in a visible Orbita window
gologin-agent-browser open https://example.com --profile your_profile_id

# or open it without a window
gologin-agent-browser open https://example.com --profile your_profile_id --headless

# read the page and act on refs
gologin-agent-browser snapshot -i
gologin-agent-browser click @e3

gologin-agent-browser screenshot ./page.png
gologin-agent-browser close
```

`--visible` (hoặc `--headed`) và `--headless` (hoặc `--background`) chọn chế độ cửa sổ cho một lần `open`. `open-visible` và `open-background` là các lệnh tắt tương ứng.

## Lệnh trình duyệt

Các lệnh phiên giống như trong runtime cloud: `snapshot`, `click`, `type`, `fill`, `find`, `wait`, `press`, `scroll`, `tabs`, `cookies`, `storage-export`, `eval`, `screenshot`, `pdf`, `upload` và nhiều lệnh khác. Xem [tài liệu tham khảo lệnh](/vi/cli-tools/agent-browser#tham-chi%E1%BA%BFu-%C4%91%E1%BA%A7y-%C4%91%E1%BB%A7-c%C3%A1c-l%E1%BB%87nh). Hiện tại `back`, `forward` và `reload` chỉ hoạt động trong runtime cloud.

`find` xác định một phần tử trên trang đang mở và thao tác với nó chỉ trong một bước. Hãy dùng lệnh này khi ref bị lỗi thời trên các trang động:

```bash
gologin-agent-browser find placeholder "Search" fill "r/programming"
gologin-agent-browser find role button click --name "Submit"
```

## Lệnh profile

Các lệnh này chạy trong runtime local ngay cả khi không có `--runtime local`:

| Lệnh | Mô tả |
|---|---|
| `profiles` | Liệt kê profile: `--local`, `--remote` hoặc `--all`. Bộ lọc: `--platform`, `--status`, `--tag`, `--search` |
| `profile <id>` | Hiển thị một profile |
| `profile-create <name>` | Tạo profile trong tài khoản Gologin của bạn và thêm vào danh sách cục bộ |
| `profile-import <id>` | Thêm một profile Gologin có sẵn vào danh sách cục bộ |
| `profile-update <id>` | Thay đổi mẫu, tên, thẻ, ghi chú hoặc proxy |
| `profile-sync <id>` | Làm mới bản ghi cục bộ từ tài khoản Gologin của bạn |
| `profile-delete <id>` | Xóa profile khỏi danh sách cục bộ. Thêm `--remote` để xóa cả trong Gologin |

`profile-create` và `profile-update` nhận một mẫu theo tình huống sử dụng và một proxy. `--proxy-country us` thêm proxy của Gologin, còn `--proxy-host` kết hợp với `--proxy-port` dùng để đặt proxy của riêng bạn.

| Mẫu | Dùng cho |
|---|---|
| `linkedin` | Tìm kiếm khách hàng tiềm năng hoặc tuyển dụng trên LinkedIn, với các vòng warmup ngắn |
| `ads` (bí danh `facebook`) | Tài khoản quảng cáo cần cách ly nghiêm ngặt và proxy ổn định |
| `smm` | Profile mạng xã hội dùng chung giữa nhiều người, với cookie và bộ nhớ ổn định |
| `scraping` | Thu thập dữ liệu có render lặp lại, tái sử dụng cookie |
| `geo` | Kiểm thử theo vị trí địa lý và QA cho thị trường địa phương |

```bash
gologin-agent-browser profile-create "LinkedIn - Sales 1" --template linkedin --proxy-country us

# check Orbita, the token, the profile and its proxy for this use case
gologin-agent-browser doctor --runtime local --use-case linkedin --check-proxy your_profile_id
```

## Runbook và tác vụ hàng loạt

Runbook là một tệp JSON chứa danh sách các bước CLI:

```json
{
  "variables": { "url": "https://www.google.com" },
  "steps": [
    { "command": "open-visible", "args": ["${url}"] },
    { "command": "wait", "args": [2000] },
    { "command": "scroll", "args": ["down", 500] },
    { "command": "wait", "args": [1500] },
    { "command": "close" }
  ]
}
```

Chạy runbook trên một profile, hoặc trên nhiều profile song song:

```bash
gologin-agent-browser run ./warmup.json --profile your_profile_id
gologin-agent-browser batch ./warmup.json --targets ./targets.json --concurrency 5 --name daily-warmup
```

`targets.json` liệt kê các profile:

```json
{
  "targets": [
    { "name": "account-1", "profileId": "profile_id_1" },
    { "name": "account-2", "profileId": "profile_id_2" }
  ]
}
```

Kiểm tra kết quả bằng `jobs` và `job <jobId>`. `--status` nhận giá trị `running`, `ok`, `partial` hoặc `failed`:

```bash
gologin-agent-browser jobs --kind batch --status failed
```

## Chuyển từ Local Agent Browser CLI

```bash
npm uninstall -g gologin-local-agent-browser-cli
npm install -g gologin-agent-browser-cli
```

- Các script gọi `gologin-local-agent-browser` vẫn hoạt động. Lệnh này hiện đến từ `gologin-agent-browser-cli`.
- Profile, cấu hình và lịch sử job trong `~/.gologin-local-agent-browser/` vẫn giữ nguyên vị trí.
- Với AI agent, hãy cài đặt [Agent Browser skill](/vi/api-reference/ai-integrations/ai-skills). Skill này hỗ trợ cả hai runtime, còn Local Agent Browser skill riêng biệt đã bị đánh dấu là lỗi thời.
