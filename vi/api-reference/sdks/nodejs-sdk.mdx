### Cài đặt

```bash
npm i gologin
```

Yêu cầu Node.js 20 trở lên. SDK phiên bản 3 chỉ hỗ trợ ESM: hãy tải SDK bằng `import`, `require('gologin')` sẽ không hoạt động.

### Cách dùng cơ bản

```javascript
import GoLogin from 'gologin';

const GL = new GoLogin({
  token: 'your-api-token',
  profile_id: 'your-profile-id',
});

const { status, wsUrl } = await GL.start();
// Connect Puppeteer or Playwright using wsUrl
// ... your automation code ...
await GL.stop();
```

### Khởi chạy bằng GologinApi

`GologinApi` khởi chạy hồ sơ và tự động kết nối Puppeteer cho bạn. `launch()` trả về một `browser` của Puppeteer. Truyền `cloud: true` để chạy hồ sơ trên [Gologin Cloud Browser](/vi/api-reference/cloud-browser/what-is-gologin-cloud-browser) thay vì trình duyệt Orbita cục bộ:

```javascript
import { GologinApi } from 'gologin';

const gologin = GologinApi({ token: 'your-api-token' });

// local Orbita on this machine
const { browser } = await gologin.launch({ profileId: 'your-profile-id' });

// or Gologin Cloud Browser
// const { browser } = await gologin.launch({ cloud: true, profileId: 'your-profile-id' });

const page = await browser.newPage();
await page.goto('https://example.com');

// close the browser and stop the profile
await gologin.exit();
```

Nếu không truyền `profileId`, `launch()` sẽ tạo một hồ sơ mới trước. `GologinApi` còn có các hàm hỗ trợ như `createProfileRandomFingerprint()`, `addGologinProxyToProfile()`, `addCookiesToProfile()` và `deleteProfile()`. Xem [Quickstart](/vi/api-reference/introduction/quickstart) để có ví dụ đầy đủ.

### Các tham số chính

| Tham số | Mặc định | Mô tả |
|---|---|---|
| `token` | bắt buộc | Token API Gologin của bạn |
| `profile_id` | bắt buộc | ID của hồ sơ cần khởi chạy |
| `executablePath` | tự động | Đường dẫn đến tệp thực thi của trình duyệt Orbita |
| `uploadCookiesToServer` | `false` | Tải cookie lên đám mây khi dừng hồ sơ. Đặt thành `true` nếu bạn cần giữ phiên đăng nhập giữa nhiều thiết bị. |
| `extra_params` | `[]` | Các cờ Chromium bổ sung được truyền cho trình duyệt |

### Dừng hồ sơ

```javascript
// Stop and sync to cloud
await GL.stop();

// Stop without syncing profile data to cloud
await GL.stopLocal({ posting: false });
```

Trước tiên hãy đóng trình duyệt trong công cụ tự động hóa của bạn, ví dụ bằng `browser.close()`. `stop()` không nhận tùy chọn nào và luôn tải hồ sơ lên Gologin. `stopLocal({ posting: false })` kết thúc phiên mà không tải dữ liệu hồ sơ lên. Hãy dùng cách này trên máy chủ nếu bạn không muốn đồng bộ lên đám mây. Cookie vẫn được tải lên nếu bạn đặt `uploadCookiesToServer: true`.

### Quản lý phiên bản trình duyệt Orbita

Khi một hồ sơ khởi động, SDK sẽ kiểm tra phiên bản Orbita mà user agent của hồ sơ yêu cầu. Nếu phiên bản đó chưa có trong `~/.gologin/browser`, SDK sẽ tải xuống, nếu có rồi thì dùng lại bản đã cài. Để chạy một bản dựng cụ thể, hãy truyền `executablePath`. Các tùy chọn `autoUpdateBrowser` (mặc định là `false`) và `checkBrowserUpdate` vẫn được chấp nhận, nhưng trong SDK hiện tại (3.0.7) chúng không làm thay đổi hành vi này.

Để tải Orbita trước, hãy gọi `checkAndDownloadBrowserByOpts()` trên một đối tượng `GoLogin`. Đây là một phương thức, không phải một export riêng:

```javascript
import { GoLogin } from 'gologin';

const GL = new GoLogin({ token: 'your-api-token' });

// Pre-download the latest Orbita version
await GL.checkAndDownloadBrowserByOpts({ lastActualCount: 1 });

// Pre-download specific versions
await GL.checkAndDownloadBrowserByOpts({ majorVersions: [142, 143] });
```

Nếu không truyền tùy chọn, hàm sẽ tải 5 phiên bản mới nhất. Hãy dùng hàm này trước khi khởi chạy song song nhiều hồ sơ để tránh nhiều lượt tải xuống cùng lúc.

### Chạy hơn 100 hồ sơ song song

Khi chạy đồng thời nhiều hồ sơ trên máy chủ:

```javascript
// Use a queue to limit concurrent launches
const CONCURRENCY = 10;
const queue = [...profileIds];
const active = new Set();

async function launchProfile(profileId) {
  const gl = new GoLogin({ token, profile_id: profileId });
  try {
    const { wsUrl } = await gl.start();
    // ... your automation ...
  } finally {
    await gl.stop();
  }
}

async function processQueue() {
  while (queue.length > 0) {
    while (active.size >= CONCURRENCY) {
      await new Promise(r => setTimeout(r, 1000));
    }
    const id = queue.shift();
    active.add(id);
    launchProfile(id).finally(() => active.delete(id));
  }
}
```

**Lưu ý quan trọng khi dùng trên máy chủ:**
- Giới hạn số hồ sơ khởi chạy đồng thời (nên bắt đầu với 10-20)
- Tải trước các phiên bản Orbita trước khi khởi chạy
- Trên Linux: cài đặt Xvfb và đặt `DISPLAY=:99`
- Tăng giới hạn số file descriptor: `ulimit -n 65536`
- Theo dõi RAM: mỗi hồ sơ dùng khoảng 300-500 MB
