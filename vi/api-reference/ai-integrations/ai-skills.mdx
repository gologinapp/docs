Gologin AI Skills là các tiện ích mở rộng cắm là chạy dành cho [Claude Code](https://claude.ai/code), giúp các AI agent có khả năng thu thập dữ liệu web và tự động hóa trình duyệt. Mỗi skill đóng gói một công cụ Gologin CLI và cung cấp công cụ đó dưới dạng một tập hợp các hàm mà agent có thể gọi.

```
agent → skill → Gologin CLI → Web Unlocker API / Cloud Browser / Local Orbita
```

## Cài đặt

Tất cả các skill của Gologin đều được cài đặt từ kho lưu trữ [GologinLabs/agent-skills](https://github.com/GologinLabs/agent-skills):

```bash
# install any skill
npx skills add GologinLabs/agent-skills@gologin-web-access-skill
npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill
npx skills add GologinLabs/agent-skills@gologin-scraping-skill
```

Mỗi skill yêu cầu cài đặt CLI nền tảng tương ứng:

| Skill | CLI cần thiết |
|---|---|
| Web Access Skill | `npm i -g gologin-web-access` |
| Agent Browser Skill | `npm i -g gologin-agent-browser-cli` (môi trường chạy cloud và local) |
| Scraping Skill | `npm i gologin-webunlocker` |

## Web Access Skill

**Cài đặt:** `npx skills add GologinLabs/agent-skills@gologin-web-access-skill`

Đây là skill mặc định và linh hoạt nhất. Skill này ủy quyền cho CLI `gologin-web-access`.

**Công cụ scraping:** `scrape_url`, `read_page`, `scrape_markdown`, `scrape_text`, `scrape_json`, `batch_scrape`, `batch_extract`, `search_web`, `map_site`, `crawl_site`, `crawl_site_async`, `extract_structured`, `track_changes`, `batch_track_changes`, `parse_document`

**Công cụ trình duyệt:** `browser_open`, `browser_search`, `browser_snapshot`, `browser_click`, `browser_type`, `browser_screenshot`, `browser_close`, `browser_sessions`, `browser_current`

**Quy trình tích hợp sẵn:** browser-ref-loop, hybrid-read-then-interact, search-discover-and-scrape, lead-enrichment, competitive-monitoring, docs-ingestion, geo-testing, login-and-navigate-dashboard

Xem [tài liệu tham khảo Web Access CLI](/vi/cli-tools/web-access) để biết chi tiết đầy đủ về các lệnh.

## Agent Browser Skill

**Cài đặt:** `npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill`

Skill chỉ dành cho trình duyệt, dùng cho các phiên trực tiếp trong Gologin Cloud Browser (mặc định) hoặc trong các profile Orbita cục bộ với `--runtime local`. Dùng khi bạn cần duyệt web tương tác mà không cần scraping.

**Khả năng:** `doctor`, `open`, `sessions`, `current`, `snapshot`, `click`, `type`, `fill`, `find`, `get`, `tabs`, `tabopen`, `tabfocus`, `tabclose`, `cookies`, `cookies-import`, `storage-export`, `storage-import`, `eval`, `back`, `forward`, `reload`, `upload`, `screenshot`, `pdf`

**Local runtime bổ sung:** quản lý profile (`profiles`, `profile-create`, `profile-import`, `profile-update`, `profile-sync`, `profile-delete`), runbook (`run`, `batch`), tác vụ (`jobs`, `job`), mẫu theo trường hợp sử dụng (`linkedin`, `ads`, `smm`, `scraping`, `geo`) và chẩn đoán (`doctor --use-case --check-proxy`).

Xem [tài liệu tham khảo Agent Browser CLI](/vi/cli-tools/agent-browser) và [Local runtime](/vi/cli-tools/local-agent-browser) để biết chi tiết đầy đủ về các lệnh.

## Scraping Skill

**Cài đặt:** `npx skills add GologinLabs/agent-skills@gologin-scraping-skill`

Skill nhỏ gọn nhất — chỉ scraping thông qua Web Unlocker SDK. Không có phiên trình duyệt, không có daemon.

**Khả năng:** HTML thô (`scrape`), văn bản (`text`), markdown (`markdown`), siêu dữ liệu có cấu trúc (`json`). Các phương thức SDK: `scrapeRaw()`, `scrape()`, `scrapeText()`, `scrapeMarkdown()`, `scrapeJSON()`, `batchScrape()`.

Dùng khi tác vụ chỉ cần scraping và bạn muốn giảm thiểu các phụ thuộc.

Xem [tài liệu tham khảo Web Unlocker SDK](/vi/scraping-api-sdk-and-cli) để biết chi tiết về API.

## Local Agent Browser Skill (không còn được khuyến nghị sử dụng)

Nếu agent của bạn vẫn đang dùng `gologin-local-agent-browser-skill`, skill này chỉ hướng agent sang skill Agent Browser. Hãy cài đặt `gologin-agent-browser-skill` thay thế: skill này hỗ trợ các profile Orbita cục bộ, warmup, luồng đăng nhập, runbook và các tác vụ hàng loạt.

## Bạn có thể yêu cầu agent làm gì

Sau khi cài đặt skill, bạn trò chuyện với Claude Code bằng ngôn ngữ tự nhiên. Dưới đây là những gì mỗi skill có thể làm:

### Với Web Access Skill

- "Đọc trang bảng giá tại competitor.com và tóm tắt các gói"
- "Scrape 15 URL này và trích xuất tên sản phẩm và giá của từng sản phẩm"
- "Crawl tài liệu tại docs.example.com và tóm tắt từng phần cho tôi"
- "Tìm kiếm 'best CRM tools 2026' và scrape 5 kết quả đầu tiên"
- "Kiểm tra xem competitor.com/pricing có thay đổi so với hôm qua không"
- "Trích xuất tiêu đề và URL của tất cả bài viết blog từ trang web này"
- "Mở example.com trong trình duyệt, đăng nhập bằng thông tin này và chụp ảnh màn hình dashboard"

### Với Agent Browser Skill

- "Mở dashboard quản trị, vào Cài đặt và chụp ảnh màn hình cấu hình hiện tại"
- "Đăng nhập vào môi trường staging và kiểm tra xem tính năng mới đã được triển khai chưa"
- "Điền biểu mẫu đăng ký trên example.com bằng các thông tin thử nghiệm này"
- "Vào trang báo cáo, tải xuống bản xuất hàng tháng và chụp ảnh màn hình phần tóm tắt"
- "Kiểm tra iphey.com hiển thị gì cho profile trình duyệt này"

### Với Scraping Skill

- "Scrape URL này và cho tôi nội dung văn bản"
- "Lấy tiêu đề, mô tả và các heading từ 10 trang này"
- "Lấy trang này dưới dạng markdown để tôi phân tích"

### Với Agent Browser Skill (local runtime)

- "Tạo một profile LinkedIn mới với proxy Mỹ và làm nóng profile đó"
- "Mở tài khoản Reddit của tôi, cuộn qua bảng tin rồi đóng lại"
- "Chạy runbook warmup trên tất cả 20 profile với mức đồng thời là 5"
- "Kiểm tra tình trạng proxy của các profile quảng cáo Facebook của tôi"
- "Đăng nhập vào tài khoản sàn thương mại điện tử này và chụp ảnh màn hình dashboard người bán"

## Ví dụ quy trình

### Nghiên cứu đối thủ cạnh tranh (Web Access Skill)

1. Agent tìm kiếm các đối thủ: `search_web("saas project management tools")`
2. Agent lập bản đồ trang web của một đối thủ: `map_site("https://competitor.com")`
3. Agent scrape hàng loạt các trang quan trọng: `batch_scrape(pricing, features, about)`
4. Agent chuyển nội dung cho Claude để phân tích và so sánh

### Làm nóng tài khoản (Agent Browser Skill, local runtime)

1. Agent tạo các profile: `profile-create "Account 1" --template linkedin`
2. Agent chạy runbook warmup: `batch ./warmup.json --targets ./profiles.json`
3. Agent kiểm tra kết quả tác vụ: `jobs --kind batch --status ok`
4. Agent báo cáo những profile nào đã sẵn sàng

### Theo dõi dashboard (Agent Browser Skill)

1. Agent mở dashboard: `open https://dashboard.example.com --profile saved_login`
2. Agent đọc trang: `snapshot`
3. Agent chuyển đến phần số liệu: `click @e5` (liên kết Báo cáo)
4. Agent chụp ảnh màn hình báo cáo: `screenshot ./daily-metrics.png`
5. Agent đóng phiên: `close`
6. Agent tóm tắt các số liệu từ dữ liệu snapshot

## Bước kiểm tra bắt buộc trước khi chạy

Trước khi thực hiện bất kỳ tác vụ nào, các skill sẽ phân loại công việc:

1. **Một trang web đã biết hay nghiên cứu rộng từ nhiều nguồn?** — xác định có cần scraping hoặc tìm kiếm hay không
2. **Chỉ trích xuất dữ liệu, theo dõi thay đổi hay làm việc tương tác với trình duyệt?** — xác định dùng scraping hay trình duyệt
3. **Chỉ cần Web Unlocker, hay cần cả Web Unlocker và Cloud Browser?** — xác định thông tin xác thực cần thiết
4. **Có nhạy cảm về vị trí địa lý hoặc bị chặn đến mức cần dùng Gologin từ đầu đến cuối không?** — xác định yêu cầu về proxy/profile
