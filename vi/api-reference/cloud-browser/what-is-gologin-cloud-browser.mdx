Gologin Cloud Browser cho phép bạn chạy trình duyệt Gologin (Orbita) **trên đám mây** và điều khiển nó từ mã tự động hóa của bạn (Puppeteer / Playwright) chỉ bằng một **URL kết nối**.

Đây là một [trình duyệt headless](./what-is-headless-browser) — trình duyệt được điều khiển hoàn toàn bằng mã, không có giao diện đồ họa — do Gologin lưu trữ và quản lý, tích hợp sẵn khả năng hỗ trợ hồ sơ lưu trữ lâu dài, cấu hình vân tay trình duyệt và định tuyến qua proxy.

## Bạn có thể làm gì với Cloud Browser

- Chạy song song nhiều phiên trình duyệt trên đám mây
- Tự động hóa với bộ công cụ hiện có của bạn (Puppeteer / Playwright)
- Dùng **hồ sơ** Gologin để giữ trạng thái lâu dài (đăng nhập, cookie, bộ nhớ lưu trữ)
- Định tuyến lưu lượng qua **proxy** bằng cách cấu hình proxy trong hồ sơ
- Dùng làm môi trường trình duyệt từ xa cho các tác nhân AI

## Khác biệt so với trình duyệt headless thông thường

Chrome headless thông thường rất dễ bị phát hiện. Các trang web dùng kỹ thuật nhận dạng vân tay trình duyệt để xác định lưu lượng tự động — kiểm tra kết xuất canvas, tham số WebGL, phông chữ, múi giờ, kích thước màn hình và hàng chục tín hiệu khác.

Gologin Cloud Browser chạy **Orbita** — một bản Chromium đã được tùy biến để quản lý các tín hiệu vân tay sao cho khớp với một hồ sơ trình duyệt nhất quán và chân thực. Kết hợp với cookie lưu trữ lâu dài và cấu hình proxy được lưu trong từng hồ sơ, các phiên của bạn trông ổn định và giống người dùng thật qua các lần truy cập lặp lại.

## Vì sao nên chọn Gologin Cloud Browser

### Tích hợp sẵn chống phát hiện — không cần plugin

Chrome headless tiêu chuẩn rất dễ bị phát hiện. Các dịch vụ cloud browser khác chạy Chromium gốc và cần plugin chống phát hiện của bên thứ ba để giảm tín hiệu vân tay — với kết quả không đồng đều.

Gologin Cloud Browser chạy **Orbita**, một bản dựng Chromium được gia cố với khả năng quản lý vân tay ngay từ lõi: canvas, WebGL, phông chữ, múi giờ, độ phân giải màn hình và nhiều hơn nữa. Chống phát hiện không phải là một bản vá thêm vào — nó chính là trình duyệt.

### Hồ sơ lưu trữ lâu dài — phiên làm việc biết ghi nhớ

Hầu hết dịch vụ cloud browser xem mỗi phiên là không lưu trạng thái. Cookie và bộ nhớ lưu trữ bị xóa khi phiên kết thúc.

Hồ sơ Gologin được lưu giữ. Đăng nhập một lần, đóng phiên, kết nối lại sau đó — hồ sơ vẫn giữ nguyên cookie, local storage và mọi cài đặt đã cấu hình. Không cần xác thực lại, không cần làm nóng phiên.

### Không bị khóa vào nhà cung cấp

Gologin Cloud Browser là một endpoint CDP tiêu chuẩn. Mã Puppeteer hoặc Playwright của bạn kết nối với nó theo cách giống hệt khi kết nối với bất kỳ phiên bản Chrome từ xa nào — không cần SDK độc quyền, không cần học API riêng. Chuyển sang hoặc rời đi chỉ bằng cách đổi một URL.

## Các tình huống kỹ thuật phổ biến

Cloud Browser thường được dùng cho những quy trình mà bạn:

- đăng nhập vào tài khoản web một lần và giữ phiên lâu dài thông qua hồ sơ
- thực hiện lặp lại các thao tác trên cùng các trang web với nhiều hồ sơ
- cần các phiên ổn định, chạy trong thời gian dài mà không phụ thuộc vào máy tính cục bộ

Ví dụ bao gồm tự động hóa các phiên đã đăng nhập cho ứng dụng web, sàn thương mại điện tử hoặc nền tảng mạng xã hội, nơi tính lưu trữ lâu dài và cài đặt hồ sơ nhất quán là điều quan trọng.

## Khái niệm cốt lõi

- **Hồ sơ** — một danh tính trình duyệt có thể tái sử dụng (cookie/bộ nhớ lưu trữ + cài đặt vân tay và proxy).
- **Phiên đám mây** — một phiên bản đang chạy của hồ sơ trên đám mây của Gologin.
- **URL kết nối** — endpoint bạn truyền cho công cụ tự động hóa để điều khiển phiên đám mây.

## Cách hoạt động (tổng quan)

1. (Khuyến nghị) Tạo và cấu hình hồ sơ thông qua Gologin REST API (proxy, vân tay trình duyệt, v.v.).
2. Kết nối với Cloud Browser bằng **dev token** của bạn và `profileId` tùy chọn.
3. Tự động hóa phiên bằng Puppeteer hoặc Playwright.
4. Đóng kết nối khi bạn hoàn tất.

## URL kết nối

Dùng URL này làm endpoint trình duyệt từ xa:

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${profileId}
```

- `token` — **dev token** Gologin của bạn (tạo trong ứng dụng Gologin: [API & MCP](https://app.gologin.com/personalArea/TokenApi) → **API** → **Mã thông báo mới**).
- `profile` — **ID hồ sơ** (tùy chọn). Nếu bỏ qua, một hồ sơ mới sẽ được tạo cho phiên.

## Quản lý hồ sơ (proxy, vân tay trình duyệt, v.v.)

Cloud Browser là **lớp kết nối**.\
Để tạo/cập nhật hồ sơ, gắn proxy và cấu hình các cài đặt hồ sơ, hãy dùng Gologin REST API:

- API hồ sơ: [Tạo hồ sơ](https://gologin.com/docs/api-reference/profile/create-profile-with-partial-parameters), [Cập nhật hồ sơ](https://gologin.com/docs/api-reference/profile/update-profile-with-partial-parameters)
- API proxy: [Thêm proxy Gologin vào hồ sơ](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy), [Đặt proxy riêng của bạn cho hồ sơ](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles)

## Dùng Cloud Browser từ CLI

Nếu bạn thích dùng lệnh shell hơn là viết mã Puppeteer/Playwright, Gologin cung cấp các công cụ CLI thân thiện với tác nhân AI:

- **[Gologin Agent Browser CLI](/vi/cli-tools/agent-browser)** — CLI cloud browser với daemon, ảnh chụp nhanh trang, tương tác dựa trên ref. Được xây dựng cho các tác nhân AI.
- **[Gologin Web Access CLI](/vi/cli-tools/web-access)** — CLI hợp nhất, kết hợp thu thập dữ liệu bằng Web Unlocker với tương tác Cloud Browser trong một công cụ.

```bash
npm install -g gologin-agent-browser-cli
export GOLOGIN_TOKEN='your_token'

gologin-agent-browser open https://example.com
gologin-agent-browser snapshot
gologin-agent-browser click @e3
gologin-agent-browser screenshot ./page.png
gologin-agent-browser close
```
