---
title: "Что такое Web Unlocker?"
---

Web Unlocker — это универсальный Scraping API. Отправьте любой URL и получите полностью отрисованный HTML либо страницу в формате Markdown или JSON, без необходимости управлять браузерами и прокси.

Он заменяет браузерную и прокси-часть вашего стека для парсинга: рендеринг, управление прокси и отпечатки браузера обрабатываются одним API-вызовом. Статические страницы и сайты с большим количеством JavaScript проходят через один и тот же эндпоинт.

---

## Какие задачи он решает

Современные сайты сложно парсить. Обычный вызов `curl` или `requests` часто возвращает пустой ответ или некорректный HTML, потому что контент загружается с помощью JavaScript. Web Unlocker берёт на себя:

- **Рендеринг JavaScript** — страницы загружаются в настоящем браузере, и скрипты полностью выполняются до получения контента
- **Умную ротацию IP** — запросы направляются через резидентные IP с реалистичными отпечатками браузера
- **Выбор ценового уровня** — запросы направляются через подходящий для целевого сайта уровень прокси

---

## Что вы получаете в ответ

Успешный запрос возвращает страницу в одном формате. Выберите его с помощью параметра запроса `format`:

| `format` | Что вы получаете |
| --- | --- |
| `html` (по умолчанию) | Полный отрисованный DOM страницы |
| `markdown` | Содержимое страницы в формате Markdown |
| `json` | JSON-объект с URL страницы, метаданными запроса и HTML |

## Web Unlocker и собственные прокси

Содержать собственную прокси-инфраструктуру дорого и ненадёжно. Web Unlocker берёт всё на себя как управляемый сервис:

|  | Web Unlocker | Собственные прокси |
| --- | --- | --- |
| Настройка | Один API-вызов | Недели работы над инфраструктурой |
| Отпечатки браузера | Встроены | Нужно создавать или покупать отдельно |
| Ротация IP | Автоматическая | Ручное управление пулом |
| Обслуживание | Не требуется | Постоянное |

## Как это работает

Web Unlocker запускает настоящий браузер Chromium в облаке для каждой задачи. Когда вы отправляете URL:

1. Запускается браузер с резидентным IP и реалистичным отпечатком браузера
2. Выполняется переход на страницу, исполняется JavaScript и загружается динамический контент
3. Возвращается отрисованный HTML, а при указании `format` — Markdown или JSON

Вам не нужно управлять инфраструктурой. Не нужно запускать браузеры, поддерживать списки прокси и писать логику рендеринга. Web Unlocker заменяет фреймворк автоматизации браузера и провайдера прокси одним HTTP-запросом.

## Как использовать

Отправьте GET-запрос с целевым URL в параметре запроса. В ответе вы получите полностью отрисованный HTML.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Чтобы получить Markdown или JSON, добавьте в запрос `format=markdown` или `format=json`.

Примеры на Python и JavaScript, а также [коды ошибок](/ru/web-unlocker-quick-start#%D0%BE%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0-%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA) смотрите в [кратком руководстве](/ru/web-unlocker-quick-start), а типичные схемы интеграции — в разделе [Сценарии использования](/ru/web-unlocker-use-cases).
