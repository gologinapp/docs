---
title: "Что такое Web Unlocker?"
---

Web Unlocker — это универсальный API для скрейпинга. Отправьте любой URL и получите полностью отрендеренный HTML, скриншот и сетевой архив — без управления инфраструктурой, без блокировок и без неудачных запросов.

Он полностью заменяет ваш стек для скрейпинга: автоматизацию браузера, управление прокси, подмену отпечатков, решение CAPTCHA — всё это выполняется одним вызовом API. Неважно, скрейпите вы простую статическую страницу или сильно защищённый сайт с JavaScript-рендерингом, — с ними справляется один и тот же эндпоинт.

---

## Какие задачи он решает

Современные сайты сложно скрейпить. Обычный вызов `curl` или `requests` часто возвращает страницу с проверкой, пустой ответ или «сломанный» HTML, потому что контент загружается с помощью JavaScript. Web Unlocker автоматически решает все эти проблемы:

- **Рендеринг JavaScript** — страницы загружаются в настоящем браузере, и контент фиксируется только после полного выполнения скриптов
- **Обход антибот-защиты** — Cloudflare, DataDome, PerimeterX и подобные системы обрабатываются автоматически
- **Умная ротация IP** — запросы направляются через чистые резидентные IP-адреса с реалистичными отпечатками браузера
- **Решение CAPTCHA** — распространённые CAPTCHA решаются без вашего участия
- **Выбор ценового уровня** — запросы направляются через подходящий уровень прокси для целевого сайта

## Что вы получаете в ответ

Каждая успешная задача возвращает три типа контента:

| Контент | Формат | Описание |
| --- | --- | --- |
| **HTML** | Строка с полным HTML | Полный отрендеренный DOM страницы |
| **Скриншот** | PNG-изображение | Снимок страницы в том виде, в каком она отображалась в браузере |
| **Архив** | ZIP (HAR) | Сетевой лог со всеми запросами, заголовками и ресурсами |

## Как это работает

Для каждой задачи Web Unlocker запускает в облаке настоящий браузер Chromium. Когда вы отправляете URL:

1. Запускается браузер с резидентным IP-адресом и реалистичным отпечатком браузера
2. Выполняется переход на страницу, исполняется JavaScript и загружается динамический контент
3. Антибот-проверки и CAPTCHA обрабатываются автоматически
4. Отрендеренный HTML, скриншот и сетевой архив фиксируются и возвращаются вам

Вам не нужно управлять инфраструктурой. Не нужно запускать браузеры, поддерживать списки прокси и писать логику обхода защиты. Web Unlocker заменяет целый стек для скрейпинга — фреймворк автоматизации браузера, прокси-провайдера и антибот-решение — одним HTTP-запросом.

## Как использовать

Отправьте GET-запрос, передав целевой URL в качестве параметра запроса. В ответ вы получите полностью отрендеренный HTML.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Примеры на Python и JavaScript смотрите в разделе [Быстрый старт](/ru/web-unlocker-quick-start), а типовые схемы интеграции — в разделе [Сценарии использования](./web-unlocker-use-cases.md).
