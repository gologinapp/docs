---
title: "Что такое Web Unlocker?"
---

Web Unlocker — это универсальный scraping API. Отправьте любой URL и получите полностью отрисованный HTML или страницу в формате Markdown или JSON — без управления инфраструктурой, без блокировок и без неудачных запросов.

Он полностью заменяет ваш стек для скрапинга: автоматизацию браузера, управление прокси, подмену отпечатков, решение CAPTCHA — всё выполняется одним вызовом API. Неважно, скрапите вы простую статическую страницу или сайт с мощной защитой и JavaScript-рендерингом, с ними справляется один и тот же эндпоинт.

---

## Какие задачи он решает

Современные сайты сложно скрапить. Обычный вызов `curl` или `requests` часто возвращает страницу с проверкой, пустой ответ или «сломанный» HTML, потому что контент подгружается через JavaScript. Web Unlocker берёт всё это на себя:

- **JavaScript-рендеринг** — страницы загружаются в настоящем браузере, и скрипты полностью выполняются до того, как контент будет получен
- **Обход антибот-защиты** — Cloudflare, DataDome, PerimeterX и подобные системы защиты обрабатываются автоматически
- **Умная ротация IP** — запросы проходят через чистые резидентные IP-адреса с реалистичными отпечатками браузера
- **Решение CAPTCHA** — распространённые CAPTCHA решаются без вашего участия
- **Выбор ценового уровня** — запросы направляются через подходящий для целевого сайта уровень прокси

## Что вы получаете в ответ

Успешный запрос возвращает страницу в одном формате. Выбрать его можно с помощью query-параметра `format`:

| `format` | Что вы получаете |
| --- | --- |
| `html` (по умолчанию) | Полный отрисованный DOM страницы |
| `markdown` | Содержимое страницы в формате Markdown |
| `json` | JSON-объект с URL страницы, метаданными запроса и HTML |

## Как это работает

Web Unlocker запускает настоящий браузер Chromium в облаке для каждой задачи. Когда вы отправляете URL:

1. Запускается браузер с резидентным IP и реалистичным отпечатком браузера
2. Выполняется переход на страницу, исполняется JavaScript и загружается динамический контент
3. Антибот-проверки и CAPTCHA обрабатываются автоматически
4. Возвращается отрисованный HTML, а если вы указали `format` — Markdown или JSON

Вам не нужно управлять инфраструктурой. Не нужно запускать браузеры, поддерживать списки прокси и создавать логику обхода защиты. Web Unlocker фактически заменяет весь стек для скрапинга — фреймворк для автоматизации браузера, прокси-провайдера и антибот-решение — одним HTTP-запросом.

## Как использовать

Отправьте GET-запрос, передав целевой URL в query-параметре. В ответ вы получите полностью отрисованный HTML.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Чтобы получить Markdown или JSON, добавьте в запрос `format=markdown` или `format=json`.

Примеры на Python и JavaScript и [коды ошибок](/ru/web-unlocker-quick-start#%D0%BE%D0%B1%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0-%D0%BE%D1%88%D0%B8%D0%B1%D0%BE%D0%BA) смотрите в [кратком руководстве](/ru/web-unlocker-quick-start), а типичные схемы интеграции — в разделе [Сценарии использования](/ru/web-unlocker-use-cases).
