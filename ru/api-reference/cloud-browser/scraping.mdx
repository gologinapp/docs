## Обзор

Gologin Cloud Browser можно использовать как управляемый удалённый браузер для скрапинга и извлечения данных. Ваш код автоматизации (Puppeteer) подключается к удалённой браузерной сессии через WebSocket-эндпоинт, а затем выполняет стандартную логику навигации и извлечения данных.

Cloud Browser — это слой подключения и выполнения; настройки профилей и прокси управляются через REST API. Такой подход может снизить затраты на инфраструктуру и уменьшить количество препятствий при скрапинге, однако результат зависит от поведения целевого сайта и применяемых им средств защиты.

## Что вы получаете

- Удалённые браузерные сессии для подключений через Puppeteer.
- Рендеринг JavaScript для динамических страниц.
- Масштабирование без необходимости поддерживать собственную браузерную инфраструктуру.
- Настройка профилей и прокси через API.
- Единый канонический эндпоинт подключения для запуска сессии.

## Типичный процесс работы

1. Создайте API-токен.
2. При необходимости создайте и настройте профиль (и прокси) через REST API.
3. Сформируйте URL подключения с параметром `token` и, при необходимости, `profile`.
4. Подключитесь из Puppeteer/Playwright и запустите извлечение данных.
5. Сохраните результат и закройте браузерную сессию.

## Предварительные требования

- Создайте токен: в приложении Gologin откройте [API & MCP](https://app.gologin.com/personalArea/TokenApi) → **API** → **Новый токен**
- Profiles API (рекомендуется для контролируемой конфигурации): [Создание профиля](https://gologin.com/docs/api-reference/profile/create-profile-with-partial-parameters), [Обновление профиля](https://gologin.com/docs/api-reference/profile/update-profile-with-partial-parameters)
- Proxy API: [Добавление прокси Gologin в профиль](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy), [Настройка собственного прокси для профилей](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles)

## Канонический эндпоинт подключения

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${profileId}
```

- Параметр `token` обязателен.
- Параметр `profile` необязателен.
- Если `profile` не указан, для сессии создаётся новый профиль.

## Минимальный пример на Puppeteer

```javascript
const puppeteer = require('puppeteer-core');

(async () => {


  const token = 'your_token_here';
  const profileId = 'your_profile_id'; // Set to '' to create a new profile for this session
  const cloudBrowserUrl = `https://cloudbrowser.gologin.com/connect?token=${token}${profileId ? `&profile=${profileId}` : ''}`;
  const browser = await puppeteer.connect({
  
    browserWSEndpoint: cloudBrowserUrl,
    defaultViewport: null
  
  });

  const page = await browser.newPage();
  await page.goto('https://example.com');
  const title = await page.title();
  console.log('Page title:', title);
  await page.screenshot({ path: 'screenshot.png' });
  await browser.close();

})();
```

## Рекомендации

- Используйте явные ожидания вместо фиксированных пауз.
- Реализуйте логику повторных попыток с ограниченной задержкой между попытками и джиттером.
- Сохраняйте результаты извлечения в структурированном виде (URL, поля, временная метка, статус).
- Настраивайте профиль и прокси до подключения, чтобы результаты были воспроизводимыми.
- Всегда закрывайте сессии и обрабатывайте очистку ресурсов при сбоях.
- Адаптируйте поведение запросов и сессий к ограничениям конкретного сайта.

## FAQ

### Нужен ли мне профиль?

Нет. Параметр `profile` необязателен. Если его не указать, для сессии будет создан новый профиль. Используйте профиль, когда вам нужна контролируемая и повторяемая конфигурация.

### Где настраивать прокси?

Настраивайте прокси через REST API: [добавьте прокси Gologin в профиль](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy) или [задайте собственный прокси для профилей](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles).

### Чем это отличается от Cloud Browser?

Ничем. Эта страница описывает использование самого Cloud Browser для скрапинга и извлечения данных. Cloud Browser отвечает за подключение и выполнение, а настройки профилей и прокси управляются через REST API.
