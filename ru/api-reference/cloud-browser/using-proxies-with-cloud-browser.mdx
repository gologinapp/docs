---
title: "Использование прокси с Cloud Browser"
---

Gologin Cloud Browser поддерживает гибкую настройку прокси для маршрутизации трафика ваших сессий браузера. Вы можете использовать встроенные резидентные прокси Gologin или подключить свои.

## Как работают прокси в Gologin

В отличие от настройки прокси на уровне сессии, **прокси в Gologin привязываются к профилям**, а не к отдельным подключениям.

Когда вы подключаетесь к сессии Cloud Browser с указанием ID профиля, прокси, настроенный в этом профиле, применяется автоматически:

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${profileId}
```

Это означает, что вы настраиваете прокси один раз (через REST API или личный кабинет), и каждая сессия с этим профилем будет стабильно работать через него — передавать данные для авторизации на прокси при каждом подключении не нужно.

> Если прокси профиля недоступен при запуске сессии, подключение завершится ошибкой тайм-аута прокси. Перед запуском автоматизации убедитесь, что прокси работает.

## Варианты прокси

### Встроенные прокси Gologin

Gologin предоставляет собственную сеть резидентных прокси с выбором геолокации. Встроенные прокси — самый простой вариант: сторонний поставщик прокси не нужен.

Чтобы привязать прокси Gologin к профилю, воспользуйтесь [Proxies API](https://gologin.com/docs/api-reference/proxy/): создайте прокси и назначьте его профилю.

Встроенные прокси поддерживают выбор геолокации по стране и региону. При создании прокси укажите в `autoProxyRegion` нужный код страны:

```json
{
  "mode": "geolocation",
  "autoProxyRegion": "us"
}
```

Распространённые коды регионов: `us`, `gb`, `de`, `fr`, `nl`, `jp`, `au`, `ca`, `br`, `in`

### Собственный прокси

К профилю можно привязать любой сторонний прокси. Gologin поддерживает прокси `http`, `https` и `socks5`.

Настройте прокси через [Proxies API](https://gologin.com/docs/api-reference/proxy/):

```json
{
  "mode": "http",
  "host": "your.proxy.host",
  "port": 10000,
  "username": "user",
  "password": "pass"
}
```

Прокси проверяется при запуске сессии. Если прокси недоступен, сессия не запустится.

### Без прокси

Чтобы запустить сессию без прокси, установите для профиля режим прокси `none`:

```json
{
  "mode": "none"
}
```

Это удобно для тестирования или для сценариев, в которых достаточно собственного IP-адреса сервера автоматизации.

## Управление прокси через API

Полное управление прокси (создание, обновление, удаление, получение списка, проверка трафика) доступно через REST API:

- [Справочник Proxies API](https://gologin.com/docs/api-reference/proxy/)

## Проверка статуса прокси перед подключением

Поскольку неработающий прокси не позволяет запустить сессию, рекомендуется проверять прокси перед запуском автоматизации, особенно в рабочих (production) процессах:

```javascript
const profileRes = await fetch(`https://api.gologin.com/browser/${profileId}`, {
  headers: { Authorization: `Bearer ${token}` },
});
const profile = await profileRes.json();

if (profile.proxy?.mode !== 'none') {
  // optionally verify proxy reachability here before connecting
}
```
