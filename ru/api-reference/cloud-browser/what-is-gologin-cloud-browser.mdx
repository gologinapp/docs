title: "Что такое Gologin Cloud Browser"

Gologin Cloud Browser позволяет запускать браузер Gologin (Orbita) **в облаке** и управлять им из кода автоматизации (Puppeteer / Playwright) через единый **URL подключения**.

Это [headless-браузер](./what-is-headless-browser) — браузер, которым полностью управляет код, без графического интерфейса. Он размещён и поддерживается Gologin и имеет встроенную поддержку постоянных профилей, настройки отпечатков и маршрутизации через прокси.

## Что можно делать с Cloud Browser

- Запускать несколько сессий браузера параллельно в облаке
- Автоматизировать работу с помощью привычных инструментов (Puppeteer / Playwright)
- Использовать **профили** Gologin для сохранения состояния (логины, cookies, хранилище)
- Направлять трафик через **прокси**, настроив их в профиле
- Использовать его с ИИ-агентами как удалённую среду выполнения браузера

## Чем он отличается от обычного headless-браузера

Обычный headless Chrome легко обнаружить. Сайты используют фингерпринтинг браузера, чтобы выявлять автоматизированный трафик: проверяют отрисовку canvas, параметры WebGL, шрифты, часовой пояс, размер экрана и десятки других сигналов.

Gologin Cloud Browser работает на **Orbita** — модифицированном Chromium, который управляет сигналами отпечатка так, чтобы они соответствовали согласованному и реалистичному профилю браузера. Благодаря постоянным cookies и настройкам прокси, которые хранятся в каждом профиле, ваши сессии выглядят стабильно и естественно при повторных посещениях.

## Почему Gologin Cloud Browser

### Встроенный антидетект — плагины не нужны

Обычный headless Chrome обнаруживается без труда. Другие сервисы облачных браузеров запускают стандартный Chromium и требуют сторонних stealth-плагинов, чтобы снизить количество сигналов отпечатка, причём результаты получаются разными.

Gologin Cloud Browser работает на **Orbita** — усиленной сборке Chromium, в основе которой лежит управление отпечатком: canvas, WebGL, шрифты, часовой пояс, разрешение экрана и многое другое. Антидетект здесь — не надстройка, а сам браузер.

### Постоянные профили — сессии, которые помнят состояние

Большинство сервисов облачных браузеров рассматривают каждую сессию как не сохраняющую состояние. Cookies и хранилище удаляются при закрытии сессии.

Профили Gologin сохраняются. Войдите в аккаунт один раз, закройте сессию, подключитесь позже — профиль сохранит cookies, локальное хранилище и все настроенные параметры. Не нужно заново входить в аккаунт и «прогревать» сессию.

### Предсказуемая цена — оплата за время, а не за трафик

| **Трафик прокси**   | \$1.99 / ГБ                                | За МБ (с минимумом на сессию)    |
| **ISP-прокси**      | \$5 / IP, безлимитный трафик               | За ГБ                            |
| **Включённые часы** | 20–200 ч/месяц в зависимости от тарифа     | Обычно отсутствуют               |

### Никакой привязки к поставщику

Gologin Cloud Browser — это стандартная конечная точка CDP. Ваш код на Puppeteer или Playwright подключается к нему так же, как к любому удалённому экземпляру Chrome: без проприетарного SDK и без необходимости изучать собственный API. Перейти на него или отказаться от него можно, изменив один URL.

### Параллельные сессии, которые масштабируются

В тарифы изначально входят 1–4 параллельные сессии. Нужно больше — свяжитесь с нами, чтобы подобрать индивидуальный тариф.

## Типичные технические сценарии

Cloud Browser обычно используют в задачах, где вам нужно:

- один раз войти в веб-аккаунт и сохранить сессию через профиль
- многократно выполнять одни и те же действия на одних и тех же сайтах с множеством профилей
- получить стабильные длительные сессии, не зависящие от локального компьютера

Примеры: автоматизация сессий с авторизацией для веб-приложений, маркетплейсов и социальных платформ, где важны сохранение состояния и согласованные настройки профиля.

## Основные понятия

- **Профиль** — многоразовая идентичность браузера (cookies/хранилище, а также настройки отпечатка и прокси).
- **Облачная сессия** — запущенный экземпляр профиля в облаке Gologin.
- **URL подключения** — конечная точка, которую вы передаёте инструменту автоматизации для управления облачной сессией.

## Как это работает (в общих чертах)

1. (Рекомендуется) Создайте и настройте профиль через REST API Gologin (прокси, отпечаток и т. д.).
2. Подключитесь к Cloud Browser, используя свой **dev-токен** и необязательный параметр `profileId`.
3. Автоматизируйте сессию с помощью Puppeteer или Playwright.
4. Закройте соединение, когда закончите.

## URL подключения

Используйте этот URL как удалённую конечную точку браузера:

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${params.profileId}
```

- `token` — ваш **dev-токен** Gologin (создайте его в личном кабинете: `Личный кабинет → API-токен`).
- `profile` — **ID профиля** (необязательно). Если параметр не указан, для сессии будет создан новый профиль.

## Управление профилями (прокси, отпечаток и т. д.)

Cloud Browser — это **уровень подключения**.\
Чтобы создавать и обновлять профили, привязывать прокси и настраивать параметры профилей, используйте REST API Gologin:

- Profiles API: https://gologin.com/docs/api-reference/profile
- Proxy API: https://gologin.com/docs/api-reference/proxy

## Использование Cloud Browser из CLI

Если вы предпочитаете команды оболочки написанию кода на Puppeteer/Playwright, Gologin предоставляет CLI-инструменты, удобные для агентов:

- **[Gologin Agent Browser CLI](/ru/cli-tools/agent-browser)** — CLI для облачного браузера с демоном, снимками страниц и взаимодействием по ссылкам на элементы. Создан для ИИ-агентов.
- **[Gologin Web Access CLI](/ru/cli-tools/web-access)** — единый CLI, объединяющий скрапинг через Web Unlocker и взаимодействие с Cloud Browser в одном инструменте.

```bash
npm install -g gologin-agent-browser-cli
export GOLOGIN_TOKEN='your_token'

gologin-agent-browser open https://example.com
gologin-agent-browser snapshot
gologin-agent-browser click @e3
gologin-agent-browser screenshot ./page.png
gologin-agent-browser close
```
