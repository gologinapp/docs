Gologin Cloud Browser позволяет запускать браузер Gologin (Orbita) **в облаке** и управлять им из кода автоматизации (Puppeteer / Playwright) через единый **URL подключения**.

Это [headless-браузер](./what-is-headless-browser): браузер, которым полностью управляет код, без графического интерфейса. Он размещён и обслуживается Gologin и имеет встроенную поддержку постоянных профилей, настройки фингерпринта и маршрутизации через прокси.

## Что можно делать с Cloud Browser

- Запускать несколько браузерных сессий параллельно в облаке
- Автоматизировать работу с помощью привычного стека (Puppeteer / Playwright)
- Использовать **профили** Gologin для сохранения состояния (логины, cookies, хранилище)
- Направлять трафик через **прокси**, настроив их в профиле
- Использовать его с ИИ-агентами как удалённую среду выполнения браузера

## Чем он отличается от обычного headless-браузера

Обычный headless Chrome легко обнаружить. Сайты используют браузерный фингерпринтинг, чтобы выявлять автоматизированный трафик: они проверяют отрисовку canvas, параметры WebGL, шрифты, часовой пояс, размер экрана и десятки других признаков.

Gologin Cloud Browser работает на **Orbita** — модифицированном Chromium, который управляет сигналами фингерпринта так, чтобы они соответствовали согласованному, реалистичному профилю браузера. Вместе с постоянными cookies и настройками прокси, сохранёнными в каждом профиле, ваши сессии выглядят стабильными и естественными при повторных посещениях.

## Почему Gologin Cloud Browser

### Встроенный антидетект — без плагинов

Обычный headless Chrome обнаруживается тривиально. Другие облачные браузерные сервисы используют стандартный Chromium и требуют сторонних stealth-плагинов, чтобы снизить количество заметных сигналов фингерпринта, причём результаты получаются разными.

Gologin Cloud Browser работает на **Orbita** — усиленной сборке Chromium, в основе которой лежит управление фингерпринтом: canvas, WebGL, шрифты, часовой пояс, разрешение экрана и многое другое. Антидетект здесь — не заплатка поверх браузера, а сам браузер.

### Постоянные профили — сессии, которые помнят

Большинство облачных браузерных сервисов обрабатывают каждую сессию без сохранения состояния. Cookies и хранилище удаляются при закрытии сессии.

Профили Gologin сохраняются. Войдите в аккаунт один раз, закройте сессию, подключитесь позже — профиль сохранит cookies, локальное хранилище и все настроенные параметры. Не нужно заново входить в аккаунт и «прогревать» сессию.

### Без привязки к поставщику

Gologin Cloud Browser — это стандартная конечная точка CDP. Ваш код на Puppeteer или Playwright подключается к нему так же, как к любому удалённому экземпляру Chrome: без проприетарного SDK и без необходимости изучать специальный API. Перейти на него или отказаться от него можно, изменив один URL.

## Типичные технические сценарии

Cloud Browser обычно используют в рабочих процессах, где нужно:

- один раз войти в веб-аккаунт и сохранить сессию с помощью профиля
- выполнять повторяющиеся действия на одних и тех же сайтах во множестве профилей
- получить стабильные, долгие сессии, не зависящие от локального компьютера

Примеры: автоматизация сессий с авторизацией для веб-приложений, маркетплейсов и социальных платформ, где важны сохранение состояния и единые настройки профиля.

## Основные понятия

- **Профиль** — многоразовая браузерная идентичность (cookies и хранилище, а также настройки фингерпринта и прокси).
- **Облачная сессия** — запущенный экземпляр профиля в облаке Gologin.
- **Connect URL** — адрес, который вы передаёте инструменту автоматизации для управления облачной сессией.

## Как это работает (в общих чертах)

1. (Рекомендуется) Создайте и настройте профиль через Gologin REST API (прокси, фингерпринт и т. д.).
2. Подключитесь к Cloud Browser, используя свой **dev-токен** и, при необходимости, `profileId`.
3. Автоматизируйте сессию с помощью Puppeteer или Playwright.
4. Закройте соединение, когда закончите.

## URL подключения

Используйте этот URL как адрес удалённого браузера:

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${profileId}
```

- `token` — ваш **dev-токен** Gologin (создайте его в приложении Gologin: [API & MCP](https://app.gologin.com/personalArea/TokenApi) → **API** → **Новый токен**).
- `profile` — **ID профиля** (необязательно). Если параметр не указан, для сессии будет создан новый профиль.

## Управление профилями (прокси, фингерпринт и т. д.)

Cloud Browser — это **слой подключения**.\
Чтобы создавать и обновлять профили, привязывать прокси и настраивать параметры профиля, используйте Gologin REST API:

- Profiles API: [Создание профиля](https://gologin.com/docs/api-reference/profile/create-profile-with-partial-parameters), [Обновление профиля](https://gologin.com/docs/api-reference/profile/update-profile-with-partial-parameters)
- Proxy API: [Добавление прокси Gologin в профиль](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy), [Установка собственного прокси в профили](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles)

## Использование Cloud Browser из CLI

Если вы предпочитаете команды оболочки написанию кода на Puppeteer/Playwright, Gologin предлагает CLI-инструменты, удобные для агентов:

- **[Gologin Agent Browser CLI](/ru/cli-tools/agent-browser)** — CLI для облачного браузера с демоном, снимками страниц и взаимодействием по ссылкам на элементы. Создан для ИИ-агентов.
- **[Gologin Web Access CLI](/ru/cli-tools/web-access)** — единый CLI, объединяющий скрапинг через Web Unlocker и взаимодействие с Cloud Browser в одном инструменте.

```bash
npm install -g gologin-agent-browser-cli
export GOLOGIN_TOKEN='your_token'

gologin-agent-browser open https://example.com
gologin-agent-browser snapshot
gologin-agent-browser click @e3
gologin-agent-browser screenshot ./page.png
gologin-agent-browser close
```
