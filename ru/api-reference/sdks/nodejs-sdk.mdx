### Установка

```bash
npm i gologin
```

Требуется Node.js 20 или новее. Третья версия SDK поддерживает только ESM: подключайте его через `import`, а `require('gologin')` не сработает.

### Базовое использование

```javascript
import GoLogin from 'gologin';

const GL = new GoLogin({
  token: 'your-api-token',
  profile_id: 'your-profile-id',
});

const { status, wsUrl } = await GL.start();
// Connect Puppeteer or Playwright using wsUrl
// ... your automation code ...
await GL.stop();
```

### Запуск через GologinApi

`GologinApi` запускает профиль и сам подключает Puppeteer. Метод `launch()` возвращает `browser` Puppeteer. Передайте `cloud: true`, чтобы запустить профиль в [Gologin Cloud Browser](/ru/api-reference/cloud-browser/what-is-gologin-cloud-browser), а не в локальном браузере Orbita:

```javascript
import { GologinApi } from 'gologin';

const gologin = GologinApi({ token: 'your-api-token' });

// local Orbita on this machine
const { browser } = await gologin.launch({ profileId: 'your-profile-id' });

// or Gologin Cloud Browser
// const { browser } = await gologin.launch({ cloud: true, profileId: 'your-profile-id' });

const page = await browser.newPage();
await page.goto('https://example.com');

// close the browser and stop the profile
await gologin.exit();
```

Если `profileId` не указан, `launch()` сначала создаёт новый профиль. В `GologinApi` также есть вспомогательные методы, например `createProfileRandomFingerprint()`, `addGologinProxyToProfile()`, `addCookiesToProfile()` и `deleteProfile()`. Полный пример смотрите в разделе [Быстрый старт](/ru/api-reference/introduction/quickstart).

### Основные параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `token` | обязательный | Ваш API-токен Gologin |
| `profile_id` | обязательный | ID профиля для запуска |
| `executablePath` | auto | Путь к исполняемому файлу браузера Orbita |
| `uploadCookiesToServer` | `false` | Загружать cookies в облако при остановке профиля. Установите `true`, если нужно сохранять сессию между устройствами. |
| `extra_params` | `[]` | Дополнительные флаги Chromium, которые передаются браузеру |

### Остановка профилей

```javascript
// Stop and sync to cloud
await GL.stop();

// Stop without syncing profile data to cloud
await GL.stopLocal({ posting: false });
```

Сначала закройте браузер в вашем инструменте автоматизации, например через `browser.close()`. Метод `stop()` не принимает параметров и всегда загружает профиль в Gologin. Метод `stopLocal({ posting: false })` завершает сеанс без загрузки данных профиля. Используйте его на серверах, где синхронизация с облаком не нужна. Cookies по-прежнему загружаются, если вы указали `uploadCookiesToServer: true`.

### Управление версиями браузера Orbita

При запуске профиля SDK проверяет, какая версия Orbita нужна для user agent этого профиля. Если этой версии ещё нет в `~/.gologin/browser`, SDK скачивает её, а если есть, использует установленную копию. Чтобы запустить конкретную сборку, передайте `executablePath`. Параметры `autoUpdateBrowser` (по умолчанию `false`) и `checkBrowserUpdate` по-прежнему принимаются, но в текущей версии SDK (3.0.7) на это поведение не влияют.

Чтобы скачать Orbita заранее, вызовите `checkAndDownloadBrowserByOpts()` у экземпляра `GoLogin`. Это метод, а не отдельный экспорт:

```javascript
import { GoLogin } from 'gologin';

const GL = new GoLogin({ token: 'your-api-token' });

// Pre-download the latest Orbita version
await GL.checkAndDownloadBrowserByOpts({ lastActualCount: 1 });

// Pre-download specific versions
await GL.checkAndDownloadBrowserByOpts({ majorVersions: [142, 143] });
```

Без параметров метод скачивает 5 последних версий. Используйте его перед параллельным запуском профилей, чтобы избежать нескольких одновременных загрузок.

### Запуск 100+ профилей параллельно

Если на сервере одновременно работает много профилей:

```javascript
// Use a queue to limit concurrent launches
const CONCURRENCY = 10;
const queue = [...profileIds];
const active = new Set();

async function launchProfile(profileId) {
  const gl = new GoLogin({ token, profile_id: profileId });
  try {
    const { wsUrl } = await gl.start();
    // ... your automation ...
  } finally {
    await gl.stop();
  }
}

async function processQueue() {
  while (queue.length > 0) {
    while (active.size >= CONCURRENCY) {
      await new Promise(r => setTimeout(r, 1000));
    }
    const id = queue.shift();
    active.add(id);
    launchProfile(id).finally(() => active.delete(id));
  }
}
```

**Важно для серверов:**
- Ограничивайте число одновременных запусков профилей (для начала рекомендуется 10-20)
- Скачивайте версии Orbita заранее, до запуска профилей
- В Linux: установите Xvfb и задайте `DISPLAY=:99`
- Увеличьте лимиты файловых дескрипторов: `ulimit -n 65536`
- Следите за оперативной памятью: каждый профиль использует ~300-500 МБ

### Отладка

Чтобы включить подробное логирование, задайте переменную окружения:

```bash
DEBUG=gologin node your-script.js
```
