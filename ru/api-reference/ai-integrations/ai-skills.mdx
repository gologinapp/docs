Gologin AI Skills — это готовые к подключению расширения для [Claude Code](https://claude.ai/code), которые дают ИИ-агентам возможности веб-скрейпинга и автоматизации браузера. Каждый навык оборачивает инструмент Gologin CLI и предоставляет его в виде набора функций, которые может вызывать агент.

```
agent → skill → Gologin CLI → Web Unlocker API / Cloud Browser / Local Orbita
```

## Установка

Все навыки Gologin устанавливаются из репозитория [GologinLabs/agent-skills](https://github.com/GologinLabs/agent-skills):

```bash
# install any skill
npx skills add GologinLabs/agent-skills@gologin-web-access-skill
npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill
npx skills add GologinLabs/agent-skills@gologin-scraping-skill
```

Для каждого навыка должен быть установлен соответствующий CLI:

| Навык | Необходимый CLI |
|---|---|
| Web Access Skill | `npm i -g gologin-web-access` |
| Agent Browser Skill | `npm i -g gologin-agent-browser-cli` (облачный и локальный режимы) |
| Scraping Skill | `npm i gologin-webunlocker` |

## Web Access Skill

**Установка:** `npx skills add GologinLabs/agent-skills@gologin-web-access-skill`

Основной и самый универсальный навык. Делегирует выполнение CLI `gologin-web-access`.

**Инструменты скрейпинга:** `scrape_url`, `read_page`, `scrape_markdown`, `scrape_text`, `scrape_json`, `batch_scrape`, `batch_extract`, `search_web`, `map_site`, `crawl_site`, `crawl_site_async`, `extract_structured`, `track_changes`, `batch_track_changes`, `parse_document`

**Инструменты браузера:** `browser_open`, `browser_search`, `browser_snapshot`, `browser_click`, `browser_type`, `browser_screenshot`, `browser_close`, `browser_sessions`, `browser_current`

**Встроенные сценарии:** browser-ref-loop, hybrid-read-then-interact, search-discover-and-scrape, lead-enrichment, competitive-monitoring, docs-ingestion, geo-testing, login-and-navigate-dashboard

Подробное описание команд смотрите в [справочнике по Web Access CLI](/ru/cli-tools/web-access).

## Agent Browser Skill

**Установка:** `npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill`

Навык только для работы с браузером: живые сессии в Gologin Cloud Browser (по умолчанию) или в локальных профилях Orbita с флагом `--runtime local`. Используйте его, когда нужна интерактивная работа в браузере без скрейпинга.

**Возможности:** `doctor`, `open`, `sessions`, `current`, `snapshot`, `click`, `type`, `fill`, `find`, `get`, `tabs`, `tabopen`, `tabfocus`, `tabclose`, `cookies`, `cookies-import`, `storage-export`, `storage-import`, `eval`, `back`, `forward`, `reload`, `upload`, `screenshot`, `pdf`

**Локальный режим добавляет:** управление профилями (`profiles`, `profile-create`, `profile-import`, `profile-update`, `profile-sync`, `profile-delete`), ранбуки (`run`, `batch`), задания (`jobs`, `job`), шаблоны для сценариев использования (`linkedin`, `ads`, `smm`, `scraping`, `geo`) и диагностику (`doctor --use-case --check-proxy`).

Подробное описание команд смотрите в [справочнике по Agent Browser CLI](/ru/cli-tools/agent-browser) и разделе [Локальный режим](/ru/cli-tools/local-agent-browser).

## Scraping Skill

**Установка:** `npx skills add GologinLabs/agent-skills@gologin-scraping-skill`

Самый компактный навык — только скрейпинг через Web Unlocker SDK. Без сессии браузера и без демона.

**Возможности:** необработанный HTML (`scrape`), текст (`text`), markdown (`markdown`), структурированные метаданные (`json`). Методы SDK: `scrapeRaw()`, `scrape()`, `scrapeText()`, `scrapeMarkdown()`, `scrapeJSON()`, `batchScrape()`.

Используйте, когда задача сводится только к скрейпингу и нужно минимум зависимостей.

Подробности об API смотрите в [справочнике по Web Unlocker SDK](/ru/scraping-api-sdk-and-cli).

## Local Agent Browser Skill (устарел)

Если у вашего агента всё ещё установлен `gologin-local-agent-browser-skill`, он лишь направляет агента к навыку Agent Browser. Установите вместо него `gologin-agent-browser-skill`: он поддерживает локальные профили Orbita, прогрев, сценарии входа, ранбуки и пакетные задания.

## Примеры сценариев

### Конкурентный анализ (Web Access Skill)

1. Агент ищет конкурентов: `search_web("saas project management tools")`
2. Агент составляет карту сайта конкурента: `map_site("https://competitor.com")`
3. Агент выполняет пакетный скрейпинг ключевых страниц: `batch_scrape(pricing, features, about)`
4. Агент передаёт содержимое Claude для анализа и сравнения

### Прогрев аккаунтов (Agent Browser Skill, локальный режим)

1. Агент создаёт профили: `profile-create "Account 1" --template linkedin`
2. Агент запускает ранбук прогрева: `batch ./warmup.json --targets ./profiles.json`
3. Агент проверяет результаты заданий: `jobs --kind batch --status ok`
4. Агент сообщает, какие профили готовы

### Мониторинг личного кабинета (Agent Browser Skill)

1. Агент открывает личный кабинет: `open https://dashboard.example.com --profile saved_login`
2. Агент читает страницу: `snapshot`
3. Агент переходит к метрикам: `click @e5` (ссылка «Отчёты»)
4. Агент делает скриншот отчёта: `screenshot ./daily-metrics.png`
5. Агент закрывает сессию: `close`
6. Агент подводит итоги по метрикам на основе данных снимка страницы

## Обязательная предварительная проверка

Перед выполнением любой задачи навыки классифицируют работу:

1. **Один известный сайт или широкое исследование по многим источникам?** — определяет, нужен ли скрейпинг или поиск
2. **Только чтение данных, мониторинг или интерактивная работа в браузере?** — определяет выбор между скрейпингом и браузером
3. **Нужен только Web Unlocker или Web Unlocker вместе с Cloud Browser?** — определяет, какие учётные данные потребуются
4. **Зависит ли задача от региона или сайт блокирует настолько, что нужен полный стек Gologin?** — определяет требования к прокси и профилю
