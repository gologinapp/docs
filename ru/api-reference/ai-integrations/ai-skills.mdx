Gologin AI Skills — это готовые к использованию расширения для [Claude Code](https://claude.ai/code), которые дают ИИ-агентам возможности веб-скрейпинга и автоматизации браузера. Каждый навык оборачивает инструмент Gologin CLI и предоставляет его как набор функций, которые может вызывать агент.

```
agent → skill → Gologin CLI → Web Unlocker API / Cloud Browser / Local Orbita
```

## Установка

```bash
# install any skill
npx skills add GologinLabs/gologin-web-access-skill
npx skills add GologinLabs/gologin-agent-browser-skill
npx skills add GologinLabs/gologin-scraping-skill
npx skills add GologinLabs/gologin-local-agent-browser-skill
```

Для каждого навыка должен быть установлен соответствующий CLI:

| Навык | Необходимый CLI |
|---|---|
| Web Access Skill | `npm i -g gologin-web-access` |
| Agent Browser Skill | `npm i -g gologin-agent-browser-cli` |
| Scraping Skill | `npm i gologin-webunlocker` |
| Local Agent Browser Skill | `npm i -g gologin-local-agent-browser-cli` |

## Web Access Skill

**Установка:** `npx skills add GologinLabs/gologin-web-access-skill`

Основной и самый универсальный навык. Делегирует выполнение CLI `gologin-web-access`.

**Инструменты скрейпинга:** `scrape_url`, `read_page`, `scrape_markdown`, `scrape_text`, `scrape_json`, `batch_scrape`, `batch_extract`, `search_web`, `map_site`, `crawl_site`, `crawl_site_async`, `extract_structured`, `track_changes`, `batch_track_changes`, `parse_document`

**Инструменты браузера:** `browser_open`, `browser_search`, `browser_snapshot`, `browser_click`, `browser_type`, `browser_screenshot`, `browser_close`, `browser_sessions`, `browser_current`

**Встроенные сценарии:** browser-ref-loop, hybrid-read-then-interact, search-discover-and-scrape, lead-enrichment, competitive-monitoring, docs-ingestion, geo-testing, login-and-navigate-dashboard

Подробное описание команд см. в [справочнике по Web Access CLI](/ru/cli-tools/web-access).

## Agent Browser Skill

**Установка:** `npx skills add GologinLabs/gologin-agent-browser-skill`

Навык только для работы в браузере с живыми облачными сессиями. Используйте его, когда нужна интерактивная работа в браузере без скрейпинга.

**Возможности:** `doctor`, `open`, `sessions`, `current`, `snapshot`, `click`, `type`, `fill`, `find`, `get`, `tabs`, `tabopen`, `tabfocus`, `tabclose`, `cookies`, `cookies-import`, `storage-export`, `storage-import`, `eval`, `back`, `forward`, `reload`, `upload`, `screenshot`, `pdf`

Подробное описание команд см. в [справочнике по Agent Browser CLI](/ru/cli-tools/agent-browser).

---

## Scraping Skill

**Установка:** `npx skills add GologinLabs/gologin-scraping-skill`

Самый компактный навык — только скрейпинг через Web Unlocker SDK. Без браузерной сессии и без демона.

**Возможности:** необработанный HTML (`scrape`), текст (`text`), markdown (`markdown`), структурированные метаданные (`json`). Методы SDK: `scrapeRaw()`, `scrape()`, `scrapeText()`, `scrapeMarkdown()`, `scrapeJSON()`, `batchScrape()`.

Используйте, если задача сводится только к скрейпингу и нужно минимизировать зависимости.

Подробности об API см. в [справочнике по Web Unlocker SDK](/ru/scraping-api-sdk-and-cli).

## Local Agent Browser Skill

**Установка:** `npx skills add GologinLabs/gologin-local-agent-browser-skill`

Для постоянной автоматизации локального Orbita: прогрев, сценарии входа, действия в соцсетях и на маркетплейсах.

**Возможности:** все команды взаимодействия с браузером, а также управление профилями (`profiles`, `profile-create`, `profile-import`, `profile-update`, `profile-sync`, `profile-delete`), ранбуки (`run`, `batch`), задания (`jobs`, `job`) и диагностика (`doctor --use-case --check-proxy`).

**Шаблоны для сценариев использования:** `linkedin`, `ads`, `smm`, `scraping`, `geo`

Подробное описание команд см. в [справочнике по Local Agent Browser CLI](/ru/cli-tools/local-agent-browser).

## Примеры сценариев

### Анализ конкурентов (Web Access Skill)

1. Агент ищет конкурентов: `search_web("saas project management tools")`
2. Агент составляет карту сайта конкурента: `map_site("https://competitor.com")`
3. Агент выполняет пакетный скрейпинг ключевых страниц: `batch_scrape(pricing, features, about)`
4. Агент передаёт содержимое Claude для анализа и сравнения

### Прогрев аккаунтов (Local Agent Browser Skill)

1. Агент создаёт профили: `profile-create "Account 1" --template linkedin`
2. Агент запускает ранбук прогрева: `batch ./warmup.json --targets ./profiles.json`
3. Агент проверяет результаты заданий: `jobs --kind batch --status completed`
4. Агент сообщает, какие профили готовы

### Мониторинг панели управления (Agent Browser Skill)

1. Агент открывает панель управления: `open https://dashboard.example.com --profile saved_login`
2. Агент считывает страницу: `snapshot`
3. Агент переходит к метрикам: `click @e5` (ссылка «Отчёты»)
4. Агент делает скриншот отчёта: `screenshot ./daily-metrics.png`
5. Агент закрывает сессию: `close`
6. Агент формирует сводку по метрикам на основе данных снимка

## Обязательная предварительная проверка

Перед выполнением любой задачи навыки классифицируют работу:

1. **Один известный сайт или широкое исследование по нескольким источникам?** — определяет, нужен ли скрейпинг или поиск
2. **Только извлечение данных, мониторинг или интерактивная работа в браузере?** — определяет выбор между скрейпингом и браузером
3. **Только Web Unlocker или и Web Unlocker, и Cloud Browser?** — определяет, какие учётные данные нужны
4. **Зависит ли задача от геолокации или достаточно ли она защищена от доступа, чтобы использовать Gologin целиком?** — определяет требования к прокси и профилям
