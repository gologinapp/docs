MCP-сервер Gologin позволяет управлять профилями браузера в диалоге с ИИ через [Model Context Protocol](https://modelcontextprotocol.io/). Подключите его к Claude Desktop, Cursor, Claude Code или любому клиенту с поддержкой MCP и управляйте профилями на естественном языке.

---

## Что можно делать

- **Управление профилями** — создание, изменение, удаление и просмотр списка профилей браузера
- **Настройка прокси** — подключение прокси к профилям
- **Управление фингерпринтами** — настройка фингерпринтов браузера и user agent
- **Организация по папкам** — создание папок и распределение профилей по ним
- **Сессии браузера** — запуск и остановка сессий браузера
- **Информация об аккаунте** — проверка статуса подписки и использования

## Установка

### Требования

- Node.js 18 или выше
- API-токен Gologin
- Активный аккаунт Gologin

### Получение API-токена

1. Войдите на [gologin.com](https://gologin.com)
2. Откройте раздел **API & MCP** в личном кабинете
3. Перейдите на вкладку **API**
4. Нажмите **Новый токен** и скопируйте его

### Claude Desktop

1. Откройте Claude Desktop → **Настройки**
2. Нажмите **Developer** на боковой панели, затем **Edit Config**
3. Добавьте в `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "gologin-mcp": {
      "command": "npx",
      "args": ["gologin-mcp"],
      "env": {
        "API_TOKEN": "your-gologin-api-token-here"
      }
    }
  }
}
```

4. Перезапустите Claude Desktop
5. Откройте **Настройки → Connectors** и проверьте, что там есть "gologin-mcp LOCAL"

### Claude Code

Добавьте в настройки MCP в Claude Code:

```json
{
  "mcpServers": {
    "gologin-mcp": {
      "command": "npx",
      "args": ["gologin-mcp"],
      "env": {
        "API_TOKEN": "your-gologin-api-token-here"
      }
    }
  }
}
```

### Cursor

Используйте ту же JSON-конфигурацию в файле настроек MCP в Cursor.

### Другие клиенты MCP

Любой клиент с поддержкой Model Context Protocol может использовать ту же структуру конфигурации.

## Примеры использования

После подключения общайтесь с ИИ-ассистентом в свободной форме:

**Аккаунт**
- "Каков статус моего аккаунта Gologin?"
- "Проверь сведения о моей подписке"

**Создание профилей**
- "Создай новый профиль браузера с прокси из США"
- "Настрой 5 профилей для управления социальными сетями"

**Управление профилями**
- "Покажи все мои профили"
- "Замени прокси у профиля с ID 123 на прокси из Великобритании"
- "Удали профиль с именем 'test-profile'"

**Организация**
- "Создай папку с названием 'Social Media Accounts'"
- "Перемести профиль XYZ в папку Social Media"

**Сессии браузера**
- "Запусти сессию браузера для моего профиля"
- "Останови все запущенные сессии браузера"

## Практические сценарии

### Настройка профилей для нового клиента

К вам пришёл новый клиент, которому нужно 10 профилей браузера для рекламных аккаунтов в разных регионах:

> "Создай 10 профилей браузера с именами 'Client X - US', 'Client X - UK', 'Client X - DE' и так далее. Настрой для каждого резидентный прокси из соответствующей страны. Помести их все в папку с названием 'Client X'."

Claude создаёт профили, настраивает прокси и раскладывает профили по папкам — и всё это на естественном языке.

### Аудит текущей конфигурации

> "Покажи все профили, у которых не настроен прокси. Также скажи, какие профили не использовались в последние 30 дней?"

Это быстрый способ найти неправильно настроенные или заброшенные профили, не перебирая их вручную в личном кабинете.

### Подготовка профилей перед автоматизацией

MCP-сервер отвечает за настройку, а CLI-инструменты — за выполнение:

1. **MCP:** "Создай 5 профилей с прокси из США для скрейпинга и помести их в папку 'Scraping'"
2. **CLI:** `gologin-agent-browser open https://target.com --profile profile_1` — запуск автоматизации
3. **MCP:** "Удали все профили в папке 'Scraping'" — после завершения работы

### Управление командой

> "Сколько активных сессий запущено сейчас? Каков лимит сессий на моём тарифе?"
> "Проверь мою подписку — сколько профилей у меня осталось?"

Удобно для руководителей команд, которым нужно следить за использованием без захода в личный кабинет.

## MCP-сервер, CLI-инструменты и AI Skills

| Инструмент | Для чего подходит | Как работает |
|---|---|---|
| **MCP-сервер** | Управление профилями, операции с аккаунтом | Естественный язык через протокол MCP |
| [CLI-инструменты](/ru/cli-tools/web-access) | Веб-скрейпинг, автоматизация браузера, пакетные операции | Команды в оболочке |
| [AI Skills](/ru/api-reference/ai-integrations/ai-skills) | Готовые функции для агентов в Claude Code | Расширения-навыки поверх CLI-инструментов |

MCP-сервер предназначен для **управления профилями и аккаунтом**. Для веб-скрейпинга и автоматизации браузера используйте [CLI-инструменты](/ru/cli-tools/web-access) или [AI Skills](/ru/api-reference/ai-integrations/ai-skills).
