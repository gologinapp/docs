---
title: 'Лимиты запросов'
---
Gologin API ограничивает количество запросов, которые можно отправить за минуту. Если вы превысили лимит, подождите, прежде чем отправлять новые запросы.

Лимит зависит от вашего тарифа:

| Тариф | Запросов в минуту |
| :-- | --: |
| Professional | 300 |
| Business | 500 |
| Enterprise | 800 |
| Custom | 1,200 |

В пробный тариф и тариф Forever Free доступ к API не входит. Что включает каждый тариф, смотрите в разделе [Цены](/ru/general/account-and-billing/pricing).

### Аннулирование токена при превышении лимита

<Warning>
Если вы превысите лимит запросов и получите ответ HTTP 429, ваш API-токен будет автоматически аннулирован. Это значит, что токен станет непригодным навсегда, и вам придётся создать новый.

Это не временная блокировка — токен отзывается. Тщательно планируйте частоту запросов и используйте экспоненциальную задержку (exponential backoff), чтобы избежать этого.
</Warning>

### Ошибки защиты Cloudflare

Если с IP-адреса вашего сервера отправляется слишком много запросов, Cloudflare CDN, который использует Gologin, может полностью заблокировать этот IP. В таком случае API вместо JSON возвращает HTML-страницы с ошибкой, и вы получаете ошибки вида:

```
SyntaxError: Unexpected token 'e', "error code: 1015" is not valid JSON
```

Это ответ Cloudflare 1015 о превышении лимита запросов. Обычно блокировка снимается сама через несколько минут или часов. Чтобы её избежать:
- Ограничивайте частоту запросов в своём коде
- Используйте экспоненциальную задержку при сбоях
- Избегайте всплесков параллельных вызовов API

### Лимиты на создание профилей

У новых аккаунтов есть лимит примерно в 300 создаваемых профилей в день. В зависимости от тарифа этот лимит может отличаться. Если вам нужны более высокие лимиты, обратитесь в поддержку.
