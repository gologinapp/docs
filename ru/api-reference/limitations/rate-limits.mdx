---
title: 'Лимиты запросов'
---
Мы не позволяем пользователям отправлять неограниченное количество запросов к нашему API. Если вы превысите лимиты, вам нужно будет подождать, пока ограничение снимется. <br />
Базовые лимиты:
- Бесплатный и пробный тарифы: 300 запросов в минуту
- Остальные тарифы: 1200 запросов в минуту

### Аннулирование токена при превышении лимита

<Warning>
Если вы превысите лимит запросов и получите ответ HTTP 429, ваш API-токен будет автоматически аннулирован. Это значит, что токен станет непригодным для использования навсегда, и вам придётся создать новый.

Это не временная блокировка: токен отзывается. Тщательно планируйте частоту запросов и используйте экспоненциальную задержку (exponential backoff), чтобы избежать этого.
</Warning>

### Ошибки защиты Cloudflare

Если с IP-адреса вашего сервера отправляется слишком много запросов, Cloudflare CDN Gologin может полностью заблокировать этот IP-адрес. В таком случае API будет возвращать HTML-страницы с ошибкой вместо JSON, из-за чего возникают ошибки вида:

```
SyntaxError: Unexpected token 'e', "error code: 1015" is not valid JSON
```

Это ответ Cloudflare об ограничении частоты запросов (ошибка 1015). Обычно блокировка снимается сама через несколько минут или часов. Чтобы избежать её:
- Ограничивайте частоту запросов в своём коде
- Используйте экспоненциальную задержку при сбоях
- Избегайте всплесков параллельных вызовов API

### Лимиты на создание профилей

Для новых аккаунтов действует лимит примерно в 300 создаваемых профилей в день. Этот лимит может отличаться в зависимости от тарифа. Если вам нужны более высокие лимиты, обратитесь в службу поддержки.
