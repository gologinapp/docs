title: "Облачный и локальный запуск"

---

При автоматизации с помощью Gologin браузер может работать в двух местах: на вашем компьютере или на серверах Gologin. От этого зависит, где выполняется файл Orbita, как вы к нему подключаетесь и какая инфраструктура вам нужна.

## Обзор

|  | Локальный запуск | Cloud Browser |
| --- | --- | --- |
| Где работает браузер | На вашем компьютере | На серверах Gologin |
| Нужно ли приложение для компьютера | Да | Нет |
| Видимое окно | По желанию (headless) | Нет |
| Требуемое оборудование | Оперативная память на каждый профиль (~300–500 МБ) | Не требуется |
| Лучше всего подходит для | Автоматизации на вашем компьютере или VPS | Серверных скриптов без локальной настройки |

## Локальный запуск

Браузер работает на вашем компьютере. SDK автоматически загружает файл Orbita при первом запуске, запускает его локально и возвращает WebSocket-адрес, к которому подключается Puppeteer или Playwright.
