---
title: "Настройки отпечатка профиля"
---

Gologin позволяет настраивать параметры отпечатка при создании или редактировании профиля браузера.

Эти настройки определяют, как ваш профиль браузера выглядит для сайтов и антифрод-систем.

Сайты собирают множество технических сигналов из среды браузера и объединяют их в **отпечаток браузера**, по которому идентифицируют устройства.

Настройки отпечатка в Gologin разделены на несколько категорий.

## Отпечаток Navigator

Параметры Navigator описывают общую среду браузера и устройства.

Сайты считывают эти значения с помощью JavaScript API, например `navigator.userAgent` и `navigator.platform`.

К распространённым параметрам Navigator относятся:

- **User-Agent** – определяет тип и версию браузера, а также операционную систему
- **Версия Orbita** – версия Chromium, которую использует профиль
- **Разрешение экрана** – размер экрана, который передаётся сайтам
- **Языки** – предпочитаемые языки браузера
- **Платформа** – платформа операционной системы
- **Потоки процессора** – количество ядер процессора, которое сообщается браузеру
- **ОЗУ** – доступный объём памяти устройства
- **Не отслеживать** – сигнал о настройках конфиденциальности

Эти параметры помогают сайтам определить, какое устройство используется.

## Шрифты

Шрифты, установленные в среде браузера, — ещё один сигнал отпечатка.

Сайты могут определять шрифты, измеряя, как на странице отображается текст. У разных операционных систем и устройств разные наборы шрифтов, что помогает отличать устройства друг от друга.

Gologin может маскировать список шрифтов и создавать реалистичные комбинации, соответствующие выбранной операционной системе.

## Медиаустройства

Настройки медиаустройств определяют, какие камеры, микрофоны и аудиовыходы видны сайтам.

Сайты могут получить эту информацию через API `navigator.mediaDevices`.

Gologin позволяет маскировать:

- видеовходы
- аудиовходы
- аудиовыходы

Это помогает предотвратить определение сайтами реальной конфигурации вашего оборудования.

## Аппаратный отпечаток

Аппаратные сигналы дают дополнительную энтропию для создания отпечатка браузера.

К этим параметрам относятся характеристики отрисовки графики и обработки звука.

### Canvas

Canvas API позволяет сайтам рисовать в браузере скрытые изображения.\
Поскольку отрисовка на разных устройствах немного отличается, полученное изображение можно преобразовать в хеш и использовать для создания отпечатка.

### WebGL

WebGL раскрывает информацию о графическом оборудовании устройства.

Сайты могут проверять отчёт WebGL или отрисовывать скрытый 3D-объект, чтобы создать отпечаток.

### AudioContext

Аудиоотпечаток использует различия в обработке звука для создания уникального хеша.

### ClientRects

Этот метод измеряет, как элементы расположены и отображаются на странице.

Gologin позволяет изменять или маскировать эти сигналы, чтобы для каждого профиля создавался стабильный, но уникальный отпечаток.

## WebRTC

WebRTC — это технология для обмена данными в реальном времени в браузерах.

Однако она может раскрывать сайтам локальные или реальные IP-адреса.

Gologin позволяет управлять поведением WebRTC:

- **На основе IP** – WebRTC сообщает IP-адрес прокси
- **Выключить** – WebRTC отключён

Это помогает предотвратить утечки IP и сохраняет соответствие отпечатка местоположению прокси.

## Рекомендации

Чтобы идентичность браузера оставалась стабильной:

- не меняйте настройки отпечатка после создания аккаунтов
- подбирайте часовой пояс и язык в соответствии с местоположением прокси
- не меняйте часто аппаратные параметры
- используйте отдельный прокси для каждого профиля

Стабильные отпечатки помогают сайтам распознавать профиль как одно и то же устройство.

## Как проверить отпечаток

После запуска профиля зайдите на один из этих сайтов, чтобы проверить отпечаток:

- [**iphey.com**](https://iphey.com) -- Показывает общую оценку доверия. Зелёный результат «Trusted» означает, что ваш профиль выглядит как настоящий браузер.
- [**pixelscan.net**](https://pixelscan.net) -- Подробная разбивка отдельных параметров отпечатка.

### Частые проблемы и что они означают

| Проблема | Значение | Решение |
| --- | --- | --- |
| Несоответствие ОС | ОС профиля не совпадает с ОС вашего реального устройства | Создайте новый профиль, соответствующий вашей реальной ОС |
| Несоответствие WebGL | Информация о GPU не согласуется с заявленным оборудованием | Обычно настраивается автоматически и правильно. Если возникает предупреждение, попробуйте другой режим WebGL в настройках профиля. |
| Несоответствие часового пояса | Часовой пояс не совпадает с местоположением прокси | Gologin автоматически подбирает часовой пояс по IP прокси. Если он неверный, проверьте местоположение прокси. |
| Хеш Canvas изменился | Отпечаток Canvas отличается между сеансами | Для стабильности на разных устройствах установите для Canvas значение «Выключить» или «Блокировать» вместо «Добавить шум» |
