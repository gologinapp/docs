title: "Amazon, eBay, Shopify"

Маркетплейсы — самые строгие платформы в части связывания аккаунтов. Amazon, eBay и Shopify ведут межаккаунтные графы связей: если у двух аккаунтов совпадает IP-адрес, способ оплаты, отпечаток устройства или адрес доставки, платформа свяжет их между собой. Когда один аккаунт блокируется, связанные с ним аккаунты, как правило, блокируются следом.

## Краткий чек-лист

- 1 аккаунт продавца = 1 профиль браузера
- 1 профиль = 1 статический резидентный или ISP-прокси
- **Никогда не используйте ротируемые прокси** — смена IP мгновенно связывает аккаунты
- **Никогда не используйте встроенные прокси Gologin** — по умолчанию они ротируемые
- Уникальный способ оплаты для каждого аккаунта
- Уникальные номер телефона и адрес электронной почты для каждого аккаунта

## Шаг 1. Настройте профиль Gologin

- **Прокси: **статический резидентный или ISP-прокси — один выделенный IP на аккаунт, без совместного использования
- **Отпечаток: **оставьте значения по умолчанию

## Шаг 2. Прогрейте аккаунт

| **Период** | **Фокус** | **Что делать** |
| :-- | :-- | :-- |
| День 0 | Настройка | Регистрация \+ подтверждение личности |
| Дни 1–3 | Знакомство | Изучите инструменты продавца, прочитайте правила |
| Дни 4–7 | Лёгкая активность | Добавьте 5–10 листингов, настройте доставку |
| Неделя 2 | Обычная работа | Управляйте листингами, отвечайте на вопросы |
| Неделя 3\+ | Масштабирование | Постепенно увеличивайте количество листингов |

## Безопасные модели активности

| Действие | Рекомендуемый подход |
| :-- | :-- |
| Листинги товаров | Добавляйте постепенно |
| Изменения в аккаунте | Редкие обновления |
| Активность в панели управления | Регулярные заходы и просмотр |
| Обработка заказов | Стабильный режим работы |

## Изоляция платежей

Это самая частая причина, по которой аккаунты на маркетплейсах связывают и блокируют вместе.

Для каждого аккаунта нужны:

- Уникальная кредитная или дебетовая карта
- Уникальный аккаунт PayPal (если используется)
- Уникальный платёжный адрес

Подходящие варианты: Revolut, Wise, N26 (несколько виртуальных карт), Privacy.com (США), предоплаченные дебетовые карты.

<Warning>
  Использование одной карты для нескольких аккаунтов продавца на Amazon считается нарушением Условий использования. Amazon заблокирует все связанные аккаунты и удержит средства на срок до 90 дней.
</Warning>

## Особенности платформ

### Amazon

- Смена IP между сессиями запускает автоматическую проверку на связь аккаунтов
- Апелляции проходят сложно — предотвратить проблему гораздо проще, чем восстановить аккаунт
- Для бизнес-аккаунтов требуются подтверждённые документы юридического лица

### eBay

- К IP менее строг, чем Amazon, но всё равно отслеживает отпечаток устройства
- Каждому аккаунту нужны отдельные банковские реквизиты для eBay Managed Payments
- Рейтинг отзывов имеет значение — у новых аккаунтов низкий уровень доверия покупателей

### Shopify

- Gologin в основном используют для управления несколькими админ-аккаунтами Shopify или для работы из разных локаций
- Межаккаунтного обнаружения, как у Amazon и eBay, нет, но у Shopify Payments есть система защиты от мошенничества при выплатах

## Частые причины блокировки

### Amazon

- Ротируемые или общие прокси-IP
- Один и тот же способ оплаты в разных аккаунтах
- Один и тот же отпечаток устройства при входе в несколько аккаунтов продавца
- Блокировка связанного аккаунта (Amazon банит по принципу связи)

### eBay

- Тот же IP или отпечаток, что и у ранее заблокированного аккаунта
- Одновременное размещение одних и тех же товаров в нескольких аккаунтах
- Схемы накрутки отзывов
