title: "Настройки профиля"
---

У каждого браузерного профиля в Gologin есть собственный набор настроек, определяющих, как профиль выглядит для сайтов. Эти настройки разбиты по вкладкам в верхней части редактора профиля.

Чтобы открыть настройки профиля, нажмите **три точки на профиле** \> **Настройки**.

## Обзор

На этой вкладке вы выбираете операционную систему, под которую будет маскироваться профиль, и создаёте его основной отпечаток.

**Операционная система** - Выберите Windows 10, Windows 11, Mac Intel, Mac ARM, Linux или Android. Эта ОС будет передаваться каждому сайту, который посещает профиль.

<Warning>
  Операционную систему можно выбрать только при создании профиля. После сохранения профиля эта опция блокируется, и изменить её нельзя. Если вам нужна другая ОС, создайте новый профиль.
</Warning>

**Обновить отпечаток** - Нажатие на эту кнопку генерирует новый набор значений отпечатка для профиля: разрешение экрана, шрифты, данные о графике и другие сигналы, по которым сайты идентифицируют браузеры. Используйте её, если хотите сбросить «личность» профиля. Кнопка не меняет ОС и не удаляет cookie и другие данные браузера.

Панель **Общая информация** справа обновляется по мере внесения изменений и позволяет быстро увидеть текущий отпечаток профиля.

## Прокси

Эта вкладка определяет, какой прокси профиль использует при работе в интернете.

- **Gologin прокси** - использовать прокси из встроенного прокси-сервиса Gologin.
- **Ваш прокси** - вставить собственный прокси от стороннего провайдера.
- **Без прокси** - профиль использует ваше реальное интернет-соединение. Сайты будут видеть ваш настоящий IP-адрес.

<Frame>
  ![Settings Proxy](/images/settings_proxy.png)
</Frame>

Назначенный здесь прокси определяет IP-адрес, который видят сайты при работе профиля. Он также влияет на часовой пояс и геолокацию, если они настроены автоматически следовать за IP.

## Часовой пояс

На этой вкладке задаётся часовой пояс, который профиль передаёт сайтам.

По умолчанию переключатель **Отображать часовой пояс на основании IP адреса** включён. Это значит, что профиль автоматически использует часовой пояс, соответствующий местоположению его прокси. Так профиль остаётся внутренне согласованным: профиль с американским прокси будет передавать американский часовой пояс, как и настоящий пользователь в этой стране.

<Note>
  Рекомендуем оставить автоматический режим и не менять часовой пояс вручную. Если часовой пояс не совпадает с местоположением прокси, это может выглядеть подозрительно для сайтов. Меняйте его только при наличии конкретной причины.
</Note>

## Расширения

На этой вкладке вы устанавливаете расширения браузера в профиль. Каждый профиль управляет своими расширениями отдельно: добавление расширения здесь не влияет на другие профили.

Нажмите **Добавить расширения**, чтобы найти и установить расширения для этого профиля.

Подробное руководство по работе расширений в профилях Gologin см. в разделе [Расширения](/ru/browser-profiles/profile-features/browser-extensions/browser-extensions).

## Закладки

На этой вкладке можно добавить закладки на панель закладок профиля. Вставьте их в текстовое поле в одном из следующих форматов:

- `folder::name::url` - создаёт закладку внутри папки с указанным названием
- `name::url` - создаёт закладку с указанным названием прямо на панели
- `url` - добавляет URL напрямую, без своего названия

Каждая строка - отдельная закладка. Закладки отображаются на панели закладок в Orbita, когда профиль запущен.

## Геолокация

Эта вкладка определяет, что происходит, когда сайт запрашивает ваше местоположение, например, когда приложение с картами спрашивает: «Разрешить сайту определять ваше местоположение?»

Доступны три варианта:

- **Спрашивать** - браузер спрашивает вас каждый раз, когда сайт запрашивает доступ к местоположению. Это вариант по умолчанию, он имитирует поведение обычного браузера.
- **Разрешить** - доступ к местоположению автоматически предоставляется любому сайту, который его запрашивает.
- **Блокировать** - все запросы местоположения отклоняются без уведомления.

Переключатель **Отображать геолокацию на основании IP адреса** включён по умолчанию. Когда он включён, Gologin автоматически устанавливает координаты профиля в соответствии с местоположением прокси.

<Note>
  Рекомендуем оставить этот переключатель включённым. Если вы выключите его и геолокация не будет совпадать с IP прокси, это несоответствие может стать сигналом для систем обнаружения. Меняйте координаты вручную, только если вы точно знаете, какие координаты вам нужны и зачем.
</Note>
