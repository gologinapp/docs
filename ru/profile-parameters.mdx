title: "Настройки профиля"
---

У каждого браузерного профиля в Gologin есть собственный набор настроек, определяющих, как он выглядит для сайтов. Эти настройки разделены по вкладкам в верхней части редактора профиля.

Чтобы открыть настройки профиля, нажмите **три точки на профиле** \> **Настройки**.

## Обзор

На этой вкладке вы выбираете операционную систему, которую профиль будет представлять сайтам как свою, и создаёте его основной отпечаток.

**Операционная система** - выберите Windows 10, Windows 11, Mac Intel, Mac ARM, Linux или Android. От этого зависит, какую ОС профиль сообщает каждому посещаемому сайту.

<Warning>
  Операционную систему можно выбрать только при создании профиля. После сохранения профиля этот параметр блокируется и не может быть изменён. Если вам нужна другая ОС, создайте новый профиль.
</Warning>

**Обновить отпечаток** - при нажатии на эту кнопку для профиля создаётся новый набор значений отпечатка: разрешение экрана, шрифты, данные о графике и другие сигналы, по которым сайты идентифицируют браузеры. Используйте её, если хотите сбросить «личность» профиля. Кнопка не меняет ОС и не удаляет cookies и другие данные браузера.

Панель **Общая информация** справа обновляется по мере внесения изменений и позволяет быстро оценить текущий отпечаток профиля.

## Прокси

Эта вкладка определяет, какой прокси профиль использует при работе в сети.

- **Gologin прокси** - использовать прокси из встроенного прокси-сервиса Gologin.
- **Ваш прокси** - вставьте собственный прокси от внешнего провайдера.
- **Без прокси** - профиль использует ваше реальное интернет-соединение. IP-адрес, который видят сайты, будет вашим настоящим IP.

<Frame>
  ![Settings Proxy](/images/settings_proxy.png)
</Frame>

Прокси, который вы назначаете здесь, определяет IP-адрес, который видят сайты, когда профиль запущен. Он также влияет на часовой пояс и геолокацию, если они настроены автоматически следовать за IP.

## Часовой пояс

Эта вкладка задаёт часовой пояс, который профиль сообщает сайтам.

По умолчанию переключатель **Отображать часовой пояс на основании IP адреса** включён. Это значит, что профиль автоматически использует часовой пояс, соответствующий местоположению его прокси. Так профиль остаётся внутренне согласованным: профиль с прокси из США будет сообщать часовой пояс США, как и настоящий пользователь в этом регионе. Чтобы профиль выглядел так, будто он из определённой страны, добавьте прокси из этой страны и оставьте часовой пояс и геолокацию на основании IP - Gologin автоматически подберёт их под местоположение прокси.

<Note>
  Рекомендуем оставить автоматический режим и не менять значение вручную. Если часовой пояс не совпадает с местоположением прокси, это может показаться сайтам подозрительным. Меняйте его только при наличии конкретной причины.
</Note>

## Расширения

На этой вкладке вы устанавливаете расширения браузера в профиль. Расширения каждого профиля управляются отдельно: добавление расширения здесь не влияет на другие профили.

Нажмите **Добавить расширения**, чтобы найти и установить расширения для этого профиля.

Подробное руководство по работе расширений в профилях Gologin см. в разделе [Расширения](/ru/browser-profiles/profile-features/browser-extensions/browser-extensions).

## Закладки

На этой вкладке можно добавить закладки на панель закладок профиля. Вставьте их в текстовое поле в одном из следующих форматов:

- `folder::name::url` - создаёт закладку внутри папки с указанным названием
- `name::url` - создаёт закладку с указанным названием прямо на панели
- `url` - добавляет URL напрямую, без пользовательского названия

Каждая строка - отдельная закладка. Закладки отображаются на панели закладок в Orbita, когда профиль запущен.

## Геолокация

Эта вкладка определяет, что происходит, когда сайт запрашивает ваше местоположение, например, когда приложение с картами спрашивает: «Разрешить этому сайту узнавать ваше местоположение?»

Доступны три варианта:

- **Спрашивать** - браузер спрашивает вас каждый раз, когда сайт запрашивает доступ к местоположению. Это значение по умолчанию, и оно имитирует поведение настоящего браузера.
- **Разрешить** - доступ к местоположению автоматически предоставляется любому сайту, который его запрашивает.
- **Блокировать** - все запросы местоположения отклоняются без уведомления.

Переключатель **Отображать геолокацию на основании IP адреса** по умолчанию включён. Когда он включён, Gologin автоматически устанавливает координаты профиля в соответствии с местоположением прокси.

<Note>
  Рекомендуем оставить этот переключатель включённым. Если выключить его и геолокация не будет совпадать с IP прокси, это несоответствие может стать сигналом для систем обнаружения. Настраивайте этот параметр вручную, только если вы знаете, какие координаты хотите использовать и зачем.
</Note>
