Facebook — одна из платформ, которые лучше всего распознают цифровые отпечатки. Для оценки аккаунтов она сопоставляет IP-адрес, окружение устройства, поведенческие паттерны и историю платежей. Несоответствия между любыми из этих сигналов приводят к проверкам безопасности.

## Краткий чек-лист

- 1 аккаунт = 1 профиль браузера
- 1 профиль = 1 статический резидентный или мобильный прокси
- Никогда не используйте один прокси в нескольких профилях
- Выбирайте ОС профиля в соответствии с ОС вашего устройства
- Не меняйте прокси и отпечаток после первого входа

## Шаг 1. Настройте профиль Gologin

Рекомендуемые настройки:

- **Прокси: **статический резидентный или мобильный — назначьте его до первого открытия Facebook
- **Отпечаток: **оставьте значения по умолчанию — не меняйте Canvas, WebGL и AudioContext вручную

После входа в Facebook в профиле не меняйте настройки прокси и отпечатка. Facebook хранит данные об устройстве на сервере. Смена отпечатка выглядит так, будто в ваш аккаунт пытается войти новое устройство.

## Шаг 2. Прогрейте браузер перед регистрацией

Перед созданием нового аккаунта потратьте 10–15 минут на обычный серфинг в профиле:

- Откройте 3–5 не связанных между собой сайтов
- Прокручивайте страницы, кликайте, делайте естественные паузы
- Пока не заходите на Facebook

Так формируется история сессий, и окружение выглядит как настоящее устройство. Абсолютно чистый браузер без истории — явный признак для систем обнаружения.

## Шаг 3. Создайте аккаунт

- Регистрируйте аккаунты с интервалом не менее 30–60 минут
- Используйте уникальный номер телефона для каждого аккаунта
- Не создавайте более 2–3 аккаунтов в день с одной локации прокси
- Избегайте одинакового сценария регистрации для разных аккаунтов

Если во время регистрации Facebook запрашивает подтверждение по телефону — пройдите его. Не пропускайте этот шаг и не используйте один номер дважды.

## Шаг 4. Заполните профиль

- Загрузите фото профиля и обложку
- Заполните основную информацию (город, место работы, образование)
- Подпишитесь на 5–10 страниц по вашей тематике
- Вступите в 1–2 группы

В первые 24 часа не публикуйте ссылки, не создавайте события и не отправляйте заявки в друзья.

## Шаг 5. Прогрейте аккаунт

Facebook особенно тщательно проверяет новые аккаунты в первые 2–3 недели.

### График прогрева

| **Период** | **Фокус** | **Что делать** |
| :-- | :-- | :-- |
| День 0 | Настройка | Заполнение профиля \+ 15 минут серфинга |
| Дни 1–7 | Пассивная активность | Просматривайте ленту, смотрите видео, ставьте лайки |
| Дни 8–14 | Лёгкое взаимодействие | Комментарии, подписки на страницы, 2–3 заявки в друзья в день |
| Неделя 3 | Обычное использование | Группы, больше взаимодействий, редкие публикации |
| Неделя 4\+ | Готов к рекламе | Настройка Business Manager \+ рекламного аккаунта |

### Безопасный уровень активности

| **Действие** | **Рекомендуемый уровень** |
| :-- | :-- |
| Заявки в друзья | 5–10 в день |
| Подписки на страницы | 5–10 в день |
| Лайки постов | 15–30 в день |
| Вступление в группы | 1–2 в день |
| Публикации с внешними ссылками | После 3-й недели |

## Настройка Meta Ads

Настраивайте Meta Ads только после прогрева личного профиля — минимум 1–2 недели активности.

- Создайте аккаунт Business Manager ([business.facebook.com](http://business.facebook.com))
- Добавьте свой личный профиль в качестве администратора
- Создайте один рекламный аккаунт — начните с одного
- Добавьте уникальный способ оплаты
- Запустите небольшую тестовую кампанию (\$5–10 в день)
- Постепенно увеличивайте расходы в течение 1–2 недель

<Warning>
  Не добавляйте один и тот же способ оплаты в несколько рекламных аккаунтов. Facebook связывает аккаунты через общие способы оплаты. Для каждого рекламного аккаунта нужен уникальный источник оплаты.
</Warning>

## Типичные триггеры риска

### Мгновенные баны

- Вход с нового IP после того, как аккаунт уже был активен
- Один способ оплаты в нескольких рекламных аккаунтах
- Создание 5\+ аккаунтов за один день с одной локации прокси
- Запуск рекламы до прогрева профиля

### Постепенные ограничения

- Публикация одного и того же контента с нескольких аккаунтов
- Большое количество заявок в друзья при низком проценте принятия
- Массовое вступление в группы за короткое время
- Необычные скачки рекламных расходов
