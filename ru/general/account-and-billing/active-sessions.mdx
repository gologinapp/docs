title: "Активные сеансы"
---

Страница **Активные сеансы** показывает все устройства и местоположения, с которых сейчас выполнен вход в ваш аккаунт Gologin. С её помощью можно контролировать доступ к аккаунту, выявлять подозрительные входы и завершать незнакомые сеансы, не покидая одну страницу.

## Как открыть страницу

1. Нажмите на **название рабочего пространства** в левом верхнем углу приложения Gologin
2. Выберите **Настройки и участники** в выпадающем меню
3. В левой боковой панели нажмите **Активные сеансы**

## Что вы увидите

**Это устройство**

В верхней части страницы Gologin выделяет сеанс, которым вы пользуетесь сейчас, и отмечает его как **онлайн**. Ваш текущий IP адрес отображается под названием устройства.

В этом разделе также находится кнопка **Сбросить другие сессии**.

**Список активных сеансов**

Ниже вашего текущего устройства перечислены все остальные активные сеансы. Для каждого из них указано следующее:

| Поле | Описание |
| :-- | :-- |
| **Устройство / платформа** | Платформа, с которой выполнен вход (например, Gologin Web, приложение для Android, Linux). |
| **Версия приложения** | Версия клиента Gologin на момент входа. |
| **IP адрес** | IP адрес, связанный с этим сеансом. |
| **Последняя активность** | Как давно сеанс использовался в последний раз. |
| **Кнопка «Выйти»** | Кнопка для отдельного сеанса, которая сразу завершает именно этот сеанс. |

## Доступные действия

**Сбросить другие сессии**

Нажмите кнопку **Сбросить другие сессии**, чтобы мгновенно выйти на всех устройствах, кроме того, которым вы пользуетесь сейчас. Это самый быстрый способ защитить аккаунт, если вы подозреваете несанкционированный доступ.

**Завершить один сеанс**

У каждого сеанса в списке есть своя кнопка **Выйти**. С её помощью можно завершить сеанс на конкретном устройстве, не затрагивая остальные. Это удобно, когда вы узнаёте большинство сеансов, но хотите удалить один незнакомый.
