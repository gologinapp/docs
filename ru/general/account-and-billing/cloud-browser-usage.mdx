Панель **Cloud Browser** показывает ваши лимиты и использование облачного браузера — для профилей, запущенных через **Run in Cloud** в веб-приложении или через Cloud Browser API — и позволяет купить дополнительные облачные лимиты.

Чтобы открыть её, нажмите **Cloud Browser** в левом меню.

## Что здесь можно найти

В верхней части страницы:

- **Concurrent sessions limit** — сколько облачных профилей может работать одновременно. Нажмите **\+**, чтобы купить больше сессий.
- **Browser time** — сколько облачных часов использовано в этом месяце из месячного лимита, например **0 of 200 hours**. Нажмите **\+**, чтобы купить больше часов, или **Usage**, чтобы посмотреть статистику.
- **API key & documentation** — токен для Cloud Browser API. Нажмите на иконку копирования, чтобы скопировать его, или **View docs**, чтобы открыть документацию API.

Если вы ещё не запускали облачные профили, на странице показаны два способа начать:

- **Run from App** — нажмите **Open Profiles**, затем **Run in Cloud** у любого профиля.
- **Use via API** — скопируйте **Your API key** и нажмите **View docs**, чтобы узнать, как его использовать.

### Статистика использования

Нажмите **Usage** в блоке **Browser time**, чтобы увидеть, сколько облачных часов вы использовали. Выберите период в правом верхнем углу, например **7 days**, и нажмите **Download CSV**, чтобы скачать данные.

## Покупка дополнительных облачных лимитов

Нажмите **\+** рядом с **Concurrent sessions limit** или **Browser time**. В окне **Upgrade Cloud Browsing Limits** выберите нужное:

- **Concurrent sessions** — **\$2 за сессию в месяц**. Определяет, сколько профилей может работать в облаке одновременно.
- **Browsing time** — дополнительные облачные часы в месяц. Стоимость часа зависит от тарифа: **\$0.09** на Professional, **\$0.08** на Business, **\$0.07** на Enterprise и **\$0.05** на тарифах Custom.

В окне видно, сколько вы платите сейчас (**Initial payment**) и сколько в месяц (**Total per month**). Нажмите **Upgrade**, чтобы оплатить. Дополнительные облачные лимиты можно оплатить только через **Stripe** — PayPal и криптовалюта для них недоступны.

### Как работает оплата дополнительных лимитов

Стоимость дополнительных лимитов одинакова для месячных и годовых тарифов, но списание происходит по-разному:

- **Месячный тариф** — вы платите за дополнительные лимиты только до конца текущего расчётного периода. После этого они продлеваются вместе с тарифом.
- **Годовой тариф** — вы платите за один месяц за раз. Дополнительные лимиты списываются отдельно каждый месяц до окончания годового тарифа.

<Note>
  Облачные профили браузера и дополнительные облачные лимиты доступны только на платных тарифах.
</Note>
