Страница **Использование Cloud Browser** показывает, как вы используете облачные профили браузера — профили, запущенные через **Запустить в облаке** в веб-приложении или через Cloud Browser API — и позволяет купить дополнительные облачные лимиты.

Чтобы открыть её, нажмите на **название рабочего пространства** в левом верхнем углу > **Настройки и участники** > **Использование Cloud Browser**.

## Что здесь можно найти

- **API Ключ** — токен для Cloud Browser API. Нажмите **Показать токен**, чтобы увидеть его, или **Копировать**, чтобы скопировать.
- **Всего запусков** и **Всего часов** за выбранный период
- **Лимит часов** — количество облачных часов в месяц, доступных на вашем тарифе
- **Максимум параллельных запусков** — сколько облачных профилей может работать одновременно
- **Период использования** — сколько часов использовано в текущем периоде и когда период начался
- **Ежедневное использование** — запуски, часы и максимальное количество параллельных сессий по дням. Нажмите **Экспорт CSV**, чтобы скачать эти данные.

## Покупка дополнительных облачных лимитов

Нажмите **Купить больше лимитов** и выберите нужное:

- **Параллельные сессии** — **\$2 за сессию в месяц**. Определяет, сколько профилей может работать в облаке одновременно.
- **Браузерное время** — дополнительные облачные часы в месяц. Стоимость часа зависит от тарифа: **\$0.09** на Professional, **\$0.08** на Business, **\$0.07** на Enterprise и **\$0.05** на тарифах Custom.

![Лимиты Cloud Browser](/images/cloud_browser_limits.png "Лимиты Cloud Browser")

Нажмите **Оплатить**, чтобы перейти к оплате. Дополнительные облачные лимиты можно оплатить только через **Stripe** — PayPal и криптовалюта для них недоступны.

### Как работает оплата дополнительных лимитов

Стоимость дополнительных лимитов одинакова для месячных и годовых тарифов, но списание происходит по-разному:

- **Месячный тариф** — вы платите за дополнительные лимиты только до конца текущего расчётного периода. После этого они продлеваются вместе с тарифом.
- **Годовой тариф** — вы платите за один месяц за раз. Дополнительные лимиты списываются отдельно каждый месяц до окончания годового тарифа.

<Note>
  Облачные профили браузера и дополнительные облачные лимиты доступны только на платных тарифах.
</Note>
