Gologin Agent Browser CLI превращает профили браузера Gologin в постоянную среду выполнения со скриптовым управлением для ИИ-агентов. Сессии запускаются в Gologin Cloud Browser или в Orbita на вашем компьютере. CLI предоставляет компактные снимки страниц, взаимодействие через refs, память сессий и удобный для оболочки вывод.

В отличие от написания кода на Puppeteer/Playwright с нуля, этот CLI даёт агентам готовый набор команд для автоматизации браузера — без шаблонного кода и без кода для управления сессиями.

---

## Облачная или локальная среда выполнения

В CLI есть две среды выполнения с одинаковыми командами. Обе используют профили, отпечатки и прокси Gologin, а демон поддерживает сессии активными между вызовами CLI.

| | `cloud` (по умолчанию) | `local` |
|---|---|---|
| Где запускается браузер | Gologin Cloud Browser | Orbita на вашем компьютере |
| ID профиля | Необязателен: без него создаётся временный облачный профиль | Обязателен |
| Подходит для | Параллельных сессий, удалённых сессий, машин, на которых не должен работать браузер | Прогрева профилей, первых входов в аккаунты, локальных cookies и состояния профиля, соответствия вашей ОС |

Выбирайте среду выполнения для каждой команды с помощью `--runtime cloud|local|auto` или один раз задайте `GOLOGIN_AGENT_BROWSER_RUNTIME`:

```bash
gologin-agent-browser open https://example.com
gologin-agent-browser open https://example.com --runtime local --profile your_profile_id
```

По умолчанию (`auto`) команды для профилей, ранбуков и задач выполняются локально, а все остальные — в облаке. После открытия локальной сессии передавайте `--runtime local` и в следующие команды. Требования и команды, доступные только в локальной среде, описаны в разделе [Локальная среда выполнения](/ru/cli-tools/local-agent-browser).

## Установка

```bash
npm install -g gologin-agent-browser-cli
```

Или запуск без глобальной установки:

```bash
npx gologin-agent-browser-cli --help
```

Требуется Node.js >= 18. Для локальной среды выполнения нужен Node.js 20 или новее.

## Учётные данные

| Переменная | Обязательна | Описание |
|---|---|---|
| `GOLOGIN_TOKEN` | Да (для `open` и команд API) | API-токен Gologin |
| `GOLOGIN_PROFILE_ID` | Необязательна | ID профиля по умолчанию |
| `GOLOGIN_AGENT_BROWSER_RUNTIME` | Необязательна | Среда выполнения по умолчанию: `cloud`, `local` или `auto` |
| `GOLOGIN_DAEMON_PORT` | Необязательна | Порт демона (по умолчанию: `44777` для cloud, `44778` для local) |
| `GOLOGIN_CONNECT_BASE` | Необязательна | Эндпоинт Cloud Browser (по умолчанию: `https://cloudbrowser.gologin.com/connect`) |
| `GOLOGIN_EXECUTABLE_PATH` | Необязательна | Путь к исполняемому файлу Orbita для локальной среды выполнения |

### Получение токена

1. Зарегистрируйтесь или войдите на [gologin.com](https://gologin.com)
2. Откройте раздел **API & MCP** в личном кабинете
3. Перейдите на вкладку **API**
4. Нажмите **Новый токен**
5. Скопируйте созданный токен доступа

```bash
export GOLOGIN_TOKEN='your_gologin_token'
```

### Файл конфигурации

`~/.gologin-agent-browser/config.json`

## Архитектура

Система состоит из двух частей:

1. **CLI `gologin-agent-browser`** — разбирает команды, выбирает среду выполнения, автоматически запускает соответствующий демон и выводит компактный результат
2. **Постоянные локальные демоны**, по одному на каждую среду выполнения — управляют активными сессиями браузера, подключаются к Gologin Cloud Browser или локальной Orbita через Playwright `connectOverCDP`, хранят активную страницу в памяти, создают снимки, разрешают refs и отслеживают метаданные сессий

Транспорт только локальный. Облачный демон слушает:
- Unix-сокет `${TMPDIR:-/tmp}/gologin-agent-browser.sock`
- Локальный HTTP на `127.0.0.1:${GOLOGIN_DAEMON_PORT:-44777}`

В облачной среде выполнения, если вы не указали ID профиля, демон создаёт временный облачный профиль Gologin через API.

## Как работают refs

Команда `snapshot` выводит компактное представление страницы и назначает интерактивным элементам refs вида `@e1`, `@e2`, `@e3`. С ними можно работать напрямую:

```bash
gologin-agent-browser snapshot
# output shows page content with refs like @e1, @e2, @e3...

gologin-agent-browser click @e3
gologin-agent-browser type @e5 "search query"
gologin-agent-browser fill @e7 "username"
```

Refs работают по принципу «наилучшей попытки», поэтому после перехода на другую страницу или существенных изменений DOM их нужно создавать заново. Вместо refs команды также принимают CSS-селекторы. На динамических страницах вместо устаревших refs обычно лучше использовать `find`: он находит элемент на живой странице и выполняет действие за один шаг.

```bash
gologin-agent-browser find label "Email" fill "user@example.com"
gologin-agent-browser find role button click --name "Submit"
```

## Быстрый старт

```bash
export GOLOGIN_TOKEN='your_token'

# open a page in cloud browser
gologin-agent-browser open https://example.com

# read the page as a compact snapshot
gologin-agent-browser snapshot

# interact with elements
gologin-agent-browser click @e3
gologin-agent-browser type @e5 "hello world"

# take a screenshot
gologin-agent-browser screenshot ./page.png

# close the session
gologin-agent-browser close
```

---

## Пример цикла работы агента

Типичный цикл работы ИИ-агента:

```
1. open <url>
2. snapshot          → agent reads page content
3. click/type/fill   → agent acts on refs
4. snapshot          → agent reads result
5. repeat 3-4 as needed
6. screenshot        → save artifact
7. close
```

## Полный справочник команд

### Диагностика

| Команда | Описание |
|---|---|
| `doctor` | Проверить работоспособность демона и подключение |

### Управление сессиями

| Команда | Описание |
|---|---|
| `open <url>` | Открыть URL в сессии браузера |
| `close` | Закрыть текущую сессию (`--all` закрывает все сессии этого демона) |
| `sessions` | Показать список активных сессий (`--prune` удаляет устаревшие) |
| `current` | Показать информацию о текущей сессии |

### Чтение страницы

| Команда | Описание |
|---|---|
| `snapshot` | Компактный текстовый снимок с refs элементов |
| `screenshot <path>` | Сохранить скриншот страницы |
| `pdf <path>` | Сохранить страницу в PDF |
| `get <kind> [target]` | Получить свойства страницы |

### Взаимодействие

| Команда | Описание |
|---|---|
| `click <ref>` | Кликнуть по элементу |
| `dblclick <ref>` | Двойной клик |
| `type <ref> <text>` | Ввести текст (добавляется к существующему) |
| `fill <ref> <text>` | Заполнить поле (заменяет содержимое) |
| `hover <ref>` | Навести курсор на элемент |
| `select <ref> <value>` | Выбрать значение в выпадающем списке |
| `check <ref>` / `uncheck <ref>` | Установить или снять флажок |
| `focus <ref>` | Установить фокус на элемент |
| `find <by> <locator> <action> [value]` | Найти элемент по `role`, `text`, `label`, `placeholder`, `first`, `last` или `nth` и выполнить над ним `click`, `fill`, `type` или `hover`, либо прочитать его `text` |

### Клавиатура и прокрутка

| Команда | Описание |
|---|---|
| `press <key> [target]` | Нажать клавишу |
| `scroll <direction> [pixels]` | Прокрутить страницу |
| `scrollintoview <ref>` | Прокрутить страницу до элемента |

### Навигация

| Команда | Описание |
|---|---|
| `back` | Назад |
| `forward` | Вперёд |
| `reload` | Перезагрузить страницу |
| `wait <target\|ms>` | Ждать появления элемента или истечения времени |

### Вкладки

| Команда | Описание |
|---|---|
| `tabs` | Показать список открытых вкладок |
| `tabopen [url]` | Открыть новую вкладку |
| `tabfocus <index>` | Переключиться на вкладку |
| `tabclose [index]` | Закрыть вкладку |

### Cookies и хранилище

| Команда | Описание |
|---|---|
| `cookies` | Экспортировать cookies |
| `cookies-import <file>` | Импортировать cookies |
| `cookies-clear` | Очистить cookies |
| `storage-export [path]` | Экспортировать localStorage |
| `storage-import <file>` | Импортировать localStorage |
| `storage-clear` | Очистить localStorage |

### Расширенные возможности

| Команда | Описание |
|---|---|
| `eval <expression>` | Выполнить JavaScript на странице |
| `upload <ref> <file...>` | Загрузить файлы |

### Профили, прокси и API Gologin

Эти команды обращаются к API Gologin с вашим токеном и не требуют демона браузера.

| Команда | Описание |
|---|---|
| `api <METHOD> <path>` | Вызвать любой эндпоинт REST API Gologin |
| `browser <action>` | Профили: список, получение, создание, обновление, удаление, cookies, прокси, запуск и остановка в облаке, импорт и экспорт |
| `proxy <action>` | Прокси: список, добавление прокси Gologin, обновление, удаление, трафик |
| `workspace`, `folder`, `share`, `template` | Рабочие пространства и участники, папки, предоставление доступа, шаблоны профилей |
| `user`, `deleted-profile` | Информация об аккаунте и dev-токены, восстановление удалённых профилей |
| `cloud-usage` | Использование Cloud Browser для профиля или рабочего пространства |
| `profile-cloud`, `profile-cookies`, `profile-fingerprint`, `profile-proxy`, `profile-ua` | Сокращённые команды: запуск или остановка профиля в облаке, экспорт или импорт его cookies, обновление отпечатка, добавление прокси, обновление user agent |

```bash
gologin-agent-browser browser list --page 1
gologin-agent-browser proxy add-gologin your_profile_id --country us --type residential
gologin-agent-browser cloud-usage --profile your_profile_id
gologin-agent-browser api GET /browser/your_profile_id
```

Добавьте `--help` к любой команде, чтобы вывести справку по её использованию.

## Сценарии использования и примеры

### Проверка, проходит ли ваш сайт антидетект-тесты

```bash
gologin-agent-browser open https://iphey.com/ --profile your_profile_id
gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # read the trust score
gologin-agent-browser screenshot ./iphey-result.png
gologin-agent-browser close
```

### Вход в веб-приложение и извлечение данных из панели управления

```bash
gologin-agent-browser open https://app.example.com/login
gologin-agent-browser snapshot

# agent reads snapshot, finds login form
gologin-agent-browser fill @e4 "user@company.com"
gologin-agent-browser fill @e6 "password"
gologin-agent-browser click @e8

gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # agent reads dashboard content

# navigate to the report page
gologin-agent-browser click @e12   # "Reports" link
gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # agent extracts report data
gologin-agent-browser screenshot ./report.png
gologin-agent-browser close
```

### Заполнение многошаговой формы

```bash
gologin-agent-browser open https://forms.example.com/apply

# step 1: personal info
gologin-agent-browser snapshot
gologin-agent-browser fill @e3 "John Doe"
gologin-agent-browser fill @e5 "john@example.com"
gologin-agent-browser select @e7 "United States"
gologin-agent-browser click @e9   # Next

# step 2: upload and submit
gologin-agent-browser wait 1000
gologin-agent-browser snapshot
gologin-agent-browser upload @e4 ./resume.pdf
gologin-agent-browser check @e6   # agree to terms
gologin-agent-browser click @e8   # Submit

gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # confirm success
gologin-agent-browser close
```

### Скриншоты страниц конкурентов

```bash
# use different profiles with different geos
for profile in us_profile de_profile jp_profile; do
  gologin-agent-browser open https://competitor.com --profile $profile
  gologin-agent-browser wait 3000
  gologin-agent-browser screenshot ./${profile}-homepage.png
  gologin-agent-browser close
done
```

### Поиск на сайте, который блокирует скрапинг

Некоторые сайты требуют выполнения JavaScript, входа в аккаунт или действий пользователя, прежде чем показать результаты. Используйте для поиска браузер:

```bash
gologin-agent-browser open https://protected-directory.com
gologin-agent-browser snapshot
gologin-agent-browser find placeholder "Search" fill "machine learning engineer San Francisco"
gologin-agent-browser press Enter
gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # agent reads search results
gologin-agent-browser screenshot ./search-results.png
gologin-agent-browser close
```

### Сохранение и восстановление состояния сессии

Экспортируйте cookies и хранилище, чтобы использовать их в следующих сессиях:

```bash
# after logging in
gologin-agent-browser cookies --output ./session-cookies.json
gologin-agent-browser storage-export ./session-storage.json
gologin-agent-browser close

# later, restore the session
gologin-agent-browser open https://app.example.com
gologin-agent-browser cookies-import ./session-cookies.json
gologin-agent-browser storage-import ./session-storage.json
gologin-agent-browser reload
gologin-agent-browser snapshot     # already logged in
```

## Параллельные сессии

Для независимых облачных задач используйте явные ID `--session`. Для очистки применяйте `close --all` или `sessions --prune --older-than-ms`.

## Правила для прокси

- Предварительно настроенные профили: прокси задаётся в самом профиле через личный кабинет Gologin или API, например `proxy add-gologin <profileId> --country us`
- Временные облачные профили: без прокси или с вашим собственным прокси через `--proxy-host` и `--proxy-port` (а также `--proxy-mode http|socks4|socks5`, `--proxy-user`, `--proxy-pass`)
- В облачной среде выполнения `open` не принимает `--proxy-country`. Чтобы использовать трафик прокси Gologin из нужной страны, добавьте прокси Gologin в профиль и откройте его с помощью `--profile`
- В локальной среде выполнения `open`, `profile-create` и `profile-update` принимают `--proxy-country`
