---
title: "Как работают прокси Gologin"
---

Прокси Gologin встроены непосредственно в среду Gologin и подключаются к профилям браузера без дополнительной настройки.

Когда профилю назначен прокси, весь интернет-трафик этого профиля проходит через прокси-сервер. Это значит, что сайты видят IP-адрес прокси, а не ваш настоящий IP-адрес.

Использование отдельных прокси для разных профилей помогает изолировать сессии и снижает вероятность того, что несколько аккаунтов будут связаны между собой.

## Доступные типы прокси

Gologin предлагает несколько типов прокси:

- **Резидентные с ротацией** — оплата за трафик
- **Мобильные с ротацией** — оплата за трафик
- **Датацентр (sticky)** — оплата за трафик
- **Выделенный IP** — статический IP, закреплённый за вами, оплачивается по подписке \$5/месяц за каждый IP

Первые три типа используют трафик, входящий в ваш тариф, и берут адрес из общего пула. Выделенный IP принадлежит только вам, не меняется и не имеет ограничения по трафику.

## Страны прокси

**Для прокси с оплатой за трафик (резидентные, мобильные, датацентр):** при покупке трафика прокси Gologin вы получаете доступ ко всем странам, в которых мы предоставляем прокси. Вы не ограничены одной страной — трафик можно использовать для любой страны из списка. Сейчас доступны десятки стран, и время от времени мы добавляем новые. Полный список можно посмотреть прямо в приложении Gologin.

**Для Выделенный IP:** вы покупаете одну страну за раз. Полученный IP относится к выбранной вами стране, и его нельзя перенести в другую. Если вам нужны адреса в нескольких странах, купите отдельный Выделенный IP для каждой из них. Выбрать можно только страну — конкретный город выбрать нельзя.

Сейчас Выделенный IP доступен в следующих странах:

- Бразилия
- Франция
- Германия
- Гонконг
- Румыния
- Турция
- Великобритания
- США

<Note>
  Вы можете купить больше одного Выделенный IP в одной и той же стране. Каждая покупка даёт вам новый адрес, а все адреса группируются по стране в менеджере прокси.
</Note>

## Преимущества прокси Gologin

Использование прокси Gologin даёт несколько преимуществ:

- быстрая настройка без конфигурации сторонних сервисов
- простое назначение прокси профилям
- интеграция с профилями браузера Gologin
- упрощённое управление прокси в приложении
