title: "Быстрый старт"

В этом руководстве показано, как получить данные с первого URL с помощью Web Unlocker.

---

## Предварительные требования

- API-ключ Web Unlocker. Получите его через форму на [странице Web Unlocker](https://gologin.com/web-unlocker/#web_unlocker_form). Ключ приходит в течение одного рабочего дня, вместе с ним вы получаете бесплатные запросы, чтобы протестировать сервис на своих целевых сайтах. Банковская карта не нужна.
- Python 3.x, Node.js или любой HTTP-клиент

---

## Аутентификация

Во всех запросах необходимо передавать ваш API-ключ в заголовке `apikey`:

```
apikey: YOUR_API_KEY
```

Базовый URL для всех запросов к API:

```
https://parsing.webunlocker.gologin.com/v1
```

---

## Выполните первый запрос

Отправьте GET-запрос, указав целевой URL в параметре запроса. В ответ вы получите полностью отрендеренный HTML страницы.

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.text)
```

### JavaScript (Node.js / Browser)

```javascript
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(html);
```

---

## Что вы получите в ответ

Тело ответа — это готовый отрендеренный HTML страницы, то есть тот же контент, который вы увидели бы, открыв этот URL в браузере. Нет JSON-обёртки, дополнительный разбор не нужен.

```html
<!DOCTYPE html>
<html>
  <head><title>Example Domain</title></head>
  <body>...</body>
</html>
```

### Другие форматы

Добавьте параметр запроса `format`, чтобы получить страницу в другом формате:

| `format` | Тело ответа |
|---|---|
| `html` | HTML страницы (по умолчанию) |
| `markdown` | Содержимое страницы в формате Markdown |
| `json` | JSON-объект с URL, метаданными запроса и HTML страницы |

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com&format=json" \
  -H "apikey: YOUR_API_KEY"
```

```json
{
  "success": true,
  "data": {
    "url": "https://example.com",
    "metadata": {
      "response_time_ms": 297,
      "status_code": 200
    },
    "html": "<!DOCTYPE html><html lang=\"en\">..."
  }
}
```

## Обработка ошибок

Перед обработкой ответа проверяйте HTTP-статус:

| Статус | Значение | Тело ответа |
|---|---|---|
| `200` | Успешно | Страница в запрошенном формате |
| `400` | Некорректный запрос, например отсутствует параметр `url` | `{"success":false,"error":"Request failed"}` |
| `401` | Отсутствует заголовок `apikey` | `{"message":"Missing API key in request"}` |

Если вы получили статус `429` или `5xx`, повторите запрос с экспоненциальной задержкой.

```python
response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

if response.status_code == 200:
    html = response.text
else:
    print(f"Error {response.status_code}: {response.text}")
```

## Быстрый старт через CLI

Вы также можете получать данные со страниц с помощью CLI-инструментов Gologin без написания кода:

### Web Unlocker CLI

```bash
npm install -g gologin-webunlocker

GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker scrape https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker markdown https://example.com
```

### Gologin Web Access CLI (единый)

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."
gologin-web-access read https://example.com
gologin-web-access scrape-json https://example.com
gologin-web-access batch-scrape https://example.com/page/1 https://example.com/page/2 --format text
```

Подробнее см. в разделах [Web Unlocker SDK и CLI](/ru/scraping-api-sdk-and-cli) и [Web Access CLI](/ru/cli-tools/web-access).
