title: "Статические и ротационные прокси"
---

### Статические прокси

Статические прокси используют фиксированный IP-адрес, который со временем не меняется.

Их рекомендуется использовать для долгосрочной работы с аккаунтами, когда нужна стабильная геолокация входа.

### Sticky-прокси

Sticky-прокси сохраняют один и тот же IP-адрес в течение ограниченного периода сессии (обычно 10–30 минут), после чего происходит ротация.

Они полезны, когда нужна стабильность в рамках короткой сессии, а также подходят для работы с аккаунтами.

### Ротационные прокси

Ротационные прокси автоматически назначают новый IP-адрес из пула прокси.

Ротация может происходить:

- при каждом запросе
- после завершения сессии
- через заданный интервал времени

Обычно их используют для масштабного скрапинга или сбора данных. Как правило, их можно применять и для работы с аккаунтами, если IP-адрес остаётся неизменным в течение сессии.

### Какой тип прокси подходит для какой платформы?

| Платформа | Рекомендуемый тип прокси | Почему |
| --- | --- | --- |
| LinkedIn | Статические резидентные или мобильные | Смена IP сразу запускает проверку безопасности |
| Facebook / Meta Ads | Статические резидентные или sticky | Для рекламных аккаунтов нужна согласованная геолокация |
| Amazon / eBay / Etsy | Статические ISP | Ротация IP связывает аккаунты и приводит к блокировкам |
| TikTok (новые аккаунты) | Мобильные | Мобильные IP вызывают наибольшее доверие при создании аккаунта |
| Веб-скрапинг | Ротационные резидентные или датацентровые | Скорость и объём важнее постоянства |
| Платформы для ставок | Мобильные | Максимальный уровень доверия; платформы жёстко реагируют на десктопные фингерпринты |

<Warning>
  Использование ротационных прокси для аккаунтов продавцов Amazon — распространённая ошибка, которая приводит к блокировке аккаунтов. Amazon связывает аккаунты по IP: если ваш IP меняется, несколько аккаунтов могут быть помечены как связанные.
</Warning>
