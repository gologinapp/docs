title: "Готовые шаблоны профилей"
---

Готовые шаблоны профилей содержат рекомендуемые настройки браузерных профилей для типичных сценариев работы с популярными платформами.

Эти шаблоны показывают типичные настройки для разных платформ: конфигурацию фингерпринта, тип прокси и региональные параметры. Их можно использовать как отправную точку при создании новых браузерных профилей в Gologin.

Шаблоны — это примеры, а не жёстко заданные пресеты, поэтому их можно изменять под ваш рабочий процесс.

## Шаблон профиля для TikTok

Рекомендуемая конфигурация для аккаунтов TikTok.

| Параметр | Рекомендуемая настройка |
| :-- | :-- |
| Тип браузера | Среда, имитирующая мобильное устройство |
| Тип прокси | Резидентный или мобильный |
| Расположение прокси | Фиксированный регион |
| Изменения фингерпринта | Минимальные |
| Часовой пояс | Соответствует расположению прокси |

TikTok сильно опирается на постоянство устройства и поведение в рамках сессии. Стабильное окружение помогает уменьшить количество проверок.
