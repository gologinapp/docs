## Требования к оборудованию

- **Оперативная память:** минимум 4 ГБ
- **Свободное место на диске:** не менее 1 ГБ

## Установка

### Windows

1. Скачайте установщик приложения [здесь](https://gologin.com/download/)
2. Откройте папку **Загрузки**
3. Дважды щёлкните по скачанному файлу и следуйте подсказкам установщика

### Mac OS

1. Скачайте установщик приложения [здесь](https://gologin.com/download/)
2. Откройте папку **Загрузки**
3. Дважды щёлкните по файлу и следуйте инструкциям

### Linux, пример для Ubuntu

Gologin для Linux поставляется в виде архива `.tar`. Приложение внутри архива самодостаточно и не требует традиционной установки: распакуйте архив и запустите Gologin из распакованной папки.

1. Скачайте архив по этой [ссылке](https://gologin.com/download)
2. Откройте папку **Загрузки**
3. Щёлкните правой кнопкой мыши по файлу `gologin.tar` \> **Извлечь**
4. Перейдите в папку **gologin** \> запустите Gologin двойным щелчком

**Если приложение не открывается**

- если система воспринимает приложение как текстовый файл, один раз запустите его через терминал с параметром --no-sandbox
  ```bash bash
  cd ~/Downloads/gologin
  ./<filename> --no-sandbox
  ```
- возможно, файл нужно сделать исполняемым. Вставьте в терминал следующие команды:
  ```bash bash
  cd ~/Downloads/gologin
  chmod +x <filename>
  ```
  замените `<filename>` на фактическое имя файла
- в новых системах может понадобиться пакет **libfuse2**. Вставьте в терминал следующую команду и попробуйте запустить приложение снова.
  ```bash bash
    sudo apt install libfuse2
  ```

**Если профили не запускаются при нажатии «Запустить»**

- откройте терминал и перейдите в папку браузера, например версии Orbita 145
- задайте новые права для **chrome-sandbox**
  ```bash bash
  cd ~/.gologin/browser/orbita-browser-145
  sudo chown root:root chrome-sandbox
  sudo chmod 4755 chrome-sandbox
  ```

### Android

Чтобы использовать Gologin на Android, достаточно установить **приложение Gologin** из **Google Play Store**.

1. Откройте **Google Play Store** на телефоне
2. Найдите строку поиска вверху и введите **Gologin** \> **установите приложение**

После установки приложением можно пользоваться сразу — встроенный браузер уже входит в его состав.

## Неподдерживаемые конфигурации

Gologin **не** поддерживает следующие платформы:

- Любые 32-разрядные системы
- Windows 7, 8, 8.1, Server 2012 (любых редакций) и более ранние версии
- macOS El Captain, Sierra, High-Sierra, Mojave, Catalina, Big Sur и более ранние версии
- Chrome OS (вы можете использовать [веб-версию Gologin](/ru/gologin-web-overview))
