title: "Настройки профиля по умолчанию"
---

**Настройки профиля по умолчанию** позволяют задать шаблон для новых профилей. Всё, что вы настроите здесь, будет автоматически применяться при создании нового профиля. Уже существующие профили не затрагиваются — изменения действуют только для профилей, созданных после них.

Пока что не все настройки доступны в настройках по умолчанию.

<Tip>
  Эти настройки применяются только к профилям, которые вы создадите после изменения. К уже существующим профилям они применены не будут.
</Tip>

Как открыть этот раздел:

1. Нажмите на **название рабочего пространства** в левом верхнем углу.
2. Перейдите в **Настройки и участники**.
3. В левой боковой панели нажмите **Настройки профиля по умолчанию**.

## Прокси и местоположение

В разделе **Прокси и местоположение** можно выбрать, какой прокси новые профили будут получать автоматически:

- **Gologin прокси** — выберите страну и тип прокси. Каждый новый профиль будет создан с Gologin прокси в выбранном местоположении.
- **Без прокси** — новые профили создаются без прокси и используют ваше реальное интернет-соединение.

По умолчанию новые профили получают Gologin прокси. Обычно это местоположение в США или в стране, которую вы выбрали при первоначальной настройке.

Это относится к профилям, созданным с помощью кнопки **\+** (быстрые профили) и через **Добавить профиль**.

<Note>
  Gologin прокси расходуют ваш прокси-трафик. Если вы предпочитаете использовать собственные прокси, переключите эту настройку на **Без прокси**, а затем назначьте прокси каждому профилю вручную. См. [Добавление прокси](/ru/proxy/proxy-management/adding-proxies).
</Note>

В этом же разделе можно включить **Отключить загрузку изображений** и **Отключить автовоспроизведение видео**, чтобы новые профили расходовали меньше прокси-трафика. Доступно только на платных тарифах.

## Восстановление настроек по умолчанию

Если вы изменили настройки профиля по умолчанию и хотите вернуть исходные, нажмите на **значок стрелки** рядом с пунктом **Восстановить базовые настройки профиля по умолчанию** в верхней части страницы. Настройки вернутся к тем, которые Gologin задаёт для новых аккаунтов в зависимости от операционной системы вашего устройства.

Это сбрасывает только шаблон для новых профилей. Ваши существующие профили не изменятся.
