title: "FAQ: Android"
---

### Приложение для Android полностью бесплатное?

Приложение можно бесплатно скачать и использовать с вашим текущим тарифом Gologin. Доступные функции зависят от подписки (действуют лимиты на количество профилей).

### Можно ли запускать несколько профилей одновременно на Android?

Нет — для стабильной работы приложение запускает только один профиль за раз. Версия для компьютера поддерживает параллельный запуск.

### Работает ли приложение на эмуляторах?

Приложение предназначено для реальных физических устройств на Android. Использовать его на эмуляторах не рекомендуется — это может ухудшить качество отпечатка.

### Как синхронизируются профили между компьютером и Android?

Войдите в один и тот же аккаунт — изменения синхронизируются между устройствами.

### Почему приложение предупреждает меня об операционной системе при запуске профиля?

Приложение для Android предупреждает вас, если профиль был создан в настольной ОС, например Windows. Вы можете нажать **Всё равно запустить**, но сайты могут заметить, что ОС профиля не совпадает с ОС устройства. Лучше запускать каждый профиль в той же ОС, в которой он был создан: профили Android — в приложении для Android, профили для компьютера — в приложении для компьютера.

### Где можно получить поддержку?

Обратитесь в поддержку через приложение, по электронной почте [**support@gologin.com**](mailto:support@gologin.com) или через официальный сайт.
