## Обзор

**Профиль браузера** — это сгенерированный набор параметров браузера, с помощью которого браузер имитирует уникальное физическое устройство и пользователя. Каждый профиль выступает как отдельная цифровая личность с уникальным отпечатком и настраиваемыми параметрами.

Новые профили можно создать тремя способами.

## Быстрые профили

Это способ быстро добавить новый профиль с учётом ваших [настроек профиля по умолчанию](/ru/default-profile-settings), включая прокси. По умолчанию быстрые профили создаются с прокси Gologin, который расходует ваш прокси-трафик. Подходит для большинства сценариев.

Чтобы создать быстрый профиль:

1. Перейдите на вкладку **Все профили**
2. Нажмите кнопку **\+** в списке профилей

<Frame>
  ![New Profile Plus](/images/new_profile_plus-3.png)
</Frame>

## Пользовательские профили

Используйте этот способ, если нужно изменить некоторые настройки. Перед созданием профиля вы можете выбрать различные параметры, например операционную систему, прокси или другие расширенные настройки.

Чтобы добавить профиль таким способом:

1. Нажмите **Добавить профиль**
2. Настройте параметры профиля
3. Нажмите **Создайте профиль**

<Frame>
  ![New Custom Profile](/images/new_custom_profile.gif)
</Frame>

Затем вы можете изменить настройки профиля и просто нажать кнопку **Создайте профиль**, чтобы сохранить их и создать профиль.

## Массовое создание профилей

Вы также можете создать **до 30 профилей** одновременно. Большинство настроек будут заданы по умолчанию, а некоторые из них можно изменить сразу после создания профилей.

1. Нажмите на стрелку рядом с кнопкой **Добавить профиль**
2. Выберите количество профилей для создания (до 30)
3. Нажмите **Добавьте несколько профилей**

<Frame>
  ![New Bulk Profiles](/images/new_bulk_profiles.gif)
</Frame>

Сразу после создания профилей вы сможете изменить некоторые параметры в новом окне.

## Запуск профиля

Чтобы запустить профиль, просто нажмите **Старт** на нужном профиле. Откроется новое окно браузера с уникальными параметрами вашего профиля.

<Frame>
  ![Run And Stop The Profile](/images/run_and_stop_the_profile.gif)
</Frame>

Чтобы остановить запущенный профиль, **закройте браузер крестиком (X)**, как любое другое окно, или нажмите **Стоп** на профиле.

<Warning>
  Дождитесь статуса профиля **готов**, прежде чем закрывать приложение Gologin: важно дождаться синхронизации данных профиля с серверами. Сбой при загрузке данных может привести к их потере!
</Warning>
