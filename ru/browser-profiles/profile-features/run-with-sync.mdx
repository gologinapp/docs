---
title: "Запустить с синхронизатором"
---

Функция «Запустить с синхронизатором» одновременно запускает несколько профилей браузера и в реальном времени повторяет ваши действия во всех них. Всё, что вы делаете в главном окне — клики, ввод текста, переход по URL, — автоматически выполняется во всех остальных профилях одновременно.

Это удобно для однотипной работы с аккаунтами: прогрева аккаунтов, выполнения одного и того же действия в нескольких профилях или заполнения одинаковых форм. Вместо того чтобы переключаться между окнами и повторять одни и те же шаги, вы выполняете их один раз.

<Warning>
  Сайты распознают одинаковое одновременное поведение разных аккаунтов. Используйте «Запустить с синхронизатором» только для задач, где одинаковые действия допустимы: прогрев, первичная настройка, переход по URL. Не используйте его для публикаций, отправки сообщений и любых действий, где одинаковый контент вызовет подозрения.
</Warning>

## Как использовать

### Шаг 1 — Выберите профили

В списке профилей отметьте флажками профили, которые хотите запустить вместе.

### Шаг 2 — Нажмите «Запустить с синхронизатором»

В верхней части экрана появится панель массовых действий. Нажмите «Запустить с синхронизатором».

Все выбранные профили откроются в отдельных окнах браузера.

### Шаг 3 — Работайте в окне лидера

Первый профиль в списке выбранных становится лидером. Все ваши действия в его окне — клики, ввод текста, переходы — повторяются в реальном времени во всех остальных открытых профилях. Остальные профили являются ведомыми: они повторяют действия лидера, но не могут им управлять.

## Примеры использования

**Прогрев аккаунтов:** откройте 10–20 новых аккаунтов и вместе просматривайте одни и те же страницы. Каждый профиль работает независимо (с разным отпечатком и разным IP), а вам нужно выполнить переход только один раз.

**Одинаковая настройка аккаунтов:** переходите на страницы настроек, переключайте одни и те же опции, заполняйте одинаковые поля профиля. Это удобно при настройке множества новых аккаунтов с одинаковой начальной конфигурацией.

**Переход по рабочему URL:** когда нужно, чтобы во всех профилях была открыта определённая страница, прежде чем вы начнёте работать с каждым из них по отдельности, перейдите по ссылке один раз, и все профили одновременно окажутся на этой странице.

**Проверка поведения отпечатков в разных профилях:** откройте сайты-чекеры ([iphey.com](http://iphey.com), [pixelscan.net](http://pixelscan.net)) сразу в нескольких профилях, чтобы сравнить результаты рядом.

## Чего следует избегать

**Публикации одинакового контента:** если все профили одновременно публикуют один и тот же текст, изображение или ссылку, платформы сразу свяжут аккаунты между собой. Используйте «Запустить с синхронизатором» только для действий, где одинаковое поведение нормально: просмотр страниц, клики, навигация. Не используйте его для создания контента.

**Рассылки и переписки:** одновременная отправка одинаковых сообщений одним и тем же людям с разных аккаунтов — один из самых быстрых способов спровоцировать автоматическую блокировку сразу всех аккаунтов.

**Вход в новые аккаунты:** в каждом профиле при входе могут появляться разные запросы 2FA, CAPTCHA или шаги проверки. Синхронизатор повторит ваши действия, но не справится с различающимися состояниями: в одном профиле может отображаться CAPTCHA, а в другом вход уже выполнен. Выполняйте вход в каждом профиле отдельно, прежде чем включать синхронизатор.

## Остановка профилей

Чтобы закрыть все профили, запущенные через «Запустить с синхронизатором»:

1. Выберите все запущенные профили с помощью флажков
2. Нажмите **Остановить профили** на панели массовых действий

<Frame>
  ![0331(1)(1)](/images/0331\(1\)\(1\).gif)
</Frame>

Также можно закрывать окна браузера по одному. Gologin синхронизирует данные каждого профиля при его закрытии.

<Warning>
  Прежде чем закрывать само приложение, дождитесь, пока у каждого профиля в приложении Gologin появится статус **готов**. Если закрыть Gologin, пока профили ещё синхронизируются, данные этих сессий будут потеряны.
</Warning>

## Отличия от обычного массового запуска

|  | Запустить (массовый) | Запустить с синхронизатором |
| :-- | :-- | :-- |
| Профили действуют независимо | ✅ | ❌ |
| Действия повторяются во всех окнах | ❌ | ✅ |
| Лучше всего подходит для | Открытия профилей для раздельной работы | Повторения одних и тех же действий во всех профилях |

Используйте обычную кнопку **Запустить**, когда нужно открыть много профилей, а затем работать с каждым по отдельности. Используйте **«Запустить с синхронизатором»**, когда нужно выполнить абсолютно одинаковые действия во всех профилях сразу.
