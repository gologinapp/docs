title: "Запустить с синхронизатором"
---

Функция «Запустить с синхронизатором» открывает сразу несколько профилей браузера и в реальном времени повторяет ваши действия во всех них. Всё, что вы делаете в главном окне — клики, ввод текста, переход по URL — автоматически выполняется во всех остальных профилях одновременно.

Это удобно для однотипной работы с аккаунтами: прогрева, выполнения одного и того же действия в нескольких профилях или заполнения одинаковых форм. Вам не нужно переключаться между окнами и повторять одни и те же шаги — достаточно выполнить их один раз.

<Warning>
  Сайты распознают одинаковое одновременное поведение разных аккаунтов. Используйте «Запустить с синхронизатором» только для задач, где одинаковые действия допустимы: прогрева, первичной настройки, перехода по URL. Не применяйте его для публикации постов, отправки сообщений и любых действий, где одинаковый контент вызовет подозрения.
</Warning>

## Как использовать

### Шаг 1 — Выберите профили

В списке профилей отметьте флажками профили, которые хотите запустить вместе.

### Шаг 2 — Нажмите «Запустить с синхронизатором»

В верхней части экрана появится панель массовых действий. Нажмите «Запустить с синхронизатором».

Все выбранные профили откроются в отдельных окнах браузера.

### Шаг 3 — Работайте в окне лидера

Первый профиль в списке выбранных становится лидером. Все ваши действия в его окне — клики, ввод текста, переходы — повторяются во всех остальных открытых профилях в реальном времени. Остальные профили являются ведомыми: они повторяют действия лидера, но не могут им управлять.

## Практические сценарии

**Прогрев аккаунтов:** откройте 10–20 новых аккаунтов и вместе просматривайте одни и те же страницы. Каждый профиль работает независимо (у него свой фингерпринт и свой IP), а переходить по страницам нужно только один раз.

**Одинаковая настройка аккаунтов:** переходите на страницы настроек, переключайте одни и те же опции, заполняйте одинаковые поля профиля. Это полезно при настройке большого количества новых аккаунтов с одинаковой начальной конфигурацией.

**Переход по рабочему URL:** если перед индивидуальной работой нужно, чтобы во всех профилях была открыта определённая страница, перейдите по ссылке один раз — и все профили одновременно окажутся на ней.

**Проверка фингерпринтов в разных профилях:** откройте сайты-чекеры ([iphey.com](http://iphey.com), [pixelscan.net](http://pixelscan.net)) сразу в нескольких профилях, чтобы сравнить результаты рядом.

## Чего следует избегать

**Публикации одинакового контента:** если все профили одновременно опубликуют один и тот же текст, изображение или ссылку, платформы сразу свяжут аккаунты между собой. Используйте «Запустить с синхронизатором» только для действий, где одинаковое поведение нормально: просмотра страниц, кликов, навигации, но не для создания контента.

**Рассылки сообщений и аутрича:** одновременная отправка одинаковых сообщений одним и тем же людям с разных аккаунтов — один из самых быстрых способов получить автоматическую блокировку сразу всех аккаунтов.

**Входа в новые аккаунты:** при входе в разных профилях могут появиться разные запросы 2FA, CAPTCHA или шаги верификации. Синхронизатор повторит ваши действия, но не справится с расхождением состояний: в одном профиле может отображаться CAPTCHA, а в другом вход уже выполнен. Выполняйте вход в каждом профиле по отдельности до включения синхронизатора.

## Остановка профилей

Чтобы закрыть все профили, запущенные через «Запустить с синхронизатором»:

1. Отметьте флажками все запущенные профили
2. Нажмите **Остановить профили** на панели массовых действий

<Frame>
  ![0331(1)(1)](/images/0331\(1\)\(1\).gif)
</Frame>

Также можно закрыть каждое окно браузера по отдельности. Gologin синхронизирует данные каждого профиля при его закрытии.

<Warning>
  Прежде чем закрывать приложение Gologin, дождитесь, пока у каждого профиля появится статус **готов**. Если закрыть Gologin, пока профили ещё синхронизируются, данные этих сессий будут потеряны.
</Warning>

## Отличия от обычного запуска («Старт», массовый)

|  | «Старт» (массовый) | «Запустить с синхронизатором» |
| :-- | :-- | :-- |
| Профили действуют независимо | ✅ | ❌ |
| Действия повторяются во всех окнах | ❌ | ✅ |
| Лучше всего подходит для | Открытия профилей для раздельной работы | Повторения одинаковых действий во всех профилях |

Используйте обычный запуск **Старт**, когда нужно открыть много профилей и затем работать с каждым по отдельности. Используйте **Запустить с синхронизатором**, когда нужно выполнить абсолютно одинаковые действия во всех профилях одновременно.
