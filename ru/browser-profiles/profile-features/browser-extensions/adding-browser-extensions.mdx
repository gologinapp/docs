---
title: "Добавление расширений браузера в профили"
---

В Gologin можно добавлять публичные расширения двумя способами.

## Добавление через вкладку «Расширения»

Расширения можно добавить в профиль браузера **прямо из настроек профиля**, не обращаясь к Chrome Web Store:

1. На странице «Все профили» **нажмите на три точки рядом с профилем**, в который нужно установить расширение, и выберите **Настройки**
2. Перейдите на вкладку **Расширения**
3. Нажмите **Добавить расширения**
4. Найдите нужное расширение с помощью строки поиска и нажмите **Установить**
5. Не забудьте нажать **Сохранить**, чтобы применить изменения

<Frame>
  ![Добавление расширений через настройки](/images/add_extensions_via_settings.gif)
</Frame>

Чтобы удалить расширение, нажмите **Удалить** в том же меню.

<Tip>
  Если нужного расширения нет в списке, установите его хотя бы один раз через Chrome Web Store. Установленное расширение появится в списке в течение 24 часов.
</Tip>

### Добавление расширений в каждый новый профиль

Если вы знаете, что определённые расширения понадобятся во всех ваших профилях, нажмите на **значок флажка** рядом с расширением — оно будет автоматически появляться в каждом новом профиле.

<Frame>
  ![Добавление расширений в каждый новый профиль](/images/add_extensions_to_every_new_profile.png)
</Frame>

<Note>
  Такие расширения не появятся в уже созданных профилях. Они будут добавлены только в те профили, которые вы создадите после этого изменения.
</Note>

## Установка через Chrome Web Store

Если вы не нашли расширение на вкладке «Расширения» в настройках профиля, можно воспользоваться **Chrome Web Store** прямо в профиле браузера. Для этого:

1. **Запустите профиль браузера**, в который нужно добавить расширение
2. В браузере нажмите **три точки в правом верхнем углу** \> **Расширения** \> **Открыть Chrome Web Store**
3. Найдите нужное расширение
4. Нажмите **Установить в Chrome** и дождитесь завершения установки
