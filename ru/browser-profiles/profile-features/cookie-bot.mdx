Cookie Bot — это встроенный инструмент Gologin, который автоматически генерирует cookie для профиля. Он поможет автоматизировать прогрев профиля.

Cookie Bot имитирует естественное поведение пользователя: посещает популярные сайты и выполняет простые действия, например прокручивает страницы и нажимает на кнопки. Благодаря этому перед входом в аккаунты создаётся более реалистичная среда браузера.

Cookie Bot помогает:

- сформировать начальную историю просмотров
- создать естественные cookie для сайтов
- прогреть новые профили браузера
- подготовить профили к входу в аккаунты или автоматизации

## Как работает Cookie Bot

Cookie Bot посещает список распространённых сайтов и имитирует базовые действия пользователя.

Это могут быть следующие действия:

- загрузка страниц
- прокрутка содержимого
- нажатие на кнопки
- загрузка изображений

В результате в профиле появляются cookie и данные о просмотрах, и сессия браузера выглядит более естественно.

## Возможности и настройки Cookie Bot

Сейчас доступны следующие настройки:

- **Загрузка изображений**\
  ВКЛ — изображения будут загружаться\
  ВЫКЛ — изображения не будут загружаться, что экономит трафик прокси
- **Использовать скролл**\
  ВКЛ — бот будет прокручивать страницы, имитируя поведение человека\
  ВЫКЛ — бот не будет прокручивать страницы и сразу перейдёт к следующему шагу
- **Использовать автоклик**\
  ВКЛ — бот будет **принимать запросы на использование cookie** за вас\
  ВЫКЛ — бот ничего не будет нажимать

Что пока не поддерживается:

- Ручная запись сценариев для бота
- Настройка того, на что нажимает бот

## Запуск Cookie Bot

### Запуск Cookie Bot для одного профиля

1. Перейдите на страницу **Все профили**.
2. Нажмите **три точки** рядом с нужным профилем.
3. Выберите **Автоматизация**.
4. Просмотрите список сайтов, которые должен посетить бот.
5. При необходимости измените дополнительные настройки.
6. Нажмите **Старт**.

<Frame>
  ![Запуск Cookie Bot для профиля](/images/run_cookie_bot_for_profile-1.gif)
</Frame>

Cookie Bot имитирует активность в браузере и создаст cookie для профиля.

### Запуск Cookie Bot для нескольких профилей

В Gologin можно запустить Cookie Bot **сразу для нескольких профилей**.

Для этого:

1. Выберите несколько профилей в таблице профилей.
2. Выберите **Автоматизация**.
3. Настройте параметры.
4. Нажмите **Старт**.

<Frame>
  ![Запуск Cookie Bot для нескольких профилей](/images/run_cookie_bot_for_multiple_profiles.gif)
</Frame>

Процесс запустится для всех выбранных профилей.

## Рекомендации

Чтобы получить наилучший результат:

- запускайте Cookie Bot до входа в новые аккаунты
- не отключайте прокси профиля во время работы бота
- не запускайте Cookie Bot слишком часто на одном и том же профиле

Это помогает сохранить естественную среду браузера.
