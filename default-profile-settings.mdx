title: "Default profile settings"
---

**Default profile settings** let you define a template for new profiles. Anything you configure here is applied automatically when a new profile is created. Existing profiles are not affected — changes only apply going forward.

Not every setting is available in the default settings for now.

<Tip>
  These settings will only apply to all the profiles you're creating after the change, they won't be applied to already existing profiles.
</Tip>

How to get there:

1. Click your **workspace name** in the top-left corner.
2. Navigate to **Settings & Members**.
3. In the left sidebar, click **Default profile settings**.

## Proxy & Location

In the **Proxy & Location** section, you can choose which proxy new profiles get automatically:

- **Gologin proxy** - choose the country and the proxy type. Every new profile will be created with a Gologin proxy in that location.
- **Without proxy** - new profiles are created without a proxy and use your real internet connection.

By default, new profiles get a Gologin proxy. The location is usually the US, or the country you chose during onboarding.

This applies to profiles created with the **\+** button (quick profiles) and with **Add profile**.

<Note>
  Gologin proxies use your proxy traffic. If you prefer to add your own proxies, switch this setting to **Without proxy**, then assign proxies to each profile manually. See [Adding proxies](/proxy/proxy-management/adding-proxies).
</Note>

In the same section, you can turn on **Disable image loading** and **Disable video autoplay** so that new profiles use less proxy traffic. Available on paid plans only.

## Restoring default settings

If you've changed your default profile settings and want to go back to the original ones, click the **arrow icon** next to **Restore default profile settings** at the top of the page. The settings will return to the ones Gologin sets for new accounts based on your device's operating system.

This only resets the template for new profiles. Your existing profiles won't change.
