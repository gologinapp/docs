**Cloud Android** lets you run real Android phones in the cloud right from the Gologin app - no physical phone needed. Each Cloud Android profile is a separate phone with its own apps and data, so you can work with mobile apps (for example, Instagram) the same way you work with browser profiles.

## Who can use it

Cloud Android is free for all paid Gologin plans. Users on the free trial can also use it during the trial if they registered with Google.

| | Phones running at the same time | Time limit |
| --- | --- | --- |
| Trial (Google sign-up) | 1 | No limit |
| Paid plans | up to 10 | No limit |

## Creating and running a Cloud Android profile

![Cloud Android](/images/cloud_android.png "Cloud Android")

1. Click **Cloud Android** in the left menu.
2. Click **Add Android Profile**.
3. Set up the proxies and other settings.
3. Click **Run** on the profile. Starting a phone can take **up to 2 minutes**.
4. When the profile is **running**, click **View** to open the phone window.
5. To finish, click **Stop**.

The number of phones running now is shown at the top of the page (**Currently running**).

## Working with the phone

The phone window has the standard Android buttons plus tools on the right side - for example, screenshots, uploading and downloading files, rotating the screen, volume, location and power.

Install apps through the app stores on the phone, such as **Aurora Store**, **F-Droid** or **Uptodown**. Apps, logins and other data stay inside the profile between launches.

![Cloud Android Prone Ui](/images/cloud_android_prone_ui.png "Cloud Android Prone Ui")

<Note>
  Not every Android app works in Cloud Android. If an app doesn't open, try its website in the browser instead.
</Note>

## Proxies

Cloud Android phones run on Gologin servers, so without a proxy, websites and apps see the server's IP address, not yours. Add a proxy to the profile the same way as for browser profiles - all proxy types are supported, including Gologin proxies and your own. Mobile proxies look the most natural for a phone, but any type works.

## Inactivity timeout

If a running phone has no activity for **15 minutes**, it stops automatically. Your data is saved.
