---
title: "¿Qué es Web Unlocker?"
---

Web Unlocker es una API de scraping universal. Envía cualquier URL y recibe el HTML completamente renderizado, una captura de pantalla y un archivo de red, sin infraestructura que gestionar, sin bloqueos y sin solicitudes fallidas.

Funciona como un reemplazo completo de tu stack de scraping: automatización del navegador, gestión de proxies, fingerprinting y resolución de CAPTCHA, todo en una sola llamada a la API. Tanto si extraes datos de una página estática sencilla como de un sitio con JavaScript y protección avanzada, el mismo endpoint se encarga de todo.

---

## Qué problemas resuelve

Hoy en día es difícil hacer scraping de los sitios web modernos. Una simple llamada con `curl` o `requests` suele devolver una página de verificación, una respuesta en blanco o HTML roto, porque el contenido se carga con JavaScript. Web Unlocker gestiona todo esto de forma automática:

- **Renderizado de JavaScript**: las páginas se cargan en un navegador real y se ejecutan por completo antes de capturar el contenido
- **Evasión de sistemas anti-bot**: protecciones como Cloudflare, DataDome, PerimeterX y similares se gestionan automáticamente
- **Rotación inteligente de IP**: las solicitudes se enrutan a través de IP residenciales limpias con fingerprints de navegador realistas
- **Resolución de CAPTCHA**: los CAPTCHA más comunes se resuelven sin intervención manual
- **Selección por nivel de precio**: las solicitudes se enrutan por el nivel de proxy adecuado para el sitio de destino

## Cómo funciona

Web Unlocker ejecuta un navegador Chromium real en la nube para cada tarea. Cuando envías una URL:

1. Se inicia un navegador con una IP residencial y un fingerprint de navegador realista
2. Se navega a la página, se ejecuta el JavaScript y se carga el contenido dinámico
3. Los desafíos anti-bot y los CAPTCHA se gestionan automáticamente
4. Se captura y se devuelve el HTML renderizado, una captura de pantalla y un archivo de red

Nunca tienes que gestionar infraestructura. No hay navegadores que poner en marcha, ni listas de proxies que mantener, ni lógica de evasión que desarrollar. Web Unlocker sustituye de forma efectiva todo un stack de scraping (framework de automatización del navegador, proveedor de proxies y solución anti-bot) por una sola solicitud HTTP.

## Cómo usarlo

Envía una solicitud GET con la URL de destino como parámetro de consulta. La respuesta es el HTML completamente renderizado.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Consulta la [Quickstart](/es/web-unlocker-quick-start) para ver ejemplos en Python y JavaScript, o [Use Cases](./web-unlocker-use-cases.md) para conocer patrones de integración habituales.
