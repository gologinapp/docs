---
title: "¿Qué es Web Unlocker?"
---

Web Unlocker es una API de scraping universal. Envías cualquier URL y recibes el HTML completamente renderizado, o bien la página en Markdown o JSON, sin tener que gestionar navegadores ni proxies.

Sustituye la parte de navegador y proxies de tu stack de scraping: el renderizado, la gestión de proxies y las huellas digitales del navegador se resuelven en una sola llamada a la API. Las páginas estáticas y los sitios con mucho JavaScript pasan por el mismo endpoint.

---

## Qué problemas resuelve

Hoy en día es difícil hacer scraping de los sitios web. Una simple llamada con `curl` o `requests` suele devolver una respuesta vacía o un HTML roto, porque el contenido se carga con JavaScript. Web Unlocker se encarga de:

- **Renderizado de JavaScript**: las páginas se cargan en un navegador real y se ejecutan por completo antes de capturar el contenido
- **Rotación inteligente de IP**: las solicitudes se enrutan a través de IP residenciales con huellas digitales de navegador realistas
- **Selección por nivel de precio**: enruta las solicitudes por el nivel de proxy adecuado para el sitio de destino

---

## Qué obtienes como respuesta

Una solicitud exitosa devuelve la página en un único formato. Lo eliges con el parámetro de consulta `format`:

| `format` | Qué obtienes |
| --- | --- |
| `html` (predeterminado) | El DOM completo y renderizado de la página |
| `markdown` | El contenido de la página en Markdown |
| `json` | Un objeto JSON con la URL de la página, los metadatos de la solicitud y el HTML |

## Web Unlocker frente a proxies propios

Mantener tu propia infraestructura de proxies es caro y frágil. Web Unlocker lo gestiona todo como un servicio administrado:

|  | Web Unlocker | Proxies propios |
| --- | --- | --- |
| Configuración | Una llamada a la API | Semanas de trabajo de infraestructura |
| Huellas digitales del navegador | Integradas | Hay que desarrollarlas o comprarlas por separado |
| Rotación de IP | Automática | Gestión manual del pool |
| Mantenimiento | Ninguno | Continuo |
| Facturación | Por solicitud exitosa | Coste fijo, tenga éxito o no |

## Casos de uso habituales

- **Monitoreo de precios**: sigue los precios en sitios de comercio electrónico
- **Estudios de mercado**: recopila datos de productos, reseñas u ofertas de empleo a gran escala
- **Agregación de contenido**: crea feeds de noticias o de datos a partir de sitios sin API
- **Pipelines de IA**: envía HTML renderizado a LLM para extraer o resumir información

---

## Cómo funciona

Web Unlocker ejecuta un navegador Chromium real en la nube para cada tarea. Cuando envías una URL:

1. Se inicia un navegador con una IP residencial y una huella digital de navegador realista
2. Se navega a la página, se ejecuta el JavaScript y se carga el contenido dinámico
3. Se devuelve el HTML renderizado, o Markdown o JSON si lo pides con `format`

Nunca gestionas infraestructura. No hay navegadores que iniciar, ni listas de proxies que mantener, ni lógica de renderizado que construir. Web Unlocker reemplaza un framework de automatización de navegadores y un proveedor de proxies con una sola solicitud HTTP.

## Cómo usarlo

Envía una solicitud GET con la URL de destino como parámetro de consulta. La respuesta es el HTML completamente renderizado.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Para obtener Markdown o JSON en su lugar, añade `format=markdown` o `format=json` a la consulta.

Consulta el [Quickstart](/es/web-unlocker-quick-start) para ver ejemplos en Python y JavaScript y los [códigos de error](/es/web-unlocker-quick-start#gesti%C3%B3n-de-errores), o los [Use Cases](/es/web-unlocker-use-cases) para conocer patrones de integración habituales.
