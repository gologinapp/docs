title: "Gologin Agent Browser CLI"
description: "CLI de automatización del navegador para agentes de IA que ejecuta perfiles de Gologin en Cloud Browser o en Orbita local, con snapshots, refs y un daemon persistente"
---

Gologin Agent Browser CLI convierte los perfiles de navegador de Gologin en un entorno de ejecución persistente y programable para agentes de IA. Las sesiones se ejecutan en Gologin Cloud Browser o en Orbita en tu propio equipo. Ofrece snapshots compactos de la página, interacción basada en refs, memoria de sesión y una salida pensada para la terminal.

A diferencia de escribir código de Puppeteer/Playwright desde cero, esta CLI da a los agentes un conjunto de comandos listo para usar en la automatización del navegador, sin código repetitivo ni lógica de gestión de sesiones.

---

## Entorno de ejecución en la nube o local

La CLI tiene dos entornos de ejecución con los mismos comandos. Ambos usan perfiles, fingerprints y proxies de Gologin, y un daemon mantiene las sesiones activas entre llamadas a la CLI.

| | `cloud` (predeterminado) | `local` |
|---|---|---|
| Dónde se ejecuta el navegador | Gologin Cloud Browser | Orbita en tu equipo |
| ID del perfil | Opcional: si no lo indicas, se crea un perfil temporal en la nube | Obligatorio |
| Ideal para | Sesiones en paralelo, sesiones remotas, equipos que no deberían ejecutar un navegador | Calentamiento de perfiles, primeros inicios de sesión, cookies y estado del perfil locales, coincidir con tu sistema operativo |

Elige el entorno de ejecución en cada comando con `--runtime cloud|local|auto`, o define `GOLOGIN_AGENT_BROWSER_RUNTIME` una sola vez:

```bash
gologin-agent-browser open https://example.com
gologin-agent-browser open https://example.com --runtime local --profile your_profile_id
```

De forma predeterminada (`auto`), los comandos de perfiles, runbooks y trabajos se ejecutan en local, y todo lo demás se ejecuta en la nube. Una vez que abras una sesión local, indica también `--runtime local` en los comandos siguientes. Consulta [Local runtime](/es/cli-tools/local-agent-browser) para ver los requisitos y los comandos exclusivos del entorno local.

## Instalación

```bash
npm install -g gologin-agent-browser-cli
```

O ejecútala sin instalación global:

```bash
npx gologin-agent-browser-cli --help
```

Requiere Node.js >= 18. El entorno de ejecución local necesita Node.js 20 o posterior.

## Credenciales

| Variable | Obligatoria | Descripción |
|---|---|---|
| `GOLOGIN_TOKEN` | Sí (para `open` y los comandos de la API) | Token de la API de Gologin |
| `GOLOGIN_PROFILE_ID` | Opcional | ID de perfil predeterminado |
| `GOLOGIN_AGENT_BROWSER_RUNTIME` | Opcional | Entorno de ejecución predeterminado: `cloud`, `local` o `auto` |
| `GOLOGIN_DAEMON_PORT` | Opcional | Puerto del daemon (predeterminado: `44777` para cloud, `44778` para local) |
| `GOLOGIN_CONNECT_BASE` | Opcional | Endpoint de Cloud Browser (predeterminado: `https://cloudbrowser.gologin.com/connect`) |
| `GOLOGIN_EXECUTABLE_PATH` | Opcional | Ruta al ejecutable de Orbita para el entorno de ejecución local |

### Obtener un token

1. Regístrate o inicia sesión en [gologin.com](https://gologin.com)
2. Abre **API & MCP** en el panel
3. Abre la pestaña **API**
4. Haz clic en **New Token**
5. Copia el token de acceso generado

```bash
export GOLOGIN_TOKEN='your_gologin_token'
```

### Archivo de configuración

`~/.gologin-agent-browser/config.json`

## Arquitectura

Consta de dos partes:

1. **La CLI `gologin-agent-browser`**: interpreta los comandos, elige el entorno de ejecución, inicia automáticamente el daemon correspondiente e imprime una salida compacta
2. **Daemons locales persistentes**, uno por cada entorno de ejecución: gestionan las sesiones de navegador activas, se conectan a Gologin Cloud Browser o a Orbita local mediante `connectOverCDP` de Playwright, mantienen la página activa en memoria, generan snapshots, resuelven refs y registran los metadatos de la sesión

El transporte es solo local. El daemon de cloud escucha en:
- Un socket Unix en `${TMPDIR:-/tmp}/gologin-agent-browser.sock`
- HTTP local en `127.0.0.1:${GOLOGIN_DAEMON_PORT:-44777}`

En el entorno de ejecución cloud, si no indicas un ID de perfil, el daemon crea un perfil temporal de Gologin en la nube a través de la API.

## Cómo funcionan los refs

`snapshot` imprime una vista compacta de la página y asigna refs como `@e1`, `@e2`, `@e3` a los elementos interactivos. Puedes actuar directamente sobre ellos:

```bash
gologin-agent-browser snapshot
# output shows page content with refs like @e1, @e2, @e3...

gologin-agent-browser click @e3
gologin-agent-browser type @e5 "search query"
gologin-agent-browser fill @e7 "username"
```

Los refs funcionan con el mejor esfuerzo y conviene regenerarlos tras navegar o después de cambios importantes en el DOM. Los comandos también aceptan selectores CSS en lugar de refs. En páginas dinámicas, `find` suele ser una mejor alternativa que los refs obsoletos: localiza el elemento en la página activa y actúa sobre él en un solo paso.

```bash
gologin-agent-browser find label "Email" fill "user@example.com"
gologin-agent-browser find role button click --name "Submit"
```

## Inicio rápido

```bash
export GOLOGIN_TOKEN='your_token'

# open a page in cloud browser
gologin-agent-browser open https://example.com

# read the page as a compact snapshot
gologin-agent-browser snapshot

# interact with elements
gologin-agent-browser click @e3
gologin-agent-browser type @e5 "hello world"

# take a screenshot
gologin-agent-browser screenshot ./page.png

# close the session
gologin-agent-browser close
```

## Ejemplo de bucle de un agente

Un bucle típico de un agente de IA:

```
1. open <url>
2. snapshot          → agent reads page content
3. click/type/fill   → agent acts on refs
4. snapshot          → agent reads result
5. repeat 3-4 as needed
6. screenshot        → save artifact
7. close
```

## Referencia completa de comandos

### Diagnóstico

| Comando | Descripción |
|---|---|
| `doctor` | Comprueba el estado y la conectividad del daemon |

### Gestión de sesiones

| Comando | Descripción |
|---|---|
| `open <url>` | Abre una URL en una sesión de navegador |
| `close` | Cierra la sesión actual (`--all` cierra todas las sesiones de este daemon) |
| `sessions` | Lista las sesiones activas (`--prune` elimina las obsoletas) |
| `current` | Muestra la información de la sesión actual |

### Lectura de la página

| Comando | Descripción |
|---|---|
| `snapshot` | Snapshot de texto compacto con refs de elementos |
| `screenshot <path>` | Guarda una captura de pantalla de la página |
| `pdf <path>` | Guarda la página como PDF |
| `get <kind> [target]` | Obtiene propiedades de la página |

### Interacción

| Comando | Descripción |
|---|---|
| `click <ref>` | Hace clic en un elemento |
| `dblclick <ref>` | Hace doble clic |
| `type <ref> <text>` | Escribe texto (añade al contenido existente) |
| `fill <ref> <text>` | Rellena un campo (reemplaza el contenido) |
| `hover <ref>` | Coloca el cursor sobre un elemento |
| `select <ref> <value>` | Selecciona un valor de una lista desplegable |
| `check <ref>` / `uncheck <ref>` | Marca o desmarca una casilla |
| `focus <ref>` | Da el foco a un elemento |
| `find <by> <locator> <action> [value]` | Encuentra un elemento por `role`, `text`, `label`, `placeholder`, `first`, `last` o `nth` y le aplica `click`, `fill`, `type` o `hover`, o lee su `text` |

### Teclado y desplazamiento

|---|---|

| `scroll <direction> [pixels]` | Desplaza la página |

### Pestañas

### Perfiles, proxies y la API de Gologin

Estos comandos llaman a la API de Gologin con tu token y no necesitan el daemon del navegador.

| Comando | Descripción |
|---|---|
| `api <METHOD> <path>` | Llama a cualquier endpoint de la API REST de Gologin |
| `browser <action>` | Perfiles: listar, obtener, crear, actualizar, eliminar, cookies, proxy, inicio y detención en la nube, importación y exportación |
| `proxy <action>` | Proxies: listar, añadir un proxy de Gologin, actualizar, eliminar, tráfico |
| `workspace`, `folder`, `share`, `template` | Workspaces y miembros, carpetas, uso compartido, plantillas de perfil |
| `user`, `deleted-profile` | Información de la cuenta y tokens de desarrollo, restauración de perfiles eliminados |
| `cloud-usage` | Uso de Cloud Browser de un perfil o workspace |
| `profile-cloud`, `profile-cookies`, `profile-fingerprint`, `profile-proxy`, `profile-ua` | Atajos: iniciar o detener un perfil en la nube, exportar o importar sus cookies, actualizar su fingerprint, añadir un proxy, actualizar su user agent |

```bash
gologin-agent-browser browser list --page 1
gologin-agent-browser proxy add-gologin your_profile_id --country us --type residential
gologin-agent-browser cloud-usage --profile your_profile_id
gologin-agent-browser api GET /browser/your_profile_id
```

Añade `--help` a cualquier comando para ver cómo se usa.

## Casos de uso y ejemplos

### Comprueba si tu sitio supera las pruebas anti-detección

```bash
gologin-agent-browser open https://iphey.com/ --profile your_profile_id
gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # read the trust score
gologin-agent-browser screenshot ./iphey-result.png
gologin-agent-browser close
```

### Inicia sesión en una aplicación web y extrae datos del panel

```bash
gologin-agent-browser open https://app.example.com/login
gologin-agent-browser snapshot

# agent reads snapshot, finds login form
gologin-agent-browser fill @e4 "user@company.com"
gologin-agent-browser fill @e6 "password"
gologin-agent-browser click @e8

gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # agent reads dashboard content

# navigate to the report page
gologin-agent-browser click @e12   # "Reports" link
gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # agent extracts report data
gologin-agent-browser screenshot ./report.png
gologin-agent-browser close
```

### Rellena un formulario de varios pasos

```bash
gologin-agent-browser open https://forms.example.com/apply

# step 1: personal info
gologin-agent-browser snapshot
gologin-agent-browser fill @e3 "John Doe"
gologin-agent-browser fill @e5 "john@example.com"
gologin-agent-browser select @e7 "United States"
gologin-agent-browser click @e9   # Next

# step 2: upload and submit
gologin-agent-browser wait 1000
gologin-agent-browser snapshot
gologin-agent-browser upload @e4 ./resume.pdf
gologin-agent-browser check @e6   # agree to terms
gologin-agent-browser click @e8   # Submit

gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # confirm success
gologin-agent-browser close
```

### Captura pantallas de las páginas de la competencia

```bash
# use different profiles with different geos
for profile in us_profile de_profile jp_profile; do
  gologin-agent-browser open https://competitor.com --profile $profile
  gologin-agent-browser wait 3000
  gologin-agent-browser screenshot ./${profile}-homepage.png
  gologin-agent-browser close
done
```

### Busca en un sitio que bloquea el scraping

Algunos sitios exigen ejecutar JavaScript, iniciar sesión o interactuar antes de mostrar resultados. Usa el navegador para buscar:

```bash
gologin-agent-browser open https://protected-directory.com
gologin-agent-browser snapshot
gologin-agent-browser find placeholder "Search" fill "machine learning engineer San Francisco"
gologin-agent-browser press Enter
gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # agent reads search results
gologin-agent-browser screenshot ./search-results.png
gologin-agent-browser close
```

### Guarda y restaura el estado de la sesión

Exporta las cookies y el almacenamiento para reutilizarlos entre sesiones:

```bash
# after logging in
gologin-agent-browser cookies --output ./session-cookies.json
gologin-agent-browser storage-export ./session-storage.json
gologin-agent-browser close

# later, restore the session
gologin-agent-browser open https://app.example.com
gologin-agent-browser cookies-import ./session-cookies.json
gologin-agent-browser storage-import ./session-storage.json
gologin-agent-browser reload
gologin-agent-browser snapshot     # already logged in
```

## Sesiones en paralelo

Usa IDs de `--session` explícitos para tareas independientes en la nube. Limpia con `close --all` o `sessions --prune --older-than-ms`.

## Reglas de proxy

- Perfiles preconfigurados: el proxy se define en el perfil desde el panel de Gologin o la API, por ejemplo `proxy add-gologin <profileId> --country us`
- Perfiles temporales en la nube: sin proxy, o con tu propio proxy mediante `--proxy-host` y `--proxy-port` (además de `--proxy-mode http|socks4|socks5`, `--proxy-user`, `--proxy-pass`)
- En el entorno de ejecución cloud, `open` no acepta `--proxy-country`. Para usar tráfico de proxy de Gologin de un país, añade un proxy de Gologin a un perfil y ábrelo con `--profile`
- En el entorno de ejecución local, `open`, `profile-create` y `profile-update` aceptan `--proxy-country`
