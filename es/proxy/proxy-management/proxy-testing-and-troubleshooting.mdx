Esta guía te ayuda a comprobar que tu proxy funciona correctamente y a solucionar los problemas de conexión más comunes.

### Cómo probar un proxy

1. Asigna el proxy a tu perfil de navegador
2. Haz clic en el **refresh icon** junto a la ubicación del proxy
3. Espera a que el sistema compruebe la conexión

Si el proxy funciona correctamente, el sistema mostrará:

- la dirección IP del proxy
- el país o la ubicación
- el estado de la conexión

Si el proxy funciona correctamente, el indicador de estado aparecerá en **verde**.
