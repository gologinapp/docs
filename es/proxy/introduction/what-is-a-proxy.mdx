---
title: "Qué es un proxy"
---

Un proxy es un servidor que actúa como intermediario entre tu dispositivo e internet.\
En lugar de conectarte directamente a un sitio web, tu tráfico pasa por el servidor proxy.

Esto significa que los sitios web ven la **dirección IP del proxy** en lugar de tu dirección IP real, como si la solicitud proviniera de otra ubicación.

Cuando se usa junto con **Gologin**, un proxy funciona en conjunto con la huella digital del navegador de un perfil.\
Cada perfil puede conectarse a través de un proxy distinto, lo que ayuda a que los sitios web los reconozcan como dispositivos independientes.

## Por qué es importante usar un proxy

Usar un proxy es **fundamental** al trabajar con Gologin.

Los sitios web rastrean la actividad de los usuarios analizando tanto las **huellas digitales del navegador como la dirección IP**.\
Aunque utilices distintos perfiles de navegador, varias cuentas seguirán vinculadas si comparten la misma dirección IP.

Con un proxy, cada perfil puede operar desde una ubicación de red diferente, lo que reduce la probabilidad de que las cuentas se asocien con el mismo dispositivo.

## Dónde conseguir un proxy

Gologin admite tanto **proveedores de proxy de terceros** como **proxies integrados de Gologin**.

Puedes conectar proxies de proveedores externos introduciendo las credenciales del proxy en la configuración del perfil.

Gologin también ofrece opciones de proxy integradas que se pueden configurar directamente dentro de la aplicación.

Para consultar una lista de proveedores de proxy recomendados, consulta [**Proveedores de proxy recomendados**](https://gologin.com/proxies/proxy-type/).
