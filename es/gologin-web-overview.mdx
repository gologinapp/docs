Gologin no solo está disponible como aplicación de escritorio, sino también como aplicación web en [app.gologin.com](http://app.gologin.com). Puedes iniciar sesión allí con tu cuenta de Gologin y gestionar tus perfiles desde cualquier navegador y en cualquier dispositivo, sin necesidad de instalar nada.

### Cloud browsers

Para entender cómo funciona la aplicación web, conviene conocer los cloud browsers.

Cuando ejecutas un perfil en la aplicación de escritorio, este se abre en tu dispositivo y utiliza sus recursos (RAM, CPU, etc.). El número de perfiles que puedes ejecutar al mismo tiempo depende de tu hardware.

Los cloud browsers funcionan de otra manera. En lugar de ejecutarse en tu dispositivo, el perfil se ejecuta en los servidores de Gologin. Tú lo ves e interactúas con él a través de tu navegador habitual. Esto significa que no se usan los recursos de tu dispositivo, puedes ejecutar perfiles desde cualquier lugar y el número de perfiles que puedes ejecutar no está limitado por tu hardware.

Cada perfil de cloud browser tiene su propia huella digital del navegador y su propia dirección IP, igual que los perfiles de la aplicación de escritorio.

### Qué puedes hacer en la aplicación web

La aplicación web en [app.gologin.com](http://app.gologin.com) ofrece las mismas funciones principales que la aplicación de escritorio. Puedes crear y gestionar perfiles, ejecutar perfiles de cloud browser y acceder a los ajustes de tu cuenta, todo desde una pestaña normal del navegador.

Esto resulta útil cuando no tienes contigo tu ordenador habitual o cuando quieres acceder a tus perfiles desde un dispositivo en el que la aplicación de escritorio no está instalada.
