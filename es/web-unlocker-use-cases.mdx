Web Unlocker es una Scraping API: usted envía una URL y recibe el HTML completamente renderizado. Esta página muestra las formas más comunes de aprovecharla.

---

## Extraer una página por su cuenta

El caso de uso más sencillo: necesita el contenido de una página web que bloquea las solicitudes HTTP normales.

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com/product/123"},
    headers={"apikey": "YOUR_API_KEY"}
)

html = response.text
print(html)
```

### JavaScript

```javascript
const html = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com/product/123"),
  { headers: { apikey: "YOUR_API_KEY" } }
).then((r) => r.text());

console.log(html);
```

Sin navegador que iniciar, sin proxy que configurar, sin pelear con Cloudflare. Una sola llamada y obtiene la página.

**Ideal para:**

- Consultar precios en el sitio de un competidor
- Obtener ofertas de empleo, reseñas o datos de productos
- Supervisar cambios en páginas
- Scripts de recopilación de datos puntuales

## Enviar contenido a una IA

Web Unlocker devuelve HTML sin procesar. Páselo a un LLM para extraer datos estructurados, resumir contenido o responder preguntas sobre la página, sin necesidad de lógica de análisis.

### Python \+ OpenAI

```python
import requests
from openai import OpenAI

html = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://news.ycombinator.com"},
    headers={"apikey": "YOUR_API_KEY"}
).text

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {
            "role": "user",
            "content": f"Extract the top 5 story titles and their URLs from this HTML:\n\n{html[:8000]}"
        }
    ]
)

print(response.choices[0].message.content)
```

### JavaScript \+ Anthropic

```javascript
import Anthropic from "@anthropic-ai/sdk";

const html = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://news.ycombinator.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
).then((r) => r.text());

const client = new Anthropic();
const message = await client.messages.create({
  model: "claude-opus-4-5",
  max_tokens: 1024,
  messages: [
    {
      role: "user",
      content: `Extract the top 5 story titles and their URLs from this HTML:\n\n${html.slice(0, 8000)}`,
    },
  ],
});

console.log(message.content[0].text);
```

**Ideal para:**

- Extraer datos estructurados (precios, nombres, fechas) sin escribir analizadores
- Resumir artículos o páginas de productos
- Comparar varias páginas y sacar conclusiones
- Crear herramientas de investigación o supervisión con IA

## Úselo dentro de un agente de IA

Dé a su agente de IA una herramienta `scrape` respaldada por Web Unlocker. El agente podrá entonces navegar por la web por su cuenta: obtener páginas, leer su contenido y actuar en consecuencia, sin que usted escriba ninguna lógica de navegación.

```python
import requests
import anthropic

def scrape(url: str) -> str:
    """Fetch a URL and return its rendered HTML."""
    return requests.get(
        "https://parsing.webunlocker.gologin.com/v1/scrape",
        params={"url": url},
        headers={"apikey": "YOUR_API_KEY"}
    ).text

tools = [
    {
        "name": "scrape",
        "description": "Fetch the rendered HTML of any URL, including JavaScript-heavy and protected sites.",
        "input_schema": {
            "type": "object",
            "properties": {
                "url": {"type": "string", "description": "The URL to scrape"}
            },
            "required": ["url"]
        }
    }
]

client = anthropic.Anthropic()
messages = [
    {"role": "user", "content": "What is the current price of the iPhone 16 Pro on apple.com?"}
]

while True:
    response = client.messages.create(
        model="claude-opus-4-5",
        max_tokens=1024,
        tools=tools,
        messages=messages
    )

    if response.stop_reason == "end_turn":
        print(response.content[0].text)
        break

    tool_results = []
    for block in response.content:
        if block.type == "tool_use" and block.name == "scrape":
            html = scrape(block.input["url"])
            tool_results.append({
                "type": "tool_result",
                "tool_use_id": block.id,
                "content": html[:10000]
            })

    messages.append({"role": "assistant", "content": response.content})
    messages.append({"role": "user", "content": tool_results})
```

El agente decide cuándo extraer datos y qué URL consultar. Web Unlocker se encarga de la obtención del contenido.

**Ideal para:**

- Agentes de investigación que navegan por la web de forma autónoma
- Bots de comparación de precios o de búsqueda de ofertas
- Flujos de inteligencia competitiva
- Cualquier agente que necesite datos web en tiempo real

## Extraer muchas páginas a la vez

Ejecute solicitudes de forma simultánea para recopilar datos de varias URL en paralelo.

```python
import requests
from concurrent.futures import ThreadPoolExecutor

API_URL = "https://parsing.webunlocker.gologin.com/v1/scrape"
API_KEY = "YOUR_API_KEY"

urls = [
    "https://example.com/page/1",
    "https://example.com/page/2",
    "https://example.com/page/3",
]

def scrape(url):
    response = requests.get(
        API_URL,
        params={"url": url},
        headers={"apikey": API_KEY}
    )
    return url, response.text

with ThreadPoolExecutor(max_workers=5) as executor:
    results = list(executor.map(scrape, urls))

for url, html in results:
    print(f"{url}: {len(html)} chars")
```

**Ideal para:**

- Extraer catálogos de productos completos o páginas de listados
- Recopilación masiva de datos para conjuntos de entrenamiento
- Supervisar muchas páginas al mismo tiempo

## Úselo desde la CLI

Olvídese de escribir código: use la CLI de Gologin Web Access para los flujos de extracción más habituales:

```bash
npm install -g gologin-web-access
export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."

# batch scrape multiple pages
gologin-web-access batch-scrape \
  https://example.com/page/1 \
  https://example.com/page/2 \
  https://example.com/page/3 \
  --format text --only-main-content --summary

# crawl a site
gologin-web-access crawl https://docs.example.com --format markdown --limit 50 --max-depth 2

# monitor page changes
gologin-web-access change-track https://example.com/pricing --format markdown

# extract structured data with a schema
gologin-web-access extract https://example.com/product/123 --schema ./product-schema.json

# search the web
gologin-web-access search "best antidetect browser 2026" --limit 10
```

Consulte [Web Access CLI](/es/cli-tools/web-access) para ver la referencia completa de comandos.
