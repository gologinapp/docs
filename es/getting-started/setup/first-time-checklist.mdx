---
title: "Lista de verificación para empezar"
---

Antes de crear tus primeros perfiles de navegador en Gologin, te recomendamos preparar tu entorno. Esto ayuda a evitar problemas con las cuentas y garantiza que los perfiles funcionen correctamente.

Usa esta lista de verificación para comenzar.

### 1. Instala Gologin

Descarga e instala la aplicación de Gologin para tu sistema operativo.

### 2. Inicia sesión en tu cuenta de Gologin

Inicia sesión con la cuenta que creaste durante el registro.

### 3. Prepara tus proxies

Asegúrate de tener proxies listos para usar.<br />Usar un proxy distinto para cada perfil ayuda a evitar que las cuentas se vinculen entre sí.

### 4. Crea tu primer perfil de navegador

Crea un perfil para simular un entorno de navegador independiente, con su propia huella digital (fingerprint) y su propio almacenamiento.

### 5. Asigna un proxy al perfil

Añade un proxy para que el perfil se conecte desde una dirección IP única.

### 6. Inicia el perfil

Haz clic en **Run** para iniciar el perfil y empezar a trabajar con tus cuentas.
