### Instalación

```bash
npm i gologin
```

Requiere Node.js 20 o posterior. La versión 3 del SDK es solo ESM: cárgala con `import`; `require('gologin')` no funciona.

### Uso básico

```javascript
import GoLogin from 'gologin';

const GL = new GoLogin({
  token: 'your-api-token',
  profile_id: 'your-profile-id',
});

const { status, wsUrl } = await GL.start();
// Connect Puppeteer or Playwright using wsUrl
// ... your automation code ...
await GL.stop();
```

### Lanzar con GologinApi

`GologinApi` inicia un perfil y conecta Puppeteer por ti. `launch()` devuelve un `browser` de Puppeteer. Pasa `cloud: true` para ejecutar el perfil en [Gologin Cloud Browser](/es/api-reference/cloud-browser/what-is-gologin-cloud-browser) en lugar de un navegador Orbita local:

```javascript
import { GologinApi } from 'gologin';

const gologin = GologinApi({ token: 'your-api-token' });

// local Orbita on this machine
const { browser } = await gologin.launch({ profileId: 'your-profile-id' });

// or Gologin Cloud Browser
// const { browser } = await gologin.launch({ cloud: true, profileId: 'your-profile-id' });

const page = await browser.newPage();
await page.goto('https://example.com');

// close the browser and stop the profile
await gologin.exit();
```

Si no indicas `profileId`, `launch()` crea primero un perfil nuevo. `GologinApi` también incluye funciones auxiliares como `createProfileRandomFingerprint()`, `addGologinProxyToProfile()`, `addCookiesToProfile()` y `deleteProfile()`. Consulta el [Quickstart](/es/api-reference/introduction/quickstart) para ver un ejemplo completo.

### Parámetros principales

| Parámetro | Valor por defecto | Descripción |
|---|---|---|
| `token` | obligatorio | Tu token de API de Gologin |
| `profile_id` | obligatorio | ID del perfil que se va a lanzar |
| `executablePath` | auto | Ruta al binario del navegador Orbita |
| `uploadCookiesToServer` | `false` | Sube las cookies a la nube al detener el perfil. Configúralo en `true` si necesitas que la sesión persista entre dispositivos. |
| `extra_params` | `[]` | Flags adicionales de Chromium que se pasan al navegador |

### Detener perfiles

```javascript
// Stop and sync to cloud
await GL.stop();

// Stop without syncing profile data to cloud
await GL.stopLocal({ posting: false });
```

Primero cierra el navegador en tu herramienta de automatización, por ejemplo con `browser.close()`. `stop()` no acepta opciones y siempre sube el perfil a Gologin. `stopLocal({ posting: false })` finaliza la sesión sin subir los datos del perfil. Úsalo en servidores donde no quieras la sincronización con la nube. Las cookies se siguen subiendo si configuras `uploadCookiesToServer: true`.

### Gestión de versiones del navegador Orbita

Cuando se inicia un perfil, el SDK comprueba qué versión de Orbita necesita el user agent del perfil. Si esa versión aún no está en `~/.gologin/browser`, el SDK la descarga; de lo contrario, reutiliza la copia instalada. Para ejecutar una compilación concreta, pasa `executablePath`. Las opciones `autoUpdateBrowser` (por defecto `false`) y `checkBrowserUpdate` se siguen aceptando, pero en el SDK actual (3.0.7) no cambian este comportamiento.

Para descargar Orbita con antelación, llama a `checkAndDownloadBrowserByOpts()` en una instancia de `GoLogin`. Es un método, no una exportación independiente:

```javascript
import { GoLogin } from 'gologin';

const GL = new GoLogin({ token: 'your-api-token' });

// Pre-download the latest Orbita version
await GL.checkAndDownloadBrowserByOpts({ lastActualCount: 1 });

// Pre-download specific versions
await GL.checkAndDownloadBrowserByOpts({ majorVersions: [142, 143] });
```

Sin opciones, descarga las 5 últimas versiones. Úsalo antes de lanzar perfiles en paralelo para evitar varias descargas simultáneas.

### Ejecutar más de 100 perfiles en paralelo

Cuando ejecutes muchos perfiles a la vez en un servidor:

```javascript
// Use a queue to limit concurrent launches
const CONCURRENCY = 10;
const queue = [...profileIds];
const active = new Set();

async function launchProfile(profileId) {
  const gl = new GoLogin({ token, profile_id: profileId });
  try {
    const { wsUrl } = await gl.start();
    // ... your automation ...
  } finally {
    await gl.stop();
  }
}

async function processQueue() {
  while (queue.length > 0) {
    while (active.size >= CONCURRENCY) {
      await new Promise(r => setTimeout(r, 1000));
    }
    const id = queue.shift();
    active.add(id);
    launchProfile(id).finally(() => active.delete(id));
  }
}
```

**Importante para servidores:**
- Limita los lanzamientos simultáneos de perfiles (se recomienda empezar con 10-20)
- Descarga las versiones de Orbita antes de lanzar los perfiles
- En Linux: instala Xvfb y configura `DISPLAY=:99`
- Aumenta los límites de descriptores de archivo: `ulimit -n 65536`
- Supervisa la RAM: cada perfil usa ~300-500 MB
