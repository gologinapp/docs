---

Las AI Skills de Gologin son extensiones plug-and-play para [Claude Code](https://claude.ai/code) que dotan a los agentes de IA de capacidades de web scraping y automatización del navegador. Cada skill envuelve una herramienta de la CLI de Gologin y la expone como un conjunto de funciones que el agente puede invocar.

```
agent → skill → Gologin CLI → Web Unlocker API / Cloud Browser / Local Orbita
```

## Instalación

```bash
# install any skill
npx skills add GologinLabs/gologin-web-access-skill
npx skills add GologinLabs/gologin-agent-browser-skill
npx skills add GologinLabs/gologin-scraping-skill
npx skills add GologinLabs/gologin-local-agent-browser-skill
```

Cada skill requiere que su CLI correspondiente esté instalada:

| Skill | CLI requerida |
|---|---|
| Web Access Skill | `npm i -g gologin-web-access` |
| Agent Browser Skill | `npm i -g gologin-agent-browser-cli` |
| Scraping Skill | `npm i gologin-webunlocker` |
| Local Agent Browser Skill | `npm i -g gologin-local-agent-browser-cli` |

## Web Access Skill

**Instalación:** `npx skills add GologinLabs/gologin-web-access-skill`

La skill predeterminada y más versátil. Delega en la CLI `gologin-web-access`.

**Herramientas de scraping:** `scrape_url`, `read_page`, `scrape_markdown`, `scrape_text`, `scrape_json`, `batch_scrape`, `batch_extract`, `search_web`, `map_site`, `crawl_site`, `crawl_site_async`, `extract_structured`, `track_changes`, `batch_track_changes`, `parse_document`

**Herramientas de navegador:** `browser_open`, `browser_search`, `browser_snapshot`, `browser_click`, `browser_type`, `browser_screenshot`, `browser_close`, `browser_sessions`, `browser_current`

**Flujos de trabajo integrados:** browser-ref-loop, hybrid-read-then-interact, search-discover-and-scrape, lead-enrichment, competitive-monitoring, docs-ingestion, geo-testing, login-and-navigate-dashboard

Consulta la [referencia de la CLI de Web Access](/es/cli-tools/web-access) para ver los detalles completos de los comandos.

## Agent Browser Skill

**Instalación:** `npx skills add GologinLabs/gologin-agent-browser-skill`

Skill solo para navegador, pensada para sesiones en la nube en vivo. Úsala cuando necesites navegación interactiva sin scraping.

**Capacidades:** `doctor`, `open`, `sessions`, `current`, `snapshot`, `click`, `type`, `fill`, `find`, `get`, `tabs`, `tabopen`, `tabfocus`, `tabclose`, `cookies`, `cookies-import`, `storage-export`, `storage-import`, `eval`, `back`, `forward`, `reload`, `upload`, `screenshot`, `pdf`

Consulta la [referencia de la CLI de Agent Browser](/es/cli-tools/agent-browser) para ver los detalles completos de los comandos.

---

## Scraping Skill

**Instalación:** `npx skills add GologinLabs/gologin-scraping-skill`

La skill más pequeña: solo hace scraping mediante el SDK de Web Unlocker. Sin sesión de navegador y sin daemon.

**Capacidades:** HTML sin procesar (`scrape`), texto (`text`), markdown (`markdown`), metadatos estructurados (`json`). Métodos del SDK: `scrapeRaw()`, `scrape()`, `scrapeText()`, `scrapeMarkdown()`, `scrapeJSON()`, `batchScrape()`.

Úsala cuando la tarea sea solo de scraping y quieras reducir el número de dependencias.

Consulta la [referencia del SDK de Web Unlocker](/es/scraping-api-sdk-and-cli) para ver los detalles de la API.

## Local Agent Browser Skill

**Instalación:** `npx skills add GologinLabs/gologin-local-agent-browser-skill`

Para la automatización local persistente con Orbita: calentamiento, flujos de inicio de sesión y acciones en redes sociales y marketplaces.

**Capacidades:** todos los comandos de interacción con el navegador, además de gestión de perfiles (`profiles`, `profile-create`, `profile-import`, `profile-update`, `profile-sync`, `profile-delete`), runbooks (`run`, `batch`), trabajos (`jobs`, `job`) y diagnóstico (`doctor --use-case --check-proxy`).

**Plantillas por caso de uso:** `linkedin`, `ads`, `smm`, `scraping`, `geo`

Consulta la [referencia de la CLI de Local Agent Browser](/es/cli-tools/local-agent-browser) para ver los detalles completos de los comandos.

## Qué puedes pedirle a tu agente

Una vez instalada una skill, te comunicas con Claude Code en lenguaje natural. Esto es lo que permite cada skill:

### Con Web Access Skill

- "Lee la página de precios de competitor.com y resume los planes"
- "Haz scraping de estas 15 URL y extrae el nombre y el precio del producto de cada una"
- "Rastrea la documentación en docs.example.com y dame un resumen de cada sección"
- "Busca 'best CRM tools 2026' y haz scraping de los 5 primeros resultados"
- "Comprueba si competitor.com/pricing ha cambiado desde ayer"
- "Extrae los títulos y las URL de todos los artículos del blog de este sitio"
- "Abre example.com en un navegador, inicia sesión con estas credenciales y haz una captura de pantalla del panel"

### Con Agent Browser Skill

- "Abre el panel de administración, ve a Settings y haz una captura de pantalla de la configuración actual"
- "Inicia sesión en el entorno de staging y comprueba si la nueva función está desplegada"
- "Rellena el formulario de registro en example.com con estos datos de prueba"
- "Ve a la página de informes, descarga la exportación mensual y haz una captura de pantalla del resumen"
- "Comprueba qué muestra iphey.com para este perfil de navegador"

### Con Scraping Skill

- "Haz scraping de esta URL y dame el contenido en texto"
- "Obtén el título, la descripción y los encabezados de estas 10 páginas"
- "Descarga esta página en markdown para poder analizarla"

### Con Local Agent Browser Skill

- "Crea un nuevo perfil de LinkedIn con un proxy de EE. UU. y caliéntalo"
- "Abre mi cuenta de Reddit, recorre el feed y ciérrala"
- "Ejecuta el runbook de calentamiento en los 20 perfiles con concurrencia 5"
- "Comprueba el estado del proxy en mis perfiles de anuncios de Facebook"
- "Inicia sesión en esta cuenta de marketplace y haz una captura de pantalla del panel de vendedor"

## Ejemplos de flujos de trabajo

### Investigación de la competencia (Web Access Skill)

1. El agente busca competidores: `search_web("saas project management tools")`
2. El agente mapea el sitio de un competidor: `map_site("https://competitor.com")`
3. El agente hace scraping por lotes de las páginas clave: `batch_scrape(pricing, features, about)`
4. El agente envía el contenido a Claude para su análisis y comparación

### Calentamiento de cuentas (Local Agent Browser Skill)

1. El agente crea perfiles: `profile-create "Account 1" --template linkedin`
2. El agente ejecuta el runbook de calentamiento: `batch ./warmup.json --targets ./profiles.json`
3. El agente revisa los resultados de los trabajos: `jobs --kind batch --status completed`
4. El agente informa qué perfiles están listos

### Monitoreo de un panel (Agent Browser Skill)

1. El agente abre el panel: `open https://dashboard.example.com --profile saved_login`
2. El agente lee la página: `snapshot`
3. El agente navega a las métricas: `click @e5` (enlace de Reports)
4. El agente hace una captura de pantalla del informe: `screenshot ./daily-metrics.png`
5. El agente cierra: `close`
6. El agente resume las métricas a partir de los datos del snapshot

## Preflight obligatorio

Antes de ejecutar cualquier tarea, las skills clasifican el trabajo:

1. **¿Un solo sitio conocido o investigación amplia con varias fuentes?** — determina si se necesita scraping o búsqueda
2. **¿Extracción de solo lectura, monitoreo o trabajo interactivo en el navegador?** — determina si se usa scraping o navegador
3. **¿Solo Web Unlocker, o Web Unlocker y Cloud Browser?** — determina qué credenciales se necesitan
4. **¿Es sensible a la geolocalización o está lo bastante bloqueado como para usar Gologin de principio a fin?** — determina los requisitos de proxy y perfil
