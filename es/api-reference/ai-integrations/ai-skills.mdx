Las AI Skills de Gologin son extensiones listas para usar para [Claude Code](https://claude.ai/code) que dotan a los agentes de IA de capacidades de web scraping y automatización del navegador. Cada skill envuelve una herramienta de la CLI de Gologin y la expone como un conjunto de funciones que el agente puede invocar.

```
agent → skill → Gologin CLI → Web Unlocker API / Cloud Browser / Local Orbita
```

## Instalación

Todas las skills de Gologin se instalan desde el repositorio [GologinLabs/agent-skills](https://github.com/GologinLabs/agent-skills):

```bash
# install any skill
npx skills add GologinLabs/agent-skills@gologin-web-access-skill
npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill
npx skills add GologinLabs/agent-skills@gologin-scraping-skill
```

Cada skill requiere que esté instalada su CLI correspondiente:

| Skill | CLI necesaria |
|---|---|
| Web Access Skill | `npm i -g gologin-web-access` |
| Agent Browser Skill | `npm i -g gologin-agent-browser-cli` (runtimes en la nube y local) |
| Scraping Skill | `npm i gologin-webunlocker` |

## Web Access Skill

**Instalación:** `npx skills add GologinLabs/agent-skills@gologin-web-access-skill`

La skill predeterminada y más versátil. Delega en la CLI `gologin-web-access`.

**Herramientas de scraping:** `scrape_url`, `read_page`, `scrape_markdown`, `scrape_text`, `scrape_json`, `batch_scrape`, `batch_extract`, `search_web`, `map_site`, `crawl_site`, `crawl_site_async`, `extract_structured`, `track_changes`, `batch_track_changes`, `parse_document`

**Herramientas de navegador:** `browser_open`, `browser_search`, `browser_snapshot`, `browser_click`, `browser_type`, `browser_screenshot`, `browser_close`, `browser_sessions`, `browser_current`

**Flujos de trabajo integrados:** browser-ref-loop, hybrid-read-then-interact, search-discover-and-scrape, lead-enrichment, competitive-monitoring, docs-ingestion, geo-testing, login-and-navigate-dashboard

Consulta la [referencia de la CLI de Web Access](/es/cli-tools/web-access) para ver los detalles completos de los comandos.

## Agent Browser Skill

**Instalación:** `npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill`

Skill solo de navegador para sesiones en vivo en Gologin Cloud Browser (predeterminado) o en perfiles locales de Orbita con `--runtime local`. Úsala cuando necesites navegar de forma interactiva sin hacer scraping.

**Capacidades:** `doctor`, `open`, `sessions`, `current`, `snapshot`, `click`, `type`, `fill`, `find`, `get`, `tabs`, `tabopen`, `tabfocus`, `tabclose`, `cookies`, `cookies-import`, `storage-export`, `storage-import`, `eval`, `back`, `forward`, `reload`, `upload`, `screenshot`, `pdf`

**El runtime local añade:** gestión de perfiles (`profiles`, `profile-create`, `profile-import`, `profile-update`, `profile-sync`, `profile-delete`), runbooks (`run`, `batch`), trabajos (`jobs`, `job`), plantillas por caso de uso (`linkedin`, `ads`, `smm`, `scraping`, `geo`) y diagnósticos (`doctor --use-case --check-proxy`).

Consulta la [referencia de la CLI de Agent Browser](/es/cli-tools/agent-browser) y el [runtime local](/es/cli-tools/local-agent-browser) para ver los detalles completos de los comandos.

## Scraping Skill

**Instalación:** `npx skills add GologinLabs/agent-skills@gologin-scraping-skill`

La skill más pequeña: solo scraping a través del SDK de Web Unlocker. Sin sesión de navegador ni daemon.

**Capacidades:** HTML sin procesar (`scrape`), texto (`text`), markdown (`markdown`), metadatos estructurados (`json`). Métodos del SDK: `scrapeRaw()`, `scrape()`, `scrapeText()`, `scrapeMarkdown()`, `scrapeJSON()`, `batchScrape()`.

Úsala cuando la tarea sea solo de scraping y quieras reducir el tamaño de las dependencias.

Consulta la [referencia del SDK de Web Unlocker](/es/scraping-api-sdk-and-cli) para ver los detalles de la API.

## Local Agent Browser Skill (obsoleta)

Si tu agente todavía tiene `gologin-local-agent-browser-skill`, esta solo redirige al agente a la skill Agent Browser. Instala `gologin-agent-browser-skill` en su lugar: cubre los perfiles locales de Orbita, el calentamiento, los flujos de inicio de sesión, los runbooks y los trabajos por lotes.

## Qué puedes pedirle a tu agente

Una vez instalada una skill, hablas con Claude Code en lenguaje natural. Esto es lo que permite cada skill:

### Con Web Access Skill

- "Lee la página de precios de competitor.com y resume los planes"
- "Haz scraping de estas 15 URL y extrae el nombre y el precio del producto de cada una"
- "Rastrea la documentación de docs.example.com y dame un resumen de cada sección"
- "Busca 'mejores herramientas CRM 2026' y haz scraping de los primeros 5 resultados"
- "Comprueba si competitor.com/pricing ha cambiado desde ayer"
- "Extrae todos los títulos y las URL de los artículos del blog de este sitio"
- "Abre example.com en un navegador, inicia sesión con estas credenciales y toma una captura de pantalla del panel"

### Con Agent Browser Skill

- "Abre el panel de administración, ve a Settings y toma una captura de pantalla de la configuración actual"
- "Inicia sesión en el entorno de preproducción y comprueba si la nueva función está desplegada"
- "Rellena el formulario de registro de example.com con estos datos de prueba"
- "Ve a la página de informes, descarga la exportación mensual y toma una captura de pantalla del resumen"
- "Comprueba qué muestra iphey.com para este perfil de navegador"

### Con Scraping Skill

- "Haz scraping de esta URL y dame el contenido de texto"
- "Obtén el título, la descripción y los encabezados de estas 10 páginas"
- "Obtén esta página en formato markdown para que pueda analizarla"

### Con Agent Browser Skill (runtime local)

- "Crea un nuevo perfil de LinkedIn con un proxy de EE. UU. y caliéntalo"
- "Abre mi cuenta de Reddit, desplázate por el feed y ciérrala"
- "Ejecuta el runbook de calentamiento en los 20 perfiles con una concurrencia de 5"
- "Comprueba el estado del proxy en mis perfiles de anuncios de Facebook"
- "Inicia sesión en esta cuenta del marketplace y toma una captura de pantalla del panel del vendedor"

## Ejemplos de flujos de trabajo

### Investigación de la competencia (Web Access Skill)

1. El agente busca competidores: `search_web("saas project management tools")`
2. El agente mapea el sitio de un competidor: `map_site("https://competitor.com")`
3. El agente hace scraping por lotes de las páginas clave: `batch_scrape(pricing, features, about)`
4. El agente pasa el contenido a Claude para su análisis y comparación

### Calentamiento de cuentas (Agent Browser Skill, runtime local)

1. El agente crea perfiles: `profile-create "Account 1" --template linkedin`
2. El agente ejecuta el runbook de calentamiento: `batch ./warmup.json --targets ./profiles.json`
3. El agente comprueba los resultados del trabajo: `jobs --kind batch --status ok`
4. El agente informa de qué perfiles están listos

### Monitorización de paneles (Agent Browser Skill)

1. El agente abre el panel: `open https://dashboard.example.com --profile saved_login`
2. El agente lee la página: `snapshot`
3. El agente navega a las métricas: `click @e5` (enlace de Reports)
4. El agente captura la pantalla del informe: `screenshot ./daily-metrics.png`
5. El agente cierra: `close`
6. El agente resume las métricas a partir de los datos del snapshot

## Preflight obligatorio

Antes de ejecutar cualquier tarea, las skills clasifican el trabajo:

1. **¿Un único sitio conocido o investigación amplia con varias fuentes?** — determina si se necesita scraping o búsqueda
2. **¿Extracción de solo lectura, monitorización o trabajo interactivo en el navegador?** — determina si se usa scraping o navegador
3. **¿Solo Web Unlocker, o Web Unlocker y Cloud Browser?** — determina las credenciales necesarias
4. **¿Es sensible a la geolocalización o está lo bastante bloqueado como para usar Gologin de principio a fin?** — determina los requisitos de proxy y perfil
