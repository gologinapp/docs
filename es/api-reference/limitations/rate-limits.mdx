---
title: 'Límites de solicitudes'
---
La API de Gologin limita cuántas solicitudes puedes enviar por minuto. Si superas el límite, espera antes de enviar más solicitudes.

El límite depende de tu plan:

| Plan | Solicitudes por minuto |
| :-- | --: |
| Professional | 300 |
| Business | 500 |
| Enterprise | 800 |
| Custom | 1,200 |

Los planes de prueba y Forever Free no incluyen acceso a la API. Consulta [Pricing](/es/general/account-and-billing/pricing) para ver qué incluye cada plan.

### Invalidación del token al superar el límite

<Warning>
Cuando superas el límite de solicitudes y recibes una respuesta HTTP 429, tu token de API se invalida automáticamente. Esto significa que el token deja de funcionar de forma permanente y debes generar uno nuevo.

No se trata de un bloqueo temporal: el token se revoca. Planifica con cuidado la frecuencia de tus solicitudes e implementa un retroceso exponencial (exponential backoff) para evitarlo.
</Warning>

### Errores de protección de Cloudflare

Si la IP de tu servidor envía demasiadas solicitudes, el CDN de Cloudflare de Gologin puede bloquear tu IP por completo. Cuando esto ocurre, las respuestas de la API son páginas de error HTML en lugar de JSON, lo que provoca errores como:

```
SyntaxError: Unexpected token 'e', "error code: 1015" is not valid JSON
```

Esta es una respuesta de límite de solicitudes de Cloudflare 1015. Normalmente se resuelve por sí sola en un lapso de minutos a horas. Para evitarlo:
- Implementa un límite de frecuencia de solicitudes en tu código
- Usa retroceso exponencial (exponential backoff) cuando haya fallos
- Evita ráfagas de llamadas paralelas a la API

### Límites de creación de perfiles

Las cuentas nuevas tienen un límite de aproximadamente 300 perfiles creados por día. Este límite puede variar según el plan. Si necesitas límites más altos, contacta con soporte.
