title: "Qué es Gologin Cloud Browser"
keywords: ["cloud browser", "headless browser"]
---

Gologin Cloud Browser te permite ejecutar un navegador Gologin (Orbita) **en la nube** y controlarlo desde tu código de automatización (Puppeteer / Playwright) mediante una única **URL de conexión**.

Es un [navegador headless](./what-is-headless-browser): un navegador controlado completamente por código, sin interfaz gráfica, alojado y gestionado por Gologin, con soporte integrado para perfiles persistentes, configuración de fingerprints y enrutamiento de proxies.

## Qué puedes hacer con Cloud Browser

- Ejecutar varias sesiones de navegador en paralelo en la nube
- Automatizar con tu stack actual (Puppeteer / Playwright)
- Usar **perfiles** de Gologin para conservar el estado persistente (inicios de sesión, cookies, almacenamiento)
- Enrutar el tráfico a través de **proxies** configurándolos en el perfil
- Usarlo con agentes de IA como entorno de navegador remoto

## En qué se diferencia de un navegador headless estándar

Un Chrome headless estándar es detectable. Los sitios web usan el browser fingerprinting para identificar el tráfico automatizado: comprueban el renderizado de canvas, los parámetros de WebGL, las fuentes, la zona horaria, el tamaño de pantalla y decenas de señales más.

Gologin Cloud Browser ejecuta **Orbita**, un Chromium modificado que gestiona las señales del fingerprint para que coincidan con un perfil de navegador coherente y realista. Combinado con las cookies persistentes y la configuración de proxy guardadas en cada perfil, tus sesiones se ven estables y humanas a lo largo de visitas repetidas.

## Por qué elegir Gologin Cloud Browser

### Anti-detect integrado, sin necesidad de plugins

Un Chrome headless estándar se detecta con total facilidad. Otros servicios de navegador en la nube ejecutan Chromium sin modificar y requieren plugins de sigilo de terceros para reducir las señales del fingerprint, con resultados desiguales.

Gologin Cloud Browser ejecuta **Orbita**, una versión reforzada de Chromium que tiene la gestión de fingerprints en su núcleo: canvas, WebGL, fuentes, zona horaria, resolución de pantalla y más. El anti-detect no es un parche añadido encima: es el propio navegador.

### Perfiles persistentes: sesiones que recuerdan

La mayoría de los servicios de navegador en la nube tratan cada sesión como si no tuviera estado. Las cookies y el almacenamiento se descartan al cerrar la sesión.

Los perfiles de Gologin son persistentes. Inicias sesión una vez, cierras la sesión y vuelves a conectarte más tarde: el perfil conserva sus cookies, el almacenamiento local y toda la configuración. Sin volver a autenticarte y sin calentar la sesión.

## Escenarios técnicos habituales

Cloud Browser se usa normalmente en flujos de trabajo en los que necesitas:

- iniciar sesión una vez en una cuenta web y mantener la sesión persistente mediante un perfil
- ejecutar acciones repetidas en los mismos sitios web a través de muchos perfiles
- disponer de sesiones estables y de larga duración sin depender de un equipo local

Algunos ejemplos son la automatización de sesiones con inicio de sesión en aplicaciones web, marketplaces o plataformas sociales, donde importan la persistencia y la coherencia de la configuración del perfil.

## Conceptos clave

- **Perfil**: una identidad de navegador reutilizable (cookies/almacenamiento, además de la configuración de fingerprint y proxy).
- **Sesión en la nube**: una instancia en ejecución de un perfil en la nube de Gologin.
- **Connect URL**: el endpoint que pasas a tu herramienta de automatización para controlar la sesión en la nube.

## Cómo funciona (visión general)

1. (Recomendado) Crea y configura un perfil mediante la API REST de Gologin (proxy, fingerprint, etc.).
2. Conéctate a Cloud Browser con tu **dev token** y, opcionalmente, un `profileId`.
3. Automatiza la sesión con Puppeteer o Playwright.
4. Cierra la conexión cuando termines.

## URL de conexión

Usa esta URL como endpoint del navegador remoto:

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${profileId}
```

- `token`: tu **dev token** de Gologin (créalo en la app de Gologin: [API & MCP](https://app.gologin.com/personalArea/TokenApi) → **API** → **New Token**).
- `profile`: **ID del perfil** (opcional). Si se omite, se creará un perfil nuevo para la sesión.

## Gestión de perfiles (proxy, fingerprint, etc.)

Cloud Browser es la **capa de conexión**.\
Para crear o actualizar perfiles, asignar proxies y configurar los ajustes del perfil, usa la API REST de Gologin:

- API de perfiles: [Create profile](https://gologin.com/docs/api-reference/profile/create-profile-with-partial-parameters), [Update profile](https://gologin.com/docs/api-reference/profile/update-profile-with-partial-parameters)
- API de proxies: [Add a Gologin proxy to a profile](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy), [Set your own proxy on profiles](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles)

## Usar Cloud Browser desde la CLI

Si prefieres los comandos de shell a escribir código de Puppeteer/Playwright, Gologin ofrece herramientas CLI pensadas para agentes:

- **[Gologin Agent Browser CLI](/es/cli-tools/agent-browser)**: CLI de navegador en la nube con daemon, capturas de página e interacción basada en referencias. Creada para agentes de IA.
- **[Gologin Web Access CLI](/es/cli-tools/web-access)**: CLI unificada que combina el scraping de Web Unlocker con la interacción de Cloud Browser en una sola herramienta.

```bash
npm install -g gologin-agent-browser-cli
export GOLOGIN_TOKEN='your_token'

gologin-agent-browser open https://example.com
gologin-agent-browser snapshot
gologin-agent-browser click @e3
gologin-agent-browser screenshot ./page.png
gologin-agent-browser close
```
