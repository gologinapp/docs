Esta guía te ayudará a configurar todo lo necesario para empezar a usar la API de Gologin. Veremos cómo empezar con uno de nuestros clientes de API y cómo hacer tu primera solicitud. También te indicaremos a dónde ir después para encontrar toda la información que necesitas para aprovechar al máximo nuestra potente API REST.

<Note>
  Antes de poder hacer solicitudes a la API de Gologin, necesitarás un token de API.
  En la aplicación de Gologin, abre [API & MCP](https://app.gologin.com/personalArea/TokenApi), ve a la pestaña **API** y haz clic en **New Token**.
</Note>

## Haz tu primera solicitud

Envía tu token en el encabezado `Authorization` de cada solicitud a `https://api.gologin.com`. Esta llamada muestra la lista de perfiles de tu cuenta:

```bash
curl https://api.gologin.com/browser/v2 \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

La respuesta contiene un arreglo `profiles` y `allProfilesCount`, el número total de perfiles. Obtienes hasta 30 perfiles por página: añade `?page=2` a la URL para ver la página siguiente. Consulta [Get all profiles](https://gologin.com/docs/api-reference/profile/get-all-profiles) para ver todos los parámetros.

## Tu primera solicitud de scraping anónimo

<CodeGroup>

```js node.js
import { GologinApi } from 'gologin';

// Token can be passed here in code or from env 
const token = process.env.GL_API_TOKEN || 'your dev token here';
const gologin = GologinApi({
  token,
  // If you want to run particular profile you need to pass profileId param
});

async function main() {
  // This line of code creates new profile that will be run. If you want to run existed profile - delete this line of code
  const profile = await gologin.createProfileRandomFingerprint();
  const profileId = profile.id;

  // This line of code adds gologin proxy to the profile.
  await gologin.addGologinProxyToProfile(profileId, 'US');

  // This line of code starts the browser and return object that can be managed by puppeteer
  const { browser } = await gologin.launch({ profileId });

  // Opens new page in browser
  const page = await browser.newPage();

  // Goes to website and waits untill all parts of the website is loaded
  await page.goto('https://iphey.com/', { waitUntil: 'networkidle2' });

  // Reads profile check result in website
  const status = await page.$eval('.trustworthy:not(.hide)',
    (elt) => elt?.innerText?.trim(),
  );

  await new Promise((resolve) => setTimeout(resolve, 10000));
  console.log('status', status);

  // This line of code deletes used profile. If you dont want to delete used profie - remove this line
  await gologin.deleteProfile(profileId);

  return status;
}

main().catch(console.error)
  .finally(gologin.exit);
```


```python Python
import time
import os
from gologin import GoLogin
from selenium import webdriver
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager


# Initialize GoLogin
gl = GoLogin({
	"token": os.environ.get('GL_API_TOKEN', 'your dev token'),
	})
profile = gl.createProfileRandomFingerprint({ "os": "win" })
profile_id = profile.get('id')
gl.setProfileId(profile_id)
# Add proxy to the profile
gl.addGologinProxyToProfile(profile_id, "us")

# Start Browser and get websocket url
debugger_address = gl.start()

# Get Chromium version for webdriver
chromium_version = gl.get_chromium_version()


# Install webdriver
service = Service(ChromeDriverManager(driver_version=chromium_version).install())

chrome_options = webdriver.ChromeOptions()
chrome_options.add_experimental_option("debuggerAddress", debugger_address)

driver = webdriver.Chrome(service=service, options=chrome_options)

# Give command to Selenium to open the page
driver.get("http://www.python.org")

time.sleep(30)
driver.quit()
time.sleep(10)

gl.delete(profile_id)

gl.stop()
```

## Ejecutar el código tú mismo en Node.js

<CodeGroup>

```bash bash
# Install required packages
npm i gologin

# Run the code - change filename.js to your actual filename and add your token
GL_API_TOKEN=[YOUR_GOLOGIN_API_TOKEN] node filename.js
```

</CodeGroup>

## Ejecutar el código tú mismo en Python

<CodeGroup>

```bash bash
# create local env for the project
python3 -m venv venv

# Install required packages
source venv/bin/activate && pip install gologin selenium webdriver-manager

# Run the script. Your file should not be named gologin.py as it will cause conflict with import
GL_API_TOKEN=[YOUR_GOLOGIN_API_TOKEN] python3 filename.py
```

</CodeGroup>

## ¿Qué sigue?

Muy bien, ya tienes configurado un cliente de API y has hecho tu primera solicitud. Estos son algunos enlaces que pueden resultarte útiles a medida que profundices en la API de Gologin:

- [Crea un token de API en API & MCP](https://app.gologin.com/personalArea/TokenApi)
- [Gologin Web Access CLI](/es/cli-tools/web-access): CLI unificada para scraping y automatización del navegador (sin necesidad de código)
- [Agent Browser CLI](/es/cli-tools/agent-browser): CLI de navegador creada para agentes de IA, en la nube o en tu equipo
- [Agent Browser CLI: entorno de ejecución local](/es/cli-tools/local-agent-browser): perfiles locales de Orbita, runbooks y trabajos por lotes
- [AI Skills](/es/api-reference/ai-integrations/ai-skills): skills listas para usar con Claude Code
- [MCP Server](/es/api-reference/ai-integrations/mcp-server): gestiona perfiles mediante conversaciones con IA
