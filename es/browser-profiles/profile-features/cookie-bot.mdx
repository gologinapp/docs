---
title: "Cookie Bot"
---

Cookie Bot es una herramienta integrada de Gologin que genera cookies de navegación de forma automática para un perfil. Esta herramienta puede ayudarte a automatizar el proceso de calentamiento.

Simula un comportamiento de navegación natural: visita sitios web populares y realiza acciones sencillas, como desplazarse por la página y hacer clic. Esto ayuda a crear un entorno de navegador más realista antes de iniciar sesión en las cuentas.

Usar Cookie Bot puede ayudarte a:

- generar un historial de navegación inicial
- crear cookies naturales para sitios web
- calentar perfiles de navegador nuevos
- preparar los perfiles para iniciar sesión en cuentas o para la automatización

## Cómo funciona Cookie Bot

Cookie Bot visita una lista de sitios web comunes y simula interacciones básicas de un usuario.

Estas acciones pueden incluir:

- cargar páginas
- desplazarse por el contenido
- hacer clic en botones
- cargar imágenes

Esta actividad crea cookies y datos de navegación dentro del perfil, lo que hace que la sesión del navegador parezca más natural.

## Funciones y ajustes de Cookie Bot

Los ajustes que puedes configurar actualmente son:

- **Loading images**\
  ON: las imágenes se cargarán\
  OFF: las imágenes no se cargarán, lo que ahorra datos de tu proxy
- **Using scrolling**\
  ON: el bot se desplazará por las páginas, imitando el comportamiento humano\
  OFF: el bot no se desplazará por las páginas y pasará directamente al siguiente paso
- **Use autoclock**\
  ON: **aceptará las solicitudes de cookies** por ti\
  OFF: no hará clic en nada

Lo que todavía no admite:

- Grabar manualmente flujos de trabajo para que el bot los ejecute
- Personalizar en qué elementos hace clic el bot

## Ejecutar Cookie Bot

### Para ejecutar Cookie Bot en un solo perfil

1. Ve a la página **All profiles**.
2. Haz clic en los **3 dots** del perfil.
3. Selecciona **Automation**.
4. Revisa la lista de sitios web que debe visitar el bot.
5. Ajusta las opciones adicionales si es necesario.
6. Haz clic en **Run**.

<Frame>
  ![Ejecutar Cookie Bot para un perfil](/images/run_cookie_bot_for_profile-1.gif)
</Frame>

Cookie Bot simulará actividad de navegación y generará cookies para el perfil.

### Ejecutar Cookie Bot en varios perfiles

Gologin también te permite ejecutar Cookie Bot **en varios perfiles a la vez**.

Para hacerlo:

1. Selecciona varios perfiles en la tabla de perfiles.
2. Elige **Automation**.
3. Configura los ajustes.
4. Haz clic en **Run**.

<Frame>
  ![Ejecutar Cookie Bot para varios perfiles](/images/run_cookie_bot_for_multiple_profiles.gif)
</Frame>

El proceso se iniciará para todos los perfiles seleccionados.

## Buenas prácticas

Para obtener los mejores resultados:

- ejecuta Cookie Bot antes de iniciar sesión en cuentas nuevas
- mantén activado el proxy del perfil durante el proceso
- evita ejecutar Cookie Bot con demasiada frecuencia en el mismo perfil

Esto ayuda a mantener un entorno de navegación natural.
