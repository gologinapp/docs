---

Esta guía te muestra cómo extraer tu primera URL con Web Unlocker.

---

## Requisitos previos

- Una clave de API de Web Unlocker. Puedes obtenerla con el formulario de la [página de Web Unlocker](https://gologin.com/web-unlocker/#web_unlocker_form). La clave llega en un plazo de un día hábil e incluye solicitudes gratuitas para que pruebes tus propios destinos. No se necesita tarjeta.
- Python 3.x, Node.js o cualquier cliente HTTP

---

## Autenticación

Todas las solicitudes requieren tu clave de API en el encabezado `apikey`:

```
apikey: YOUR_API_KEY
```

La URL base para todas las solicitudes a la API es:

```
https://parsing.webunlocker.gologin.com/v1
```

---

## Haz tu primera solicitud

Envía una solicitud GET con la URL de destino como parámetro de consulta. La respuesta es el HTML de la página completamente renderizado.

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.text)
```

### JavaScript (Node.js / Browser)

```javascript
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(html);
```

---

## Qué obtienes como respuesta

El cuerpo de la respuesta es el HTML renderizado de la página, sin procesar: el mismo contenido que verías al abrir la URL en un navegador. No hay envoltorio JSON ni necesitas ningún análisis adicional.

```html
<!DOCTYPE html>
<html>
  <head><title>Example Domain</title></head>
  <body>...</body>
</html>
```

### Otros formatos

Añade el parámetro de consulta `format` para obtener la página en otro formato:

| `format` | Cuerpo de la respuesta |
|---|---|
| `html` | HTML de la página (valor predeterminado) |
| `markdown` | Contenido de la página en Markdown |
| `json` | Objeto JSON con la URL, los metadatos de la solicitud y el HTML de la página |

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com&format=json" \
  -H "apikey: YOUR_API_KEY"
```

```json
{
  "success": true,
  "data": {
    "url": "https://example.com",
    "metadata": {
      "response_time_ms": 297,
      "status_code": 200
    },
    "html": "<!DOCTYPE html><html lang=\"en\">..."
  }
}
```

---

## Gestión de errores

Comprueba el código de estado HTTP antes de procesar la respuesta:

| Estado | Significado | Cuerpo de la respuesta |
|---|---|---|
| `200` | Correcto | La página en el formato solicitado |
| `400` | Solicitud incorrecta, por ejemplo, falta el parámetro `url` | `{"success":false,"error":"Request failed"}` |
| `401` | Falta el encabezado `apikey` | `{"message":"Missing API key in request"}` |

Si recibes un estado `429` o `5xx`, vuelve a intentarlo con retroceso exponencial.

```python
response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

if response.status_code == 200:
    html = response.text
else:
    print(f"Error {response.status_code}: {response.text}")
```

## Inicio rápido con la CLI

También puedes extraer páginas con las herramientas CLI de Gologin sin escribir código:

### CLI de Web Unlocker

```bash
npm install -g gologin-webunlocker

GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker scrape https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker markdown https://example.com
```

### CLI de Gologin Web Access (unificada)

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."
gologin-web-access read https://example.com
gologin-web-access scrape-json https://example.com
gologin-web-access batch-scrape https://example.com/page/1 https://example.com/page/2 --format text
```

Consulta [SDK y CLI de Web Unlocker](/es/scraping-api-sdk-and-cli) y [CLI de Web Access](/es/cli-tools/web-access) para ver todos los detalles.
