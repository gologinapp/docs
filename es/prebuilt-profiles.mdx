---
title: "Plantillas de perfil predefinidas"
---

Las plantillas de perfil predefinidas ofrecen configuraciones recomendadas de perfiles de navegador para los flujos de trabajo habituales en distintas plataformas.

Estas plantillas muestran los ajustes típicos que se usan en cada plataforma, como la configuración de la huella digital, el tipo de proxy y los ajustes regionales. Puedes usarlas como punto de partida al crear nuevos perfiles de navegador en Gologin.

Las plantillas son ejemplos, no ajustes fijos, y puedes modificarlas según tu flujo de trabajo.

## Plantilla de perfil para TikTok

Configuración recomendada para entornos de cuentas de TikTok.

| Parámetro | Ajuste recomendado |
| :-- | :-- |
| Tipo de navegador | Entorno de tipo móvil |
| Tipo de proxy | Residencial o móvil |
| Ubicación del proxy | Región fija |
| Cambios en la huella digital | Mínimos |
| Zona horaria | Que coincida con la ubicación del proxy |

TikTok da mucha importancia a la coherencia del dispositivo y al comportamiento de la sesión. Los entornos estables ayudan a reducir las verificaciones adicionales.

## Plantilla de perfil para Facebook / Meta Ads

Configuración recomendada para cuentas de Facebook y flujos de trabajo de Meta Ads.

| Parámetro | Ajuste recomendado |
| :-- | :-- |
| Tipo de navegador | Escritorio |
| Tipo de proxy | Residencial |
| Ubicación del proxy | Fija |
| Cambios en la huella digital | Evitar cambios frecuentes |
| Comportamiento de la sesión | Actividad gradual |

Facebook evalúa las señales del dispositivo y el historial de inicios de sesión, por lo que es importante mantener entornos coherentes.

## Plantilla de perfil para plataformas de criptomonedas

Configuración recomendada para exchanges de criptomonedas y plataformas con verificación KYC.

| Parámetro | Ajuste recomendado |
| :-- | :-- |
| Tipo de navegador | Escritorio |
| Tipo de proxy | Residencial |
| Ubicación del proxy | Región fija |
| Cambios en la huella digital | Evitar cambios después de la verificación |
| Estabilidad de la sesión | Alta |

Una vez completada la verificación KYC, mantener el mismo entorno de dispositivo ayuda a reducir los controles de seguridad adicionales.

## Plantilla de perfil para Gmail / Google

Configuración recomendada para servicios de Google como Gmail y Google Ads.

| Parámetro | Ajuste recomendado |
| :-- | :-- |
| Tipo de navegador | Escritorio |
| Tipo de proxy | Residencial |
| Ubicación del proxy | Región estable |
| Cambios en la huella digital | Mínimos |
| Comportamiento de la sesión | Actividad gradual |

Google evalúa la coherencia de los inicios de sesión y la actividad en todos sus servicios para determinar el nivel de confianza de una cuenta.
