---
title: "IP incorrecta: mi IP real se filtra al usar un proxy"
description: "Qué hacer cuando tu IP real se filtra al usar el navegador de Gologin con un proxy"
---

El único motivo de filtración de IP que conocemos es tener el software **NordVPN** en ejecución con la función **Threat Protection** activada.\
﻿La función Threat Protection tiene mayor prioridad en el sistema y hace que todos los navegadores (incluidos tus navegadores habituales) utilicen la IP de NordVPN. Funciona incluso si la conexión VPN está desactivada.

Si quieres seguir trabajando en Gologin con un proxy, **desactiva Threat Protection** para que se muestre la IP correcta del proxy.
