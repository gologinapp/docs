---

Busca tu error en esta página con **Ctrl+F** (Windows) o **Cmd+F** (macOS): la mayoría de los encabezados usan el texto exacto del error.

## Antes de empezar

- **Consulta el error completo.** Pasa el cursor sobre el estado **Error** del perfil en la lista de perfiles para ver el mensaje completo.
- **Cierra la aplicación por completo.** Cerrar la ventana de Gologin solo la oculta: la aplicación sigue ejecutándose en segundo plano. Para cerrarla, haz clic en el icono de Gologin en la bandeja del sistema (abajo a la derecha en Windows, barra de menús en macOS) y selecciona **Quit**.
- **Actualiza Gologin y el navegador.** Descarga la última versión desde [gologin.com/download](https://gologin.com/download) e instálala sobre la actual: tus perfiles se conservan. Para actualizar el navegador de un perfil, haz clic en los tres puntos junto al perfil y selecciona **Update browser**.
- **¿Vas a contactar con soporte?** Incluye el ID del perfil (tres puntos junto al perfil → **Copy ID**) y una captura de pantalla del error.

## Errores al iniciar un perfil

### "The profile is being run by another user"

**Cómo se ve:** El perfil no se inicia y muestra este mensaje, aunque parezca que nadie más lo está usando.

**Por qué ocurre:** Gologin no permite que un mismo perfil se ejecute en varios dispositivos al mismo tiempo. Así se evitan conflictos de sincronización y problemas con las cookies y las sesiones. Verás este mensaje cuando:

- alguien con quien has compartido el perfil lo tiene abierto en este momento;
- la aplicación de Gologin está instalando una actualización (verás una barra de progreso en la parte superior de la aplicación);
- la sesión anterior del perfil no se cerró correctamente.

**Cómo solucionarlo:**

1. Comprueba que nadie con quien hayas compartido el perfil lo tenga abierto y espera a que termine cualquier actualización de la aplicación.
2. Haz clic en el logotipo de Gologin en la esquina superior izquierda de la aplicación y vuelve a ejecutar el perfil.
3. Cierra Gologin por completo desde la bandeja del sistema, vuelve a abrirlo y ejecuta el perfil.
4. Si el error continúa, clona el perfil (tres puntos junto al perfil → **Clone**) y ejecuta la copia.

### El perfil se queda atascado en Downloading o Archiving

**Cómo se ve:** El estado del perfil se queda en **Downloading** al iniciarlo, o en **Archiving** al detenerlo.

**Por qué ocurre:** Gologin no puede terminar de cargar o guardar los datos del perfil. Las causas habituales son una conexión bloqueada con los servidores de Gologin, un antivirus o archivos dañados del navegador.

**Cómo solucionarlo:**

1. Revisa tu conexión; consulta [Errores de conexión](#errores-de-conexión) más abajo.
2. Desactiva el antivirus de terceros o añade Gologin a sus excepciones.
3. Cierra Gologin por completo desde la bandeja del sistema.
4. Elimina la carpeta del navegador para que Gologin lo descargue de nuevo:
   - **Windows:** `C:\Users\<YourUser>\.gologin\browser`
   - **macOS:** `~/.gologin/browser` (en Terminal: `rm -r ~/.gologin/browser`)
5. Inicia Gologin (en Windows, haz clic derecho sobre él y selecciona **Run as administrator**), espera a que se descargue el navegador y ejecuta el perfil.
6. Si nada funciona, reinstala Gologin desde [gologin.com/download](https://gologin.com/download). Antes de desinstalar la aplicación, asegúrate de que no haya perfiles en ejecución: tus perfiles permanecen en tu cuenta.

### "Seems like you don't have installed browser"

**Cómo se ve:** El mensaje completo es "Seems like you don't have installed browser. We will try to install it. Please run the profile again after the installation is finished."

**Por qué ocurre:** Orbita, el navegador en el que se ejecutan los perfiles de Gologin, aún no ha terminado de descargarse, o sus archivos se eliminaron de tu ordenador.

**Cómo solucionarlo:**

1. Espera a que termine la descarga del navegador y vuelve a ejecutar el perfil.
2. Si el mensaje sigue apareciendo, comprueba que tu antivirus no esté eliminando archivos de Orbita (consulta [Antivirus y software de seguridad](#antivirus-y-software-de-seguridad)) y que tengas espacio libre en el disco.

### "Seems like a GPU process has crashed"

**Cómo se ve:** El mensaje completo es "Seems like a GPU process has crashed. Please try to restart the profile or restart your system".

**Cómo solucionarlo:**

1. Vuelve a ejecutar el perfil.
2. Reinicia tu ordenador.
3. Si sigue ocurriendo, sigue los pasos 2–5 de [un perfil atascado en Downloading o Archiving](#el-perfil-se-queda-atascado-en-downloading-o-archiving).

### "Your PC does not have enough memory or other system resource to run the browser"

**Por qué ocurre:** A tu ordenador se le ha agotado la memoria o el espacio en disco. Los errores que contienen `ENOSPC` o `SQLITE_FULL` también indican que el disco está lleno.

**Cómo solucionarlo:**

1. Cierra los perfiles y programas que no necesites.
2. Libera espacio en el disco: Gologin guarda en él los datos de los perfiles en ejecución.
3. Reinicia Gologin y vuelve a ejecutar el perfil.

### "Container not found"

**Cómo se ve:** Aparece "Container not found" al intentar iniciar un perfil, sobre todo en modo nube.

**Por qué ocurre:** Los datos del perfil están dañados, o el contenedor en la nube no pudo iniciarse en los servidores de Gologin.

**Cómo solucionarlo:**

1. Reinicia la aplicación de Gologin e intenta iniciar el perfil de nuevo.
2. Intenta iniciar el perfil desde la versión web en [app.gologin.com](https://app.gologin.com).
3. Si el problema continúa, contacta con soporte e indica el ID de tu perfil.

### "Couldn't prepare your profile, contact support"

**Cómo se ve:** Este error aparece cuando Gologin no logra preparar tu perfil para iniciarlo.

**Por qué ocurre:** Suele deberse a un problema de sincronización del perfil, a datos del perfil dañados o a una discrepancia entre la versión de tu navegador Orbita y la versión esperada.

**Cómo solucionarlo:**

1. Actualiza la aplicación de escritorio de Gologin a la última versión.
2. Revisa tu conexión a internet: una conexión inestable puede interrumpir la sincronización del perfil.
3. Prueba a cambiar a otra red (por ejemplo, de WiFi a un punto de acceso móvil).
4. Si el error continúa, contacta con soporte con el ID de tu perfil y la versión de la aplicación.

### "Profile has been deleted"

**Cómo se ve:** Aparece "Profile has been deleted" o "Profile has been already deleted", aunque no hayas eliminado el perfil.

**Por qué ocurre:** Este mensaje es engañoso. **No** significa que tu perfil se haya eliminado realmente. Normalmente aparece cuando has alcanzado el límite de inicios de perfil en un plan de prueba o gratuito.

<Info>
  Gologin conserva los perfiles en sus servidores hasta 180 días después de que caduque una suscripción. Los datos de tu perfil no se pierden cuando ves este mensaje.
</Info>

**Cómo solucionarlo:**

1. Cambia a un plan de pago o renueva tu suscripción para recuperar el acceso.
2. Si crees que se trata de un error, contacta con soporte con los datos de tu cuenta.

### ECONNREFUSED 127.0.0.1

**Cómo se ve:** Aparece un error que contiene `ECONNREFUSED 127.0.0.1` al intentar iniciar un perfil de forma local.

**Por qué ocurre:** El navegador Orbita no pudo iniciarse en tu equipo. Las causas más comunes son:

- Una descarga de Orbita dañada
- Una incompatibilidad con el proxy que impide que el navegador se inicialice
- Una versión desactualizada de la aplicación de Gologin

**Cómo solucionarlo:**

1. Actualiza la aplicación de escritorio de Gologin a la última versión.
2. Descarga Orbita de nuevo: cierra Gologin por completo y elimina la carpeta del navegador, como se describe en [un perfil atascado en Downloading o Archiving](#el-perfil-se-queda-atascado-en-downloading-o-archiving).
3. Revisa la configuración de tu proxy: prueba a iniciar el perfil sin proxy para aislar el problema.

### EBUSY: resource busy or locked (Windows)

**Cómo se ve:** En Windows, aparece un error `EBUSY: resource busy or locked`, a menudo haciendo referencia a un archivo Cookies.

**Por qué ocurre:** Un proceso anterior de Orbita no se cerró correctamente y sigue bloqueando archivos del perfil.

**Cómo solucionarlo:**

1. Abre el **Task Manager** (Ctrl+Shift+Esc) y finaliza todos los procesos llamados `orbita` o `browser`.
2. Elimina la copia local del perfil. Abre `C:\Users\<YourUser>\AppData\Roaming\GoLogin\profiles\` y elimina la carpeta que coincide con el ID del perfil afectado.
3. Reinicia Gologin e inténtalo de nuevo.

<Warning>
  Eliminar esta carpeta solo borra la copia local del perfil. Los datos de tu perfil almacenados en los servidores de Gologin no se ven afectados.
</Warning>

## Errores de conexión

### "Timezone request error", "Profile loading error" y otros errores de conexión

**Cómo se ve:** Aparece uno de estos mensajes, o la aplicación muestra una pantalla blanca o verde en lugar de cargarse:

- "Timezone request error"
- "Profile loading error. Check internet connection."
- "Error in profile request. Check your internet connection and try again."
- "Error uploading profile. Please check your internet connection and try again."
- "Retrying your request due to internet connectivity issues. Thank you for your patience."

**Por qué ocurre:** Tu red o tu proveedor de internet bloquea o interrumpe la conexión entre la aplicación de Gologin y los servidores de Gologin. Otros sitios web pueden seguir funcionando con normalidad en la misma conexión.

**Cómo solucionarlo:**

1. Cambia a otra red: por ejemplo, desactiva el WiFi y comparte internet móvil desde tu teléfono.
2. Activa una VPN en tu ordenador. Si la primera VPN no ayuda, prueba con otro proveedor: a veces hace falta probar varios.
3. Después de cambiar de red o de VPN, cierra Gologin por completo desde la bandeja del sistema y vuelve a abrirlo.

<Tip>
  Si ves "SSL certificate error. Please check and adjust your system time or check your internet connection", primero asegúrate de que la fecha, la hora y la zona horaria de tu ordenador estén configuradas de forma automática.
</Tip>

### "Something went wrong. Please try again later"

**Cómo se ve:** Aparece "Something went wrong. Please try again later" o una página que dice "Oops! Something went wrong…".

**Por qué ocurre:** Falló una solicitud a los servidores de Gologin. Es un error general con muchas causas posibles.

**Cómo solucionarlo:**

1. Pulsa **Ctrl+Shift+R** (Windows) o **Cmd+Shift+R** (macOS) para recargar. Funciona tanto en la aplicación de escritorio como en la versión web.
2. Si el error se repite, cierra Gologin por completo desde la bandeja del sistema y vuelve a abrirlo.
3. Si sigue ocurriendo, sigue los pasos de [errores de conexión](#errores-de-conexión).
4. Si nada funciona, reinstala Gologin desde [gologin.com/download](https://gologin.com/download) o contacta con soporte con una captura de pantalla.

### "Internal server error"

**Por qué ocurre:** Un problema temporal por parte de Gologin.

**Cómo solucionarlo:**

1. Espera unos minutos e inténtalo de nuevo.
2. Actualiza Gologin a la última versión.
3. Si el error no desaparece, contacta con soporte.

### "The proxy is functional but not working on your device or network"

**Cómo se ve:** Gologin informa de que el proxy superó la comprobación en el servidor, pero no puede conectarse desde tu equipo.

**Por qué ocurre:** Tu red local o tu proveedor de internet está bloqueando la conexión con el proxy. El proxy en sí funciona (Gologin lo verificó en sus servidores), pero el tráfico no puede salir de tu dispositivo.

**Cómo solucionarlo:**

1. Prueba a activar una VPN en tu dispositivo y vuelve a iniciar el perfil.
2. Cambia a otra red (de WiFi a un punto de acceso móvil, o viceversa).
3. Revisa la configuración de tu firewall o antivirus para asegurarte de que no bloqueen Gologin ni el puerto del proxy.

### SyntaxError: Unexpected token 'e'

**Cómo se ve:** Aparece un error de tipo JavaScript `SyntaxError: Unexpected token 'e'`, normalmente en la aplicación de Gologin o en una respuesta de la API.

**Por qué ocurre:** Esto sucede cuando Cloudflare devuelve una página de error de límite de solicitudes 1015 (HTML) en lugar de la respuesta JSON esperada de la API de Gologin. El analizador de JSON encuentra el HTML y falla en el primer carácter inesperado.

**Cómo solucionarlo:**

1. Reduce la frecuencia de tus solicitudes a la API o de los inicios de perfil.
2. Espera unos minutos antes de volver a intentarlo.
3. Si usas la API de Gologin de forma programática, implementa un retroceso exponencial (exponential backoff) en la lógica de tus solicitudes.

## Errores de macOS

### "Your macOS version is not supported by Chromium Engine"

**Por qué ocurre:** Orbita 151 y las versiones posteriores no son compatibles con macOS 12 Monterey ni con versiones anteriores de macOS.

**Cómo solucionarlo:**

1. Actualiza macOS a una versión más reciente, **o**
2. Crea un perfil nuevo con Orbita 150 o anterior: haz clic en **Add profile**, abre la pestaña **Advanced** y elige la versión del navegador en **Old versions**.

<Note>
  No es posible volver a una versión anterior del navegador en un perfil existente: crea un perfil nuevo.
</Note>

### "Current browser version is not supported for ARM processor architecture"

**Cómo se ve:** Los perfiles muestran este error, o Gologin va muy lento o se congela en tu Mac.

**Por qué ocurre:** La versión de Gologin para Intel está instalada en un Mac con chip Apple Silicon (M1 o posterior), o el perfil usa una versión antigua del navegador.

**Cómo solucionarlo:**

1. Comprueba tu chip: abre el menú Apple → **About This Mac** y mira el campo **Chip**.
2. Si es un chip Apple de la serie M, mueve Gologin de **Applications** a la papelera e instala la versión para Apple Silicon desde [gologin.com/download](https://gologin.com/download).
3. Actualiza el navegador del perfil: tres puntos junto al perfil → **Update browser**.

### "Cannot update while running on a read-only volume"

**Cómo se ve:** Gologin no puede instalar una actualización y muestra "Cannot update while running on a read-only volume. The application is on a read-only volume. Please move the application and try again."

**Por qué ocurre:** Gologin se está ejecutando desde la imagen de disco descargada o desde la carpeta **Downloads** en lugar de **Applications**.

**Cómo solucionarlo:**

1. Cierra Gologin.
2. Arrastra Gologin a la carpeta **Applications**.
3. Abre Gologin desde **Applications** e instala la actualización.

<Tip>
  Si una actualización se queda atascada en cualquier sistema, revisa tu [conexión](#errores-de-conexión) o descarga la última versión desde [gologin.com/download](https://gologin.com/download) e instálala sobre la actual. Tus perfiles se conservan.
</Tip>

## Antivirus y software de seguridad

### "Seems like your antivirus is blocking access to the Orbita browser"

**Cómo se ve:** Aparece uno de estos mensajes:

- "Seems like your antivirus is blocking access to the Orbita browser. Please adjust your antivirus and restart the profile"
- "Seems like something is blocking application access to the system. Please check your antivirus or other security software."
- "Seems like your browser files are damaged or missing (possibly deleted by antivirus software)…"
- "Permission denied" al actualizar el navegador

**Por qué ocurre:** Tu antivirus u otro software de seguridad bloquea Gologin u Orbita, o ha movido sus archivos a cuarentena.

**Cómo solucionarlo:**

1. En Windows, abre **Windows Security** → **Virus & threat protection** → **Protection history** y busca archivos de Gologin u Orbita bloqueados o en cuarentena. Restáuralos si encuentras alguno.
2. Añade Gologin a las excepciones de tu antivirus, o desactiva el antivirus.
3. Reinicia Gologin y vuelve a ejecutar el perfil: Gologin restaura automáticamente los archivos del navegador que falten.

## Errores de plan y límites

### "The owner of this profile has run out of subscription time"

**Cómo se ve:** No puedes ejecutar un perfil que alguien ha compartido contigo. El mensaje completo es "The owner of this profile has run out of subscription time. To resume using this profile, the owner needs to renew their subscription."

**Por qué ocurre:** La suscripción del propietario del perfil ha terminado.

**Cómo solucionarlo:** Pide al propietario del perfil que renueve su suscripción. Después, el perfil volverá a ejecutarse.

### "The workspace subscription has ended. Please upgrade your plan to restore access"

**Por qué ocurre:** Tu plan de prueba o de pago ha terminado.

**Cómo solucionarlo:** Elige un plan en **Settings & Members** → **Billing Plans** → **Change plan**. Para cambiar al plan Forever Free, haz clic en **Forever Free** en la parte inferior de esa página: tu espacio de trabajo no debe tener más de 3 perfiles.

### "You've exceeded your workspace limits"

**Por qué ocurre:** En el plan Forever Free puedes tener hasta 3 perfiles al mismo tiempo y crear hasta 25 perfiles al mes.

**Cómo solucionarlo:**

1. Si tienes 3 perfiles, elimina uno que no necesites. Eliminar un perfil no devuelve una creación.
2. Si has usado las 25 creaciones, espera a que se restablezca el límite mensual o [cambia a un plan de pago](/es/general/account-and-billing/how-to-subscribe-to-gologin).

Consulta [Limitaciones del plan gratuito](/es/general/account-and-billing/pricing#limitaciones-del-plan-gratuito) para más detalles.

### "You've reached max shares number. To share more update your plan"

**Por qué ocurre:** Has agotado el número de veces que puedes compartir perfiles con tu plan.

**Cómo solucionarlo:** Revoca los accesos compartidos que ya no necesites en el menú **Share** de tus perfiles, o cambia a un plan superior.

### "You've reached max parallel cloud launches limit"

**Cómo se ve:** Este error, o "You've hit your parallel launch limit", aparece cuando intentas iniciar un perfil en la nube.

**Por qué ocurre:** Has alcanzado el número máximo de sesiones simultáneas en la nube que permite tu plan.

Los límites de sesiones simultáneas en la nube son:

| Plan         | Sesiones simultáneas en la nube |
|--------------|---------------------------------|
| Professional | 1                               |
| Business     | 2                               |
| Enterprise   | 3                               |
| Custom       | 4                               |

**Cómo solucionarlo:**

1. Cierra uno o más perfiles en la nube que estén en ejecución antes de iniciar uno nuevo.
2. Compra más inicios paralelos en la nube: haz clic en el nombre de tu cuenta en la esquina superior izquierda → **Settings & Members** → **Cloud Browser Usage** → **Buy more limits**.
3. Ejecuta los perfiles en la aplicación de escritorio: los inicios locales no están limitados por tu plan.

<Note>
  Ejecutar perfiles en la nube requiere un plan de pago.
</Note>

### "You've exceeded your traffic limit" / "exceeded request limit"

**Cómo se ve:** Aparece uno de dos mensajes relacionados al iniciar un perfil o realizar acciones.

**Por qué ocurre:** Este error tiene dos causas posibles:

- **Límite de tráfico:** Se ha agotado el tráfico de proxy de Gologin (medido en GB). Tu suscripción y el tráfico de proxy son independientes: tener un plan activo no significa que te quede tráfico.
- **Límite de solicitudes/IP:** Has alcanzado un límite de solicitudes basado en la IP, que normalmente se activa al crear demasiadas cuentas desde la misma dirección IP en poco tiempo.

**Cómo solucionarlo:**

- **Para límites de tráfico:** Compra más tráfico: abre la pestaña **Proxies** a la izquierda, elige el tipo de proxy, haz clic en **+**, selecciona la cantidad de GB y paga.
- **Si acabas de comprar tráfico:** Asegúrate de que tus perfiles usen el mismo tipo de proxy que el tráfico que compraste. Por ejemplo, si compraste tráfico Datacenter, cambia el proxy del perfil de Residential a Datacenter en la configuración del perfil.
- **Para límites de IP:** Espera aproximadamente 1 hora a que caduque el bloqueo de la IP y vuelve a intentarlo.

## Errores de cuenta

### "Registration error. Please try again."

**Por qué ocurre:** Hubo demasiados intentos de registro en poco tiempo, o ya existe una cuenta con este correo electrónico.

**Cómo solucionarlo:**

1. Espera un rato e inténtalo de nuevo.
2. Si ya te has registrado antes con este correo, haz clic en **Log in**. Si no recuerdas la contraseña, usa **Forgot password?**.

<Note>
  "Invalid input data. Check field - "email"" significa que no se aceptó la dirección de correo. Usa una dirección con al menos 3 caracteres antes de la @. Las direcciones con "+1", como name+1@gmail.com, no se aceptan.
</Note>

### No puedo iniciar sesión con Google

**Cómo solucionarlo:**

1. En la pantalla de inicio de sesión, haz clic en **Forgot password?** e introduce el correo de tu cuenta de Gologin.
2. Introduce el código del correo y establece una contraseña.
3. Inicia sesión con tu correo y contraseña.

## Errores de Cloud Android

### "No available devices"

**Por qué ocurre:** Todos los teléfonos en la nube están ocupados en este momento. No depende de tu perfil.

**Cómo solucionarlo:** Inténtalo de nuevo más tarde.

## Errores del navegador y de extensiones

### "To install add-ons, you'll need the new Microsoft Edge"

**Cómo se ve:** Al intentar instalar una extensión del navegador dentro de un perfil de Gologin, aparece un aviso sobre Microsoft Edge.

**Por qué ocurre:** El navegador Orbita (basado en Chromium) a veces muestra este mensaje cuando intentas instalar extensiones desde la tienda de complementos de Microsoft Edge o mediante una vía de instalación incompatible.

**Cómo solucionarlo:**

1. Instala las extensiones desde la [Chrome Web Store](https://chromewebstore.google.com/) en lugar de la tienda de complementos de Edge.
2. También puedes usar la interfaz de gestión de extensiones de Gologin para añadir extensiones a tu perfil antes de iniciarlo.

### Ventana emergente de autenticación del proxy para geo.floppydata.com:10080

**Cómo se ve:** Al iniciar un perfil, aparece un cuadro de diálogo de autenticación del proxy que solicita credenciales para `geo.floppydata.com:10080`.

**Por qué ocurre:** El proxy integrado de Gologin solicita autenticación de forma inesperada. Puede ocurrir cuando la configuración del proxy no se transmite correctamente al navegador, a menudo por un conflicto de red o de VPN.

**Cómo solucionarlo:**

1. Cierra Gologin por completo (comprueba la bandeja del sistema para asegurarte de que está cerrado).
2. Activa una VPN en tu dispositivo.
3. Reinicia Gologin.
4. Vuelve a iniciar el perfil. Con proxies residenciales rotativos, reiniciar el perfil también te da una IP nueva.

<Info>
  Si la ventana emergente sigue apareciendo, ejecuta el perfil en la versión web en [app.gologin.com](https://app.gologin.com), prueba con otro proxy o contacta con el soporte de Gologin.
</Info>
