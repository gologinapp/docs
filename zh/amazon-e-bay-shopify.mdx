title: "Amazon、eBay、Shopify"
---

电商平台对账号关联的检测最为严格。Amazon、eBay 和 Shopify 都会维护跨账号关联图谱——如果两个账号共用 IP、支付方式、设备指纹或收货地址,平台就会将它们关联起来。一旦其中一个账号被封停,与之关联的账号通常也会随之被封。

## 快速检查清单

- 1 个卖家账号 = 1 个浏览器配置文件
- 1 个配置文件 = 1 个静态住宅代理或 ISP 代理
- **切勿使用轮换代理**——IP 变化会立即导致账号被关联
- **切勿使用 Gologin 内置代理**——它们默认是轮换的
- 每个账号使用独立的支付方式
- 每个账号使用独立的手机号和邮箱

## 第 1 步:设置 Gologin 配置文件

- **代理:**静态住宅代理或 ISP 代理——每个账号使用一个专属 IP,绝不共用
- **指纹:**保持默认设置

## 第 2 步:养号

| **时间段** | **重点** | **操作内容** |
| :-- | :-- | :-- |
| 第 0 天 | 设置 | 注册 \+ 身份验证 |
| 第 1–3 天 | 熟悉平台 | 浏览卖家工具,阅读平台政策 |
| 第 4–7 天 | 轻度活动 | 添加 5–10 个商品,设置物流 |
| 第 2 周 | 正常使用 | 管理商品,回复买家咨询 |
| 第 3 周\+ | 扩大规模 | 逐步增加商品上架数量 |

## 安全的操作模式

| 操作 | 建议做法 |
| :-- | :-- |
| 商品上架 | 逐步添加 |
| 账号信息修改 | 偶尔更新 |
| 后台活动 | 定期浏览 |
| 订单处理 | 保持稳定的处理节奏 |

## 支付隔离

这是导致电商平台账号被关联并一同被封的最常见原因。

每个账号都需要:

- 独立的信用卡或借记卡
- 独立的 PayPal 账号(如使用)
- 独立的账单地址

可行的方案:Revolut、Wise、N26(多张虚拟卡)、Privacy.com(美国)、预付借记卡。

<Warning>
  在多个 Amazon 卖家账号之间共用一张银行卡,会被视为违反服务条款。Amazon 会封停所有关联账号,并冻结资金最长 90 天。
</Warning>

## 各平台注意事项

### Amazon

- 不同会话之间 IP 发生变化,会触发账号关联的自动审查
- 申诉难度很大——预防远比事后恢复容易
- 企业账号需要提供经过验证的法人实体文件

### eBay

- 对 IP 的要求不如 Amazon 严格,但同样会追踪设备指纹
- 每个账号需要为 eBay Managed Payments 提供各自独立的银行信息
- 评价分数很重要——新账号的买家信任度较低

### Shopify

- Gologin 主要用于管理多个 Shopify 管理员账号,或在不同地点开展运营
- 不像 Amazon/eBay 那样存在跨账号检测,但 Shopify Payments 会对收款进行欺诈检测

## 常见封号触发因素

### Amazon

- 使用轮换或共享的代理 IP
- 多个账号使用相同的支付方式
- 多个卖家账号登录时使用相同的设备指纹
- 关联账号被封停(Amazon 会连带封号)

### eBay

- 与曾被封停的账号使用相同的 IP 或指纹
- 在多个账号中同时上架相同的商品
- 出现操纵评价的行为模式
