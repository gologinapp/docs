Gologin 不仅提供桌面应用,还提供网页版应用,访问地址为 [app.gologin.com](http://app.gologin.com)。你可以在该页面使用 Gologin 账号登录,并在任意设备的任意浏览器中管理你的配置文件,无需安装。

### 云端浏览器

要了解网页版应用的工作方式,首先需要了解云端浏览器。

在桌面应用中运行配置文件时,配置文件会在你的设备上打开,并占用设备资源,例如内存(RAM)和 CPU。因此,可同时运行的配置文件数量会受到硬件性能的限制。

云端浏览器的工作方式则不同。配置文件不是在你的设备上运行,而是在 Gologin 的服务器上运行,你通过自己常用的浏览器查看并操作它。这意味着不会占用你设备的资源,你可以在任何地方运行配置文件,并且可运行的配置文件数量不再受硬件限制。

与桌面应用中的配置文件一样,每个云端浏览器配置文件都有自己独立的浏览器指纹和 IP 地址。

### 你可以在网页版应用中做什么

[app.gologin.com](http://app.gologin.com) 上的网页版应用提供与桌面应用相同的核心功能。你可以创建和管理配置文件、运行云端浏览器配置文件,以及访问账号设置,所有操作都能在普通的浏览器标签页中完成。

当你没有带上常用的电脑,或者想在未安装桌面应用的设备上访问自己的配置文件时,这会非常有用。
