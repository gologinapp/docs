---
title: "哪些设置可以安全修改"
---

使用 Gologin 管理账号时,保持浏览器指纹的一致性非常重要。\
网站通常会通过分析浏览器配置的变化来识别异常行为。

部分配置文件设置可以随时安全修改,而另一些设置在账号开始使用该配置文件后,应保持稳定。

## 可以安全修改的设置

以下设置通常可以修改,不会影响浏览器指纹或账号的可信度:

- 配置文件名称
- 备注
- 文件夹和标签
- 扩展程序
- 代理凭据(前提是代理所在地区保持不变)

这些设置不会影响网站所使用的核心指纹信号。

## 需谨慎修改的设置

部分参数可能会影响浏览器环境,修改时需要格外谨慎。

包括:

- 时区
- 语言设置
- WebRTC 模式
- 媒体设备配置

如果必须修改,请尽量使其与代理所在地区和设备类型保持一致。

## 账号创建后应避免修改的设置

某些参数构成了浏览器指纹的核心。\
频繁修改这些参数,可能会导致网站将该浏览器视为一台新设备。

在账号已登录该配置文件后,请避免修改以下设置:

- 操作系统
- User Agent
- 屏幕分辨率
- 字体配置
- Canvas 指纹
- WebGL 指纹
- AudioContext 指纹
- CPU 线程数和内存(RAM)数值

对这些参数进行大幅修改,可能会触发额外的验证或登录检查。

## 最佳实践

为获得最稳定的效果:

- 在登录账号之前,先创建配置文件并配置好其指纹
- 添加账号后,保持指纹设置不变
- 为每个配置文件使用独立的专用代理
- 避免频繁修改与硬件相关的参数

保持指纹一致,有助于网站将该配置文件识别为一台稳定的设备。
