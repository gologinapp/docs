---
title: "Gologin 代理的工作原理"
---

Gologin 代理已直接集成到 Gologin 环境中，无需额外配置即可分配给浏览器配置文件。

为配置文件分配代理后，该配置文件的所有互联网流量都会通过代理服务器转发。这意味着网站看到的是代理 IP 地址，而不是您的真实 IP 地址。

为不同的配置文件使用独立的代理，有助于保持会话相互隔离，并降低多个账号被关联的可能性。

## 可用的代理类型

Gologin 提供多种代理类型：

- **住宅轮换代理** - 按流量计费
- **移动轮换代理** - 按流量计费
- **数据中心固定代理** - 按流量计费
- **专用 IP** - 为您保留的静态 IP，按每个 IP 每月 \$5 订阅计费

前三种代理共享您套餐的流量额度，并从共享池中获取地址。专用 IP 由您独享，不会轮换，也没有流量限制。

## 代理国家/地区

**对于按流量计费的代理（住宅、移动、数据中心）：** 购买 Gologin 代理流量后，您可以使用我们所有的代理国家/地区，不限于某一个国家/地区，流量可用于列表中的任意位置。我们目前提供数十个国家/地区，并会不定期新增。完整列表请直接在 Gologin 应用中查看。

**对于专用 IP：** 每次只能购买一个国家/地区的 IP。您获得的 IP 属于所选的国家/地区，且无法更换为其他国家/地区。如果您需要多个国家/地区的地址，请为每个国家/地区分别购买专用 IP。您只能选择国家/地区，无法指定具体城市。

专用 IP 目前支持以下国家/地区：

- 巴西
- 法国
- 德国
- 中国香港
- 罗马尼亚
- 土耳其
- 英国
- 美国

<Note>
  您可以在同一个国家/地区购买多个专用 IP。每次购买都会获得不同的地址，这些地址会在代理管理器中归入该国家/地区下。
</Note>

## Gologin 代理的优势

使用 Gologin 代理有以下几个优点：

- 无需第三方配置，快速完成设置
- 轻松将代理分配给配置文件
- 与 Gologin 浏览器配置文件集成
- 在应用内简化代理管理
