---
title: "什么是 Gologin 代理"
---

Gologin 代理是**直接集成在 Gologin 浏览器中**的 IP 地址。当代理绑定到浏览器配置文件后，它决定了**你的网络流量来自哪里**，并帮助网站把每个配置文件视为**独立的真实用户**。

这种方式可以防止网站和平台根据 IP 地址数据**将多个账号关联在一起**，并降低被封禁、限制或触发安全验证的风险。

## 内置代理与自定义代理

Gologin 支持**两种使用代理的方式**，可根据你的需求和使用经验选择。

- **内置代理**：内置代理由 **Gologin 提供并管理**。它们开箱即用，无需任何外部设置，并能与我们的浏览器指纹系统无缝配合。如果你想要**简单、稳定、快速**的设置，并且不想处理第三方服务，这是最佳选择。
- **自定义代理**：自定义代理是**从第三方服务商购买**并手动添加到 Gologin 的代理。这种方式让你在选择代理服务商、地区和代理格式上拥有更大的灵活性，更适合需要对代理基础设施有更多控制的**高级用户**。

内置代理适合追求**简单和可靠**的用户，而自定义代理则为高级设置提供**更多控制权**。

## Gologin 代理的类型

根据你的套餐和需求，Gologin 可能提供不同类型的代理，例如：

- **住宅代理**：真实用户的 IP，适用于大多数平台
- **移动代理**：来自移动网络的 IP，适合对信任度要求更高的环境
- **数据中心代理**：速度更快、价格更低，但更容易被识别
- **专用 IP**：专属于你一人的 IP 地址。它不会更换，来自真实的互联网服务提供商，且没有流量限制。

住宅代理、移动代理和数据中心代理按流量（以 GB 计）付费。专用 IP 单独计费，每个 IP 每月订阅费为 \$5，适用于付费套餐。

<Note>
  **专用 IP**、**ISP 代理**和**静态代理**指的是同一个东西。Gologin 应用中称之为**购买专用 IP**，本文档中也统一使用这一说法。
</Note>

## 关于轮换代理

Gologin 的住宅代理和移动代理都是轮换代理：IP 地址大约每 **3-15 分钟**自动更换一次，因此在一次浏览会话中 IP 就可能发生变化。Gologin 不提供按流量计费的静态住宅代理。如果你需要一个永不更换的 IP，请使用**专用 IP**，它是静态住宅（ISP）地址。

**轮换代理适用于：**

- 网页抓取
- 较短的浏览会话
- 一般性调研 **不适合使用轮换代理的情况**

<Warning>
  请勿在 Amazon、eBay、Etsy、PayPal 或任何会监控账号历史记录的电商平台上使用轮换代理。轮换 IP 是这些平台上账号被关联和封禁最快的原因之一。这些账号请改用专用 IP。
</Warning>

- Amazon 和 eBay 会检测同一账号是否随着时间推移从不同的 IP 地址登录。它们会把这一点当作账号由第三方管理或属于多账号操作的信号。轮换代理会在每次会话中更换你的 IP，这正是它们所标记的模式。
- LinkedIn 在发现会话之间 IP 发生变化时，会让会话退出登录并触发安全审查。轮换代理会导致频繁退出登录和验证提示。
- 博彩平台要求每个账号使用一致的 IP 地址。IP 变化会被视为可疑登录行为，通常会导致账号受限。
- PayPal 和金融平台会将 IP 变化标记为账号可能被盗用。它们可能会冻结账号或要求进行身份验证。

## 银行和支付网站

Gologin 按流量计费的代理（住宅、移动和数据中心代理）无法用于银行和支付网站，例如 Stripe 或 PayPal，这些网站的页面可能无法加载或显示连接错误。若要在配置文件中进行支付或使用银行网站，请使用支持这些网站的第三方代理。

## 应该使用什么

对于任何敏感平台上的长期账号管理，你需要为每个账号配备一个永不更换的 IP 地址。在 Gologin 中，这就是**专用 IP**。

| 平台 | 推荐的代理类型 |
| --- | --- |
| Amazon / eBay / Etsy | 专用 IP |
| LinkedIn | 专用 IP |
| Facebook / Meta Ads | 专用 IP 或静态移动代理 |
| 博彩网站 | 静态移动代理 |
| 网页抓取 | 轮换住宅代理或数据中心代理 |
| 测试 / 快速检查 | 使用轮换的 Gologin 代理即可 |

完整说明请参阅[适合你的场景的最佳代理](https://gologin.com/docs/proxy/introduction/best-proxy-for-your-case)，或查看[推荐的代理服务商](https://gologin.com/best-proxy-server-services/)了解具体服务。

## 关于套餐包含的流量额度

每个 Gologin 套餐都包含以 GB 计量的代理流量额度。这是配置文件浏览时通过代理传输的数据量，而不是存储空间。

**粗略估算：**

- 轻度浏览（查看动态、阅读页面）：每个配置文件每天约 0.3–0.5 GB
- 积极使用（加载媒体、投放广告）：每个配置文件每天约 1–2 GB
- 10 个 LinkedIn 配置文件，每天使用 2 小时：每月约 3–6 GB

如果你为配置文件连接自己的第三方代理，则不会消耗 Gologin 的流量额度，只有通过 Gologin 自有代理网络传输的流量才会计入。
