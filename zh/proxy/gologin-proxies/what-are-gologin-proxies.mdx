---
title: "什么是 Gologin 代理"
---

Gologin 代理是**直接集成在 Gologin 浏览器中**的 IP 地址。当代理绑定到浏览器配置文件后,它会决定**你的网络流量来自哪里**,并让网站将每个配置文件视为**独立的真实用户**。

这种方式可以防止网站和平台根据 IP 地址数据**将多个账号关联在一起**,并降低被封禁、限制或触发安全验证的风险。

## 内置代理与自定义代理

Gologin 支持**两种使用代理的方式**,可根据你的需求和使用经验选择。

- **内置代理**:内置代理由 **Gologin 提供并管理**。开箱即用,无需任何外部设置,并且能与我们的浏览器指纹系统无缝配合。如果你想要**简单、稳定、快速**的配置,又不想处理第三方服务,这是最佳选择。
- **自定义代理**:自定义代理是**从第三方服务商购买**并手动添加到 Gologin 的代理。这种方式让你在选择代理服务商、地区和代理格式时更加灵活,更适合需要对代理基础设施有更多控制权的**高级用户**。

内置代理适合追求**简单与可靠**的用户,而自定义代理则为高级配置提供**更多控制权**。

## Gologin 代理的类型

根据你的套餐和需求,Gologin 可能提供不同类型的代理,例如:

- **住宅代理**:真实用户的 IP,适用于大多数平台
- **移动代理**:来自移动网络的 IP,适合对信任度要求更高的环境
- **数据中心代理**:速度更快、价格更低,但更容易被识别
- **专用 IP**:仅供你独享的一个 IP 地址。它不会更换,来自真实的互联网服务提供商,且没有流量限制。

住宅代理、移动代理和数据中心代理按流量(以 GB 计)付费。专用 IP 单独付费,每个 IP 订阅价格为 \$5/月,仅限付费套餐使用。

<Note>
  **专用 IP**、**ISP 代理**和**静态代理**指的是同一种东西。Gologin 应用中称之为**购买专用 IP**,本文档中也统一使用这一术语。
</Note>

## 关于轮换代理

Gologin 的住宅代理和移动代理会每 5-30 分钟自动轮换 IP 地址。这意味着在一次浏览会话中,你的 IP 会发生变化。

**轮换代理适用于:**

- 网页抓取
- 短时间浏览会话
- 一般性调研 **不适合使用轮换代理的场景**

<Warning>
  请勿将轮换代理用于 Amazon、eBay、Etsy、PayPal,或任何会监控账号历史记录的电商平台。轮换 IP 是这些平台上账号被关联和封禁的最快途径之一。请改为为这些账号使用专用 IP。
</Warning>

- Amazon 和 eBay 会检测同一账号是否长期从不同 IP 地址登录,并将其视为账号由第三方管理或属于多账号操作的信号。轮换代理在每次会话中都会更换你的 IP,这正是它们会标记的模式。
- LinkedIn 一旦发现会话之间 IP 发生变化,就会让会话登出并触发安全审核。轮换代理会导致频繁登出和验证提示。
- 博彩平台要求每个账号使用固定的 IP 地址。IP 变化会被视为可疑登录行为,通常会导致账号受限。
- PayPal 和金融类平台会将 IP 变化标记为账号可能被盗用,可能会冻结账号或要求进行身份验证。

## 应该使用什么

对于任何敏感平台上的长期账号管理,你需要为每个账号配置一个永不更换的 IP 地址。在 Gologin 中,这就是**专用 IP**。

| 平台 | 推荐的代理类型 |
| --- | --- |
| Amazon / eBay / Etsy | 专用 IP |
| LinkedIn | 专用 IP |
| Facebook / Meta Ads | 专用 IP 或静态移动代理 |
| 博彩网站 | 静态移动代理 |
| 网页抓取 | 轮换住宅代理或数据中心代理 |
| 测试 / 快速检查 | 使用 Gologin 轮换代理即可 |

完整说明请参阅[适合你的最佳代理](https://gologin.com/docs/proxy/introduction/best-proxy-for-your-case),如需了解具体服务,请参阅[推荐的代理服务商](https://gologin.com/best-proxy-server-services/)。

## 关于包含的流量额度

每个 Gologin 套餐都包含一定的代理流量额度,以 GB 计。这指的是配置文件浏览时通过代理传输的数据量,而不是存储空间。

**粗略估算:**

- 轻度浏览(查看动态、阅读页面):每个配置文件每天约 0.3–0.5 GB
- 活跃使用(加载媒体、投放广告):每个配置文件每天约 1–2 GB
- 10 个 LinkedIn 配置文件每天使用 2 小时:每月约 3–6 GB

如果你为配置文件连接自己的第三方代理,则不会消耗 Gologin 的流量额度,只有通过 Gologin 自有代理网络传输的流量才会计入。
