---
title: "购买 Gologin 代理"
---

Gologin 以两种方式销售代理:

- **代理流量**:按 GB 计算,适用于我们的住宅代理、移动代理和数据中心代理。每个付费方案都已包含一部分流量。
- **专用 IP**:为您保留的单个静态 IP 地址,按每个地址每月 \$5 订阅。本文将介绍这两种方式。

## 默认代理流量

所有付费方案每月都包含 **2 GB 住宅代理流量**,与方案级别或计费周期(按月或按年)无关。这部分流量会在每个计费月开始时刷新,不会累计,上个月未用完的流量会被新的 2 GB 替换。

<Check>
  年度订阅用户同样是每月 2 GB,而不是每年 2 GB。在整个订阅期内,流量每月都会刷新。
</Check>

## 购买额外流量

### 一次性充值

充值是一次性购买额外流量。如果您只是偶尔用量激增,不需要每月都有更多流量,可以使用这种方式。

**步骤:**

1. 在主页面 **所有简介** 中,点击左侧菜单中 **代理** 标签旁边的流量数值。
2. 选择您要购买流量的**代理类型**。
3. 选择所需的**流量数量**。
4. 点击所选数量旁边的 **\+** 按钮,然后继续结账。

<Frame>
  ![代理流量充值](/images/proxy_top_up.png)
</Frame>

<Info>
  应用内显示的价格是最新的。购买前请直接在应用中查看价格。
</Info>

**充值支付方式:**

您可以使用信用卡、借记卡或加密货币支付。部分国家(如俄罗斯和白俄罗斯)的用户可能无法使用银行卡为充值付款。如果您的银行卡支付被拒绝,请改用加密货币。

### 订阅附加项

订阅附加项会定期为您的方案增加固定数量的代理流量,也就是每月自动添加流量。

您可以在首次结账时为订阅添加流量,也可以随时通过更改当前方案来添加。

**如何为当前方案添加流量:**

1. 在主页面 **所有简介** 中,点击左下角方案信息旁边的**齿轮图标**。
2. 点击 **更改方案**。
3. 在价格页面确认您的方案。您应该会看到 **延长现行计划** 按钮,这表示您是在当前方案的基础上添加内容,而不是更换方案。
4. 找到**代理流量**附加项,并设置每月要添加的数量。
5. 点击 **立即升级**,选择支付方式,然后点击 **支付** 完成结账。

<Frame>
  ![通过订阅购买代理流量](/images/proxy_with_subscription.gif)
</Frame>

**循环流量的运作方式:**

- **月度方案**:每月订阅续费时,会收取附加项费用并添加相应流量。
- **年度方案**:附加项费用作为年度订阅的一部分一次性支付,并在全年内每月添加到您的账户。

有关更改方案的更多信息,请参阅 [更改和升级订阅](/zh/general/account-and-billing/change-plan)。

## 购买专用 IP

**专用 IP** 是只属于您的单个静态地址。它不会轮换,没有流量限制,非常适合需要长期保持同一 IP 的账户,例如 Amazon、eBay、LinkedIn、Meta Ads、PayPal 和博彩平台。

<Info>
  专用 IP 仅适用于付费方案,不包含在免费试用中。
</Info>

### 步骤

1. 点击 **添加简介**。
2. 打开 **代理人** 标签,选择 **Gologin 代理**。
3. 点击 **购买专用 IP**。
4. 在选择器中选择一个国家。
5. 点击 **每月 \$5 购买**。
6. 在打开的账单窗口中完成结账。您可以通过 Stripe 使用银行卡支付,或通过 Cryptomus 使用加密货币支付。
7. 返回 Gologin 后,会出现确认窗口,告知您付款已成功。
8. 等待 **5-7 分钟**,IP 将分配到您的账户。

<Frame>
  ![购买专用 IP](/images/buying_dedicated_IP.gif "购买专用 IP")
</Frame>

<Note>
  价格始终为 **\$5**,Gologin 不会收取任何手续费。如果您使用加密货币支付,您自己的钱包或交易所可能会在账单金额之外收取网络费用。详情请参阅 [支付方式](https://gologin.com/docs/general/account-and-billing/payment-methods)。
</Note>

### 购买后查找您的专用 IP

该 IP **不会自动绑定到任何简介**。5-7 分钟后请刷新页面,您可能需要重新加载页面它才会出现。

之后,您的专用 IP 会出现在以下三个位置:

- **代理** 页面中您自己的代理列表
- **新浏览器配置文件** 页面中的 **您的代理** 标签
- **所有简介** 页面中的代理管理器,用于为现有简介分配代理

### 专用 IP 的计费方式

专用 IP 与您的 Gologin 主订阅绑定,因此会随订阅结束而结束。

| 您的方案 | 您需要支付的费用 |
| --- | --- |
| 月度 | \$5,立即扣款,之后每月随方案续费 |
| 年度,且还有剩余月数 | \$5 × 剩余月数,立即扣款 |

如果您的年度方案还剩不足一个月的时间,将按整月计费。

**只要您的订阅保持有效并持续续费,IP 就不会改变。** 在您取消订阅之前,您将一直使用同一个地址。

<Warning>
  如果您使用加密货币支付,专用 IP 无法自动续费。它只在您已付费的期间内有效,到期后即停止使用,之后您将无法重新获得同一个 IP。
</Warning>

### 取消与退款

- 专用 IP 会随您的 Gologin 订阅一并取消。目前无法单独取消某一个 IP。
- 如果您取消订阅,IP 会继续使用到您已付费的期限结束。
- 专用 IP 无法更换为其他地址。
- 购买后 **14 天**内可申请退款,请联系支持团队。

<Note>
  专用 IP 属于购买它的账户,不会与其他工作区成员共享。但是,如果您将其分配给某个简介并共享该简介,任何有权访问该简介的人都可以使用它。
</Note>
