## 按流量计费的代理

### 如何选择代理类型？

要为新连接选择代理类型，只需创建一个新的代理服务器：点击 **档案中的"选择位置或代理" \> 国家旁边的箭头 \> 添加新服务器 \> 选择代理类型**。

### 我需要多少流量？

所需流量取决于您的使用场景，主要受以下因素影响：

- 使用浏览器档案的频率
- 每次会话的持续时间
- 工作时加载的大体积内容（如视频、图片或音频）的多少

### 代理流量用完后会怎样？会被检测到吗？

如果流量在使用过程中耗尽，Gologin 会断开您的档案与互联网的连接，在您充值流量或改用第三方代理之前，将无法继续使用这些档案。您仍然可以关闭档案且不会丢失数据，因为档案同步不会消耗代理流量。

### 如果我使用自己的第三方代理，会消耗 Gologin 代理流量吗？

当然不会！只有使用我们的代理时，才会消耗 Gologin 代理流量。

### 注册试用套餐后，我能获得免费的 Gologin 代理试用流量吗？

目前 Gologin 不会向新注册用户提供试用流量。您可以先购买一部分流量，再看看 Gologin 代理是否满足您的需求。

### 为什么有些端口在 Gologin 代理上无法使用？

可确保正常使用的端口是 80 和 443，它们是常规网站流量的标准端口。

其他端口主要被用于发送垃圾邮件、DDoS 攻击和暴力破解，因此已被屏蔽。

## 专用 IP

### ISP 代理、静态代理和专用 IP 有什么区别？

没有区别，它们只是同一种服务的三种叫法，您可能会在网上看到这三种说法。在 Gologin 中，该功能称为**专用 IP**。

### 什么是专用 IP？

专用 IP 是仅为您保留、不与他人共用的单个 IP 地址。它来自真实的互联网服务提供商，但托管在数据中心，因此既具备数据中心代理的速度和稳定性，又能让网站将其识别为普通的家庭网络连接。它不会轮换，也没有流量限制。

### 我订阅的是年度套餐，为什么被收取了超过 \$5 的费用？

专用 IP 与您的主订阅绑定，并且始终随主订阅一同到期，因此您需要为剩余的月数付费。如果您的年度套餐还剩 7 个月，则需预先支付 \$35。不足一个月的部分按整月计费。

### 我已经付款，但找不到我的专用 IP 代理

将地址分配到您的账户需要 5-7 分钟，并且准备就绪时不会有通知。请等待几分钟，然后刷新**代理**页面，即可看到该地址。

### 专用 IP 会消耗我套餐中的代理流量吗？

不会。通过专用 IP 产生的流量不限量，也不占用您的 GB 流量额度。即使您的流量额度完全用完，使用专用 IP 的档案也可以继续正常使用。

### 如果我有专用 IP，还需要代理流量吗？

只有使用我们的轮换代理的档案才需要。如果您运行的所有档案都使用专用 IP，那么您的流量额度将不会被使用。

### 使用专用 IP 时，我的 IP 会保持不变吗？

会。只要您的订阅处于有效状态并持续续订，您就可以一直使用同一个地址。

### 我使用加密货币付款，专用 IP 会续订吗？

不会。加密货币付款无法自动续订，因此该 IP 仅在您已付费的期限内有效，到期后将停止使用，之后您也无法再获得同一个地址。如果您想长期保留某个地址，请使用银行卡付款。
