## 按流量计费的代理

### 如何选择代理类型？

要为新连接选择代理类型，只需创建一个新的代理服务器：点击 **配置文件中的“选择位置或代理” \> 国家旁边的箭头 \> 添加新服务器 \> 选择代理类型**。

### 我需要多少流量？

所需流量取决于你的使用场景，主要受以下因素影响：

- 你使用浏览器配置文件的频率
- 每次会话持续的时间
- 你在工作时加载的大体积内容（如视频、图片或音频）的多少

### 代理流量用完后会怎样？我会被检测到吗？

如果流量在使用过程中耗尽，Gologin 会直接断开你的配置文件与互联网的连接，在你充值流量或改用第三方代理之前，将无法继续使用这些配置文件。你仍然可以关闭配置文件且不会丢失数据，因为配置文件同步不会消耗代理流量。

### 如果我使用自己的第三方代理，会消耗 Gologin 代理流量吗？

当然不会！只有使用我们的代理时，才会消耗 Gologin 代理流量。

### 注册试用套餐后，我能获得免费的 Gologin 代理试用流量吗？

目前，Gologin 不会向新注册用户提供试用流量。你可以随时购买一些流量，看看 Gologin 代理是否满足你的需求。

### 为什么 Gologin 代理上有些端口无法使用？

确保可用的端口是 80 和 443，它们是普通网站流量使用的标准端口。

其他所有端口都已被屏蔽，因为它们多被用于发送垃圾邮件、DDoS 攻击和暴力破解。

### Gologin 代理需要用户名和密码吗？

需要。Gologin 代理始终使用用户名和密码。如果你复制 Gologin 代理到其他地方使用，请复制全部凭据，否则代理检测会失败。

### 我购买的流量什么时候可以使用？

付款成功后立即可用。

### Gologin 代理支持 SOCKS5 吗？

支持。请在配置文件的代理设置中选择协议，详见[选择代理协议](/zh/proxy/gologin-proxies/gologin-proxy-management/gologin-proxy-settings#choosing-the-proxy-protocol-http-or-socks5)。

### 我可以将 Gologin 代理用于银行或支付网站吗？

Gologin 按流量计费的代理不适用于银行和支付网站，例如 Stripe 或 PayPal。请使用支持这些网站的第三方代理。详见[银行和支付网站](/zh/proxy/gologin-proxies/what-are-gologin-proxies#banking-and-payment-websites)。

## 专用 IP

### ISP 代理、静态代理和专用 IP 有什么区别？

没有区别，它们是同一事物的三种叫法，你可能会在网上看到这些不同的说法。在 Gologin 中，该功能称为 **专用 IP**。

### 什么是专用 IP？

专用 IP 是仅供你一人使用的单个 IP 地址。它来自真实的互联网服务提供商，但托管在数据中心，因此既具备数据中心代理的速度和稳定性，在网站看来又像普通的家庭网络连接。它不会轮换，也没有流量限制。

### 我使用的是年度套餐，为什么被收取了超过 \$5 的费用？

专用 IP 与你的主订阅绑定，并且始终随主订阅结束而结束，因此你需要为剩余的月数付费。如果你的年度套餐还剩 7 个月，就会预先收取 \$35。不足一个月的部分按一个月计费。

### 我已付款，但在任何地方都看不到我的专用 IP 代理

地址分配到你的账户需要 5-7 分钟，准备就绪时不会有通知。请等待几分钟后刷新 **代理** 页面，它就会出现。

### 专用 IP 会消耗我套餐中的代理流量吗？

不会。通过专用 IP 的流量不受限制，也不会占用你的 GB 流量额度。即使你的流量额度完全用完，使用专用 IP 的配置文件仍可继续正常工作。

### 如果我有专用 IP，还需要代理流量吗？

只有使用我们的轮换代理的配置文件才需要。如果你运行的所有配置文件都使用专用 IP，你的流量额度就只是闲置。

### 使用专用 IP 时，我的 IP 会保持不变吗？

会。只要你的订阅处于有效状态并持续续订，你就会一直使用同一个地址。

### 我使用加密货币付款，专用 IP 会续订吗？

不会。加密货币付款无法自动续订，因此该 IP 只在你已付款的期限内有效，之后将停止使用，并且你之后无法重新获得同一个地址。如果你想长期保留某个地址，请使用银行卡付款。
