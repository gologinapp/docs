---
title: "为什么不用 VPN 来运行浏览器配置文件？"
---

很多人会把 VPN 和代理混为一谈，因为二者都会改变你对外显示的 IP 地址。但它们的工作方式不同，在多账号场景下，这种差异非常关键。

|  | VPN | 代理 |
| :-- | :-- | :-- |
| 更改 IP | ✅ | ✅ |
| 更改浏览器指纹 | ❌ | ❌ |
| 整台设备共用一个 IP | ✅ | ❌ |
| 每个浏览器配置文件一个 IP | ❌ | ✅ |
| 可在 Gologin 中使用 | ❌ | ✅ |
| 被 Facebook / LinkedIn 检测到 | 经常 | 很少（住宅代理） |

## VPN 的工作原理

VPN 会加密你设备上的所有流量，并通过单一服务器转发。你电脑上的所有应用——浏览器、Slack、Spotify 等——都共用同一个 IP 地址。

这对保护隐私和绕过地区限制很有用，但在多账号场景下会带来两个问题：

**问题 1——所有配置文件共用一个 IP。** 如果你有 10 个浏览器配置文件，它们看起来都来自同一个 IP 地址。Facebook、LinkedIn 等平台会发现同一地点出现多个账号，并将这些账号关联起来。

**问题 2——VPN 不会更改浏览器指纹。** 平台追踪的远不止 IP。它们还会读取你的屏幕分辨率、字体、显卡、时区以及数十种其他信号。VPN 不会更改其中任何一项，而 Gologin 配置文件会全部更改。

## 代理的工作原理

代理会分配给某一个特定的浏览器配置文件。该配置文件的流量会经过代理，而你电脑上的其他程序不受影响。

这意味着：

- 配置文件 A → 纽约的代理 → 看起来像是位于纽约的真实设备
- 配置文件 B → 伦敦的代理 → 看起来像是位于伦敦的另一台完全不同的设备
- 你的真实电脑 → 不使用代理 → 使用你正常的 IP

每个配置文件都拥有各自独立的网络身份。再结合 Gologin 为每个配置文件生成的独特指纹，平台看到的就是真正相互独立的设备。

## 为什么 VPN 不适合多账号管理

与住宅代理相比，平台也更容易识别 VPN。VPN 服务器的 IP 广为人知，并且出现在各种黑名单中。许多平台（Facebook、LinkedIn、PayPal 以及大多数博彩网站）会明确封锁或标记 VPN 的 IP。

## VPN 仍然适用的场景

在以下情况下，使用 VPN 是没问题的：

- 访问在你所在国家被地区限制的网站
- 在公共 Wi-Fi 下保护你的真实 IP
- 通过其他国家的 IP 地址使用单个账号
- 你的网络在连接 Gologin 服务或代理时遇到问题

但 VPN 并不能取代 Gologin 中的代理。
