title: "连接 LinkedIn 账户"
description: "使用密码、Cookies 或 Gologin 配置文件连接 LinkedIn 账户,选择 IP 所在国家,并在同一窗口中通过 LinkedIn 的验证。"
---

每个 LinkedIn 账户只需连接一次。之后它会保持登录状态,并在云端持续运行。

## 连接账户

1. 打开 **Accounts**,然后点击 **Connect account**。
2. **选择网络。** 目前支持 LinkedIn。
3. **选择 IP 的来源:**
   - **专用 IP**:可选国家包括巴西、法国、德国、中国香港、印度、印度尼西亚、罗马尼亚、韩国、土耳其、英国或美国。该列表可能会变化。
   - **您自己的代理。** 输入代理信息,点击 **检查代理**,然后点击 **Use this proxy**。
4. **通过以下三种方式之一登录 LinkedIn:**
   - **Credentials**:账户的电子邮箱和密码。密码会被加密存储,仅用于日后恢复会话。
   - **饼干**:来自您已登录 LinkedIn 的浏览器中的 `li_at` Cookie。无需提供密码。
   - **Gologin profile**:一个已登录 LinkedIn 的 Gologin 配置文件。无需重新登录,账户将使用该配置文件自带的代理。
5. 如需导入您已有的 LinkedIn 对话,请勾选 **Import existing conversations**。否则,只会存储连接之后产生的对话。
6. 点击 **登录**。Gologin 会分配一个专用 IP,为该账户创建浏览器配置文件,并登录 LinkedIn。

<Tip>
  要复制 `li_at` Cookie,请在已登录 LinkedIn 的浏览器中打开 LinkedIn,按 **F12**,依次进入 **Application** > **Cookies** > **https://www.linkedin.com**(在 Firefox 中:**存储** > **饼干**),然后复制 `li_at` 的值。
</Tip>

## 通过 LinkedIn 验证

LinkedIn 可能会要求您确认是本人操作。您可以在同一窗口中完成:

- **邮箱验证码**:输入 LinkedIn 发送到账户邮箱的验证码。
- **身份验证器应用**:输入 Google Authenticator 或类似应用中的验证码。
- **电话号码**:输入电话号码。LinkedIn 通常会向该号码发送验证码。
- **LinkedIn 应用**:在手机上的 LinkedIn 应用中确认登录。窗口会自动继续。

CAPTCHA 会被自动解决。如果 LinkedIn 显示无法自动通过的验证,系统会打开一个浏览器窗口,供您自行完成验证。

每项验证最长等待 10 分钟。如果未在时限内输入验证码或确认登录,请重新登录。

如果您看到 **LinkedIn asked for an extra check we can't complete here, sign in with cookies instead**,请使用 `li_at` Cookie 连接该账户。

## 账户状态

| 状态 | 含义 |
| :-- | :-- |
| **Active** | 账户已登录并正常运行。 |
| **Needs action** | 您需要进行操作:输入验证码、确认登录、通过 LinkedIn 验证或重新登录。原因会显示在状态下方。 |
| **Restricted** | LinkedIn 已限制该账户。请在 linkedin.com 上查看。 |
| **暂停** | 您已断开该账户的连接。 |

状态下方常见的原因:

| 原因 | 处理方法 |
| :-- | :-- |
| Wrong password · retry login | 使用正确的密码重新登录,或改用 Cookies。 |
| Session expired · log in again | LinkedIn 已结束该会话。请使用密码或新的 Cookies 重新登录。 |
| LinkedIn asked for a checkpoint | 在 linkedin.com 上通过验证,然后使用新的 Cookies 重新登录。 |
| Verification code expired | 未在 10 分钟内输入验证码。请重新登录并使用新的验证码。 |
| Not confirmed in the LinkedIn app in time | 请重新登录,并在 LinkedIn 应用中确认登录。 |
| No dedicated IP available | 请选择其他国家,或使用您自己的代理。 |
| Already connected in this workspace | 该 LinkedIn 账户已在您的列表中。 |
| LinkedIn has restricted this account | 请在 linkedin.com 上查看该账户。 |

## 断开或删除账户

- **断开连接。** 从该账户运行的任务会停止。账户仍保留在您的列表中,并继续占用席位,直到您重新连接。
- **删除。** 账户、其聊天记录和历史记录会被永久删除。从该账户运行的任务会停止,其席位将释放给其他账户使用。
