title: "连接 LinkedIn 账号"
description: "使用密码、Cookies 或 Gologin 配置文件连接 LinkedIn 账号,选择 IP 所在国家,并在同一窗口中通过 LinkedIn 的验证。"
---

每个 LinkedIn 账号只需连接一次。之后它会保持登录状态,并在云端持续运行。

## 连接账号

1. 打开 **Accounts**,点击 **Connect account**。
2. **选择网络。** 目前支持 LinkedIn。
3. **选择 IP 的来源:**
   - **专用 IP**,可选国家包括:巴西、法国、德国、中国香港、印度、印度尼西亚、罗马尼亚、韩国、土耳其、英国或美国。该列表可能会变化。
   - **您自己的代理。** 输入代理信息,点击 **检查代理**,然后点击 **Use this proxy**。
4. **通过以下三种方式之一登录 LinkedIn:**
   - **Credentials** - 账号的邮箱和密码。密码会加密存储,仅用于日后恢复会话。
   - **饼干** - 来自已登录 LinkedIn 的浏览器的 `li_at` Cookie。无需提供密码。
   - **Gologin profile** - 一个已登录 LinkedIn 的 Gologin 配置文件。无需重新登录,该账号将使用该配置文件自带的代理。
5. 如需导入已有的 LinkedIn 对话,请勾选 **Import existing conversations**。否则,只会保存连接之后产生的对话。
6. 点击 **登录**。Gologin 会分配专用 IP,为该账号创建浏览器配置文件,并登录 LinkedIn。

<Tip>
  要复制 `li_at` Cookie,请在已登录 LinkedIn 的浏览器中打开 LinkedIn,按 **F12**,依次进入 **Application** > **Cookies** > **https://www.linkedin.com**(在 Firefox 中:**存储** > **饼干**),然后复制 `li_at` 的值。
</Tip>

## 通过 LinkedIn 验证

LinkedIn 可能会要求您确认是本人操作。您可以在同一窗口中完成:

- **邮箱验证码** - 输入 LinkedIn 发送到账号邮箱的验证码。
- **验证器应用** - 输入 Google Authenticator 或类似应用中的验证码。
- **电话号码** - 输入手机号码。LinkedIn 通常会向该号码发送验证码。
- **LinkedIn 应用** - 在手机上的 LinkedIn 应用中确认登录。窗口会自动继续。

如果 LinkedIn 显示需要真人完成的验证,系统会打开一个浏览器窗口,供您亲自通过验证。

每项验证最多等待 10 分钟。如果未在规定时间内输入验证码或确认登录,请重新登录。

如果您看到 **LinkedIn asked for an extra check we can't complete here, sign in with cookies instead**,请使用 `li_at` Cookie 连接账号。

## 账号状态

| 状态 | 含义 |
| :-- | :-- |
| **Active** | 账号已登录并正常运行。 |
| **Needs action** | 您需要进行操作:输入验证码、确认登录、通过 LinkedIn 验证或重新登录。原因会显示在状态下方。 |
| **Restricted** | LinkedIn 已限制该账号。请在 linkedin.com 上查看。 |
| **暂停** | 您已断开该账号的连接。 |

状态下方的常见原因:

| 原因 | 处理方法 |
| :-- | :-- |
| Wrong password · retry login | 使用正确的密码重新登录,或改用 Cookies。 |
| Session expired · log in again | LinkedIn 已结束该会话。请使用密码或最新的 Cookies 重新登录。 |
| LinkedIn asked for a checkpoint | 在 linkedin.com 上通过验证,然后使用最新的 Cookies 重新登录。 |
| Verification code expired | 未在 10 分钟内输入验证码。请重新登录并使用新的验证码。 |
| Not confirmed in the LinkedIn app in time | 重新登录,并在 LinkedIn 应用中确认登录。 |
| No dedicated IP available | 选择其他国家,或使用您自己的代理。 |
| Already connected in this workspace | 此 LinkedIn 账号已在您的列表中。 |
| LinkedIn has restricted this account | 请在 linkedin.com 上查看该账号。 |

## 断开或删除账号

- **断开连接。** 由该账号运行的任务将停止。账号仍保留在您的列表中并占用席位,直到您重新连接。
- **删除。** 账号及其聊天和历史记录将被永久删除。由该账号运行的任务将停止,其席位会释放给其他账号使用。
