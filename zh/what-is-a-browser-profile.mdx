---
title: "什么是浏览器配置文件"
---

Gologin 中的**浏览器配置文件**是一个独立的虚拟浏览器。它的外观和行为与安装在真实电脑上的真实浏览器完全一致,但它存在于 Gologin 中,可以在几秒钟内创建、保存、切换或删除。

每个配置文件都有自己独立的:

- 唯一的浏览器[指纹](/zh/how-browser-fingerprints-work)(下文会详细介绍)
- Cookie 和本地存储
- 浏览历史
- 已保存的密码和扩展程序
- 代理连接

打开配置文件时,网站会把它视为来自另一台设备的完全独立的访问者。关闭配置文件时,所有内容都会按照你离开时的状态原样保存。

## 为什么这很重要?了解浏览器指纹

在深入了解配置文件之前,你需要先理解一个概念:**浏览器指纹**。

每次访问网站时,你的浏览器都会悄悄向网站发送数十项有关你的设备和设置的技术信号,例如:

- 你使用的浏览器及其版本
- 你的操作系统
- 屏幕分辨率
- 你电脑上安装的字体
- 你的时区和语言
- 你的显卡如何渲染图像
- 你是否使用触摸屏

网站会收集所有这些信号,并将它们组合成一个唯一的“指纹”来识别你——即使你清除了 Cookie、使用了 VPN 或打开了无痕窗口,也无法避免。

<Note>
  无痕模式只会向使用同一台电脑的其他人隐藏你的浏览历史,**不会**向网站隐藏你的浏览器指纹。在外界看来,每个无痕窗口与你平时使用的浏览器仍然完全一样。
</Note>

这就是为什么仅仅在不同标签页中使用多个账号是行不通的。所有这些标签页共用同一个指纹,网站可以判断出它们属于同一个人。

## Gologin 配置文件如何解决这个问题

在 Gologin 中创建浏览器配置文件时,应用会从零开始构建一个完整的、虚构但可信的浏览器身份。

Gologin 会为每个指纹参数生成逼真的值——合理的屏幕尺寸、可信的字体组合、一致的时区、匹配的 User Agent 字符串等等。所有这些值都保存在配置文件中,并在你使用该配置文件访问任何网站时提供给对方。

## 配置文件的存储方式

Gologin 将你的配置文件存储在云端。这意味着:

- 你可以在任何安装了 Gologin 的电脑上打开任意配置文件
- 即使本地电脑崩溃或被更换,配置文件也不会丢失
- 你可以与团队成员共享配置文件,他们无需重新登录即可使用同一个已保存的会话

## 配置文件与无痕窗口的区别

|  | 无痕窗口 | Gologin 配置文件 |
| --- | --- | --- |
| 在本地隐藏浏览历史 | ✅ | ✅ |
| 关闭时清除 Cookie | ✅ | ❌(Cookie 会被保存) |
| 更改你的浏览器指纹 | ❌ | ✅ |
| 更改你的 IP 地址 | ❌ | ✅(需配合代理) |
| 可以保存并重新打开 | ❌ | ✅ |
| 看起来像另一台设备 | ❌ | ✅ |

无痕模式是针对本地设备的隐私工具,而 Gologin 配置文件则是在互联网上完整替换你的身份。

## 总结

Gologin 中的浏览器配置文件是一个已保存的虚拟浏览器,拥有自己的指纹、Cookie 和代理。打开配置文件后,在你访问的任何网站看来,你就像是另一台设备上的另一个人。关闭配置文件会保存你的会话,方便你随时回来继续使用。这样,你就可以在一台电脑上管理多个相互独立的网络身份——干净、安全,并且这些账号之间不会相互关联,也不会关联到你本人。
