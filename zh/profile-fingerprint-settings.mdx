---
title: "配置文件指纹设置"
---

Gologin 允许您在创建或编辑浏览器配置文件时配置指纹参数。

这些设置决定了您的浏览器配置文件在网站和反欺诈系统眼中的呈现方式。

网站会从浏览器环境中收集多种技术信号,并将它们组合成用于识别设备的**浏览器指纹**。

Gologin 中的指纹设置分为以下几个类别。

## Navigator 指纹

Navigator 参数用于描述浏览器和设备的整体环境。

网站通过 `navigator.userAgent` 和 `navigator.platform` 等 JavaScript API 读取这些值。

常见的 Navigator 参数包括:

- **用户代理** – 标识浏览器类型、版本和操作系统
- **轨道版** – 配置文件使用的 Chromium 版本
- **屏幕分辨率** – 向网站报告的屏幕尺寸
- **语言** – 浏览器的首选语言
- **平台** – 操作系统平台
- **CPU 线程** – 向浏览器报告的处理器核心数量
- **RAM** – 设备可用内存
- **不跟踪** – 隐私偏好信号

这些参数可帮助网站判断所使用的设备类型。

## 字体

浏览器环境中安装的字体是另一种指纹信号。

网站可以通过测量文本在页面上的渲染效果来检测字体。不同的操作系统和设备拥有不同的字体集合,这有助于区分设备。

Gologin 可以屏蔽字体列表,生成与所选操作系统相匹配的真实字体组合。

## 媒体设备

媒体设备设置用于定义网站可见的摄像头、麦克风和音频输出设备。

网站可以通过 `navigator.mediaDevices` API 获取这些信息。

Gologin 允许您屏蔽:

- 视频输入
- 音频输入
- 音频输出

这有助于防止网站识别您真实的硬件配置。

## 硬件指纹

与硬件相关的信号为浏览器指纹识别提供了更多的特征信息。

这些参数包括图形和音频渲染特征。

### Canvas

Canvas API 允许网站在浏览器中绘制隐藏图像。\
由于不同设备的渲染结果存在细微差异,生成的图像可以被转换为哈希值并用于指纹识别。

### WebGL

WebGL 会暴露设备所使用的图形硬件信息。

网站可能会检查 WebGL 报告,或渲染一个隐藏的 3D 对象来生成指纹。

### AudioContext

音频指纹利用音频处理上的差异来生成唯一的哈希值。

### ClientRects

此方法通过测量元素在页面上的位置和渲染方式来识别设备。

Gologin 允许您修改或屏蔽这些信号,为每个配置文件生成稳定且唯一的指纹。

## WebRTC

WebRTC 是浏览器中用于实时通信的技术。

但是,它可能会向网站暴露本地 IP 或真实 IP 地址。

Gologin 允许您控制 WebRTC 的行为:

- **基于IP** – WebRTC 报告代理 IP
- **关闭** – 禁用 WebRTC

这有助于防止 IP 泄露,并使指纹与代理所在位置保持一致。

## 最佳实践

为了保持浏览器身份的稳定:

- 账号创建后,保持指纹设置不变
- 使时区和语言与代理所在位置相匹配
- 避免频繁更改与硬件相关的参数
- 为每个配置文件使用专用代理

稳定的指纹可以让网站将该配置文件识别为一台始终如一的设备。

## 如何验证您的指纹

启动配置文件后,访问以下网站之一来检查您的指纹:

- [**iphey.com**](https://iphey.com) -- 显示整体信任评分。绿色的“Trusted”结果表示您的配置文件看起来像一个真实的浏览器。
- [**pixelscan.net**](https://pixelscan.net) -- 对各项指纹参数进行详细分析。

### 常见问题及其含义

| 问题 | 含义 | 解决方法 |
| --- | --- | --- |
| 操作系统不匹配 | 配置文件的操作系统与您真实设备的操作系统不一致 | 创建一个与您实际操作系统相匹配的新配置文件 |
| WebGL 不匹配 | GPU 信息与声明的硬件不一致 | 通常会自动正确配置。如果被标记,请尝试在配置文件设置中使用其他 WebGL 模式。 |
| 时区不匹配 | 时区与代理所在位置不一致 | Gologin 会自动将时区与代理 IP 匹配。如果不正确,请检查您的代理所在位置。 |
| Canvas 哈希值发生变化 | 不同会话之间的 Canvas 指纹不一致 | 为了在不同设备间保持一致,请将 Canvas 设置为“关闭”或“阻止”,而不是“添加噪点” |
