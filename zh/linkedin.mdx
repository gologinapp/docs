title: "LinkedIn"

使用 Gologin 管理 LinkedIn 账号的实用指南，涵盖获客、外联、养号和团队访问。

在 Gologin 生态中，LinkedIn 是对安全性最敏感的平台之一。它对登录模式、IP 一致性和设备指纹的监控比大多数社交网络更严格。出现可疑信号的账号会很快被限制，有时甚至没有任何提示。

## 快速检查清单

开始之前：

- 1 个账号 = 1 个浏览器配置文件
- 1 个配置文件 = 1 个静态住宅或移动代理人
- 不要更换已使用过的配置文件的代理人
- 配置文件的操作系统要与你设备的操作系统一致
- 不要同时在两台设备上打开同一个配置文件

## 第 1 步：选择合适的代理人

LinkedIn 对 IP 变化高度敏感。请使用静态住宅代理人或静态移动代理人，即在各次会话中保持不变的专用 IP。

<Warning>
  对于你重视的 LinkedIn 账号，请不要使用轮换代理人、数据中心代理人或 Gologin 内置的代理人。会话之间 IP 发生变化，会立即触发安全审查，并且通常会导致会话被登出。
</Warning>

如果你和团队成员在同一个城市，可以使用相同国家/城市的代理人位置。如果团队成员分布在不同地区，每个人都应使用与该 LinkedIn 账号所在地理区域相匹配的代理人，而不是团队成员实际所在的位置。

适用于 LinkedIn 的推荐代理人类型：

- 静态住宅代理人（最适合长期账号管理）
- 移动代理人（适合新账号注册和养号）
- ISP 代理人（稳定，信任度尚可）

具体服务请参阅[推荐的代理人服务商](https://gologin.com/best-proxy-server-services/)。

## 第 2 步：设置你的 Gologin 配置文件

为每个 LinkedIn 账号创建一个新的配置文件。

推荐设置：

- **操作系统**：与你的设备一致（Windows 设备选择 Windows，Mac 设备选择 Mac）
- **代理人**：在首次登录前分配好你的静态代理人
- **指纹**：保持默认设置，除非有特殊原因，否则不要自定义 WebGL、Canvas 或 AudioContext

在配置文件中登录 LinkedIn 之后，**请不要更改代理人或指纹设置。** LinkedIn 会在服务器端存储设备信息，指纹一旦改变，就像是一台全新的设备在尝试访问该账号。

## 第 3 步：为新账号养号

刚注册的 LinkedIn 新账号如果立即发送好友请求或消息，很快就会被限制。LinkedIn 期望新账号表现得像真实用户一样：浏览、阅读，并逐步建立个人形象。

养号时间表：

| 时间 | 操作 |
| :-- | :-- |
| 第 0 天 | 完善资料：头像、标题、简介、工作经历 |
| 第 1-7 天 | 浏览动态、查看他人主页、关注几家公司 |
| 第 8-14 天 | 点赞并评论帖子，暂不进行外联 |
| 第 3 周 | 向你“认识”的人发送 5–10 个好友请求 |
| 第 4 周\+ | 开始逐步外联，缓慢提高上限 |

安全的活动量

| **操作** | **建议水平** |
| :-- | :-- |
| 点赞 / 赞同 | 每天 10–20 次 |
| 评论 | 每天 2–3 条 |
| 发帖 / 回答 | 偶尔进行 |
| 加入社群 | 循序渐进 |

以上均为保守估计。LinkedIn 的实际限制会因账号年龄、活动历史和订阅类型而异。

## 第 4 步：避免常见封号原因

以下行为会立即触发 LinkedIn 的限制：

- 账号已活跃后，从新的 IP 登录（请使用静态代理人）
- 同时在两台设备上打开同一个配置文件
- 短时间内向大量用户发送相同的消息
- 在同一天创建多个账号，并使用相同的配置文件设置模式
- 使用无法保持会话一致性的自动化工具（见下方自动化部分）

以下行为会逐渐触发限制：

- 发送大量好友请求但通过率很低
- 查看大量主页却没有互动
- 在多个账号上发布相同的内容
- 账号数周没有任何活动，随后突然大量外联

## 第 5 步：与团队共享访问权限

要让团队成员在 Gologin 中访问某个 LinkedIn 账号：

1. 使用**配置文件共享**将配置文件共享给对方（对方需要有一个免费的 Gologin 账号）
2. 如果对方只需要打开并使用该配置文件，请分配角色 \*\*可以运行\*\*
3. 如果对方还需要修改设置，请分配**可以编辑**

<Warning>
  同一时间只应有一个人在某个 LinkedIn 配置文件中操作。LinkedIn 会检测到来自不同位置的并发会话，并将两个会话都登出或触发安全验证。
</Warning>

详细步骤请参阅[ 共享配置文件](https://gologin.com/docs/general/team-collaboration/sharing-profiles)。

## 自动化工具

Gologin 与常见的 LinkedIn 自动化工具兼容。关键要求是自动化必须在 Gologin 配置文件内部运行，而不是作为普通 Chrome 窗口中的独立浏览器扩展。

兼容的方式：

- 将自动化工具作为 Chrome 扩展安装在 Gologin 配置文件内运行
- 使用 Gologin 的 API 启动配置文件，然后将自动化工具连接到正在运行的浏览器会话

不兼容的方式：

- 在普通 Chrome 窗口中运行自动化，同时又使用 Gologin（两者的会话相互独立，可能产生冲突）
- 使用会在 Gologin 之外自行打开浏览器的自动化工具

自动化操作应始终遵守 LinkedIn 的每日限制。不经养号就进行大批量自动化，是账号被限制的最快途径。

## 从其他防关联浏览器迁移配置文件

如果你正从 Dolphin Anty、Multilogin 或其他防关联浏览器迁移，浏览器配置文件数据（饼干、会话、本地存储）可以导出并导入到 Gologin。

步骤：

1. 从现有的防关联浏览器中导出饼干（大多数支持 JSON 导出）
2. 在 Gologin 中打开目标配置文件，进入**饼干**
3. 导入饼干文件

这样可以保留你的 LinkedIn 会话，无需重新登录。指纹会有所不同（Gologin 会生成自己的指纹），但只要代理人 IP 保持不变，LinkedIn 通常会将该会话视为同一台设备。

## LinkedIn 为什么会登出会话

LinkedIn 会话被登出几乎总是由以下原因之一造成：

- 代理人 IP 发生变化：即使是很小的 IP 变化也会触发安全审查
- 在不同的操作系统上打开配置文件：指纹不一致
- 在两台设备上同时打开配置文件：检测到并发会话
- 长时间不活动后突然活跃：看起来像账号被盗用
- 检测到自动化：操作模式异常，速度不像真人

如果你经常被登出，请首先检查你的代理人：静态与轮换的区别是最常见的原因。
