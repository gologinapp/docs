加密货币交易所和钱包(Binance、Coinbase、Kraken 等)会通过身份验证(KYC)将每个账户与真实用户绑定。验证通过后,交易所会持续关注您的登录地点和登录方式,因此 IP 或设备的突然变化可能触发安全审查、额外验证,甚至导致账户被冻结。

<Warning>
  请仅使用您本人的身份证件完成验证。使用他人的身份或证件是被[可接受使用政策](https://gologin.com/acceptable-use-policy/)所禁止的。
</Warning>

## 快速检查清单

- 1 个账户 = 1 个浏览器配置文件
- 1 个配置文件 = 1 个静态住宅代理
- 保持代理所在地不变,尤其是在验证通过之后
- 身份验证通过后,请勿更改指纹或代理

## Gologin 配置文件设置

- **代理:**静态住宅代理,每次会话使用相同的 IP
- **代理位置:**您居住且与证件一致的国家

<Warning>
  在交易所通过验证后,请勿更改该配置文件的代理。交易所会记住您验证时所用的设备和 IP,下次登录时如果 IP 或指纹不同,可能会被视为账户被盗用。
</Warning>

## 新账户的前几周

| **时间段** | **重点** | **操作内容** |
| :-- | :-- | :-- |
| 第 0 天 | 注册 | 创建账户并确认邮箱 |
| 第 1–3 天 | 验证 | 提交身份证件并完成验证 |
| 第 4–7 天 | 熟悉平台 | 浏览平台和交易界面 |
| 第 2 周 | 小额交易 | 存入少量资金,进行 1–2 笔交易 |
| 第 3 周\+ | 正常使用 | 保持常规交易活动 |

## 哪些情况会触发安全检查

- 验证后 IP 发生变化,即使仍在同一个国家
- 不同会话之间设备指纹不一致
- 账户创建后立即存入大额资金
