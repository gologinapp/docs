---
title: "加密货币与 KYC 平台"
---

加密货币平台分为两类:一类是交易所和钱包(Binance、Coinbase、Kraken),这类平台通过 KYC 将账户与真实身份绑定;另一类是空投/撸毛平台(Galxe、Zealy、Layer3、Premint),这类平台的目标是在多个活动中管理多个账户。

## 快速检查清单

- 1 个账户 = 1 个浏览器配置文件
- 1 个配置文件 = 1 个静态住宅代理
- 保持代理所在地一致,尤其是在完成 KYC 之后
- 身份验证完成后,不要更改指纹或代理
- 对于撸毛:将账户视为一次性账户,不要把撸毛账户与真实的交易所账户混用

## 交易所与 KYC 平台

完成 KYC 后,一致性至关重要。从新 IP 登录或指纹发生变化,会触发安全审查、额外验证或账户冻结。

### Gologin 配置文件设置

- \*\*代理:\*\* 静态住宅代理,每次会话使用同一个 IP
- \*\*代理所在地:\*\* 尽可能与身份证件上的国家一致

<Warning>
  在加密货币交易所完成 KYC 后,切勿更改 Gologin 配置文件上的代理。交易所会记录你在验证时的设备环境。下次登录时如果 IP 或指纹不同,会被视为账户被盗用。
</Warning>

## 养号时间表

| **阶段** | **重点** | **操作内容** |
| :-- | :-- | :-- |
| 第 0 天 | 注册 | 创建账户 \+ 邮箱验证 |
| 第 1–3 天 | KYC | 提交身份证件,完成验证 |
| 第 4–7 天 | 熟悉平台 | 浏览平台,了解交易界面 |
| 第 2 周 | 小额交易 | 小额充值,进行 1–2 笔交易 |
| 第 3 周\+ | 正常使用 | 保持常规交易活动 |

### 常见封号触发因素:交易所

- KYC 后 IP 发生变化(即使在同一国家、不同城市)
- 不同会话之间设备指纹不一致
- 账户创建后立即大额充值
- 多个账户使用相同的支付方式或银行账户

## 空投与积分撸毛(Galxe、Zealy、Premint、Layer3)

Web3 活动(空投、任务、积分计划)通常每人只允许参与一次。在这类场景中,Gologin 用于管理多个合规账户(例如团队中每位成员各自独立参与),同时在技术层面保持这些账户相互隔离。

### **平台如何检测关联账户**

平台使用两类信号:

浏览器和网络信号(Gologin 可以处理的部分):

- 多个账户使用相同的 IP 地址
- 相同的浏览器指纹
- 多个账户在同一环境中于相同时间完成任务

链上信号(不在 Gologin 的处理范围内):

- 区块链是公开的,所有交易都永久可见
- 如果多个钱包地址从同一个来源钱包收到资金,它们在链上很容易被关联
- 平台在分发代币之前,会使用 Nansen 或 Arkham 等工具分析钱包之间的关系

Gologin 隔离的是浏览器环境和 IP。链上钱包关系是另一个问题,需要每位用户根据自己的设置和平台规则自行管理。

### 多账户活动的 Gologin 设置

如果你代表多位团队成员管理账户,每个人都应该拥有:

- 一个专属的 Gologin 配置文件
- 一个独立的住宅代理
- 自己连接的钱包,不要使用团队共用钱包为其充值

### 大规模管理

对于在多个活动中拥有 10\+ 个账户的团队:

- 在 Gologin 中按活动或团队成员用文件夹整理配置文件
- 使用标签跟踪状态(进行中、已完成、待处理)
- 使用 Gologin API 以编程方式启动和管理配置文件
- 记录每个配置文件对应的团队成员和钱包
