---
title: "代理协议"
---

HTTP/HTTPS 和 SOCKS 协议适用于大多数网站，但对于设有高级反机器人措施的网站，支持 UDP 的 SOCKS5 代理因其通用性更强，通常是更好的选择。

Gologin 支持最常见的代理协议。

### HTTP / HTTPS

- HTTP 代理广泛用于普通网页流量。
- HTTPS 代理支持使用 SSL/TLS 的加密连接，常用于安全浏览。

### SOCKS4 / SOCKS5

- SOCKS 代理支持更广泛的网络协议。
- SOCKS5 是最灵活的选项，同时支持 TCP 和 UDP 连接。
- 因此，SOCKS5 代理通常更适合用于自动化和数据抓取任务。
