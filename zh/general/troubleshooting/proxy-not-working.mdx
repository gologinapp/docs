## 代理故障排查步骤

如果您的代理在 Gologin 中无法使用，请按顺序执行以下步骤，以找出并解决问题。

### 1. 查看完整的错误信息

在浏览器配置文件设置中，将鼠标悬停在代理字段旁边的错误图标（红色或黄色图标）上。Gologin 会在悬停时显示完整的错误信息，其中通常包含连接失败原因的具体说明。

### 2. 确认代理在 Gologin 之外可以正常使用

单独测试您的代理，确认它是否可用：

- 使用在线代理检测工具。
- 在普通浏览器中配置该代理（通过 FoxyProxy 等代理扩展），然后尝试打开网站。

如果代理在 Gologin 之外同样无法使用，说明问题出在代理本身——请联系您的代理服务商。

### 3. 更换网络

部分网络会屏蔽代理流量。请尝试以下方法之一：

- 将 WiFi 切换为手机热点（或反过来）。
- 在启动配置文件之前，先在设备上开启 VPN。

如果代理在其他网络下可以正常使用，则说明原来的网络很可能拦截了该连接。

### 4. 在网页版上测试

尝试在 [app.gologin.com](https://app.gologin.com)（网页版/云端版）上启动同一个配置文件。如果配置文件在网页版上可以正常运行，但在桌面应用中不行，则问题出在您的本地环境，而不是代理本身。

### 5. 更新 Gologin

请确保您使用的是最新版本的 Gologin 桌面应用。旧版本可能与某些代理协议或配置存在兼容性问题。请前往 [gologin.com](https://gologin.com) 下载最新版本。

### 6. 使用 SOCKS 代理时检查 DNS 设置

如果您在配置文件中设置了自定义 DNS，请注意，自定义 DNS 仅适用于 **SOCKS4** 和 **SOCKS5** 代理协议。

<Warning>
HTTP 或 HTTPS 代理不支持自定义 DNS 设置。如果您使用的是 HTTP/HTTPS 代理并设置了自定义 DNS，请删除自定义 DNS 配置，或改用 SOCKS 代理。
</Warning>

### 7. 代理可以连接，但位置不正确

如果代理连接成功，但某些网站（尤其是 Google）显示的位置有误，或显示了您的真实位置：

这是因为部分网站会独立于 IP 地址，直接使用浏览器的 **Geolocation API**。即使您的 IP 显示的是另一个位置，Geolocation API 仍可能暴露您的真实位置。

**解决方法：** 在配置文件设置中禁用地理位置。在配置文件的设置中找到“地理位置”选项，将其设置为 **受阻**，或手动设置与代理所在地一致的坐标。

### 8. Gologin 内置代理显示错误

如果您使用的是 Gologin 内置代理，但无法正常使用：

- 尝试在可选项中选择其他代理位置。
- 检查您的 Gologin 代理流量额度是否已用完。您可以在账户设置中查看剩余流量。
- 如果流量已用完，请充值，或改用外部代理服务商。

---

<Warning>
如果以上步骤均无法解决问题，请联系支持团队，并提供以下信息：

- 以 `ip:port:login:password` 格式提供的代理凭据
- 错误信息的截图
- 您的 Gologin 应用版本（可在“设置 > 关于”中查看）
</Warning>
