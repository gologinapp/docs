使用 **Ctrl+F**（Windows）或 **Cmd+F**（macOS）在本页查找您遇到的错误——大多数标题使用的就是错误信息的原文。

## 开始之前

- **查看完整的错误信息。** 将鼠标悬停在资料列表中该资料的 **错误** 状态上，即可查看完整信息。
- **彻底退出应用。** 关闭 Gologin 窗口只会将其隐藏——应用仍会在后台运行。要退出应用，请点击系统托盘中的 Gologin 图标（Windows 位于右下角，macOS 位于菜单栏），然后选择 **退出**。
- **更新 Gologin 和浏览器。** 从 [gologin.com/download](https://gologin.com/download) 下载最新版本并直接覆盖安装——您的资料会被保留。要更新某个资料的浏览器，请点击该资料旁边的三个点，然后选择 **更新浏览器**。
- **联系支持团队？** 请附上资料 ID（资料旁边的三个点 → **复制 ID**）和错误截图。

## 资料启动错误

### "The profile is being run by another user"

**表现：** 资料无法启动并显示此信息，即使看起来没有其他人在使用它。

**原因：** Gologin 不允许同一个资料同时在多台设备上运行，以避免同步冲突以及 Cookie 和会话方面的问题。出现此信息的情况包括：

- 您分享过该资料的人此刻正在使用它；
- Gologin 应用正在安装更新（应用顶部会显示进度条）；
- 该资料最近在另一台设备上关闭——资料关闭后，锁定会在 1-2 分钟内解除；
- 该资料上一次会话未正常关闭。

**解决方法：**

1. 确认您分享过该资料的人没有在使用它，并等待应用更新完成。
2. 点击应用左上角的 Gologin 徽标，然后再次运行该资料。
3. 从系统托盘中彻底退出 Gologin，重新启动后再运行该资料。
4. 如果错误仍然存在，请克隆该资料（资料旁边的三个点 → **克隆**），然后运行副本。

### 资料卡在“下载中”或“归档中”状态

**表现：** 启动资料时状态一直停留在 **下载中**，或者停止资料时一直停留在 **归档中**。

**原因：** Gologin 无法完成资料数据的加载或保存。常见原因包括与 Gologin 服务器的连接被阻止、杀毒软件，或浏览器文件损坏。

**解决方法：**

1. 检查您的网络连接——请参阅下方的[连接错误](#%E8%BF%9E%E6%8E%A5%E9%94%99%E8%AF%AF)。
2. 关闭第三方杀毒软件，或将 Gologin 添加到其例外列表。
3. 从系统托盘中彻底退出 Gologin。
4. 删除浏览器文件夹，让 Gologin 重新下载：
   - **Windows：** `C:\Users\<YourUser>\.gologin\browser`
   - **macOS：** `~/.gologin/browser`（在终端中执行：`rm -r ~/.gologin/browser`）
5. 启动 Gologin（在 Windows 上，右键点击它并选择 **以管理员身份运行**），等待浏览器下载完成，然后运行资料。
6. 如果仍然无法解决，请从 [gologin.com/download](https://gologin.com/download) 重新安装 Gologin。卸载应用前，请确保没有正在运行的资料——您的资料仍保存在您的账户中。

### "Seems like you don't have installed browser"

**表现：** 完整信息为："Seems like you don't have installed browser. We will try to install it. Please run the profile again after the installation is finished."

**原因：** Gologin 资料所运行的浏览器 Orbita 尚未下载完成，或者它的文件已从您的电脑中被删除。

**解决方法：**

1. 等待浏览器下载完成，然后再次运行资料。
2. 如果该信息反复出现，请检查杀毒软件是否删除了 Orbita 文件——请参阅[杀毒软件和安全软件](#%E6%9D%80%E6%AF%92%E8%BD%AF%E4%BB%B6%E5%92%8C%E5%AE%89%E5%85%A8%E8%BD%AF%E4%BB%B6)——并确认磁盘还有可用空间。

### "Seems like a GPU process has crashed"

**表现：** 完整信息为："Seems like a GPU process has crashed. Please try to restart the profile or restart your system"。

**解决方法：**

1. 再次运行资料。
2. 重启电脑。
3. 如果问题持续出现，请按照[资料卡在“下载中”或“归档中”状态](#%E8%B5%84%E6%96%99%E5%8D%A1%E5%9C%A8%E2%80%9C%E4%B8%8B%E8%BD%BD%E4%B8%AD%E2%80%9D%E6%88%96%E2%80%9C%E5%BD%92%E6%A1%A3%E4%B8%AD%E2%80%9D%E7%8A%B6%E6%80%81)中的第 2–5 步操作。

### "Your PC does not have enough memory or other system resource to run the browser"

**原因：** 您的电脑内存或磁盘空间不足。包含 `ENOSPC` 或 `SQLITE_FULL` 的错误同样表示磁盘已满。

**解决方法：**

1. 关闭不需要的资料和程序。
2. 释放磁盘空间——Gologin 会将正在运行的资料数据存储在您的磁盘上。
3. 重启 Gologin，然后再次运行资料。

### "Container not found"

**表现：** 尝试启动资料时（尤其是在云端模式下）看到 "Container not found"。

**原因：** 资料数据已损坏，或者云端容器在 Gologin 服务器上启动失败。

**解决方法：**

1. 重启 Gologin 应用，然后再次尝试启动资料。
2. 尝试通过网页版 [app.gologin.com](https://app.gologin.com) 启动资料。
3. 如果问题仍然存在，请联系支持团队并提供您的资料 ID。

### "Couldn't prepare your profile, contact support"

**表现：** Gologin 无法为启动准备您的资料时会出现此错误。

**原因：** 通常是由资料同步问题、资料数据损坏，或您的 Orbita 浏览器版本与所需版本不匹配造成的。

**解决方法：**

1. 将 Gologin 桌面应用更新到最新版本。
2. 检查您的网络连接——不稳定的连接可能会中断资料同步。
3. 尝试切换到其他网络（例如从 WiFi 切换到手机热点）。
4. 如果错误仍然存在，请联系支持团队，并提供您的资料 ID 和应用版本。

### "Profile has been deleted"

**表现：** 即使您没有删除过资料，也会看到 "Profile has been deleted" 或 "Profile has been already deleted"。

**原因：** 这条信息具有误导性。它**并不**表示您的资料真的被删除了。通常是因为您在试用版或免费方案上已达到资料启动次数上限。

<Info>
  订阅到期后，Gologin 会在其服务器上保存资料最多 180 天。看到此信息时，您的资料数据并不会丢失。
</Info>

**解决方法：**

1. 升级到付费方案或续订订阅以恢复访问。
2. 如果您认为这是一个错误，请联系支持团队并提供您的账户信息。

### ECONNREFUSED 127.0.0.1

**表现：** 在本地启动资料时出现包含 `ECONNREFUSED 127.0.0.1` 的错误。

**原因：** Orbita 浏览器未能在您的电脑上启动。常见原因包括：

- Orbita 下载文件损坏
- 代理不兼容，导致浏览器无法初始化
- Gologin 应用版本过旧

**解决方法：**

1. 将 Gologin 桌面应用更新到最新版本。
2. 重新下载 Orbita：彻底退出 Gologin 并删除浏览器文件夹，具体方法请参阅[资料卡在“下载中”或“归档中”状态](#%E8%B5%84%E6%96%99%E5%8D%A1%E5%9C%A8%E2%80%9C%E4%B8%8B%E8%BD%BD%E4%B8%AD%E2%80%9D%E6%88%96%E2%80%9C%E5%BD%92%E6%A1%A3%E4%B8%AD%E2%80%9D%E7%8A%B6%E6%80%81)。
3. 检查您的代理设置——尝试不使用代理启动资料，以确定问题所在。

### EBUSY: resource busy or locked (Windows)

**表现：** 在 Windows 上，您会看到 `EBUSY: resource busy or locked` 错误，通常会提到 Cookies 文件。

**原因：** 之前的 Orbita 进程没有正常关闭，仍然锁定着资料文件。

**解决方法：**

1. 打开 **任务管理器**（Ctrl+Shift+Esc），结束所有名为 `orbita` 或 `browser` 的进程。
2. 删除该资料的本地副本。打开 `C:\Users\<YourUser>\AppData\Roaming\GoLogin\profiles\`，删除与出错资料 ID 对应的文件夹。
3. 重启 Gologin 并重试。

<Warning>
  删除此文件夹只会移除资料的本地副本，不会影响存储在 Gologin 服务器上的资料数据。
</Warning>

## 连接错误

### "Timezone request error"、"Profile loading error" 及其他连接错误

**表现：** 出现以下信息之一，或者应用显示白屏或绿屏而无法加载：

- "Timezone request error"
- "Profile loading error. Check internet connection."
- "Error in profile request. Check your internet connection and try again."
- "Error uploading profile. Please check your internet connection and try again."
- "Retrying your request due to internet connectivity issues. Thank you for your patience."

**原因：** 您的网络或网络服务提供商阻止或中断了 Gologin 应用与 Gologin 服务器之间的连接。在同一网络下，其他网站可能仍可正常访问。

**解决方法：**

1. 切换到其他网络——例如关闭 WiFi，使用手机共享的移动网络。
2. 在电脑上开启 VPN。如果第一个 VPN 没有效果，请尝试其他服务商——有时需要多试几个。
3. 切换网络或 VPN 后，从系统托盘中彻底退出 Gologin，然后重新启动。

<Tip>
  如果您看到 "SSL certificate error. Please check and adjust your system time or check your internet connection"，请首先确认电脑的日期、时间和时区已设置为自动。
</Tip>

### "Something went wrong. Please try again later"

**表现：** 您看到 "Something went wrong. Please try again later"，或者一个显示 "Oops! Something went wrong…" 的页面。

**原因：** 向 Gologin 服务器发出的请求失败。这是一个通用错误，可能有多种原因。

**解决方法：**

1. 按 **Ctrl+Shift+R**（Windows）或 **Cmd+Shift+R**（macOS）重新加载。这在桌面应用和网页版中都适用。
2. 如果错误再次出现，请从系统托盘中彻底退出 Gologin，然后重新启动。
3. 如果仍然出现，请按照[连接错误](#%E8%BF%9E%E6%8E%A5%E9%94%99%E8%AF%AF)中的步骤操作。
4. 如果仍然无法解决，请从 [gologin.com/download](https://gologin.com/download) 重新安装 Gologin，或附上截图联系支持团队。

### "Internal server error"

**原因：** Gologin 一侧出现了临时性问题。

**解决方法：**

1. 等待几分钟后重试。
2. 将 Gologin 更新到最新版本。
3. 如果错误没有消失，请联系支持团队。

### "The proxy is functional but not working on your device or network"

**表现：** Gologin 提示代理已通过服务器端检测，但无法从您的电脑连接。

**原因：** 您的本地网络或网络服务提供商阻止了代理连接。代理本身是正常的——Gologin 已在其服务器上验证过——但流量无法从您的设备发出。

**解决方法：**

1. 尝试在设备上开启 VPN，然后再次启动资料。
2. 切换到其他网络（WiFi 切换到手机热点，或反过来）。
3. 检查防火墙或杀毒软件设置，确保它们没有阻止 Gologin 或代理端口。

### SyntaxError: Unexpected token 'e'

**表现：** 出现 JavaScript 风格的错误 `SyntaxError: Unexpected token 'e'`，通常出现在 Gologin 应用或 API 响应中。

**原因：** 当 Cloudflare 返回 1015 速率限制错误页面（HTML），而不是 Gologin API 预期的 JSON 响应时，就会出现这种情况。JSON 解析器遇到 HTML 后，会在第一个意外字符处失败。

**解决方法：**

1. 降低 API 请求或资料启动的频率。
2. 等待几分钟后再重试。
3. 如果您通过程序调用 Gologin API，请在请求逻辑中实现指数退避。

## macOS 错误

### "Orbita quit unexpectedly" 或 "Your macOS version is not supported by Chromium Engine"

**表现：** 资料启动后 Orbita 立即关闭，macOS 显示 **Orbita quit unexpectedly** 报告，或者您看到 “not supported” 信息。

**原因：** Google 在 Chrome 150 之后停止了对 macOS 12 Monterey 的支持。Orbita 151 及更新版本无法在 macOS 12 Monterey 及更旧的 macOS 版本上运行。

**解决方法：**

1. 将 macOS 更新到 13 Ventura 或更新版本，**或者**
2. 使用 Orbita 150 或更早版本创建新资料：点击 **添加简介**，打开 **先进的** 选项卡，然后在 **旧版本** 下选择浏览器版本。

<Note>
  您无法降低现有资料的浏览器版本——请创建新的资料。
</Note>

### "Current browser version is not supported for ARM processor architecture"

**表现：** 资料显示此错误，或者 Gologin 在您的 Mac 上非常慢或卡死。

**原因：** 在搭载 Apple Silicon 芯片（M1 或更新）的 Mac 上安装了 Intel 版本的 Gologin，或者资料使用了旧版浏览器。

**解决方法：**

1. 检查您的芯片：打开苹果菜单 → **关于本机**，查看 **芯片** 一栏。
2. 如果是 Apple M 系列芯片，请将 Gologin 从 **应用程序** 移到废纸篓，然后从 [gologin.com/download](https://gologin.com/download) 安装 Apple Silicon 版本。
3. 更新该资料的浏览器：资料旁边的三个点 → **更新浏览器**。

### "Cannot update while running on a read-only volume"

**表现：** Gologin 无法安装更新，并显示 "Cannot update while running on a read-only volume. The application is on a read-only volume. Please move the application and try again."

**原因：** Gologin 是从下载的磁盘映像或 **下载** 文件夹中运行的，而不是从 **应用程序** 文件夹运行的。

**解决方法：**

1. 退出 Gologin。
2. 将 Gologin 拖到 **应用程序** 文件夹中。
3. 从 **应用程序** 中打开 Gologin 并安装更新。

<Tip>
  如果在任何系统上更新卡住，请检查您的[网络连接](#%E8%BF%9E%E6%8E%A5%E9%94%99%E8%AF%AF)，或从 [gologin.com/download](https://gologin.com/download) 下载最新版本并覆盖安装。您的资料会被保留。
</Tip>

## 杀毒软件和安全软件

### "Seems like your antivirus is blocking access to the Orbita browser"

**表现：** 您会看到以下信息之一：

- "Seems like your antivirus is blocking access to the Orbita browser. Please adjust your antivirus and restart the profile"
- "Seems like something is blocking application access to the system. Please check your antivirus or other security software."
- "Seems like your browser files are damaged or missing (possibly deleted by antivirus software)…"
- 更新浏览器时出现 "Permission denied"

**原因：** 您的杀毒软件或其他安全软件阻止了 Gologin 或 Orbita，或者已将它们的文件移至隔离区。

**解决方法：**

1. 在 Windows 上，打开 **Windows 安全中心** → **病毒和威胁防护** → **保护历史记录**，检查是否有被阻止或被隔离的 Gologin 或 Orbita 文件。如果有，请将其还原。
2. 将 Gologin 添加到杀毒软件的例外列表，或关闭杀毒软件。
3. 重启 Gologin 并再次运行资料——Gologin 会自动恢复缺失的浏览器文件。

## 方案和限额错误

### "The owner of this profile has run out of subscription time"

**表现：** 您无法运行他人分享给您的资料。完整信息为："The owner of this profile has run out of subscription time. To resume using this profile, the owner needs to renew their subscription."

**原因：** 该资料所有者的订阅已结束。

**解决方法：** 请资料所有者续订订阅。之后该资料即可再次运行。

### "The workspace subscription has ended. Please upgrade your plan to restore access"

**原因：** 您的试用方案或付费方案已结束。

**解决方法：** 在 **设置和成员** → **计费方案** → **更改方案** 中选择一个方案。要切换到 Forever Free 方案，请点击该页面底部的 **Forever Free**——您的工作区资料数量不得超过 3 个。

### "You've exceeded your workspace limits"

**原因：** 在 Forever Free 方案上，您最多可以同时拥有 3 个资料，每月最多创建 25 个资料。

**解决方法：**

1. 如果您已有 3 个资料，请删除一个不需要的资料。删除资料不会返还创建次数。
2. 如果您已用完 25 次创建额度，请等待每月额度重置，或[升级到付费方案](/zh/general/account-and-billing/how-to-subscribe-to-gologin)。

详情请参阅[免费方案限制](/zh/general/account-and-billing/pricing#%E5%85%8D%E8%B4%B9%E6%96%B9%E6%A1%88%E9%99%90%E5%88%B6)。

### "You've reached max shares number. To share more update your plan"

**原因：** 您已用完方案中包含的所有资料分享次数。

**解决方法：** 在资料的 **分享** 菜单中移除不再需要的分享，或升级您的方案。

### 分享资料时出现 "Bad Request"

**原因：** 您输入的邮箱没有对应的 Gologin 账户，或者邮箱存在拼写错误。

**解决方法：** 检查邮箱。如果对方还没有 Gologin 账户，请让对方先注册，然后再次分享资料。

### "You've reached max parallel cloud launches limit"

**表现：** 当您尝试在云端启动资料时，会出现此错误或 "You've hit your parallel launch limit"。

**原因：** 您已达到所用方案允许的最大并发云端会话数。

并发云端会话上限如下：

| 方案         | 并发云端会话数            |
|--------------|---------------------------|
| Professional | 1                         |
| Business     | 2                         |
| Enterprise   | 3                         |
| Custom       | 4                         |

**解决方法：**

1. 在启动新的云端资料之前，先关闭一个或多个正在运行的云端资料。
2. 购买更多并行云端启动数：点击左上角的账户名称 → **设置和成员** → **Cloud Browser 使用情况** → **购买更多限额**。
3. 在桌面应用中运行资料——本地启动不受您方案的限制。

<Note>
  在云端运行资料需要付费方案。
</Note>

### "You've exceeded your traffic limit" / "exceeded request limit"

**表现：** 启动资料或执行操作时，会出现两条相关信息之一。

**原因：** 此错误有两种可能的原因：

- **流量限制：** 您的 Gologin 代理流量（以 GB 计）已用完。您的订阅和代理流量是分开的：方案有效并不意味着您还有剩余流量。
- **请求/IP 速率限制：** 您触发了基于 IP 的速率限制，通常是因为在短时间内使用同一个 IP 地址创建了过多账户。

**解决方法：**

- **针对流量限制：** 购买更多流量：打开左侧的 **代理** 选项卡，选择代理类型，点击 **+**，选择 GB 数量并付款。
- **如果您刚刚购买了流量：** 请确保您的资料使用的代理类型与所购买流量的类型一致。例如，如果您购买的是 Datacenter 流量，请在资料设置中将资料的代理从 Residential 切换为 Datacenter。
- **针对 IP 速率限制：** 等待约 1 小时，待 IP 封锁解除后再重试。

## 账户错误

### "Registration error. Please try again."

**原因：** 短时间内注册尝试次数过多，或者使用该邮箱的账户已存在。

**解决方法：**

1. 稍等片刻后重试。
2. 如果您之前已用此邮箱注册过，请改为点击 **登录**。如果您不记得密码，请使用 **忘记密码？**。

<Note>
  "Invalid input data. Check field - "email"" 表示邮箱地址未被接受。请使用 @ 前至少包含 3 个字符的地址。带有 "+1" 的地址（如 name+1@gmail.com）不被接受。
</Note>

### 无法使用 Google 登录

**解决方法：**

1. 在登录界面点击 **忘记密码？**，并输入您的 Gologin 账户邮箱。
2. 输入邮件中的验证码并设置密码。
3. 使用邮箱和密码登录。

## 浏览器和扩展程序错误

### "To install add-ons, you'll need the new Microsoft Edge"

**表现：** 尝试在 Gologin 资料内安装浏览器扩展程序时，会看到有关 Microsoft Edge 的提示。

**原因：** 当您尝试从 Microsoft Edge 加载项商店安装扩展程序，或通过不兼容的安装路径安装时，Orbita 浏览器（基于 Chromium）有时会触发此信息。

**解决方法：**

1. 请从 [Chrome 应用商店](https://chromewebstore.google.com/)而不是 Edge 加载项商店安装扩展程序。
2. 或者，在启动资料之前，使用 Gologin 的扩展程序管理界面将扩展程序添加到您的资料中。

### geo.floppydata.com:10080 的代理身份验证弹窗

**表现：** 启动资料时，会弹出一个代理身份验证对话框，要求输入 `geo.floppydata.com:10080` 的凭据。

**原因：** Gologin 内置代理意外地请求身份验证。当代理配置未正确传递给浏览器时可能会出现这种情况，通常是由网络或 VPN 冲突引起的。

**解决方法：**

1. 彻底退出 Gologin（检查系统托盘，确保它已关闭）。
2. 在设备上开启 VPN。
3. 重启 Gologin。
4. 再次启动资料。对于轮换住宅代理，重启资料还会为您换取新的 IP。

<Info>
  如果弹窗仍然出现，请在网页版 [app.gologin.com](https://app.gologin.com) 中运行该资料，尝试使用其他代理，或联系 Gologin 支持团队。
</Info>
