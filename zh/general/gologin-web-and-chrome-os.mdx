## Gologin 网页版 ([app.gologin.com](http://app.gologin.com))

无需安装桌面应用，您即可在任意浏览器中访问 **app.gologin.com**，管理您的所有配置文件。这在以下场景中非常实用：

- Chrome OS 设备
- 共享或受限制的电脑
- 在任意设备上快速访问

**云端会话数量限制如下：**

- Professional：1 个并发云端会话
- Business：2 个并发云端会话
- Enterprise：3 个并发云端会话

所有配置文件数据会在桌面版和网页版之间同步。

## Chrome OS

Gologin 可通过网页版（app.gologin.com）在 Chrome OS 上使用。无需安装——打开浏览器并登录即可。云端会话数量限制取决于您的套餐。
