---
title: "活动会话"
---

**活动会话**页面可以让您全面查看当前登录您 Gologin 账户的所有设备和位置。您可以在这里监控账户访问情况、排查可疑登录，并撤销不认识的会话，所有操作一站式完成。

## 如何进入

1. 点击 Gologin 应用左上角的**工作区名称**
2. 在下拉菜单中选择**设置和成员**
3. 在左侧边栏中点击**活动会话**

## 页面内容

**本设备**

在页面顶部，Gologin 会突出显示您当前使用的会话，并将其标记为**在线**。设备名称下方会显示您当前的 IP 地址。

此区域还包含**终止所有其他会话**按钮。

**活动会话列表**

在当前设备下方，会列出所有其他活动会话。每个条目显示以下信息：

| 字段 | 说明 |
| :-- | :-- |
| **设备/平台** | 登录时使用的平台（例如 Gologin Web、Android 应用、Linux）。 |
| **应用版本** | 登录时的 Gologin 客户端版本。 |
| **IP 地址** | 与该会话关联的 IP 地址。 |
| **最后一次活动** | 该会话距离上次使用已过去的时间。 |
| **撤销按钮** | 针对单个会话的按钮，可立即登出该会话。 |

## 您可以执行的操作

**终止所有其他会话**

点击**终止所有其他会话**按钮，可立即登出除当前设备以外的所有设备。如果您怀疑账户被未经授权访问，这是保护账户安全的最快方式。

**撤销单个会话**

列表中的每个会话都有各自的**撤销**按钮。您可以用它登出特定设备，而不影响其他任何会话。当您认得大多数会话，只想移除其中一个陌生条目时，这个功能非常实用。
