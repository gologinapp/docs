---
title: "高级配置文件设置"
---

**先进的** 选项卡让您可以直接控制 Gologin 为每个配置文件管理的各项指纹参数。大多数用户无需改动这里的任何内容——在绝大多数网站上，配置文件使用默认设置即可正常运行。

<Warning>
  仅当您有明确的理由并且了解自己要调整的内容时，才更改这些设置。某些更改可以让配置文件在特定网站上表现得更好，但不正确的值也可能使配置文件看起来可疑，或导致网站功能异常。在这里进行尝试之前，我们建议您先在相关论坛和社区群组中了解多账号运营的相关实践。
</Warning>

您可以通过点击 **配置文件上的 3 个点** \> **设置** \> **先进的** 进入高级选项卡。

## 导航器

此部分控制配置文件向网站报告的浏览器和系统参数。

**用户代理** - 向您访问的每个网站标识您的浏览器和操作系统的字符串。如果您有多个操作系统和浏览器版本相同的配置文件，它们可能共用相同的用户代理，这是正常现象。有效的组合数量有限，Gologin 会通过其他指纹参数来区分各个配置文件。

**屏幕分辨率** - 配置文件报告的屏幕尺寸。请避免将其设置得高于您实际显示器的分辨率，因为这种不匹配可能成为可被检测到的信号。浏览器窗口无法调整到超过此值的大小，因此如果您需要更大的窗口，请在此处提高分辨率。请参阅 [为什么我无法将浏览器窗口扩展到全屏？](/zh/faq-profile-managment#why-cant-i-expand-the-browser-window-to-full-screen)

**语言** - 向网站报告的系统语言。设置为 **基于IP** 时，它会自动跟随代理所在位置对应的语言。如果您手动设置，请注意：在除 macOS 之外的所有系统上，这也会更改浏览器的界面语言；而在 macOS 上，浏览器始终遵循实际的系统语言设置。

**平台** - 向网站报告操作系统。它反映创建配置文件时选择的操作系统，且无法在现有配置文件上更改。

**CPU 线程** 和 **RAM** - 这些是浏览器向网站报告的硬件数值。更改它们不会影响浏览器的实际性能——它们只是用于报告的数值，并不会被实际使用。

**不跟踪** - 向网站发送“请勿跟踪”（Do Not Track）信号。大多数网站会忽略此信号，而且由于普通用户很少启用它，开启后本身也可能成为一个指纹识别数据点。

## 字体

网站可以询问浏览器系统中安装了哪些字体，并将得到的列表用作指纹。

**启用字体列表屏蔽** - 开启后，Gologin 会向网站提供配置文件自己精心挑选的字体列表，而不是您计算机上实际安装的字体。当前列表显示在开关下方，可通过 **编辑** 按钮手动修改。

建议保持开启。关闭后，配置文件访问的每个网站都能看到您真实的系统字体。

## 屏蔽媒体设备

网站和网络应用可以检测到您的设备连接了多少个摄像头、麦克风和扬声器。

**屏蔽媒体设备** - 启用后，配置文件会报告一组固定的媒体设备，而不是您真实的设备。您可以分别设置报告的 **视频输入**（摄像头）、**音频输入**（麦克风）和 **音频输出**（扬声器）数量。

默认每项均为 1，与典型的单设备配置相符。

## 硬件

此部分控制配置文件如何应对探测浏览器图形和音频渲染的指纹识别技术。这里的信号是通过让浏览器的渲染引擎运行小型任务并比较输出结果而产生的——每台设备产生的结果都略有不同。

<Note>
  这里的默认设置对大多数使用场景都是安全的。这些是高级指纹控制选项，错误地更改它们更可能使配置文件显得异常，而不是改善效果。
</Note>

**帆布** - 控制配置文件如何处理 Canvas 指纹识别。选项包括 **噪音**（为渲染输出添加细微的随机变化）、**关闭**（返回未经修改的正常输出）和 **堵塞**（完全阻止对 Canvas API 的访问）。阻止 Canvas 本身就可以被检测到，因此不推荐使用。

**Clients Rects** - 与 Canvas 类似，但针对的是浏览器测量页面上元素位置和大小的方式。可选 **噪音** 或 **关闭**。

**音频背景** - 控制音频渲染指纹。可以要求浏览器处理音频，其输出在每台设备上都略有不同。**噪音** 会添加轻微变化；**关闭** 则不做任何修改。

**WebGL图像** - 控制 WebGL 渲染的视觉输出，其结果因 GPU 而异。可选 **噪音** 或 **关闭**。

**WebGL 元数据** - 控制 WebGL 报告的 GPU 供应商和渲染器字符串。**屏蔽** 会将真实值替换为下方 **WebGL供应商** 和 **WebGL 渲染器** 字段中指定的值。**真实** 则直接传递您实际的 GPU 信息。

## 存储选项

这些开关控制每个配置文件在会话之间被允许保存的内容。

**启用本地存储** - 允许网站将数据存储在浏览器的本地存储中。许多网站依赖它来保存登录会话和偏好设置。禁用它可能会导致某些网络应用无法正常运行。

**启用索引数据库** - 允许网站使用结构更完善的浏览器端数据库。许多现代网络应用同样会用到它。如果您在会话持久性方面遇到问题，请启用此项。

**启用扩展存储** - 允许已安装的扩展在多次会话之间保存自己的数据。

## 浏览器插件

**启用可能易受攻击的插件** - 启用 Adobe PDF 查看器和 Widevine（用于受 DRM 保护的视频）等浏览器插件。这些插件默认处于禁用状态，因为旧版插件接口历来是指纹识别的途径。如果您需要在配置文件中查看 PDF 或播放受保护的视频，请启用此项。

## 其他

**启用 Google 服务** - 允许配置文件在后台连接 Google 的服务（拼写检查、安全浏览等）。大多数用户可以保持开启。

**禁用图片加载** 和 **禁用视频自动播放** - 开启后，配置文件不会在网站上加载图片，也不会自动播放视频。这样可以减少配置文件使用的代理流量，适用于数据抓取、自动化，或任何不需要查看媒体内容的工作。两者默认均为关闭。仅限付费方案使用。

**启用浏览器书签保存** - 决定会话期间创建或更改的书签是否在配置文件关闭时保存。

**启用浏览器历史记录保存** - 决定浏览历史记录是否在会话之间保存。

**启用密码保存** - 决定浏览器内置的密码管理器在此配置文件中是否启用。

**启用系统扩展** - 开启后，安装在您实际操作系统上的扩展会在配置文件启动时自动导入配置文件。这会在启动时触发安装提示。默认关闭，除非您确实需要，否则最好保持关闭。

**起始网址** - 配置文件启动时浏览器打开的内容。共有三个选项：**以前打开的标签页** 会恢复上次打开的所有标签页，**打开新标签页** 则从全新页面开始，**打开指定页面** 会打开您定义的网址。

**启动参数** - 在启动时传递给浏览器的标志，与普通 Chrome 所用的类型相同（例如 `--disable-gpu` 或 `--start-maximized`）。除非您清楚自己需要什么，否则请留空。请注意，某些参数已被屏蔽，即使输入也不会生效。

**自定义 DNS** - 允许您为此配置文件指定 DNS 服务器。它适用于 SOCKS 代理、VPN 连接和直接连接，但不适用于 HTTP 或 HTTPS 代理。

**WebRTC** - 控制浏览器如何处理 WebRTC。WebRTC 是一种用于实时音频和视频的技术，即使代理处于活动状态，它也可能暴露您的真实 IP 地址。**基于IP** 会使 WebRTC 的行为与代理的 IP 保持一致。**关闭** 会完全禁用 WebRTC，但某些网站需要启用它才能正常运行。
