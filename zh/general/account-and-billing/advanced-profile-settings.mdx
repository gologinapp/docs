---
title: "高级配置文件设置"
---

**先进的**选项卡可让您直接控制 Gologin 为每个配置文件管理的各项指纹参数。大多数用户无需改动这里的任何内容——在大多数网站上，使用默认设置的配置文件就能正常工作。

<Warning>
  只有在有明确需求并且了解所调整内容的情况下，才应更改这些设置。某些更改可以改善配置文件在特定网站上的表现，但错误的值也可能让配置文件看起来可疑，或导致网站功能异常。在这里进行尝试之前，我们建议您先在相关论坛和社区群组中了解多账号运营的相关实践。
</Warning>

您可以通过点击**配置文件上的 3 个点** \> **设置** \> **先进的**进入高级选项卡。

## 导航器

本部分控制配置文件向网站报告的浏览器和系统参数。

**用户代理** - 向您访问的每个网站标识您的浏览器和操作系统的字符串。如果您有多个操作系统和浏览器版本相同的配置文件，它们可能会共用同一个用户代理——这是正常现象。有效的组合数量有限，Gologin 会通过其他指纹参数来区分各个配置文件。

**屏幕分辨率** - 配置文件报告的屏幕尺寸。请避免将其设置得高于您实际显示器的分辨率，因为这种不一致可能会被检测到。浏览器窗口无法调整到超过该值的大小，因此如果您需要更大的窗口，请在此处提高分辨率。请参阅[为什么我无法将浏览器窗口扩展为全屏？](/zh/faq-profile-management#%E4%B8%BA%E4%BB%80%E4%B9%88%E6%88%91%E6%97%A0%E6%B3%95%E5%B0%86%E6%B5%8F%E8%A7%88%E5%99%A8%E7%AA%97%E5%8F%A3%E6%89%A9%E5%B1%95%E4%B8%BA%E5%85%A8%E5%B1%8F)

**语言** - 向网站报告的系统语言。设置为**基于IP**时，它会自动跟随代理所在位置对应的语言。如果您手动设置，请注意：在除 macOS 之外的所有系统上，这也会更改浏览器的界面语言——在 macOS 上，浏览器始终跟随实际的系统语言设置。

**平台** - 向网站报告操作系统。它反映的是创建配置文件时所选的操作系统，对已有的配置文件无法更改。

**CPU 线程**和 **RAM** - 这些是浏览器向网站报告的硬件值。更改它们不会影响浏览器的实际性能——它们只是用于报告的数值，并不是实际使用的数值。

**不跟踪** - 向网站发送“请勿跟踪”（Do Not Track）信号。大多数网站会忽略该信号，而且启用它本身也可能成为指纹识别的数据点，因为普通用户并不常用。

## 字体

网站可以询问浏览器系统中安装了哪些字体，并将得到的列表用作指纹。

**启用字体列表屏蔽** - 开启后，Gologin 会向网站提供配置文件自己精心设置的字体列表，而不是您机器上实际安装的字体。当前列表显示在开关下方，可通过**编辑**按钮手动修改。

建议保持开启。关闭后，配置文件访问的每个网站都能看到您真实的系统字体。

## 屏蔽媒体设备

网站和网络应用可以检测到您的设备连接了多少个摄像头、麦克风和扬声器。

**屏蔽媒体设备** - 启用后，配置文件会报告一组固定的媒体设备，而不是您的真实设备。您可以分别设置报告的**视频输入**（摄像头）、**音频输入**（麦克风）和**音频输出**（扬声器）数量。

默认每项均为 1，与典型的单设备配置相符。

## 硬件

本部分控制配置文件如何应对探测浏览器图形和音频渲染的指纹识别技术。这里的信号是通过让浏览器渲染引擎运行小型任务并比较输出结果生成的——每台设备产生的结果都会略有不同。

<Note>
  这里的默认设置对大多数使用场景都是安全的。这些是高级指纹控制项，错误地更改它们更可能让配置文件看起来异常，而不是得到改善。
</Note>

**帆布** - 控制配置文件如何处理 Canvas 指纹识别。选项包括**噪音**（为渲染输出添加细微的随机变化）、**关闭**（返回正常输出，不做任何修改）和**堵塞**（完全阻止 Canvas API 访问）。阻止 Canvas 本身就可能被检测到，因此不建议使用。

**Clients Rects** - 与 Canvas 类似，但针对的是浏览器测量页面上元素位置和大小的方式。可选择**噪音**或**关闭**。

**音频背景** - 控制音频渲染指纹。可以要求浏览器处理音频，其输出在每台设备上都略有不同。**噪音**会添加细微变化；**关闭**则不做修改。

**WebGL图像** - 控制 WebGL 渲染的视觉输出，该输出因 GPU 而异。可选择**噪音**或**关闭**。

**WebGL 元数据** - 控制 WebGL 报告的 GPU 供应商和渲染器字符串。**屏蔽**会用下方 **WebGL供应商**和 **WebGL 渲染器**字段中指定的值替换真实值。**真实**则会直接传递您实际的 GPU 信息。

## 存储选项

这些开关控制每个配置文件在会话之间允许保存哪些内容。

**启用本地存储** - 允许网站在浏览器的本地存储中保存数据。许多网站依赖它来保持登录会话和偏好设置。禁用它可能会导致某些网络应用无法正常工作。

**启用索引数据库** - 允许网站使用结构化程度更高的浏览器端数据库。许多现代网络应用也会用到它。如果您遇到会话无法保持的问题，请启用此项。

**启用扩展存储** - 允许已安装的扩展在多个会话之间保存自己的数据。

## 浏览器插件

**启用可能易受攻击的插件** - 启用 Adobe PDF 查看器和 Widevine（用于受 DRM 保护的视频）等浏览器插件。这些插件默认处于禁用状态，因为旧版插件接口历来是指纹识别的途径之一。如果您需要在配置文件中查看 PDF 或播放受保护的视频，请启用此项。

## 其他

**启用 Google 服务** - 允许配置文件在后台连接 Google 的服务（拼写检查、安全浏览等）。大多数用户可以保持开启。

**禁用图片加载**和**禁用视频自动播放** - 开启后，配置文件不会在网站上加载图片或自动播放视频。这可以减少配置文件使用的代理流量，适用于数据抓取、自动化或任何无需查看媒体内容的工作。两项默认均为关闭。仅限付费套餐使用。禁用图片后，某些网站或页面可能无法正常工作——例如某些设置页面。如果某个页面无法打开，请重新开启图片加载。

**启用浏览器书签保存** - 会话期间创建或更改的书签是否在配置文件关闭时保存。

**启用浏览器历史记录保存** - 浏览历史记录是否在会话之间保存。

**启用密码保存** - 浏览器内置的密码管理器是否在此配置文件中启用。

**启用系统扩展** - 开启后，您实际操作系统上安装的扩展会在配置文件启动时自动导入到配置文件中。这会在启动时触发安装提示。默认关闭，除非您确实需要，否则最好保持关闭。

**起始网址** - 配置文件启动时浏览器打开的内容。有三个选项：**以前打开的标签页**会恢复上次打开的所有标签页，**打开新标签页**会从全新页面开始，**打开指定页面** 会打开您定义的网址。

**启动参数** - 在启动时传递给浏览器的标志，与常规 Chrome 所用的类型相同（例如 `--disable-gpu` 或 `--start-maximized`）。除非您清楚自己需要什么，否则请留空。请注意，某些参数被屏蔽，即使输入也不会生效。

**自定义 DNS** - 允许您为此配置文件指定 DNS 服务器。它适用于 SOCKS 代理、VPN 连接和直接连接，但不适用于 HTTP 或 HTTPS 代理。

**WebRTC** - 控制浏览器如何处理 WebRTC。这是一项用于实时音视频的技术，即使启用了代理也可能暴露您的真实 IP 地址。**基于IP**会使 WebRTC 的行为与代理的 IP 保持一致。**关闭**会完全禁用 WebRTC，但某些网站需要启用它才能正常运行。
