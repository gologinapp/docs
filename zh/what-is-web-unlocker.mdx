---
title: "什么是 Web Unlocker？"
---

Web Unlocker 是一个通用的抓取 API。只需发送任意 URL，即可获得完整渲染后的 HTML、一张截屏和一份网络档案——无需管理任何基础设施，不会被拦截，也不会出现请求失败。

它可以完整替代您现有的抓取技术栈：浏览器自动化、代理管理、指纹处理、验证码破解，全部通过一次 API 调用完成。无论是简单的静态页面，还是受到严密保护、依赖 JavaScript 渲染的网站，都可以使用同一个接口来处理。

---

## 它解决了什么问题

现代网站越来越难以抓取。由于内容由 JavaScript 加载，直接使用 `curl` 或 `requests` 发起请求，往往只会得到验证页面、空白响应或残缺的 HTML。Web Unlocker 会自动处理这些问题：

- **JavaScript 渲染**——页面会在真实浏览器中加载，并在脚本完全执行后再抓取内容
- **绕过反机器人检测**——自动应对 Cloudflare、DataDome、PerimeterX 等类似防护
- **智能 IP 轮换**——请求通过干净的住宅 IP 发出，并搭配逼真的浏览器指纹
- **验证码破解**——无需人工干预，即可自动解决常见的验证码挑战
- **价格档位定向**——根据目标网站，自动选择合适档位的代理发送请求

---

## 您会得到什么

每个成功的任务都会返回三类内容：

| 内容 | 格式 | 说明 |
| --- | --- | --- |
| **HTML** | 完整的 HTML 字符串 | 页面完整的渲染后 DOM |
| **截屏** | PNG 图片 | 页面在浏览器中呈现效果的截屏 |
| **档案** | ZIP (HAR) | 包含所有请求、请求头和资源的网络日志 |

自行搭建代理基础设施成本高昂，而且稳定性差。Web Unlocker 将这一切作为托管服务来提供：

|  | Web Unlocker | 自建代理 |
| --- | --- | --- |
| 部署 | 一次 API 调用 | 数周的基础设施搭建工作 |
| 验证码破解 | 内置 | 需自行开发或另行购买 |
| 浏览器指纹 | 内置 | 需自行开发或另行购买 |

## 工作原理

Web Unlocker 会为每个任务在云端运行一个真实的 Chromium 浏览器。当您发送一个 URL 时：

1. 启动一个浏览器，并配置住宅 IP 和逼真的浏览器指纹
2. 浏览器打开页面，执行 JavaScript，并加载动态内容
3. 自动处理反机器人挑战和验证码
4. 抓取并返回渲染后的 HTML、一张截屏和一份网络档案

您无需管理任何基础设施：不用启动浏览器，不用维护代理列表，也不用自己开发绕过逻辑。Web Unlocker 只需一次 HTTP 请求，就能取代整套抓取技术栈，包括浏览器自动化框架、代理服务商和反机器人方案。

## 使用方法

发送一个 GET 请求，并将目标 URL 作为查询参数传入。响应内容即为完整渲染后的 HTML。

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

有关 Python 和 JavaScript 的示例，请参阅[快速入门](/zh/web-unlocker-quick-start)；有关常见的集成模式，请参阅[使用场景](./web-unlocker-use-cases.md)。
