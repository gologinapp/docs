---
title: "什么是 Web Unlocker?"
---

Web Unlocker 是一个通用的抓取 API。只需发送任意 URL,即可获得完整渲染后的 HTML,或 Markdown、JSON 格式的页面内容——无需管理基础设施,不会被拦截,也不会出现请求失败。

它可以完整替代你现有的抓取技术栈:浏览器自动化、代理管理、指纹处理、CAPTCHA 验证码识别,全部通过一次 API 调用完成。无论是简单的静态页面,还是防护严密、依赖 JavaScript 渲染的网站,都可以使用同一个接口处理。

---

## 它能解决什么问题

现代网站很难抓取。直接使用 `curl` 或 `requests` 发起请求,往往会得到验证页面、空白响应,或因内容由 JavaScript 加载而残缺的 HTML。Web Unlocker 会自动处理这些问题:

- **JavaScript 渲染** —— 页面在真实浏览器中加载,并在 JavaScript 完全执行后才抓取内容
- **绕过反机器人检测** —— 自动应对 Cloudflare、DataDome、PerimeterX 等类似防护
- **智能 IP 轮换** —— 请求通过干净的住宅 IP 发出,并带有逼真的浏览器指纹
- **CAPTCHA 验证码识别** —— 常见的 CAPTCHA 验证码无需人工干预即可自动通过
- **价格档位匹配** —— 根据目标网站,将请求路由到合适档位的代理

---

## 返回的内容

请求成功后,会以一种格式返回页面。你可以通过 `format` 查询参数选择格式:

| `format` | 返回内容 |
| --- | --- |
| `html`(默认) | 页面完整渲染后的 DOM |
| `markdown` | Markdown 格式的页面内容 |
| `json` | 包含页面 URL、请求元数据和 HTML 的 JSON 对象 |

## Web Unlocker 与自建代理对比

自建代理基础设施成本高昂且脆弱。Web Unlocker 以托管服务的方式为你处理一切:

|  | Web Unlocker | 自建代理 |
| --- | --- | --- |
| 部署 | 一次 API 调用 | 需要数周的基础设施工作 |
| CAPTCHA 验证码识别 | 内置 | 需自行开发或另行购买 |
| 浏览器指纹 | 内置 | 需自行开发或另行购买 |
| IP 轮换 | 自动 | 手动管理 IP 池 |
| 维护 | 无需维护 | 持续投入 |
| 计费 | 按成功请求计费 | 无论成功与否,成本固定 |

- **价格监控** —— 抓取会拦截自动化请求的电商网站

- **内容聚合** —— 从没有 API 的网站采集内容，构建新闻或数据源
- **AI 流水线** —— 将渲染后的 HTML 提供给大语言模型,用于信息提取或摘要

## 工作原理

Web Unlocker 会为每个任务在云端运行一个真实的 Chromium 浏览器。当你发送一个 URL 时:

1. 启动一个浏览器,使用住宅 IP 和逼真的浏览器指纹
2. 访问页面,执行 JavaScript,并加载动态内容
3. 自动处理反机器人验证和 CAPTCHA 验证码
4. 返回渲染后的 HTML;如果通过 `format` 指定,则返回 Markdown 或 JSON

你无需管理任何基础设施:不用启动浏览器,不用维护代理列表,也不用自行构建绕过逻辑。Web Unlocker 只需一个 HTTP 请求,就能有效替代整套抓取技术栈——浏览器自动化框架、代理服务商和反机器人解决方案。

## 使用方法

发送一个 GET 请求,并将目标 URL 作为查询参数传入。响应内容即为完整渲染后的 HTML。

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

如需获取 Markdown 或 JSON,请在查询参数中添加 `format=markdown` 或 `format=json`。

Python 和 JavaScript 示例以及[错误代码](/zh/web-unlocker-quick-start#handling-errors)请参阅[快速入门](/zh/web-unlocker-quick-start),常见的集成模式请参阅[使用场景](/zh/web-unlocker-use-cases)。
