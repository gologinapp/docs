本指南介绍如何使用 Web Unlocker 抓取你的第一个 URL。

---

## 前提条件

- 一个 Web Unlocker API 密钥。请通过 [Web Unlocker 页面](https://gologin.com/web-unlocker/#web_unlocker_form)上的表单获取。密钥将在一个工作日内发送给你,并附带免费请求额度,可用于测试你自己的目标网站。无需绑定银行卡。
- Python 3.x、Node.js 或任意 HTTP 客户端

---

## 身份验证

所有请求都需要在 `apikey` 请求头中携带你的 API 密钥:

```
apikey: YOUR_API_KEY
```

所有 API 请求的基础 URL 为:

```
https://parsing.webunlocker.gologin.com/v1
```

---

## 发送第一个请求

发送一个 GET 请求,并将目标 URL 作为查询参数传入。响应内容为页面完整渲染后的 HTML。

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.text)
```

### JavaScript (Node.js / Browser)

```javascript
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(html);
```

---

## 返回内容

响应正文是页面渲染后的原始 HTML,与你在浏览器中打开该 URL 时看到的内容一致。没有 JSON 外层包装,也无需额外解析。

```html
<!DOCTYPE html>
<html>
  <head><title>Example Domain</title></head>
  <body>...</body>
</html>
```

### 其他格式

添加 `format` 查询参数,即可获取其他格式的页面内容:

| `format` | 响应正文 |
|---|---|
| `html` | 页面 HTML(默认值) |
| `markdown` | Markdown 格式的页面内容 |
| `json` | 包含 URL、请求元数据和页面 HTML 的 JSON 对象 |

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com&format=json" \
  -H "apikey: YOUR_API_KEY"
```

```json
{
  "success": true,
  "data": {
    "url": "https://example.com",
    "metadata": {
      "response_time_ms": 297,
      "status_code": 200
    },
    "html": "<!DOCTYPE html><html lang=\"en\">..."
  }
}
```

---

## 错误处理

处理响应之前,请先检查 HTTP 状态码:

| 状态码 | 含义 | 响应正文 |
|---|---|---|
| `200` | 成功 | 所请求格式的页面内容 |
| `400` | 请求错误,例如缺少 `url` 参数 | `{"success":false,"error":"Request failed"}` |
| `401` | 缺少 `apikey` 请求头 | `{"message":"Missing API key in request"}` |

如果收到 `429` 或 `5xx` 状态码,请使用指数退避策略重试。

```python
response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

if response.status_code == 200:
    html = response.text
else:
    print(f"Error {response.status_code}: {response.text}")
```

## 使用 CLI 快速开始

你也可以使用 Gologin CLI 工具抓取页面,无需编写代码:

### Web Unlocker CLI

```bash
npm install -g gologin-webunlocker

GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker scrape https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker markdown https://example.com
```

### Gologin Web Access CLI(统一版)

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."
gologin-web-access read https://example.com
gologin-web-access scrape-json https://example.com
gologin-web-access batch-scrape https://example.com/page/1 https://example.com/page/2 --format text
```

详细信息请参阅 [Web Unlocker SDK 和 CLI](/zh/scraping-api-sdk-and-cli) 以及 [Web Access CLI](/zh/cli-tools/web-access)。
