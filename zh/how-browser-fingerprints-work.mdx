---
title: "浏览器指纹的工作原理"
---

当你访问一个网站时，浏览器会自动共享页面正常运行所需的某些技术信息。网站可以通过 HTTP 标头和 JavaScript API 获取这些信息。

指纹识别脚本会从浏览器和设备环境中收集多个数据点，例如：

- 浏览器和操作系统信息
- 屏幕分辨率和显示设置
- 已安装的字体
- 语言和时区
- 硬件特征
- 图形渲染数据（Canvas 和 WebGL）
- 音频处理数据
- 系统中可用的媒体设备

这些数据点经过组合和处理后，会生成一个**浏览器指纹**——一个代表设备和浏览器配置的唯一标识符。

网站会保存这个指纹，并在同一用户再次访问时进行比对。如果指纹与之前记录的配置一致，即使 Cookie 已被删除，网站也能识别出该设备。

网站广泛使用指纹识别来：

- 检测可疑的登录行为
- 防范欺诈和自动化流量
- 识别回访用户
- 将多个会话关联到同一设备

如果指纹在不同会话之间发生显著变化，网站可能会将该浏览器视为新设备或可疑设备。

Gologin 通过创建**相互隔离的浏览器配置文件**来解决这个问题。每个配置文件都有自己独立的指纹配置，因此表现得就像一台独立的设备。这样，你就可以管理多个账号，同时让它们的浏览器环境保持相互独立。
