title: "云端启动与本地启动"
hidden: true
---

使用 Gologin 进行自动化时，浏览器可以在两个位置运行：在你自己的设备上，或在 Gologin 的服务器上。这决定了 Orbita 二进制文件在哪里执行、你如何连接到浏览器，以及你需要准备哪些基础设施。

## 概览

|  | 本地启动 | Cloud Browser |
| --- | --- | --- |
| 浏览器运行位置 | 你的设备 | Gologin 的服务器 |
| 是否需要桌面应用 | 是 | 否 |
| 可见窗口 | 可选（无头模式） | 无 |
| 硬件需求 | 每个配置文件需要内存（约 300–500 MB） | 无 |
| 适用场景 | 在自己的设备或 VPS 上进行自动化 | 服务器端脚本，无需本地配置 |

## 本地启动

浏览器在你的设备上运行。SDK 会在首次运行时自动下载 Orbita 二进制文件，在本地启动浏览器，并返回一个 WebSocket 端点，供 Puppeteer 或 Playwright 连接。
