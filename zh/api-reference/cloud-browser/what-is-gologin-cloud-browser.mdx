Gologin Cloud Browser 让你可以在**云端**运行 Gologin（Orbita）浏览器，并通过一个**连接 URL**，用自动化代码（Puppeteer / Playwright）对其进行控制。

它是一种[无头浏览器](./what-is-headless-browser)，即完全由代码控制、没有图形界面的浏览器，由 Gologin 托管和管理，并内置支持持久化配置文件、指纹配置和代理路由。

## Cloud Browser 能做什么

- 在云端并行运行多个浏览器会话
- 使用现有技术栈（Puppeteer / Playwright）进行自动化
- 使用 Gologin **配置文件**保存持久状态（登录状态、Cookie、存储数据）
- 通过在配置文件中设置**代理**来转发流量
- 作为远程浏览器运行环境供 AI 代理使用

## 与标准无头浏览器的区别

标准的无头 Chrome 很容易被识别。网站会利用浏览器指纹识别自动化流量，检测 canvas 渲染、WebGL 参数、字体、时区、屏幕尺寸等数十种信号。

Gologin Cloud Browser 运行的是 **Orbita**，这是一个经过修改的 Chromium，能够管理指纹信号，使其与一致且真实的浏览器配置文件相匹配。再结合每个配置文件中保存的持久 Cookie 和代理配置，你的会话在多次访问中都会显得稳定、自然，如同真人操作。

## 为什么选择 Gologin Cloud Browser

### 内置反检测，无需插件

标准的无头 Chrome 极易被检测。其他云浏览器服务运行的是原生 Chromium，需要借助第三方隐身插件来减少指纹信号，效果参差不齐。

Gologin Cloud Browser 运行的是 **Orbita**，这是一个经过加固的 Chromium 版本，核心就是指纹管理：canvas、WebGL、字体、时区、屏幕分辨率等。反检测不是外挂的补丁，而是浏览器本身的能力。

### 持久化配置文件，会话有记忆

大多数云浏览器服务把每个会话都视为无状态的，会话关闭后 Cookie 和存储数据就会被丢弃。

Gologin 的配置文件是持久保存的。登录一次，关闭会话，之后再重新连接，配置文件仍会保留其 Cookie、本地存储和所有已配置的设置。无需重新认证，也无需预热会话。

## 常见技术场景

Cloud Browser 通常用于以下工作流：

- 登录一次网站账号，并通过配置文件保持会话持久
- 在多个配置文件之间，对相同网站重复执行操作
- 需要稳定、长时间运行的会话，且不依赖本地机器

典型示例包括为网页应用、电商平台或社交平台自动化已登录的会话，这些场景对会话持久性和配置文件设置的一致性要求较高。

## 核心概念

- **用户档案们**：可重复使用的浏览器身份（Cookie/存储数据，加上指纹和代理设置）。
- **云端会话**：配置文件在 Gologin 云端运行的实例。
- **连接 URL**：传给自动化工具、用来控制云端会话的端点。

## 工作原理（概览）

1. （推荐）通过 Gologin REST API 创建并配置配置文件（代理、指纹等）。
2. 使用你的**开发者令牌**和可选的 `profileId` 连接到 Cloud Browser。
3. 使用 Puppeteer 或 Playwright 自动化会话。
4. 完成后关闭连接。

## 连接 URL

将此 URL 用作远程浏览器端点：

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${profileId}
```

- `token`：你的 Gologin **开发者令牌**（在 Gologin 应用中创建：[API & MCP](https://app.gologin.com/personalArea/TokenApi) → **API** → **新代币**）。
- `profile`：**配置文件 ID**（可选）。如果省略，将为该会话创建一个新的配置文件。

## 管理配置文件（代理、指纹等）

Cloud Browser 是**连接层**。\
如需创建/更新配置文件、绑定代理以及配置文件设置，请使用 Gologin REST API：

- 配置文件 API：[创建配置文件](https://gologin.com/docs/api-reference/profile/create-profile-with-partial-parameters)、[更新配置文件](https://gologin.com/docs/api-reference/profile/update-profile-with-partial-parameters)
- 代理 API：[为配置文件添加 Gologin 代理](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy)、[为配置文件设置你自己的代理](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles)

## 通过 CLI 使用 Cloud Browser

如果你更喜欢使用 shell 命令，而不是编写 Puppeteer/Playwright 代码，Gologin 提供了适合 AI 代理使用的 CLI 工具：

- **[Gologin Agent Browser CLI](/zh/cli-tools/agent-browser)**：云浏览器 CLI，支持守护进程、页面快照和基于引用的交互，专为 AI 代理打造。
- **[Gologin Web Access CLI](/zh/cli-tools/web-access)**：统一的 CLI，将 Web Unlocker 抓取与 Cloud Browser 交互整合在一个工具中。

```bash
npm install -g gologin-agent-browser-cli
export GOLOGIN_TOKEN='your_token'

gologin-agent-browser open https://example.com
gologin-agent-browser snapshot
gologin-agent-browser click @e3
gologin-agent-browser screenshot ./page.png
gologin-agent-browser close
```
