Gologin AI Skills 是适用于 [Claude Code](https://claude.ai/code) 的即插即用扩展，可为 AI 智能体提供网页抓取和浏览器自动化能力。每个技能都封装了一个 Gologin CLI 工具，并将其以一组可供智能体调用的函数形式提供。

```
agent → skill → Gologin CLI → Web Unlocker API / Cloud Browser / Local Orbita
```

---

## 可用技能

<CardGroup cols={2}>
  <Card title="Web Access Skill" icon="globe" href="https://github.com/GologinLabs/agent-skills/tree/main/gologin-web-access-skill">
    默认技能，适用于已知网站的读取、提取、爬取、监控，以及先抓取后浏览的混合任务。

  <Card title="Scraping Skill" icon="code" href="https://github.com/GologinLabs/agent-skills/tree/main/gologin-scraping-skill">

## 安装

所有 Gologin 技能都从 [GologinLabs/agent-skills](https://github.com/GologinLabs/agent-skills) 仓库安装：

```bash
# install any skill
npx skills add GologinLabs/agent-skills@gologin-web-access-skill
npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill
npx skills add GologinLabs/agent-skills@gologin-scraping-skill
```

每个技能都需要先安装其底层 CLI：

| 技能 | 所需 CLI |
|---|---|
| Web Access Skill | `npm i -g gologin-web-access` |
| Agent Browser Skill | `npm i -g gologin-agent-browser-cli`（云端和本地运行时均适用） |
| Scraping Skill | `npm i gologin-webunlocker` |

| 任务 | 技能 |
|---|---|
| 读取文档页面、文章或已知 URL | Web Access |

| 批量抓取多个 URL | Web Access |
| 爬取网站、映射 URL | Web Access |
| 监控页面变化 | Web Access |
| 先读取页面，再在浏览器中交互 | Web Access（混合模式） |
| 打开实时云浏览器会话 | Agent Browser |
| 登录控制面板、截图 | Agent Browser |
| 填写表单、完成点击流程 | Agent Browser |
| 仅需抓取、无需浏览器的 Node.js 应用 | Scraping |
| 预热本地配置文件 | Agent Browser（本地运行时） |
| 使用持久化 Cookie 的账号登录流程 | Agent Browser（本地运行时） |
| 在本地 Orbita 中执行社交媒体 / 电商平台操作 | Agent Browser（本地运行时） |
| 对多个本地配置文件批量运行运行手册 | Agent Browser（本地运行时） |

## Web Access Skill

**安装：** `npx skills add GologinLabs/agent-skills@gologin-web-access-skill`

默认且功能最全面的技能，委托 `gologin-web-access` CLI 执行。

**抓取工具：** `scrape_url`、`read_page`、`scrape_markdown`、`scrape_text`、`scrape_json`、`batch_scrape`、`batch_extract`、`search_web`、`map_site`、`crawl_site`、`crawl_site_async`、`extract_structured`、`track_changes`、`batch_track_changes`、`parse_document`

**浏览器工具：** `browser_open`、`browser_search`、`browser_snapshot`、`browser_click`、`browser_type`、`browser_screenshot`、`browser_close`、`browser_sessions`、`browser_current`

**内置工作流：** browser-ref-loop、hybrid-read-then-interact、search-discover-and-scrape、lead-enrichment、competitive-monitoring、docs-ingestion、geo-testing、login-and-navigate-dashboard

完整命令详情请参阅 [Web Access CLI 参考](/zh/cli-tools/web-access)。

## Agent Browser Skill

**安装：** `npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill`

仅用于浏览器的技能，可在 Gologin Cloud Browser（默认）中运行实时会话，或通过 `--runtime local` 在本地 Orbita 配置文件中运行。适用于需要交互式浏览但无需抓取的场景。

**功能：** `doctor`、`open`、`sessions`、`current`、`snapshot`、`click`、`type`、`fill`、`find`、`get`、`tabs`、`tabopen`、`tabfocus`、`tabclose`、`cookies`、`cookies-import`、`storage-export`、`storage-import`、`eval`、`back`、`forward`、`reload`、`upload`、`screenshot`、`pdf`

**本地运行时新增：** 配置文件管理（`profiles`、`profile-create`、`profile-import`、`profile-update`、`profile-sync`、`profile-delete`）、运行手册（`run`、`batch`）、任务（`jobs`、`job`）、用例模板（`linkedin`、`ads`、`smm`、`scraping`、`geo`）以及诊断（`doctor --use-case --check-proxy`）。

完整命令详情请参阅 [Agent Browser CLI 参考](/zh/cli-tools/agent-browser) 和 [本地运行时](/zh/cli-tools/local-agent-browser)。

## Scraping Skill

**安装：** `npx skills add GologinLabs/agent-skills@gologin-scraping-skill`

最精简的技能，仅通过 Web Unlocker SDK 进行抓取。无浏览器会话，无守护进程。

**功能：** 原始 HTML（`scrape`）、文本（`text`）、Markdown（`markdown`）、结构化元数据（`json`）。SDK 方法：`scrapeRaw()`、`scrape()`、`scrapeText()`、`scrapeMarkdown()`、`scrapeJSON()`、`batchScrape()`。

适用于仅需抓取、且希望依赖更少的任务。

API 详情请参阅 [Web Unlocker SDK 参考](/zh/scraping-api-sdk-and-cli)。

## Local Agent Browser Skill（已弃用）

如果您的智能体仍在使用 `gologin-local-agent-browser-skill`，它只会将智能体指向 Agent Browser 技能。请改为安装 `gologin-agent-browser-skill`：它涵盖本地 Orbita 配置文件、预热、登录流程、运行手册和批量任务。

## 您可以让智能体做什么

安装技能后，您可以用自然语言与 Claude Code 交流。以下是各个技能支持的操作：

### 使用 Web Access Skill

- "读取 competitor.com 上的价格页面，并总结各个套餐"
- "抓取这 15 个 URL，并从每个页面提取产品名称和价格"
- "爬取 docs.example.com 上的文档，并给出每个章节的摘要"
- "搜索 'best CRM tools 2026'，并抓取前 5 条结果"
- "检查 competitor.com/pricing 自昨天以来是否有变化"
- "提取该网站上所有博客文章的标题和 URL"
- "在浏览器中打开 example.com，使用这些凭据登录，并对控制面板截图"

### 使用 Agent Browser Skill

- "打开管理后台，进入设置，并对当前配置截图"
- "登录预发布环境，检查新功能是否已部署"
- "使用这些测试信息填写 example.com 上的注册表单"
- "进入报表页面，下载月度导出文件，并对摘要截图"
- "查看 iphey.com 对此浏览器配置文件显示的结果"

### 使用 Scraping Skill

- "抓取此 URL 并给我文本内容"
- "获取这 10 个页面的标题、描述和各级标题"
- "以 Markdown 格式获取此页面，方便我分析"

### 使用 Agent Browser Skill（本地运行时）

- "创建一个使用美国代理的新 LinkedIn 配置文件并进行预热"
- "打开我的 Reddit 账号，浏览信息流，然后关闭"
- "以并发数 5 对全部 20 个配置文件运行预热运行手册"
- "检查我的 Facebook 广告配置文件的代理健康状况"
- "登录此电商平台账号，并对卖家后台截图"

## 工作流示例

### 竞品调研（Web Access Skill）

1. 智能体搜索竞争对手：`search_web("saas project management tools")`
2. 智能体映射竞争对手网站：`map_site("https://competitor.com")`
3. 智能体批量抓取关键页面：`batch_scrape(pricing, features, about)`
4. 智能体将内容交给 Claude 进行分析和对比

### 账号预热（Agent Browser Skill，本地运行时）

1. 智能体创建配置文件：`profile-create "Account 1" --template linkedin`
2. 智能体运行预热运行手册：`batch ./warmup.json --targets ./profiles.json`
3. 智能体检查任务结果：`jobs --kind batch --status ok`
4. 智能体报告哪些配置文件已准备就绪

### 控制面板监控（Agent Browser Skill）

1. 智能体打开控制面板：`open https://dashboard.example.com --profile saved_login`
2. 智能体读取页面：`snapshot`
3. 智能体导航到指标页面：`click @e5`（报表链接）
4. 智能体对报表截图：`screenshot ./daily-metrics.png`
5. 智能体关闭会话：`close`
6. 智能体根据快照数据总结各项指标

## 必要的预检

在运行任何任务之前，技能会先对工作进行分类：

1. **单个已知网站还是广泛的多来源调研？** — 决定是否需要抓取或搜索
2. **只读提取、监控还是交互式浏览器操作？** — 决定使用抓取还是浏览器
3. **仅使用 Web Unlocker，还是同时使用 Web Unlocker 和 Cloud Browser？** — 决定所需的凭据
4. **是否对地理位置敏感，或被封锁到需要全程使用 Gologin？** — 决定代理和配置文件的要求
