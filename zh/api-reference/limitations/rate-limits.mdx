---
title: '速率限制'
---
Gologin API 会限制您每分钟可以发送的请求数量。如果超出限制，请等待一段时间后再继续发送请求。

限制取决于您的套餐：

| 套餐 | 每分钟请求数 |
| :-- | --: |
| Professional | 300 |
| Business | 500 |
| Enterprise | 800 |
| Custom | 1,200 |

试用套餐和 Forever Free 套餐不包含 API 访问权限。各套餐包含的内容请参阅[价格](/zh/general/account-and-billing/pricing)。

### 触发速率限制后令牌失效

<Warning>
当您超出速率限制并收到 HTTP 429 响应时，您的 API 令牌会被自动作废。这意味着该令牌将永久无法使用，您必须重新生成一个新的令牌。

这不是临时冷却，令牌会被直接撤销。请合理规划请求频率，并采用指数退避策略来避免这种情况。
</Warning>

### Cloudflare 防护错误

如果您的服务器 IP 发送的请求过多，Gologin 的 Cloudflare CDN 可能会完全封锁该 IP。此时，API 返回的将是 HTML 错误页面而不是 JSON，从而导致如下错误：

```
SyntaxError: Unexpected token 'e', "error code: 1015" is not valid JSON
```

这是 Cloudflare 的 1015 速率限制响应，通常会在几分钟到几小时内自行恢复。为避免出现这种情况：
- 在代码中实现请求速率限制
- 请求失败时使用指数退避
- 避免突发的并行 API 调用

### 创建配置文件的限制

新账户每天大约可创建 300 个配置文件。该限制可能因套餐而异。如果您需要更高的额度，请联系客服。
