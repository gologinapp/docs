---
title: '速率限制'
---
我们不允许用户向 API 发送无限数量的请求。如果超出限制，您需要等待一段时间后再继续请求。<br />
我们的基础限制如下：
- 免费版和试用版套餐：每 1 分钟 300 个请求
- 其他套餐：每 1 分钟 1200 个请求

### 触发速率限制后令牌失效

<Warning>
当您超出速率限制并收到 HTTP 429 响应时，您的 API 令牌会被自动作废。这意味着该令牌将永久无法使用，您必须重新生成一个新令牌。

这并不是临时的冷却等待，而是令牌会被直接撤销。请合理规划请求频率，并实现指数退避机制以避免这种情况。
</Warning>

### Cloudflare 防护错误

如果您的服务器 IP 发送的请求过多，Gologin 的 Cloudflare CDN 可能会完全封锁您的 IP。发生这种情况时，API 返回的将是 HTML 错误页面，而不是 JSON，从而导致如下错误：

```
SyntaxError: Unexpected token 'e', "error code: 1015" is not valid JSON
```

这是 Cloudflare 1015 速率限制响应，通常会在几分钟到几小时内自行恢复。为避免此问题，请：
- 在代码中实现请求速率限制
- 在请求失败时使用指数退避
- 避免突发的并行 API 调用

### 配置文件创建限制

新账户每天大约可创建 300 个配置文件，具体限制可能因套餐而异。如果您需要更高的限额，请联系客服支持。
