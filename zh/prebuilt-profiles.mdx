---
title: "预设配置文件模板"
---

预设配置文件模板为常见平台的使用场景提供了推荐的浏览器配置文件设置。

这些模板展示了不同平台常用的设置，包括指纹配置、代理类型和地区设置。在 Gologin 中创建新的浏览器配置文件时，您可以将它们作为起点。

模板只是示例，并非固定预设，您可以根据自己的工作流程进行调整。

## TikTok 配置文件模板

适用于 TikTok 账号环境的推荐配置。

| 参数 | 推荐设置 |
| :-- | :-- |
| 浏览器类型 | 类移动设备环境 |
| 代理类型 | 住宅代理或移动代理 |
| 代理位置 | 固定地区 |
| 指纹更改 | 尽量少 |
| 时区 | 与代理位置一致 |

TikTok 非常看重设备的一致性和会话行为。稳定的环境有助于减少验证检查。

## Facebook / Meta Ads 配置文件模板

适用于 Facebook 账号和 Meta Ads 工作流程的推荐配置。

| 参数 | 推荐设置 |
| :-- | :-- |
| 浏览器类型 | 桌面端 |
| 代理类型 | 住宅代理 |
| 代理位置 | 固定 |
| 指纹更改 | 避免频繁更改 |
| 会话行为 | 活跃度逐步提升 |

Facebook 会评估设备信号和登录历史，因此保持环境一致非常重要。
