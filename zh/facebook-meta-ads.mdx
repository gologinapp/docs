---
title: "Facebook / Meta Ads"
---

Facebook 是对指纹最为敏感的平台之一。它会综合比对 IP 地址、设备环境、行为模式和付款记录来评估账号。这些信号之间只要出现不一致,就会触发验证检查。

## 快速检查清单

- 1 个账号 = 1 个浏览器配置文件
- 1 个配置文件 = 1 个静态住宅代理或移动代理
- 切勿在多个配置文件之间重复使用同一个代理
- 配置文件的操作系统要与你设备的操作系统一致
- 首次登录后,不要更改代理或指纹

## 第 1 步:设置你的 Gologin 配置文件

推荐设置:

- **代理:**静态住宅代理或移动代理——请在首次打开 Facebook 之前分配好
- **指纹:**保持默认设置——不要手动调整 Canvas、WebGL 或 AudioContext

在某个配置文件中登录 Facebook 之后,请不要再更改代理或指纹设置。Facebook 会在服务器端保存设备数据,指纹一旦变化,看起来就像是有新设备在尝试访问你的账号。

## 第 2 步:注册前先养浏览器

在创建新账号之前,先在配置文件中正常浏览 10–15 分钟:

- 打开 3–5 个互不相关的网站
- 自然地滚动、点击、停顿
- 暂时不要访问 Facebook

这样可以积累会话历史,让环境看起来像一台真实的设备。一个完全没有任何历史记录的全新浏览器,是很明显的检测信号。

## 第 3 步:创建账号

- 每次账号注册之间至少间隔 30–60 分钟
- 每个账号使用一个独立的手机号码
- 同一代理所在地每天创建的账号不要超过 2–3 个
- 避免各账号采用完全相同的注册流程

如果 Facebook 在注册过程中要求进行手机验证,请完成验证。不要跳过,也不要重复使用同一个号码。

## 第 4 步:完善个人资料

- 上传头像和封面照片
- 填写基本信息(所在地、工作单位、教育经历)
- 关注 5–10 个与你的领域相关的主页
- 加入 1–2 个小组

最初 24 小时内,不要发布链接、创建活动或发送好友请求。

## 第 5 步:养号

Facebook 会在新账号注册后的前 2–3 周内对其进行严格评估。

### 养号时间表

| **时间段** | **重点** | **操作内容** |
| :-- | :-- | :-- |
| 第 0 天 | 设置 | 完善个人资料 \+ 浏览 15 分钟 |
| 第 1–7 天 | 被动浏览 | 浏览动态、观看视频、给帖子点赞 |
| 第 8–14 天 | 轻度互动 | 评论、关注主页,每天 2–3 个好友请求 |
| 第 3 周 | 正常使用 | 小组、更多互动、偶尔发帖 |
| 第 4 周\+ | 可投放广告 | 设置 Business Manager \+ 广告账户 |

### 安全的活跃度水平

| **操作** | **建议水平** |
| :-- | :-- |
| 好友请求 | 5–10 / 天 |
| 关注主页 | 5–10 / 天 |
| 帖子点赞 | 15–30 / 天 |
| 加入小组 | 1–2 / 天 |
| 发布外部链接 | 第 3 周之后 |

## Meta Ads 设置

请在个人账号养号完成之后再设置 Meta Ads——至少要有 1–2 周的活跃记录。

- 创建 Business Manager 账号([business.facebook.com](http://business.facebook.com))
- 将你的个人账号添加为管理员
- 创建一个广告账户——先从一个开始
- 添加一个独立的付款方式
- 启动一个小型测试广告系列(\$5–10/天)
- 在 1–2 周内逐步增加预算

<Warning>
  不要将同一个付款方式添加到多个广告账户。Facebook 会通过共用的付款方式关联账号。每个广告账户都需要一个独立的付款来源。
</Warning>

## 常见风险触发因素

### 立即封号

- 账号已处于活跃状态后,从新的 IP 登录
- 多个广告账户使用同一个付款方式
- 在同一代理所在地一天内创建 5 个\+账号
- 在个人账号养号完成之前投放广告

### 逐步受限

- 多个账号发布相同的内容
- 好友请求数量多但通过率低
- 短时间内集中加入大量小组
- 广告支出出现异常激增
