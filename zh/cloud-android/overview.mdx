**Cloud Android**让您可以直接在 Gologin 应用中运行云端真实 Android 手机，无需实体手机。每个 Cloud Android 配置文件都是一部独立的手机，拥有各自的应用和数据，因此您可以像使用浏览器配置文件一样使用移动应用（例如 Instagram）。

## 谁可以使用

所有 Gologin 付费套餐均可免费使用 Cloud Android。使用 Google 账号注册的免费试用用户，在试用期内也可以使用。

| | 同时运行的手机数量 | 时间限制 |
| --- | --- | --- |
| 试用（Google 账号注册） | 1 | 无限制 |
| 付费套餐 | 最多 10 | 无限制 |

## 创建并运行 Cloud Android 配置文件

![Cloud Android](/images/cloud_android.png "Cloud Android")

1. 点击左侧菜单中的**云端安卓**。
2. 点击**添加安卓配置文件**。
3. 设置代理和其他选项。
3. 点击配置文件上的**运行**。手机启动最多可能需要 **2 分钟**。
4. 当配置文件处于**运行**状态时，点击**查看**即可打开手机窗口。
5. 使用完毕后，点击**停止**。

当前正在运行的手机数量显示在页面顶部（**当前运行**）。

## 使用手机

手机窗口包含标准的 Android 按键，右侧还提供多种工具，例如截图、上传和下载文件、旋转屏幕、音量、位置和电源。

请通过手机上的应用商店安装应用，例如 **Aurora Store**、**F-Droid** 或 **Uptodown**。应用、登录信息和其他数据会在多次启动之间保留在配置文件中。

![Cloud Android 手机界面](/images/cloud_android_prone_ui.png "Cloud Android 手机界面")

<Note>
  并非所有 Android 应用都能在 Cloud Android 中使用。如果某个应用无法打开，请尝试在浏览器中访问其网站。
</Note>

## 代理

Cloud Android 手机运行在 Gologin 服务器上，因此如果不使用代理，网站和应用看到的是服务器的 IP 地址，而不是您自己的。添加代理的方式与浏览器配置文件相同，支持所有类型的代理，包括 Gologin 代理和您自己的代理。移动代理对手机来说最自然，但任何类型的代理都可以使用。

## 无操作超时

如果运行中的手机 **15 分钟**内没有任何操作，将自动停止。您的数据会被保存。
