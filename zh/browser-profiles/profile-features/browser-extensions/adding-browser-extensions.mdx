---
title: "为配置文件添加浏览器扩展"
---

在 Gologin 中，你可以通过两种方式添加公共扩展。

## 通过“扩展”标签页添加

你可以**直接在配置文件设置中**为浏览器配置文件添加扩展，无需访问 Chrome 网上应用店：

1. 在“所有配置文件”页面，**点击要安装扩展的配置文件旁的三个点**，然后点击**设置**
2. 进入**扩展**标签页
3. 点击**添加扩展**
4. 使用搜索栏查找所需的扩展，然后点击**安装**
5. 别忘了点击**节省**以应用更改

<Frame>
  ![通过设置添加扩展](/images/add_extensions_via_settings.gif)
</Frame>

如需删除扩展，在同一菜单中点击**消除**即可。

<Tip>
  如果在列表中找不到所需的扩展，只需通过 Chrome 网上应用店至少安装一次。已安装的扩展会在 24 小时内显示在列表中。
</Tip>

### 为每个新配置文件添加扩展

如果你知道每个配置文件都需要用到某些扩展，可以点击扩展旁边的**旗帜图标**，让它出现在之后创建的每个新配置文件中。

<Frame>
  ![为每个新配置文件添加扩展](/images/add_extensions_to_every_new_profile.png)
</Frame>

<Note>
  此类扩展不会出现在你已创建的配置文件中，只会添加到更改之后新建的配置文件。
</Note>

## 通过 Chrome 网上应用店安装

如果在配置文件设置的“扩展”标签页中找不到所需的扩展，可以在浏览器配置文件中使用 **Chrome 网上应用店**。操作步骤如下：

1. **启动**需要新增扩展的**浏览器配置文件**
2. 在浏览器中点击**右上角的三个点** \> **扩展** \> **访问 Chrome 网上应用店**
3. 找到所需的扩展
4. 点击**添加至 Chrome**，等待安装完成
