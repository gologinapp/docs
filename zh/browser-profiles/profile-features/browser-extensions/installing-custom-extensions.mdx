---
title: "安装自定义扩展"
---

**自定义扩展**让您可以在 Gologin 配置文件中使用私有、修改过或本地开发的工具。与公共扩展不同，自定义扩展需要使用扩展文件手动安装。

## 确保您的扩展兼容

**Gologin 不支持 .crx 或 .zip 压缩包。** 不过，您可以将这类文件转换为 Gologin 支持的**未打包文件夹**。

如果您有 **.zip** 压缩包，只需将其解压，得到的文件夹即可作为自定义扩展添加。

如果您有 **.crx** 文件：

1. 将 extension.crx 重命名为 extension.zip
2. 使用 7-zip 应用或操作系统自带的解压工具进行解压

<Warning>
  请确保解压后的文件夹中包含 **manifest.json** 以及其他扩展资源（js、html、图标等）。 \
  如果无法添加扩展，请检查是否存在 manifext.json
</Warning>

## 安装未打包的扩展

Gologin 支持以**未打包文件夹**形式安装扩展。安装步骤如下：

1. **点击要安装扩展的配置文件上的三个点**，然后点击**设置**
2. 进入**扩展**选项卡，点击**添加扩展**
3. 点击**上传自定义扩展**按钮
4. 打开包含该扩展的文件夹，点击**选择文件夹**
5. 点击**节省**以应用更改
