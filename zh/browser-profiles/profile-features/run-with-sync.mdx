---
title: "同步运行"
---

“同步运行”会同时启动多个浏览器个人资料，并将您的操作实时镜像到所有个人资料中。您在主窗口中执行的任何操作（点击、输入、跳转到某个 URL）都会同时自动在其他每个个人资料中执行。

这对重复性的账号工作非常有用，例如养号、在多个个人资料中执行相同的操作，或填写相同的表单。您无需在各个窗口之间来回切换并重复相同的步骤，只需操作一次即可。

<Warning>
  网站会检测多个账号之间同时发生的相同行为。仅在可以接受相同操作的任务中使用“同步运行”，例如养号、初始设置、跳转到某个 URL；不要将其用于发布内容、发送消息，或任何内容相同会显得可疑的活动。
</Warning>

## 使用方法

### 步骤 1：选择个人资料

在个人资料列表中，勾选您想一起启动的个人资料旁边的复选框。

### 步骤 2：点击“同步运行”

批量操作面板会显示在屏幕顶部。点击“同步运行”。

所有选中的个人资料都会在各自独立的浏览器窗口中打开。

### 步骤 3：在主控窗口中操作

您所选列表中的第一个个人资料将成为主控窗口。您在该窗口中的所有操作（点击、输入、跳转）都会实时复制到其他所有已打开的个人资料中。其他个人资料为跟随窗口：它们会镜像主控窗口的操作，但无法对其进行控制。

## 实际使用场景

**账号养号：** 打开 10 到 20 个新账号，一起浏览相同的页面。每个个人资料都独立浏览（指纹不同、IP 不同），而您只需操作一次。

**多个账号的相同设置：** 进入设置页面，切换相同的选项，填写相同的个人资料信息字段。适用于批量设置初始配置相同的全新账号。

**跳转到工作 URL：** 当您需要先让所有个人资料打开某个特定页面，然后再逐个处理时，只需跳转一次，所有个人资料就会同时打开该页面。

**测试多个个人资料的指纹表现：** 同时在多个个人资料中打开检测网站（[iphey.com](http://iphey.com)、[pixelscan.net](http://pixelscan.net)），并排对比结果。

## 需要避免的操作

**发布相同的内容：** 如果所有个人资料在同一时间发布相同的文字、图片或链接，平台会立即将这些账号关联起来。仅在相同行为属于正常情况的操作中使用“同步运行”，例如浏览、点击、跳转，不要用于内容创作。

**发送消息和外联：** 同时从不同账号向相同的人发送相同的消息，是导致所有这些账号被自动封禁的最快方式之一。

**账号较新时的登录流程：** 每个个人资料在登录时可能会遇到不同的双重验证提示、CAPTCHA 或验证步骤。同步器会复制您的输入，但无法处理各个窗口状态不一致的情况：可能一个个人资料停留在 CAPTCHA 页面，而另一个已经登录。请在启用同步器之前，逐个完成登录。

## 停止个人资料

要关闭所有通过“同步运行”启动的个人资料：

1. 使用复选框选中所有正在运行的个人资料
2. 在批量操作面板中点击 **停止多个个人资料**

<Frame>
  ![0331(1)(1)](/images/0331\(1\)\(1\).gif)
</Frame>

或者逐个关闭每个浏览器窗口。Gologin 会在每个个人资料关闭时同步其数据。

<Warning>
  请等待每个个人资料在 Gologin 应用中显示 **准备好** 状态后，再关闭应用本身。如果在个人资料仍在同步时关闭 Gologin，这些会话的数据将会丢失。
</Warning>

## 与普通“运行”（批量）的区别

|  | 运行（批量） | 同步运行 |
| :-- | :-- | :-- |
| 个人资料独立操作 | ✅ | ❌ |
| 操作在各窗口间镜像 | ❌ | ✅ |
| 最适合 | 打开多个个人资料后分别单独处理 | 在所有个人资料中重复相同的操作 |

当您想打开多个个人资料，然后逐个单独处理时，请使用普通的 **运行**。当您想在所有个人资料中同时执行完全相同的操作时，请使用 **同步运行**。
