---
title: "同步运行"
---

“同步运行”会同时启动多个浏览器配置文件,并将你的操作实时镜像到所有配置文件中。你在主窗口中进行的任何操作(点击、输入、跳转到某个 URL)都会同时在其他所有配置文件中自动执行。

这对于重复性的账号工作非常有用,例如养号、在多个配置文件中执行相同的操作,或填写相同的表单。你无需在不同窗口之间来回切换并重复相同的步骤,只需操作一次即可。

<Warning>
  网站会检测多个账号之间完全相同的同步行为。请仅在可以接受相同操作的任务中使用“同步运行”,例如养号、初始设置、跳转到某个 URL;不要用于发帖、发送消息,或任何内容完全相同会显得可疑的活动。
</Warning>

## 使用方法

### 第 1 步 — 选择个人资料

在个人资料列表中,勾选你想一起启动的个人资料旁边的复选框。

### 第 2 步 — 点击“同步运行”

批量操作面板会显示在屏幕顶部。点击“同步运行”。

所有选中的个人资料都会在各自独立的浏览器窗口中打开。

### 第 3 步 — 在主控窗口中操作

所选列表中的第一个个人资料会成为主控(leader)。你在它的窗口中进行的所有操作(点击、输入、跳转)都会实时复制到其他所有已打开的个人资料中。其他个人资料是跟随者(follower):它们会镜像主控窗口的操作,但无法反过来控制主控窗口。

## 实际使用场景

**账号养号:** 打开 10–20 个新账号,一起浏览相同的页面。每个个人资料都会独立浏览(指纹不同、IP 不同),而你只需操作一次。

**在多个账号中进行相同设置:** 进入设置页面,切换相同的选项,填写相同的个人资料信息。适用于批量设置初始配置相同的全新账号。

**跳转到工作 URL:** 当你需要所有个人资料先打开某个特定页面,然后再分别逐个处理时,只需跳转一次,所有个人资料就会同时打开该页面。

**跨个人资料测试指纹表现:** 在多个个人资料中同时打开检测网站([iphey.com](http://iphey.com)、[pixelscan.net](http://pixelscan.net)),并排对比结果。

## 需要避免的做法

**发布相同的内容:** 如果所有个人资料在同一时间发布相同的文字、图片或链接,平台会立即将这些账号关联起来。请仅在相同行为属于正常情况的操作中使用“同步运行”,例如浏览、点击和跳转,不要用于内容创作。

**发送消息和外联:** 同时用不同账号向相同的人发送相同的消息,是导致所有这些账号被自动封禁的最快方式之一。

**账号较新时的登录流程:** 每个个人资料在登录时可能会遇到不同的两步验证(2FA)提示、验证码(CAPTCHA)或验证步骤。同步器会复制你的输入,但无法处理各窗口状态不一致的情况,例如一个个人资料停留在验证码页面,而另一个已经登录成功。请在启用同步器之前,逐个完成登录。

## 停止个人资料

要关闭所有通过“同步运行”启动的个人资料:

1. 使用复选框选中所有正在运行的个人资料
2. 在批量操作面板中点击 **停止多个个人资料**

<Frame>
  ![0331(1)(1)](/images/0331\(1\)\(1\).gif)
</Frame>

你也可以逐个关闭每个浏览器窗口。Gologin 会在每个个人资料关闭时同步其数据。

<Warning>
  在关闭 Gologin 应用之前,请等待每个个人资料在应用中显示 **准备好** 状态。如果在个人资料仍在同步时关闭 Gologin,这些会话的数据将会丢失。
</Warning>

## 与普通运行(批量)的区别

|  | 运行(批量) | 同步运行 |
| :-- | :-- | :-- |
| 个人资料独立操作 | ✅ | ❌ |
| 操作在各窗口间镜像 | ❌ | ✅ |
| 最适合 | 打开个人资料后分别单独操作 | 在所有个人资料中重复相同的操作 |

当你想打开多个个人资料,然后逐个单独操作时,请使用普通的 **运行**。当你想在所有个人资料中同时执行完全相同的操作时,请使用 **同步运行**。
