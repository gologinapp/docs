---
title: "Dateien herunterladen und hochladen"
---

Wenn Sie ein Profil in der Cloud ausführen, läuft der Browser nicht auf Ihrem Computer, sondern auf einem entfernten Server. Deshalb funktionieren das Herunterladen und Hochladen von Dateien etwas anders als in einem lokalen Browser. Die Dateien laufen dabei über einen Zwischenschritt im Cloud-Container.

### Eine Datei auf Ihren Computer herunterladen

1. Laden Sie die Datei wie gewohnt von der Website herunter. Die Datei wird im Cloud-Container gespeichert, nicht auf Ihrem lokalen Gerät
2. Klicken Sie im Fenster des Cloud-Browsers unten links auf das Symbol **Files**
3. Klicken Sie neben dem Dateinamen auf die Schaltfläche **↓**
4. Auf Ihrem lokalen Computer öffnet sich ein Datei-Explorer. Wählen Sie einen Ordner aus und speichern Sie die Datei

### Eine Datei auf eine Website hochladen

1. Klicken Sie im Fenster des Cloud-Browsers unten links auf das Symbol Files
2. Wählen Sie **Click or drag files here** und wählen Sie die Datei von Ihrem lokalen Computer aus. Die Datei wird in den Cloud-Container hochgeladen
3. Klicken Sie auf der Zielwebsite auf die Upload-Schaltfläche
4. Ein Datei-Explorer auf dem entfernten Container wird geöffnet. Wechseln Sie in den Ordner **Downloads**, wählen Sie die hochgeladene Datei aus und klicken Sie auf **Open**
