## Verfügbare Proxy-Einstellungen

Wenn Sie bestimmte Proxy-Parameter konfigurieren möchten, müssen Sie eine **neue Proxy-Verbindung erstellen**.

<Info>
  Hinweis: Die Einstellungen einer bestehenden Proxy-Verbindung können nicht geändert werden.
</Info>

So erstellen Sie einen neuen benutzerdefinierten Gologin Proxy:

1. Klicken Sie im Browserprofil auf **Choose location or proxy**.
2. Klicken Sie auf den **Pfeil** neben dem ausgewählten Proxy-Land.
3. Wählen Sie **Add new server** aus.<br />Hier können Sie die folgenden Parameter konfigurieren:
   - **City** - für einige der beliebtesten Länder verfügbar
   - **Name** - ein frei wählbarer Name für die Proxy-Verbindung
   - **Proxy type** - Residential, Mobile oder Datacenter
4. Klicken Sie auf **Connect**, um den neuen Proxy zu übernehmen.

</Frame>

## Verbindung prüfen und Proxy-Informationen anzeigen

Um zu überprüfen, ob der Proxy korrekt funktioniert und ob noch genügend Traffic verfügbar ist, klicken Sie auf das Symbol mit den **kreisförmigen Pfeilen** neben der Proxy-Flagge. In diesem Menü können Sie außerdem Folgendes einsehen:

- **City**
- **IP address**
- **Proxy type**
- **Remaining traffic**

So können Sie schnell bestätigen, dass der Proxy aktiv und wie gewünscht konfiguriert ist.

<Frame>
  ![Checking Gologin Proxy](/images/checking_gologin_proxy.png)
</Frame>

## Proxy vom Profil trennen

Wenn Sie einen Gologin Proxy vom Profil trennen möchten, **klicken Sie einmal auf den Proxy** und dann auf das **X**. Der Proxy wird vom Profil getrennt, bleibt aber in der Liste des Proxy-Managers erhalten.

<Frame>
  ![Unlink Gologin Proxy](/images/unlink_gologin_proxy.gif)
</Frame>

## Proxy löschen

So löschen Sie einen Proxy: **Klicken Sie in einem Profil einmal auf den Proxy**, um den Proxy-Manager zu öffnen, **klicken Sie dann mit der rechten Maustaste darauf** \> **Delete proxy** \> **bestätigen Sie Ihre Auswahl**. Der Proxy wird aus Ihrer Proxy-Liste entfernt und kann über das [Proxy Archive](/de/proxy/proxy-management/proxy-manager/proxy-archive) wiederhergestellt werden.

<Frame>
  ![Delete Gologin Proxy](/images/delete_gologin_proxy.gif)
</Frame>

## Proxy-Zugangsdaten kopieren

Sie können die Zugangsdaten eines Gologin Proxys (Host, Port, Login, Passwort) kopieren, um sie an anderer Stelle zu verwenden. Gehen Sie dazu so vor: **Klicken Sie auf einen Proxy**, um den Proxy-Manager zu öffnen \> **klicken Sie mit der rechten Maustaste darauf** \> **Copy proxy**.

<Frame>
  ![Copy Gologin Proxy](/images/copy_gologin_proxy.gif)
</Frame>

## Massenaktionen für Proxys

Sie können im Proxy-Manager mehrere Proxys auswählen und Aktionen ausführen, zum Beispiel:

- alle Proxys auswählen
- Proxys kopieren
- Proxys löschen

So gehen Sie vor: **Klicken Sie auf der Seite All profiles auf einen beliebigen Proxy** \> **klicken Sie mit der rechten Maustaste darauf** \> klicken Sie auf **Select proxy**. Anschließend können Sie die gewünschten Proxys anhaken und die Aktionen über die Schaltflächen am unteren Rand des Proxy-Managers ausführen.
