## Traffic-basierte Proxys

### Wie wähle ich den Proxy-Typ aus?

Um den Proxy-Typ für Ihre neue Verbindung auszuwählen, erstellen Sie einfach einen neuen Proxy-Server. Klicken Sie dazu im Profil auf **Choose location or proxy \> arrow next to the country \> Add new server \> choose the proxy type**.

### Wie viel Traffic benötige ich?

Der erforderliche Umfang hängt von Ihrem Anwendungsfall ab. Er richtet sich vor allem danach,

- wie oft Sie Ihre Browserprofile verwenden,
- wie lange Ihre Sitzungen dauern,
- wie viele datenintensive Inhalte (z. B. Videos, Bilder oder Audio) Sie bei der Arbeit laden.

### Was passiert, wenn mein Proxy-Traffic aufgebraucht ist? Werde ich dann erkannt?

Wenn Ihr Traffic während der Nutzung aufgebraucht ist, trennt Gologin Ihre Profile einfach vom Internet. Sie können sie erst wieder verwenden, wenn Sie Traffic nachkaufen oder auf einen Proxy eines Drittanbieters wechseln. Sie können die Profile ohne Datenverlust schließen, da die Profilsynchronisierung keinen Proxy-Traffic verbraucht.

### Verbrauche ich Gologin-Proxy-Traffic, wenn ich meine eigenen Proxys von Drittanbietern verwende?

Natürlich nicht! Gologin-Proxy-Traffic verbrauchen Sie nur, wenn Sie unsere Proxys nutzen.

### Erhalte ich nach der Registrierung in meinem Testplan kostenlosen Gologin-Proxy-Traffic zum Ausprobieren?

Gologin bietet neu registrierten Nutzern derzeit keinen Test-Traffic an. Sie können jederzeit etwas Traffic kaufen und selbst prüfen, ob die Gologin-Proxys Ihren Anforderungen entsprechen.

### Warum funktionieren einige Ports bei Gologin-Proxys nicht?

Die Ports 80 und 443 funktionieren garantiert. Das sind die Standardports für normalen Website-Traffic.

Alle anderen Ports werden blockiert, da sie hauptsächlich für Spam-Versand, DDoS-Angriffe und Brute-Force-Angriffe genutzt werden.

### Benötigen Gologin-Proxys einen Benutzernamen und ein Passwort?

Ja. Gologin-Proxys verwenden immer einen Benutzernamen und ein Passwort. Wenn Sie einen Gologin-Proxy kopieren, um ihn an anderer Stelle zu verwenden, kopieren Sie alle Zugangsdaten, da die Proxy-Prüfung sonst fehlschlägt.

### Wann kann ich den gekauften Traffic nutzen?

Sofort nach Abschluss der Zahlung.

### Unterstützen Gologin-Proxys SOCKS5?

Ja. Wählen Sie das Protokoll in den Proxy-Einstellungen des Profils aus – siehe [Auswahl des Proxy-Protokolls](/de/proxy/gologin-proxies/gologin-proxy-management/gologin-proxy-settings#choosing-the-proxy-protocol-http-or-socks5).

### Kann ich Gologin-Proxys für Banking- oder Zahlungswebsites verwenden?

Traffic-basierte Gologin-Proxys funktionieren nicht mit Banking- und Zahlungswebsites wie Stripe oder PayPal. Verwenden Sie einen Proxy eines Drittanbieters, der diese Websites unterstützt. Siehe [Banking- und Zahlungswebsites](/de/proxy/gologin-proxies/what-are-gologin-proxies#banking-and-payment-websites).

## Dedicated IP

### Was ist der Unterschied zwischen ISP-Proxys, statischen Proxys und Dedicated IP?

Es gibt keinen – es sind drei Bezeichnungen für dasselbe. Sie begegnen Ihnen im Internet alle drei. In Gologin heißt die Funktion **Dedicated IP**.

### Was ist eine Dedicated IP?

Eine Dedicated IP ist eine einzelne IP-Adresse, die nur für Sie reserviert ist und die sonst niemand nutzt. Sie stammt von einem echten Internetanbieter, wird aber in einem Rechenzentrum gehostet. Dadurch bietet sie die Geschwindigkeit und Stabilität eines Rechenzentrums-Proxys, wirkt auf Websites aber wie ein gewöhnlicher Privatanschluss. Sie wechselt nie und hat kein Traffic-Limit.

### Ich habe einen Jahresplan. Warum wurde mir mehr als \$5 berechnet?

Eine Dedicated IP ist an Ihr Hauptabonnement gebunden und endet immer zusammen mit diesem. Deshalb zahlen Sie für die verbleibenden Monate. Wenn Ihr Jahresplan noch 7 Monate läuft, werden Ihnen vorab \$35 berechnet. Ein angefangener Monat wird als voller Monat abgerechnet.

### Ich habe bezahlt, sehe meinen Dedicated-IP-Proxy aber nirgends

Es dauert 5–7 Minuten, bis die Adresse Ihrem Konto zugewiesen wird, und Sie erhalten keine Benachrichtigung, wenn sie bereit ist. Warten Sie ein paar Minuten und aktualisieren Sie die Seite **Proxies** – dann ist der Proxy dort zu finden.

### Verbraucht eine Dedicated IP den Proxy-Traffic meines Plans?

Nein. Der Traffic über eine Dedicated IP ist unbegrenzt und wird nicht von Ihrem GB-Kontingent abgezogen. Selbst wenn Ihr Kontingent vollständig aufgebraucht ist, funktionieren Profile mit einer Dedicated IP weiterhin.

### Benötige ich weiterhin Proxy-Traffic, wenn ich eine Dedicated IP habe?

Nur für Profile, die unsere rotierenden Proxys verwenden. Wenn alle Ihre Profile mit einer Dedicated IP laufen, bleibt Ihr Traffic-Kontingent einfach ungenutzt.

### Bleibt meine IP bei einer Dedicated IP immer gleich?

Ja. Solange Ihr Abonnement aktiv ist und verlängert wird, behalten Sie dieselbe Adresse.

### Ich habe mit Kryptowährung bezahlt – wird meine Dedicated IP verlängert?

Nein. Zahlungen mit Kryptowährung können nicht automatisch verlängert werden. Die IP funktioniert daher für den bezahlten Zeitraum und wird danach deaktiviert. Dieselbe Adresse können Sie anschließend nicht zurückerhalten. Wenn Sie eine Adresse langfristig behalten möchten, zahlen Sie per Karte.
