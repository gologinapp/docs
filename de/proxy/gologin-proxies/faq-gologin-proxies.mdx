## Trafficbasierte Proxys

### Wie wähle ich den Proxy-Typ aus?

Um den Proxy-Typ für Ihre neue Verbindung auszuwählen, erstellen Sie einfach einen neuen Proxy-Server: Klicken Sie im Profil auf **Choose location or proxy \> arrow next to the country \> Add new server \> choose the proxy type**.

### Wie viel Traffic brauche ich?

Der benötigte Umfang hängt von Ihrem Anwendungsfall ab. Er variiert vor allem je nach:

- Wie oft Sie Ihre Browserprofile nutzen
- Wie lange Ihre Sitzungen dauern
- Wie viele datenintensive Inhalte (z. B. Videos, Bilder oder Audio) Sie bei der Arbeit laden

### Was passiert, wenn mein Proxy-Traffic aufgebraucht ist? Werde ich dann erkannt?

Wenn Ihr Traffic während der Nutzung aufgebraucht ist, trennt Gologin Ihre Profile einfach vom Internet. Sie können sie erst wieder verwenden, wenn Sie Traffic nachkaufen oder auf einen Proxy eines Drittanbieters wechseln. Sie können die Profile ohne Datenverlust schließen, da die Profilsynchronisierung keinen Proxy-Traffic verbraucht.

### Verbrauche ich Gologin-Proxy-Traffic, wenn ich meine eigenen Proxys von Drittanbietern nutze?

Natürlich nicht! Gologin-Proxy-Traffic verbrauchen Sie nur, wenn Sie unsere Proxys verwenden.

### Erhalte ich nach der Registrierung in meinem Testtarif kostenlosen Gologin-Proxy-Traffic zum Ausprobieren?

Gologin bietet neu registrierten Nutzern derzeit keinen Test-Traffic an. Sie können aber jederzeit etwas Traffic kaufen und ausprobieren, ob die Gologin-Proxys zu Ihren Anforderungen passen.

### Einige Ports funktionieren bei Gologin-Proxys nicht. Warum?

Die Ports 80 und 443 funktionieren garantiert. Das sind die Standardports für regulären Website-Traffic.

Alle anderen Ports, die hauptsächlich für Spam-Mails, DDoS-Angriffe und Brute-Force-Attacken genutzt werden, sind gesperrt.

## Dedicated IP

### Was ist der Unterschied zwischen ISP-Proxys, statischen Proxys und Dedicated IP?

Es gibt keinen – das sind drei Bezeichnungen für dasselbe. Sie begegnen im Internet allen dreien. In Gologin heißt die Funktion **Dedicated IP**.

### Was ist eine Dedicated IP?

Das ist eine einzelne IP-Adresse, die ausschließlich für Sie reserviert ist. Sie stammt von einem echten Internetanbieter, wird aber in einem Rechenzentrum gehostet. So bietet sie die Geschwindigkeit und Stabilität eines Rechenzentrums-Proxys und wirkt für Websites wie ein gewöhnlicher Heimanschluss. Sie wechselt nie und hat kein Trafficlimit.

### Ich habe einen Jahrestarif. Warum wurde mir mehr als \$5 berechnet?

Eine Dedicated IP ist an Ihr Hauptabonnement gebunden und endet immer zusammen mit diesem. Deshalb zahlen Sie für die verbleibenden Monate. Wenn Ihr Jahrestarif noch 7 Monate läuft, werden Ihnen \$35 im Voraus berechnet. Ein angefangener Monat wird als voller Monat abgerechnet.

### Ich habe bezahlt, sehe meinen Dedicated-IP-Proxy aber nirgends

Es dauert 5–7 Minuten, bis die Adresse Ihrem Konto zugewiesen wird, und Sie erhalten keine Benachrichtigung, wenn sie bereit ist. Warten Sie ein paar Minuten und aktualisieren Sie die Seite **Proxies** – dort wird sie dann angezeigt.

### Verbraucht eine Dedicated IP den Proxy-Traffic meines Tarifs?

Nein. Der Traffic über eine Dedicated IP ist unbegrenzt und wird nicht von Ihrem GB-Kontingent abgezogen. Selbst wenn Ihr Kontingent vollständig aufgebraucht ist, funktionieren Profile mit einer Dedicated IP weiter.

### Brauche ich weiterhin Proxy-Traffic, wenn ich eine Dedicated IP habe?

Nur für Profile, die unsere rotierenden Proxys verwenden. Wenn alle Ihre Profile über eine Dedicated IP laufen, bleibt Ihr Traffic-Kontingent einfach ungenutzt.

### Bleibt meine IP bei einer Dedicated IP gleich?

Ja. Solange Ihr Abonnement aktiv ist und sich verlängert, behalten Sie dieselbe Adresse.

### Ich habe mit Kryptowährung bezahlt – wird meine Dedicated IP verlängert?

Nein. Zahlungen mit Kryptowährung können nicht automatisch verlängert werden. Die IP funktioniert daher für den bezahlten Zeitraum und wird dann deaktiviert. Danach können Sie dieselbe Adresse nicht mehr zurückerhalten. Wenn Sie eine Adresse langfristig behalten möchten, zahlen Sie per Karte.
