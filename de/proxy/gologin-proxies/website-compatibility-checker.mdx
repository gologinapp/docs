### Was ist das?

Bevor Sie einen Proxy kaufen, sollten Sie sicherstellen, dass sich die Zielwebsite tatsächlich öffnen lässt und die IP-Adresse nicht blockiert.

**Website Checker** ist ein einfaches Online-Tool, das zeigt, ob eine bestimmte Website über Gologin-Proxys erreichbar ist. Sie geben eine URL ein, wählen den Proxy-Typ (Residential, Mobile oder Data Center) sowie den Standort und erhalten anschließend das Ergebnis der Prüfung.

Außerdem erhalten Sie einen allgemeinen Überblick über den **Fraud Score, die verfügbaren ASNs und IPs** der Gologin-Proxys in den gewünschten Regionen\\Proxy-Typen.

Wenn Sie Probleme beim Laden der Website mit Gologin-Proxys haben, prüfen Sie zuerst die Erreichbarkeit mit diesem Tool.
