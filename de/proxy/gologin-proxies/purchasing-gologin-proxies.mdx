title: "Gologin-Proxys kaufen"
---

Gologin verkauft Proxys auf zwei Arten:

- **Proxy-Traffic** in Gigabyte, der für unsere Residential-, Mobile- und Datacenter-Proxys verwendet wird. In jedem kostenpflichtigen Tarif ist bereits etwas Traffic enthalten.
- **Dedicated IP** – eine einzelne statische IP-Adresse, die exklusiv für Sie reserviert ist. Sie wird als Abonnement für \$5/Monat pro Adresse verkauft. Dieser Artikel behandelt beides.

## Standardmäßiger Proxy-Traffic

Alle kostenpflichtigen Tarife enthalten pro Monat **2 GB Residential-Proxy-Traffic**, unabhängig von der Tarifstufe oder vom Abrechnungszeitraum (monatlich oder jährlich). Dieser Traffic wird zu Beginn jedes Abrechnungsmonats erneuert. Er wird nicht übertragen – nicht genutzter Traffic aus dem Vormonat wird durch frische 2 GB ersetzt.

In der App kann dieses Kontingent als **2GB of location data** angezeigt werden. Gologin-Proxy-Traffic ist im Tarif Forever Free nicht enthalten.

<Check>
  Auch Abonnenten mit Jahrestarif erhalten 2 GB pro Monat, nicht 2 GB pro Jahr. Die Erneuerung erfolgt jeden Monat während der gesamten Laufzeit des Abonnements.
</Check>

## Zusätzlichen Traffic kaufen

### Einmalige Aufladung

Eine Aufladung ist ein einmaliger Kauf von zusätzlichem Traffic. Nutzen Sie sie, wenn Sie gelegentlich einen höheren Verbrauch haben und nicht jeden Monat mehr Traffic benötigen.

**Schritte:**

1. Klicken Sie auf der Hauptseite **All profiles** im linken Seitenmenü auf die Traffic-Anzeige neben dem Tab **Proxies**.
2. Wählen Sie den **proxy type** aus, für den Sie Traffic kaufen möchten.
3. Wählen Sie die gewünschte **amount of traffic**.
4. Klicken Sie neben der gewählten Menge auf die Schaltfläche **\+** und fahren Sie mit dem Checkout fort.

<Frame>
  ![Proxy Top Up](/images/proxy_top_up.png)
</Frame>

<Info>
  Die in der App angezeigten Preise sind am aktuellsten. Prüfen Sie sie vor dem Kauf direkt dort.
</Info>

**Zahlungsmethoden für Aufladungen:**

Sie können mit Kredit- oder Debitkarte oder mit Kryptowährung bezahlen. Nutzer aus einigen Ländern – etwa Russland und Belarus – können Aufladungen unter Umständen nicht per Karte bezahlen. Wird Ihre Kartenzahlung abgelehnt, nutzen Sie stattdessen Kryptowährung.

### Abo-Zusatz

Ein Abo-Zusatz fügt Ihrem Tarif regelmäßig eine bestimmte Menge Proxy-Traffic hinzu. Das heißt, der Traffic wird jeden Monat automatisch ergänzt.

Sie können Ihrem Abonnement beim ersten Checkout oder jederzeit später Traffic hinzufügen, indem Sie Ihren aktuellen Tarif ändern.

**So fügen Sie Ihrem aktuellen Tarif Traffic hinzu:**

1. Klicken Sie auf der Hauptseite **All profiles** unten links neben Ihren Tarifinformationen auf das **Zahnrad-Symbol**.
2. Klicken Sie auf **Change plan**.
3. Bestätigen Sie auf der Preisseite Ihren Tarif – Sie sollten die Schaltfläche **Renew the current plan** sehen. Das bedeutet, dass Sie Ihren aktuellen Tarif erweitern und nicht wechseln.
4. Suchen Sie den Zusatz für **proxy traffic** und legen Sie die Menge fest, die jeden Monat hinzugefügt werden soll.
5. Klicken Sie auf **Upgrade now**, wählen Sie die Zahlungsmethode und klicken Sie auf **Pay now**, um den Checkout abzuschließen.

<Frame>
  ![Proxy With Subscription](/images/proxy_with_subscription.gif)
</Frame>

**So funktioniert wiederkehrender Traffic:**

- **Monatlicher Tarif** – Die zusätzliche Traffic-Menge wird jeden Monat bei der Verlängerung Ihres Abonnements berechnet und hinzugefügt.
- **Jahrestarif** – Der Zusatz wird einmalig als Teil Ihres Jahresabonnements bezahlt und Ihrem Konto das ganze Jahr über jeden Monat gutgeschrieben.

Weitere Informationen zum Ändern Ihres Tarifs finden Sie unter [Change and upgrade subscription](/de/general/account-and-billing/change-plan).

## Eine Dedicated IP kaufen

Eine **Dedicated IP** ist eine einzelne statische Adresse, die nur Ihnen gehört. Sie wechselt nie, hat kein Traffic-Limit und ist die richtige Wahl für jedes Konto, das seine IP-Adresse dauerhaft beibehalten muss – Amazon, eBay, LinkedIn, Meta Ads, PayPal, Wettplattformen.

<Info>
  Dedicated IPs sind nur in kostenpflichtigen Tarifen verfügbar. Sie sind nicht Teil der kostenlosen Testphase.
</Info>

### Schritte

1. Klicken Sie auf **Add profile**.
2. Öffnen Sie den Tab **Proxy** und wählen Sie **Gologin proxy**.
3. Klicken Sie auf **Buy dedicated IP**.
4. Wählen Sie im Auswahlfeld ein Land aus.
5. Klicken Sie auf **Buy for \$5/month**.
6. Schließen Sie den Checkout im geöffneten Abrechnungsfenster ab. Sie können per Karte über Stripe oder mit Kryptowährung über Cryptomus bezahlen.
7. Wenn Sie zu Gologin zurückkehren, bestätigt ein Fenster, dass die Zahlung erfolgreich war.
8. Warten Sie **5-7 Minuten**, bis die IP Ihrem Konto zugewiesen wurde.

<Frame>
  ![Buying Dedicated IP](/images/buying_dedicated_IP.gif "Buying Dedicated IP")
</Frame>

<Note>
  Der Preis beträgt immer **\$5** – Gologin erhebt keine zusätzlichen Bearbeitungsgebühren. Wenn Sie mit Kryptowährung bezahlen, kann Ihre eigene Wallet oder Börse zusätzlich zur Rechnung eine Netzwerkgebühr berechnen. Weitere Informationen finden Sie unter [Payment methods](https://gologin.com/docs/general/account-and-billing/payment-methods).
</Note>

### Ihre Dedicated IP nach dem Kauf finden

Die IP wird **nicht automatisch einem Profil zugewiesen**. Aktualisieren Sie die Seite nach 5-7 Minuten – eventuell müssen Sie sie neu laden, damit die IP erscheint.

Ihre Dedicated IP ist dann an drei Stellen verfügbar:

- Auf der Seite **Proxies** in der Liste Ihrer eigenen Proxys
- Im Tab **Your proxy** auf der Seite **New Browser Profile**
- Im Proxy-Manager auf der Seite **All profiles**, wenn Sie einem bestehenden Profil einen Proxy zuweisen

### So funktioniert die Abrechnung der Dedicated IP

Eine Dedicated IP ist an Ihr Haupt-Abonnement bei Gologin gebunden und endet daher immer mit dem Ende Ihres Abonnements.

| Ihr Tarif | Was Sie zahlen |
| --- | --- |
| Monatlich | \$5, sofort berechnet, verlängert sich jeden Monat mit Ihrem Tarif |
| Jährlich, mit verbleibenden Monaten | \$5 × Anzahl der verbleibenden Monate, sofort berechnet |

Wenn bei Ihrem Jahrestarif noch ein angebrochener Monat übrig ist, wird er als voller Monat berechnet.

**Solange Ihr Abonnement aktiv ist und verlängert wird, bleibt die IP gleich.** Sie behalten dieselbe Adresse, bis Sie kündigen.

<Warning>
  Wenn Sie mit Kryptowährung bezahlen, kann die Dedicated IP nicht automatisch verlängert werden. Sie funktioniert für den bezahlten Zeitraum und wird danach beendet. Dieselbe IP können Sie anschließend nicht zurückerhalten.
</Warning>

### Kündigung und Rückerstattung

- Eine Dedicated IP wird zusammen mit Ihrem Gologin-Abonnement gekündigt. Eine separate Kündigung einzelner IPs ist derzeit nicht möglich.
- Wenn Sie kündigen, funktioniert die IP bis zum Ende des bereits bezahlten Zeitraums weiter.
- Rückerstattungen sind innerhalb von **14 Tagen** nach dem Kauf möglich – wenden Sie sich an den Support.

<Note>
  Eine Dedicated IP gehört dem Konto, das sie gekauft hat, und wird nicht mit anderen Mitgliedern des Workspace geteilt. Wenn Sie sie jedoch einem Profil zuweisen und dieses Profil teilen, kann jeder mit Zugriff auf das Profil sie nutzen.
</Note>
