---
title: "Was sind Gologin Proxys"
---

Gologin Proxys sind IP-Adressen, die **direkt in den Gologin-Browser integriert** sind. Wenn einem Browserprofil ein Proxy zugewiesen ist, legt dieser fest, **woher Ihr Internetverkehr stammt**, und sorgt dafür, dass Websites jedes Profil als **eigenen, echten Nutzer** wahrnehmen.

So wird verhindert, dass Websites und Plattformen **mehrere Konten anhand der IP-Adresse miteinander verknüpfen**. Das senkt das Risiko von Sperren, Einschränkungen oder Sicherheitsprüfungen.

## Integrierte Proxys vs. eigene Proxys

Gologin unterstützt **zwei Arten der Proxy-Nutzung**, je nach Bedarf und Erfahrung.

- **Integrierte Proxys** Integrierte Proxys werden **von Gologin bereitgestellt und verwaltet**. Sie sind sofort einsatzbereit, erfordern keine externe Einrichtung und arbeiten nahtlos mit unserem Browser-Fingerprinting-System zusammen. Sie sind die beste Wahl, wenn Sie eine **einfache, stabile und schnelle Einrichtung** ohne Drittanbieter-Dienste wünschen.
- **Eigene Proxys** Eigene Proxys werden **bei Drittanbietern gekauft** und manuell zu Gologin hinzugefügt. Diese Option bietet mehr Flexibilität bei der Wahl von Proxy-Anbietern, Standorten und Proxy-Formaten. Sie eignet sich besser für **fortgeschrittene Nutzer**, die mehr Kontrolle über ihre Proxy-Infrastruktur benötigen.

Integrierte Proxys eignen sich ideal für **Einfachheit und Zuverlässigkeit**, während eigene Proxys **mehr Kontrolle** für fortgeschrittene Setups bieten.

## Arten von Gologin Proxys

Je nach Tarif und Bedarf bietet Gologin unter Umständen verschiedene Proxy-Typen an, zum Beispiel:

- **Residential Proxys** – IPs echter Nutzer, für die meisten Plattformen geeignet
- **Mobile Proxys** – IPs aus Mobilfunknetzen, nützlich für Umgebungen mit höheren Vertrauensanforderungen
- **Datacenter Proxys** – schneller und günstiger, aber leichter zu erkennen
- **Dedicated IP** - eine IP-Adresse, die ausschließlich Ihnen vorbehalten ist. Sie ändert sich nie, stammt von einem echten Internetanbieter und hat kein Traffic-Limit.

Residential, Mobile und Datacenter Proxys werden nach Traffic (in Gigabyte) abgerechnet. Eine Dedicated IP wird separat bezahlt, als Abo für \$5/Monat pro IP, und ist in kostenpflichtigen Tarifen verfügbar.

<Note>
  **Dedicated IP**, **ISP-Proxy** und **statischer Proxy** bedeuten alle dasselbe. In der Gologin-App heißt die Option **Buy dedicated IP**, und dieser Begriff wird in der gesamten Dokumentation verwendet.
</Note>

## Rotierende Proxys

Die Residential und Mobile Proxys von Gologin sind rotierend: Die IP-Adresse wechselt automatisch etwa alle **3-15 Minuten**, kann sich also während einer Browsersitzung ändern. Gologin bietet keine statischen Residential Proxys mit Traffic-basierter Abrechnung an. Wenn Sie eine IP benötigen, die sich nie ändert, nutzen Sie eine **Dedicated IP** – das ist eine statische Residential-Adresse (ISP).

**Rotation ist geeignet für:**

- Web Scraping
- Kurze Browsersitzungen
- Allgemeine Recherche **Wann Sie keine rotierenden Proxys verwenden sollten**

<Warning>
  Verwenden Sie keine rotierenden Proxys für Amazon, eBay, Etsy, PayPal oder andere Marktplätze, die den Kontoverlauf überwachen. Rotierende IPs gehören auf diesen Plattformen zu den schnellsten Wegen, Konten verknüpfen und sperren zu lassen. Nutzen Sie für diese Konten stattdessen eine Dedicated IP.
</Warning>

- Amazon und eBay erkennen, wenn sich dasselbe Konto im Lauf der Zeit von verschiedenen IP-Adressen anmeldet. Sie werten dies als Hinweis darauf, dass ein Konto von Dritten verwaltet wird oder Teil eines Multi-Account-Schemas ist. Ein rotierender Proxy ändert Ihre IP bei jeder Sitzung – genau das Muster, das diese Plattformen markieren.
- LinkedIn meldet Sitzungen ab und löst Sicherheitsprüfungen aus, wenn sich die IP zwischen Sitzungen ändert. Rotierende Proxys führen zu häufigen Abmeldungen und Verifizierungsaufforderungen.
- Wettplattformen verlangen pro Konto konsistente IP-Adressen. Ein IP-Wechsel wird als verdächtige Anmeldeaktivität behandelt und führt oft zu Kontoeinschränkungen.
- PayPal und Finanzplattformen werten IP-Wechsel als mögliche Kontokompromittierung. Sie können das Konto einfrieren oder eine Identitätsprüfung verlangen.

## Banking- und Zahlungs-Websites

Die Traffic-basierten Proxys von Gologin (Residential, Mobile und Datacenter) funktionieren nicht mit Banking- und Zahlungs-Websites wie Stripe oder PayPal – die Seiten werden möglicherweise nicht geladen oder zeigen einen Verbindungsfehler an. Um in einem Profil Zahlungen zu tätigen oder mit Banking-Websites zu arbeiten, verwenden Sie einen Drittanbieter-Proxy, der diese Websites unterstützt.

## Was Sie stattdessen verwenden sollten

Für die langfristige Verwaltung von Konten auf sensiblen Plattformen benötigen Sie pro Konto eine IP-Adresse, die sich nie ändert. In Gologin ist das eine **Dedicated IP**.

| Plattform | Empfohlener Proxy-Typ |
| --- | --- |
| Amazon / eBay / Etsy | Dedicated IP |
| LinkedIn | Dedicated IP |
| Facebook / Meta Ads | Dedicated IP oder statischer Mobile Proxy |
| Wettseiten | Statischer Mobile Proxy |
| Web Scraping | Rotierende Residential oder Datacenter Proxys |
| Tests / schnelle Prüfungen | Rotierende Gologin Proxys sind in Ordnung |

Eine vollständige Übersicht finden Sie unter [Der beste Proxy für Ihren Anwendungsfall](https://gologin.com/docs/proxy/introduction/best-proxy-for-your-case), konkrete Dienste unter [Empfohlene Proxy-Anbieter](https://gologin.com/best-proxy-server-services/).

## Inklusives Traffic-Kontingent

Jeder Gologin-Tarif enthält ein Proxy-Traffic-Kontingent, das in Gigabyte gemessen wird. Das ist die Datenmenge, die über den Proxy läuft, während Ihre Profile im Internet surfen – kein Speicherplatz.

**Grobe Schätzwerte:**

- Leichtes Surfen (Feeds prüfen, Seiten lesen): ~0,3–0,5 GB pro Profil und Tag
- Aktives Arbeiten (Medien laden, Anzeigen schalten): ~1–2 GB pro Profil und Tag
- 10 LinkedIn-Profile bei 2 Stunden Nutzung pro Tag: ~3–6 GB pro Monat

Wenn Sie einen eigenen Drittanbieter-Proxy mit einem Profil verbinden, verbraucht dieser Ihr Gologin-Traffic-Kontingent nicht – nur Traffic, der über das eigene Proxy-Netzwerk von Gologin läuft, wird angerechnet.
