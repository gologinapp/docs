---
title: "So funktionieren Gologin-Proxys"
---

Gologin-Proxys sind direkt in die Gologin-Umgebung integriert und lassen sich ohne zusätzliche Konfiguration Browserprofilen zuweisen.

Wenn einem Profil ein Proxy zugewiesen ist, wird der gesamte Internetverkehr dieses Profils über den Proxyserver geleitet. Das bedeutet, dass Websites die IP-Adresse des Proxys statt Ihrer echten IP-Adresse sehen.

Wenn Sie für verschiedene Profile separate Proxys verwenden, bleiben die Sitzungen voneinander getrennt, und die Wahrscheinlichkeit sinkt, dass mehrere Konten miteinander in Verbindung gebracht werden.

## Verfügbare Proxy-Typen

Gologin bietet mehrere Proxy-Typen an:

- **Residential rotating** - Abrechnung nach Datenverkehr
- **Mobile rotating** - Abrechnung nach Datenverkehr
- **Datacenter sticky** - Abrechnung nach Datenverkehr
- **Dedicated IP** - eine für Sie reservierte statische IP-Adresse, abgerechnet als Abonnement für \$5/Monat pro IP

Die ersten drei teilen sich das Datenvolumen Ihres Tarifs und beziehen eine Adresse aus einem gemeinsamen Pool. Eine Dedicated IP gehört nur Ihnen, wird nicht rotiert und unterliegt keinem Datenlimit.

## Proxy-Länder

**Für verbrauchsbasierte Proxys (Residential, Mobile, Datacenter):** Wenn Sie Gologin-Proxy-Datenverkehr kaufen, erhalten Sie Zugriff auf alle unsere Proxy-Länder. Sie sind nicht auf ein einzelnes Land beschränkt – der Datenverkehr kann für jedes Land der Liste genutzt werden. Wir bieten Dutzende Länder an und ergänzen von Zeit zu Zeit neue. Die vollständige Liste finden Sie direkt in der Gologin-App.

**Für Dedicated IP:** Sie kaufen jeweils ein Land. Die IP-Adresse, die Sie erhalten, gehört zum gewählten Land und kann nicht in ein anderes verschoben werden. Wenn Sie Adressen in mehreren Ländern benötigen, kaufen Sie für jedes Land eine eigene Dedicated IP.

Dedicated IPs sind derzeit in folgenden Ländern verfügbar:

- Brasilien
- Frankreich
- Deutschland
- Hongkong
- Rumänien
- Türkei
- Vereinigtes Königreich
- Vereinigte Staaten

<Note>
  Sie können mehr als eine Dedicated IP im selben Land kaufen. Jeder Kauf liefert Ihnen eine andere Adresse, und diese werden im Proxy-Manager unter dem jeweiligen Land gruppiert.
</Note>

## Das bieten Gologin-Proxys

Die Nutzung von Gologin-Proxys bietet mehrere Vorteile:

- schnelle Einrichtung ohne Konfiguration durch Drittanbieter
- einfache Zuweisung von Proxys zu Profilen
- Integration in Gologin-Browserprofile
- vereinfachte Proxy-Verwaltung innerhalb der Anwendung
