---
title: "Was ist ein Proxy"
---

Ein Proxy ist ein Server, der als Vermittler zwischen Ihrem Gerät und dem Internet fungiert.\
Anstatt sich direkt mit einer Website zu verbinden, wird Ihr Datenverkehr über den Proxy-Server geleitet.

Das bedeutet, dass Websites die **IP-Adresse des Proxys** statt Ihrer echten IP-Adresse sehen. So wirkt es, als käme die Anfrage von einem anderen Standort.

In Kombination mit **Gologin** arbeitet ein Proxy zusammen mit dem Browser-Fingerprint eines Profils.\
Jedes Profil kann über einen anderen Proxy verbunden werden, sodass Websites die Profile als getrennte Geräte erkennen.

## Warum die Verwendung eines Proxys wichtig ist

Die Verwendung eines Proxys ist bei der Arbeit mit Gologin **entscheidend**.

Websites verfolgen die Aktivitäten von Nutzern, indem sie sowohl **Browser-Fingerprints als auch die IP-Adresse** analysieren.\
Selbst wenn Sie verschiedene Browserprofile verwenden, werden mehrere Konten dennoch über dieselbe IP-Adresse miteinander verknüpft.

Mit einem Proxy kann jedes Profil von einem anderen Netzwerkstandort aus arbeiten. Dadurch sinkt die Wahrscheinlichkeit, dass Konten demselben Gerät zugeordnet werden.

## Wo Sie einen Proxy erhalten

Gologin unterstützt sowohl **Proxys von Drittanbietern** als auch **integrierte Gologin-Proxys**.

Sie können Proxys externer Anbieter verbinden, indem Sie die Proxy-Zugangsdaten in den Profileinstellungen eingeben.

Gologin bietet außerdem integrierte Proxy-Optionen, die direkt in der Anwendung konfiguriert werden können.

Eine Liste empfohlener Proxy-Anbieter finden Sie unter [**Empfohlene Proxy-Anbieter**](https://gologin.com/proxies/proxy-type/).
