Diese Anleitung hilft Ihnen zu überprüfen, ob Ihr Proxy korrekt funktioniert, und zeigt Ihnen, wie Sie häufige Verbindungsprobleme beheben.

### So testen Sie einen Proxy

1. Weisen Sie Ihrem Browserprofil den Proxy zu.
2. Klicken Sie neben dem Proxy-Standort auf das **refresh icon**.
3. Warten Sie, bis das System die Verbindung geprüft hat.

Wenn der Proxy korrekt funktioniert, zeigt das System Folgendes an:

- IP-Adresse des Proxys
- Land oder Standort
- Verbindungsstatus

Wenn der Proxy korrekt funktioniert, wird die Statusanzeige **grün** angezeigt.
