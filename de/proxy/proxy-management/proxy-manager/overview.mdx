---
title: "Integrierter Proxy-Manager"
---

Mit dem **Built-in Proxy Manager** können Sie Proxys, die Sie in Ihren Gologin-Browserprofilen verwenden, speichern und verwalten.

Er bietet eine zentrale Liste, in der Sie Proxys von **Gologin** und von **Drittanbietern** ablegen und bei Bedarf schnell Profilen zuweisen können.

Der Proxy Manager ist direkt über die Seite **All Profiles** erreichbar und erleichtert die Proxy-Verwaltung, wenn Sie mit mehreren Konten arbeiten. Er ist der Proxy-Manager, den die meisten Gologin-Nutzer bevorzugen.

<Frame>
  ![Proxy Manager](/images/proxy_manager.png)
</Frame>

Mit dem Proxy Manager können Sie:

- Proxys in einer eigenen Liste speichern
- Proxys in verschiedenen Profilen wiederverwenden
- Proxys von Gologin und externen Anbietern an einem Ort verwalten
- Proxys beim Erstellen oder Bearbeiten von Profilen schnell zuweisen

Dieses Tool ist besonders nützlich, wenn Sie viele Profile verwalten oder mit mehreren Proxy-Anbietern arbeiten.
