title: "Anwendungsfälle für Web Unlocker"

Web Unlocker ist eine Scraping API: Sie senden eine URL und erhalten das vollständig gerenderte HTML zurück. Diese Seite zeigt die gängigsten Einsatzmöglichkeiten.

---

## Eine Seite selbst scrapen

Der einfachste Anwendungsfall: Sie benötigen den Inhalt einer Webseite, die normale HTTP-Anfragen blockiert.

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com/product/123"},
    headers={"apikey": "YOUR_API_KEY"}
)

html = response.text
print(html)
```

### JavaScript

```javascript
const html = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com/product/123"),
  { headers: { apikey: "YOUR_API_KEY" } }
).then((r) => r.text());

console.log(html);
```

Sie müssen keinen Browser starten, keinen Proxy konfigurieren und sich nicht mit Cloudflare herumschlagen. Ein Aufruf genügt, und Sie erhalten die Seite.

**Geeignet für:**

- Preise auf der Website eines Mitbewerbers prüfen
- Stellenanzeigen, Bewertungen oder Produktdaten abrufen
- Seiten auf Änderungen überwachen
- Einmalige Skripte zur Datenerfassung

## Inhalte an eine KI übergeben

Web Unlocker liefert rohes HTML. Übergeben Sie dieses an ein LLM, um strukturierte Daten zu extrahieren, Inhalte zusammenzufassen oder Fragen zur Seite zu beantworten – ganz ohne eigene Parsing-Logik.

### Python \+ OpenAI

```python
import requests
from openai import OpenAI

html = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://news.ycombinator.com"},
    headers={"apikey": "YOUR_API_KEY"}
).text

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {
            "role": "user",
            "content": f"Extract the top 5 story titles and their URLs from this HTML:\n\n{html[:8000]}"
        }
    ]
)

print(response.choices[0].message.content)
```

### JavaScript \+ Anthropic

```javascript
import Anthropic from "@anthropic-ai/sdk";

const html = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://news.ycombinator.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
).then((r) => r.text());

const client = new Anthropic();
const message = await client.messages.create({
  model: "claude-opus-4-5",
  max_tokens: 1024,
  messages: [
    {
      role: "user",
      content: `Extract the top 5 story titles and their URLs from this HTML:\n\n${html.slice(0, 8000)}`,
    },
  ],
});

console.log(message.content[0].text);
```

**Geeignet für:**

- Strukturierte Daten (Preise, Namen, Datumsangaben) extrahieren, ohne Parser zu schreiben
- Artikel oder Produktseiten zusammenfassen
- Mehrere Seiten vergleichen und Schlüsse daraus ziehen
- KI-gestützte Recherche- oder Monitoring-Tools entwickeln

## In einem KI-Agenten verwenden

Geben Sie Ihrem KI-Agenten ein `scrape`-Tool, das auf Web Unlocker basiert. Der Agent kann dann selbstständig im Web navigieren – Seiten abrufen, Inhalte lesen und Aktionen ausführen –, ohne dass Sie eine eigene Browsing-Logik schreiben müssen.

```python
import requests
import anthropic

def scrape(url: str) -> str:
    """Fetch a URL and return its rendered HTML."""
    return requests.get(
        "https://parsing.webunlocker.gologin.com/v1/scrape",
        params={"url": url},
        headers={"apikey": "YOUR_API_KEY"}
    ).text

tools = [
    {
        "name": "scrape",
        "description": "Fetch the rendered HTML of any URL, including JavaScript-heavy and protected sites.",
        "input_schema": {
            "type": "object",
            "properties": {
                "url": {"type": "string", "description": "The URL to scrape"}
            },
            "required": ["url"]
        }
    }
]

client = anthropic.Anthropic()
messages = [
    {"role": "user", "content": "What is the current price of the iPhone 16 Pro on apple.com?"}
]

while True:
    response = client.messages.create(
        model="claude-opus-4-5",
        max_tokens=1024,
        tools=tools,
        messages=messages
    )

    if response.stop_reason == "end_turn":
        print(response.content[0].text)
        break

    tool_results = []
    for block in response.content:
        if block.type == "tool_use" and block.name == "scrape":
            html = scrape(block.input["url"])
            tool_results.append({
                "type": "tool_result",
                "tool_use_id": block.id,
                "content": html[:10000]
            })

    messages.append({"role": "assistant", "content": response.content})
    messages.append({"role": "user", "content": tool_results})
```

Der Agent entscheidet, wann er scrapt und welche URL er abruft. Web Unlocker übernimmt den eigentlichen Abruf.

**Geeignet für:**

- Recherche-Agenten, die selbstständig im Web browsen
- Bots für Preisvergleiche oder die Suche nach Angeboten
- Pipelines für Wettbewerbsanalysen
- Jeden Agenten, der Echtzeit-Webdaten benötigt

## Viele Seiten gleichzeitig scrapen

Führen Sie Anfragen parallel aus, um Daten von mehreren URLs gleichzeitig zu erfassen.

```python
import requests
from concurrent.futures import ThreadPoolExecutor

API_URL = "https://parsing.webunlocker.gologin.com/v1/scrape"
API_KEY = "YOUR_API_KEY"

urls = [
    "https://example.com/page/1",
    "https://example.com/page/2",
    "https://example.com/page/3",
]

def scrape(url):
    response = requests.get(
        API_URL,
        params={"url": url},
        headers={"apikey": API_KEY}
    )
    return url, response.text

with ThreadPoolExecutor(max_workers=5) as executor:
    results = list(executor.map(scrape, urls))

for url, html in results:
    print(f"{url}: {len(html)} chars")
```

**Geeignet für:**

- Komplette Produktkataloge oder Listenseiten scrapen
- Massenhafte Datenerfassung für Trainingsdatensätze
- Viele Seiten gleichzeitig überwachen

## Zusammenfassung

| Anwendungsfall | Was Sie tun | Was Sie erhalten |
| --- | --- | --- |
| Einzelne Seite scrapen | GET mit URL-Parameter | Gerendertes HTML |
| An ein LLM übergeben | Scrapen → an Modell übergeben | Extrahierte Daten oder Zusammenfassung |
| Tool für KI-Agenten | Agent ruft es bei Bedarf auf | Echtzeit-Webinhalte |
| Massen-Scraping | Parallele Anfragen | HTML für jede URL |

## Über die CLI verwenden

Kommen Sie ganz ohne eigenen Code aus – nutzen Sie die Gologin Web Access CLI für gängige Scraping-Workflows:

```bash
npm install -g gologin-web-access
export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."

# batch scrape multiple pages
gologin-web-access batch-scrape \
  https://example.com/page/1 \
  https://example.com/page/2 \
  https://example.com/page/3 \
  --format text --only-main-content --summary

# crawl a site
gologin-web-access crawl https://docs.example.com --format markdown --limit 50 --max-depth 2

# monitor page changes
gologin-web-access change-track https://example.com/pricing --format markdown

# extract structured data with a schema
gologin-web-access extract https://example.com/product/123 --schema ./product-schema.json

# search the web
gologin-web-access search "best antidetect browser 2026" --limit 10
```

Die vollständige Befehlsreferenz finden Sie unter [Web Access CLI](/de/cli-tools/web-access).
