### Installation

```bash
npm i gologin
```

Erfordert Node.js 20 oder höher. Version 3 des SDK ist ausschließlich ESM: Laden Sie es mit `import`, `require('gologin')` funktioniert nicht.

### Grundlegende Verwendung

```javascript
import GoLogin from 'gologin';

const GL = new GoLogin({
  token: 'your-api-token',
  profile_id: 'your-profile-id',
});

const { status, wsUrl } = await GL.start();
// Connect Puppeteer or Playwright using wsUrl
// ... your automation code ...
await GL.stop();
```

### Start mit GologinApi

`GologinApi` startet ein Profil und verbindet Puppeteer automatisch. `launch()` gibt einen Puppeteer-`browser` zurück. Übergeben Sie `cloud: true`, um das Profil im [Gologin Cloud Browser](/de/api-reference/cloud-browser/what-is-gologin-cloud-browser) statt in einem lokalen Orbita-Browser auszuführen:

```javascript
import { GologinApi } from 'gologin';

const gologin = GologinApi({ token: 'your-api-token' });

// local Orbita on this machine
const { browser } = await gologin.launch({ profileId: 'your-profile-id' });

// or Gologin Cloud Browser
// const { browser } = await gologin.launch({ cloud: true, profileId: 'your-profile-id' });

const page = await browser.newPage();
await page.goto('https://example.com');

// close the browser and stop the profile
await gologin.exit();
```

Ohne `profileId` erstellt `launch()` zunächst ein neues Profil. `GologinApi` bietet außerdem Hilfsfunktionen wie `createProfileRandomFingerprint()`, `addGologinProxyToProfile()`, `addCookiesToProfile()` und `deleteProfile()`. Ein vollständiges Beispiel finden Sie im [Quickstart](/de/api-reference/introduction/quickstart).

### Wichtige Parameter

| Parameter | Standardwert | Beschreibung |
|---|---|---|
| `token` | erforderlich | Ihr Gologin API-Token |
| `profile_id` | erforderlich | ID des Profils, das gestartet werden soll |
| `executablePath` | auto | Pfad zur Orbita-Browser-Binärdatei |
| `uploadCookiesToServer` | `false` | Lädt Cookies beim Beenden des Profils in die Cloud hoch. Setzen Sie den Wert auf `true`, wenn Sie Sitzungen geräteübergreifend beibehalten möchten. |
| `extra_params` | `[]` | Zusätzliche Chromium-Flags, die an den Browser übergeben werden |

### Profile beenden

```javascript
// Stop and sync to cloud
await GL.stop();

// Stop without syncing profile data to cloud
await GL.stopLocal({ posting: false });
```

Schließen Sie zuerst den Browser in Ihrem Automatisierungstool, zum Beispiel mit `browser.close()`. `stop()` akzeptiert keine Optionen und lädt das Profil immer zu Gologin hoch. `stopLocal({ posting: false })` beendet die Sitzung, ohne Profildaten hochzuladen. Verwenden Sie diese Methode auf Servern, auf denen Sie keine Cloud-Synchronisierung wünschen. Cookies werden weiterhin hochgeladen, wenn Sie `uploadCookiesToServer: true` gesetzt haben.

### Orbita-Browserversionen verwalten

Beim Start eines Profils prüft das SDK, welche Orbita-Version der User-Agent des Profils benötigt. Ist diese Version noch nicht in `~/.gologin/browser` vorhanden, lädt das SDK sie herunter, andernfalls verwendet es die installierte Kopie. Um einen bestimmten Build auszuführen, übergeben Sie `executablePath`. Die Optionen `autoUpdateBrowser` (Standardwert `false`) und `checkBrowserUpdate` werden weiterhin akzeptiert, ändern dieses Verhalten im aktuellen SDK (3.0.7) jedoch nicht.

Um Orbita im Voraus herunterzuladen, rufen Sie `checkAndDownloadBrowserByOpts()` auf einer `GoLogin`-Instanz auf. Dies ist eine Methode und kein separater Export:

```javascript
import { GoLogin } from 'gologin';

const GL = new GoLogin({ token: 'your-api-token' });

// Pre-download the latest Orbita version
await GL.checkAndDownloadBrowserByOpts({ lastActualCount: 1 });

// Pre-download specific versions
await GL.checkAndDownloadBrowserByOpts({ majorVersions: [142, 143] });
```

Ohne Optionen werden die 5 neuesten Versionen heruntergeladen. Verwenden Sie die Methode, bevor Sie Profile parallel starten, um mehrere gleichzeitige Downloads zu vermeiden.

### Mehr als 100 Profile parallel ausführen

Wenn Sie viele Profile gleichzeitig auf einem Server ausführen:

```javascript
// Use a queue to limit concurrent launches
const CONCURRENCY = 10;
const queue = [...profileIds];
const active = new Set();

async function launchProfile(profileId) {
  const gl = new GoLogin({ token, profile_id: profileId });
  try {
    const { wsUrl } = await gl.start();
    // ... your automation ...
  } finally {
    await gl.stop();
  }
}

async function processQueue() {
  while (queue.length > 0) {
    while (active.size >= CONCURRENCY) {
      await new Promise(r => setTimeout(r, 1000));
    }
    const id = queue.shift();
    active.add(id);
    launchProfile(id).finally(() => active.delete(id));
  }
}
```

**Wichtig für Server:**
- Begrenzen Sie die Anzahl gleichzeitiger Profilstarts (zum Einstieg werden 10-20 empfohlen)
- Laden Sie Orbita-Versionen vor dem Start herunter
- Unter Linux: Installieren Sie Xvfb und setzen Sie `DISPLAY=:99`
- Erhöhen Sie die Limits für Dateideskriptoren: `ulimit -n 65536`
- Überwachen Sie den Arbeitsspeicher: Jedes Profil benötigt ca. 300-500 MB

### Debugging

Setzen Sie die Umgebungsvariable für ausführliche Protokollierung:

```bash
DEBUG=gologin node your-script.js
```
