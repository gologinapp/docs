Mit Gologin Cloud Browser führen Sie einen Gologin-Browser (Orbita) **in der Cloud** aus und steuern ihn über eine einzige **Connection URL** aus Ihrem Automatisierungscode (Puppeteer / Playwright).

Es handelt sich um einen [Headless-Browser](./what-is-headless-browser) – einen Browser, der vollständig per Code gesteuert wird und keine grafische Oberfläche hat. Er wird von Gologin gehostet und verwaltet und bietet integrierte Unterstützung für persistente Profile, Fingerprint-Konfiguration und Proxy-Routing.

## Was Sie mit Cloud Browser tun können

- Mehrere Browser-Sitzungen parallel in der Cloud ausführen
- Mit Ihrem bestehenden Stack automatisieren (Puppeteer / Playwright)
- Gologin-**Profile** nutzen, um persistente Zustände (Logins, Cookies, Speicher) zu erhalten
- Datenverkehr über **Proxys** leiten, die Sie im Profil konfigurieren
- Als Remote-Browser-Laufzeitumgebung mit KI-Agenten verwenden

## Worin er sich von einem Standard-Headless-Browser unterscheidet

Ein standardmäßiger Headless-Chrome ist erkennbar. Websites nutzen Browser-Fingerprinting, um automatisierten Datenverkehr zu identifizieren – sie prüfen unter anderem Canvas-Rendering, WebGL-Parameter, Schriftarten, Zeitzone, Bildschirmgröße und Dutzende weitere Signale.

Gologin Cloud Browser nutzt **Orbita** – ein modifiziertes Chromium, das Fingerprint-Signale so verwaltet, dass sie zu einem konsistenten, realistischen Browserprofil passen. In Kombination mit persistenten Cookies und der Proxy-Konfiguration, die in jedem Profil gespeichert sind, wirken Ihre Sitzungen bei wiederholten Besuchen stabil und menschlich.

## Warum Gologin Cloud Browser

### Integrierter Anti-Detect – keine Plugins nötig

Standardmäßiger Headless-Chrome lässt sich mühelos erkennen. Andere Cloud-Browser-Dienste setzen auf Standard-Chromium und benötigen Stealth-Plugins von Drittanbietern, um Fingerprint-Signale zu verringern – mit gemischten Ergebnissen.

Gologin Cloud Browser nutzt **Orbita**, einen gehärteten Chromium-Build, dessen Kern das Fingerprint-Management ist: Canvas, WebGL, Schriftarten, Zeitzone, Bildschirmauflösung und mehr. Anti-Detect ist kein nachträglicher Patch – es ist der Browser selbst.

### Persistente Profile – Sitzungen, die sich erinnern

Die meisten Cloud-Browser-Dienste behandeln jede Sitzung als zustandslos. Cookies und Speicherdaten werden verworfen, sobald die Sitzung endet.

Gologin-Profile bleiben erhalten. Melden Sie sich einmal an, beenden Sie die Sitzung und verbinden Sie sich später erneut – das Profil behält seine Cookies, den lokalen Speicher und alle konfigurierten Einstellungen. Keine erneute Authentifizierung, kein Aufwärmen der Sitzung.

### Kein Vendor-Lock-in

Gologin Cloud Browser ist ein standardmäßiger CDP-Endpunkt. Ihr Puppeteer- oder Playwright-Code verbindet sich damit genauso wie mit jeder anderen Remote-Chrome-Instanz – kein proprietäres SDK, keine eigene API, die Sie erst lernen müssen. Der Wechsel hinein oder heraus gelingt mit einer einzigen URL-Änderung.

## Typische technische Szenarien

Cloud Browser wird typischerweise für Workflows eingesetzt, in denen Sie:

- sich einmal in ein Webkonto einloggen und die Sitzung über ein Profil dauerhaft beibehalten
- wiederkehrende Aktionen auf denselben Websites über viele Profile hinweg ausführen
- stabile, lang laufende Sitzungen benötigen, ohne von einem lokalen Rechner abhängig zu sein

Beispiele sind die Automatisierung eingeloggter Sitzungen für Web-Apps, Marktplätze oder soziale Plattformen, bei denen Persistenz und konsistente Profileinstellungen wichtig sind.

## Grundlegende Konzepte

- **Profil** – eine wiederverwendbare Browser-Identität (Cookies/Speicher sowie Fingerprint- und Proxy-Einstellungen).
- **Cloud-Sitzung** – eine laufende Instanz eines Profils in der Gologin-Cloud.
- **Connect URL** – der Endpunkt, den Sie Ihrem Automatisierungstool übergeben, um die Cloud-Sitzung zu steuern.

## So funktioniert es (Überblick)

1. (Empfohlen) Erstellen und konfigurieren Sie ein Profil über die Gologin REST API (Proxy, Fingerprint usw.).
2. Verbinden Sie sich mit Cloud Browser über Ihren **Dev-Token** und optional eine `profileId`.
3. Automatisieren Sie die Sitzung mit Puppeteer oder Playwright.
4. Schließen Sie die Verbindung, wenn Sie fertig sind.

## Connection URL

Verwenden Sie diese URL als Endpunkt des Remote-Browsers:

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${profileId}
```

- `token` – Ihr Gologin-**Dev-Token** (erstellen Sie ihn in der Gologin-App: [API & MCP](https://app.gologin.com/personalArea/TokenApi) → **API** → **New Token**).
- `profile` – **Profil-ID** (optional). Wird sie weggelassen, wird für die Sitzung ein neues Profil erstellt.

## Profile verwalten (Proxy, Fingerprint usw.)

Cloud Browser ist die **Verbindungsschicht**.\
Um Profile zu erstellen oder zu aktualisieren, Proxys zuzuweisen und Profileinstellungen zu konfigurieren, verwenden Sie die Gologin REST API:

- Profiles API: [Create profile](https://gologin.com/docs/api-reference/profile/create-profile-with-partial-parameters), [Update profile](https://gologin.com/docs/api-reference/profile/update-profile-with-partial-parameters)
- Proxy API: [Add a Gologin proxy to a profile](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy), [Set your own proxy on profiles](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles)

## Cloud Browser über die CLI nutzen

Wenn Sie Shell-Befehle dem Schreiben von Puppeteer-/Playwright-Code vorziehen, bietet Gologin agentenfreundliche CLI-Tools:

- **[Gologin Agent Browser CLI](/de/cli-tools/agent-browser)** – Cloud-Browser-CLI mit Daemon, Seiten-Snapshots und referenzbasierter Interaktion. Entwickelt für KI-Agenten.
- **[Gologin Web Access CLI](/de/cli-tools/web-access)** – einheitliche CLI, die Scraping mit Web Unlocker und Interaktion mit Cloud Browser in einem Tool vereint.

```bash
npm install -g gologin-agent-browser-cli
export GOLOGIN_TOKEN='your_token'

gologin-agent-browser open https://example.com
gologin-agent-browser snapshot
gologin-agent-browser click @e3
gologin-agent-browser screenshot ./page.png
gologin-agent-browser close
```
