Gologin AI Skills sind sofort einsetzbare Erweiterungen für [Claude Code](https://claude.ai/code), die KI-Agents Web Scraping und Browser-Automatisierung ermöglichen. Jeder Skill kapselt ein Gologin-CLI-Tool und stellt es als Satz von Funktionen bereit, die der Agent aufrufen kann.

```
agent → skill → Gologin CLI → Web Unlocker API / Cloud Browser / Local Orbita
```

## Installation

Alle Gologin Skills werden aus dem Repository [GologinLabs/agent-skills](https://github.com/GologinLabs/agent-skills) installiert:

```bash
# install any skill
npx skills add GologinLabs/agent-skills@gologin-web-access-skill
npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill
npx skills add GologinLabs/agent-skills@gologin-scraping-skill
```

Für jeden Skill muss die zugrunde liegende CLI installiert sein:

| Skill | Erforderliche CLI |
|---|---|
| Web Access Skill | `npm i -g gologin-web-access` |
| Agent Browser Skill | `npm i -g gologin-agent-browser-cli` (Cloud- und lokale Runtimes) |
| Scraping Skill | `npm i gologin-webunlocker` |

## Welcher Skill passt zu welcher Aufgabe?

| Aufgabe | Skill |
|---|---|
| Eine Dokumentationsseite, einen Artikel oder eine bekannte URL lesen | Web Access |
| Strukturierte Daten scrapen und extrahieren | Web Access |
| Viele URLs im Batch scrapen | Web Access |
| Eine Website crawlen, URLs erfassen | Web Access |
| Seitenänderungen überwachen | Web Access |
| Eine Seite lesen und anschließend im Browser interagieren | Web Access (Hybridmodus) |
| Eine Live-Cloud-Browsersitzung öffnen | Agent Browser |
| In ein Dashboard einloggen, Screenshots erstellen | Agent Browser |
| Formulare ausfüllen, Abläufe durchklicken | Agent Browser |
| Nur Scraping, kein Browser nötig, Node.js-App | Scraping |
| Lokale Profile aufwärmen | Agent Browser (lokale Runtime) |
| Konto-Logins mit dauerhaften Cookies | Agent Browser (lokale Runtime) |
| Social-Media- und Marktplatz-Aktionen in lokalem Orbita | Agent Browser (lokale Runtime) |
| Batch-Runbooks über viele lokale Profile | Agent Browser (lokale Runtime) |

## Web Access Skill

**Installation:** `npx skills add GologinLabs/agent-skills@gologin-web-access-skill`

Der Standard-Skill und zugleich der vielseitigste. Er delegiert an die CLI `gologin-web-access`.

**Scraping-Tools:** `scrape_url`, `read_page`, `scrape_markdown`, `scrape_text`, `scrape_json`, `batch_scrape`, `batch_extract`, `search_web`, `map_site`, `crawl_site`, `crawl_site_async`, `extract_structured`, `track_changes`, `batch_track_changes`, `parse_document`

**Browser-Tools:** `browser_open`, `browser_search`, `browser_snapshot`, `browser_click`, `browser_type`, `browser_screenshot`, `browser_close`, `browser_sessions`, `browser_current`

**Integrierte Workflows:** browser-ref-loop, hybrid-read-then-interact, search-discover-and-scrape, lead-enrichment, competitive-monitoring, docs-ingestion, geo-testing, login-and-navigate-dashboard

Alle Details zu den Befehlen finden Sie in der [Web Access CLI-Referenz](/de/cli-tools/web-access).

## Agent Browser Skill

**Installation:** `npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill`

Reiner Browser-Skill für Live-Sitzungen in Gologin Cloud Browser (Standard) oder in lokalen Orbita-Profilen mit `--runtime local`. Verwenden Sie ihn, wenn Sie interaktiv browsen möchten, ohne zu scrapen.

**Funktionen:** `doctor`, `open`, `sessions`, `current`, `snapshot`, `click`, `type`, `fill`, `find`, `get`, `tabs`, `tabopen`, `tabfocus`, `tabclose`, `cookies`, `cookies-import`, `storage-export`, `storage-import`, `eval`, `back`, `forward`, `reload`, `upload`, `screenshot`, `pdf`

**Die lokale Runtime ergänzt:** Profilverwaltung (`profiles`, `profile-create`, `profile-import`, `profile-update`, `profile-sync`, `profile-delete`), Runbooks (`run`, `batch`), Jobs (`jobs`, `job`), Vorlagen für Anwendungsfälle (`linkedin`, `ads`, `smm`, `scraping`, `geo`) und Diagnose (`doctor --use-case --check-proxy`).

Alle Details zu den Befehlen finden Sie in der [Agent Browser CLI-Referenz](/de/cli-tools/agent-browser) und unter [Lokale Runtime](/de/cli-tools/local-agent-browser).

## Scraping Skill

**Installation:** `npx skills add GologinLabs/agent-skills@gologin-scraping-skill`

Der kleinste Skill – Scraping ausschließlich über das Web Unlocker SDK. Keine Browsersitzung, kein Daemon.

**Funktionen:** Roh-HTML (`scrape`), Text (`text`), Markdown (`markdown`), strukturierte Metadaten (`json`). SDK-Methoden: `scrapeRaw()`, `scrape()`, `scrapeText()`, `scrapeMarkdown()`, `scrapeJSON()`, `batchScrape()`.

Verwenden Sie ihn, wenn die Aufgabe nur aus Scraping besteht und Sie möglichst wenige Abhängigkeiten wünschen.

Details zur API finden Sie in der [Web Unlocker SDK-Referenz](/de/scraping-api-sdk-and-cli).

## Local Agent Browser Skill (veraltet)

Wenn Ihr Agent noch `gologin-local-agent-browser-skill` verwendet, verweist dieser Skill den Agent lediglich auf den Agent Browser Skill. Installieren Sie stattdessen `gologin-agent-browser-skill`: Er deckt lokale Orbita-Profile, Warmup, Login-Abläufe, Runbooks und Batch-Jobs ab.

## Beispiel-Workflows

### Wettbewerbsrecherche (Web Access Skill)

1. Der Agent sucht nach Wettbewerbern: `search_web("saas project management tools")`
2. Der Agent erfasst die Struktur einer Wettbewerber-Website: `map_site("https://competitor.com")`
3. Der Agent scrapt wichtige Seiten im Batch: `batch_scrape(pricing, features, about)`
4. Der Agent übergibt die Inhalte zur Analyse und zum Vergleich an Claude

### Konto-Warmup (Agent Browser Skill, lokale Runtime)

1. Der Agent erstellt Profile: `profile-create "Account 1" --template linkedin`
2. Der Agent führt das Warmup-Runbook aus: `batch ./warmup.json --targets ./profiles.json`
3. Der Agent prüft die Job-Ergebnisse: `jobs --kind batch --status ok`
4. Der Agent meldet, welche Profile bereit sind

### Dashboard-Monitoring (Agent Browser Skill)

1. Der Agent öffnet das Dashboard: `open https://dashboard.example.com --profile saved_login`
2. Der Agent liest die Seite: `snapshot`
3. Der Agent navigiert zu den Metriken: `click @e5` (Link „Reports“)
4. Der Agent macht einen Screenshot des Berichts: `screenshot ./daily-metrics.png`
5. Der Agent schließt die Sitzung: `close`
6. Der Agent fasst die Metriken anhand der Snapshot-Daten zusammen

## Verbindlicher Preflight

Bevor eine Aufgabe ausgeführt wird, ordnen die Skills die Arbeit ein:

1. **Eine bekannte Website oder breit angelegte Recherche über mehrere Quellen?** – bestimmt, ob Scraping oder Suche nötig ist
2. **Reine Extraktion, Monitoring oder interaktive Browser-Arbeit?** – bestimmt, ob Scraping oder Browser zum Einsatz kommt
3. **Nur Web Unlocker oder sowohl Web Unlocker als auch Cloud Browser?** – bestimmt, welche Zugangsdaten benötigt werden
4. **Geo-sensibel oder so stark blockiert, dass Gologin durchgängig nötig ist?** – bestimmt die Anforderungen an Proxy und Profil
