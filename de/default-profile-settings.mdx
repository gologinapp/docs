---
title: "Standardeinstellungen für Profile"
---

Mit den **Default profile settings** legen Sie eine Vorlage für neue Profile fest. Alles, was Sie hier konfigurieren, wird automatisch angewendet, wenn ein neues Profil erstellt wird. Bestehende Profile sind davon nicht betroffen – Änderungen gelten nur für die Zukunft.

Derzeit sind nicht alle Einstellungen in den Standardeinstellungen verfügbar.

<Tip>
  Diese Einstellungen gelten nur für Profile, die Sie nach der Änderung erstellen. Auf bereits vorhandene Profile werden sie nicht angewendet.
</Tip>

So gelangen Sie dorthin:

1. Klicken Sie oben links auf den **Namen Ihres Workspace**.
2. Öffnen Sie **Settings & Members**.
3. Klicken Sie in der linken Seitenleiste auf **Default profile settings**.

## Proxy & Location

Im Bereich **Proxy & Location** legen Sie fest, welchen Proxy neue Profile automatisch erhalten:

- **Gologin proxy** – Wählen Sie das Land und den Proxy-Typ aus. Jedes neue Profil wird mit einem Gologin-Proxy an diesem Standort erstellt.
- **Without proxy** – Neue Profile werden ohne Proxy erstellt und nutzen Ihre echte Internetverbindung.

Standardmäßig erhalten neue Profile einen Gologin-Proxy. Der Standort ist in der Regel die USA oder das Land, das Sie beim Onboarding ausgewählt haben.

Das gilt für Profile, die mit der Schaltfläche **\+** (Schnellprofile) und über **Add profile** erstellt werden.

<Note>
  Gologin-Proxys verbrauchen Ihr Proxy-Traffic-Kontingent. Wenn Sie lieber eigene Proxys verwenden möchten, stellen Sie diese Einstellung auf **Without proxy** und weisen Sie anschließend jedem Profil manuell Proxys zu. Siehe [Proxys hinzufügen](/de/proxy/proxy-management/adding-proxies).
</Note>

Im selben Bereich können Sie **Disable image loading** und **Disable video autoplay** aktivieren, damit neue Profile weniger Proxy-Traffic verbrauchen. Nur in kostenpflichtigen Tarifen verfügbar.

## Standardeinstellungen wiederherstellen

Wenn Sie Ihre Standardeinstellungen für Profile geändert haben und zu den ursprünglichen Einstellungen zurückkehren möchten, klicken Sie oben auf der Seite auf das **Pfeilsymbol** neben **Restore default profile settings**. Die Einstellungen werden auf die Werte zurückgesetzt, die Gologin für neue Konten abhängig vom Betriebssystem Ihres Geräts festlegt.

Dadurch wird nur die Vorlage für neue Profile zurückgesetzt. Ihre bestehenden Profile bleiben unverändert.
