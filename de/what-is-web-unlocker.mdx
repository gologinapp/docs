---
title: "Was ist Web Unlocker?"
---

Web Unlocker ist eine universelle Scraping API. Sie senden eine beliebige URL und erhalten vollständig gerendertes HTML oder die Seite als Markdown oder JSON zurück, ohne Browser oder Proxys verwalten zu müssen.

Web Unlocker ersetzt den Browser- und Proxy-Teil Ihres Scraping-Stacks: Rendering, Proxy-Verwaltung und Browser-Fingerprints werden in einem einzigen API-Aufruf erledigt. Statische Seiten und JavaScript-lastige Websites laufen über denselben Endpunkt.

---

## Welche Probleme es löst

Moderne Websites sind schwer zu scrapen. Ein einfacher Aufruf mit `curl` oder `requests` liefert oft eine leere Antwort oder fehlerhaftes HTML, weil der Inhalt per JavaScript nachgeladen wird. Web Unlocker übernimmt Folgendes:

- **JavaScript-Rendering** — Seiten werden in einem echten Browser geladen und vollständig ausgeführt, bevor der Inhalt erfasst wird
- **Intelligente IP-Rotation** — Anfragen werden über Residential-IPs mit realistischen Browser-Fingerprints geleitet
- **Preisstufen-Targeting** — Anfragen werden über die passende Proxy-Stufe für die Zielseite geleitet

---

## Was Sie zurückerhalten

Eine erfolgreiche Anfrage liefert die Seite in einem Format. Wählen Sie es mit dem Query-Parameter `format`:

| `format` | Was Sie erhalten |
| --- | --- |
| `html` (Standard) | Das vollständig gerenderte DOM der Seite |
| `markdown` | Der Seiteninhalt als Markdown |
| `json` | Ein JSON-Objekt mit der Seiten-URL, Metadaten der Anfrage und dem HTML |

## Web Unlocker im Vergleich zu selbst verwalteten Proxys

Eine eigene Proxy-Infrastruktur zu betreiben ist teuer und störanfällig. Web Unlocker übernimmt alles als Managed Service:

|  | Web Unlocker | Selbst verwaltete Proxys |
| --- | --- | --- |
| Einrichtung | Ein API-Aufruf | Wochen an Infrastrukturarbeit |
| Browser-Fingerprinting | Integriert | Separat entwickeln oder kaufen |
| IP-Rotation | Automatisch | Manuelle Verwaltung des Pools |
| Wartung | Keine | Laufend |
| Abrechnung | Pro erfolgreicher Anfrage | Feste Kosten unabhängig vom Erfolg |

## Typische Anwendungsfälle

- **Preisüberwachung** — Preise in E-Commerce-Shops verfolgen
- **Marktforschung** — Produktdaten, Bewertungen oder Stellenanzeigen in großem Umfang sammeln
- **Content-Aggregation** — News- oder Daten-Feeds aus Websites ohne API aufbauen
- **KI-Pipelines** — gerendertes HTML zur Extraktion oder Zusammenfassung an LLMs übergeben

---

## So funktioniert es

Web Unlocker startet für jede Aufgabe einen echten Chromium-Browser in der Cloud. Wenn Sie eine URL senden:

1. Ein Browser wird mit einer Residential-IP und einem realistischen Browser-Fingerprint gestartet
2. Die Seite wird aufgerufen, JavaScript wird ausgeführt und dynamische Inhalte werden geladen
3. Das gerenderte HTML wird zurückgegeben, oder Markdown bzw. JSON, wenn Sie es mit `format` anfordern

Sie müssen keine Infrastruktur verwalten. Sie müssen keine Browser hochfahren, keine Proxy-Listen pflegen und keine Rendering-Logik entwickeln. Web Unlocker ersetzt ein Framework für Browser-Automatisierung und einen Proxy-Anbieter durch eine einzige HTTP-Anfrage.

---

## So verwenden Sie es

Senden Sie eine GET-Anfrage mit der Ziel-URL als Query-Parameter. Die Antwort ist das vollständig gerenderte HTML.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Um stattdessen Markdown oder JSON zu erhalten, fügen Sie der Anfrage `format=markdown` oder `format=json` hinzu.

Beispiele in Python und JavaScript sowie [Fehlercodes](/de/web-unlocker-quick-start#fehlerbehandlung) finden Sie in der [Quickstart](/de/web-unlocker-quick-start), gängige Integrationsmuster unter [Use Cases](/de/web-unlocker-use-cases).
