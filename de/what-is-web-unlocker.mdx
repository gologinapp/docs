---
title: "Was ist Web Unlocker?"
---

Web Unlocker ist eine universelle Scraping API. Sie senden eine beliebige URL und erhalten vollständig gerendertes HTML oder die Seite als Markdown oder JSON zurück – ohne Infrastruktur, die Sie verwalten müssen, ohne Blockaden und ohne fehlgeschlagene Anfragen.

Web Unlocker ersetzt Ihren gesamten Scraping-Stack: Browser-Automatisierung, Proxy-Verwaltung, Fingerprinting und CAPTCHA-Lösung werden in einem einzigen API-Aufruf erledigt. Ob einfache statische Seite oder stark geschützte, per JavaScript gerenderte Website: Derselbe Endpoint übernimmt beides.

---

## Was Web Unlocker löst

Moderne Websites lassen sich nur schwer scrapen. Ein einfacher Aufruf mit `curl` oder `requests` liefert oft eine Challenge-Seite, eine leere Antwort oder fehlerhaftes HTML, weil die Inhalte per JavaScript nachgeladen werden. Web Unlocker erledigt das alles automatisch:

- **JavaScript-Rendering** – Seiten werden in einem echten Browser geladen und vollständig ausgeführt, bevor der Inhalt erfasst wird
- **Anti-Bot-Umgehung** – Schutzmechanismen wie Cloudflare, DataDome, PerimeterX und ähnliche werden automatisch umgangen
- **Intelligente IP-Rotation** – Anfragen laufen über saubere Residential-IPs mit realistischen Browser-Fingerprints
- **CAPTCHA-Lösung** – gängige CAPTCHA-Aufgaben werden ohne manuelles Eingreifen gelöst
- **Preisstufen-Zuordnung** – Anfragen werden über die passende Proxy-Stufe für die Zielwebsite geleitet

---

## Was Sie zurückerhalten

Eine erfolgreiche Anfrage liefert die Seite in einem Format. Wählen Sie es mit dem Query-Parameter `format`:

| `format` | Was Sie erhalten |
| --- | --- |
| `html` (Standard) | Das vollständig gerenderte DOM der Seite |
| `markdown` | Der Seiteninhalt als Markdown |
| `json` | Ein JSON-Objekt mit der Seiten-URL, Metadaten zur Anfrage und dem HTML |

## Web Unlocker im Vergleich zu selbst verwalteten Proxys

Eine eigene Proxy-Infrastruktur zu betreiben ist teuer und störanfällig. Web Unlocker übernimmt alles als Managed Service:

|  | Web Unlocker | Selbst verwaltete Proxys |
| --- | --- | --- |
| Einrichtung | Ein API-Aufruf | Wochenlanger Infrastrukturaufwand |
| CAPTCHA-Lösung | Integriert | Selbst entwickeln oder separat zukaufen |
| Browser-Fingerprinting | Integriert | Selbst entwickeln oder separat zukaufen |
| IP-Rotation | Automatisch | Manuelle Pool-Verwaltung |
| Wartung | Keine | Dauerhaft |
| Abrechnung | Pro erfolgreicher Anfrage | Feste Kosten, unabhängig vom Erfolg |

## Typische Anwendungsfälle

- **Preisüberwachung** – scrapen Sie E-Commerce-Seiten, die automatisierte Anfragen blockieren
- **Lead-Generierung** – extrahieren Sie Kontaktdaten aus Verzeichnissen und Firmeneinträgen

## So funktioniert es

Web Unlocker startet für jede Aufgabe einen echten Chromium-Browser in der Cloud. Wenn Sie eine URL senden:

1. Ein Browser wird mit einer Residential-IP und einem realistischen Browser-Fingerprint gestartet
2. Die Seite wird aufgerufen, JavaScript wird ausgeführt und dynamische Inhalte werden geladen
3. Anti-Bot-Challenges und CAPTCHAs werden automatisch bearbeitet
4. Das gerenderte HTML wird zurückgegeben – oder Markdown bzw. JSON, wenn Sie es mit `format` anfordern

Sie müssen keine Infrastruktur verwalten. Es gibt keine Browser, die Sie hochfahren müssen, keine Proxy-Listen, die Sie pflegen müssen, und keine Umgehungslogik, die Sie entwickeln müssen. Web Unlocker ersetzt einen kompletten Scraping-Stack – Framework für Browser-Automatisierung, Proxy-Anbieter, Anti-Bot-Lösung – durch eine einzige HTTP-Anfrage.

## So verwenden Sie Web Unlocker

Senden Sie eine GET-Anfrage mit der Ziel-URL als Query-Parameter. Die Antwort ist das vollständig gerenderte HTML.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Um stattdessen Markdown oder JSON zu erhalten, fügen Sie der Abfrage `format=markdown` oder `format=json` hinzu.

Beispiele in Python und JavaScript sowie die [Fehlercodes](/de/web-unlocker-quick-start#fehlerbehandlung) finden Sie in der [Schnellstart-Anleitung](/de/web-unlocker-quick-start). Gängige Integrationsmuster finden Sie unter [Anwendungsfälle](/de/web-unlocker-use-cases).
