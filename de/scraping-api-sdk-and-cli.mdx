Gologin Web Unlocker ist eine **Scraping API mit einem einzigen Endpoint** für JavaScript-lastige und geschützte Websites.

Sie senden eine URL, erhalten den gerenderten HTML-Code bzw. Text der Seite und verarbeiten ihn in Ihrer eigenen Extraktions-Pipeline.

## Warum als Scraping API nutzen

- Ein Endpoint für jede beliebige Ziel-URL
- Authentifizierung per API-Key, keine Browser-Orchestrierung erforderlich
- Standardmäßig HTML, auf Wunsch Markdown oder JSON, bereit für bestehende Parser
- Passt gut zu ETL, Monitoring, KI-Datenaufnahme und Daten-Pipelines

## Endpoint

`GET https://parsing.webunlocker.gologin.com/v1/scrape?url={encoded_url}`

## Authentifizierung

Senden Sie Ihren API-Key in den Headern:

```http
apikey: <API_KEY>
```

## Anfragemodell

| Name | Position | Typ | Erforderlich | Beschreibung |
|---|---|---|---|---|
| `url` | query | string (absolute URL) | ja | Ziel-URL für das Scraping |
| `format` | query | string | nein | Antwortformat: `html` (Standard), `markdown` oder `json` |

## Schnellstart

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.status_code)
print(response.text[:500])
```

### JavaScript (fetch)

```js
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(response.status, html.slice(0, 500));
```

## Antwortverhalten

Standardmäßig ist der Antwort-Body der **gerenderte Roh-HTML-Code** der Seite. Mit `format=markdown` ist der Body Markdown. Mit `format=json` ist der Body ein JSON-Objekt:

```json
{
  "success": true,
  "data": {
    "url": "https://example.com",
    "metadata": {
      "response_time_ms": 297,
      "status_code": 200
    },
    "html": "<!DOCTYPE html><html lang=\"en\">..."
  }
}
```

Statuscodes:

- `200` -> Erfolg, der Body enthält die Seite im angeforderten Format
- `400` -> fehlerhafte Anfrage, zum Beispiel fehlt `url`; Body: `{"success":false,"error":"Request failed"}`
- `401` -> der Header `apikey` fehlt; Body: `{"message":"Missing API key in request"}`

## Hinweise zu Wiederholungsversuchen

Wiederholen Sie die Anfrage mit exponentiellem Backoff bei:

- Netzwerkfehlern
- `408`, `429`, `500`, `502`, `503`, `504`

## Offizielles Node.js SDK

Installation:

```bash
npm i gologin-webunlocker
```

### SDK-Schnellstart

```ts
import { WebUnlocker } from "gologin-webunlocker";

const client = new WebUnlocker({
  apiKey: process.env.GOLOGIN_WEBUNLOCKER_API_KEY!
});

const result = await client.scrape("https://example.com");
console.log(result.status);
console.log(result.content.slice(0, 500));
```

### Konstruktor-Optionen

```ts
new WebUnlocker({
  apiKey: "wu_live_xxx",
  baseUrl: "https://parsing.webunlocker.gologin.com",
  timeoutMs: 15000,
  maxRetries: 2
});
```

### Zentrale SDK-Methoden

- `scrape(url)` -> normalisiertes Antwortobjekt
- `scrapeRaw(url)` -> native `Response`
- `buildScrapeUrl(url)` -> vollständige Anfrage-URL

### Im SDK abgeleitete Methoden (aus dem zurückgegebenen HTML)

Dies sind **keine separaten Backend-Endpoints**; sie werden im SDK aus dem HTML der API abgeleitet. Das SDK sendet nur den Parameter `url`, nicht `format`. Daher kann diese Ausgabe von der eigenen Antwort der API mit `format=markdown` oder `format=json` abweichen:

- `scrapeText(url)` -> reiner Text
- `scrapeMarkdown(url)` -> Markdown
- `scrapeJSON(url)` -> strukturierte Metadaten (`title`, `description`, `canonical`, `meta`, `headings`, `links`)
- `batchScrape(urls, { concurrency })` -> Hilfsmethode für mehrere Scrape-Aufrufe

### Typisierte Fehler

- `WebUnlockerError`
- `AuthenticationError`
- `RateLimitError`
- `APIError`
- `TimeoutError`
- `NetworkError`

Zuordnung:

- `401` / `403` -> `AuthenticationError`
- `429` -> `RateLimitError`
- `500+` und andere Nicht-2xx-Statuscodes (zum Beispiel `400`) -> `APIError`
- Timeout/Abbruch -> `TimeoutError`
- Fetch-/Netzwerkfehler -> `NetworkError`

## CLI

```bash
gologin-webunlocker <command> <url> [options]
```

Befehle:

- `scrape` (roher HTML-Code/Text)
- `text` (abgeleiteter Text)
- `markdown` (abgeleitetes Markdown)
- `json` (abgeleitete Metadaten)

Beispiele:

```bash
gologin-webunlocker scrape https://example.com --api-key wu_live_xxx
GOLOGIN_WEBUNLOCKER_API_KEY=wu_live_xxx gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_live_xxx gologin-webunlocker json https://example.com
```

## Typische Anwendungsfälle für Scraping

- Preis- und Katalogüberwachung
- Anreicherung von Leads und Verzeichnissen
- Pipelines für Marktanalysen
- Content-Aggregation und Indexierung
- Workflows für LLM-Datenaufnahme und Extraktion

## Gologin Web Access CLI (einheitlich)

Für eine leistungsfähigere CLI, die Web Unlocker und Cloud Browser in einer gemeinsamen Befehlsoberfläche vereint, verwenden Sie `gologin-web-access`:

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."

# all scraping commands from gologin-webunlocker, plus:
gologin-web-access batch-scrape url1 url2 url3 --format text --summary
gologin-web-access search "query" --limit 10
gologin-web-access map https://example.com --limit 50
gologin-web-access crawl https://docs.example.com --format markdown --limit 20
gologin-web-access extract https://example.com --schema ./schema.json
gologin-web-access change-track https://example.com --format markdown

# plus cloud browser interaction (requires GOLOGIN_TOKEN)
gologin-web-access open https://example.com
gologin-web-access snapshot
gologin-web-access click e3
```

Die vollständige Referenz finden Sie unter [Gologin Web Access CLI](/de/cli-tools/web-access).
