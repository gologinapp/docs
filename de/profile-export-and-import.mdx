---
title: "Profil-Export und -Import"
---

Diese Anleitung erklärt, wie Sie Profile in Gologin exportieren und importieren und wann Sie welche Methode verwenden sollten.

Gologin unterstützt den Import und Export von Profilen über **CSV-Dateien**.

## So exportieren Sie Profile

1. **Wählen** Sie auf der Seite All profiles ein oder mehrere Profile aus
2. Klicken Sie auf **Export profiles**
3. **Speichern** Sie die CSV-Datei

<Frame>
  ![Profil-Export](/images/profile_export.gif)
</Frame>

## So importieren Sie Profile

Profile können über das Workspace-Menü importiert werden.

1. **Klicken Sie auf den Pfeil** neben der Schaltfläche Add profile im linken Menü
2. Klicken Sie auf **Import profiles**
3. Laden Sie eine CSV-Datei hoch oder fügen Sie CSV-Daten ein
4. Klicken Sie auf **Import**

<Frame>
  ![Profil-Import](/images/profile_import-2.gif)
</Frame>

<Warning>
  Wenn importierte Profile bereits in Ihrer Liste All profiles vorhanden sind, werden sie lediglich aktualisiert. \
  Es werden keine Duplikate erstellt.
</Warning>
