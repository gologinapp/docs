---
title: "Checkliste für den Einstieg"
---

Bevor Sie Ihre ersten Browserprofile in Gologin erstellen, sollten Sie Ihre Umgebung vorbereiten. So vermeiden Sie Probleme mit Ihren Accounts und stellen sicher, dass die Profile korrekt funktionieren.

Nutzen Sie diese Checkliste für den Start.

### 1. Gologin installieren

Laden Sie die Gologin-Anwendung für Ihr Betriebssystem herunter und installieren Sie sie.

### 2. Bei Ihrem Gologin-Account anmelden

Melden Sie sich mit dem Account an, den Sie bei der Registrierung erstellt haben.

### 3. Proxys vorbereiten

Stellen Sie sicher, dass Sie Proxys zur Verfügung haben.<br />Wenn Sie für jedes Profil einen eigenen Proxy verwenden, verhindern Sie, dass Accounts miteinander verknüpft werden.

### 4. Ihr erstes Browserprofil erstellen

Erstellen Sie ein Profil, um eine separate Browserumgebung mit eigenem Fingerprint und eigenem Speicher zu simulieren.

### 5. Dem Profil einen Proxy zuweisen

Fügen Sie einen Proxy hinzu, damit das Profil über eine eindeutige IP-Adresse verbunden ist.

### 6. Das Profil starten

Klicken Sie auf **Run**, um das Profil zu starten und mit Ihren Accounts zu arbeiten.
