title: "Cookie Bot"
---

Cookie Bot ist ein in Gologin integriertes Tool, das automatisch Browsing-Cookies für ein Profil erzeugt. Mit diesem Tool können Sie Ihren Warmup-Prozess automatisieren.

Es simuliert natürliches Surfverhalten, indem es beliebte Websites besucht und einfache Aktionen wie Scrollen und Klicken ausführt. So entsteht eine realistischere Browserumgebung, bevor Sie sich in Konten einloggen.

Cookie Bot kann Ihnen dabei helfen:

- einen ersten Browserverlauf zu erzeugen
- natürliche Cookies für Websites zu erstellen
- neue Browserprofile aufzuwärmen
- Profile auf den Login in Konten oder auf Automatisierung vorzubereiten

## So funktioniert Cookie Bot

Cookie Bot besucht eine Liste gängiger Websites und simuliert grundlegende Nutzerinteraktionen.

Dazu können folgende Aktionen gehören:

- Seiten laden
- durch Inhalte scrollen
- auf Schaltflächen klicken
- Bilder laden

Diese Aktivität erzeugt Cookies und Browserdaten im Profil, sodass die Browsersitzung natürlicher wirkt.

## Funktionen und Einstellungen von Cookie Bot

Folgende Einstellungen stehen aktuell zur Verfügung:

- **Loading images**\
  ON – Bilder werden geladen\
  OFF – Bilder werden nicht geladen, was Ihr Proxy-Datenvolumen spart
- **Using scrolling**\
  ON – der Bot scrollt durch die Seiten und ahmt so menschliches Verhalten nach\
  OFF – der Bot scrollt nicht und fährt direkt mit dem nächsten Schritt fort
- **Use autoclock**\
  ON – **akzeptiert Cookie-Anfragen** für Sie\
  OFF – klickt auf nichts

Das wird noch nicht unterstützt:

- Manuelles Aufzeichnen von Abläufen, die der Bot ausführen soll
- Anpassen, worauf der Bot klickt

## Cookie Bot ausführen

### Cookie Bot für ein einzelnes Profil ausführen

1. Öffnen Sie die Seite **All profiles**.
2. Klicken Sie beim Profil auf **3 dots**.
3. Wählen Sie **Automation**.
4. Prüfen Sie die Liste der Websites, die der Bot besuchen soll.
5. Passen Sie bei Bedarf die optionalen Einstellungen an.
6. Klicken Sie auf **Run**.

<Frame>
  ![Run Cookie Bot For Profile](/images/run_cookie_bot_for_profile-1.gif)
</Frame>

Cookie Bot simuliert Surfaktivität und erzeugt Cookies für das Profil.

### Cookie Bot für mehrere Profile ausführen

Mit Gologin können Sie Cookie Bot auch **für mehrere Profile gleichzeitig** ausführen.

Gehen Sie dazu so vor:

1. Wählen Sie in der Profiltabelle mehrere Profile aus.
2. Wählen Sie **Automation**.
3. Konfigurieren Sie die Einstellungen.
4. Klicken Sie auf **Run**.

<Frame>
  ![Run Cookie Bot For Multiple Profiles](/images/run_cookie_bot_for_multiple_profiles.gif)
</Frame>

Der Vorgang wird für alle ausgewählten Profile gestartet.

## Best Practices

Für optimale Ergebnisse:

- Führen Sie Cookie Bot aus, bevor Sie sich in neue Konten einloggen
- Lassen Sie den Profil-Proxy während des Vorgangs aktiviert
- Vermeiden Sie es, Cookie Bot zu häufig für dasselbe Profil auszuführen

So bleibt eine natürliche Browserumgebung erhalten.
