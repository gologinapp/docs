---
title: "Übersicht über Browser-Erweiterungen"
---

Mit Erweiterungen in einem Gologin-Profil können Sie jede Browser-Umgebung individuell anpassen. Da jedes Profil in Gologin wie ein eigener Browser mit eigenem Fingerprint und eigenem Speicher funktioniert, werden Erweiterungen **pro Profil** installiert und verwaltet, nicht global. So behalten Sie die volle Kontrolle darüber, welche Tools in der jeweiligen Account-Umgebung laufen.

## Was sind Profil-Erweiterungen?

**Profil-Erweiterungen** sind **Chrome-kompatible** Browser-Erweiterungen, die Sie **direkt in einem bestimmten Gologin-Profil** installieren.

Jedes Profil:

- Hat eine eigene Erweiterungsliste
- Speichert Erweiterungsdaten getrennt
- Hält Erweiterungseinstellungen isoliert
- Teilt Erweiterungen nicht mit anderen Profilen

Dadurch können Sie für verschiedene Accounts unterschiedliche Setups ohne Überschneidungen betreiben.

## Warum Erweiterungen in Gologin-Profilen nutzen?

Erweiterungen sind oft unverzichtbar für:

- Automatisierungstools
- Cookie-Verwaltung
- Anzeigenverifizierung
- Unterstützung beim Web Scraping
- Produktivitäts-Workflows

Da die Profile voneinander isoliert sind, können Sie auf verschiedenen Accounts sicher unterschiedliche Tools einsetzen, ohne dass sich Daten vermischen.

## Erweiterungen und Fingerprint-Stabilität

Erweiterungen können das Verhalten des Browsers beeinflussen.

Einige Erweiterungen:

- Verändern Request-Header
- Fügen Skripte ein
- Interagieren mit WebRTC
- Verändern das Canvas-Verhalten

Wenn Sie mit sensiblen Plattformen arbeiten (Werbung, E-Commerce, Krypto), testen Sie neue Erweiterungen sorgfältig, bevor Sie sie auf eingespielten Accounts verwenden.

## Best Practices

- Installieren Sie keine unnötigen Erweiterungen
- Verwenden Sie pro Account-Typ möglichst dieselben Erweiterungen
- Fügen Sie bei etablierten Profilen nicht ständig Erweiterungen hinzu und entfernen Sie sie nicht wieder. Abrupte Änderungen am Erweiterungs-Setup können auf Plattformen mit hohen Sicherheitsanforderungen verdächtig wirken.
