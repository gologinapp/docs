---
title: "Browser-Erweiterungen zu Profilen hinzufügen"
---

In Gologin können Sie öffentliche Erweiterungen auf zwei verschiedene Arten hinzufügen.

## Hinzufügen über den Tab Extensions

Sie können Erweiterungen **direkt in den Profileinstellungen** zu Ihrem Browserprofil hinzufügen, ohne den Chrome Web Store zu verwenden:

1. Klicken Sie auf der Seite All Profiles **auf die drei Punkte beim Profil**, auf dem Sie die Erweiterung installieren möchten, und anschließend auf **Settings**.
2. Wechseln Sie zum Tab **Extensions**.
3. Klicken Sie auf **Add extensions**.
4. Suchen Sie über die Suchleiste nach der gewünschten Erweiterung und klicken Sie auf **Install**.
5. Vergessen Sie nicht, auf **Save** zu klicken, um die Änderung zu übernehmen.

<Frame>
  ![Add Extensions Via Settings](/images/add_extensions_via_settings.gif)
</Frame>

Um eine Erweiterung zu löschen, klicken Sie im selben Menü einfach auf **Remove**.

<Tip>
  Wenn Sie die gewünschte Erweiterung nicht in der Liste finden, installieren Sie sie mindestens einmal über den Chrome Web Store. Die installierte Erweiterung erscheint innerhalb von 24 Stunden in der Liste.
</Tip>

### Erweiterungen zu jedem neuen Profil hinzufügen

Wenn Sie wissen, dass Sie bestimmte Erweiterungen in jedem Ihrer Profile benötigen, klicken Sie auf das **Flag icon** neben der Erweiterung. Sie wird dann in jedem neuen Profil angezeigt.

<Frame>
  ![Add Extensions To Every New Profile](/images/add_extensions_to_every_new_profile.png)
</Frame>

<Note>
  Solche Erweiterungen erscheinen nicht in bereits erstellten Profilen. Sie werden nur zu Profilen hinzugefügt, die Sie nach der Änderung erstellen.
</Note>

## Installation über den Chrome Web Store

Falls Sie die Erweiterung im Tab Extensions der Profileinstellungen nicht finden, können Sie den **Chrome Web Store** im Browserprofil verwenden. Gehen Sie dazu wie folgt vor:

1. **Starten Sie das Browserprofil**, für das Sie eine neue Erweiterung benötigen.
2. Klicken Sie im Browser auf die **drei Punkte oben rechts** \> **Extensions** \> **Visit Chrome Web Store**.
3. Suchen Sie die gewünschte Erweiterung.
4. Klicken Sie auf **Add to Chrome** und warten Sie, bis die Installation abgeschlossen ist.
