title: "Profilsuche"
---

Wenn Sie ein bestimmtes Profil nicht in der Liste finden, nachdem es mit Ihnen geteilt wurde, oder wenn Sie einfach **so viele** Profile haben, können Sie jederzeit die **Profilsuche** verwenden.

## So funktioniert die Profilsuche

Derzeit ist die Suche nur nach **Profilnamen** oder **Profil-ID** möglich.

So finden Sie ein Profil:

1. Suchen Sie das **Lupen**-Symbol ⌕ oben links auf der Seite All profiles und klicken Sie darauf
2. Geben Sie einfach den Profilnamen ein und drücken Sie Enter

  ![Profilsuche](/images/profile_search.gif)
</Frame>

## Zusätzliche Funktionen

**Suche geöffnet lassen** – Klicken Sie zweimal auf die Lupe, damit die Suchleiste geöffnet bleibt.

**Letzte Suchanfragen** – Es werden bis zu 5 Ihrer letzten Suchanfragen gespeichert, die Ihnen beim Öffnen des Suchfensters zur Verfügung stehen. Sie können Suchanfragen auch entfernen, indem Sie auf das X daneben klicken.
