---
title: "Profile anordnen"
---

Auf dem Tab **All profiles** können Sie Ihre Profile bequem mit **Sorting** und **Drag-n-drop** anordnen.

## Profile sortieren

Mit der Sortierung organisieren Sie die Profile in der Tabelle **All profiles**.

In Gologin können Sie Profile nach **profile name, last updated, last launched, created, shared, proxy type and the profile OS.** sortieren.

<Info>
  Standardmäßig werden Profile nach **Created descending** sortiert (die neuesten Profile zuerst).
</Info>

### So sortieren Sie Profile

1. Öffnen Sie die Seite **All Profiles**.
2. Suchen Sie die gewünschte Spalte in der Profiltabelle.
3. Klicken Sie auf das **Sortiersymbol** neben dem Spaltennamen.
   - **↑ - Ascending** (A-Z, von alt nach neu)\
     **↓ - Descending** (Z-A, von neu nach alt)\
     **⇅ - Sorting disabled**
4. Klicken Sie erneut, um zwischen **ascending**, **descending** und **disabling** zu wechseln.

</Frame>

## Profile per Drag-n-drop anordnen

Mit dieser Funktion können Sie Profile auf der Seite All profiles nach Ihren Wünschen anordnen, **unabhängig** von der jeweiligen Sortierung.

Ziehen Sie die Profile einfach per Drag-n-drop an die Position, die für Sie passt.

### So verwenden Sie Drag-n-drop

1. **Profilsortierung deaktivieren**
   - Stellen Sie sicher, dass bei allen Spalten das Symbol **⇅** angezeigt wird, sonst funktioniert die Funktion nicht.
2. Halten Sie ein **Profil gedrückt** und **verschieben** Sie es über oder unter die aktuelle Position.

<Frame>
  ![Drag N Drop](/images/drag-n-drop.gif)
</Frame>

<Tip>
  Die per Drag-n-drop festgelegte Anordnung bleibt auch erhalten, wenn Sie die Sortierung wieder aktivieren. Sobald Sie die Sortierung erneut deaktivieren, werden die Profile wieder in der zuvor benutzerdefinierten Reihenfolge angezeigt. Neue Profile werden oberhalb der bestehenden Profile eingefügt.
</Tip>
