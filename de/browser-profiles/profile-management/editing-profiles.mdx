## Änderungen auf der Profilseite

Einige Einstellungen können Sie direkt auf der Hauptseite **All profiles** ändern. Dazu gehören: **name, proxies, notes, status, tags**.

<Frame>
  ![Änderungen auf der Profilseite](/images/changes_from_the_profiles_page.gif)
</Frame>

## Schnelle Profileinstellungen

Um Ihre Profile schnell anzupassen, klicken Sie beim jeweiligen Profil auf die Schaltfläche **Settings**. Anschließend können Sie in der Seitenleiste neue Einstellungen festlegen.

<Frame>
  ![Schnelle Profileinstellungen](/images/quick_profile_settings.gif)
</Frame>

## Allgemeine Profileinstellungen

Die allgemeinen Profileinstellungen öffnen Sie über **die drei Punkte beim Profil \> Settings**. Dort finden Sie weitere Parameter sowie eine ausführlichere Beschreibung zu jedem einzelnen davon.

<Frame>
  ![Allgemeine Profileinstellungen](/images/main_profile_settings.gif)
</Frame>
