---
title: "Ordner"
---

Wenn Sie in Gologin mit vielen Browserprofilen arbeiten, helfen Ihnen Organisationstools dabei, Ihren Arbeitsbereich übersichtlich und leicht verwaltbar zu halten.

Gologin bietet mehrere Möglichkeiten, Profile effizient zu organisieren, darunter **Ordner, Gruppen, Tags, Status und die Sortierung von Profilen**.

Mit **Ordnern** können Sie Profile nach Projekt, Plattform oder Workflow trennen. Ordner werden oben auf der Seite „Profiles" angezeigt, sodass Sie schnell zwischen verschiedenen Profilsammlungen wechseln können.

## So erstellen Sie einen Ordner

1. Klicken Sie oben auf der Seite „Profiles" neben der Schaltfläche **All profiles** auf die **3 dots**
2. Wählen Sie **Add folder**
3. Geben Sie den Namen des Ordners ein
4. Erstellen Sie Profile im Ordner oder verschieben Sie vorhandene Profile hinein

<Frame>
  ![Create New Folder](/images/create_new_folder.gif)
</Frame>

## Profile in einem Ordner verwalten

Sie können neue Profile direkt im Ordner erstellen oder bereits vorhandene Profile in den Ordner verschieben.

Um **Profile im Ordner zu erstellen**, wechseln Sie in der oberen Ordnerleiste zum gewünschten Ordner und erstellen Sie die Profile wie gewohnt. Solange Sie sich im Ordner befinden, werden alle neuen Profile dort angelegt.

Um **Profile in den Ordner zu verschieben**, haben Sie zwei Möglichkeiten:

- entweder **auf die 3 dots beim Profil klicken \> Folders \> den Ordner auswählen**
- oder **mehrere Profile auswählen \> Folders \> Add to Folder \> den Ordner auswählen**

<Frame>
  ![Add Profiles To A Folder](/images/add_profiles_to_a_folder.gif)
</Frame>

Um Profile **aus einem Ordner zu entfernen**, führen Sie dieselben Schritte in umgekehrter Reihenfolge aus.

<Tip>
  Ein Profil kann Teil mehrerer Ordner sein
</Tip>

<Check>
  Ab dem Business-Tarif können Sie den Zugriff auf einen Ordner freigeben. Wie das geht, erfahren Sie [hier](https://gologin.com/docs/general/team-collaboration/sharing-profiles#how-to-share-folder)
</Check>
