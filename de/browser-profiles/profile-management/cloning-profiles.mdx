---
title: "Profile klonen"
---

Mit dem Klonen erstellen Sie ein neues Profil auf Basis eines bestehenden Profils.

Das ist nützlich, wenn Sie eine Umgebung duplizieren möchten und die Accounts dabei voneinander getrennt bleiben sollen.\
Geklonte Profile können Folgendes übernehmen:

- Fingerprint-Parameter
- Browsereinstellungen
- Konfiguration der Erweiterungen

Anschließend können Sie den Proxy oder andere Parameter für das neue Profil anpassen.

So klonen Sie ein bestehendes Profil:

1. Öffnen Sie **All profiles tab**
2. Suchen Sie das Profil, das Sie duplizieren möchten
3. Klicken Sie neben dem Profil auf die **three dots**
4. Wählen Sie **Clone**

<Frame>
  ![Profile klonen](/images/cloning_profiles.gif)
</Frame>

Es wird ein neues Profil mit der kopierten Konfiguration erstellt.
