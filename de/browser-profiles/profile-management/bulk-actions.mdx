---
title: "Massenaktionen"
---

Mit Massenaktionen in Gologin können Sie dieselbe Aktion auf mehrere Profile gleichzeitig anwenden.

Wählen Sie zunächst mehrere Profile in der Liste über die Kontrollkästchen aus. Anschließend erscheint oben auf der Seite die Leiste für Massenaktionen.

## So verwenden Sie Massenaktionen

1. Wählen Sie mehrere Profile über die Kontrollkästchen aus
2. Die Leiste für Massenaktionen erscheint oben auf der Seite
3. Wählen Sie die Aktion aus, die Sie anwenden möchten

## Wann Massenaktionen sinnvoll sind

Massenaktionen sind besonders nützlich, wenn Sie:

- mehrere Profile für die tägliche Arbeit oder zum Warm-up starten möchten
- Einstellungen in Stapeln aktualisieren möchten
- Profile in Ordnern und Projekten organisieren möchten
- den Zugriff für Teammitglieder verwalten möchten
- Fingerprints in großem Umfang pflegen oder erneuern möchten

## Was Sie mit Massenaktionen tun können

### **Profile starten**

Wählen Sie die Profile aus und klicken Sie auf **Run profile**, um alle ausgewählten Profile zu starten.

Damit starten Sie mehrere Konten für die tägliche Arbeit oder für Warm-up-Sitzungen.

<Note>
  Wenn Sie zu viele Profile gleichzeitig starten, kann dies je nach System die Leistung beeinträchtigen.
</Note>

<Frame>
  ![Bulk Run Profiles](/images/bulk_run_profiles.gif)
</Frame>

### **Profile mit Sync starten**

Wählen Sie die Profile aus und klicken Sie auf **Run with Sync**, um sie mit aktivierter Synchronisierung zu starten.

<Frame>
  ![Bulk Run With Sync](/images/bulk_run_with_sync.gif)
</Frame>

### **Profile beenden**

Wählen Sie die laufenden Profile aus und klicken Sie auf **Stop profile**, um sie zu schließen.

<Frame>
  ![Bulk Stop Profiles](/images/bulk_stop_profiles-1.gif)
</Frame>

### **Profile zu einem Ordner hinzufügen**

Wählen Sie die Profile aus, klicken Sie auf **Add to Folder** und wählen Sie den Zielordner aus.

<Frame>
  ![Bulk Add Profiles To Folder](/images/bulk_add_profiles_to_folder-1.gif)
</Frame>

### **Proxys zuweisen oder ändern**

Wählen Sie die Profile aus, klicken Sie auf **Proxy** und fügen Sie die Proxy-Einstellungen für alle ausgewählten Profile hinzu oder aktualisieren Sie sie.

Achten Sie darauf, dass der Standort des Proxys zu den Profileinstellungen (Land, Zeitzone) passt.

<Warning>
  Vermeiden Sie es, denselben Proxy vielen Profilen zuzuweisen.
</Warning>

<Frame>
  ![Bulk Change Proxies](/images/bulk_change_proxies-1.gif)
</Frame>

### **Profile teilen**

Wählen Sie die Profile aus, klicken Sie auf **Share Profile** und gewähren Sie einem anderen Benutzer Zugriff.

<Frame>
  ![Bulk Share Profiles](/images/bulk_share_profiles.gif)
</Frame>

### **Tags bearbeiten**

Wählen Sie die Profile aus, klicken Sie auf **Edit tags** und aktualisieren Sie die Tags für alle ausgewählten Profile.

Mit Tags können Sie auch sehr große Profilmengen schnell filtern und verwalten.

<Frame>
  ![Bulk Edit Tags](/images/bulk_edit_tags-1.gif)
</Frame>

### **Erweiterungen bearbeiten**

Wählen Sie die Profile aus und klicken Sie auf **Edit extensions**, um die Erweiterungen für die ausgewählten Profile zu verwalten.

<Frame>
  ![Bulk Edit Extensions](/images/bulk_edit_extensions.gif)
</Frame>

### **Lesezeichen bearbeiten**

Wählen Sie die Profile aus und klicken Sie auf **Edit bookmarks**, um die Lesezeichen zu aktualisieren.

<Frame>
  ![Bulk Edit Bookmarks](/images/bulk_edit_bookmarks.gif)
</Frame>

### **Profile umbenennen**

Wählen Sie die Profile aus und klicken Sie auf **Rename profiles**, um sie gesammelt umzubenennen.

<Frame>
  ![Bulk Rename Profiles](/images/bulk_rename_profiles-2.gif)
</Frame>

### **Profile klonen**

Wählen Sie die Profile aus und klicken Sie auf **Clone**, um Kopien davon zu erstellen.

<Frame>
  ![Bulk Clone Profiles](/images/bulk_clone_profiles.gif)
</Frame>

### **Profile übertragen**

Wählen Sie die Profile aus und klicken Sie auf **Transfer**, um sie in einen anderen Workspace oder zu einem anderen Benutzer zu verschieben, sofern dies in Ihrer Konfiguration verfügbar ist.

<Frame>
  ![Bulk Transfer Profiles](/images/bulk_transfer_profiles.gif)
</Frame>

### **Profile exportieren**

Wählen Sie die Profile aus und klicken Sie auf **Export profiles**, um sie zu exportieren.

<Frame>
  ![Bulk Export Profiles](/images/bulk_export_profiles.gif)
</Frame>

### **Fingerprint aktualisieren**

Wählen Sie die Profile aus und klicken Sie auf **Update fingerprint**, um die Fingerprint-Einstellungen zu erneuern.

<Frame>
  ![Bulk Update Fingerprint](/images/bulk_update_fingerprint.gif)
</Frame>

### **Profile löschen**

Wählen Sie die Profile aus und klicken Sie auf **Delete**, um sie zu entfernen.

<Frame>
  ![Bulk Delete Profiles](/images/bulk_delete_profiles-1.gif)
</Frame>

### **Automatisierung verwenden**

Wählen Sie die Profile aus und klicken Sie auf **Automation**, um automatisierungsbezogene Aktionen anzuwenden.

<Frame>
  ![Bulk Use Automation](/images/bulk_use_automation.gif)
</Frame>

<Info>
  Massenaktionen wirken sich auf alle ausgewählten Profile gleichzeitig aus.\
  Stellen Sie vor dem Anwenden einer Aktion sicher, dass die richtigen Profile ausgewählt sind, insbesondere bei **Delete**, **Transfer** oder **Update fingerprint**.
</Info>
