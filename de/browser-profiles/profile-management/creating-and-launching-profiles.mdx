## Überblick

Ein **Browserprofil** ist ein generierter Satz von Browserparametern, mit dem der Browser ein einzigartiges physisches Gerät und einen einzigartigen Nutzer nachahmt. Jedes Profil funktioniert wie eine eigene digitale Identität mit einem individuellen Fingerprint und anpassbaren Einstellungen.

Es gibt drei Möglichkeiten, neue Profile zu erstellen.

## Quick profiles

So fügen Sie schnell ein neues Profil hinzu, das Ihren [Standardeinstellungen für Profile](/de/default-profile-settings) einschließlich des Proxys entspricht. Standardmäßig werden Quick profiles mit einem Gologin-Proxy erstellt, der Ihr Proxy-Traffic-Kontingent verbraucht. Das eignet sich für die meisten Anwendungsfälle.

So erstellen Sie ein Quick profile:

1. Öffnen Sie den Tab **All profiles**
2. Klicken Sie in der Profilliste auf die Schaltfläche **\+**

<Frame>
  ![New Profile Plus](/images/new_profile_plus-3.png)
</Frame>

## Custom profiles

Verwenden Sie diese Option, wenn Sie einige Einstellungen anpassen möchten. Bevor das Profil erstellt wird, können Sie verschiedene Parameter wie das Betriebssystem, Proxys oder weitere erweiterte Einstellungen auswählen.

So fügen Sie ein Profil auf diese Weise hinzu:

1. Klicken Sie auf **Add profile**
2. Konfigurieren Sie die Profileinstellungen
3. Klicken Sie auf **Create Profile**

<Frame>
  ![New Custom Profile](/images/new_custom_profile.gif)
</Frame>

Anschließend können Sie die Profileinstellungen bearbeiten und mit einem Klick auf die Schaltfläche **Create Profile** speichern und das Profil erstellen.

## Bulk profiles

Sie können auch **bis zu 30 Profile** auf einmal erstellen. Die meisten Einstellungen sind dabei standardmäßig vorgegeben, einige davon können Sie direkt nach der Erstellung der Profile ändern.

1. Klicken Sie auf den Pfeil neben **Add profile**
2. Wählen Sie die Anzahl der Profile aus, die erstellt werden sollen (bis zu 30)
3. Klicken Sie auf **Add multiple profiles**

<Frame>
  ![New Bulk Profiles](/images/new_bulk_profiles.gif)
</Frame>

Sobald die Profile erstellt wurden, können Sie in einem neuen Fenster einige Parameter ändern.

## Profil starten

Um ein Profil zu starten, klicken Sie einfach beim gewünschten Profil auf **Run**. Es öffnet sich ein neues Browserfenster mit Ihren individuellen Profilparametern.

<Frame>
  ![Run And Stop The Profile](/images/run_and_stop_the_profile.gif)
</Frame>

Um ein gestartetes Profil zu beenden, **schließen Sie den Browser mit dem X**, wie Sie es bei jedem anderen Fenster tun, oder klicken Sie beim Profil auf **Stop**.

<Warning>
  Warten Sie auf den Profilstatus **ready**, bevor Sie die Gologin-App schließen, da die Profildaten zuerst mit den Servern synchronisiert werden müssen. Ein fehlgeschlagener Upload kann zu Datenverlust führen!
</Warning>
