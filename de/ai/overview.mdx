Gologin bietet KI-Agenten drei Dinge, die sie für die zuverlässige Arbeit im Web benötigen:

1. **Das Web lesen** – Scrapen Sie beliebige Seiten, auch JS-lastige und geschützte Websites, mit Web Unlocker
2. **Mit dem Web interagieren** – Öffnen Sie echte Browser-Sessions mit Klicks, Eingaben, Navigation und persistenten Cookies über Cloud Browser
3. **Unentdeckt bleiben** – Anti-Detect-Fingerprinting, Residential-Proxys und profilbasiertes Identitätsmanagement

Diese Funktionen stehen auf mehreren Integrationsebenen zur Verfügung – wählen Sie die Variante, die zu Ihrem Stack passt.

## So greift alles ineinander

```
┌─────────────────────────────────────────────────┐
│                  AI Agent                        │
│         (Claude, Codex, custom agent)            │
└──────┬──────────┬──────────┬────────────────────┘
       │          │          │
  MCP Server   AI Skills   CLI Tools / SDK
       │          │          │
       └──────────┴──────────┘
                  │
    ┌─────────────┴─────────────┐
    │                           │
Web Unlocker              Cloud Browser
(stateless scraping)    (stateful sessions)
    │                           │
    └─────────────┬─────────────┘
                  │
          Gologin Infrastructure
    (proxies, fingerprints, profiles)
```

- **Web Unlocker** übernimmt zustandsloses Lesen und Extrahieren – Sie senden eine URL und erhalten gerendertes HTML zurück
- **Cloud Browser** übernimmt zustandsbehaftete Interaktion – Sie öffnen eine Session, klicken, tippen, navigieren und speichern Cookies dauerhaft
- **Local Orbita** übernimmt persistente lokale Profile – Warmup, Login-Abläufe, Aktionen in sozialen Netzwerken und auf Marktplätzen

Alle drei nutzen dieselbe Gologin-Infrastruktur: Residential-Proxys, Anti-Detect-Fingerprinting und Profilverwaltung.

## Was man damit umsetzen kann

### Recherche und Wettbewerbsanalyse

Ein KI-Agent, der Preise, Produkteinführungen und Inhaltsänderungen der Konkurrenz auf Dutzenden Websites überwacht – täglich und automatisch. Der Agent scrapt Wettbewerberseiten über Web Unlocker, extrahiert strukturierte Daten, vergleicht sie mit dem Snapshot vom Vortag und erstellt eine tägliche Zusammenfassung. Es sind keine Browser-Sessions nötig, sondern nur zustandslose Extraktion in großem Maßstab.

```bash
# scrape 20 competitor pricing pages and get structured output
gologin-web-access batch-scrape \
  https://competitor1.com/pricing \
  https://competitor2.com/pricing \
  https://competitor3.com/pricing \
  --format json --summary --output ./today-prices.json

# detect what changed since last check
gologin-web-access batch-change-track \
  https://competitor1.com/pricing \
  https://competitor2.com/features \
  --format markdown --output ./changes.json
```

### Lead-Generierung und -Anreicherung

Scrapen Sie Branchenverzeichnisse, LinkedIn-Unternehmensseiten und Bewertungsportale – und übergeben Sie das HTML an Claude, um Namen, E-Mail-Adressen, Telefonnummern, Unternehmensgröße und Tech-Stack zu extrahieren. Das funktioniert als Tool innerhalb einer KI-Agent-Schleife: Der Agent entscheidet, welche Seiten er scrapt, ruft das Tool auf und erhält strukturierte Daten zurück.

```bash
# search for leads
gologin-web-access search "saas companies series A 2026" --limit 20

# scrape and extract structured data from each result
gologin-web-access extract https://example.com/company/123 --schema ./lead-schema.json
```

### Verwaltung mehrerer Accounts

Betreiben Sie mehr als 50 Social-Media-Accounts, Werbekonten oder Verkäufer-Accounts auf Marktplätzen – jeweils mit eigenem Browserprofil, Fingerprint, Proxy und eigenen Cookies. Local Agent Browser verwaltet die Profile, wärmt sie mit Runbooks auf und hält Sessions über mehrere Agent-Aufrufe hinweg aktiv.

```bash
# create profiles for each account
gologin-local-agent-browser profile-create "FB Ads Account 1" --template ads
gologin-local-agent-browser profile-create "FB Ads Account 2" --template ads

# warm up profiles in batch
gologin-local-agent-browser batch ./warmup-runbook.json \
  --targets ./all-profiles.json --concurrency 5
```

### Automatisches Ausfüllen von Formularen und Dateneingabe

Ein KI-Agent, der sich in interne Dashboards einloggt, Formulare ausfüllt, Berichte einreicht und Exporte herunterlädt – alles in einer echten Cloud-Browser-Session. Der Agent liest die Seite als Snapshot, findet die richtigen Felder anhand ihrer Referenz, tippt Werte ein, klickt auf „submit“ und prüft das Ergebnis.

```bash
gologin-agent-browser open https://internal-dashboard.com/login --profile my_profile
gologin-agent-browser snapshot
gologin-agent-browser fill @e3 "username"
gologin-agent-browser fill @e5 "password"
gologin-agent-browser click @e7    # submit button
gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # verify login success
gologin-agent-browser screenshot ./logged-in.png
```

### Content-Monitoring und Benachrichtigungen

Verfolgen Sie Änderungen auf Seiten mit behördlichen Vorschriften, Wettbewerber-Blogs, Jobbörsen oder anderen Seiten, die für Ihr Unternehmen wichtig sind. Führen Sie die Überwachung täglich per Cron oder mit einem geplanten Agenten aus, vergleichen Sie mit der vorherigen Version und lassen Sie sich bei relevanten Änderungen benachrichtigen.

```bash
# track changes on key pages
gologin-web-access change-track https://regulations.gov/new-rules --format markdown
gologin-web-access batch-change-track \
  https://competitor.com/blog \
  https://competitor.com/changelog \
  --output ./changes.json
```

### KI-gestützte Web-Scraping-Pipelines

Bauen Sie eine durchgängige Pipeline auf: Crawlen Sie eine Dokumentationswebsite, konvertieren Sie sie in Markdown und übergeben Sie sie an ein LLM für Zusammenfassungen oder Q&A. Nutzen Sie die CLI für die Extraktion und Ihren eigenen Code für den LLM-Teil.

```bash
# crawl an entire docs site
gologin-web-access crawl https://docs.example.com \
  --format markdown --limit 100 --max-depth 3 --only-main-content \
  --output ./docs-corpus.json

# or map the site first, then selectively scrape
gologin-web-access map https://docs.example.com --limit 200
gologin-web-access batch-scrape url1 url2 url3 --format text --output ./selected.json
```

### Geo-Tests und Lokalisierungs-QA

Prüfen Sie, wie Ihre Website in verschiedenen Ländern aussieht. Öffnen Sie dieselbe URL über Profile, die mit Proxys in verschiedenen Regionen konfiguriert sind, machen Sie Screenshots und vergleichen Sie sie.

```bash
# create geo-specific profiles
gologin-local-agent-browser profile-create "US Test" --template geo --proxy-country us
gologin-local-agent-browser profile-create "DE Test" --template geo --proxy-country de
gologin-local-agent-browser profile-create "JP Test" --template geo --proxy-country jp

# screenshot from each location
gologin-agent-browser open https://yoursite.com --profile us_profile_id
gologin-agent-browser screenshot ./us-view.png
gologin-agent-browser close
```

## Beispiele für den Schnellstart

### Eine Seite scrapen (CLI)

```bash
npm install -g gologin-web-access
export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."

gologin-web-access read https://example.com
```

### Einen Cloud-Browser öffnen (CLI)

```bash
npm install -g gologin-agent-browser-cli
export GOLOGIN_TOKEN='your_token'

gologin-agent-browser open https://example.com
gologin-agent-browser snapshot
gologin-agent-browser click @e3
gologin-agent-browser close
```

### Einen AI Skill installieren (Claude Code)

```bash
npx skills add GologinLabs/gologin-web-access-skill
```

Bitten Sie anschließend Claude Code einfach, eine Seite zu scrapen oder mit einer Website zu interagieren – den Rest übernimmt der Skill.

### MCP verbinden (Claude Desktop)

Fügen Sie Folgendes zu `claude_desktop_config.json` hinzu:

```json
{
  "mcpServers": {
    "gologin-mcp": {
      "command": "npx",
      "args": ["gologin-mcp"],
      "env": { "API_TOKEN": "your-token" }
    }
  }
}
```

Bitten Sie dann Claude: „Erstelle ein neues Browserprofil mit einem US-Proxy.“
