Du verbindest jedes LinkedIn-Konto nur einmal. Danach bleibt es angemeldet und funktioniert in der Cloud.

## Konto verbinden

1. Öffne **Accounts** und klicke auf **Connect account**.
2. **Wähle das Netzwerk.** LinkedIn ist derzeit verfügbar.
3. **Wähle, woher die IP stammt:**
   - **Eine dedizierte IP** in einem der verfügbaren Länder: Brasilien, Frankreich, Deutschland, Hongkong, Indien, Indonesien, Rumänien, Südkorea, Türkei, Vereinigtes Königreich oder USA. Die Liste kann sich ändern.
   - **Dein eigener Proxy.** Gib ihn ein, klicke auf **Check proxy** und dann auf **Use this proxy**.
4. **Melde dich bei LinkedIn an**, und zwar auf eine von drei Arten:
   - **Credentials** - E-Mail-Adresse und Passwort des Kontos. Das Passwort wird verschlüsselt gespeichert und nur verwendet, um die Sitzung später wiederherzustellen.
   - **Cookies** - das `li_at`-Cookie aus einem Browser, in dem du bei LinkedIn angemeldet bist. Das Passwort brauchst du nicht.
   - **Gologin profile** - ein Gologin-Profil, das bereits bei LinkedIn angemeldet ist. Eine neue Anmeldung ist nicht nötig, und das Konto verwendet den Proxy des Profils.
5. Wenn du deine bestehenden LinkedIn-Unterhaltungen übernehmen möchtest, aktiviere **Import existing conversations**. Andernfalls werden nur Unterhaltungen ab dem Zeitpunkt der Verbindung gespeichert.
6. Klicke auf **Login**. Gologin weist eine dedizierte IP zu, erstellt ein Browserprofil für das Konto und meldet sich bei LinkedIn an.

<Tip>
  So kopierst du das `li_at`-Cookie: Öffne LinkedIn in einem Browser, in dem du angemeldet bist, drücke **F12**, gehe zu **Application** > **Cookies** > **https://www.linkedin.com** (in Firefox: **Storage** > **Cookies**) und kopiere den Wert von `li_at`.
</Tip>

## LinkedIn-Prüfungen bestehen

LinkedIn kann dich bitten zu bestätigen, dass du es bist. Das erledigst du im selben Fenster:

- **Code from email** - gib den Code ein, den LinkedIn an die E-Mail-Adresse des Kontos geschickt hat.
- **Authenticator app** - gib den Code aus Google Authenticator oder einer ähnlichen App ein.
- **Phone number** - gib eine Telefonnummer ein. LinkedIn sendet in der Regel einen Code dorthin.
- **LinkedIn app** - bestätige die Anmeldung in der LinkedIn-App auf deinem Smartphone. Das Fenster fährt von selbst fort.

Zeigt LinkedIn eine Prüfung an, die von einer Person gelöst werden muss, öffnet sich ein Browserfenster, in dem du sie selbst bestehen kannst.

Jede Prüfung wartet bis zu 10 Minuten. Wird der Code nicht rechtzeitig eingegeben oder die Anmeldung nicht rechtzeitig bestätigt, melde dich erneut an.

Wenn die Meldung **LinkedIn asked for an extra check we can't complete here, sign in with cookies instead** erscheint, verbinde das Konto mit dem `li_at`-Cookie.

## Kontostatus

| Status | Bedeutung |
| :-- | :-- |
| **Active** | Das Konto ist angemeldet und funktioniert. |
| **Needs action** | Du musst etwas tun: einen Code eingeben, die Anmeldung bestätigen, eine LinkedIn-Prüfung bestehen oder dich erneut anmelden. Der Grund wird unter dem Status angezeigt. |
| **Restricted** | LinkedIn hat das Konto eingeschränkt. Prüfe es auf linkedin.com. |
| **Paused** | Du hast das Konto getrennt. |

Häufige Gründe unter dem Status:

| Grund | Was zu tun ist |
| :-- | :-- |
| Wrong password · retry login | Melde dich erneut mit dem richtigen Passwort an oder verwende Cookies. |
| Session expired · log in again | LinkedIn hat die Sitzung beendet. Melde dich erneut mit deinem Passwort oder neuen Cookies an. |
| LinkedIn asked for a checkpoint | Bestehe die Prüfung auf linkedin.com und melde dich dann erneut mit neuen Cookies an. |
| Verification code expired | Der Code wurde nicht innerhalb von 10 Minuten eingegeben. Melde dich erneut an und verwende den neuen Code. |
| Not confirmed in the LinkedIn app in time | Melde dich erneut an und bestätige die Anmeldung in der LinkedIn-App. |
| No dedicated IP available | Wähle ein anderes Land oder verwende deinen eigenen Proxy. |
| Already connected in this workspace | Dieses LinkedIn-Konto befindet sich bereits in deiner Liste. |
| LinkedIn has restricted this account | Prüfe das Konto auf linkedin.com. |

## Konto trennen oder löschen

- **Disconnect.** Aufgaben, die über dieses Konto laufen, werden gestoppt. Das Konto bleibt in deiner Liste und behält seinen Platz, bis du es wieder verbindest.
- **Delete.** Das Konto sowie seine Chats und der Verlauf werden endgültig entfernt. Aufgaben, die darüber laufen, werden gestoppt, und der Platz wird für ein anderes Konto frei.
