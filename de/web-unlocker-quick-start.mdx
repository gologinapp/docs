Diese Anleitung zeigt, wie Sie Ihre erste URL mit Web Unlocker scrapen.

---

## Voraussetzungen

- Ein Web Unlocker API-Schlüssel. Sie erhalten ihn über das Formular auf der [Web Unlocker-Seite](https://gologin.com/web-unlocker/#web_unlocker_form). Der Schlüssel kommt innerhalb eines Werktags an, inklusive kostenloser Anfragen, mit denen Sie Ihre eigenen Ziele testen können. Eine Kreditkarte ist nicht erforderlich.
- Python 3.x, Node.js oder ein beliebiger HTTP-Client

---

## Authentifizierung

Alle Anfragen erfordern Ihren API-Schlüssel im Header `apikey`:

```
apikey: YOUR_API_KEY
```

Die Basis-URL für alle API-Anfragen lautet:

```
https://parsing.webunlocker.gologin.com/v1
```

---

## Erste Anfrage senden

Senden Sie eine GET-Anfrage mit der Ziel-URL als Query-Parameter. Die Antwort ist das vollständig gerenderte HTML der Seite.

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.text)
```

### JavaScript (Node.js / Browser)

```javascript
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(html);
```

---

## Was Sie als Antwort erhalten

Der Antwort-Body ist das unveränderte, gerenderte HTML der Seite – derselbe Inhalt, den Sie sehen würden, wenn Sie die URL in einem Browser öffnen. Es gibt keinen JSON-Wrapper und kein Parsing ist nötig.

```html
<!DOCTYPE html>
<html>
  <head><title>Example Domain</title></head>
  <body>...</body>
</html>
```

### Weitere Formate

Fügen Sie den Query-Parameter `format` hinzu, um die Seite in einem anderen Format zu erhalten:

| `format` | Antwort-Body |
|---|---|
| `html` | Seiten-HTML (Standard) |
| `markdown` | Seiteninhalt als Markdown |
| `json` | JSON-Objekt mit der URL, den Anfrage-Metadaten und dem Seiten-HTML |

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com&format=json" \
  -H "apikey: YOUR_API_KEY"
```

```json
{
  "success": true,
  "data": {
    "url": "https://example.com",
    "metadata": {
      "response_time_ms": 297,
      "status_code": 200
    },
    "html": "<!DOCTYPE html><html lang=\"en\">..."
  }
}
```

---

## Fehlerbehandlung

Prüfen Sie den HTTP-Statuscode, bevor Sie die Antwort verarbeiten:

| Status | Bedeutung | Antwort-Body |
|---|---|---|
| `200` | Erfolg | Die Seite im angeforderten Format |
| `400` | Ungültige Anfrage, zum Beispiel fehlt der Parameter `url` | `{"success":false,"error":"Request failed"}` |
| `401` | Der Header `apikey` fehlt | `{"message":"Missing API key in request"}` |

Wenn Sie `429` oder einen `5xx`-Status erhalten, wiederholen Sie die Anfrage mit exponentiellem Backoff.

```python
response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

if response.status_code == 200:
    html = response.text
else:
    print(f"Error {response.status_code}: {response.text}")
```

## Schnellstart mit der CLI

Sie können Seiten auch ohne eigenen Code mit den Gologin CLI-Tools scrapen:

### Web Unlocker CLI

```bash
npm install -g gologin-webunlocker

GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker scrape https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker markdown https://example.com
```

### Gologin Web Access CLI (einheitlich)

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."
gologin-web-access read https://example.com
gologin-web-access scrape-json https://example.com
gologin-web-access batch-scrape https://example.com/page/1 https://example.com/page/2 --format text
```

Weitere Details finden Sie unter [Web Unlocker SDK und CLI](/de/scraping-api-sdk-and-cli) und [Web Access CLI](/de/cli-tools/web-access).
