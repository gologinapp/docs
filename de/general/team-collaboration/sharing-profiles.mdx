---
title: "Profile teilen"
---

Wenn Sie nur ein oder zwei Profile teilen möchten, müssen Sie dafür nicht die Funktion Team members nutzen: Sie können die Funktion **Share profile** direkt in Ihrer Profilliste verwenden!

## Was als Profilfreigabe zählt

**1 Freigabe = 1 Instanz eines geteilten Profils.**\
Beispiel: Wenn Sie **2 Profile für 5 Personen** oder **10 Profile für einen einzelnen Kollegen** freigeben, werden in beiden Fällen **10 Freigaben** verbraucht.

<Check>
  Nur bestehende Freigaben werden auf das Limit angerechnet. Wenn Sie nicht mehr benötigte Freigaben entfernen, werden die entsprechenden Freigabeplätze wieder frei.
</Check>

## So teilen Sie ein Profil

<Info>
  **Hinweis**: Mit den [Massenaktionen](/de/browser-profiles/profile-management/bulk-actions) können Sie mehrere Profile gleichzeitig teilen.
</Info>

1. Bewegen Sie den Mauszeiger über die **drei Punkte** eines Profils \> **Share**
2. Geben Sie die **E-Mail-Adresse des Nutzers** ein
3. Wählen Sie eine Rolle aus:
   1. **Can run** - kann die freigegebenen Profile **ansehen** und **ausführen**
   2. **Can edit** - kann die freigegebenen Profile **ausführen**, **klonen** und deren Einstellungen **bearbeiten**
   3. **Full access** - wie **Can edit**, kann aber zusätzlich Profile **teilen**
4. Klicken Sie auf **Share**, um die Änderungen zu übernehmen

<Frame>
  ![How To Share Profile](/images/how_to_share_profile.gif)
</Frame>

Nachdem die Freigabe aktiviert wurde, erscheint das Profil in der Profilliste Ihres Kollegen.

Um eine Freigabe zu entfernen, klicken Sie im selben Menü auf die **Rolle** \> **Remove**.
