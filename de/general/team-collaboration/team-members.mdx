---
title: "Teammitglieder"
---

Mit der Funktion **Team Members** können Sie andere Personen in Ihren Gologin-Workspace einladen, damit diese mit Ihren Profilen arbeiten können – ohne dass Sie Ihr Kontopasswort oder Ihre Zugangsdaten weitergeben müssen.

Jede eingeladene Person belegt einen **Team-Member-Platz** Ihres Abonnements.

## Teammitglieder-Plätze kaufen

Die Tarife **Business**, **Enterprise** und **Custom** enthalten einen Teammitglieder-Platz. Im Tarif **Professional** sind keine Plätze enthalten, sie können aber dazugekauft werden. Wenn Sie weitere Plätze benötigen, gehen Sie wie folgt vor:

1. Öffnen Sie das **main menu**, indem Sie oben links auf den Namen des Workspace klicken
2. Gehen Sie zu **Settings & Members**
3. Öffnen Sie den Tab **Billing Plans**
4. Klicken Sie auf **Change plan**
5. Suchen Sie Ihren aktuellen Tarif
6. Geben Sie die neue Anzahl an Teammitglieder-Plätzen an
7. Klicken Sie auf **Upgrade plan** und schließen Sie die Zahlung ab

<Frame>
  ![Teammitglieder-Plätze kaufen](/images/purchasing_team_members.gif)
</Frame>

Nach dem Kauf können Sie neue Teammitglieder in den Workspace einladen.

## Zugriffsoptionen

Sie können den Zugriff entweder auf den gesamten Workspace oder nur auf bestimmte Ordner freigeben:

- **Workspace access** – gewährt Zugriff auf Ihren gesamten Workspace, einschließlich aller Profile und Ordner.
- **Selected folders** – gewährt nur Zugriff auf die ausgewählten Ordner. Das Teammitglied kann keine Ordner verwalten.

## Rollen und Berechtigungen

### Rollen

Unabhängig davon, ob Sie Zugriff auf **Ordner** oder auf einen **Workspace** gewähren, stehen die folgenden Rollen und Berechtigungen zur Verfügung:

| Rolle | View, Run | Create, Edit, Clone, Delete | Share, Transfer | Share and Transfer Folders | Invite Team Members |
| :-- | :-: | :-: | :-: | :-: | :-: |
| Can run | ✅ | 🚫 | 🚫 | 🚫 | 🚫 |
| Can edit | ✅ | ✅ | 🚫 | 🚫 | 🚫 |
| Folder full access | ✅ | ✅ | ✅ | 🚫 | 🚫 |
| Workspace full access | ✅ | ✅ | ✅ | ✅ | ✅ |

Wie Sie sehen, erhält Ihr Teammitglied nur dann Kontrolle über Ihre Ordner und Mitglieder, wenn es Zugriff auf den gesamten Workspace hat.

### Berechtigungen im Detail

**View, Run profiles** – kann Profile und Profileinstellungen ansehen und Profile starten.

**Create, Edit, Clone, Delete profiles** – kann neue Profile erstellen, bestehende Profile bearbeiten, Profile innerhalb desselben Bereichs klonen und bestehende Profile löschen.

**Share, Transfer profiles** – kann bestehende Profile einzeln freigeben und Profile in andere Workspaces übertragen.

**Share and Transfer folders** – kann Ordner freigeben und in andere Workspaces übertragen.

**Invite Team Members** – kann neue Teammitglieder in den aktuellen Workspace einladen. Darüber hinaus erhalten sie keine Rechte zur Verwaltung des Teams.
