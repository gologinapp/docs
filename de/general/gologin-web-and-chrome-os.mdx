## Gologin Web ([app.gologin.com](http://app.gologin.com))

Sie können von jedem Browser aus unter **app.gologin.com** auf alle Ihre Profile zugreifen, ohne die Desktop-App zu installieren. Das ist praktisch für:

- Chrome-OS-Geräte
- Gemeinsam genutzte oder eingeschränkte Computer
- Schnellen Zugriff von jedem Gerät aus

**Es gelten Limits für Cloud-Sitzungen:**

- Professional: 1 gleichzeitige Cloud-Sitzung
- Business: 2 gleichzeitige Cloud-Sitzungen
- Enterprise: 3 gleichzeitige Cloud-Sitzungen

Alle Profildaten werden zwischen der Desktop- und der Web-Version synchronisiert.

## Chrome OS

Gologin funktioniert auf Chrome OS über die Web-Version (app.gologin.com). Es ist keine Installation nötig – öffnen Sie einfach Ihren Browser und melden Sie sich an. Je nach Tarif gelten Limits für Cloud-Sitzungen.
