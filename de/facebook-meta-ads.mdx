Facebook gehört zu den Plattformen, die Fingerprints besonders genau auswerten. Die Plattform gleicht IP-Adresse, Geräteumgebung, Verhaltensmuster und Zahlungshistorie miteinander ab, um Accounts zu bewerten. Widersprüche zwischen diesen Signalen lösen Verifizierungsprüfungen aus.

## Kurz-Checkliste

- 1 Account = 1 Browserprofil
- 1 Profil = 1 statischer Residential- oder Mobile-Proxy
- Verwenden Sie einen Proxy niemals für mehrere Profile
- Das Betriebssystem des Profils sollte zu dem Ihres Geräts passen
- Ändern Sie nach dem ersten Login weder Proxy noch Fingerprint

## Schritt 1: Gologin-Profil einrichten

Empfohlene Einstellungen:

- **Proxy: **statisch, Residential oder Mobile – weisen Sie ihn zu, bevor Sie Facebook zum ersten Mal öffnen
- **Fingerprint: **Standardeinstellungen beibehalten – passen Sie Canvas, WebGL oder AudioContext nicht manuell an

Sobald Sie in einem Profil bei Facebook angemeldet sind, ändern Sie weder Proxy noch Fingerprint-Einstellungen. Facebook speichert Gerätedaten serverseitig. Eine Änderung des Fingerprints sieht aus wie ein neues Gerät, das auf Ihren Account zugreifen will.

## Schritt 2: Browser vor der Registrierung aufwärmen

Bevor Sie einen neuen Account erstellen, surfen Sie 10–15 Minuten ganz normal im Profil:

- Öffnen Sie 3–5 Websites ohne Bezug zueinander
- Scrollen und klicken Sie, und machen Sie natürliche Pausen
- Rufen Sie Facebook noch nicht auf

So entsteht eine Sitzungshistorie, und die Umgebung wirkt wie ein echtes Gerät. Ein komplett neuer Browser ohne Verlauf ist ein starkes Erkennungssignal.

## Schritt 3: Account erstellen

- Legen Sie zwischen den Registrierungen mindestens 30–60 Minuten Abstand
- Verwenden Sie für jeden Account eine eigene Telefonnummer
- Erstellen Sie pro Proxy-Standort nicht mehr als 2–3 Accounts pro Tag
- Vermeiden Sie identische Registrierungsabläufe bei mehreren Accounts

Wenn Facebook bei der Registrierung eine Telefonverifizierung verlangt, führen Sie diese durch. Überspringen Sie sie nicht und verwenden Sie dieselbe Nummer nicht zweimal.

## Schritt 4: Profil vervollständigen

- Laden Sie ein Profilbild und ein Titelbild hoch
- Füllen Sie die Basisinformationen aus (Wohnort, Arbeitgeber, Ausbildung)
- Folgen Sie 5–10 Seiten, die zu Ihrer Nische passen
- Treten Sie 1–2 Gruppen bei

Posten Sie in den ersten 24 Stunden keine Links, erstellen Sie keine Events und senden Sie keine Freundschaftsanfragen.

## Schritt 5: Account aufwärmen

Facebook prüft neue Accounts in den ersten 2–3 Wochen besonders streng.

### Zeitplan fürs Aufwärmen

| **Zeitraum** | **Schwerpunkt** | **Was zu tun ist** |
| :-- | :-- | :-- |
| Tag 0 | Einrichtung | Profil vervollständigen \+ 15 Min. Surfen |
| Tag 1–7 | Passiv | Feed durchsehen, Videos ansehen, Beiträge liken |
| Tag 8–14 | Leichte Interaktion | Kommentare, Seiten folgen, 2–3 Freundschaftsanfragen/Tag |
| Woche 3 | Normale Nutzung | Gruppen, mehr Interaktionen, gelegentliche Beiträge |
| Woche 4\+ | Bereit für Ads | Business Manager \+ Werbekonto einrichten |

### Sichere Aktivitätsniveaus

| **Aktion** | **Empfohlenes Niveau** |
| :-- | :-- |
| Freundschaftsanfragen | 5–10 / Tag |
| Seiten folgen | 5–10 / Tag |
| Beiträge liken | 15–30 / Tag |
| Gruppenbeitritte | 1–2 / Tag |
| Beiträge mit externen Links | Nach Woche 3 |

## Meta Ads einrichten

Richten Sie Meta Ads erst ein, wenn das persönliche Profil aufgewärmt ist – mindestens 1–2 Wochen Aktivität.

- Erstellen Sie einen Business-Manager-Account ([business.facebook.com](http://business.facebook.com))
- Fügen Sie Ihr persönliches Profil als Admin hinzu
- Erstellen Sie ein Werbekonto – beginnen Sie mit nur einem
- Hinterlegen Sie eine eigene Zahlungsmethode
- Starten Sie eine kleine Testkampagne (\$5–10/Tag)
- Steigern Sie das Budget über 1–2 Wochen schrittweise

<Warning>
  Fügen Sie dieselbe Zahlungsmethode nicht mehreren Werbekonten hinzu. Facebook verknüpft Accounts über gemeinsame Zahlungsmethoden. Jedes Werbekonto braucht eine eigene Zahlungsquelle.
</Warning>

## Häufige Risikoauslöser

### Sofortige Sperren

- Anmeldung von einer neuen IP, nachdem der Account bereits aktiv war
- Dieselbe Zahlungsmethode bei mehreren Werbekonten
- 5\+ Accounts an einem Tag über denselben Proxy-Standort erstellen
- Anzeigen schalten, bevor das Profil aufgewärmt ist

### Schleichende Einschränkungen

- Derselbe Inhalt wird von mehreren Accounts gepostet
- Viele Freundschaftsanfragen bei geringer Annahmequote
- Massenhafte Gruppenbeitritte in kurzer Zeit
- Ungewöhnliche Ausgabenspitzen bei Anzeigen
