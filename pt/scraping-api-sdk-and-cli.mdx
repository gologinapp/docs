O Gologin Web Unlocker é uma **Scraping API de endpoint único** para sites protegidos e com muito JavaScript.

Você envia uma URL, recebe o HTML/texto renderizado da página e o processa no seu próprio pipeline de extração.

## Por que usar como Scraping API

- Um único endpoint para qualquer URL de destino
- Autenticação por chave de API, sem necessidade de orquestrar navegadores
- HTML por padrão, ou Markdown ou JSON sob demanda, pronto para os parsers que você já usa
- Ideal para ETL, monitoramento, ingestão de dados para IA e pipelines de dados

## Endpoint

`GET https://parsing.webunlocker.gologin.com/v1/scrape?url={encoded_url}`

## Autenticação

Envie sua chave de API nos cabeçalhos:

```http
apikey: <API_KEY>
```

## Modelo de requisição

| Nome | Onde | Tipo | Obrigatório | Descrição |
|---|---|---|---|---|
| `url` | query | string (URL absoluta) | sim | URL de destino a ser extraída |
| `format` | query | string | não | Formato da resposta: `html` (padrão), `markdown` ou `json` |

## Início rápido

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.status_code)
print(response.text[:500])
```

### JavaScript (fetch)

```js
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(response.status, html.slice(0, 500));
```

## Comportamento da resposta

Por padrão, o corpo da resposta é o **HTML renderizado bruto** da página. Com `format=markdown`, o corpo é Markdown. Com `format=json`, o corpo é um objeto JSON:

```json
{
  "success": true,
  "data": {
    "url": "https://example.com",
    "metadata": {
      "response_time_ms": 297,
      "status_code": 200
    },
    "html": "<!DOCTYPE html><html lang=\"en\">..."
  }
}
```

Códigos de status:

- `200` -> sucesso, o corpo contém a página no formato solicitado
- `400` -> requisição inválida, por exemplo, quando `url` não foi informada; corpo: `{"success":false,"error":"Request failed"}`
- `401` -> o cabeçalho `apikey` está ausente; corpo: `{"message":"Missing API key in request"}`

## Orientações sobre novas tentativas

Tente novamente com backoff exponencial nos seguintes casos:

- erros de rede
- `408`, `429`, `500`, `502`, `503`, `504`

## SDK oficial para Node.js

Instalação:

```bash
npm i gologin-webunlocker
```

### Início rápido do SDK

```ts
import { WebUnlocker } from "gologin-webunlocker";

const client = new WebUnlocker({
  apiKey: process.env.GOLOGIN_WEBUNLOCKER_API_KEY!
});

const result = await client.scrape("https://example.com");
console.log(result.status);
console.log(result.content.slice(0, 500));
```

### Opções do construtor

```ts
new WebUnlocker({
  apiKey: "wu_live_xxx",
  baseUrl: "https://parsing.webunlocker.gologin.com",
  timeoutMs: 15000,
  maxRetries: 2
});
```

### Métodos principais do SDK

- `scrape(url)` -> objeto de resposta normalizado
- `scrapeRaw(url)` -> `Response` nativo
- `buildScrapeUrl(url)` -> URL completa da requisição

### Métodos derivados no SDK (a partir do HTML retornado)

Estes **não são endpoints separados no backend**; eles são derivados no SDK a partir do HTML retornado pela API. O SDK envia apenas o parâmetro `url`, e não `format`, portanto essa saída pode ser diferente da resposta de `format=markdown` ou `format=json` da própria API:

- `scrapeText(url)` -> texto simples
- `scrapeMarkdown(url)` -> markdown
- `scrapeJSON(url)` -> metadados estruturados (`title`, `description`, `canonical`, `meta`, `headings`, `links`)
- `batchScrape(urls, { concurrency })` -> auxiliar para várias chamadas de scrape

### Erros tipados

- `WebUnlockerError`
- `AuthenticationError`
- `RateLimitError`
- `APIError`
- `TimeoutError`
- `NetworkError`

Mapeamento:

- `401` / `403` -> `AuthenticationError`
- `429` -> `RateLimitError`
- `500+` e outros status que não sejam 2xx (por exemplo, `400`) -> `APIError`
- timeout/abort -> `TimeoutError`
- falha de fetch/rede -> `NetworkError`

## CLI

```bash
gologin-webunlocker <command> <url> [options]
```

Comandos:

- `scrape` (HTML/texto bruto)
- `text` (texto derivado)
- `markdown` (markdown derivado)
- `json` (metadados derivados)

Exemplos:

```bash
gologin-webunlocker scrape https://example.com --api-key wu_live_xxx
GOLOGIN_WEBUNLOCKER_API_KEY=wu_live_xxx gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_live_xxx gologin-webunlocker json https://example.com
```

## Casos de uso típicos de scraping

- monitoramento de preços e catálogos
- enriquecimento de leads e diretórios
- pipelines de inteligência de mercado
- agregação e indexação de conteúdo
- fluxos de ingestão e extração para LLMs

## Gologin Web Access CLI (unificada)

Para uma CLI mais poderosa, que combina o Web Unlocker com o Cloud Browser em uma única interface de comandos, use o `gologin-web-access`:

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."

# all scraping commands from gologin-webunlocker, plus:
gologin-web-access batch-scrape url1 url2 url3 --format text --summary
gologin-web-access search "query" --limit 10
gologin-web-access map https://example.com --limit 50
gologin-web-access crawl https://docs.example.com --format markdown --limit 20
gologin-web-access extract https://example.com --schema ./schema.json
gologin-web-access change-track https://example.com --format markdown

# plus cloud browser interaction (requires GOLOGIN_TOKEN)
gologin-web-access open https://example.com
gologin-web-access snapshot
gologin-web-access click e3
```

Consulte a [CLI Gologin Web Access](/pt/cli-tools/web-access) para ver a referência completa.
