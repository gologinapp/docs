O Gologin Cloud Browser permite executar um navegador Gologin (Orbita) **na nuvem** e controlá-lo a partir do seu código de automação (Puppeteer / Playwright) usando uma única **URL de conexão**.

É um [navegador headless](./what-is-headless-browser), ou seja, um navegador controlado inteiramente por código, sem interface gráfica, hospedado e gerenciado pela Gologin, com suporte integrado a perfis persistentes, configuração de fingerprint e roteamento de proxy.

## O que você pode fazer com o Cloud Browser

- Executar várias sessões de navegador em paralelo na nuvem
- Automatizar com a sua stack atual (Puppeteer / Playwright)
- Usar **perfis** da Gologin para manter o estado persistente (logins, cookies, armazenamento)
- Direcionar o tráfego por **proxies** configurados no perfil
- Usar como ambiente de navegador remoto para agentes de IA

## Como ele se diferencia de um navegador headless comum

Um Chrome headless comum é detectável. Os sites usam fingerprinting de navegador para identificar tráfego automatizado, verificando a renderização do canvas, os parâmetros do WebGL, as fontes, o fuso horário, o tamanho da tela e dezenas de outros sinais.

O Gologin Cloud Browser executa o **Orbita**, um Chromium modificado que gerencia os sinais de fingerprint para corresponder a um perfil de navegador consistente e realista. Combinadas com cookies persistentes e com a configuração de proxy armazenada em cada perfil, suas sessões parecem estáveis e humanas ao longo de visitas repetidas.

## Por que usar o Gologin Cloud Browser

### Anti-detect integrado, sem necessidade de plugins

O Chrome headless padrão é facilmente detectável. Outros serviços de navegador na nuvem executam o Chromium padrão e exigem plugins stealth de terceiros para reduzir os sinais de fingerprint, com resultados variáveis.

O Gologin Cloud Browser executa o **Orbita**, uma versão reforçada do Chromium com gerenciamento de fingerprint em sua essência: canvas, WebGL, fontes, fuso horário, resolução de tela e muito mais. O anti-detect não é um remendo aplicado por cima: ele é o próprio navegador.

### Perfis persistentes: sessões que se lembram de você

A maioria dos serviços de navegador na nuvem trata cada sessão como se não tivesse estado. Cookies e armazenamento são descartados quando a sessão é encerrada.

Os perfis da Gologin são persistentes. Faça login uma vez, encerre a sessão e reconecte mais tarde: o perfil mantém seus cookies, o armazenamento local e todas as configurações definidas. Sem nova autenticação e sem necessidade de aquecer a sessão.

## Cenários técnicos comuns

O Cloud Browser normalmente é usado em fluxos de trabalho em que você:

- faz login em uma conta web uma vez e mantém a sessão persistente por meio de um perfil
- executa ações repetidas nos mesmos sites em vários perfis
- precisa de sessões estáveis e de longa duração sem depender de uma máquina local

Exemplos incluem a automação de sessões autenticadas em aplicativos web, marketplaces ou plataformas sociais, onde a persistência e a consistência das configurações do perfil são importantes.

## Conceitos principais

- **Perfil** — uma identidade de navegador reutilizável (cookies/armazenamento + configurações de fingerprint e proxy).
- **Sessão na nuvem** — uma instância em execução de um perfil na nuvem da Gologin.
- **URL de conexão** — o endpoint que você passa para a sua ferramenta de automação para controlar a sessão na nuvem.

## Como funciona (visão geral)

1. (Recomendado) Crie e configure um perfil pela API REST da Gologin (proxy, fingerprint etc.).
2. Conecte-se ao Cloud Browser usando seu **dev token** e, opcionalmente, o `profileId`.
3. Automatize a sessão com Puppeteer ou Playwright.
4. Encerre a conexão quando terminar.

## URL de conexão

Use esta URL como endpoint do navegador remoto:

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${profileId}
```

- `token` — seu **dev token** da Gologin (crie-o no app da Gologin: [API & MCP](https://app.gologin.com/personalArea/TokenApi) → **API** → **Novo Token**).
- `profile` — **ID do perfil** (opcional). Se omitido, um novo perfil será criado para a sessão.

## Gerenciamento de perfis (proxy, fingerprint etc.)

O Cloud Browser é a **camada de conexão**.\
Para criar/atualizar perfis, associar proxies e configurar os ajustes do perfil, use a API REST da Gologin:

- API de perfis: [Criar perfil](https://gologin.com/docs/api-reference/profile/create-profile-with-partial-parameters), [Atualizar perfil](https://gologin.com/docs/api-reference/profile/update-profile-with-partial-parameters)
- API de proxy: [Adicionar um proxy da Gologin a um perfil](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy), [Configurar seu próprio proxy nos perfis](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles)

## Use o Cloud Browser pela CLI

Se você prefere comandos de shell a escrever código Puppeteer/Playwright, a Gologin oferece ferramentas de CLI voltadas para agentes:

- **[Gologin Agent Browser CLI](/pt/cli-tools/agent-browser)** — CLI de navegador na nuvem com daemon, snapshots de página e interação baseada em referências. Criada para agentes de IA.
- **[Gologin Web Access CLI](/pt/cli-tools/web-access)** — CLI unificada que combina a extração de dados do Web Unlocker com a interação do Cloud Browser em uma única ferramenta.

```bash
npm install -g gologin-agent-browser-cli
export GOLOGIN_TOKEN='your_token'

gologin-agent-browser open https://example.com
gologin-agent-browser snapshot
gologin-agent-browser click @e3
gologin-agent-browser screenshot ./page.png
gologin-agent-browser close
```
