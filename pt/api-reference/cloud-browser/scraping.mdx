## Visão geral

O Gologin Cloud Browser pode ser usado como um navegador remoto gerenciado para fluxos de trabalho de scraping e extração de dados. Seu código de automação (Puppeteer) se conecta a uma sessão de navegador remota por meio de um endpoint WebSocket e, em seguida, executa a lógica padrão de navegação e extração.

O Cloud Browser é a camada de conexão e execução; as configurações de perfil e proxy são gerenciadas pela API REST. Essa configuração pode reduzir a sobrecarga de infraestrutura e ajudar a diminuir os bloqueios durante o scraping, mas os resultados dependem do comportamento e dos controles do site de destino.

## O que você recebe

- Sessões de navegador remotas para conexões com o Puppeteer.
- Renderização de JavaScript para páginas dinâmicas.
- Escalabilidade sem precisar manter sua própria infraestrutura de navegadores.
- Configuração de perfis e proxies gerenciada por API.
- Um único endpoint de conexão canônico para iniciar sessões.

## Fluxo de trabalho típico

1. Gere um token de API.
2. Opcionalmente, crie/configure um perfil (e um proxy) pela API REST.
3. Monte a URL de conexão com o `token` e, opcionalmente, um `profile`.
4. Conecte-se pelo Puppeteer/Playwright e execute a extração.
5. Armazene os resultados e encerre a sessão do navegador.

## Pré-requisitos

- Crie um token: no app Gologin, abra [API & MCP](https://app.gologin.com/personalArea/TokenApi) → **API** → **Novo Token**
- API de perfis (recomendada para configuração controlada): [Criar perfil](https://gologin.com/docs/api-reference/profile/create-profile-with-partial-parameters), [Atualizar perfil](https://gologin.com/docs/api-reference/profile/update-profile-with-partial-parameters)
- API de proxies: [Adicionar um proxy Gologin a um perfil](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy), [Definir seu próprio proxy nos perfis](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles)

## Um endpoint de conexão canônico

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${profileId}
```

- `token` é obrigatório.
- `profile` é opcional.
- Se `profile` for omitido, um novo perfil é criado para a sessão.

## Exemplo mínimo com Puppeteer

```javascript
const puppeteer = require('puppeteer-core');

(async () => {


  const token = 'your_token_here';
  const profileId = 'your_profile_id'; // Set to '' to create a new profile for this session
  const cloudBrowserUrl = `https://cloudbrowser.gologin.com/connect?token=${token}${profileId ? `&profile=${profileId}` : ''}`;
  const browser = await puppeteer.connect({
  
    browserWSEndpoint: cloudBrowserUrl,
    defaultViewport: null
  
  });

  const page = await browser.newPage();
  await page.goto('https://example.com');
  const title = await page.title();
  console.log('Page title:', title);
  await page.screenshot({ path: 'screenshot.png' });
  await browser.close();

})();
```

## Boas práticas

- Prefira esperas explícitas a pausas fixas.
- Implemente lógica de nova tentativa com backoff limitado e jitter.
- Armazene os dados extraídos de forma estruturada (URL, campos, data/hora, status).
- Configure o perfil/proxy antes da conexão para garantir reprodutibilidade.
- Sempre encerre as sessões e trate a limpeza em caso de falhas.
- Adapte o comportamento das requisições e sessões de acordo com as restrições de cada site de destino.

## Perguntas frequentes

### Preciso de um perfil?

Não. O parâmetro `profile` é opcional. Se for omitido, um novo perfil é criado para a sessão. Use um perfil quando precisar de uma configuração controlada e repetível.

### Onde configuro os proxies?

Configure os proxies pela API REST: [adicione um proxy Gologin a um perfil](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy) ou [defina seu próprio proxy nos perfis](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles).

### Isso é diferente do Cloud Browser?

Não. Esta é uma página sobre o uso do próprio Cloud Browser para scraping e extração de dados. O Cloud Browser cuida da conexão e da execução, enquanto as configurações de perfil e proxy são gerenciadas pela API REST.
