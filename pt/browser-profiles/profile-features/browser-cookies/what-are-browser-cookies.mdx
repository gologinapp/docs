---
title: "O que são cookies do navegador"
---

Os **Biscoitos** são pequenos arquivos de dados criados pelos sites e armazenados no seu navegador.

Os Biscoitos geralmente incluem:

- Tokens de sessão de login
- Autenticação "Lembrar de mim"
- Configurações de idioma e região
- Dados do carrinho de compras
- Identificadores de rastreamento
- Sinais de confiança antifraude

Ao trabalhar com várias contas, os Biscoitos costumam determinar se um site considera a sua sessão confiável ou suspeita.

## Como os Biscoitos funcionam no Gologin

Cada perfil do Gologin:

- Tem seu próprio armazenamento de Biscoitos isolado
- Não compartilha Biscoitos com outros perfis
- Sincroniza os Biscoitos com a nuvem quando o perfil é fechado corretamente
- Restaura os Biscoitos quando o perfil é iniciado novamente

Isso significa que cada perfil se comporta como um dispositivo físico separado, desde que você use proxies diferentes para cada perfil.

## Consistência entre proxy e fingerprint

Os Biscoitos, por si só, não garantem o acesso à conta.

Para importar Biscoitos com sucesso:

- Use o mesmo proxy ou um proxy geograficamente compatível
- Mantenha o fuso horário alinhado com o IP
- Evite grandes alterações no fingerprint
- Não misture Biscoitos de dispositivos móveis com fingerprints de desktop

Se o país do IP ou o fingerprint do dispositivo mudar drasticamente, os sites podem invalidar a sessão.

## Boas práticas

- Sempre feche os perfis corretamente para sincronizar os Biscoitos
- Mantenha a geografia do proxy consistente
- Exporte os Biscoitos antes de fazer alterações importantes
- Teste as importações primeiro em contas não críticas
- Evite trocar Biscoitos com frequência em contas já estabelecidas
