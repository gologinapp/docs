---
title: "Visão geral das extensões do navegador"
---

As extensões dentro de um perfil do Gologin permitem personalizar cada ambiente de navegador individualmente. Como cada perfil no Gologin funciona como um navegador separado, com seu próprio fingerprint e armazenamento, as extensões são instaladas e gerenciadas **por perfil**, e não de forma global. Isso dá a você controle total sobre quais ferramentas são executadas no ambiente de cada conta.

## O que são extensões de perfil?

**Extensões de perfil** são extensões de navegador **compatíveis com Chrome** que você instala **diretamente em um perfil específico do Gologin**.

Cada perfil:

- Tem sua própria lista de extensões
- Armazena os dados das extensões separadamente
- Mantém as configurações das extensões isoladas
- Não compartilha extensões com outros perfis

Isso significa que você pode usar configurações diferentes para contas diferentes, sem sobreposição.

## Por que usar extensões nos perfis do Gologin?

As extensões costumam ser essenciais para:

- Ferramentas de automação
- Gerenciamento de cookies
- Verificação de anúncios
- Auxílio em web scraping
- Fluxos de trabalho de produtividade

Como os perfis são isolados, você pode usar ferramentas diferentes em cada conta com segurança, sem contaminação cruzada de dados.

## Extensões e estabilidade do fingerprint

As extensões podem afetar o comportamento do navegador.

Algumas extensões:

- Modificam cabeçalhos de requisição
- Injetam scripts
- Interagem com o WebRTC
- Alteram o comportamento do canvas

Se você trabalha com plataformas sensíveis (anúncios, e-commerce, cripto), teste novas extensões com cuidado antes de usá-las em contas já aquecidas.

## Boas práticas

- Evite instalar extensões desnecessárias
- Use extensões consistentes para cada tipo de conta
- Não adicione nem remova extensões com frequência em perfis já estabelecidos. Mudanças bruscas na configuração das extensões podem parecer suspeitas em plataformas de alta segurança.
