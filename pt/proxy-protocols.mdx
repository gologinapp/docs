---
title: "Protocolos de proxy"
---

Tanto os protocolos HTTP/HTTPS quanto o SOCKS funcionam na maioria dos sites, mas, para sites com medidas avançadas contra bots, os proxies SOCKS5 com suporte a UDP costumam ser preferidos por sua versatilidade.

O Gologin é compatível com os protocolos de proxy mais comuns.

### HTTP / HTTPS

- Os proxies HTTP são amplamente usados para o tráfego web padrão.
- Os proxies HTTPS oferecem suporte a conexões criptografadas por SSL/TLS e são comumente usados para uma navegação segura.

### SOCKS4 / SOCKS5

- Os proxies SOCKS oferecem suporte a uma variedade maior de protocolos de rede.
- O SOCKS5 é a opção mais flexível e oferece suporte a conexões TCP e UDP.
- Por isso, os proxies SOCKS5 costumam ser preferidos para tarefas de automação e scraping.
