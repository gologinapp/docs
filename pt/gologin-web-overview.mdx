O Gologin está disponível não apenas como aplicativo para desktop, mas também como aplicativo web em [app.gologin.com](http://app.gologin.com). Você pode entrar nele com a sua conta do Gologin e gerenciar seus perfis de qualquer navegador, em qualquer dispositivo, sem precisar instalar nada.

### Cloud Browser

Para entender como o aplicativo web funciona, é útil conhecer o Cloud Browser.

Quando você executa um perfil no aplicativo para desktop, ele abre no seu dispositivo e usa os recursos dele, como memória RAM, CPU e assim por diante. O número de perfis que você pode executar ao mesmo tempo é limitado pelo seu hardware.

O Cloud Browser funciona de maneira diferente. Em vez de rodar no seu dispositivo, o perfil é executado nos servidores do Gologin. Você o visualiza e interage com ele pelo seu navegador habitual. Isso significa que os recursos do seu dispositivo não são usados, você pode executar perfis de qualquer lugar e o número de perfis que pode executar não é limitado pelo seu hardware.

Cada perfil do Cloud Browser tem a própria impressão digital do navegador e o próprio endereço IP, assim como os perfis no aplicativo para desktop.

### O que você pode fazer no aplicativo web

O aplicativo web em [app.gologin.com](http://app.gologin.com) oferece as mesmas funcionalidades principais do aplicativo para desktop. Você pode criar e gerenciar perfis, executar perfis do Cloud Browser e acessar as configurações da sua conta, tudo a partir de uma aba comum do navegador.

Isso é útil quando você não está com o seu computador habitual ou quando quer acessar seus perfis em um dispositivo no qual o aplicativo para desktop não está instalado.
