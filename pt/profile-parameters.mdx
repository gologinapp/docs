---
title: "Configurações do perfil"
---

Cada perfil de navegador no Gologin tem seu próprio conjunto de configurações, que definem como ele aparece para os sites. Essas configurações são organizadas em abas na parte superior do editor de perfil.

Você pode acessar as configurações do perfil clicando em **3 pontos no perfil** \> **Configurações**.

## Visão geral

Nesta aba, você define o sistema operacional em que o perfil parecerá estar sendo executado e gera a impressão digital principal dele.

**Sistema operacional** - Escolha entre Windows 10, Windows 11, Mac Intel, Mac ARM, Linux e Android. Isso determina o sistema operacional que o perfil informa a todos os sites que ele visita.

<Warning>
  O sistema operacional só pode ser selecionado ao criar um perfil. Depois que o perfil é salvo, essa opção fica bloqueada e não pode ser alterada. Se você precisar de um sistema operacional diferente, crie um novo perfil.
</Warning>

**Nova impressão digital** - Ao clicar aqui, é gerado um novo conjunto de valores de impressão digital para o perfil, como resolução de tela, fontes, detalhes de gráficos e outros sinais que os sites usam para identificar navegadores. Use essa opção se quiser redefinir a identidade do perfil. Ela não altera o sistema operacional nem apaga cookies ou outros dados do navegador.

O painel **Resumo do Perfil**, à direita, é atualizado conforme você faz alterações e oferece uma visão rápida da impressão digital atual do perfil.

## Proxy

Esta aba controla qual proxy o perfil usa ao navegar.

- **Proxy Gologin** - Use um proxy do serviço de proxy integrado do Gologin.
- **Seu proxy** - Cole o seu próprio proxy de um provedor externo.
- **Sem proxy** - O perfil usa sua conexão real com a internet. O endereço IP visível para os sites será o seu IP verdadeiro.

<Frame>
  ![Configurações — Proxy](/images/settings_proxy.png)
</Frame>

O proxy que você atribui aqui determina o endereço IP que os sites veem quando este perfil está em execução. Ele também afeta o fuso horário e a geolocalização, caso estejam configurados para seguir o IP automaticamente.

## Fuso horário

Esta aba define o fuso horário que o perfil informa aos sites.

Por padrão, a opção **Preencha o fuso horário com base no IP externo** vem ativada, o que significa que o perfil usa automaticamente o fuso horário correspondente à localização do proxy. Isso mantém o perfil consistente: um perfil com proxy dos EUA informará um fuso horário dos EUA, que é o que um usuário real nesse local teria. Para fazer um perfil parecer de um país específico, adicione um proxy desse país e mantenha o fuso horário e a geolocalização baseados no IP. O Gologin os ajusta automaticamente à localização do proxy.

<Note>
  Recomendamos deixar essa opção no automático e não alterá-la manualmente. Se o fuso horário não corresponder à localização do proxy, isso pode parecer suspeito para os sites. Só altere se tiver um motivo específico.
</Note>

## Extensões

Nesta aba, você instala extensões de navegador no perfil. Cada perfil gerencia suas próprias extensões separadamente: adicionar uma aqui não afeta nenhum outro perfil.

Clique em **Adicionar extensões** para procurar e instalar extensões neste perfil.

Para um passo a passo completo de como as extensões funcionam nos perfis do Gologin, consulte [Extensões](/pt/browser-profiles/profile-features/browser-extensions/browser-extensions).

  ![Configurações — Extensões](/images/settings_extensions.png)

## Favoritos

Nesta aba, você pode adicionar favoritos à barra de favoritos do perfil. Cole-os no campo de texto usando um destes formatos:

- `folder::name::url` - cria um favorito dentro de uma pasta com nome
- `name::url` - cria um favorito com nome diretamente na barra
- `url` - adiciona a URL diretamente, sem nome personalizado

Cada linha é um favorito separado. Eles aparecem na barra de favoritos dentro do Orbita quando o perfil está em execução.

## Geolocalização

Esta aba controla o que acontece quando um site solicita a sua localização, por exemplo, um aplicativo de mapas perguntando "Permitir que este site saiba sua localização?"

Há três opções:

- **Pronto** - O navegador pergunta a cada vez que um site solicita acesso à localização. Este é o padrão e imita o comportamento de um navegador real.
- **Permitir** - O acesso à localização é concedido automaticamente a qualquer site que o solicitar.
- **Bloquear** - Todas as solicitações de localização são negadas silenciosamente.

A opção **Preencher geolocalização com base no IP externo** vem ativada por padrão. Quando ativada, o Gologin define as coordenadas informadas pelo perfil para corresponder à localização do proxy automaticamente.

<Note>
  Recomendamos manter essa opção ativada. Se você a desativar e a geolocalização não corresponder ao IP do proxy, a divergência pode servir de sinal para sistemas de detecção. Só ajuste isso manualmente se você souber quais coordenadas quer usar e por quê.
</Note>
