---
title: "Checklist para iniciantes"
---

Antes de criar seus primeiros perfis de navegador no Gologin, é recomendável preparar seu ambiente. Isso ajuda a evitar problemas com as contas e garante que os perfis funcionem corretamente.

Use este checklist para começar.

### 1. Instale o Gologin

Baixe e instale o aplicativo Gologin para o seu sistema operacional.

### 2. Faça login na sua conta do Gologin

Entre com a conta que você criou durante o cadastro.

### 3. Prepare os proxies

Verifique se você já tem proxies prontos para usar.<br />Usar um proxy separado para cada perfil ajuda a evitar que as contas sejam vinculadas entre si.

### 4. Crie seu primeiro perfil de navegador

Crie um perfil para simular um ambiente de navegador separado, com sua própria impressão digital (fingerprint) e seu próprio armazenamento.

### 5. Atribua um proxy ao perfil

Adicione um proxy para que o perfil se conecte a partir de um endereço IP exclusivo.

### 6. Inicie o perfil

Clique em **Executar** para iniciar o perfil e começar a trabalhar com suas contas.
