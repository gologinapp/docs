Você pode baixar o app Gologin para qualquer sistema compatível usando o link abaixo:

👉 [**Baixar o Gologin**](https://gologin.com/download/)

## Requisitos de hardware

- **RAM:** mínimo de 4GB
- **Espaço livre em disco:** pelo menos 1 GB

## Sistemas operacionais compatíveis

### **Windows**

- Windows 11
- Windows 10
- Windows Server 2016

### Mac OS (chips da série M, Mac Neo e Intel)

- macOS 27 Golden Gate
- macOS 26 Tahoe
- macOS 15 Sequoia (versão do navegador 122 ou superior)
- macOS 14 Sonoma
- macOS 13 Ventura
- macOS 12 Monterey (versão do navegador 150 ou inferior)

### Linux

- Ubuntu
- Mint

### Android

- Android 10.0 ou superior
- 3\+ GB de RAM

### iOS

- iPhone ou iPad com iOS 17 ou superior

## Processo de instalação

### Windows

1. Baixe o instalador do app [aqui](https://gologin.com/download/)
2. Acesse a pasta **Downloads**
3. Clique duas vezes no arquivo baixado e siga as instruções de instalação

### Mac OS

1. Baixe o instalador do app [aqui](https://gologin.com/download/)
2. Acesse a pasta **Downloads**
3. Clique duas vezes no arquivo e siga as instruções

### Linux, exemplo com Ubuntu

O Gologin para Linux é fornecido como um arquivo `.tar`. O app que está dentro dele é autônomo e não exige uma instalação tradicional: basta extrair o arquivo e abrir o Gologin a partir da pasta extraída.

1. Baixe o arquivo usando este [link](https://gologin.com/download)
2. Acesse a pasta **Downloads**
3. Clique com o botão direito em `gologin.tar` \> **Extrair**
4. Vá até a pasta **gologin** \> abra o Gologin com um clique duplo

**Se o app não abrir**

- se o seu sistema reconhecer o app como um arquivo de texto, abra-o uma vez pelo terminal com o parâmetro --no-sandbox
  ```bash bash
  cd ~/Downloads/gologin
  ./<filename> --no-sandbox
  ```
- talvez seja necessário tornar o arquivo executável. Cole o seguinte no terminal:
  ```bash bash
  cd ~/Downloads/gologin
  chmod +x <filename>
  ```
  substitua `<filename>` pelo nome real do arquivo
- em sistemas mais recentes, pode ser necessário o pacote **libfuse2**. Cole o seguinte no terminal e tente abrir o app novamente.
  ```bash bash
    sudo apt install libfuse2
  ```

**Se os perfis não iniciarem ao clicar em Executar**

- abra o Terminal e acesse a pasta do navegador, por exemplo, a versão Orbita 145
- defina novas permissões para o **chrome-sandbox**
  ```bash bash
  cd ~/.gologin/browser/orbita-browser-145
  sudo chown root:root chrome-sandbox
  sudo chmod 4755 chrome-sandbox
  ```

### Android

Para usar o Gologin no Android, basta instalar o **app Gologin** pela **Google Play Store**.

1. Abra a **Google Play Store** no seu celular
2. Localize a barra de pesquisa no topo e digite **Gologin** \> **instale o app**

Depois de instalado, você pode usá-lo imediatamente, com o navegador já integrado.

## Configurações não compatíveis

O Gologin **não** é compatível com as seguintes plataformas:

- Qualquer sistema de 32 bits
- Windows 7, 8, 8.1, Server 2012 (qualquer revisão) ou anteriores
- macOS El Capitan, Sierra, High Sierra, Mojave, Catalina, Big Sur ou anteriores
- Chrome OS (você pode usar a versão [Gologin web](/pt/gologin-web-overview))
