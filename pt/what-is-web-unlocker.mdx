---
title: "O que é o Web Unlocker?"
---

O Web Unlocker é uma API de scraping universal. Envie qualquer URL e receba o HTML totalmente renderizado ou a página em Markdown ou JSON, sem precisar gerenciar navegadores ou proxies.

Ele substitui a parte de navegador e proxy da sua stack de scraping: renderização, gerenciamento de proxies e fingerprints de navegador são tratados em uma única chamada de API. Páginas estáticas e sites com muito JavaScript usam o mesmo endpoint.

---

## O que ele resolve

Os sites modernos são difíceis de raspar. Uma chamada simples com `curl` ou `requests` muitas vezes retorna uma resposta em branco ou um HTML quebrado, porque o conteúdo é carregado por JavaScript. O Web Unlocker cuida de:

- **Renderização de JavaScript** — as páginas são carregadas em um navegador real e totalmente executadas antes de o conteúdo ser capturado
- **Rotação inteligente de IPs** — as requisições passam por IPs residenciais com fingerprints de navegador realistas
- **Direcionamento por faixa de preço** — as requisições são encaminhadas pela faixa de proxy adequada ao site de destino

---

## O que você recebe

Uma requisição bem-sucedida retorna a página em um único formato. Escolha o formato com o parâmetro de consulta `format`:

| `format` | O que você recebe |
| --- | --- |
| `html` (padrão) | O DOM completo e renderizado da página |
| `markdown` | O conteúdo da página em Markdown |
| `json` | Um objeto JSON com a URL da página, os metadados da requisição e o HTML |

## Web Unlocker vs. proxies gerenciados por você

Manter sua própria infraestrutura de proxies é caro e frágil. O Web Unlocker cuida de tudo como um serviço gerenciado:

|  | Web Unlocker | Proxies próprios |
| --- | --- | --- |
| Configuração | Uma chamada de API | Semanas de trabalho de infraestrutura |
| Fingerprint de navegador | Incluído | Desenvolver ou comprar separadamente |
| Rotação de IPs | Automática | Gerenciamento manual do pool |
| Manutenção | Nenhuma | Contínua |
| Cobrança | Por requisição bem-sucedida | Custo fixo, independentemente do sucesso |

## Como funciona

O Web Unlocker executa um navegador Chromium real na nuvem para cada tarefa. Quando você envia uma URL:

1. Um navegador é iniciado com um IP residencial e um fingerprint de navegador realista
2. A página é acessada, o JavaScript é executado e o conteúdo dinâmico é carregado
3. O HTML renderizado é retornado, ou Markdown ou JSON, se você solicitar com `format`

Você nunca gerencia infraestrutura. Não há navegadores para iniciar, listas de proxies para manter nem lógica de renderização para criar. O Web Unlocker substitui um framework de automação de navegador e um provedor de proxies por uma única requisição HTTP.

## Como usar

Envie uma requisição GET com a URL de destino como parâmetro de consulta. A resposta é o HTML totalmente renderizado.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Para receber Markdown ou JSON, adicione `format=markdown` ou `format=json` à consulta.

Consulte o [Quickstart](/pt/web-unlocker-quick-start) para ver exemplos em Python e JavaScript e os [códigos de erro](/pt/web-unlocker-quick-start#tratamento-de-erros), ou [Casos de uso](/pt/web-unlocker-use-cases) para padrões comuns de integração.
