title: "O que é o Web Unlocker?"
---

O Web Unlocker é uma API de scraping universal. Envie qualquer URL e receba o HTML totalmente renderizado ou a página em Markdown ou JSON — sem infraestrutura para gerenciar, sem bloqueios e sem requisições com falha.

Ele funciona como substituto completo da sua stack de scraping: automação de navegador, gerenciamento de proxies, fingerprinting e resolução de CAPTCHA, tudo em uma única chamada de API. Seja uma página estática simples ou um site com renderização em JavaScript e proteção pesada, o mesmo endpoint cuida de tudo.

---

## O que ele resolve

Sites modernos são difíceis de extrair dados. Uma chamada simples com `curl` ou `requests` muitas vezes retorna uma página de desafio, uma resposta em branco ou um HTML quebrado, porque o conteúdo é carregado por JavaScript. O Web Unlocker resolve tudo isso automaticamente:

- **Renderização de JavaScript** — as páginas são carregadas em um navegador real e totalmente executadas antes de o conteúdo ser capturado
- **Bypass de anti-bot** — proteções como Cloudflare, DataDome, PerimeterX e similares são tratadas automaticamente
- **Rotação inteligente de IPs** — as requisições passam por IPs residenciais limpos, com fingerprints de navegador realistas
- **Resolução de CAPTCHA** — os desafios de CAPTCHA mais comuns são resolvidos sem intervenção manual
- **Seleção por faixa de preço** — as requisições são roteadas pela faixa de proxy adequada ao site de destino

## O que você recebe

Uma requisição bem-sucedida retorna a página em um único formato. Escolha o formato com o parâmetro de consulta `format`:

| `format` | O que você recebe |
| --- | --- |
| `html` (padrão) | O DOM renderizado completo da página |
| `markdown` | O conteúdo da página em Markdown |
| `json` | Um objeto JSON com a URL da página, os metadados da requisição e o HTML |

## Web Unlocker vs. proxies gerenciados por você

Manter sua própria infraestrutura de proxies é caro e frágil. O Web Unlocker cuida de tudo como um serviço gerenciado:

|  | Web Unlocker | Proxies gerenciados por você |
| --- | --- | --- |
| Configuração | Uma chamada de API | Semanas de trabalho de infraestrutura |
| Resolução de CAPTCHA | Integrada | Desenvolver ou contratar à parte |
| Fingerprinting de navegador | Integrado | Desenvolver ou contratar à parte |
| Rotação de IPs | Automática | Gerenciamento manual do pool |
| Manutenção | Nenhuma | Contínua |
| Cobrança | Por requisição bem-sucedida | Custo fixo, independentemente do sucesso |

## Como funciona

O Web Unlocker executa um navegador Chromium real na nuvem para cada tarefa. Quando você envia uma URL:

1. Um navegador é iniciado com um IP residencial e um fingerprint de navegador realista
2. A página é acessada, o JavaScript é executado e o conteúdo dinâmico é carregado
3. Os desafios anti-bot e os CAPTCHAs são tratados automaticamente
4. O HTML renderizado é retornado, ou Markdown ou JSON, se você solicitar com `format`

Você nunca precisa gerenciar infraestrutura. Não há navegadores para iniciar, listas de proxies para manter nem lógica de bypass para desenvolver. O Web Unlocker substitui na prática uma stack de scraping inteira — framework de automação de navegador, provedor de proxies e solução anti-bot — por uma única requisição HTTP.

## Como usar

Envie uma requisição GET com a URL de destino como parâmetro de consulta. A resposta é o HTML totalmente renderizado.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Para receber Markdown ou JSON, adicione `format=markdown` ou `format=json` à consulta.

Veja o [Início rápido](/pt/web-unlocker-quick-start) para exemplos em Python e JavaScript e para os [códigos de erro](/pt/web-unlocker-quick-start#tratamento-de-erros), ou os [Casos de uso](/pt/web-unlocker-use-cases) para padrões de integração comuns.
