## Ativando um código promocional

Se você ainda não tem uma assinatura, pode usar um código de cupom antes da primeira compra.

Para ativá-lo:

1. Acesse as **configurações principais no canto superior esquerdo** \> **Definições e membros**
2. Vá até a aba **Planos de faturamento**
3. Na seção **Cupom**, insira o código promocional e clique em **Aplicar**
4. Agora você pode escolher o plano de assinatura clicando em **Alterar Plano**. O código promocional será aplicado no checkout.

## Quando o código promocional pode ser ativado

O código de cupom só pode ser ativado se a conta não tiver nenhuma assinatura adquirida anteriormente, e está disponível apenas para a **primeira assinatura mensal**.

**Não há códigos promocionais para a assinatura anual**, pois ela já oferece automaticamente 50% de desconto.

Os códigos promocionais funcionam com todos os [métodos de pagamento](/pt/general/account-and-billing/payment-methods) disponíveis, **exceto PayPal**.

Os códigos promocionais não podem ser usados nos seguintes casos:

- se o código promocional for inválido ou estiver expirado
- se você já usou um código promocional anteriormente
- se você já teve uma assinatura antes
- se você estiver tentando comprar uma assinatura anual
- se você estiver tentando pagar com PayPal

## Onde conseguir um código

Códigos promocionais podem ser encontrados em vários lugares na internet. Recomendamos fazer uma busca online. Lembre-se de que nossa equipe de suporte não tem códigos promocionais disponíveis, então não é preciso insistir com nossos atendentes para conseguir um :)
