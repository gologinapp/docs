## Ativando um código promocional

Se você ainda não tem uma assinatura, pode usar um código de cupom antes da primeira compra.

Para ativá-lo:

1. Acesse as **configurações principais no canto superior esquerdo** \> **Definições e membros**
2. Vá para a aba **Planos de faturamento**
3. Na seção **Cupom**, insira o código promocional e clique em **Aplicar**
4. Agora você pode escolher seu plano de assinatura clicando em **Alterar Plano**. O código promocional será aplicado no checkout.

## Quando o código promocional pode ser ativado

O código de cupom pode ser ativado se você não tiver nenhuma assinatura comprada anteriormente na conta. Ele está disponível apenas para a **primeira assinatura mensal**.

**Não há códigos promocionais para a assinatura anual**, pois ela já oferece 50% de desconto automaticamente.

Os códigos promocionais funcionam com todos os [métodos de pagamento](/pt/general/account-and-billing/payment-methods) disponíveis, **exceto PayPal**.

Os códigos promocionais não podem ser usados nos seguintes casos:

- se o código promocional for inválido ou estiver expirado
- se você já usou um código promocional antes
- se você já assinou antes
- se você está tentando comprar uma assinatura anual
- se você está tentando pagar com PayPal

## Onde conseguir um código

Os códigos promocionais podem ser encontrados em vários lugares na internet. Recomendamos fazer uma busca online. Lembre-se de que nossa equipe de suporte não tem códigos promocionais disponíveis, então não é necessário pressionar nossos atendentes por isso :)
