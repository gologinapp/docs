## **Por que isso acontece e como funciona?**

Sites diferentes usam vários bancos de dados de geolocalização de IP para determinar o país de um endereço IP. Esses bancos de dados não são sincronizados entre si, o que leva a situações em que o mesmo IP é detectado como pertencente a vários locais diferentes.

Outro fator importante é se o IP está marcado como pertencente a um Datacenter / VPN / qualquer outro serviço.<br />Se um IP for reconhecido como serviço, a pontuação de confiança dele pode cair drasticamente, o que aumenta a chance de ele ser sinalizado ou bloqueado pelos sites.

Não recomendamos usar proxies com as discrepâncias listadas acima.

## **Como o Gologin determina a localização do proxy**

A verificação de proxy do Gologin usa um banco de dados GeoIP de terceiros. Quando esse banco de dados é atualizado, o país exibido para um IP pode mudar. Para proxies novos, os dados de localização nos bancos de dados GeoIP podem ainda não ter sido atualizados, então o país pode ser diferente do que você comprou - consulte o seu provedor de proxy. Não é possível alterar o banco de dados usado pelo Gologin; se um site exigir um país específico, use um proxy que seja detectado de forma consistente como sendo desse país.

## **Como evitar problemas com proxies**

Para minimizar os problemas causados por localizações incorretas de proxy:

- **Use provedores de proxy confiáveis** – Provedores de alta qualidade garantem que seus IPs sejam categorizados e registrados corretamente. Você pode usar os proxies do Gologin ou [<u>os proxies que recomendamos</u>](https://gologin.com/proxies/proxy-type/).
- **Evite proxies de datacenter em tarefas sensíveis** – Proxies residenciais ou móveis geralmente têm pontuações de confiança mais altas.
- **Teste o seu proxy antes de usá-lo** – Verifique-o em vários verificadores de IP para garantir a consistência.
- **Troque de IP, se necessário** – Se um IP específico for sinalizado incorretamente, mudar para outro IP pode resolver o problema.
