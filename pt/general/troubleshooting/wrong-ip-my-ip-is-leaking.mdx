---
title: "IP errado: meu IP real está vazando ao usar um proxy"
description: "Quando o seu IP real está vazando ao usar o navegador Gologin com um proxy"
---

O único motivo conhecido para o vazamento de IP é o **NordVPN** estar em execução com o recurso **Threat Protection** (Proteção contra Ameaças) ativado.\
﻿O recurso Threat Protection tem prioridade mais alta no sistema e faz com que todos os navegadores (inclusive os seus navegadores comuns) usem o IP da NordVPN. Ele continua funcionando mesmo que a conexão VPN esteja desativada.

Se você quer continuar trabalhando no Gologin com um proxy, **desative o Threat Protection** para que o IP correto do proxy seja exibido.
