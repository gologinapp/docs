O Web Unlocker é uma Scraping API: você envia uma URL e ele retorna o HTML totalmente renderizado. Esta página mostra as formas mais comuns de usá-lo.

---

## Faça scraping de uma página por conta própria

O caso de uso mais simples: você precisa do conteúdo de uma página da web que bloqueia requisições HTTP comuns.

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com/product/123"},
    headers={"apikey": "YOUR_API_KEY"}
)

html = response.text
print(html)
```

### JavaScript

```javascript
const html = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com/product/123"),
  { headers: { apikey: "YOUR_API_KEY" } }
).then((r) => r.text());

console.log(html);
```

Sem navegador para iniciar, sem proxy para configurar, sem precisar lutar contra o Cloudflare. Com uma única chamada, você recebe a página.

**Ideal para:**

- Verificar preços no site de um concorrente
- Coletar vagas de emprego, avaliações ou dados de produtos
- Monitorar alterações em páginas
- Scripts pontuais de coleta de dados

## Envie conteúdo para uma IA

O Web Unlocker retorna HTML bruto. Passe esse HTML para um LLM para extrair dados estruturados, resumir conteúdo ou responder perguntas sobre a página, sem necessidade de lógica de parsing.

### Python \+ OpenAI

```python
import requests
from openai import OpenAI

html = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://news.ycombinator.com"},
    headers={"apikey": "YOUR_API_KEY"}
).text

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {
            "role": "user",
            "content": f"Extract the top 5 story titles and their URLs from this HTML:\n\n{html[:8000]}"
        }
    ]
)

print(response.choices[0].message.content)
```

### JavaScript \+ Anthropic

```javascript
import Anthropic from "@anthropic-ai/sdk";

const html = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://news.ycombinator.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
).then((r) => r.text());

const client = new Anthropic();
const message = await client.messages.create({
  model: "claude-opus-4-5",
  max_tokens: 1024,
  messages: [
    {
      role: "user",
      content: `Extract the top 5 story titles and their URLs from this HTML:\n\n${html.slice(0, 8000)}`,
    },
  ],
});

console.log(message.content[0].text);
```

**Ideal para:**

- Extrair dados estruturados (preços, nomes, datas) sem escrever parsers
- Resumir artigos ou páginas de produtos
- Comparar várias páginas e tirar conclusões
- Criar ferramentas de pesquisa ou monitoramento com tecnologia de IA

## Use dentro de um agente de IA

Dê ao seu agente de IA uma ferramenta `scrape` baseada no Web Unlocker. Assim, o agente pode navegar na web por conta própria, buscando páginas, lendo o conteúdo e tomando ações, sem que você precise escrever nenhuma lógica de navegação.

```python
import requests
import anthropic

def scrape(url: str) -> str:
    """Fetch a URL and return its rendered HTML."""
    return requests.get(
        "https://parsing.webunlocker.gologin.com/v1/scrape",
        params={"url": url},
        headers={"apikey": "YOUR_API_KEY"}
    ).text

tools = [
    {
        "name": "scrape",
        "description": "Fetch the rendered HTML of any URL, including JavaScript-heavy and protected sites.",
        "input_schema": {
            "type": "object",
            "properties": {
                "url": {"type": "string", "description": "The URL to scrape"}
            },
            "required": ["url"]
        }
    }
]

client = anthropic.Anthropic()
messages = [
    {"role": "user", "content": "What is the current price of the iPhone 16 Pro on apple.com?"}
]

while True:
    response = client.messages.create(
        model="claude-opus-4-5",
        max_tokens=1024,
        tools=tools,
        messages=messages
    )

    if response.stop_reason == "end_turn":
        print(response.content[0].text)
        break

    tool_results = []
    for block in response.content:
        if block.type == "tool_use" and block.name == "scrape":
            html = scrape(block.input["url"])
            tool_results.append({
                "type": "tool_result",
                "tool_use_id": block.id,
                "content": html[:10000]
            })

    messages.append({"role": "assistant", "content": response.content})
    messages.append({"role": "user", "content": tool_results})
```

O agente decide quando fazer scraping e qual URL buscar. O Web Unlocker cuida da obtenção em si.

**Ideal para:**

- Agentes de pesquisa que navegam na web de forma autônoma
- Bots de comparação de preços ou de busca de ofertas
- Pipelines de inteligência competitiva
- Qualquer agente que precise de dados da web em tempo real

## Faça scraping de várias páginas de uma vez

Execute requisições de forma concorrente para coletar dados de várias URLs em paralelo.

```python
import requests
from concurrent.futures import ThreadPoolExecutor

API_URL = "https://parsing.webunlocker.gologin.com/v1/scrape"
API_KEY = "YOUR_API_KEY"

urls = [
    "https://example.com/page/1",
    "https://example.com/page/2",
    "https://example.com/page/3",
]

def scrape(url):
    response = requests.get(
        API_URL,
        params={"url": url},
        headers={"apikey": API_KEY}
    )
    return url, response.text

with ThreadPoolExecutor(max_workers=5) as executor:
    results = list(executor.map(scrape, urls))

for url, html in results:
    print(f"{url}: {len(html)} chars")
```

**Ideal para:**

- Fazer scraping de catálogos de produtos completos ou páginas de listagem
- Coleta de dados em massa para conjuntos de dados de treinamento
- Monitorar muitas páginas simultaneamente

## Use pela CLI

Dispense a escrita de código: use a CLI Gologin Web Access para fluxos de scraping comuns:

```bash
npm install -g gologin-web-access
export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."

# batch scrape multiple pages
gologin-web-access batch-scrape \
  https://example.com/page/1 \
  https://example.com/page/2 \
  https://example.com/page/3 \
  --format text --only-main-content --summary

# crawl a site
gologin-web-access crawl https://docs.example.com --format markdown --limit 50 --max-depth 2

# monitor page changes
gologin-web-access change-track https://example.com/pricing --format markdown

# extract structured data with a schema
gologin-web-access extract https://example.com/product/123 --schema ./product-schema.json

# search the web
gologin-web-access search "best antidetect browser 2026" --limit 10
```

Consulte [Web Access CLI](/pt/cli-tools/web-access) para ver a referência completa de comandos.
