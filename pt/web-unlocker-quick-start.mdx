Este guia mostra como extrair (fazer scraping) da sua primeira URL usando o Web Unlocker.

---

## Pré-requisitos

- Uma chave de API do Web Unlocker. Obtenha uma pelo formulário na [página do Web Unlocker](https://gologin.com/web-unlocker/#web_unlocker_form). A chave chega em até um dia útil, com requisições gratuitas para você testar nos seus próprios alvos. Não é necessário cartão.
- Python 3.x, Node.js ou qualquer cliente HTTP

---

## Autenticação

Todas as requisições exigem a sua chave de API no cabeçalho `apikey`:

```
apikey: YOUR_API_KEY
```

A URL base para todas as requisições à API é:

```
https://parsing.webunlocker.gologin.com/v1
```

---

## Faça sua primeira requisição

Envie uma requisição GET com a URL de destino como parâmetro de consulta. A resposta é o HTML da página totalmente renderizado.

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.text)
```

### JavaScript (Node.js / Browser)

```javascript
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(html);
```

---

## O que você recebe de volta

O corpo da resposta é o HTML bruto renderizado da página, o mesmo conteúdo que você veria ao abrir a URL em um navegador. Não há wrapper JSON nem necessidade de parsing.

```html
<!DOCTYPE html>
<html>
  <head><title>Example Domain</title></head>
  <body>...</body>
</html>
```

### Outros formatos

Adicione o parâmetro de consulta `format` para receber a página em outro formato:

| `format` | Corpo da resposta |
|---|---|
| `html` | HTML da página (o padrão) |
| `markdown` | Conteúdo da página em Markdown |
| `json` | Objeto JSON com a URL, os metadados da requisição e o HTML da página |

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com&format=json" \
  -H "apikey: YOUR_API_KEY"
```

```json
{
  "success": true,
  "data": {
    "url": "https://example.com",
    "metadata": {
      "response_time_ms": 297,
      "status_code": 200
    },
    "html": "<!DOCTYPE html><html lang=\"en\">..."
  }
}
```

---

## Tratamento de erros

Verifique o código de status HTTP antes de processar a resposta:

| Status | Significado | Corpo da resposta |
|---|---|---|
| `200` | Sucesso | A página no formato solicitado |
| `400` | Requisição inválida, por exemplo, quando o parâmetro `url` está ausente | `{"success":false,"error":"Request failed"}` |
| `401` | O cabeçalho `apikey` está ausente | `{"message":"Missing API key in request"}` |

Se você receber `429` ou um status `5xx`, tente novamente com backoff exponencial.

```python
response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

if response.status_code == 200:
    html = response.text
else:
    print(f"Error {response.status_code}: {response.text}")
```

## Início rápido com a CLI

Você também pode extrair páginas usando as ferramentas de CLI da Gologin, sem escrever código:

### CLI do Web Unlocker

```bash
npm install -g gologin-webunlocker

GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker scrape https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker markdown https://example.com
```

### CLI Gologin Web Access (unificada)

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."
gologin-web-access read https://example.com
gologin-web-access scrape-json https://example.com
gologin-web-access batch-scrape https://example.com/page/1 https://example.com/page/2 --format text
```

Veja o [SDK e a CLI do Web Unlocker](/pt/scraping-api-sdk-and-cli) e a [CLI do Web Access](/pt/cli-tools/web-access) para mais detalhes.
