Este guia mostra como fazer o scraping da sua primeira URL usando o Web Unlocker.

---

## Pré-requisitos

- Uma chave de API do Web Unlocker (entre em contato com **ermakova.t@gologin.com** para obter uma)
- Python 3.x, Node.js ou qualquer cliente HTTP

---

## Autenticação

Todas as requisições exigem sua chave de API no cabeçalho `apikey`:

```
apikey: YOUR_API_KEY
```

A URL base para todas as requisições da API é:

```
https://parsing.webunlocker.gologin.com/v1
```

---

## Faça sua primeira requisição

Envie uma requisição GET com a URL de destino como parâmetro de consulta. A resposta é o HTML da página totalmente renderizado.

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.text)
```

### JavaScript (Node.js / Browser)

```javascript
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(html);
```

---

## O que você recebe de volta

O corpo da resposta é o HTML bruto renderizado da página, o mesmo conteúdo que você veria ao abrir a URL em um navegador. Não há wrapper JSON nem necessidade de parsing.

```html
<!DOCTYPE html>
<html>
  <head><title>Example Domain</title></head>
  <body>...</body>
</html>
```

---

## Tratamento de erros

Verifique o código de status HTTP antes de processar a resposta:

| Status | Significado |
|---|---|
| `200` | Sucesso — o corpo da resposta é o HTML da página |
| `401` | Chave de API inválida ou ausente |
| `422` | Parâmetro de URL inválido ou ausente |
| `429` | Limite de requisições excedido |
| `500` / `503` | Erro do servidor — tente novamente com backoff |

```python
response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

if response.status_code == 200:
    html = response.text
else:
    print(f"Error {response.status_code}: {response.text}")
```

## Início rápido com a CLI

Você também pode fazer scraping de páginas usando as ferramentas de CLI da Gologin, sem escrever código:

### CLI do Web Unlocker

```bash
npm install -g gologin-webunlocker

GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker scrape https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker markdown https://example.com
```

### CLI Gologin Web Access (unificada)

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."
gologin-web-access read https://example.com
gologin-web-access scrape-json https://example.com
gologin-web-access batch-scrape https://example.com/page/1 https://example.com/page/2 --format text
```

Consulte [Web Unlocker SDK e CLI](/pt/scraping-api-sdk-and-cli) e [Web Access CLI](/pt/cli-tools/web-access) para mais detalhes.
