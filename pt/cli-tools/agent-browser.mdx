title: "CLI Gologin Agent Browser"
description: "CLI de automação de navegador para agentes de IA que executa perfis do Gologin no Cloud Browser ou no Orbita local, com snapshots, refs e um daemon persistente"
---

A CLI Gologin Agent Browser transforma os perfis de navegador do Gologin em um ambiente de execução persistente e programável para agentes de IA. As sessões rodam no Gologin Cloud Browser ou no Orbita, na sua própria máquina. Ela oferece snapshots compactos da página, interação baseada em refs, memória de sessão e saída adequada para uso no shell.

Diferente de escrever código Puppeteer/Playwright do zero, esta CLI oferece aos agentes um conjunto pronto de comandos para automação de navegador — sem código repetitivo e sem código de gerenciamento de sessão.

---

## Execução na nuvem ou local

A CLI tem dois ambientes de execução com os mesmos comandos. Ambos usam perfis, fingerprints e proxies do Gologin, e um daemon mantém as sessões ativas entre as chamadas da CLI.

| | `cloud` (padrão) | `local` |
|---|---|---|
| Onde o navegador roda | Gologin Cloud Browser | Orbita na sua máquina |
| ID do perfil | Opcional: sem ele, um perfil temporário na nuvem é criado | Obrigatório |
| Ideal para | Sessões paralelas, sessões remotas, máquinas que não devem rodar um navegador | Aquecimento de perfis, primeiros logins, cookies e estado do perfil locais, compatibilidade com o seu sistema operacional |

Escolha o ambiente de execução por comando com `--runtime cloud|local|auto`, ou defina `GOLOGIN_AGENT_BROWSER_RUNTIME` uma única vez:

```bash
gologin-agent-browser open https://example.com
gologin-agent-browser open https://example.com --runtime local --profile your_profile_id
```

Por padrão (`auto`), os comandos de perfil, runbook e job rodam localmente e todo o resto roda na nuvem. Depois de abrir uma sessão local, passe `--runtime local` também aos comandos seguintes. Consulte [Ambiente local](/pt/cli-tools/local-agent-browser) para ver os requisitos e os comandos exclusivos do modo local.

## Instalação

```bash
npm install -g gologin-agent-browser-cli
```

Ou execute sem instalação global:

```bash
npx gologin-agent-browser-cli --help
```

Requer Node.js >= 18. O ambiente local requer Node.js 20 ou superior.

## Credenciais

| Variável | Obrigatória | Descrição |
|---|---|---|
| `GOLOGIN_TOKEN` | Sim (para `open` e comandos de API) | Token de API do Gologin |
| `GOLOGIN_PROFILE_ID` | Opcional | ID do perfil padrão |
| `GOLOGIN_AGENT_BROWSER_RUNTIME` | Opcional | Ambiente de execução padrão: `cloud`, `local` ou `auto` |
| `GOLOGIN_DAEMON_PORT` | Opcional | Porta do daemon (padrão: `44777` para cloud, `44778` para local) |
| `GOLOGIN_CONNECT_BASE` | Opcional | Endpoint do Cloud Browser (padrão: `https://cloudbrowser.gologin.com/connect`) |
| `GOLOGIN_EXECUTABLE_PATH` | Opcional | Caminho para o executável do Orbita no ambiente local |

### Obtenha um token

1. Cadastre-se ou faça login em [gologin.com](https://gologin.com)
2. Abra **API & MCP** no painel
3. Abra a aba **API**
4. Clique em **Novo Token**
5. Copie o token de acesso gerado

```bash
export GOLOGIN_TOKEN='your_gologin_token'
```

### Arquivo de configuração

`~/.gologin-agent-browser/config.json`

## Arquitetura

Duas partes:

1. **CLI `gologin-agent-browser`** — interpreta os comandos, escolhe o ambiente de execução, inicia automaticamente o daemon correspondente e imprime uma saída compacta
2. **Daemons locais persistentes**, um por ambiente de execução — controlam as sessões ativas do navegador, conectam-se ao Gologin Cloud Browser ou ao Orbita local por meio do `connectOverCDP` do Playwright, mantêm a página ativa na memória, geram snapshots, resolvem refs e acompanham os metadados da sessão

O transporte é somente local. O daemon da nuvem escuta em:
- Socket Unix em `${TMPDIR:-/tmp}/gologin-agent-browser.sock`
- HTTP em localhost, em `127.0.0.1:${GOLOGIN_DAEMON_PORT:-44777}`

No ambiente de nuvem, se você não informar um ID de perfil, o daemon cria um perfil temporário do Gologin na nuvem por meio da API.

## Como funcionam as refs

O `snapshot` imprime uma visão compacta da página e atribui refs como `@e1`, `@e2`, `@e3` aos elementos interativos. Você age diretamente sobre elas:

```bash
gologin-agent-browser snapshot
# output shows page content with refs like @e1, @e2, @e3...

gologin-agent-browser click @e3
gologin-agent-browser type @e5 "search query"
gologin-agent-browser fill @e7 "username"
```

As refs funcionam em regime de melhor esforço e devem ser geradas novamente após uma navegação ou mudanças grandes no DOM. Os comandos também aceitam seletores CSS no lugar das refs. Em páginas dinâmicas, o `find` costuma ser uma alternativa melhor do que refs desatualizadas: ele localiza o elemento na página ativa e age sobre ele em uma única etapa.

```bash
gologin-agent-browser find label "Email" fill "user@example.com"
gologin-agent-browser find role button click --name "Submit"
```

## Início rápido

```bash
export GOLOGIN_TOKEN='your_token'

# open a page in cloud browser
gologin-agent-browser open https://example.com

# read the page as a compact snapshot
gologin-agent-browser snapshot

# interact with elements
gologin-agent-browser click @e3
gologin-agent-browser type @e5 "hello world"

# take a screenshot
gologin-agent-browser screenshot ./page.png

# close the session
gologin-agent-browser close
```

## Exemplo de loop de agente

Um loop típico de agente de IA:

```
1. open <url>
2. snapshot          → agent reads page content
3. click/type/fill   → agent acts on refs
4. snapshot          → agent reads result
5. repeat 3-4 as needed
6. screenshot        → save artifact
7. close
```

### Perfis, proxies e a API do Gologin

Estes comandos chamam a API do Gologin com o seu token e não precisam do daemon do navegador.

| Comando | Descrição |
|---|---|
| `api <METHOD> <path>` | Chama qualquer endpoint da API REST do Gologin |
| `browser <action>` | Perfis: listar, obter, criar, atualizar, excluir, cookies, proxy, iniciar e parar na nuvem, importar e exportar |
| `proxy <action>` | Proxies: listar, adicionar um proxy do Gologin, atualizar, excluir, tráfego |
| `workspace`, `folder`, `share`, `template` | Workspaces e membros, pastas, compartilhamento, modelos de perfil |
| `user`, `deleted-profile` | Informações da conta e tokens de desenvolvedor, restauração de perfis excluídos |
| `cloud-usage` | Uso do Cloud Browser de um perfil ou workspace |
| `profile-cloud`, `profile-cookies`, `profile-fingerprint`, `profile-proxy`, `profile-ua` | Atalhos: iniciar ou parar um perfil na nuvem, exportar ou importar seus cookies, atualizar seu fingerprint, adicionar um proxy, atualizar seu user agent |

```bash
gologin-agent-browser browser list --page 1
gologin-agent-browser proxy add-gologin your_profile_id --country us --type residential
gologin-agent-browser cloud-usage --profile your_profile_id
gologin-agent-browser api GET /browser/your_profile_id
```

Adicione `--help` a qualquer comando para exibir seu modo de uso.

## Casos de uso e exemplos

### Verifique se o seu site passa nos testes anti-detect

```bash
gologin-agent-browser open https://iphey.com/ --profile your_profile_id
gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # read the trust score
gologin-agent-browser screenshot ./iphey-result.png
gologin-agent-browser close
```

### Faça login em um aplicativo web e extraia dados do painel

```bash
gologin-agent-browser open https://app.example.com/login
gologin-agent-browser snapshot

# agent reads snapshot, finds login form
gologin-agent-browser fill @e4 "user@company.com"
gologin-agent-browser fill @e6 "password"
gologin-agent-browser click @e8

gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # agent reads dashboard content

# navigate to the report page
gologin-agent-browser click @e12   # "Reports" link
gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # agent extracts report data
gologin-agent-browser screenshot ./report.png
gologin-agent-browser close
```

### Preencha um formulário de várias etapas

```bash
gologin-agent-browser open https://forms.example.com/apply

# step 1: personal info
gologin-agent-browser snapshot
gologin-agent-browser fill @e3 "John Doe"
gologin-agent-browser fill @e5 "john@example.com"
gologin-agent-browser select @e7 "United States"
gologin-agent-browser click @e9   # Next

# step 2: upload and submit
gologin-agent-browser wait 1000
gologin-agent-browser snapshot
gologin-agent-browser upload @e4 ./resume.pdf
gologin-agent-browser check @e6   # agree to terms
gologin-agent-browser click @e8   # Submit

gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # confirm success
gologin-agent-browser close
```

### Tire capturas de tela de páginas de concorrentes

```bash
# use different profiles with different geos
for profile in us_profile de_profile jp_profile; do
  gologin-agent-browser open https://competitor.com --profile $profile
  gologin-agent-browser wait 3000
  gologin-agent-browser screenshot ./${profile}-homepage.png
  gologin-agent-browser close
done
```

### Pesquise em um site que bloqueia scraping

Alguns sites exigem execução de JavaScript, login ou interação antes de mostrar os resultados. Use o navegador para pesquisar:

```bash
gologin-agent-browser open https://protected-directory.com
gologin-agent-browser snapshot
gologin-agent-browser find placeholder "Search" fill "machine learning engineer San Francisco"
gologin-agent-browser press Enter
gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # agent reads search results
gologin-agent-browser screenshot ./search-results.png
gologin-agent-browser close
```

### Salve e restaure o estado da sessão

Exporte cookies e armazenamento para reutilizá-los entre sessões:

```bash
# after logging in
gologin-agent-browser cookies --output ./session-cookies.json
gologin-agent-browser storage-export ./session-storage.json
gologin-agent-browser close

# later, restore the session
gologin-agent-browser open https://app.example.com
gologin-agent-browser cookies-import ./session-cookies.json
gologin-agent-browser storage-import ./session-storage.json
gologin-agent-browser reload
gologin-agent-browser snapshot     # already logged in
```

## Sessões paralelas

Use IDs `--session` explícitos para tarefas independentes na nuvem. Faça a limpeza com `close --all` ou `sessions --prune --older-than-ms`.

## Regras de proxy

- Perfis pré-configurados: o proxy é definido no perfil pelo painel do Gologin ou pela API, por exemplo `proxy add-gologin <profileId> --country us`
- Perfis temporários na nuvem: sem proxy, ou com o seu próprio proxy usando `--proxy-host` e `--proxy-port` (além de `--proxy-mode http|socks4|socks5`, `--proxy-user`, `--proxy-pass`)
- No ambiente de nuvem, o `open` não aceita `--proxy-country`. Para usar tráfego de proxy do Gologin de um país, adicione um proxy do Gologin a um perfil e abra-o com `--profile`
- No ambiente local, `open`, `profile-create` e `profile-update` aceitam `--proxy-country`
