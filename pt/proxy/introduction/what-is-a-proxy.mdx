---
title: "O que é um proxy"
---

Um proxy é um servidor que atua como intermediário entre o seu dispositivo e a internet.\
Em vez de se conectar diretamente a um site, o seu tráfego é roteado pelo servidor proxy.

Isso significa que os sites veem o **endereço IP do proxy** em vez do seu endereço IP real, e a requisição parece vir de outra localização.

Quando usado junto com o **Gologin**, o proxy funciona em conjunto com a impressão digital do navegador de um perfil.\
Cada perfil pode se conectar por um proxy diferente, o que ajuda os sites a reconhecê-los como dispositivos separados.

## Por que usar um proxy é importante

Usar um proxy é **fundamental** ao trabalhar com o Gologin.

Os sites rastreiam a atividade dos usuários analisando tanto a **impressão digital do navegador quanto o endereço IP**.\
Mesmo que você use perfis de navegador diferentes, várias contas ainda serão vinculadas se compartilharem o mesmo endereço IP.

Usar um proxy permite que cada perfil opere a partir de uma localização de rede diferente, reduzindo a chance de as contas serem associadas ao mesmo dispositivo.

## Onde conseguir um proxy

O Gologin é compatível com **provedores de proxy de terceiros** e com **proxies integrados do Gologin**.

Você pode conectar proxies de provedores externos inserindo as credenciais do proxy nas configurações do perfil.

O Gologin também oferece opções de proxy integradas, que podem ser configuradas diretamente no aplicativo.

Para ver uma lista de provedores de proxy recomendados, consulte [**Provedores de proxy recomendados**](https://gologin.com/proxies/proxy-type/).
