---
title: "Czym jest Web Unlocker?"
---

Web Unlocker to uniwersalne API do scrapowania. Wysyłasz dowolny adres URL, a w odpowiedzi dostajesz w pełni wyrenderowany kod HTML albo stronę w formacie Markdown lub JSON — bez zarządzania infrastrukturą, bez blokad i bez nieudanych żądań.

Web Unlocker może w całości zastąpić Twój dotychczasowy stack do scrapowania: automatyzację przeglądarki, zarządzanie proxy, fingerprinting i rozwiązywanie CAPTCHA — wszystko w jednym wywołaniu API. Niezależnie od tego, czy scrapujesz prostą stronę statyczną, czy mocno chronioną witrynę renderowaną w JavaScript, obsłuży ją ten sam endpoint.

---

## Jakie problemy rozwiązuje

Współczesne strony internetowe trudno scrapować. Zwykłe wywołanie `curl` lub `requests` często zwraca stronę z wyzwaniem, pustą odpowiedź albo uszkodzony kod HTML, ponieważ treść jest ładowana przez JavaScript. Web Unlocker obsługuje to wszystko automatycznie:

- **Renderowanie JavaScript** — strony są ładowane w prawdziwej przeglądarce i w pełni wykonywane, zanim treść zostanie pobrana
- **Omijanie zabezpieczeń antybotowych** — Cloudflare, DataDome, PerimeterX i podobne zabezpieczenia są obsługiwane automatycznie
- **Inteligentna rotacja IP** — żądania są kierowane przez czyste adresy IP typu residential z realistycznymi fingerprintami przeglądarki
- **Rozwiązywanie CAPTCHA** — popularne wyzwania CAPTCHA są rozwiązywane bez ręcznej interwencji
- **Dobór poziomu cenowego** — żądania są kierowane przez odpowiedni poziom proxy dla docelowej witryny

## Co otrzymujesz w odpowiedzi

Udane żądanie zwraca stronę w jednym formacie. Wybierasz go za pomocą parametru zapytania `format`:

| `format` | Co otrzymujesz |
| --- | --- |
| `html` (domyślnie) | Kompletny wyrenderowany DOM strony |
| `markdown` | Treść strony w formacie Markdown |
| `json` | Obiekt JSON z adresem URL strony, metadanymi żądania i kodem HTML |

## Web Unlocker a własne proxy

Utrzymywanie własnej infrastruktury proxy jest drogie i zawodne. Web Unlocker zajmuje się wszystkim jako usługa zarządzana:

|  | Web Unlocker | Własne proxy |
| --- | --- | --- |
| Konfiguracja | Jedno wywołanie API | Tygodnie pracy nad infrastrukturą |
| Rozwiązywanie CAPTCHA | Wbudowane | Trzeba zbudować lub kupić osobno |
| Fingerprinting przeglądarki | Wbudowany | Trzeba zbudować lub kupić osobno |
| Rotacja IP | Automatyczna | Ręczne zarządzanie pulą |
| Utrzymanie | Brak | Stałe |
| Rozliczanie | Za udane żądanie | Stały koszt niezależnie od skuteczności |

## Typowe zastosowania

- **Monitorowanie cen** — scrapowanie sklepów internetowych, które blokują zautomatyzowane żądania
- **Pozyskiwanie leadów** — pobieranie danych kontaktowych z katalogów i wykazów firm
- **Badania rynku** — zbieranie danych o produktach, opinii lub ofert pracy na dużą skalę
- **Agregacja treści** — tworzenie kanałów z wiadomościami lub danymi na podstawie stron bez API
- **Potoki AI** — przekazywanie wyrenderowanego HTML do modeli LLM w celu ekstrakcji lub streszczania

## Jak to działa

Web Unlocker uruchamia w chmurze prawdziwą przeglądarkę Chromium dla każdego zadania. Gdy wysyłasz adres URL:

1. Uruchamiana jest przeglądarka z adresem IP typu residential i realistycznym fingerprintem przeglądarki
2. Przeglądarka otwiera stronę, wykonuje JavaScript i ładuje treści dynamiczne
3. Zabezpieczenia antybotowe i CAPTCHA są obsługiwane automatycznie
4. Zwracany jest wyrenderowany kod HTML, a jeśli o to poprosisz za pomocą `format` — Markdown lub JSON

Nie zarządzasz żadną infrastrukturą. Nie musisz uruchamiać przeglądarek, utrzymywać list proxy ani budować logiki omijania zabezpieczeń. Web Unlocker w praktyce zastępuje cały stack do scrapowania — framework do automatyzacji przeglądarki, dostawcę proxy i rozwiązanie antybotowe — jednym żądaniem HTTP.

## Jak z niego korzystać

Wyślij żądanie GET z docelowym adresem URL jako parametrem zapytania. Odpowiedzią jest w pełni wyrenderowany kod HTML.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Aby otrzymać Markdown lub JSON, dodaj do zapytania `format=markdown` lub `format=json`.

Przykłady w Pythonie i JavaScript oraz [kody błędów](/pl/web-unlocker-quick-start#handling-errors) znajdziesz w [Quickstart](/pl/web-unlocker-quick-start), a typowe wzorce integracji w [Use Cases](/pl/web-unlocker-use-cases).
