---
title: "Czym jest Web Unlocker?"
---

Web Unlocker to uniwersalne API do scrapingu. Wysyłasz dowolny adres URL, a w odpowiedzi dostajesz w pełni wyrenderowany kod HTML, zrzut ekranu i archiwum ruchu sieciowego — bez zarządzania infrastrukturą, bez blokad i bez nieudanych żądań.

Działa jako kompletny zamiennik całego stosu do scrapingu: automatyzacji przeglądarki, zarządzania proxy, fingerprintingu i rozwiązywania CAPTCHA — wszystko w jednym wywołaniu API. Niezależnie od tego, czy pobierasz prostą stronę statyczną, czy mocno chronioną witrynę renderowaną w JavaScript, obsługuje ją ten sam endpoint.

---

## Jakie problemy rozwiązuje

Współczesne strony internetowe trudno scrapować. Zwykłe wywołanie `curl` lub `requests` często zwraca stronę z wyzwaniem, pustą odpowiedź albo uszkodzony kod HTML, ponieważ treść jest ładowana przez JavaScript. Web Unlocker obsługuje to wszystko automatycznie:

- **Renderowanie JavaScript** — strony są ładowane w prawdziwej przeglądarce i w pełni wykonywane, zanim treść zostanie pobrana
- **Omijanie zabezpieczeń anty-botowych** — Cloudflare, DataDome, PerimeterX i podobne zabezpieczenia są obsługiwane automatycznie
- **Inteligentna rotacja IP** — żądania są kierowane przez czyste rezydencjalne adresy IP z realistycznymi fingerprintami przeglądarki
- **Rozwiązywanie CAPTCHA** — typowe wyzwania CAPTCHA są rozwiązywane bez ręcznej interwencji
- **Dobór poziomu cenowego** — żądania są kierowane przez odpowiedni poziom proxy dla danej witryny

## Web Unlocker a własne proxy

Utrzymywanie własnej infrastruktury proxy jest kosztowne i zawodne. Web Unlocker zapewnia wszystko jako usługę zarządzaną:

|  | Web Unlocker | Własne proxy |
| --- | --- | --- |
| Konfiguracja | Jedno wywołanie API | Tygodnie pracy nad infrastrukturą |
| Rozwiązywanie CAPTCHA | Wbudowane | Trzeba zbudować lub kupić osobno |
| Fingerprinting przeglądarki | Wbudowany | Trzeba zbudować lub kupić osobno |
| Rotacja IP | Automatyczna | Ręczne zarządzanie pulą |
| Utrzymanie | Brak | Stałe |
| Rozliczenia | Za każde udane żądanie | Stały koszt niezależnie od skuteczności |

## Jak to działa

Web Unlocker uruchamia w chmurze prawdziwą przeglądarkę Chromium dla każdego zadania. Gdy wysyłasz adres URL:

1. Uruchamiana jest przeglądarka z rezydencjalnym adresem IP i realistycznym fingerprintem przeglądarki
2. Następuje przejście na stronę, wykonanie JavaScript i załadowanie treści dynamicznych
3. Wyzwania anty-botowe i CAPTCHA są obsługiwane automatycznie
4. Wyrenderowany kod HTML, zrzut ekranu i archiwum sieciowe są przechwytywane i zwracane

Nie zarządzasz żadną infrastrukturą. Nie musisz uruchamiać przeglądarek, utrzymywać list proxy ani budować logiki omijania zabezpieczeń. Web Unlocker w praktyce zastępuje cały stos do scrapingu — framework do automatyzacji przeglądarki, dostawcę proxy i rozwiązanie anty-botowe — jednym żądaniem HTTP.

## Jak z niego korzystać

Wyślij żądanie GET z docelowym adresem URL jako parametrem zapytania. Odpowiedzią jest w pełni wyrenderowany kod HTML.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Przykłady w Pythonie i JavaScript znajdziesz w [Quickstart](/pl/web-unlocker-quick-start), a typowe wzorce integracji w [Use Cases](./web-unlocker-use-cases.md).
