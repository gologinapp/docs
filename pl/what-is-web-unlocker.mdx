---
title: "Czym jest Web Unlocker?"
---

Web Unlocker to uniwersalne Scraping API. Wystarczy wysłać dowolny adres URL, aby otrzymać w pełni wyrenderowany kod HTML albo stronę w formacie Markdown lub JSON, bez konieczności zarządzania przeglądarkami i serwerami proxy.

Zastępuje część stosu do scrapingu odpowiedzialną za przeglądarkę i proxy: renderowanie, zarządzanie proxy oraz odciski przeglądarki (fingerprinty) obsługiwane są w jednym wywołaniu API. Strony statyczne i witryny oparte na JavaScript korzystają z tego samego endpointu.

---

## Jaki problem rozwiązuje

Współczesne strony internetowe trudno scrapować. Zwykłe wywołanie `curl` lub `requests` często zwraca pustą odpowiedź albo uszkodzony kod HTML, ponieważ treść jest ładowana przez JavaScript. Web Unlocker zajmuje się następującymi kwestiami:

- **Renderowanie JavaScript** — strony są ładowane w prawdziwej przeglądarce, a ich skrypty są w pełni wykonywane, zanim treść zostanie pobrana
- **Inteligentna rotacja IP** — żądania są kierowane przez rezydencyjne adresy IP z realistycznymi odciskami przeglądarki
- **Dobór poziomu cenowego** — żądania są kierowane przez odpowiedni poziom proxy dla danej witryny

---

## Co otrzymujesz w odpowiedzi

Udane żądanie zwraca stronę w jednym formacie. Wybierzesz go za pomocą parametru zapytania `format`:

| `format` | Co otrzymujesz |
| --- | --- |
| `html` (domyślnie) | Kompletny wyrenderowany DOM strony |
| `markdown` | Treść strony w formacie Markdown |
| `json` | Obiekt JSON z adresem URL strony, metadanymi żądania i kodem HTML |

## Web Unlocker a własne serwery proxy

Utrzymywanie własnej infrastruktury proxy jest drogie i zawodne. Web Unlocker obsługuje wszystko jako usługa zarządzana:

|  | Web Unlocker | Własne serwery proxy |
| --- | --- | --- |
| Konfiguracja | Jedno wywołanie API | Tygodnie pracy nad infrastrukturą |
| Odciski przeglądarki | Wbudowane | Trzeba je zbudować lub kupić osobno |
| Rotacja IP | Automatyczna | Ręczne zarządzanie pulą |
| Utrzymanie | Brak | Ciągłe |
| Rozliczenia | Za każde udane żądanie | Stały koszt niezależnie od skuteczności |

## Typowe zastosowania

- **Monitorowanie cen** — śledzenie cen w sklepach internetowych
- **Badania rynku** — zbieranie na dużą skalę danych o produktach, opinii lub ofert pracy
- **Agregacja treści** — tworzenie kanałów z wiadomościami lub danymi ze stron bez API
- **Pipeline'y AI** — przekazywanie wyrenderowanego HTML do modeli LLM w celu ekstrakcji lub streszczania

## Jak to działa

Web Unlocker uruchamia w chmurze prawdziwą przeglądarkę Chromium dla każdego zadania. Gdy wysyłasz adres URL:

1. Uruchamiana jest przeglądarka z rezydencyjnym adresem IP i realistycznym odciskiem przeglądarki
2. Przeglądarka otwiera stronę, wykonuje JavaScript i ładuje treści dynamiczne
3. Zwracany jest wyrenderowany kod HTML albo Markdown lub JSON, jeśli zażądasz tego za pomocą `format`

Nie zarządzasz żadną infrastrukturą. Nie musisz uruchamiać przeglądarek, utrzymywać list proxy ani tworzyć logiki renderowania. Web Unlocker zastępuje framework do automatyzacji przeglądarki oraz dostawcę proxy jednym żądaniem HTTP.

---

## Jak z tego korzystać

Wyślij żądanie GET z docelowym adresem URL jako parametrem zapytania. Odpowiedzią jest w pełni wyrenderowany kod HTML.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Aby zamiast tego otrzymać Markdown lub JSON, dodaj do zapytania `format=markdown` lub `format=json`.

Przykłady w Pythonie i JavaScript oraz [kody błędów](/pl/web-unlocker-quick-start#obs%C5%82uga-b%C5%82%C4%99d%C3%B3w) znajdziesz w [Quickstart](/pl/web-unlocker-quick-start), a typowe wzorce integracji w sekcji [Use Cases](/pl/web-unlocker-use-cases).
