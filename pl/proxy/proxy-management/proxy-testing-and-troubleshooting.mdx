Ten przewodnik pomoże Ci sprawdzić, czy proxy działa prawidłowo, oraz rozwiązać najczęstsze problemy z połączeniem.

### Jak przetestować proxy

1. Przypisz proxy do swojego profilu przeglądarki
2. Kliknij **refresh icon** obok lokalizacji proxy
3. Poczekaj, aż system sprawdzi połączenie

Jeśli proxy działa prawidłowo, system wyświetli:

- adres IP proxy
- kraj lub lokalizację
- status połączenia

Jeśli proxy działa prawidłowo, wskaźnik statusu będzie **zielony**.
