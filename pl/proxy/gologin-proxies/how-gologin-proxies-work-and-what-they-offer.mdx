---
title: "Jak działają proxy Gologin"
---

Proxy Gologin są zintegrowane bezpośrednio ze środowiskiem Gologin i można je przypisywać do profili przeglądarki bez dodatkowej konfiguracji.

Gdy proxy zostaje przypisane do profilu, cały ruch internetowy z tego profilu jest kierowany przez serwer proxy. Oznacza to, że strony internetowe widzą adres IP proxy zamiast Twojego prawdziwego adresu IP.

Używanie osobnych proxy dla różnych profili pomaga zachować izolację sesji i zmniejsza ryzyko powiązania ze sobą wielu kont.

## Dostępne typy proxy

Gologin oferuje kilka typów proxy:

- **Residential rotating** - płatne według ruchu
- **Mobile rotating** - płatne według ruchu
- **Datacenter sticky** - płatne według ruchu
- **Dedicated IP** - statyczny adres IP zarezerwowany wyłącznie dla Ciebie, płatny w ramach subskrypcji w cenie \$5/miesiąc za jeden adres IP

Pierwsze trzy typy korzystają z limitu ruchu w Twoim planie i pobierają adres ze wspólnej puli. Dedicated IP jest tylko Twój, nie rotuje i nie ma limitu ruchu.

## Kraje proxy

**Proxy rozliczane według ruchu (residential, mobile, datacenter):** po zakupie ruchu proxy Gologin otrzymujesz dostęp do wszystkich dostępnych krajów proxy. Nie jesteś ograniczony do jednego kraju - ruch możesz wykorzystać w dowolnym kraju z listy. Dostępnych jest kilkadziesiąt krajów, a od czasu do czasu dodajemy nowe. Pełną listę znajdziesz bezpośrednio w aplikacji Gologin.

**Dedicated IP:** kupujesz jeden kraj naraz. Otrzymany adres IP należy do wybranego przez Ciebie kraju i nie można go przenieść do innego. Jeśli potrzebujesz adresów w kilku krajach, kup osobny Dedicated IP dla każdego z nich.

Dedicated IP są obecnie dostępne w następujących krajach:

- Brazylia
- Francja
- Niemcy
- Hongkong
- Rumunia
- Turcja
- Wielka Brytania
- Stany Zjednoczone

<Note>
  Możesz kupić więcej niż jeden Dedicated IP w tym samym kraju. Każdy zakup daje inny adres, a wszystkie są pogrupowane pod danym krajem w menedżerze proxy.
</Note>

## Co oferują proxy Gologin

Korzystanie z proxy Gologin daje kilka korzyści:

- szybka konfiguracja bez ustawień po stronie zewnętrznych dostawców
- łatwe przypisywanie proxy do profili
- integracja z profilami przeglądarki Gologin
- uproszczone zarządzanie proxy w aplikacji
