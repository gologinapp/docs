## Proxy rozliczane według ruchu

### Jak wybrać typ proxy?

Aby wybrać typ proxy dla nowego połączenia, utwórz nowy serwer proxy: kliknij **Choose location or proxy on the profile \> arrow next to the country \> Add new server \> choose the proxy type**.

### Ile ruchu potrzebuję?

Wymagana ilość zależy od sposobu korzystania z proxy. Zmienia się głównie w zależności od tego:

- jak często używasz swoich profili przeglądarki,
- jak długo trwają Twoje sesje,
- ile ciężkich treści (takich jak wideo, obrazy czy audio) wczytujesz podczas pracy.

### Co się stanie, gdy zużyję cały ruch proxy? Czy zostanę wykryty?

Jeśli ruch skończy się w trakcie pracy, Gologin po prostu odłączy Twoje profile od internetu i nie będziesz mógł ich używać, dopóki nie dokupisz ruchu lub nie przełączysz się na proxy zewnętrznego dostawcy. Profile możesz zamknąć bez utraty danych, ponieważ synchronizacja profili nie zużywa ruchu proxy.

### Czy jeśli używam własnych proxy zewnętrznych, zużywam ruch proxy Gologin?

Oczywiście, że nie! Ruch proxy Gologin zużywasz tylko wtedy, gdy korzystasz z naszych proxy.

### Czy po rejestracji na okresie próbnym dostanę darmowy próbny ruch proxy Gologin?

Gologin na razie nie przyznaje próbnego ruchu nowo zarejestrowanym użytkownikom. Zawsze możesz jednak kupić niewielką ilość ruchu i sprawdzić, czy proxy Gologin spełniają Twoje potrzeby.

### Niektóre porty nie działają w proxy Gologin. Dlaczego?

Porty, których działanie jest gwarantowane, to 80 i 443. Są to standardowe porty do zwykłego ruchu na stronach internetowych.

Wszystkie pozostałe porty, używane głównie do wysyłania spamu, ataków DDoS i ataków brute-force, są zablokowane.

## Dedicated IP

### Jaka jest różnica między proxy ISP, proxy statycznymi a Dedicated IP?

Żadna – to trzy nazwy tego samego rozwiązania. Możesz spotkać wszystkie z nich w internecie. W Gologin ta funkcja nazywa się **Dedicated IP**.

### Czym jest Dedicated IP?

To pojedynczy adres IP zarezerwowany wyłącznie dla Ciebie. Pochodzi od prawdziwego dostawcy internetu, ale jest hostowany w centrum danych. Dzięki temu ma szybkość i stabilność proxy z centrum danych, a strony internetowe widzą go jak zwykłe domowe połączenie. Nigdy się nie zmienia i nie ma limitu ruchu.

### Mam plan roczny. Dlaczego naliczono mi więcej niż \$5?

Dedicated IP jest powiązany z Twoją główną subskrypcją i zawsze wygasa razem z nią, więc płacisz za pozostałe miesiące. Jeśli do końca Twojego planu rocznego zostało 7 miesięcy, z góry zapłacisz \$35. Niepełny miesiąc jest rozliczany jak pełny.

### Zapłaciłem, ale nigdzie nie widzę swojego proxy Dedicated IP

Przypisanie adresu do Twojego konta trwa 5–7 minut, a po jego zakończeniu nie otrzymasz powiadomienia. Poczekaj kilka minut i odśwież stronę **Proxies** – adres się pojawi.

### Czy Dedicated IP zużywa ruch proxy z mojego planu?

Nie. Ruch przez Dedicated IP jest nielimitowany i nie wpływa na Twój limit GB. Nawet jeśli limit ruchu całkowicie się wyczerpie, profile korzystające z Dedicated IP nadal będą działać.

### Czy nadal potrzebuję ruchu proxy, jeśli mam Dedicated IP?

Tylko w przypadku profili, które używają naszych rotacyjnych proxy. Jeśli wszystkie Twoje profile korzystają z Dedicated IP, limit ruchu po prostu pozostanie niewykorzystany.

### Czy mój adres IP pozostanie taki sam przy Dedicated IP?

Tak. Dopóki Twoja subskrypcja jest aktywna i odnawiana, zachowujesz ten sam adres.

### Zapłaciłem kryptowalutą – czy mój Dedicated IP zostanie odnowiony?

Nie. Płatności kryptowalutami nie mogą być odnawiane automatycznie, więc adres IP działa przez opłacony okres, a potem przestaje. Później nie będzie można odzyskać tego samego adresu. Jeśli chcesz zachować adres na dłużej, zapłać kartą.
