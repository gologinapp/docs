Gologin daje agentom AI trzy rzeczy, których potrzebują do niezawodnej pracy w sieci:

1. **Odczyt sieci** — scrapuj dowolną stronę, także z dużą ilością JS i zabezpieczoną, za pomocą Web Unlocker
2. **Interakcja z siecią** — otwieraj prawdziwe sesje przeglądarki z klikaniem, wpisywaniem tekstu, nawigacją i trwałymi plikami cookie dzięki Cloud Browser
3. **Pozostawanie niewykrytym** — fingerprinting anti-detect, rezydencyjne proxy i zarządzanie tożsamością oparte na profilach

Te możliwości są dostępne na kilku poziomach integracji — wybierz ten, który pasuje do Twojego stosu technologicznego.

## Jak to wszystko do siebie pasuje

```
┌─────────────────────────────────────────────────┐
│                  AI Agent                        │
│         (Claude, Codex, custom agent)            │
└──────┬──────────┬──────────┬────────────────────┘
       │          │          │
  MCP Server   AI Skills   CLI Tools / SDK
       │          │          │
       └──────────┴──────────┘
                  │
    ┌─────────────┴─────────────┐
    │                           │
Web Unlocker              Cloud Browser
(stateless scraping)    (stateful sessions)
    │                           │
    └─────────────┬─────────────┘
                  │
          Gologin Infrastructure
    (proxies, fingerprints, profiles)
```

- **Web Unlocker** obsługuje bezstanowy odczyt i wyodrębnianie danych — wysyłasz adres URL, otrzymujesz wyrenderowany kod HTML
- **Cloud Browser** obsługuje interakcje ze stanem — otwierasz sesję, klikasz, wpisujesz tekst, nawigujesz i zachowujesz pliki cookie
- **Lokalna Orbita** obsługuje trwałe profile lokalne — rozgrzewanie, procesy logowania, działania w mediach społecznościowych i na marketplace'ach

Wszystkie trzy korzystają z tej samej infrastruktury Gologin: rezydencyjnych proxy, fingerprintingu anti-detect i zarządzania profilami.

## Co ludzie z tym budują

### Analiza rynku i wywiad konkurencyjny

Agent AI, który monitoruje ceny konkurencji, premiery produktów i zmiany treści na dziesiątkach stron — codziennie i automatycznie. Agent scrapuje strony konkurentów przez Web Unlocker, wyodrębnia ustrukturyzowane dane, porównuje je z wczorajszą migawką i tworzy dzienne podsumowanie. Nie są potrzebne sesje przeglądarki, wystarczy bezstanowe wyodrębnianie danych na dużą skalę.

```bash
# scrape 20 competitor pricing pages and get structured output
gologin-web-access batch-scrape \
  https://competitor1.com/pricing \
  https://competitor2.com/pricing \
  https://competitor3.com/pricing \
  --format json --summary --output ./today-prices.json

# detect what changed since last check
gologin-web-access batch-change-track \
  https://competitor1.com/pricing \
  https://competitor2.com/features \
  --format markdown --output ./changes.json
```

### Generowanie i wzbogacanie leadów

Scrapuj katalogi firm, strony firmowe na LinkedIn i serwisy z opiniami, a następnie przekaż kod HTML do Claude, aby wyodrębnić nazwy, adresy e-mail, numery telefonów, wielkość firmy i stos technologiczny. Działa jako narzędzie w pętli agenta AI: agent decyduje, które strony scrapować, wywołuje narzędzie i otrzymuje ustrukturyzowane dane.

```bash
# search for leads
gologin-web-access search "saas companies series A 2026" --limit 20

# scrape and extract structured data from each result
gologin-web-access extract https://example.com/company/123 --schema ./lead-schema.json
```

### Zarządzanie wieloma kontami

Prowadź ponad 50 kont w mediach społecznościowych, kont reklamowych lub kont sprzedawców na marketplace'ach — każde z własnym profilem przeglądarki, fingerprintem, proxy i plikami cookie. Local Agent Browser zarządza profilami, rozgrzewa je za pomocą runbooków i utrzymuje sesje przy kolejnych wywołaniach agenta.

```bash
# create profiles for each account
gologin-local-agent-browser profile-create "FB Ads Account 1" --template ads
gologin-local-agent-browser profile-create "FB Ads Account 2" --template ads

# warm up profiles in batch
gologin-local-agent-browser batch ./warmup-runbook.json \
  --targets ./all-profiles.json --concurrency 5
```

### Automatyczne wypełnianie formularzy i wprowadzanie danych

Agent AI, który loguje się do wewnętrznych paneli, wypełnia formularze, wysyła raporty i pobiera eksporty — wszystko w prawdziwej sesji przeglądarki w chmurze. Agent odczytuje stronę jako migawkę, znajduje właściwe pola po ref, wpisuje wartości, klika przycisk wysyłania i weryfikuje wynik.

```bash
gologin-agent-browser open https://internal-dashboard.com/login --profile my_profile
gologin-agent-browser snapshot
gologin-agent-browser fill @e3 "username"
gologin-agent-browser fill @e5 "password"
gologin-agent-browser click @e7    # submit button
gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # verify login success
gologin-agent-browser screenshot ./logged-in.png
```

### Monitorowanie treści i alerty

Śledź zmiany na stronach z przepisami prawnymi, blogach konkurencji, portalach z ofertami pracy lub na dowolnej stronie ważnej dla Twojej firmy. Uruchamiaj to codziennie przez cron lub zaplanowanego agenta, porównuj z poprzednią wersją i wysyłaj alerty o istotnych zmianach.

```bash
# track changes on key pages
gologin-web-access change-track https://regulations.gov/new-rules --format markdown
gologin-web-access batch-change-track \
  https://competitor.com/blog \
  https://competitor.com/changelog \
  --output ./changes.json
```

### Potoki scrapingu z wykorzystaniem AI

Zbuduj kompletny potok: przeszukaj witrynę z dokumentacją, przekonwertuj ją na markdown i przekaż do LLM w celu streszczenia lub odpowiadania na pytania. Do wyodrębniania danych użyj CLI, a część z LLM zrealizuj własnym kodem.

```bash
# crawl an entire docs site
gologin-web-access crawl https://docs.example.com \
  --format markdown --limit 100 --max-depth 3 --only-main-content \
  --output ./docs-corpus.json

# or map the site first, then selectively scrape
gologin-web-access map https://docs.example.com --limit 200
gologin-web-access batch-scrape url1 url2 url3 --format text --output ./selected.json
```

### Testy geograficzne i kontrola jakości lokalizacji

Sprawdź, jak Twoja witryna wygląda w różnych krajach. Otwórz ten sam adres URL przez profile skonfigurowane z proxy w różnych lokalizacjach, zrób zrzuty ekranu i porównaj je.

```bash
# create geo-specific profiles
gologin-local-agent-browser profile-create "US Test" --template geo --proxy-country us
gologin-local-agent-browser profile-create "DE Test" --template geo --proxy-country de
gologin-local-agent-browser profile-create "JP Test" --template geo --proxy-country jp

# screenshot from each location
gologin-agent-browser open https://yoursite.com --profile us_profile_id
gologin-agent-browser screenshot ./us-view.png
gologin-agent-browser close
```

## Przykłady szybkiego startu

### Scrapowanie strony (CLI)

```bash
npm install -g gologin-web-access
export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."

gologin-web-access read https://example.com
```

### Otwieranie przeglądarki w chmurze (CLI)

```bash
npm install -g gologin-agent-browser-cli
export GOLOGIN_TOKEN='your_token'

gologin-agent-browser open https://example.com
gologin-agent-browser snapshot
gologin-agent-browser click @e3
gologin-agent-browser close
```

### Instalacja AI Skill (Claude Code)

```bash
npx skills add GologinLabs/gologin-web-access-skill
```

Następnie po prostu poproś Claude Code o zescrapowanie strony lub interakcję z witryną — resztą zajmie się skill.

### Połączenie MCP (Claude Desktop)

Dodaj do `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "gologin-mcp": {
      "command": "npx",
      "args": ["gologin-mcp"],
      "env": { "API_TOKEN": "your-token" }
    }
  }
}
```

Następnie poproś Claude: „Utwórz nowy profil przeglądarki z proxy w USA."
