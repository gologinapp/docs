Gologin daje agentom AI trzy rzeczy, których potrzebują, aby niezawodnie pracować z siecią:

1. **Czytanie sieci** — pobieraj dane z dowolnej strony, także z mocno opartych na JS i chronionych, za pomocą Web Unlocker
2. **Interakcja z siecią** — otwieraj prawdziwe sesje przeglądarki z klikaniem, wpisywaniem tekstu, nawigacją i trwałymi plikami cookie za pomocą Cloud Browser
3. **Pozostawanie niewykrytym** — fingerprinting anti-detect, proxy rezydencyjne i zarządzanie tożsamością w oparciu o profile

Te możliwości są dostępne na kilku poziomach integracji — wybierz ten, który pasuje do Twojego stosu technologicznego.

## Jak to wszystko do siebie pasuje

```
┌─────────────────────────────────────────────────┐
│                  AI Agent                        │
│         (Claude, Codex, custom agent)            │
└──────┬──────────┬──────────┬────────────────────┘
       │          │          │
  MCP Server   AI Skills   CLI Tools / SDK
       │          │          │
       └──────────┴──────────┘
                  │
    ┌─────────────┴─────────────┐
    │                           │
Web Unlocker              Cloud Browser
(stateless scraping)    (stateful sessions)
    │                           │
    └─────────────┬─────────────┘
                  │
          Gologin Infrastructure
    (proxies, fingerprints, profiles)
```

- **Web Unlocker** obsługuje bezstanowy odczyt i wyodrębnianie danych — wysyłasz adres URL, a w odpowiedzi dostajesz wyrenderowany kod HTML
- **Cloud Browser** obsługuje interakcje ze stanem — otwierasz sesję, klikasz, wpisujesz tekst, nawigujesz i zachowujesz pliki cookie
- **Lokalna Orbita** obsługuje trwałe profile lokalne — rozgrzewanie, procesy logowania, działania w mediach społecznościowych i na marketplace'ach — za pośrednictwem lokalnego środowiska uruchomieniowego Agent Browser CLI

Wszystkie trzy korzystają z tej samej infrastruktury Gologin: proxy rezydencyjnych, fingerprintingu anti-detect i zarządzania profilami.

## Co można zbudować dzięki temu rozwiązaniu

### Badania i analiza konkurencji

Agent AI, który monitoruje ceny konkurencji, premiery produktów i zmiany w treściach na dziesiątkach stron — codziennie i automatycznie. Agent pobiera strony konkurencji za pomocą Web Unlocker, wyodrębnia uporządkowane dane, porównuje je z wczorajszym zapisem i tworzy codzienne podsumowanie. Nie są potrzebne sesje przeglądarki — wystarczy bezstanowe wyodrębnianie danych na dużą skalę.

```bash
# scrape 20 competitor pricing pages and get structured output
gologin-web-access batch-scrape \
  https://competitor1.com/pricing \
  https://competitor2.com/pricing \
  https://competitor3.com/pricing \
  --format json --summary --output ./today-prices.json

# detect what changed since last check
gologin-web-access batch-change-track \
  https://competitor1.com/pricing \
  https://competitor2.com/features \
  --format markdown --output ./changes.json
```

### Generowanie i wzbogacanie leadów

Pobieraj dane z katalogów firm, stron firmowych na LinkedIn i serwisów z opiniami, a następnie przekaż kod HTML do Claude, aby wyodrębnił nazwiska, adresy e-mail, numery telefonów, wielkość firmy i stos technologiczny. Działa jako narzędzie w pętli agenta AI: agent decyduje, które strony pobrać, wywołuje narzędzie i otrzymuje uporządkowane dane.

```bash
# search for leads
gologin-web-access search "saas companies series A 2026" --limit 20

# scrape and extract structured data from each result
gologin-web-access extract https://example.com/company/123 --schema ./lead-schema.json
```

### Zarządzanie wieloma kontami

Prowadź ponad 50 kont w mediach społecznościowych, kont reklamowych lub kont sprzedawców na marketplace'ach — każde z własnym profilem przeglądarki, fingerprintem, proxy i plikami cookie. Lokalne środowisko uruchomieniowe Agent Browser CLI zarządza profilami, rozgrzewa je za pomocą runbooków i utrzymuje sesje przy kolejnych wywołaniach agenta. Polecenia dotyczące profili i runbooków działają lokalnie, bez dodatkowych flag.

```bash
# create profiles for each account
gologin-agent-browser profile-create "FB Ads Account 1" --template ads
gologin-agent-browser profile-create "FB Ads Account 2" --template ads

# warm up profiles in batch
gologin-agent-browser batch ./warmup-runbook.json \
  --targets ./all-profiles.json --concurrency 5
```

### Automatyczne wypełnianie formularzy i wprowadzanie danych

Agent AI, który loguje się do wewnętrznych paneli, wypełnia formularze, przesyła raporty i pobiera eksporty — wszystko w prawdziwej sesji przeglądarki w chmurze. Agent odczytuje stronę jako snapshot, znajduje odpowiednie pola po ref, wpisuje wartości, klika przycisk wysyłania i weryfikuje wynik.

```bash
gologin-agent-browser open https://internal-dashboard.com/login --profile my_profile
gologin-agent-browser snapshot
gologin-agent-browser fill @e3 "username"
gologin-agent-browser fill @e5 "password"
gologin-agent-browser click @e7    # submit button
gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # verify login success
gologin-agent-browser screenshot ./logged-in.png
```

### Monitorowanie treści i alerty

Śledź zmiany na stronach z przepisami prawnymi, blogach konkurencji, portalach z ofertami pracy lub na dowolnej stronie ważnej dla Twojego biznesu. Uruchamiaj to codziennie przez cron lub zaplanowanego agenta, porównuj z poprzednią wersją i wysyłaj alerty o istotnych zmianach.

```bash
# track changes on key pages
gologin-web-access change-track https://regulations.gov/new-rules --format markdown
gologin-web-access batch-change-track \
  https://competitor.com/blog \
  https://competitor.com/changelog \
  --output ./changes.json
```

### Potoki scrapingu wspierane przez AI

Zbuduj kompletny potok: przeskanuj witrynę z dokumentacją, przekonwertuj ją do markdown i przekaż do LLM w celu streszczenia lub odpowiadania na pytania. Do wyodrębniania danych użyj CLI, a część związaną z LLM zrealizuj własnym kodem.

```bash
# crawl an entire docs site
gologin-web-access crawl https://docs.example.com \
  --format markdown --limit 100 --max-depth 3 --only-main-content \
  --output ./docs-corpus.json

# or map the site first, then selectively scrape
gologin-web-access map https://docs.example.com --limit 200
gologin-web-access batch-scrape url1 url2 url3 --format text --output ./selected.json
```

### Testy geograficzne i kontrola jakości lokalizacji

Sprawdź, jak Twoja witryna wygląda w różnych krajach. Otwórz ten sam adres URL przez profile skonfigurowane z proxy w różnych lokalizacjach, zrób zrzuty ekranu i porównaj je.

```bash
# create geo-specific profiles
gologin-agent-browser profile-create "US Test" --template geo --proxy-country us
gologin-agent-browser profile-create "DE Test" --template geo --proxy-country de
gologin-agent-browser profile-create "JP Test" --template geo --proxy-country jp

# screenshot from each location
gologin-agent-browser open https://yoursite.com --profile us_profile_id
gologin-agent-browser screenshot ./us-view.png
gologin-agent-browser close
```

## Przykłady szybkiego startu

### Pobierz stronę (CLI)

```bash
npm install -g gologin-web-access
export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."

gologin-web-access read https://example.com
```

### Otwórz przeglądarkę w chmurze (CLI)

```bash
npm install -g gologin-agent-browser-cli
export GOLOGIN_TOKEN='your_token'

gologin-agent-browser open https://example.com
gologin-agent-browser snapshot
gologin-agent-browser click @e3
gologin-agent-browser close
```

### Zainstaluj AI Skill (Claude Code)

```bash
npx skills add GologinLabs/agent-skills@gologin-web-access-skill
```

Następnie po prostu poproś Claude Code o pobranie strony lub interakcję z witryną — resztą zajmie się skill.

### Połącz MCP (Claude Desktop)

Dodaj do `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "gologin-mcp": {
      "command": "npx",
      "args": ["gologin-mcp"],
      "env": { "API_TOKEN": "your-token" }
    }
  }
}
```

Następnie poproś Claude: "Utwórz nowy profil przeglądarki z proxy z USA."
