---
title: "Akcje zbiorcze"
---

Akcje zbiorcze w Gologin pozwalają zastosować tę samą czynność do wielu profili jednocześnie.

Aby skorzystać z akcji zbiorczych, najpierw zaznacz kilka profili na liście za pomocą pól wyboru. Następnie u góry strony pojawi się panel akcji zbiorczych.

## Jak korzystać z akcji zbiorczych

1. Zaznacz kilka profili za pomocą pól wyboru
2. U góry pojawi się panel akcji zbiorczych
3. Wybierz akcję, którą chcesz zastosować

## Kiedy warto korzystać z akcji zbiorczych

Akcje zbiorcze są najbardziej przydatne, gdy musisz:

- Uruchomić wiele profili do codziennej pracy lub rozgrzewania kont (warm-up)
- Zaktualizować ustawienia w partiach
- Uporządkować profile w folderach i projektach
- Zarządzać dostępem członków zespołu
- Utrzymywać lub odświeżać fingerprinty na dużą skalę

## Co możesz zrobić za pomocą akcji zbiorczych

### **Uruchamianie profili**

Zaznacz profile i kliknij **Run profile**, aby uruchomić wszystkie wybrane profile.

Użyj tej opcji, aby uruchomić wiele kont do codziennej pracy lub sesji rozgrzewkowych.

<Note>
  Uruchomienie zbyt wielu profili naraz może wpłynąć na wydajność, w zależności od możliwości Twojego systemu.
</Note>

<Frame>
  ![Bulk Run Profiles](/images/bulk_run_profiles.gif)
</Frame>

### **Uruchamianie profili z synchronizacją**

Zaznacz profile i kliknij **Run with Sync**, aby uruchomić je z włączoną synchronizacją.

<Frame>
  ![Bulk Run With Sync](/images/bulk_run_with_sync.gif)
</Frame>

### **Zatrzymywanie profili**

Zaznacz uruchomione profile i kliknij **Stop profile**, aby je zamknąć.

<Frame>
  ![Bulk Stop Profiles](/images/bulk_stop_profiles-1.gif)
</Frame>

### **Dodawanie profili do folderu**

Zaznacz profile, kliknij **Add to Folder** i wybierz folder docelowy.

<Frame>
  ![Bulk Add Profiles To Folder](/images/bulk_add_profiles_to_folder-1.gif)
</Frame>

### **Przypisywanie lub zmiana proxy**

Zaznacz profile, kliknij **Proxy** i dodaj lub zaktualizuj ustawienia proxy dla wszystkich wybranych profili.

Upewnij się, że lokalizacja proxy zgadza się z ustawieniami profilu (kraj, strefa czasowa).

<Warning>
  Unikaj przypisywania tego samego proxy do wielu profili.
</Warning>

<Frame>
  ![Bulk Change Proxies](/images/bulk_change_proxies-1.gif)
</Frame>

### **Udostępnianie profili**

Zaznacz profile, kliknij **Share Profile** i przyznaj dostęp innemu użytkownikowi.

<Frame>
  ![Bulk Share Profiles](/images/bulk_share_profiles.gif)
</Frame>

### **Edycja tagów**

Zaznacz profile, kliknij **Edit tags** i zaktualizuj tagi dla wszystkich wybranych profili.

Używaj tagów, aby szybko filtrować i porządkować bardzo duże zbiory profili.

<Frame>
  ![Bulk Edit Tags](/images/bulk_edit_tags-1.gif)
</Frame>

### **Edycja rozszerzeń**

Zaznacz profile i kliknij **Edit extensions**, aby zarządzać rozszerzeniami w wybranych profilach.

<Frame>
  ![Bulk Edit Extensions](/images/bulk_edit_extensions.gif)
</Frame>

### **Edycja zakładek**

Zaznacz profile i kliknij **Edit bookmarks**, aby zaktualizować zakładki.

<Frame>
  ![Bulk Edit Bookmarks](/images/bulk_edit_bookmarks.gif)
</Frame>

### **Zmiana nazw profili**

Zaznacz profile i kliknij **Rename profiles**, aby zmienić ich nazwy zbiorczo.

<Frame>
  ![Bulk Rename Profiles](/images/bulk_rename_profiles-2.gif)
</Frame>

### **Klonowanie profili**

Zaznacz profile i kliknij **Clone**, aby utworzyć ich kopie.

<Frame>
  ![Bulk Clone Profiles](/images/bulk_clone_profiles.gif)
</Frame>

### **Przenoszenie profili**

Zaznacz profile i kliknij **Transfer**, aby przenieść je do innego workspace'u lub użytkownika, jeśli jest to dostępne w Twojej konfiguracji.

<Frame>
  ![Bulk Transfer Profiles](/images/bulk_transfer_profiles.gif)
</Frame>

### **Eksport profili**

Zaznacz profile i kliknij **Export profiles**, aby je wyeksportować.

<Frame>
  ![Bulk Export Profiles](/images/bulk_export_profiles.gif)
</Frame>

### **Aktualizacja fingerprintu**

Zaznacz profile i kliknij **Update fingerprint**, aby odświeżyć ustawienia fingerprintu.

<Frame>
  ![Bulk Update Fingerprint](/images/bulk_update_fingerprint.gif)
</Frame>

### **Usuwanie profili**

Zaznacz profile i kliknij **Delete**, aby je usunąć.

<Frame>
  ![Bulk Delete Profiles](/images/bulk_delete_profiles-1.gif)
</Frame>

### **Korzystanie z automatyzacji**

Zaznacz profile i kliknij **Automation**, aby zastosować akcje związane z automatyzacją.

<Frame>
  ![Bulk Use Automation](/images/bulk_use_automation.gif)
</Frame>

<Info>
  Akcje zbiorcze dotyczą jednocześnie wszystkich zaznaczonych profili.\
  Przed zastosowaniem jakiejkolwiek akcji upewnij się, że zaznaczono właściwe profile, zwłaszcza w przypadku opcji **Delete**, **Transfer** lub **Update fingerprint**.
</Info>
