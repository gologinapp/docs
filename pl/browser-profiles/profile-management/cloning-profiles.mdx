---
title: "Klonowanie profili"
---

Klonowanie pozwala utworzyć nowy profil na podstawie już istniejącego.

Jest to przydatne, gdy chcesz odtworzyć dane środowisko, zachowując rozdzielone konta.\
Sklonowane profile mogą dziedziczyć:

- parametry fingerprintu
- ustawienia przeglądarki
- konfigurację rozszerzeń

Następnie możesz zmienić serwer proxy lub inne parametry nowego profilu.

Aby sklonować istniejący profil:

1. Przejdź do **All profiles tab**
2. Znajdź profil, który chcesz zduplikować
3. Kliknij **three dots** obok profilu
4. Wybierz **Clone**

<Frame>
  ![Klonowanie profili](/images/cloning_profiles.gif)
</Frame>

Zostanie utworzony nowy profil ze skopiowaną konfiguracją.
