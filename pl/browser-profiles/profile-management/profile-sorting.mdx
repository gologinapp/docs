Profile na karcie **All profiles** możesz wygodnie układać za pomocą **Sorting** oraz **Drag-n-drop**.

## Sortowanie profili

Sortowanie pozwala uporządkować profile w tabeli **All profiles**.

W Gologin możesz sortować profile według **profile name, last updated, last launched, created, shared, proxy type and the profile OS.**

<Info>
  Domyślnie profile są sortowane według **Created descending** (najnowsze profile na górze)
</Info>

### Jak sortować profile

1. Przejdź na stronę **All Profiles**.
2. Znajdź odpowiednią kolumnę w tabeli profili.
3. Kliknij **ikonę sortowania** obok nazwy kolumny.
   - **↑ - Ascending** (A-Z, od najstarszych do najnowszych)\
     **↓ - Descending** (Z-A, od najnowszych do najstarszych)\
     **⇅ - Sorting disabled**
4. Kliknij ponownie, aby przełączać między opcjami **ascending**, **descending** i **disabling**.

## Układanie profili metodą Drag-n-drop

Ta funkcja pozwala dowolnie ułożyć profile na stronie All profiles, **niezależnie** od wybranego rodzaju sortowania.

Wystarczy przeciągnąć profile w wybrane miejsce.

### Jak korzystać z funkcji Drag and drop

1. **Wyłącz sortowanie profili**
   - upewnij się, że we wszystkich kolumnach widnieje **ikona ⇅**, w przeciwnym razie funkcja nie zadziała
2. **Przytrzymaj dłużej wybrany profil** i **przesuń go** powyżej lub poniżej obecnej pozycji

<Frame>
  ![Drag N Drop](/images/drag-n-drop.gif)
</Frame>

<Tip>
  Ułożenie wykonane metodą drag-n-drop jest zapamiętywane także po włączeniu sortowania. Gdy ponownie wyłączysz sortowanie, profile wrócą do poprzedniego, własnego układu. Nowe profile będą umieszczane nad dotychczasowymi.
</Tip>
