title: "Run with Sync"
---

Run with Sync uruchamia jednocześnie wiele profili przeglądarki i odwzorowuje Twoje działania we wszystkich z nich w czasie rzeczywistym. Wszystko, co zrobisz w głównym oknie — kliknięcie, wpisanie tekstu, przejście pod adres URL — dzieje się automatycznie w każdym pozostałym profilu w tym samym czasie.

Przydaje się to przy powtarzalnej pracy na kontach: rozgrzewaniu kont, wykonywaniu tej samej czynności w wielu profilach czy wypełnianiu identycznych formularzy. Zamiast przełączać się między oknami i powtarzać te same kroki, robisz to tylko raz.

<Warning>
  Strony internetowe wykrywają identyczne, jednoczesne zachowania na różnych kontach. Używaj Run with Sync tylko do zadań, w których identyczne działania są akceptowalne — rozgrzewania kont, wstępnej konfiguracji, przechodzenia pod adres URL — a nie do publikowania, wysyłania wiadomości ani żadnej aktywności, w której identyczna treść byłaby podejrzana.
</Warning>

## Jak z tego korzystać

### Krok 1 — Wybierz profile

Na liście profili zaznacz pola wyboru przy profilach, które chcesz uruchomić razem.

### Krok 2 — Kliknij Run with Sync

U góry ekranu pojawi się panel akcji zbiorczych. Kliknij Run with Sync.

Wszystkie wybrane profile otworzą się w osobnych oknach przeglądarki.

### Krok 3 — Pracuj w oknie lidera

Pierwszy profil na liście wybranych profili zostaje liderem. Wszystkie Twoje działania w jego oknie — kliknięcia, wpisywanie tekstu, nawigacja — są odwzorowywane w czasie rzeczywistym we wszystkich pozostałych otwartych profilach. Pozostałe profile są obserwatorami: powtarzają działania lidera, ale nie mogą nim sterować.

## Praktyczne zastosowania

**Rozgrzewanie kont:** Otwórz 10–20 nowych kont i wspólnie przeglądaj te same strony. Każdy profil przegląda niezależnie (inny fingerprint, inny adres IP), a Ty musisz nawigować tylko raz.

**Identyczna konfiguracja wielu kont:** Przejdź do stron ustawień, przełącz te same opcje, wypełnij te same pola informacji o profilu. Przydaje się to przy konfigurowaniu wielu świeżych kont o identycznej konfiguracji początkowej.

**Przechodzenie pod roboczy adres URL:** Gdy chcesz, aby wszystkie profile otworzyły określoną stronę, zanim zaczniesz pracować z każdym z nich osobno, przejdź pod adres raz, a wszystkie profile trafią tam jednocześnie.

**Testowanie zachowania fingerprintu w różnych profilach:** Otwórz strony testujące ([iphey.com](http://iphey.com), [pixelscan.net](http://pixelscan.net)) jednocześnie w wielu profilach, aby porównać wyniki obok siebie.

## Czego unikać

**Publikowania identycznych treści:** Jeśli wszystkie profile opublikują ten sam tekst, obraz lub link w tym samym czasie, platformy natychmiast powiążą te konta ze sobą. Używaj Run with Sync tylko do działań, w których identyczne zachowanie jest normalne — przeglądania, klikania, nawigacji — a nie do tworzenia treści.

**Wysyłania wiadomości i kontaktowania się z odbiorcami:** Jednoczesne wysyłanie identycznych wiadomości do tych samych osób z różnych kont to jeden z najszybszych sposobów na wywołanie automatycznej blokady wszystkich z nich.

**Logowania, gdy konta są nowe:** Każdy profil może wyświetlać inne monity 2FA, CAPTCHA lub kroki weryfikacji podczas logowania. Synchronizator odwzoruje Twoje działania, ale nie poradzi sobie z rozbieżnymi stanami — jeden profil może być na CAPTCHA, a inny może być już zalogowany. Zaloguj się na każde konto osobno, zanim włączysz synchronizator.

## Zatrzymywanie profili

Aby zamknąć wszystkie profile uruchomione za pomocą Run with Sync:

1. Zaznacz wszystkie uruchomione profile za pomocą pól wyboru
2. Kliknij **Stop profiles** w panelu akcji zbiorczych

<Frame>
  ![0331(1)(1)](/images/0331\(1\)\(1\).gif)
</Frame>

Możesz też zamknąć każde okno przeglądarki osobno. Gologin zsynchronizuje dane każdego profilu podczas jego zamykania.

<Warning>
  Zanim zamkniesz aplikację Gologin, poczekaj, aż każdy profil wyświetli status **Ready**. Zamknięcie Gologin, gdy profile nadal się synchronizują, spowoduje utratę danych z tych sesji.
</Warning>

## Różnice w porównaniu ze zwykłym Run (zbiorczo)

|  | Run (zbiorczo) | Run with Sync |
| :-- | :-- | :-- |
| Profile działają niezależnie | ✅ | ❌ |
| Działania są odwzorowywane w oknach | ❌ | ✅ |
| Najlepsze do | Otwierania profili do osobnej pracy | Powtarzania tych samych działań we wszystkich profilach |

Używaj zwykłego **Run**, gdy chcesz otworzyć wiele profili, a następnie pracować z każdym z nich osobno. Używaj **Run with Sync**, gdy chcesz wykonać dokładnie te same działania we wszystkich profilach jednocześnie.
