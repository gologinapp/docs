Giełdy kryptowalut i portfele (Binance, Coinbase, Kraken i inne) łączą każde konto z prawdziwą osobą poprzez weryfikację tożsamości (KYC). Po weryfikacji giełda obserwuje, skąd i w jaki sposób się logujesz, więc nagła zmiana adresu IP lub urządzenia może wywołać kontrolę bezpieczeństwa, dodatkową weryfikację lub zablokowanie konta.

<Warning>
  Przechodź weryfikację wyłącznie przy użyciu własnych dokumentów tożsamości. Wykorzystywanie cudzej tożsamości lub cudzych dokumentów jest zabronione przez [Acceptable Use Policy](https://gologin.com/acceptable-use-policy/).
</Warning>

## Szybka lista kontrolna

- 1 konto = 1 profil przeglądarki
- 1 profil = 1 statyczne proxy rezydencjalne
- Utrzymuj tę samą lokalizację proxy, zwłaszcza po weryfikacji
- Nie zmieniaj odcisku przeglądarki (fingerprint) ani proxy po weryfikacji tożsamości

## Konfiguracja profilu Gologin

- **Proxy:** statyczne rezydencjalne, ten sam adres IP przy każdej sesji
- **Lokalizacja proxy:** kraj, w którym mieszkasz i który widnieje w Twoich dokumentach

<Warning>
  Nie zmieniaj proxy w profilu po przejściu weryfikacji na giełdzie. Giełda zapamiętuje Twoje urządzenie i adres IP z momentu weryfikacji, a inny adres IP lub odcisk przeglądarki (fingerprint) przy kolejnym logowaniu może wyglądać jak przejęcie konta.
</Warning>

## Pierwsze tygodnie nowego konta

| **Okres** | **Cel** | **Co zrobić** |
| :-- | :-- | :-- |
| Dzień 0 | Rejestracja | Załóż konto i potwierdź adres e-mail |
| Dni 1–3 | Weryfikacja | Prześlij dokumenty tożsamości i dokończ weryfikację |
| Dni 4–7 | Zapoznanie z platformą | Przeglądaj platformę i interfejs handlowy |
| Tydzień 2 | Małe transakcje | Wpłać niewielką kwotę, wykonaj 1–2 transakcje |
| Tydzień 3\+ | Normalne korzystanie | Regularna aktywność handlowa |

## Co wywołuje kontrole bezpieczeństwa

- Zmiana adresu IP po weryfikacji, nawet w obrębie tego samego kraju
- Odcisk urządzenia (fingerprint) różniący się między sesjami
- Duże wpłaty tuż po założeniu konta
