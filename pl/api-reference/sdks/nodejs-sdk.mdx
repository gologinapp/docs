### Instalacja

```bash
npm i gologin
```

Wymaga Node.js w wersji 20 lub nowszej. Wersja 3 pakietu SDK jest dostępna wyłącznie jako ESM: ładuj ją za pomocą `import`, ponieważ `require('gologin')` nie działa.

### Podstawowe użycie

```javascript
import GoLogin from 'gologin';

const GL = new GoLogin({
  token: 'your-api-token',
  profile_id: 'your-profile-id',
});

const { status, wsUrl } = await GL.start();
// Connect Puppeteer or Playwright using wsUrl
// ... your automation code ...
await GL.stop();
```

### Uruchamianie za pomocą GologinApi

`GologinApi` uruchamia profil i automatycznie podłącza Puppeteer. Metoda `launch()` zwraca obiekt `browser` z Puppeteera. Przekaż `cloud: true`, aby uruchomić profil w [Gologin Cloud Browser](/pl/api-reference/cloud-browser/what-is-gologin-cloud-browser) zamiast w lokalnej przeglądarce Orbita:

```javascript
import { GologinApi } from 'gologin';

const gologin = GologinApi({ token: 'your-api-token' });

// local Orbita on this machine
const { browser } = await gologin.launch({ profileId: 'your-profile-id' });

// or Gologin Cloud Browser
// const { browser } = await gologin.launch({ cloud: true, profileId: 'your-profile-id' });

const page = await browser.newPage();
await page.goto('https://example.com');

// close the browser and stop the profile
await gologin.exit();
```

Jeśli nie podasz `profileId`, `launch()` najpierw utworzy nowy profil. `GologinApi` udostępnia również funkcje pomocnicze, takie jak `createProfileRandomFingerprint()`, `addGologinProxyToProfile()`, `addCookiesToProfile()` i `deleteProfile()`. Pełny przykład znajdziesz w [Quickstart](/pl/api-reference/introduction/quickstart).

### Najważniejsze parametry

| Parametr | Wartość domyślna | Opis |
|---|---|---|
| `token` | wymagany | Twój token API Gologin |
| `profile_id` | wymagany | Identyfikator profilu do uruchomienia |
| `executablePath` | auto | Ścieżka do pliku wykonywalnego przeglądarki Orbita |
| `uploadCookiesToServer` | `false` | Przesyła pliki cookie do chmury po zatrzymaniu profilu. Ustaw na `true`, jeśli potrzebujesz zachować sesję na różnych urządzeniach. |
| `extra_params` | `[]` | Dodatkowe flagi Chromium przekazywane do przeglądarki |

### Zatrzymywanie profili

```javascript
// Stop and sync to cloud
await GL.stop();

// Stop without syncing profile data to cloud
await GL.stopLocal({ posting: false });
```

Najpierw zamknij przeglądarkę w narzędziu do automatyzacji, na przykład za pomocą `browser.close()`. Metoda `stop()` nie przyjmuje żadnych opcji i zawsze przesyła profil do Gologin. Metoda `stopLocal({ posting: false })` kończy sesję bez przesyłania danych profilu. Używaj jej na serwerach, na których nie chcesz synchronizacji z chmurą. Pliki cookie nadal zostaną przesłane, jeśli ustawisz `uploadCookiesToServer: true`.

### Zarządzanie wersjami przeglądarki Orbita

Przy uruchamianiu profilu SDK sprawdza, jakiej wersji Orbita wymaga user agent danego profilu. Jeśli tej wersji nie ma jeszcze w `~/.gologin/browser`, SDK ją pobiera, a w przeciwnym razie używa zainstalowanej kopii. Aby uruchomić konkretną wersję, przekaż `executablePath`. Opcje `autoUpdateBrowser` (domyślnie `false`) i `checkBrowserUpdate` są nadal akceptowane, ale w obecnej wersji SDK (3.0.7) nie zmieniają tego zachowania.

Aby pobrać Orbita z wyprzedzeniem, wywołaj `checkAndDownloadBrowserByOpts()` na instancji `GoLogin`. To metoda, a nie osobny eksport:

```javascript
import { GoLogin } from 'gologin';

const GL = new GoLogin({ token: 'your-api-token' });

// Pre-download the latest Orbita version
await GL.checkAndDownloadBrowserByOpts({ lastActualCount: 1 });

// Pre-download specific versions
await GL.checkAndDownloadBrowserByOpts({ majorVersions: [142, 143] });
```

Bez podania opcji metoda pobiera 5 najnowszych wersji. Użyj jej przed równoległym uruchamianiem profili, aby uniknąć wielu jednoczesnych pobrań.

### Równoległe uruchamianie ponad 100 profili

Gdy na serwerze uruchamiasz jednocześnie wiele profili:

```javascript
// Use a queue to limit concurrent launches
const CONCURRENCY = 10;
const queue = [...profileIds];
const active = new Set();

async function launchProfile(profileId) {
  const gl = new GoLogin({ token, profile_id: profileId });
  try {
    const { wsUrl } = await gl.start();
    // ... your automation ...
  } finally {
    await gl.stop();
  }
}

async function processQueue() {
  while (queue.length > 0) {
    while (active.size >= CONCURRENCY) {
      await new Promise(r => setTimeout(r, 1000));
    }
    const id = queue.shift();
    active.add(id);
    launchProfile(id).finally(() => active.delete(id));
  }
}
```

**Ważne w przypadku serwerów:**
- Ogranicz liczbę jednocześnie uruchamianych profili (na początek zalecamy 10-20)
- Pobierz wersje Orbita przed uruchomieniem profili
- W systemie Linux: zainstaluj Xvfb i ustaw `DISPLAY=:99`
- Zwiększ limity deskryptorów plików: `ulimit -n 65536`
- Monitoruj pamięć RAM: każdy profil zajmuje ok. 300-500 MB

### Debugowanie

Ustaw zmienną środowiskową, aby włączyć szczegółowe logowanie:

```bash
DEBUG=gologin node your-script.js
```
