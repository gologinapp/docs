---
title: 'Limity zapytań'
---
Gologin API ogranicza liczbę zapytań, które możesz wysłać w ciągu minuty. Jeśli przekroczysz limit, odczekaj, zanim wyślesz kolejne zapytania.

Limit zależy od Twojego planu:

| Plan | Zapytania na minutę |
| :-- | --: |
| Professional | 300 |
| Business | 500 |
| Enterprise | 800 |
| Custom | 1,200 |

Plan próbny i plan Forever Free nie obejmują dostępu do API. Zobacz [Pricing](/pl/general/account-and-billing/pricing), aby sprawdzić, co zawiera każdy plan.

### Unieważnienie tokena po przekroczeniu limitu

<Warning>
Jeśli przekroczysz limit zapytań i otrzymasz odpowiedź HTTP 429, Twój token API zostanie automatycznie unieważniony. Oznacza to, że token przestaje działać na stałe i musisz wygenerować nowy.

To nie jest tymczasowa blokada — token zostaje odwołany. Zaplanuj starannie częstotliwość zapytań i wdróż wykładniczy backoff (exponential backoff), aby tego uniknąć.
</Warning>

### Błędy ochrony Cloudflare

Jeśli adres IP Twojego serwera wysyła zbyt wiele zapytań, sieć CDN Cloudflare używana przez Gologin może całkowicie zablokować ten adres IP. W takiej sytuacji zamiast JSON API zwraca strony błędów w formacie HTML, co powoduje błędy takie jak:

```
SyntaxError: Unexpected token 'e', "error code: 1015" is not valid JSON
```

To odpowiedź Cloudflare 1015 informująca o przekroczeniu limitu zapytań. Zwykle problem ustępuje samoistnie w ciągu od kilku minut do kilku godzin. Aby go uniknąć:
- Wprowadź w kodzie ograniczanie liczby zapytań
- Stosuj wykładniczy backoff po nieudanych zapytaniach
- Unikaj nagłych serii równoległych wywołań API

### Limity tworzenia profili

Nowe konta mają limit około 300 utworzonych profili dziennie. Limit ten może się różnić w zależności od planu. Jeśli potrzebujesz wyższych limitów, skontaktuj się z pomocą techniczną.
