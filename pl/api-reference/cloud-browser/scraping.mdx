## Przegląd

Gologin Cloud Browser może służyć jako zarządzana zdalna przeglądarka do scrapingu i pobierania danych. Twój kod automatyzujący (Puppeteer) łączy się ze zdalną sesją przeglądarki przez endpoint WebSocket, a następnie wykonuje standardową logikę nawigacji i pobierania danych.

Cloud Browser stanowi warstwę połączenia i wykonywania, a ustawieniami profilu i proxy zarządza się przez REST API. Takie rozwiązanie może zmniejszyć nakłady na infrastrukturę i pomóc ograniczyć problemy ze scrapingiem, ale wyniki zależą od zachowania i zabezpieczeń docelowej witryny.

## Co otrzymujesz

- Zdalne sesje przeglądarki dla połączeń Puppeteer.
- Renderowanie JavaScript dla dynamicznych stron.
- Skalowanie bez konieczności utrzymywania własnej infrastruktury przeglądarek.
- Konfigurację profili i proxy zarządzaną przez API.
- Jeden kanoniczny endpoint połączenia do uruchamiania sesji.

## Typowy przebieg pracy

1. Wygeneruj token API.
2. Opcjonalnie utwórz lub skonfiguruj profil (oraz proxy) przez REST API.
3. Zbuduj adres URL połączenia z parametrem `token` i opcjonalnym parametrem `profile`.
4. Połącz się z poziomu Puppeteer/Playwright i uruchom pobieranie danych.
5. Zapisz wyniki i zamknij sesję przeglądarki.

## Wymagania wstępne

- Utwórz token: w aplikacji Gologin otwórz [API & MCP](https://app.gologin.com/personalArea/TokenApi) → **API** → **New Token**
- API profili (zalecane do kontrolowanej konfiguracji): [Utwórz profil](https://gologin.com/docs/api-reference/profile/create-profile-with-partial-parameters), [Zaktualizuj profil](https://gologin.com/docs/api-reference/profile/update-profile-with-partial-parameters)
- API proxy: [Dodaj proxy Gologin do profilu](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy), [Ustaw własne proxy w profilach](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles)

## Kanoniczny endpoint połączenia

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${profileId}
```

- Parametr `token` jest wymagany.
- Parametr `profile` jest opcjonalny.
- Jeśli pominiesz `profile`, na potrzeby sesji zostanie utworzony nowy profil.

## Minimalny przykład dla Puppeteer

```javascript
const puppeteer = require('puppeteer-core');

(async () => {


  const token = 'your_token_here';
  const profileId = 'your_profile_id'; // Set to '' to create a new profile for this session
  const cloudBrowserUrl = `https://cloudbrowser.gologin.com/connect?token=${token}${profileId ? `&profile=${profileId}` : ''}`;
  const browser = await puppeteer.connect({
  
    browserWSEndpoint: cloudBrowserUrl,
    defaultViewport: null
  
  });

  const page = await browser.newPage();
  await page.goto('https://example.com');
  const title = await page.title();
  console.log('Page title:', title);
  await page.screenshot({ path: 'screenshot.png' });
  await browser.close();

})();
```

## Najlepsze praktyki

- Preferuj jawne oczekiwanie na zdarzenia zamiast stałych opóźnień.
- Zaimplementuj ponawianie prób z ograniczonym opóźnieniem między próbami i losowym rozrzutem (jitter).
- Zapisuj ustrukturyzowane wyniki pobierania danych (URL, pola, znacznik czasu, status).
- Skonfiguruj profil i proxy przed nawiązaniem połączenia, aby zapewnić powtarzalność.
- Zawsze zamykaj sesje i obsługuj czyszczenie zasobów w przypadku błędów.
- Dostosuj zachowanie żądań i sesji do ograniczeń docelowej witryny.

## FAQ

### Czy potrzebuję profilu?

Nie. Parametr `profile` jest opcjonalny. Jeśli go pominiesz, na potrzeby sesji zostanie utworzony nowy profil. Profilu warto użyć, gdy potrzebujesz kontrolowanej i powtarzalnej konfiguracji.

### Gdzie skonfigurować proxy?

Proxy konfiguruje się przez REST API: [dodaj proxy Gologin do profilu](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy) lub [ustaw własne proxy w profilach](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles).

### Czy to coś innego niż Cloud Browser?

Nie. To strona o wykorzystaniu samego Cloud Browser do scrapingu i pobierania danych. Cloud Browser odpowiada za połączenie i wykonywanie, a ustawieniami profilu i proxy zarządza się przez REST API.
