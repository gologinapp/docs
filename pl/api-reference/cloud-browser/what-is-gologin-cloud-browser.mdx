Gologin Cloud Browser pozwala uruchomić przeglądarkę Gologin (Orbita) **w chmurze** i sterować nią z poziomu kodu automatyzacji (Puppeteer / Playwright) za pomocą jednego **adresu URL połączenia**.

Jest to [przeglądarka headless](./what-is-headless-browser) — przeglądarka sterowana w całości przez kod, bez interfejsu graficznego — hostowana i zarządzana przez Gologin, z wbudowaną obsługą trwałych profili, konfiguracji fingerprintu i routingu przez proxy.

## Co możesz zrobić z Cloud Browser

- Uruchamiać wiele sesji przeglądarki równolegle w chmurze
- Automatyzować pracę w swoim obecnym środowisku (Puppeteer / Playwright)
- Używać **profili** Gologin do zachowywania trwałego stanu (logowania, pliki cookie, pamięć lokalna)
- Kierować ruch przez **proxy**, konfigurując je w profilu
- Używać jej z agentami AI jako zdalnego środowiska przeglądarki

## Czym różni się od standardowej przeglądarki headless

Standardowa przeglądarka Chrome w trybie headless jest łatwa do wykrycia. Strony internetowe wykorzystują fingerprinting przeglądarki do rozpoznawania ruchu automatycznego — sprawdzają renderowanie canvas, parametry WebGL, czcionki, strefę czasową, rozmiar ekranu i dziesiątki innych sygnałów.

Gologin Cloud Browser działa na **Orbita** — zmodyfikowanej przeglądarce Chromium, która zarządza sygnałami fingerprintu tak, aby odpowiadały spójnemu, realistycznemu profilowi przeglądarki. Dzięki trwałym plikom cookie i konfiguracji proxy zapisanym w każdym profilu Twoje sesje wyglądają stabilnie i naturalnie przy kolejnych odwiedzinach.

## Dlaczego Gologin Cloud Browser

### Wbudowana ochrona anti-detect — bez dodatkowych wtyczek

Standardowa przeglądarka Chrome w trybie headless jest banalnie łatwa do wykrycia. Inne usługi cloud browser uruchamiają zwykły Chromium i wymagają zewnętrznych wtyczek stealth, aby ograniczyć sygnały fingerprintu — z różnym skutkiem.

Gologin Cloud Browser działa na **Orbita**, wzmocnionej wersji Chromium, w której zarządzanie fingerprintem jest podstawą działania: canvas, WebGL, czcionki, strefa czasowa, rozdzielczość ekranu i nie tylko. Anti-detect nie jest nakładką — to sama przeglądarka.

### Trwałe profile — sesje, które pamiętają

Większość usług cloud browser traktuje każdą sesję jako bezstanową. Pliki cookie i dane przeglądarki są usuwane po zamknięciu sesji.

Profile Gologin są trwałe. Zaloguj się raz, zamknij sesję, połącz się ponownie później — profil zachowa pliki cookie, local storage i wszystkie skonfigurowane ustawienia. Bez ponownego logowania i bez „rozgrzewania" sesji.

### Brak uzależnienia od dostawcy

Gologin Cloud Browser to standardowy punkt końcowy CDP. Twój kod Puppeteer lub Playwright łączy się z nim tak samo, jak z dowolną zdalną instancją Chrome — bez własnościowego SDK i bez konieczności uczenia się specjalnego API. Przejście na to rozwiązanie lub z niego wymaga zmiany jednego adresu URL.

## Typowe scenariusze techniczne

Cloud Browser jest zwykle używany w przepływach pracy, w których:

- logujesz się raz na konto internetowe i utrzymujesz trwałą sesję za pomocą profilu
- wykonujesz powtarzalne działania na tych samych stronach w wielu profilach
- potrzebujesz stabilnych, długotrwałych sesji bez zależności od lokalnego komputera

Przykłady to automatyzacja zalogowanych sesji w aplikacjach internetowych, na marketplace'ach lub platformach społecznościowych, gdzie liczy się trwałość i spójne ustawienia profilu.

## Podstawowe pojęcia

- **Profil** — wielokrotnego użytku tożsamość przeglądarki (pliki cookie/dane przeglądarki oraz ustawienia fingerprintu i proxy).
- **Sesja w chmurze** — uruchomiona instancja profilu w chmurze Gologin.
- **Connect URL** — punkt końcowy, który przekazujesz do narzędzia automatyzacji, aby sterować sesją w chmurze.

## Jak to działa (w skrócie)

1. (Zalecane) Utwórz i skonfiguruj profil za pomocą Gologin REST API (proxy, fingerprint itd.).
2. Połącz się z Cloud Browser, używając swojego **dev token** i opcjonalnie `profileId`.
3. Zautomatyzuj sesję za pomocą Puppeteer lub Playwright.
4. Zamknij połączenie po zakończeniu pracy.

## Adres URL połączenia

Użyj tego adresu URL jako zdalnego punktu końcowego przeglądarki:

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${profileId}
```

- `token` — Twój **dev token** Gologin (utwórz go w aplikacji Gologin: [API & MCP](https://app.gologin.com/personalArea/TokenApi) → **API** → **New Token**).
- `profile` — **identyfikator profilu** (opcjonalnie). Jeśli go pominiesz, na potrzeby sesji zostanie utworzony nowy profil.

## Zarządzanie profilami (proxy, fingerprint itd.)

Cloud Browser jest **warstwą połączenia**.\
Aby tworzyć i aktualizować profile, przypisywać proxy oraz konfigurować ustawienia profilu, użyj Gologin REST API:

- Profiles API: [Create profile](https://gologin.com/docs/api-reference/profile/create-profile-with-partial-parameters), [Update profile](https://gologin.com/docs/api-reference/profile/update-profile-with-partial-parameters)
- Proxy API: [Add a Gologin proxy to a profile](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy), [Set your own proxy on profiles](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles)

## Korzystanie z Cloud Browser w CLI

Jeśli wolisz polecenia powłoki od pisania kodu Puppeteer/Playwright, Gologin udostępnia narzędzia CLI przyjazne dla agentów:

- **[Gologin Agent Browser CLI](/pl/cli-tools/agent-browser)** — CLI do cloud browser z demonem, migawkami stron i interakcją opartą na odwołaniach (ref). Stworzone z myślą o agentach AI.
- **[Gologin Web Access CLI](/pl/cli-tools/web-access)** — zunifikowane CLI łączące scraping z Web Unlocker z interakcją z Cloud Browser w jednym narzędziu.

```bash
npm install -g gologin-agent-browser-cli
export GOLOGIN_TOKEN='your_token'

gologin-agent-browser open https://example.com
gologin-agent-browser snapshot
gologin-agent-browser click @e3
gologin-agent-browser screenshot ./page.png
gologin-agent-browser close
```
