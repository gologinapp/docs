Gologin AI Skills to gotowe do użycia rozszerzenia dla [Claude Code](https://claude.ai/code), które dają agentom AI możliwości web scrapingu i automatyzacji przeglądarki. Każdy skill opakowuje narzędzie Gologin CLI i udostępnia je jako zestaw funkcji wywoływanych przez agenta.

```
agent → skill → Gologin CLI → Web Unlocker API / Cloud Browser / Local Orbita
```

## Instalacja

Wszystkie skille Gologin instalują się z repozytorium [GologinLabs/agent-skills](https://github.com/GologinLabs/agent-skills):

```bash
# install any skill
npx skills add GologinLabs/agent-skills@gologin-web-access-skill
npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill
npx skills add GologinLabs/agent-skills@gologin-scraping-skill
```

Każdy skill wymaga zainstalowania odpowiadającego mu CLI:

| Skill | Wymagane CLI |
|---|---|
| Web Access Skill | `npm i -g gologin-web-access` |
| Agent Browser Skill | `npm i -g gologin-agent-browser-cli` (środowiska cloud i local) |
| Scraping Skill | `npm i gologin-webunlocker` |

## Web Access Skill

**Instalacja:** `npx skills add GologinLabs/agent-skills@gologin-web-access-skill`

Domyślny i najbardziej wszechstronny skill. Deleguje zadania do CLI `gologin-web-access`.

**Narzędzia do scrapingu:** `scrape_url`, `read_page`, `scrape_markdown`, `scrape_text`, `scrape_json`, `batch_scrape`, `batch_extract`, `search_web`, `map_site`, `crawl_site`, `crawl_site_async`, `extract_structured`, `track_changes`, `batch_track_changes`, `parse_document`

**Narzędzia przeglądarki:** `browser_open`, `browser_search`, `browser_snapshot`, `browser_click`, `browser_type`, `browser_screenshot`, `browser_close`, `browser_sessions`, `browser_current`

**Wbudowane workflowy:** browser-ref-loop, hybrid-read-then-interact, search-discover-and-scrape, lead-enrichment, competitive-monitoring, docs-ingestion, geo-testing, login-and-navigate-dashboard

Pełne informacje o poleceniach znajdziesz w [dokumentacji Web Access CLI](/pl/cli-tools/web-access).

## Agent Browser Skill

**Instalacja:** `npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill`

Skill wyłącznie do przeglądarki, obsługujący sesje na żywo w Gologin Cloud Browser (domyślnie) lub w lokalnych profilach Orbita z opcją `--runtime local`. Używaj go, gdy potrzebujesz interaktywnego przeglądania bez scrapingu.

**Możliwości:** `doctor`, `open`, `sessions`, `current`, `snapshot`, `click`, `type`, `fill`, `find`, `get`, `tabs`, `tabopen`, `tabfocus`, `tabclose`, `cookies`, `cookies-import`, `storage-export`, `storage-import`, `eval`, `back`, `forward`, `reload`, `upload`, `screenshot`, `pdf`

**Środowisko local dodaje:** zarządzanie profilami (`profiles`, `profile-create`, `profile-import`, `profile-update`, `profile-sync`, `profile-delete`), runbooki (`run`, `batch`), zadania (`jobs`, `job`), szablony dla konkretnych zastosowań (`linkedin`, `ads`, `smm`, `scraping`, `geo`) oraz diagnostykę (`doctor --use-case --check-proxy`).

Pełne informacje o poleceniach znajdziesz w [dokumentacji Agent Browser CLI](/pl/cli-tools/agent-browser) oraz w sekcji [Local runtime](/pl/cli-tools/local-agent-browser).

## Scraping Skill

**Instalacja:** `npx skills add GologinLabs/agent-skills@gologin-scraping-skill`

Najmniejszy skill — wyłącznie scraping przez Web Unlocker SDK. Bez sesji przeglądarki i bez demona.

**Możliwości:** surowy HTML (`scrape`), tekst (`text`), markdown (`markdown`), ustrukturyzowane metadane (`json`). Metody SDK: `scrapeRaw()`, `scrape()`, `scrapeText()`, `scrapeMarkdown()`, `scrapeJSON()`, `batchScrape()`.

Używaj go, gdy zadanie dotyczy wyłącznie scrapingu i zależy Ci na mniejszej liczbie zależności.

Szczegóły API znajdziesz w [dokumentacji Web Unlocker SDK](/pl/scraping-api-sdk-and-cli).

## O co możesz poprosić swojego agenta

Po zainstalowaniu skilla rozmawiasz z Claude Code w języku naturalnym. Oto, co umożliwia każdy ze skilli:

### Z Web Access Skill

- „Przeczytaj stronę z cennikiem na competitor.com i podsumuj plany"
- „Zescrapuj te 15 adresów URL i wyciągnij z każdego nazwę produktu oraz cenę"
- „Zrób crawl dokumentacji na docs.example.com i przygotuj podsumowanie każdej sekcji"
- „Wyszukaj »best CRM tools 2026« i zescrapuj 5 pierwszych wyników"
- „Sprawdź, czy competitor.com/pricing zmieniło się od wczoraj"
- „Wyciągnij tytuły i adresy URL wszystkich artykułów blogowych z tej witryny"
- „Otwórz example.com w przeglądarce, zaloguj się tymi danymi i zrób zrzut ekranu panelu"

### Z Agent Browser Skill

- „Otwórz panel administracyjny, przejdź do Settings i zrób zrzut ekranu aktualnej konfiguracji"
- „Zaloguj się do środowiska stagingowego i sprawdź, czy nowa funkcja została wdrożona"
- „Wypełnij formularz rejestracji na example.com tymi danymi testowymi"
- „Przejdź na stronę raportów, pobierz miesięczny eksport i zrób zrzut ekranu podsumowania"
- „Sprawdź, co iphey.com pokazuje dla tego profilu przeglądarki"

### Ze Scraping Skill

- „Zescrapuj ten adres URL i podaj mi treść tekstową"
- „Pobierz tytuł, opis i nagłówki z tych 10 stron"

### Z Agent Browser Skill (środowisko local)

- „Utwórz nowy profil LinkedIn z proxy z USA i rozgrzej go"

## Przykładowe workflowy

### Analiza konkurencji (Web Access Skill)

1. Agent wyszukuje konkurentów: `search_web("saas project management tools")`
2. Agent mapuje witrynę konkurenta: `map_site("https://competitor.com")`
3. Agent zbiorczo scrapuje kluczowe strony: `batch_scrape(pricing, features, about)`
4. Agent przekazuje treść do Claude w celu analizy i porównania

### Rozgrzewanie kont (Agent Browser Skill, środowisko local)

1. Agent tworzy profile: `profile-create "Account 1" --template linkedin`
2. Agent uruchamia runbook rozgrzewania: `batch ./warmup.json --targets ./profiles.json`
3. Agent sprawdza wyniki zadań: `jobs --kind batch --status ok`
4. Agent raportuje, które profile są gotowe

### Monitorowanie panelu (Agent Browser Skill)

1. Agent otwiera panel: `open https://dashboard.example.com --profile saved_login`
2. Agent odczytuje stronę: `snapshot`
3. Agent przechodzi do metryk: `click @e5` (link Reports)
4. Agent robi zrzut ekranu raportu: `screenshot ./daily-metrics.png`
5. Agent zamyka sesję: `close`
6. Agent podsumowuje metryki na podstawie danych ze snapshotu

## Obowiązkowa kontrola wstępna

Przed uruchomieniem jakiegokolwiek zadania skille klasyfikują pracę:

1. **Jedna znana witryna czy szeroki research z wielu źródeł?** — określa, czy potrzebny jest scraping, czy wyszukiwanie
2. **Wyłącznie odczyt danych, monitorowanie czy interaktywna praca w przeglądarce?** — określa wybór między scrapingiem a przeglądarką
3. **Tylko Web Unlocker, czy Web Unlocker i Cloud Browser?** — określa wymagane dane uwierzytelniające
4. **Czy zadanie zależy od geolokalizacji lub jest na tyle blokowane, że wymaga pełnego użycia Gologin?** — określa wymagania dotyczące proxy i profilu
