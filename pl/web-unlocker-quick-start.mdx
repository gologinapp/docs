title: "Szybki start"
---

Ten przewodnik pokazuje, jak pobrać dane z pierwszego adresu URL za pomocą Web Unlocker.

---

## Wymagania wstępne

- Klucz API Web Unlocker. Otrzymasz go, wypełniając formularz na [stronie Web Unlocker](https://gologin.com/web-unlocker/#web_unlocker_form). Klucz dotrze w ciągu jednego dnia roboczego, wraz z darmowymi zapytaniami do przetestowania na własnych celach. Karta nie jest wymagana.
- Python 3.x, Node.js lub dowolny klient HTTP

---

## Uwierzytelnianie

Każde zapytanie wymaga podania klucza API w nagłówku `apikey`:

```
apikey: YOUR_API_KEY
```

Bazowy adres URL dla wszystkich zapytań API to:

```
https://parsing.webunlocker.gologin.com/v1
```

---

## Wyślij pierwsze zapytanie

Wyślij zapytanie GET z docelowym adresem URL jako parametrem zapytania. W odpowiedzi otrzymasz w pełni wyrenderowany kod HTML strony.

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.text)
```

### JavaScript (Node.js / Browser)

```javascript
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(html);
```

---

## Co otrzymasz w odpowiedzi

Treścią odpowiedzi jest surowy, wyrenderowany kod HTML strony — dokładnie to, co zobaczyłbyś po otwarciu adresu URL w przeglądarce. Bez opakowania w JSON i bez konieczności parsowania.

```html
<!DOCTYPE html>
<html>
  <head><title>Example Domain</title></head>
  <body>...</body>
</html>
```

### Inne formaty

Dodaj parametr zapytania `format`, aby otrzymać stronę w innym formacie:

| `format` | Treść odpowiedzi |
|---|---|
| `html` | Kod HTML strony (domyślnie) |
| `markdown` | Treść strony w formacie Markdown |
| `json` | Obiekt JSON z adresem URL, metadanymi zapytania i kodem HTML strony |

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com&format=json" \
  -H "apikey: YOUR_API_KEY"
```

```json
{
  "success": true,
  "data": {
    "url": "https://example.com",
    "metadata": {
      "response_time_ms": 297,
      "status_code": 200
    },
    "html": "<!DOCTYPE html><html lang=\"en\">..."
  }
}
```

---

## Obsługa błędów

Przed przetworzeniem odpowiedzi sprawdź kod statusu HTTP:

| Status | Znaczenie | Treść odpowiedzi |
|---|---|---|
| `200` | Sukces | Strona w żądanym formacie |
| `400` | Nieprawidłowe zapytanie, na przykład brakuje parametru `url` | `{"success":false,"error":"Request failed"}` |
| `401` | Brakuje nagłówka `apikey` | `{"message":"Missing API key in request"}` |

Jeśli otrzymasz status `429` lub `5xx`, ponów zapytanie, stosując wykładniczy backoff.

```python
response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

if response.status_code == 200:
    html = response.text
else:
    print(f"Error {response.status_code}: {response.text}")
```

## Szybki start z CLI

Strony możesz też pobierać za pomocą narzędzi CLI Gologin, bez pisania kodu:

### Web Unlocker CLI

```bash
npm install -g gologin-webunlocker

GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker scrape https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker markdown https://example.com
```

### Gologin Web Access CLI (zunifikowane)

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."
gologin-web-access read https://example.com
gologin-web-access scrape-json https://example.com
gologin-web-access batch-scrape https://example.com/page/1 https://example.com/page/2 --format text
```

Więcej szczegółów znajdziesz w artykułach [Web Unlocker SDK i CLI](/pl/scraping-api-sdk-and-cli) oraz [Web Access CLI](/pl/cli-tools/web-access).
