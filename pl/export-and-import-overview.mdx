---
title: "Przegląd eksportu i importu"
---

Import i eksport CSV to prosty sposób na zarządzanie wieloma profilami przeglądarki jednocześnie. Zamiast konfigurować wszystko ręcznie, możesz użyć pliku CSV, aby kopiować konfiguracje, tworzyć profile zbiorczo, aktualizować ustawienia, takie jak proxy, oraz przenosić konfiguracje między workspace'ami. Jest to szczególnie przydatne, gdy pracujesz na dużą skalę lub zależy Ci na spójności profili albo konfiguracji w zespole.

Eksport i import CSV przenosi **konfigurację profilu**: nazwę, notatki, proxy, pliki cookie, zakładki, rozszerzenia oraz ustawienia fingerprintu. Foldery, tagi i status nie są uwzględniane.

### Co możesz zrobić dzięki CSV

- Utworzyć wiele profili naraz
- Kopiować i ponownie wykorzystywać konfiguracje profili
- Zbiorczo aktualizować proxy i ustawienia
- Utrzymywać spójne konfiguracje w zespole
- Przenosić konfiguracje między workspace'ami

### Co jest uwzględniane, a co nie

**Uwzględnione:**

- Nazwa profilu i notatki
- Ustawienia proxy (w tym login i hasło do proxy)
- Pliki cookie
- Zakładki i rozszerzenia
- Start URL
- Ustawienia środowiska i fingerprintu: system operacyjny, user agent, język, strefa czasowa, geolokalizacja, WebRTC, WebGL, Canvas, czcionki, rozdzielczość ekranu itd.

**Nieuwzględnione:**

- Foldery, tagi i status
- Historia przeglądania, local storage i zapisane hasła

### Warto pamiętać

- Import tworzy **nowe profile** z nowymi identyfikatorami, a oryginalne profile pozostają bez zmian
- Niektóre strony mogą poprosić o ponowne zalogowanie, ponieważ local storage i zapisane hasła nie są przenoszone
- Import CSV **nie jest pełną metodą tworzenia kopii zapasowej**
- Nieprawidłowe formatowanie może **uniemożliwić import lub utworzyć nieprawidłowe profile**

<Warning>
  Plik CSV zawiera dane uwierzytelniające proxy oraz pliki cookie w postaci zwykłego tekstu. Nie udostępniaj go osobom, które nie powinny mieć dostępu do Twoich kont.
</Warning>

### Najważniejsze wnioski

Import i eksport CSV najlepiej sprawdza się przy **skalowaniu i zarządzaniu konfiguracjami profili**. Nie jest to pełna kopia profilu: foldery, tagi, historia przeglądania i local storage nie są przenoszone.
