---

Gologin Agent Browser CLI zamienia profile przeglądarki Gologin w trwałe środowisko uruchomieniowe, którym agenci AI mogą sterować za pomocą skryptów. Sesje działają w Gologin Cloud Browser lub w Orbita na Twoim komputerze. Narzędzie udostępnia zwięzłe migawki stron, interakcję opartą na refach, pamięć sesji oraz wynik przyjazny dla powłoki.

W przeciwieństwie do pisania kodu Puppeteer/Playwright od zera, to CLI daje agentom gotowy zestaw poleceń do automatyzacji przeglądarki — bez kodu szablonowego i bez własnej obsługi sesji.

---

## Środowisko w chmurze lub lokalne

CLI ma dwa środowiska uruchomieniowe z tymi samymi poleceniami. Oba korzystają z profili, fingerprintów i proxy Gologin, a demon utrzymuje sesje przy życiu między kolejnymi wywołaniami CLI.

| | `cloud` (domyślne) | `local` |
|---|---|---|
| Gdzie działa przeglądarka | Gologin Cloud Browser | Orbita na Twoim komputerze |
| ID profilu | Opcjonalne: bez niego tworzony jest tymczasowy profil w chmurze | Wymagane |
| Dobre do | Sesji równoległych, sesji zdalnych, maszyn, na których nie powinna działać przeglądarka | Rozgrzewania profili, pierwszych logowań, lokalnych ciasteczek i stanu profilu, dopasowania do Twojego systemu operacyjnego |

Środowisko wybierasz dla pojedynczego polecenia za pomocą `--runtime cloud|local|auto` albo ustawiasz raz zmienną `GOLOGIN_AGENT_BROWSER_RUNTIME`:

```bash
gologin-agent-browser open https://example.com
gologin-agent-browser open https://example.com --runtime local --profile your_profile_id
```

Domyślnie (`auto`) polecenia profili, runbooków i zadań działają lokalnie, a wszystkie pozostałe w chmurze. Po otwarciu sesji lokalnej przekazuj `--runtime local` także do kolejnych poleceń. Wymagania i polecenia dostępne tylko lokalnie znajdziesz w sekcji [Local runtime](/pl/cli-tools/local-agent-browser).

## Instalacja

```bash
npm install -g gologin-agent-browser-cli
```

Lub uruchom bez instalacji globalnej:

```bash
npx gologin-agent-browser-cli --help
```

Wymaga Node.js w wersji 18 lub nowszej. Środowisko lokalne wymaga Node.js w wersji 20 lub nowszej.

## Dane uwierzytelniające

| Zmienna | Wymagana | Opis |
|---|---|---|
| `GOLOGIN_TOKEN` | Tak (dla `open` i poleceń API) | Token API Gologin |
| `GOLOGIN_PROFILE_ID` | Opcjonalna | Domyślne ID profilu |
| `GOLOGIN_AGENT_BROWSER_RUNTIME` | Opcjonalna | Domyślne środowisko: `cloud`, `local` lub `auto` |
| `GOLOGIN_DAEMON_PORT` | Opcjonalna | Port demona (domyślnie: `44777` dla chmury, `44778` dla środowiska lokalnego) |
| `GOLOGIN_CONNECT_BASE` | Opcjonalna | Punkt końcowy Cloud Browser (domyślnie: `https://cloudbrowser.gologin.com/connect`) |
| `GOLOGIN_EXECUTABLE_PATH` | Opcjonalna | Ścieżka do pliku wykonywalnego Orbita dla środowiska lokalnego |

### Jak uzyskać token

1. Zarejestruj się lub zaloguj na [gologin.com](https://gologin.com)
2. Otwórz **API & MCP** w panelu
3. Otwórz kartę **API**
4. Kliknij **New Token**
5. Skopiuj wygenerowany token dostępu

```bash
export GOLOGIN_TOKEN='your_gologin_token'
```

### Plik konfiguracyjny

`~/.gologin-agent-browser/config.json`

## Architektura

Składa się z dwóch części:

1. **CLI `gologin-agent-browser`** — analizuje polecenia, wybiera środowisko, automatycznie uruchamia odpowiedni demon i wyświetla zwięzły wynik
2. **Trwałe lokalne demony**, po jednym na każde środowisko — zarządzają aktywnymi sesjami przeglądarki, łączą się z Gologin Cloud Browser lub lokalną Orbita przez Playwright `connectOverCDP`, trzymają aktywną stronę w pamięci, budują migawki, rozwiązują refy i śledzą metadane sesji

Transport jest wyłącznie lokalny. Demon chmurowy nasłuchuje na:
- gnieździe Unix pod ścieżką `${TMPDIR:-/tmp}/gologin-agent-browser.sock`
- lokalnym HTTP pod adresem `127.0.0.1:${GOLOGIN_DAEMON_PORT:-44777}`

W środowisku chmurowym, jeśli nie podasz ID profilu, demon tworzy tymczasowy profil Gologin w chmurze za pośrednictwem API.

## Jak działają refy

`snapshot` wyświetla zwięzły widok strony i przypisuje refy, takie jak `@e1`, `@e2`, `@e3`, elementom interaktywnym. Możesz działać na nich bezpośrednio:

```bash
gologin-agent-browser snapshot
# output shows page content with refs like @e1, @e2, @e3...

gologin-agent-browser click @e3
gologin-agent-browser type @e5 "search query"
gologin-agent-browser fill @e7 "username"
```

Refy działają w trybie „best-effort" i po nawigacji lub większych zmianach w DOM należy wygenerować je ponownie. Polecenia przyjmują też selektory CSS zamiast refów. Na stronach dynamicznych lepszym rozwiązaniem zapasowym niż nieaktualne refy jest zwykle `find`: lokalizuje element na aktywnej stronie i wykonuje na nim akcję w jednym kroku.

```bash
gologin-agent-browser find label "Email" fill "user@example.com"
gologin-agent-browser find role button click --name "Submit"
```

## Szybki start

```bash
export GOLOGIN_TOKEN='your_token'

# open a page in cloud browser
gologin-agent-browser open https://example.com

# read the page as a compact snapshot
gologin-agent-browser snapshot

# interact with elements
gologin-agent-browser click @e3
gologin-agent-browser type @e5 "hello world"

# take a screenshot
gologin-agent-browser screenshot ./page.png

# close the session
gologin-agent-browser close
```

## Przykład pętli agenta

Typowa pętla agenta AI:

```
1. open <url>
2. snapshot          → agent reads page content
3. click/type/fill   → agent acts on refs
4. snapshot          → agent reads result
5. repeat 3-4 as needed
6. screenshot        → save artifact
7. close
```

### Zarządzanie sesjami

| Polecenie | Opis |
|---|---|
| `open <url>` | Otwiera adres URL w sesji przeglądarki |
| `close` | Zamyka bieżącą sesję (`--all` zamyka wszystkie sesje tego demona) |
| `sessions` | Wyświetla listę aktywnych sesji (`--prune` usuwa nieaktualne) |
| `current` | Pokazuje informacje o bieżącej sesji |

### Odczyt strony

| Polecenie | Opis |
|---|---|
| `snapshot` | Zwięzła tekstowa migawka z refami elementów |
| `screenshot <path>` | Zapisuje zrzut ekranu strony |
| `pdf <path>` | Zapisuje stronę jako PDF |
| `get <kind> [target]` | Pobiera właściwości strony |

### Interakcja

| Polecenie | Opis |
|---|---|
| `click <ref>` | Klika element |
| `dblclick <ref>` | Klika dwukrotnie |
| `type <ref> <text>` | Wpisuje tekst (dopisuje) |
| `fill <ref> <text>` | Wypełnia pole (zastępuje zawartość) |
| `hover <ref>` | Najeżdża kursorem na element |
| `select <ref> <value>` | Wybiera wartość z listy rozwijanej |
| `check <ref>` / `uncheck <ref>` | Zaznacza lub odznacza pole wyboru |
| `focus <ref>` | Ustawia fokus na elemencie |
| `find <by> <locator> <action> [value]` | Znajduje element według `role`, `text`, `label`, `placeholder`, `first`, `last` lub `nth` i wykonuje na nim `click`, `fill`, `type` lub `hover`, albo odczytuje jego `text` |

### Klawiatura i przewijanie

### Profile, proxy i API Gologin

Te polecenia wywołują API Gologin z użyciem Twojego tokena i nie wymagają demona przeglądarki.

| Polecenie | Opis |
|---|---|
| `api <METHOD> <path>` | Wywołuje dowolny punkt końcowy REST API Gologin |
| `browser <action>` | Profile: lista, pobieranie, tworzenie, aktualizacja, usuwanie, ciasteczka, proxy, uruchamianie i zatrzymywanie w chmurze, import i eksport |
| `proxy <action>` | Proxy: lista, dodawanie proxy Gologin, aktualizacja, usuwanie, ruch |
| `workspace`, `folder`, `share`, `template` | Workspace'y i ich członkowie, foldery, udostępnianie, szablony profili |
| `user`, `deleted-profile` | Informacje o koncie i tokeny deweloperskie, przywracanie usuniętych profili |
| `cloud-usage` | Użycie Cloud Browser dla profilu lub workspace'u |
| `profile-cloud`, `profile-cookies`, `profile-fingerprint`, `profile-proxy`, `profile-ua` | Skróty: uruchamianie lub zatrzymywanie profilu w chmurze, eksport lub import jego ciasteczek, odświeżanie jego fingerprintu, dodawanie proxy, aktualizacja jego user agenta |

```bash
gologin-agent-browser browser list --page 1
gologin-agent-browser proxy add-gologin your_profile_id --country us --type residential
gologin-agent-browser cloud-usage --profile your_profile_id
gologin-agent-browser api GET /browser/your_profile_id
```

Dodaj `--help` do dowolnego polecenia, aby wyświetlić jego sposób użycia.

### Tylko środowisko lokalne

## Zastosowania i przykłady

### Sprawdź, czy Twoja strona przechodzi testy anti-detect

```bash
gologin-agent-browser open https://iphey.com/ --profile your_profile_id
gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # read the trust score
gologin-agent-browser screenshot ./iphey-result.png
gologin-agent-browser close
```

### Zaloguj się do aplikacji webowej i pobierz dane z panelu

```bash
gologin-agent-browser open https://app.example.com/login
gologin-agent-browser snapshot

# agent reads snapshot, finds login form
gologin-agent-browser fill @e4 "user@company.com"
gologin-agent-browser fill @e6 "password"
gologin-agent-browser click @e8

gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # agent reads dashboard content

# navigate to the report page
gologin-agent-browser click @e12   # "Reports" link
gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # agent extracts report data
gologin-agent-browser screenshot ./report.png
gologin-agent-browser close
```

### Wypełnij wieloetapowy formularz

```bash
gologin-agent-browser open https://forms.example.com/apply

# step 1: personal info
gologin-agent-browser snapshot
gologin-agent-browser fill @e3 "John Doe"
gologin-agent-browser fill @e5 "john@example.com"
gologin-agent-browser select @e7 "United States"
gologin-agent-browser click @e9   # Next

# step 2: upload and submit
gologin-agent-browser wait 1000
gologin-agent-browser snapshot
gologin-agent-browser upload @e4 ./resume.pdf
gologin-agent-browser check @e6   # agree to terms
gologin-agent-browser click @e8   # Submit

gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # confirm success
gologin-agent-browser close
```

### Rób zrzuty ekranu stron konkurencji

```bash
# use different profiles with different geos
for profile in us_profile de_profile jp_profile; do
  gologin-agent-browser open https://competitor.com --profile $profile
  gologin-agent-browser wait 3000
  gologin-agent-browser screenshot ./${profile}-homepage.png
  gologin-agent-browser close
done
```

### Wyszukiwanie na stronie, która blokuje scraping

Niektóre strony wymagają wykonania JavaScriptu, zalogowania się lub interakcji, zanim pokażą wyniki. Użyj przeglądarki, aby przeprowadzić wyszukiwanie:

```bash
gologin-agent-browser open https://protected-directory.com
gologin-agent-browser snapshot
gologin-agent-browser find placeholder "Search" fill "machine learning engineer San Francisco"
gologin-agent-browser press Enter
gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # agent reads search results
gologin-agent-browser screenshot ./search-results.png
gologin-agent-browser close
```

### Zapisywanie i przywracanie stanu sesji

Wyeksportuj ciasteczka i pamięć lokalną, aby użyć ich w kolejnych sesjach:

```bash
# after logging in
gologin-agent-browser cookies --output ./session-cookies.json
gologin-agent-browser storage-export ./session-storage.json
gologin-agent-browser close

# later, restore the session
gologin-agent-browser open https://app.example.com
gologin-agent-browser cookies-import ./session-cookies.json
gologin-agent-browser storage-import ./session-storage.json
gologin-agent-browser reload
gologin-agent-browser snapshot     # already logged in
```

## Sesje równoległe

Używaj jawnych identyfikatorów `--session` dla niezależnych zadań w chmurze. Porządkuj za pomocą `close --all` lub `sessions --prune --older-than-ms`.

---

## Zasady dotyczące proxy

- Profile ze skonfigurowanym proxy: proxy jest ustawione w profilu w panelu Gologin lub przez API, na przykład `proxy add-gologin <profileId> --country us`
- Tymczasowe profile w chmurze: bez proxy albo z własnym proxy za pomocą `--proxy-host` i `--proxy-port` (oraz `--proxy-mode http|socks4|socks5`, `--proxy-user`, `--proxy-pass`)
- W środowisku chmurowym `open` nie przyjmuje `--proxy-country`. Aby korzystać z ruchu proxy Gologin z danego kraju, dodaj proxy Gologin do profilu i otwórz go z `--profile`
- W środowisku lokalnym `open`, `profile-create` i `profile-update` przyjmują `--proxy-country`
