Gologin Web Unlocker to **scraping API z jednym endpointem** przeznaczone dla stron intensywnie korzystających z JavaScriptu oraz stron chronionych.

Wysyłasz adres URL, otrzymujesz wyrenderowany kod HTML lub tekst strony i przetwarzasz go we własnym procesie ekstrakcji danych.

## Dlaczego warto używać go jako Scraping API

- Jeden endpoint dla dowolnego docelowego adresu URL
- Uwierzytelnianie kluczem API, bez konieczności zarządzania przeglądarką
- Domyślnie HTML, a na życzenie Markdown lub JSON, gotowe do użycia w istniejących parserach
- Łatwa integracja z procesami ETL, monitoringiem, pozyskiwaniem danych dla AI i potokami danych

## Endpoint

`GET https://parsing.webunlocker.gologin.com/v1/scrape?url={encoded_url}`

## Uwierzytelnianie

Prześlij swój klucz API w nagłówkach:

```http
apikey: <API_KEY>
```

## Model żądania

| Nazwa | Gdzie | Typ | Wymagany | Opis |
|---|---|---|---|---|
| `url` | query | string (bezwzględny adres URL) | tak | Docelowy adres URL do pobrania |
| `format` | query | string | nie | Format odpowiedzi: `html` (domyślnie), `markdown` lub `json` |

## Szybki start

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.status_code)
print(response.text[:500])
```

### JavaScript (fetch)

```js
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(response.status, html.slice(0, 500));
```

## Zachowanie odpowiedzi

Domyślnie treścią odpowiedzi jest **surowy, wyrenderowany kod HTML** strony. Przy `format=markdown` treść jest zwracana w formacie Markdown. Przy `format=json` treścią jest obiekt JSON:

```json
{
  "success": true,
  "data": {
    "url": "https://example.com",
    "metadata": {
      "response_time_ms": 297,
      "status_code": 200
    },
    "html": "<!DOCTYPE html><html lang=\"en\">..."
  }
}
```

Kody statusu:

- `200` -> sukces, treść zawiera stronę w żądanym formacie
- `400` -> nieprawidłowe żądanie, na przykład brak `url`; treść: `{"success":false,"error":"Request failed"}`
- `401` -> brak nagłówka `apikey`; treść: `{"message":"Missing API key in request"}`

## Zalecenia dotyczące ponawiania żądań

Ponawiaj żądania z wykładniczym wydłużaniem odstępów (exponential backoff) w przypadku:

- błędów sieci
- kodów `408`, `429`, `500`, `502`, `503`, `504`

## Oficjalny SDK dla Node.js

Instalacja:

```bash
npm i gologin-webunlocker
```

### Szybki start z SDK

```ts
import { WebUnlocker } from "gologin-webunlocker";

const client = new WebUnlocker({
  apiKey: process.env.GOLOGIN_WEBUNLOCKER_API_KEY!
});

const result = await client.scrape("https://example.com");
console.log(result.status);
console.log(result.content.slice(0, 500));
```

### Opcje konstruktora

```ts
new WebUnlocker({
  apiKey: "wu_live_xxx",
  baseUrl: "https://parsing.webunlocker.gologin.com",
  timeoutMs: 15000,
  maxRetries: 2
});
```

### Podstawowe metody SDK

- `scrape(url)` -> znormalizowany obiekt odpowiedzi
- `scrapeRaw(url)` -> natywny obiekt `Response`
- `buildScrapeUrl(url)` -> pełny adres URL żądania

### Metody pochodne po stronie SDK (na podstawie zwróconego HTML)

To **nie są osobne endpointy backendu**; są one tworzone w SDK na podstawie HTML zwróconego przez API. SDK wysyła tylko parametr `url`, bez `format`, dlatego wynik może się różnić od odpowiedzi API z `format=markdown` lub `format=json`:

- `scrapeText(url)` -> zwykły tekst
- `scrapeMarkdown(url)` -> markdown
- `scrapeJSON(url)` -> uporządkowane metadane (`title`, `description`, `canonical`, `meta`, `headings`, `links`)
- `batchScrape(urls, { concurrency })` -> pomocnik do wielu wywołań scrape

### Typowane błędy

- `WebUnlockerError`
- `AuthenticationError`
- `RateLimitError`
- `APIError`
- `TimeoutError`
- `NetworkError`

Mapowanie:

- `401` / `403` -> `AuthenticationError`
- `429` -> `RateLimitError`
- `500+` i inne statusy inne niż 2xx (na przykład `400`) -> `APIError`
- przekroczenie limitu czasu/przerwanie -> `TimeoutError`
- błąd fetch/sieci -> `NetworkError`

## CLI

```bash
gologin-webunlocker <command> <url> [options]
```

Polecenia:

- `scrape` (surowy HTML/tekst)
- `text` (tekst pochodny)
- `markdown` (markdown pochodny)
- `json` (metadane pochodne)

Przykłady:

```bash
gologin-webunlocker scrape https://example.com --api-key wu_live_xxx
GOLOGIN_WEBUNLOCKER_API_KEY=wu_live_xxx gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_live_xxx gologin-webunlocker json https://example.com
```

## Typowe zastosowania scrapingu

- monitorowanie cen i katalogów
- wzbogacanie danych o leadach i katalogach
- procesy analizy rynku
- agregowanie i indeksowanie treści
- pozyskiwanie danych dla LLM i procesy ekstrakcji

## Gologin Web Access CLI (ujednolicone)

Jeśli potrzebujesz bardziej rozbudowanego CLI, które łączy Web Unlocker z Cloud Browser w jednym zestawie poleceń, użyj `gologin-web-access`:

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."

# all scraping commands from gologin-webunlocker, plus:
gologin-web-access batch-scrape url1 url2 url3 --format text --summary
gologin-web-access search "query" --limit 10
gologin-web-access map https://example.com --limit 50
gologin-web-access crawl https://docs.example.com --format markdown --limit 20
gologin-web-access extract https://example.com --schema ./schema.json
gologin-web-access change-track https://example.com --format markdown

# plus cloud browser interaction (requires GOLOGIN_TOKEN)
gologin-web-access open https://example.com
gologin-web-access snapshot
gologin-web-access click e3
```

Pełny opis znajdziesz w [Gologin Web Access CLI](/pl/cli-tools/web-access).
