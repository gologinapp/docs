---
title: "Eksport i import profili"
---

Ten przewodnik wyjaśnia, jak eksportować i importować profile w Gologin oraz kiedy stosować każdą z metod.

Gologin obsługuje import i eksport profili za pomocą **plików CSV**.

## Jak wyeksportować profile

1. **Zaznacz** jeden lub więcej profili na stronie All profiles
2. Kliknij **Export profiles**
3. **Zapisz** plik CSV

<Frame>
  ![Eksport profili](/images/profile_export.gif)
</Frame>

## Jak zaimportować profile

Profile można zaimportować z menu obszaru roboczego.

1. **Kliknij strzałkę** obok przycisku Add profile w menu po lewej stronie
2. Kliknij **Import profiles**
3. Prześlij plik CSV lub wklej dane CSV
4. Kliknij **Import**

<Frame>
  ![Import profili](/images/profile_import-2.gif)
</Frame>

<Warning>
  Jeśli zaimportowane profile znajdują się już na liście All profiles, zostaną jedynie zaktualizowane. \
  Duplikaty nie zostaną utworzone.
</Warning>
