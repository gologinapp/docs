---
title: "FAQ: Profiles"
---

### Can I run multiple profiles at the same time?

Yes. Gologin allows you to run multiple browser profiles simultaneously, depending on your system resources and subscription plan.

Each profile runs in an isolated browser environment with its own fingerprint, cookies, and proxy settings.

### Can I use the same proxy for multiple profiles?

Technically yes, but it is not recommended.

Using the same proxy for multiple profiles may link accounts together and reduce their trust score on certain platforms.

For best results, use **a unique proxy for each profile**.

### What happens if I close a profile incorrectly?

If a profile is closed before synchronization is completed, the latest session data may not be saved.

This can result in:

- lost cookies
- lost session state
- websites logging you out

Always close profiles normally and wait until the profile state returns to **Ready**.

### Can I launch a single profile on multiple devices simultaneously?

This is technically possible but not recommended.

Running the same profile simultaneously on different devices may cause synchronization conflicts and increase the risk of account issues.

### Can I copy or duplicate a profile?

Yes. Gologin allows you to **clone profiles**.

Cloning a profile copies its settings, fingerprint configuration, and environment, allowing you to quickly create similar profiles.

### Can I connect to profiles via RDP, VNC or other remote tools?

Gologin profiles are not emulated, they're running on your device locally or in the cloud. They don't have an underlying operating system, so there's nothing to connect to. You can, however, connect via RDP to a device that's running Gologin profiles on it may the need be.

### Can I recover a deleted profile?

Yes. Deleted profiles can be restored for a limited time from the **Restore profiles** section in Settings.

If the profile has not been permanently removed, it can be recovered with its data intact.

### Why did my account get logged out after launching a profile?

This can happen if:

- the proxy location changed
- the fingerprint changed significantly
- cookies were invalid or expired

To reduce this risk, keep proxy, fingerprint, and timezone settings consistent.

### Can I turn on background notifications from websites or extensions in my profiles?

Orbita doesn't have a way of sending background notifications for now.

### Why can't I expand the browser window to full screen?

A profile's browser window can't be larger than the **Screen Resolution** set in its settings. This is intentional. Websites can see both the screen size a profile reports and the actual size of the browser window. On a real device, the window is never larger than the screen, so a mismatch can make the profile look suspicious.

To make the window larger:

1. Open the profile **Settings** > **Advanced**.
2. In **Screen Resolution**, choose a value that matches your monitor's resolution or is slightly lower.
3. Save the settings and relaunch the profile.

If you're already logged into accounts in this profile, keep in mind that websites may treat a resolution change as a new device and ask for additional verification.

To have new profiles open at the right size from the start, set the screen resolution in [Default profile settings](/default-profile-settings). It will apply to all profiles you create afterwards.
