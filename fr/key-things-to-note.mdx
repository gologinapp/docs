title: "Points importants à retenir"
---

L'application web Gologin offre presque les mêmes fonctionnalités que l'application de bureau, mais quelques points méritent votre attention avant de commencer.

### Définir Linux comme système d'exploitation du profil

Les navigateurs Cloud Browser de Gologin s'exécutent sur des serveurs Linux. Pour obtenir les meilleurs résultats, le système d'exploitation défini dans votre profil de navigateur doit correspondre à celui du serveur. Les profils Linux fonctionnent donc mieux lorsqu'ils sont lancés dans le cloud.

Lorsque vous créez des profils dans l'application web, Linux est sélectionné par défaut comme système d'exploitation, vous n'avez donc rien à modifier. Si vous lancez dans le cloud des profils de navigateur créés dans l'application de bureau, gardez cette limite à l'esprit. Cela ne provoque pas toujours de problèmes visibles, mais si un site web se comporte de manière inattendue, le système d'exploitation du profil est la première chose à vérifier.

### Le navigateur peut avoir un aspect et un comportement différents

Lorsque vous lancez un profil dans le cloud, ce que vous voyez dans l'onglet de votre navigateur est un flux vidéo en direct d'un navigateur exécuté sur les serveurs de Gologin, et non une fenêtre de navigateur locale. Vous pouvez donc remarquer :

- Des bandes noires sur les côtés de la fenêtre du navigateur
- Une résolution qui ne semble pas tout à fait correcte
- Un léger décalage entre vos actions et ce qui s'affiche à l'écran

C'est normal et inhérent à la diffusion vidéo. Une connexion internet lente ou instable rendra ces effets plus visibles.

### Différences dans le téléchargement et l'envoi de fichiers

Lorsque vous lancez un profil dans le cloud, le navigateur ne s'exécute pas sur votre ordinateur, mais sur un serveur distant. Pour cette raison, le téléchargement et l'envoi de fichiers fonctionnent un peu différemment. Pour en savoir plus sur leur fonctionnement, consultez [cette page](/fr/downloading-and-uploading-files).

### Les profils cloud restent actifs jusqu'à leur arrêt

Fermer l'onglet du navigateur n'arrête pas un profil cloud. Le profil continue de s'exécuter sur les serveurs de Gologin jusqu'à ce que l'une des situations suivantes se produise :

- Vous cliquez manuellement sur **Arrêter** depuis la page Tous les profils
- Il est arrêté automatiquement après 15 minutes d'inactivité

Gardez cela à l'esprit si votre abonnement limite l'utilisation du cloud.

### L'utilisation sur mobile n'est pas officiellement prise en charge

L'application web Gologin et Cloud Browser sont conçus pour les navigateurs de bureau. Vous pouvez essayer d'y accéder depuis un navigateur mobile, mais cela n'est pas officiellement pris en charge et peut ne pas fonctionner comme prévu. Si vous utilisez Android, utilisez plutôt l'application Gologin dédiée pour Android.
