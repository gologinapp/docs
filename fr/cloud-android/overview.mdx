**Cloud Android** vous permet d'exécuter de vrais téléphones Android dans le cloud directement depuis l'application Gologin, sans avoir besoin d'un téléphone physique. Chaque profil Cloud Android est un téléphone distinct avec ses propres applications et ses propres données, ce qui vous permet de travailler avec des applications mobiles (par exemple Instagram) de la même manière qu'avec des profils de navigateur.

## Qui peut l'utiliser

Cloud Android est gratuit pour tous les forfaits payants de Gologin. Les utilisateurs de la période d'essai gratuite peuvent également l'utiliser pendant l'essai s'ils se sont inscrits avec Google.

| | Téléphones en cours d'exécution simultanée | Limite de temps |
| --- | --- | --- |
| Essai (inscription avec Google) | 1 | Aucune limite |
| Forfaits payants | jusqu'à 10 | Aucune limite |

## Créer et exécuter un profil Cloud Android

![Cloud Android](/images/cloud_android.png "Cloud Android")

1. Cliquez sur **Cloud Android** dans le menu de gauche.
2. Cliquez sur **Ajouter un profil Android**.
3. Configurez les proxys et les autres paramètres.
3. Cliquez sur **Exécuter** sur le profil. Le démarrage d'un téléphone peut prendre **jusqu'à 2 minutes**.
4. Lorsque le profil est en **course**, cliquez sur **Voir** pour ouvrir la fenêtre du téléphone.
5. Pour terminer, cliquez sur **Arrêter**.

Le nombre de téléphones en cours d'exécution est affiché en haut de la page (**Actuellement en course**).

## Utiliser le téléphone

La fenêtre du téléphone contient les boutons Android standard ainsi que des outils sur le côté droit, par exemple : captures d'écran, envoi et téléchargement de fichiers, rotation de l'écran, volume, localisation et alimentation.

Installez des applications via les boutiques d'applications du téléphone, comme **Aurora Store**, **F-Droid** ou **Uptodown**. Les applications, les identifiants de connexion et les autres données restent dans le profil entre les lancements.

![Cloud Android Prone Ui](/images/cloud_android_prone_ui.png "Cloud Android Prone Ui")

<Note>
  Toutes les applications Android ne fonctionnent pas dans Cloud Android. Si une application ne s'ouvre pas, essayez plutôt d'utiliser son site web dans le navigateur.
</Note>

## Proxys

Les téléphones Cloud Android fonctionnent sur les serveurs de Gologin. Sans proxy, les sites web et les applications voient donc l'adresse IP du serveur, et non la vôtre. Ajoutez un proxy au profil de la même manière que pour les profils de navigateur : tous les types de proxy sont pris en charge, y compris les proxys Gologin et les vôtres. Les proxys mobiles paraissent les plus naturels pour un téléphone, mais tous les types fonctionnent.

## Délai d'inactivité

Si un téléphone en cours d'exécution reste inactif pendant **15 minutes**, il s'arrête automatiquement. Vos données sont enregistrées.
