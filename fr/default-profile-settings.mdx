title: "Paramètres de profil par défaut"
---

Les **Paramètres de profil par défaut** vous permettent de définir un modèle pour les nouveaux profils. Tout ce que vous configurez ici est appliqué automatiquement lors de la création d'un nouveau profil. Les profils existants ne sont pas concernés : les modifications s'appliquent uniquement aux profils créés par la suite.

Pour le moment, tous les paramètres ne sont pas disponibles dans les paramètres par défaut.

<Tip>
  Ces paramètres s'appliqueront uniquement aux profils que vous créerez après la modification. Ils ne seront pas appliqués aux profils déjà existants.
</Tip>

Comment y accéder :

1. Cliquez sur le **nom de votre espace de travail** dans le coin supérieur gauche.
2. Accédez à **Paramètres et membres**.
3. Dans la barre latérale gauche, cliquez sur **Paramètres de profil par défaut**.

## Proxy et emplacement

Dans la section **Proxy et emplacement**, vous pouvez choisir le proxy attribué automatiquement aux nouveaux profils :

- **Proxy Gologin** - choisissez le pays et le type de proxy. Chaque nouveau profil sera créé avec un proxy Gologin situé à cet emplacement.
- **Sans procuration** - les nouveaux profils sont créés sans proxy et utilisent votre connexion Internet réelle.

Par défaut, les nouveaux profils reçoivent un proxy Gologin. L'emplacement correspond généralement aux États-Unis, ou au pays que vous avez choisi lors de l'inscription.

Ce paramètre s'applique aux profils créés avec le bouton **\+** (profils rapides) et avec **Ajouter un profil**.

<Note>
  Les proxys Gologin utilisent votre trafic proxy. Si vous préférez ajouter vos propres proxys, réglez ce paramètre sur **Sans procuration**, puis attribuez manuellement un proxy à chaque profil. Consultez [Ajouter des proxys](/fr/proxy/proxy-management/adding-proxies).
</Note>

Dans la même section, vous pouvez activer **Désactiver le chargement des images** et **Désactiver la lecture automatique des vidéos** afin que les nouveaux profils consomment moins de trafic proxy. Disponible uniquement avec les offres payantes.

## Restaurer les paramètres par défaut

Si vous avez modifié vos paramètres de profil par défaut et souhaitez revenir aux paramètres d'origine, cliquez sur l'**icône en forme de flèche** à côté de **Restaurer les paramètres par défaut du profil** en haut de la page. Les paramètres reviendront à ceux que Gologin définit pour les nouveaux comptes en fonction du système d'exploitation de votre appareil.

Cela réinitialise uniquement le modèle des nouveaux profils. Vos profils existants ne changeront pas.
