---
title: "Simulation de saisie humaine"
---

La simulation de saisie humaine dans Gologin rend la saisie de texte dans les profils de navigateur plus naturelle.

Lorsque du texte est collé ou saisi dans un champ, Gologin simule le comportement d'une saisie humaine afin que le texte semble tapé manuellement plutôt qu'inséré instantanément.

Cela aide les sites web à interpréter l'activité comme provenant d'un véritable utilisateur.

## Pourquoi la saisie humaine est utile

La simulation de saisie humaine peut être utile lors de l'interaction avec des sites web qui surveillent le comportement des utilisateurs, comme :

- les plateformes de réseaux sociaux
- les places de marché
- les plateformes publicitaires
- les services dotés de systèmes anti-fraude

En rendant les actions de saisie plus naturelles, les profils peuvent paraître plus fiables aux yeux des systèmes de sécurité des sites web.

## Comment cela fonctionne dans Gologin

Lorsque la simulation de saisie humaine est active :

- le texte collé est saisi progressivement
- les caractères apparaissent avec de petits délais
- le comportement de saisie se rapproche de celui d'un utilisateur réel

Ainsi, les workflows automatisés et les actions dans les profils ressemblent davantage à une activité utilisateur normale.

### Comment utiliser la saisie humaine

1. Ouvrez un **profil de navigateur**
2. **Copiez du texte** depuis n'importe quelle source
3. Dans n'importe quel champ de texte d'un profil de navigateur
   - faites un **clic droit** sur le champ de texte et choisissez Coller en saisie humaine
   - ou utilisez le raccourci clavier **Ctrl\+Shift\+E**
