---
title: "Cloner des profils"
---

Le clonage vous permet de créer un nouveau profil à partir d'un profil existant.

C'est utile lorsque vous devez reproduire un environnement tout en gardant vos comptes séparés.\
Les profils clonés peuvent hériter de :

- les paramètres du fingerprint
- les paramètres du navigateur
- la configuration des extensions

Vous pouvez ensuite modifier le proxy ou d'autres paramètres pour le nouveau profil.

Pour cloner un profil existant :

1. Allez dans l'**onglet Tous les profils**
2. Trouvez le profil que vous souhaitez dupliquer
3. Cliquez sur les **trois points** à côté du profil
4. Sélectionnez **Cloner**

<Frame>
  ![Cloner des profils](/images/cloning_profiles.gif)
</Frame>

Un nouveau profil sera créé avec la configuration copiée.
