## Modifications depuis la page des profils

Vous pouvez modifier certains paramètres directement depuis la page principale **Tous les profils**. Vous pouvez gérer des paramètres tels que : **nom, proxys, notes, statut, tags**.

<Frame>
  ![Modifications depuis la page des profils](/images/changes_from_the_profiles_page.gif)
</Frame>

## Paramètres rapides du profil

Pour modifier rapidement vos profils, cliquez simplement sur le bouton **Paramètres** du profil. Vous pouvez ensuite définir de nouveaux paramètres dans la barre latérale.

<Frame>
  ![Paramètres rapides du profil](/images/quick_profile_settings.gif)
</Frame>

## Paramètres principaux du profil

Vous pouvez accéder aux paramètres principaux du profil en **cliquant sur les 3 points du profil \> Paramètres**. Vous y trouverez davantage d'options, ainsi qu'une description détaillée de chacune d'elles.

<Frame>
  ![Paramètres principaux du profil](/images/main_profile_settings.gif)
</Frame>
