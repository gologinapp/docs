---
title: "Actions groupées"
---

Les actions groupées dans Gologin vous permettent d'appliquer la même action à plusieurs profils en une seule fois.

Pour utiliser les actions groupées, sélectionnez d'abord plusieurs profils dans la liste à l'aide des cases à cocher. Le panneau des actions groupées apparaît ensuite en haut de la page.

## Comment utiliser les actions groupées

1. Sélectionnez plusieurs profils à l'aide des cases à cocher
2. Le panneau des actions groupées apparaît en haut de la page
3. Choisissez l'action que vous souhaitez appliquer

## Quand utiliser les actions groupées

Les actions groupées sont particulièrement utiles lorsque vous devez :

- Lancer plusieurs profils pour le travail quotidien ou le warm-up
- Modifier des paramètres par lots
- Organiser les profils dans des dossiers et des projets
- Gérer les accès des membres de votre équipe
- Maintenir ou actualiser les empreintes à grande échelle

## Ce que vous pouvez faire avec les actions groupées

### **Lancer les profils**

Sélectionnez les profils et cliquez sur **Lancer le profil** pour lancer tous les profils sélectionnés.

Utilisez cette option pour démarrer plusieurs comptes pour le travail quotidien ou des sessions de warm-up.

<Note>
  Lancer trop de profils à la fois peut affecter les performances, selon votre système.
</Note>

<Frame>
  ![Lancement groupé de profils](/images/bulk_run_profiles.gif)
</Frame>

### **Lancer les profils avec Sync**

Sélectionnez les profils et cliquez sur **Exécutez avec Sync** pour les lancer avec la synchronisation activée.

<Frame>
  ![Lancement groupé avec Sync](/images/bulk_run_with_sync.gif)
</Frame>

### **Arrêter les profils**

Sélectionnez les profils en cours d'exécution et cliquez sur **Arrêter le profil** pour les fermer.

<Frame>
  ![Arrêt groupé de profils](/images/bulk_stop_profiles-1.gif)
</Frame>

### **Ajouter des profils à un dossier**

Sélectionnez les profils, cliquez sur **Ajouter au dossier**, puis choisissez le dossier de destination.

<Frame>
  ![Ajout groupé de profils à un dossier](/images/bulk_add_profiles_to_folder-1.gif)
</Frame>

### **Attribuer ou modifier des proxys**

Sélectionnez les profils, cliquez sur **Procuration**, puis ajoutez ou modifiez les paramètres de proxy pour tous les profils sélectionnés.

Assurez-vous que l'emplacement du proxy correspond aux paramètres du profil (pays, fuseau horaire).

<Warning>
  Évitez d'attribuer le même proxy à de nombreux profils.
</Warning>

<Frame>
  ![Modification groupée des proxys](/images/bulk_change_proxies-1.gif)
</Frame>

### **Partager les profils**

Sélectionnez les profils, cliquez sur **Partager le profil**, puis attribuez l'accès à un autre utilisateur.

<Frame>
  ![Partage groupé de profils](/images/bulk_share_profiles.gif)
</Frame>

### **Modifier les balises**

Sélectionnez les profils, cliquez sur **Modifier les balises**, puis mettez à jour les balises de tous les profils sélectionnés.

Utilisez les balises pour filtrer et gérer rapidement de très grands ensembles de profils.

<Frame>
  ![Modification groupée des balises](/images/bulk_edit_tags-1.gif)
</Frame>

### **Modifier les extensions**

Sélectionnez les profils, puis cliquez sur **Modifier les extensions** pour gérer les extensions de l'ensemble des profils sélectionnés.

<Frame>
  ![Modification groupée des extensions](/images/bulk_edit_extensions.gif)
</Frame>

### **Modifier les signets**

Sélectionnez les profils et cliquez sur **Modifier les signets** pour mettre à jour les signets.

<Frame>
  ![Modification groupée des signets](/images/bulk_edit_bookmarks.gif)
</Frame>

### **Renommer les profils**

Sélectionnez les profils et cliquez sur **Renommer les profils** pour les renommer en une seule fois.

<Frame>
  ![Renommage groupé de profils](/images/bulk_rename_profiles-2.gif)
</Frame>

### **Cloner les profils**

Sélectionnez les profils et cliquez sur **Cloner** pour en créer des copies.

<Frame>
  ![Clonage groupé de profils](/images/bulk_clone_profiles.gif)
</Frame>

### **Transférer les profils**

Sélectionnez les profils et cliquez sur **Transfert** pour les déplacer vers un autre espace de travail ou un autre utilisateur, si cette option est disponible dans votre configuration.

<Frame>
  ![Transfert groupé de profils](/images/bulk_transfer_profiles.gif)
</Frame>

### **Exporter les profils**

Sélectionnez les profils et cliquez sur **Exporter des profils** pour les exporter.

<Frame>
  ![Exportation groupée de profils](/images/bulk_export_profiles.gif)
</Frame>

### **Mettre à jour l'empreinte**

Sélectionnez les profils et cliquez sur **Mettre à jour l'empreinte** pour actualiser les paramètres d'empreinte.

<Frame>
  ![Mise à jour groupée de l'empreinte](/images/bulk_update_fingerprint.gif)
</Frame>

### **Supprimer les profils**

Sélectionnez les profils et cliquez sur **Supprimer** pour les retirer.

<Frame>
  ![Suppression groupée de profils](/images/bulk_delete_profiles-1.gif)
</Frame>

### **Utiliser l'automatisation**

Sélectionnez les profils et cliquez sur **Automatisation** pour appliquer des actions liées à l'automatisation.

<Frame>
  ![Utilisation groupée de l'automatisation](/images/bulk_use_automation.gif)
</Frame>

<Info>
  Les actions groupées s'appliquent à tous les profils sélectionnés en même temps.\
  Avant d'appliquer une action, vérifiez que les bons profils sont sélectionnés, en particulier lorsque vous utilisez **Supprimer**, **Transfert** ou **Mettre à jour l'empreinte**.
</Info>
