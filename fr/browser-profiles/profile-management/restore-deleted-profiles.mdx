---
title: "Restaurer les profils supprimés"
---

Gologin conserve vos profils pendant au moins **120 heures** après leur suppression, ce qui vous permet de récupérer des profils supprimés par erreur depuis le menu **Restaurer les profils**. Cette fonctionnalité est disponible sur tous les forfaits payants !

## Comment restaurer vos profils

1. Cliquez sur le **nom de votre espace de travail** dans le coin supérieur gauche
2. Accédez à **Paramètres et membres**
3. Ouvrez l'onglet **Restaurer les profils**
4. Recherchez les profils à récupérer et cliquez sur **Restaurer**

<Frame>
  ![Restaurer les profils](/images/restore_profiles.gif)
</Frame>

Les profils restaurés apparaîtront sur la page Tous les profils.

<Note>
  Les profils supprimés il y a plus de 120 heures ne peuvent pas être restaurés. Si vous ne trouvez pas les profils perdus, essayez de les rechercher par nom grâce à la fonction de recherche ou contactez le support pour obtenir de l'aide.
</Note>
