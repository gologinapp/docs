---
title: "Restaurer les profils supprimés"
description: "Récupérez des profils supprimés par erreur dans un délai de 120 heures (5 jours) sur n'importe quel forfait payant."
---

Gologin conserve vos profils pendant au moins **120 heures** après leur suppression, ce qui vous permet de récupérer des profils supprimés accidentellement depuis le menu **Restaurer les profils**. Cette fonctionnalité est disponible sur tous les forfaits payants !

## Comment restaurer vos profils

1. Cliquez sur le **nom de votre espace de travail** dans le coin supérieur gauche
2. Accédez à **Paramètres et membres**
3. Ouvrez l'onglet **Restaurer les profils**
4. Repérez les profils à récupérer et cliquez sur **Restaurer**

<Frame>
  ![Restaurer les profils](/images/restore_profiles.gif)
</Frame>

Les profils restaurés apparaîtront sur la page Tous les profils.

<Note>
  Les profils supprimés il y a plus de 120 heures ne peuvent pas être restaurés. Si vous ne retrouvez pas vos profils, essayez de les rechercher par leur nom à l'aide de la fonction de recherche, ou contactez le support pour obtenir de l'aide.
</Note>
