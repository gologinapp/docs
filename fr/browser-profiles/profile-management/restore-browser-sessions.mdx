---
title: "Restaurer les sessions du navigateur"
---

Chaque fois que vous lancez puis fermez un profil Gologin, le système crée automatiquement un **instantané de session**. L'**Historique du profil** dans Gologin vous permet de restaurer l'une des **5 dernières sessions**.

Un instantané de session comprend :

- Les cookies
- Le stockage de session
- L'état de connexion
- Les jetons des sites web
- Les données du navigateur issues de cette session

Si nécessaire, vous pouvez restaurer le profil à l'un de ces états de session précédents.

## Comment restaurer la session d'un profil ?

Pour restaurer votre profil à l'une des 5 dernières sessions, procédez comme suit :

1. Cliquez sur les **3 points** du profil
2. Sélectionnez **Histoire**
3. Choisissez la session souhaitée
4. Cliquez sur **Restaurer**

## Quand utiliser l'Historique du profil ?

La restauration à partir d'instantanés peut être utile dans les cas suivants :

1. **Un compte a été déconnecté**\
   Si un site web vous déconnecte de manière inattendue, vous pouvez restaurer une session précédente où le compte était encore actif.
2. **Perte de données**\
   Si vous ne voyez pas les onglets ouverts récemment ou si vous pensez que la dernière synchronisation du profil s'est mal déroulée à cause de problèmes de connexion réseau.
3. **État du site web corrompu**\
   Si un site web ne se comporte pas comme il le devrait à cause de modifications du cache ou de l'intervention d'une extension.
4. **Profil non fonctionnel**\
   Si vous ne parvenez pas à lancer un profil pour une raison non liée au proxy, par exemple si la session précédente ne s'est pas synchronisée correctement.

## Bonnes pratiques

- **Fermez toujours les profils correctement**\
  Un arrêt brutal peut produire des instantanés instables.
- **N'abusez pas des restaurations**\
  Passer constamment d'une session à l'autre peut paraître peu naturel.
- **Conservez un proxy cohérent**\
  Restaurer une session des États-Unis tout en utilisant un nouveau proxy européen peut invalider les cookies.
- **Utilisez cette fonction comme outil de récupération**\
  Elle est idéale pour corriger des erreurs ou revenir en arrière en cas d'instabilité.
