---
title: "Synchronisation des profils"
---

**La synchronisation des profils** dans Gologin permet d'enregistrer automatiquement dans le cloud vos profils de navigateur, avec toutes leurs empreintes, leurs cookies, leur stockage local et leurs extensions. Cela signifie que :

- Vous pouvez **accéder au même profil depuis le web ou depuis n'importe quel appareil** sur lequel Gologin est installé
- Les membres de votre équipe peuvent **collaborer sur des profils partagés**
- Vos profils restent **cohérents**, quel que soit l'endroit où ils sont lancés

## Fonctionnement de la synchronisation

Lorsqu'un profil est fermé correctement, Gologin envoie les dernières données du profil vers les serveurs cloud. Au prochain lancement du profil, l'état enregistré est restauré. Les données de votre session, vos cookies et l'état du navigateur restent ainsi cohérents.

## Comment utiliser vos profils en toute sécurité

- **Assurez-vous que la synchronisation est terminée avant d'éteindre votre ordinateur.**\
  Le statut doit indiquer **prêt** et le bouton **Exécuter** doit être actif sur le profil : cela signifie que les données du profil sont synchronisées.
- **Fermez les profils avant d'éteindre l'ordinateur ou de fermer l'application.**\
  Fermez les profils en **fermant la fenêtre du profil** ou en cliquant sur **Arrêter** dans l'application afin de terminer la synchronisation.
- **N'utilisez pas un même profil sur plusieurs appareils en même temps.**\
  Bien que ce soit possible, ce n'est pas recommandé : un seul des profils lancés simultanément peut être synchronisé avec les serveurs cloud. Cela peut créer des écarts entre ce qui est enregistré dans le profil et ce que le site web s'attend à voir, ce qui risque de réduire votre score de confiance.
- **Ne fermez pas le profil si vous n'avez pas de connexion Internet.**\
  Si la synchronisation n'est pas terminée, vous risquez de perdre votre progression actuelle et de devoir récupérer les données des sessions précédentes.

## Règles de sécurité de la synchronisation

Pour que les données de vos profils restent intactes, suivez ces règles :

- Assurez-vous que la synchronisation est terminée avant de fermer l'application
- Attendez que le statut du profil indique prêt
- Fermez toujours vos profils avant d'éteindre votre ordinateur
- N'exécutez pas le même profil sur plusieurs appareils en même temps
- Évitez de fermer des profils lorsque votre connexion Internet est instable

Exécuter le même profil sur plusieurs appareils en même temps peut créer des incohérences dans les données de session enregistrées.
