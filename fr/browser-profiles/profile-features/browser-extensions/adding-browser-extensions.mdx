---
title: "Ajouter des extensions de navigateur aux profils"
---

Dans Gologin, vous pouvez ajouter des extensions publiques de deux manières différentes.

## Ajouter une extension via l'onglet Extensions

Vous pouvez ajouter des extensions à votre profil de navigateur **directement depuis les paramètres du profil**, sans passer par le Chrome Web Store :

1. Sur la page Tous les profils, **cliquez sur les 3 points du profil** sur lequel vous souhaitez installer l'extension, puis cliquez sur **Paramètres**
2. Accédez à l'onglet **Extensions**
3. Cliquez sur **Ajouter des extensions**
4. Recherchez l'extension souhaitée à l'aide de la barre de recherche, puis cliquez sur **Installer**
5. N'oubliez pas de cliquer sur **Sauvez** pour appliquer la modification

<Frame>
  ![Ajouter des extensions via les paramètres](/images/add_extensions_via_settings.gif)
</Frame>

Pour supprimer l'extension, cliquez simplement sur **Supprimer** dans le même menu.

<Tip>
  Si vous ne trouvez pas l'extension souhaitée dans la liste, installez-la au moins une fois depuis le Chrome Web Store. L'extension installée apparaîtra dans la liste sous 24 heures.
</Tip>

### Ajouter des extensions à chaque nouveau profil

Si vous savez que vous aurez besoin de certaines extensions sur chacun de vos profils, vous pouvez cliquer sur l'**icône de drapeau** à côté de l'extension pour qu'elle apparaisse dans chaque nouveau profil.

<Frame>
  ![Ajouter des extensions à chaque nouveau profil](/images/add_extensions_to_every_new_profile.png)
</Frame>

<Note>
  Ces extensions n'apparaîtront pas dans les profils que vous avez déjà créés. Elles seront ajoutées uniquement aux profils que vous créerez après cette modification.
</Note>

## Installer une extension via le Chrome Web Store

Si vous ne trouvez pas l'extension dans l'onglet Extensions des paramètres du profil, vous pouvez utiliser le **Chrome Web Store** depuis le profil de navigateur. Pour cela :

1. **Lancez le profil de navigateur** qui a besoin d'une nouvelle extension
2. Dans le navigateur, cliquez sur **les 3 points en haut à droite** \> **Extensions** \> **Accéder au Chrome Web Store**
3. Trouvez l'extension souhaitée
4. Cliquez sur **Ajouter à Chrome** et attendez la fin de l'installation
