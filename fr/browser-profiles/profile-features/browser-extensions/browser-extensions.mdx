---
title: "Présentation des extensions de navigateur"
---

Les extensions d'un profil Gologin vous permettent de personnaliser chaque environnement de navigation individuellement. Comme chaque profil Gologin fonctionne comme un navigateur distinct, avec sa propre empreinte et son propre stockage, les extensions sont installées et gérées **par profil**, et non de façon globale. Vous gardez ainsi un contrôle total sur les outils qui s'exécutent dans l'environnement de chaque compte.

## Que sont les extensions de profil ?

Les **extensions de profil** sont des extensions de navigateur **compatibles avec Chrome** que vous installez **directement dans un profil Gologin précis**.

Chaque profil :

- Possède sa propre liste d'extensions
- Stocke les données des extensions séparément
- Garde les paramètres des extensions isolés
- Ne partage pas ses extensions avec les autres profils

Vous pouvez donc utiliser des configurations différentes pour différents comptes, sans chevauchement.

## Pourquoi utiliser des extensions dans les profils Gologin ?

Les extensions sont souvent indispensables pour :

- Les outils d'automatisation
- La gestion des cookies
- La vérification des publicités
- L'aide au web scraping
- Les workflows de productivité

Comme les profils sont isolés, vous pouvez utiliser en toute sécurité des outils différents selon les comptes, sans contamination croisée des données.

## Extensions et stabilité de l'empreinte

Les extensions peuvent modifier le comportement du navigateur.

Certaines extensions :

- Modifient les en-têtes de requête
- Injectent des scripts
- Interagissent avec WebRTC
- Modifient le comportement du canvas

Si vous travaillez sur des plateformes sensibles (publicité, e-commerce, crypto), testez soigneusement les nouvelles extensions avant de les utiliser sur des comptes déjà « chauffés ».

## Bonnes pratiques

- Évitez d'installer des extensions inutiles
- Utilisez des extensions cohérentes selon le type de compte
- N'ajoutez ni ne supprimez pas fréquemment des extensions sur des profils établis. Des changements brusques dans la configuration des extensions peuvent paraître suspects sur les plateformes à haute sécurité.
