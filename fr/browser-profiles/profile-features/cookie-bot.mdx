---
title: "Cookie Bot"
---

Cookie Bot est un outil intégré à Gologin qui génère automatiquement des cookies de navigation pour un profil. Cet outil peut vous aider à automatiser votre processus de préchauffage.

Il simule un comportement de navigation naturel en visitant des sites web populaires et en effectuant des actions simples, comme faire défiler les pages et cliquer. Cela permet de créer un environnement de navigation plus réaliste avant de vous connecter à des comptes.

Cookie Bot peut vous aider à :

- générer un historique de navigation initial
- créer des cookies naturels pour les sites web
- préchauffer de nouveaux profils de navigateur
- préparer les profils pour la connexion à un compte ou l'automatisation

## Fonctionnement de Cookie Bot

Cookie Bot visite une liste de sites web courants et simule des interactions utilisateur basiques.

Ces actions peuvent inclure :

- le chargement des pages
- le défilement du contenu
- le clic sur des boutons
- le chargement des images

<Frame>
  ![Cookie Bot](/images/cookie_bot.png)
</Frame>

Cette activité crée des cookies et des données de navigation dans le profil, ce qui rend la session du navigateur plus naturelle.

## Fonctionnalités et paramètres de Cookie Bot

Les paramètres que vous pouvez configurer actuellement :

- **Chargement des images**\
  ON : les images seront chargées\
  OFF : les images ne seront pas chargées, ce qui économise les données de votre proxy
- **Utilisation du défilement**\
  ON : le bot fera défiler les pages en imitant un comportement humain\
  OFF : le bot ne fera pas défiler les pages et passera directement à l'étape suivante
- **Utiliser le clic automatique**\
  ON : le bot **acceptera les demandes de cookies** à votre place\
  OFF : le bot ne cliquera sur rien

Ce qui n'est pas encore pris en charge :

- L'enregistrement manuel de scénarios que le bot devra exécuter
- La personnalisation des éléments sur lesquels le bot clique

## Exécuter Cookie Bot

### Exécuter Cookie Bot pour un seul profil

1. Accédez à la page **Tous les profils**.
2. Cliquez sur les **3 points** du profil.
3. Sélectionnez **Automatisation**.
4. Consultez la liste des sites web que le bot doit visiter.
5. Ajustez les paramètres facultatifs si nécessaire.
6. Cliquez sur **Exécuter**.

<Frame>
  ![Exécuter Cookie Bot pour un profil](/images/run_cookie_bot_for_profile-1.gif)
</Frame>

Cookie Bot simulera une activité de navigation et générera des cookies pour le profil.

### Exécuter Cookie Bot pour plusieurs profils

Gologin vous permet également d'exécuter Cookie Bot **pour plusieurs profils à la fois**.

Pour cela :

1. Sélectionnez plusieurs profils dans le tableau des profils.
2. Choisissez **Automatisation**.
3. Configurez les paramètres.
4. Cliquez sur **Exécuter**.

<Frame>
  ![Exécuter Cookie Bot pour plusieurs profils](/images/run_cookie_bot_for_multiple_profiles.gif)
</Frame>

Le processus démarrera pour tous les profils sélectionnés.

## Bonnes pratiques

Pour obtenir les meilleurs résultats :

- exécutez Cookie Bot avant de vous connecter à de nouveaux comptes
- gardez le proxy du profil activé pendant le processus
- évitez d'exécuter Cookie Bot trop fréquemment sur le même profil

Cela contribue à maintenir un environnement de navigation naturel.
