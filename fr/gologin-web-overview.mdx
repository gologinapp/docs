Gologin est disponible non seulement en tant qu'application de bureau, mais aussi en tant qu'application web sur [app.gologin.com](http://app.gologin.com). Vous pouvez vous y connecter avec votre compte Gologin et gérer vos profils depuis n'importe quel navigateur, sur n'importe quel appareil, sans aucune installation.

### Cloud Browser

Pour comprendre le fonctionnement de l'application web, il est utile de connaître le principe du Cloud Browser.

Lorsque vous lancez un profil dans l'application de bureau, il s'ouvre sur votre appareil et utilise les ressources de celui-ci : RAM, processeur, etc. Le nombre de profils que vous pouvez exécuter en même temps est limité par votre matériel.

Le Cloud Browser fonctionne différemment. Au lieu de s'exécuter sur votre appareil, le profil s'exécute sur les serveurs de Gologin. Vous le consultez et interagissez avec lui via votre navigateur habituel. Les ressources de votre appareil ne sont donc pas sollicitées, vous pouvez lancer vos profils de n'importe où, et le nombre de profils exécutables n'est pas limité par votre matériel.

Chaque profil Cloud Browser possède sa propre empreinte de navigateur et sa propre adresse IP, exactement comme les profils de l'application de bureau.

### Ce que vous pouvez faire dans l'application web

L'application web disponible sur [app.gologin.com](http://app.gologin.com) offre les mêmes fonctionnalités de base que l'application de bureau. Vous pouvez créer et gérer des profils, lancer des profils Cloud Browser et accéder aux paramètres de votre compte, le tout depuis un simple onglet de navigateur.

C'est pratique lorsque vous n'avez pas votre ordinateur habituel sous la main, ou lorsque vous souhaitez accéder à vos profils depuis un appareil sur lequel l'application de bureau n'est pas installée.
