Gologin Web Unlocker est une **Scraping API à point de terminaison unique** conçue pour les sites web riches en JavaScript et protégés.

Vous envoyez une URL, vous recevez le HTML ou le texte de la page rendue, puis vous le traitez dans votre propre pipeline d'extraction.

## Pourquoi l'utiliser comme Scraping API

- Un seul point de terminaison pour n'importe quelle URL cible
- Authentification par clé API, sans orchestration de navigateur
- HTML par défaut, ou Markdown ou JSON sur demande, prêt pour vos parseurs existants
- Idéal pour l'ETL, la surveillance, l'ingestion par IA et les pipelines de données

## Point de terminaison

`GET https://parsing.webunlocker.gologin.com/v1/scrape?url={encoded_url}`

## Authentification

Envoyez votre clé API dans les en-têtes :

```http
apikey: <API_KEY>
```

## Modèle de requête

| Nom | Emplacement | Type | Obligatoire | Description |
|---|---|---|---|---|
| `url` | query | string (URL absolue) | oui | URL cible à scraper |
| `format` | query | string | non | Format de la réponse : `html` (par défaut), `markdown` ou `json` |

## Démarrage rapide

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.status_code)
print(response.text[:500])
```

### JavaScript (fetch)

```js
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(response.status, html.slice(0, 500));
```

## Comportement de la réponse

Par défaut, le corps de la réponse est le **HTML brut rendu** de la page. Avec `format=markdown`, le corps est en Markdown. Avec `format=json`, le corps est un objet JSON :

```json
{
  "success": true,
  "data": {
    "url": "https://example.com",
    "metadata": {
      "response_time_ms": 297,
      "status_code": 200
    },
    "html": "<!DOCTYPE html><html lang=\"en\">..."
  }
}
```

Codes de statut :

- `200` -> succès, le corps contient la page dans le format demandé
- `400` -> requête incorrecte, par exemple si `url` est absent ; corps : `{"success":false,"error":"Request failed"}`
- `401` -> l'en-tête `apikey` est absent ; corps : `{"message":"Missing API key in request"}`

## Recommandations pour les nouvelles tentatives

Effectuez de nouvelles tentatives avec un backoff exponentiel en cas de :

- erreurs réseau
- `408`, `429`, `500`, `502`, `503`, `504`

## SDK Node.js officiel

Installation :

```bash
npm i gologin-webunlocker
```

### Démarrage rapide du SDK

```ts
import { WebUnlocker } from "gologin-webunlocker";

const client = new WebUnlocker({
  apiKey: process.env.GOLOGIN_WEBUNLOCKER_API_KEY!
});

const result = await client.scrape("https://example.com");
console.log(result.status);
console.log(result.content.slice(0, 500));
```

### Options du constructeur

```ts
new WebUnlocker({
  apiKey: "wu_live_xxx",
  baseUrl: "https://parsing.webunlocker.gologin.com",
  timeoutMs: 15000,
  maxRetries: 2
});
```

### Méthodes principales du SDK

- `scrape(url)` -> objet de réponse normalisé
- `scrapeRaw(url)` -> `Response` natif
- `buildScrapeUrl(url)` -> URL complète de la requête

### Méthodes dérivées côté SDK (à partir du HTML renvoyé)

Il ne s'agit **pas de points de terminaison backend distincts** : elles sont dérivées du HTML de l'API au sein du SDK. Le SDK envoie uniquement le paramètre `url`, et non `format`. Ce résultat peut donc différer de la réponse `format=markdown` ou `format=json` de l'API elle-même :

- `scrapeText(url)` -> texte brut
- `scrapeMarkdown(url)` -> markdown
- `scrapeJSON(url)` -> métadonnées structurées (`title`, `description`, `canonical`, `meta`, `headings`, `links`)
- `batchScrape(urls, { concurrency })` -> utilitaire pour effectuer plusieurs appels de scraping

### Erreurs typées

- `WebUnlockerError`
- `AuthenticationError`
- `RateLimitError`
- `APIError`
- `TimeoutError`
- `NetworkError`

Correspondances :

- `401` / `403` -> `AuthenticationError`
- `429` -> `RateLimitError`
- `500+` et les autres statuts non 2xx (par exemple `400`) -> `APIError`
- délai dépassé ou abandon -> `TimeoutError`
- échec de fetch ou du réseau -> `NetworkError`

## CLI

```bash
gologin-webunlocker <command> <url> [options]
```

Commandes :

- `scrape` (HTML/texte brut)
- `text` (texte dérivé)
- `markdown` (markdown dérivé)
- `json` (métadonnées dérivées)

Exemples :

```bash
gologin-webunlocker scrape https://example.com --api-key wu_live_xxx
GOLOGIN_WEBUNLOCKER_API_KEY=wu_live_xxx gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_live_xxx gologin-webunlocker json https://example.com
```

## Cas d'usage courants du scraping

- surveillance des prix et des catalogues
- enrichissement de leads et d'annuaires
- pipelines de veille économique
- agrégation et indexation de contenu
- workflows d'ingestion et d'extraction pour les LLM

## Gologin Web Access CLI (unifiée)

Pour une CLI plus puissante qui combine Web Unlocker et Cloud Browser dans un seul ensemble de commandes, utilisez `gologin-web-access` :

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."

# all scraping commands from gologin-webunlocker, plus:
gologin-web-access batch-scrape url1 url2 url3 --format text --summary
gologin-web-access search "query" --limit 10
gologin-web-access map https://example.com --limit 50
gologin-web-access crawl https://docs.example.com --format markdown --limit 20
gologin-web-access extract https://example.com --schema ./schema.json
gologin-web-access change-track https://example.com --format markdown

# plus cloud browser interaction (requires GOLOGIN_TOKEN)
gologin-web-access open https://example.com
gologin-web-access snapshot
gologin-web-access click e3
```

Consultez [Gologin Web Access CLI](/fr/cli-tools/web-access) pour la référence complète.
