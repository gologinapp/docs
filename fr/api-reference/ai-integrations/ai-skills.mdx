Les Skills IA Gologin sont des extensions prêtes à l'emploi pour [Claude Code](https://claude.ai/code) qui donnent aux agents IA des capacités de web scraping et d'automatisation du navigateur. Chaque skill encapsule un outil CLI Gologin et l'expose sous la forme d'un ensemble de fonctions appelables par l'agent.

```
agent → skill → Gologin CLI → Web Unlocker API / Cloud Browser / Local Orbita
```

## Installation

Tous les skills Gologin s'installent depuis le dépôt [GologinLabs/agent-skills](https://github.com/GologinLabs/agent-skills) :

```bash
# install any skill
npx skills add GologinLabs/agent-skills@gologin-web-access-skill
npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill
npx skills add GologinLabs/agent-skills@gologin-scraping-skill
```

Chaque skill nécessite l'installation du CLI sous-jacent :

| Skill | CLI requis |
|---|---|
| Web Access Skill | `npm i -g gologin-web-access` |
| Agent Browser Skill | `npm i -g gologin-agent-browser-cli` (runtimes cloud et local) |
| Scraping Skill | `npm i gologin-webunlocker` |

## Web Access Skill

**Installation :** `npx skills add GologinLabs/agent-skills@gologin-web-access-skill`

Le skill par défaut, le plus polyvalent. Il délègue au CLI `gologin-web-access`.

**Outils de scraping :** `scrape_url`, `read_page`, `scrape_markdown`, `scrape_text`, `scrape_json`, `batch_scrape`, `batch_extract`, `search_web`, `map_site`, `crawl_site`, `crawl_site_async`, `extract_structured`, `track_changes`, `batch_track_changes`, `parse_document`

**Outils de navigateur :** `browser_open`, `browser_search`, `browser_snapshot`, `browser_click`, `browser_type`, `browser_screenshot`, `browser_close`, `browser_sessions`, `browser_current`

**Workflows intégrés :** browser-ref-loop, hybrid-read-then-interact, search-discover-and-scrape, lead-enrichment, competitive-monitoring, docs-ingestion, geo-testing, login-and-navigate-dashboard

Consultez la [référence du CLI Web Access](/fr/cli-tools/web-access) pour le détail complet des commandes.

## Agent Browser Skill

**Installation :** `npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill`

Skill dédié au navigateur, pour les sessions en direct dans Gologin Cloud Browser (par défaut) ou dans des profils Orbita locaux avec `--runtime local`. À utiliser lorsque vous avez besoin d'une navigation interactive sans scraping.

**Fonctionnalités :** `doctor`, `open`, `sessions`, `current`, `snapshot`, `click`, `type`, `fill`, `find`, `get`, `tabs`, `tabopen`, `tabfocus`, `tabclose`, `cookies`, `cookies-import`, `storage-export`, `storage-import`, `eval`, `back`, `forward`, `reload`, `upload`, `screenshot`, `pdf`

**Le runtime local ajoute :** la gestion des profils (`profiles`, `profile-create`, `profile-import`, `profile-update`, `profile-sync`, `profile-delete`), les runbooks (`run`, `batch`), les jobs (`jobs`, `job`), les modèles par cas d'usage (`linkedin`, `ads`, `smm`, `scraping`, `geo`) et les diagnostics (`doctor --use-case --check-proxy`).

Consultez la [référence du CLI Agent Browser](/fr/cli-tools/agent-browser) et le [runtime local](/fr/cli-tools/local-agent-browser) pour le détail complet des commandes.

## Scraping Skill

**Installation :** `npx skills add GologinLabs/agent-skills@gologin-scraping-skill`

Le plus petit des skills : du scraping uniquement, via le SDK Web Unlocker. Pas de session de navigateur, pas de daemon.

**Fonctionnalités :** HTML brut (`scrape`), texte (`text`), markdown (`markdown`), métadonnées structurées (`json`). Méthodes du SDK : `scrapeRaw()`, `scrape()`, `scrapeText()`, `scrapeMarkdown()`, `scrapeJSON()`, `batchScrape()`.

À utiliser lorsque la tâche se limite au scraping et que vous souhaitez réduire le nombre de dépendances.

Consultez la [référence du SDK Web Unlocker](/fr/scraping-api-sdk-and-cli) pour le détail de l'API.

## Local Agent Browser Skill (obsolète)

Si votre agent utilise encore `gologin-local-agent-browser-skill`, ce skill ne fait que rediriger l'agent vers le skill Agent Browser. Installez plutôt `gologin-agent-browser-skill` : il couvre les profils Orbita locaux, le préchauffage, les parcours de connexion, les runbooks et les jobs en lot.

## Ce que vous pouvez demander à votre agent

Une fois un skill installé, vous parlez à Claude Code en langage naturel. Voici ce que permet chaque skill :

### Avec le Web Access Skill

- « Lis la page des tarifs de competitor.com et résume les offres »
- « Scrape ces 15 URL et extrais le nom du produit et le prix pour chacune »
- « Crawle la documentation sur docs.example.com et fais-moi un résumé de chaque section »
- « Recherche "best CRM tools 2026" et scrape les 5 premiers résultats »
- « Vérifie si competitor.com/pricing a changé depuis hier »
- « Extrais tous les titres et URL des articles de blog de ce site »
- « Ouvre example.com dans un navigateur, connecte-toi avec ces identifiants et fais une capture d'écran du tableau de bord »

### Avec l'Agent Browser Skill

- « Ouvre le tableau de bord d'administration, va dans Paramètres et fais une capture d'écran de la configuration actuelle »
- « Connecte-toi à l'environnement de staging et vérifie si la nouvelle fonctionnalité est déployée »
- « Remplis le formulaire d'inscription sur example.com avec ces données de test »
- « Va sur la page des rapports, télécharge l'export mensuel et fais une capture d'écran du récapitulatif »
- « Vérifie ce qu'affiche iphey.com pour ce profil de navigateur »

### Avec le Scraping Skill

- « Scrape cette URL et donne-moi le contenu texte »
- « Récupère le titre, la description et les titres de section de ces 10 pages »
- « Récupère cette page en markdown pour que je puisse l'analyser »

### Avec l'Agent Browser Skill (runtime local)

- « Crée un nouveau profil LinkedIn avec un proxy américain et préchauffe-le »
- « Ouvre mon compte Reddit, fais défiler le fil d'actualité, puis ferme-le »
- « Lance le runbook de préchauffage sur les 20 profils avec une concurrence de 5 »
- « Vérifie l'état des proxys sur mes profils publicitaires Facebook »
- « Connecte-toi à ce compte de place de marché et fais une capture d'écran du tableau de bord vendeur »

## Exemples de workflows

### Veille concurrentielle (Web Access Skill)

1. L'agent recherche des concurrents : `search_web("saas project management tools")`
2. L'agent cartographie le site d'un concurrent : `map_site("https://competitor.com")`
3. L'agent scrape en lot les pages clés : `batch_scrape(pricing, features, about)`
4. L'agent transmet le contenu à Claude pour analyse et comparaison

### Préchauffage de comptes (Agent Browser Skill, runtime local)

1. L'agent crée des profils : `profile-create "Account 1" --template linkedin`
2. L'agent lance le runbook de préchauffage : `batch ./warmup.json --targets ./profiles.json`
3. L'agent vérifie les résultats des jobs : `jobs --kind batch --status ok`
4. L'agent indique quels profils sont prêts

### Surveillance d'un tableau de bord (Agent Browser Skill)

1. L'agent ouvre le tableau de bord : `open https://dashboard.example.com --profile saved_login`
2. L'agent lit la page : `snapshot`
3. L'agent navigue vers les métriques : `click @e5` (lien Rapports)
4. L'agent fait une capture d'écran du rapport : `screenshot ./daily-metrics.png`
5. L'agent ferme la session : `close`
6. L'agent résume les métriques à partir des données du snapshot

## Vérification préalable obligatoire

Avant d'exécuter une tâche, les skills la classent selon les critères suivants :

1. **Un seul site connu ou une recherche large sur plusieurs sources ?** — détermine si un scraping ou une recherche est nécessaire
2. **Extraction en lecture seule, surveillance ou travail interactif dans le navigateur ?** — détermine le choix entre scraping et navigateur
3. **Web Unlocker seul, ou Web Unlocker et Cloud Browser ?** — détermine les identifiants nécessaires
4. **Contenu sensible à la géolocalisation ou suffisamment bloqué pour justifier Gologin de bout en bout ?** — détermine les exigences en matière de proxy et de profil
