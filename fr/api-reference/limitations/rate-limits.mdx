---
title: 'Limites de débit'
---
L'API de Gologin limite le nombre de requêtes que vous pouvez envoyer par minute. Si vous dépassez la limite, attendez avant d'envoyer de nouvelles requêtes.

La limite dépend de votre forfait :

| Forfait | Requêtes par minute |
| :-- | --: |
| Professional | 300 |
| Business | 500 |
| Enterprise | 800 |
| Custom | 1,200 |

Les forfaits d'essai et Forever Free n'incluent pas l'accès à l'API. Consultez la page [Tarifs](/fr/general/account-and-billing/pricing) pour voir ce que comprend chaque forfait.

### Invalidation du jeton en cas de dépassement de la limite

<Warning>
Si vous dépassez la limite de débit et recevez une réponse HTTP 429, votre jeton d'API est automatiquement invalidé. Votre jeton devient alors définitivement inutilisable et vous devez en générer un nouveau.

Il ne s'agit pas d'un simple délai d'attente temporaire : le jeton est révoqué. Planifiez soigneusement votre fréquence de requêtes et mettez en place un délai d'attente exponentiel (exponential backoff) pour éviter cette situation.
</Warning>

### Erreurs de protection Cloudflare

Si l'adresse IP de votre serveur envoie trop de requêtes, le CDN Cloudflare de Gologin peut bloquer entièrement votre adresse IP. Dans ce cas, les réponses de l'API sont des pages d'erreur HTML au lieu de JSON, ce qui provoque des erreurs comme :

```
SyntaxError: Unexpected token 'e', "error code: 1015" is not valid JSON
```

Il s'agit d'une réponse de limitation de débit Cloudflare 1015. Elle se résout généralement d'elle-même en quelques minutes à quelques heures. Pour l'éviter :
- Mettez en place une limitation du débit des requêtes dans votre code
- Utilisez un délai d'attente exponentiel (exponential backoff) en cas d'échec
- Évitez les rafales d'appels d'API en parallèle

### Limites de création de profils

Les nouveaux comptes sont limités à environ 300 créations de profils par jour. Cette limite peut varier selon le forfait. Si vous avez besoin de limites plus élevées, contactez le support.
