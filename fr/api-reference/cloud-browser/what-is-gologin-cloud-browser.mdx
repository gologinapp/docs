Gologin Cloud Browser vous permet d'exécuter un navigateur Gologin (Orbita) **dans le cloud** et de le piloter depuis votre code d'automatisation (Puppeteer / Playwright) à l'aide d'une seule **URL de connexion**.

Il s'agit d'un [navigateur headless](./what-is-headless-browser), c'est-à-dire un navigateur entièrement contrôlé par du code, sans interface graphique, hébergé et géré par Gologin, avec une prise en charge intégrée des profils persistants, de la configuration des empreintes et du routage par proxy.

## Ce que vous pouvez faire avec Cloud Browser

- Exécuter plusieurs sessions de navigateur en parallèle dans le cloud
- Automatiser avec votre stack existante (Puppeteer / Playwright)
- Utiliser les **profils** Gologin pour conserver un état persistant (connexions, cookies, stockage)
- Faire passer le trafic par des **proxys** en les configurant sur le profil
- L'utiliser avec des agents IA comme environnement de navigateur distant

## En quoi il diffère d'un navigateur headless standard

Un Chrome headless standard est détectable. Les sites web utilisent le fingerprinting du navigateur pour identifier le trafic automatisé : ils examinent le rendu canvas, les paramètres WebGL, les polices, le fuseau horaire, la taille de l'écran et des dizaines d'autres signaux.

Gologin Cloud Browser exécute **Orbita**, un Chromium modifié qui gère les signaux d'empreinte afin de correspondre à un profil de navigateur cohérent et réaliste. Associées aux cookies persistants et à la configuration du proxy enregistrés dans chaque profil, vos sessions paraissent stables et humaines d'une visite à l'autre.

## Pourquoi choisir Gologin Cloud Browser

### Anti-détection intégrée, sans plugin

Un Chrome headless standard est trivialement détectable. D'autres services de navigateur cloud exécutent un Chromium standard et nécessitent des plugins de furtivité tiers pour réduire les signaux d'empreinte, avec des résultats variables.

Gologin Cloud Browser exécute **Orbita**, une version renforcée de Chromium dont la gestion des empreintes est au cœur : canvas, WebGL, polices, fuseau horaire, résolution d'écran, et plus encore. L'anti-détection n'est pas un correctif ajouté après coup : c'est le navigateur lui-même.

### Profils persistants : des sessions qui se souviennent

La plupart des services de navigateur cloud traitent chaque session comme sans état. Les cookies et le stockage sont supprimés à la fermeture de la session.

Les profils Gologin sont persistants. Connectez-vous une fois, fermez la session, reconnectez-vous plus tard : le profil conserve ses cookies, son stockage local et tous les paramètres configurés. Pas de nouvelle authentification, pas de préchauffage de session.

## Scénarios techniques courants

Cloud Browser est généralement utilisé pour des workflows où vous :

- vous connectez une seule fois à un compte web et conservez la session grâce à un profil
- effectuez des actions répétées sur les mêmes sites web avec de nombreux profils
- avez besoin de sessions stables et de longue durée sans dépendre d'une machine locale

Parmi les exemples : l'automatisation de sessions connectées pour des applications web, des places de marché ou des plateformes sociales, où la persistance et la cohérence des paramètres de profil sont essentielles.

## Concepts clés

- **Profil** : une identité de navigateur réutilisable (cookies/stockage + paramètres d'empreinte et de proxy).
- **Session cloud** : une instance en cours d'exécution d'un profil dans le cloud de Gologin.
- **URL de connexion** : le point de terminaison que vous transmettez à votre outil d'automatisation pour contrôler la session cloud.

## Fonctionnement (vue d'ensemble)

1. (Recommandé) Créez et configurez un profil via l'API REST de Gologin (proxy, empreinte, etc.).
2. Connectez-vous à Cloud Browser avec votre **jeton de développeur** et, en option, un `profileId`.
3. Automatisez la session avec Puppeteer ou Playwright.
4. Fermez la connexion lorsque vous avez terminé.

## URL de connexion

Utilisez cette URL comme point de terminaison du navigateur distant :

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${profileId}
```

- `token` : votre **jeton de développeur** Gologin (créez-le dans l'application Gologin : [API & MCP](https://app.gologin.com/personalArea/TokenApi) → **API** → **Nouveau jeton**).
- `profile` : **ID de profil** (facultatif). S'il est omis, un nouveau profil sera créé pour la session.

## Gérer les profils (proxy, empreinte, etc.)

Cloud Browser est la **couche de connexion**.\
Pour créer ou mettre à jour des profils, associer des proxys et configurer les paramètres des profils, utilisez l'API REST de Gologin :

- API des profils : [Créer un profil](https://gologin.com/docs/api-reference/profile/create-profile-with-partial-parameters), [Mettre à jour un profil](https://gologin.com/docs/api-reference/profile/update-profile-with-partial-parameters)
- API des proxys : [Ajouter un proxy Gologin à un profil](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy), [Définir votre propre proxy sur des profils](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles)

## Utiliser Cloud Browser depuis la CLI

Si vous préférez les commandes shell à l'écriture de code Puppeteer/Playwright, Gologin propose des outils CLI adaptés aux agents :

- **[Gologin Agent Browser CLI](/fr/cli-tools/agent-browser)** : CLI de navigateur cloud avec démon, instantanés de page et interaction basée sur des références. Conçu pour les agents IA.
- **[Gologin Web Access CLI](/fr/cli-tools/web-access)** : CLI unifiée combinant le scraping Web Unlocker et l'interaction avec Cloud Browser dans un seul outil.

```bash
npm install -g gologin-agent-browser-cli
export GOLOGIN_TOKEN='your_token'

gologin-agent-browser open https://example.com
gologin-agent-browser snapshot
gologin-agent-browser click @e3
gologin-agent-browser screenshot ./page.png
gologin-agent-browser close
```
