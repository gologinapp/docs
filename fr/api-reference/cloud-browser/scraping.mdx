## Vue d'ensemble

Gologin Cloud Browser peut être utilisé comme navigateur distant géré pour vos workflows de scraping et d'extraction de données. Votre code d'automatisation (Puppeteer) se connecte à une session de navigateur distante via un point de terminaison WebSocket, puis exécute la logique habituelle de navigation et d'extraction.

Cloud Browser est la couche de connexion et d'exécution ; les paramètres de profil et de proxy sont gérés via l'API REST. Cette configuration peut réduire la charge liée à l'infrastructure et aider à limiter les blocages lors du scraping, mais les résultats dépendent du comportement et des protections du site ciblé.

## Ce que vous obtenez

- Des sessions de navigateur distantes pour les connexions Puppeteer.
- Le rendu JavaScript pour les pages dynamiques.
- Une montée en charge sans avoir à gérer votre propre infrastructure de navigateurs.
- Une configuration des profils et des proxys pilotée par API.
- Un point de connexion canonique unique pour démarrer une session.

## Workflow type

1. Générez un jeton d'API.
2. Si besoin, créez ou configurez un profil (et un proxy) via l'API REST.
3. Construisez l'URL de connexion avec `token` et, éventuellement, `profile`.
4. Connectez-vous depuis Puppeteer/Playwright et lancez l'extraction.
5. Enregistrez les résultats et fermez la session du navigateur.

## Prérequis

- Créez un jeton : dans l'application Gologin, ouvrez [API & MCP](https://app.gologin.com/personalArea/TokenApi) → **API** → **Nouveau jeton**
- API Profils (recommandée pour une configuration maîtrisée) : [Créer un profil](https://gologin.com/docs/api-reference/profile/create-profile-with-partial-parameters), [Mettre à jour un profil](https://gologin.com/docs/api-reference/profile/update-profile-with-partial-parameters)
- API Proxy : [Ajouter un proxy Gologin à un profil](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy), [Définir votre propre proxy sur des profils](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles)

## Un point de connexion canonique

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${profileId}
```

- `token` est obligatoire.
- `profile` est facultatif.
- Si `profile` est omis, un nouveau profil est créé pour la session.

## Exemple Puppeteer minimal

```javascript
const puppeteer = require('puppeteer-core');

(async () => {


  const token = 'your_token_here';
  const profileId = 'your_profile_id'; // Set to '' to create a new profile for this session
  const cloudBrowserUrl = `https://cloudbrowser.gologin.com/connect?token=${token}${profileId ? `&profile=${profileId}` : ''}`;
  const browser = await puppeteer.connect({
  
    browserWSEndpoint: cloudBrowserUrl,
    defaultViewport: null
  
  });

  const page = await browser.newPage();
  await page.goto('https://example.com');
  const title = await page.title();
  console.log('Page title:', title);
  await page.screenshot({ path: 'screenshot.png' });
  await browser.close();

})();
```

## Bonnes pratiques

- Privilégiez les attentes explicites plutôt que les pauses fixes.
- Mettez en place une logique de nouvelle tentative avec un backoff borné et du jitter.
- Stockez les résultats d'extraction de manière structurée (URL, champs, horodatage, statut).
- Configurez le profil et le proxy avant la connexion pour garantir la reproductibilité.
- Fermez toujours les sessions et gérez le nettoyage en cas d'échec.
- Adaptez le comportement des requêtes et des sessions aux contraintes de chaque site ciblé.

## FAQ

### Ai-je besoin d'un profil ?

Non. Le paramètre `profile` est facultatif. S'il est omis, un nouveau profil est créé pour la session. Utilisez un profil lorsque vous avez besoin d'une configuration maîtrisée et reproductible.

### Où configurer les proxys ?

Configurez les proxys via l'API REST : [ajoutez un proxy Gologin à un profil](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy) ou [définissez votre propre proxy sur des profils](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles).

### Est-ce différent de Cloud Browser ?

Non. Cette page présente l'utilisation de Cloud Browser pour le scraping et l'extraction de données. Cloud Browser gère la connexion et l'exécution, tandis que les paramètres de profil et de proxy sont gérés via l'API REST.
