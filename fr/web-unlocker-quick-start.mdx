title: "Démarrage rapide"
---

Ce guide explique comment extraire les données de votre première URL avec Web Unlocker.

---

## Prérequis

- Une clé API Web Unlocker. Obtenez-en une grâce au formulaire de la [page Web Unlocker](https://gologin.com/web-unlocker/#web_unlocker_form). La clé arrive sous un jour ouvré, avec des requêtes gratuites pour tester vos propres cibles. Aucune carte bancaire n'est nécessaire.
- Python 3.x, Node.js ou n'importe quel client HTTP

---

## Authentification

Toutes les requêtes nécessitent votre clé API dans l'en-tête `apikey` :

```
apikey: YOUR_API_KEY
```

L'URL de base de toutes les requêtes API est :

```
https://parsing.webunlocker.gologin.com/v1
```

---

## Envoyer votre première requête

Envoyez une requête GET avec l'URL cible comme paramètre de requête. La réponse correspond au code HTML entièrement rendu de la page.

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.text)
```

### JavaScript (Node.js / Navigateur)

```javascript
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(html);
```

---

## Ce que vous recevez

Le corps de la réponse est le code HTML brut rendu de la page, soit le même contenu que celui que vous verriez en ouvrant l'URL dans un navigateur. Il n'y a pas d'enveloppe JSON ni d'analyse à effectuer.

```html
<!DOCTYPE html>
<html>
  <head><title>Example Domain</title></head>
  <body>...</body>
</html>
```

### Autres formats

Ajoutez le paramètre de requête `format` pour obtenir la page dans un autre format :

| `format` | Corps de la réponse |
|---|---|
| `html` | HTML de la page (valeur par défaut) |
| `markdown` | Contenu de la page en Markdown |
| `json` | Objet JSON contenant l'URL, les métadonnées de la requête et le HTML de la page |

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com&format=json" \
  -H "apikey: YOUR_API_KEY"
```

```json
{
  "success": true,
  "data": {
    "url": "https://example.com",
    "metadata": {
      "response_time_ms": 297,
      "status_code": 200
    },
    "html": "<!DOCTYPE html><html lang=\"en\">..."
  }
}
```

---

## Gestion des erreurs

Vérifiez le code d'état HTTP avant de traiter la réponse :

| Statut | Signification | Corps de la réponse |
|---|---|---|
| `200` | Succès | La page dans le format demandé |
| `400` | Requête incorrecte, par exemple si le paramètre `url` est manquant | `{"success":false,"error":"Request failed"}` |
| `401` | L'en-tête `apikey` est manquant | `{"message":"Missing API key in request"}` |

Si vous recevez un statut `429` ou `5xx`, réessayez avec un délai d'attente exponentiel (exponential backoff).

```python
response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

if response.status_code == 200:
    html = response.text
else:
    print(f"Error {response.status_code}: {response.text}")
```

## Démarrage rapide avec la CLI

Vous pouvez également extraire des pages avec les outils CLI de Gologin, sans écrire de code :

### CLI Web Unlocker

```bash
npm install -g gologin-webunlocker

GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker scrape https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker markdown https://example.com
```

### CLI Gologin Web Access (unifiée)

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."
gologin-web-access read https://example.com
gologin-web-access scrape-json https://example.com
gologin-web-access batch-scrape https://example.com/page/1 https://example.com/page/2 --format text
```

Consultez [Web Unlocker SDK et CLI](/fr/scraping-api-sdk-and-cli) et [CLI Web Access](/fr/cli-tools/web-access) pour plus de détails.
