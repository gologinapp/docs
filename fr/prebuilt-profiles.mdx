---
title: "Modèles de profils prédéfinis"
---

Les modèles de profils prédéfinis proposent des configurations de profils de navigateur recommandées pour les workflows courants sur différentes plateformes.

Ces modèles présentent les paramètres généralement utilisés pour chaque plateforme, notamment la configuration de l'empreinte, le type de proxy et les paramètres régionaux. Vous pouvez les utiliser comme point de départ lors de la création de nouveaux profils de navigateur dans Gologin.

Les modèles sont des exemples et non des préréglages figés : vous pouvez les adapter selon votre workflow.

## Modèle de profil TikTok

Configuration recommandée pour les environnements de comptes TikTok.

| Paramètre | Réglage recommandé |
| :-- | :-- |
| Type de navigateur | Environnement de type mobile |
| Type de proxy | Résidentiel ou mobile |
| Emplacement du proxy | Région fixe |
| Modifications de l'empreinte | Minimales |
| Fuseau horaire | Identique à l'emplacement du proxy |

TikTok accorde une grande importance à la cohérence de l'appareil et au comportement des sessions. Des environnements stables aident à réduire les vérifications.

## Modèle de profil Facebook / Meta Ads

Configuration recommandée pour les comptes Facebook et les workflows Meta Ads.

| Paramètre | Réglage recommandé |
| :-- | :-- |
| Type de navigateur | Ordinateur |
| Type de proxy | Résidentiel |
| Emplacement du proxy | Fixe |
| Modifications de l'empreinte | Évitez les changements fréquents |
| Comportement de la session | Activité progressive |

Facebook analyse les signaux de l'appareil et l'historique de connexion. Il est donc important de conserver des environnements cohérents.

## Modèle de profil pour plateformes crypto

Configuration recommandée pour les plateformes d'échange de cryptomonnaies et les plateformes avec vérification KYC.

| Paramètre | Réglage recommandé |
| :-- | :-- |
| Type de navigateur | Ordinateur |
| Type de proxy | Résidentiel |
| Emplacement du proxy | Région fixe |
| Modifications de l'empreinte | Évitez tout changement après la vérification |
| Stabilité de la session | Élevée |

Une fois la vérification KYC terminée, conserver le même environnement d'appareil permet de limiter les contrôles de sécurité supplémentaires.

## Modèle de profil Gmail / Google

Configuration recommandée pour les services Google tels que Gmail et Google Ads.

| Paramètre | Réglage recommandé |
| :-- | :-- |
| Type de navigateur | Ordinateur |
| Type de proxy | Résidentiel |
| Emplacement du proxy | Région stable |
| Modifications de l'empreinte | Minimales |
| Comportement de la session | Activité progressive |

Google évalue la cohérence des connexions et l'activité sur l'ensemble de ses services pour déterminer le niveau de confiance d'un compte.
