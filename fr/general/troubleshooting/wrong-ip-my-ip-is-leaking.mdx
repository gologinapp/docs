---
title: "Mauvaise IP : mon IP réelle fuit lorsque j'utilise un proxy"
description: "Que faire lorsque votre IP réelle fuit alors que vous utilisez le navigateur Gologin avec un proxy"
---

La seule cause de fuite d'IP que nous connaissions est un logiciel **NordVPN** en cours d'exécution avec la fonctionnalité **Threat Protection** activée.\
﻿La fonctionnalité Threat Protection a une priorité plus élevée dans le système et force tous les navigateurs (y compris vos navigateurs habituels) à utiliser l'IP de NordVPN. Elle fonctionne même si la connexion VPN est désactivée.

Si vous souhaitez continuer à travailler dans Gologin avec un proxy, veuillez **désactiver Threat Protection** afin que l'IP du proxy s'affiche correctement.
