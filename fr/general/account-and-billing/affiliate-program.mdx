---
title: "Programme d'affiliation"
---

Le programme d'affiliation de Gologin vous permet de gagner **10 % de chaque paiement** effectué par les utilisateurs que vous parrainez. Il n'y a aucune limite : chaque fois qu'un utilisateur parrainé renouvelle ou améliore son abonnement, vous touchez une commission.

## Comment y accéder

1. Cliquez sur le **nom de votre espace de travail** dans le coin supérieur gauche.
2. Sélectionnez **Paramètres et membres**
3. Dans la barre latérale gauche, cliquez sur **Programme d'affiliation**

<Frame>
  ![Programme d'affiliation](/images/affiliate_program.png)
</Frame>

Présentation du tableau de bord :

| Indicateur | Description |
| :-- | :-- |
| **Retiré** | Total des gains qui vous ont déjà été versés. |
| **Gagné** | Total des commissions gagnées depuis votre inscription au programme. |
| **Disponible** | Solde que vous pouvez retirer dès maintenant. |
| **Affiliation %** | Votre taux de commission actuel (par défaut : 10 %). |

## Créer votre lien de référence

Saisissez un préfixe personnalisé dans le champ **Ajouter un lien**, puis cliquez sur **Créer un lien de référence**. Votre lien suivra le format : `https://gologin.com/join/your-prefix`

Partagez ce lien où vous voulez : réseaux sociaux, blogs, descriptions de vidéos YouTube, ou directement avec des utilisateurs potentiels.

## Suivre les performances

Le tableau situé sous le générateur de lien récapitule toute votre activité de parrainage :

- **Lien** : le lien de référence utilisé
- **Clics** : le nombre de clics sur le lien
- **Parrainages** : le nombre de clics qui ont abouti à une inscription
- **Acheteurs** : le nombre d'inscriptions qui sont devenues des clients payants
- **Montant de la somme** : le revenu total généré par ce lien

## Retirer vos gains

Cliquez sur **Retrait** pour demander le versement de votre solde disponible. Vous pouvez également consulter vos versements précédents dans **Historique des paiements**.

<Info>
  Nous pouvons vous demander votre adresse de paiement et d'autres informations afin d'effectuer le versement. Veuillez contacter l'équipe d'assistance si votre paiement n'est pas crédité au bout de plus d'une semaine.
</Info>
