## Activer un code promo

Si vous n'avez pas encore d'abonnement, vous pouvez utiliser un code promo avant votre premier achat.

Pour l'activer :

1. Allez dans les **paramètres principaux en haut à gauche** \> **Paramètres et membres**
2. Ouvrez l'onglet **Plans de facturation**
3. Dans la section **Coupon**, saisissez le code promo et cliquez sur **Appliquer**
4. Vous pouvez maintenant choisir votre forfait en cliquant sur **Сhanger de forfait** ; le code promo sera appliqué lors du paiement.

## Quand le code promo peut-il être activé ?

Le code promo peut être activé si aucun abonnement n'a été acheté auparavant sur le compte. Il est valable uniquement pour le **premier abonnement mensuel**.

Il n'existe **aucun code promo pour l'abonnement annuel**, car celui-ci bénéficie automatiquement d'une réduction de 50 %.

Les codes promo fonctionnent avec tous les [moyens de paiement](/fr/general/account-and-billing/payment-methods) disponibles, **sauf PayPal**.

Les codes promo ne peuvent pas être utilisés dans les cas suivants :

- si le code promo est invalide ou expiré
- si vous avez déjà utilisé un code promo
- si vous avez déjà souscrit un abonnement auparavant
- si vous essayez d'acheter un abonnement annuel
- si vous essayez de payer avec PayPal

## Où trouver un code

Vous pouvez trouver des codes promo à divers endroits en ligne. Nous vous recommandons de faire une recherche sur Internet. Notez que notre équipe d'assistance ne dispose d'aucun code promo, il est donc inutile de faire pression sur nos agents pour en obtenir :)
