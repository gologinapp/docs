La page **Utilisation de Cloud Browser** vous montre comment vous utilisez les profils de navigateur cloud (les profils lancés avec **Exécuter dans le cloud**, dans l'application web ou via l'API Cloud Browser) et vous permet d'acheter des limites cloud supplémentaires.

Pour l'ouvrir, cliquez sur le **nom de votre espace de travail** en haut à gauche > **Paramètres et membres** > **Utilisation de Cloud Browser**.

## Ce que vous y trouverez

- **Clé API** : le jeton de l'API Cloud Browser. Cliquez sur **Révéler le jeton** pour l'afficher ou sur **Copie** pour le copier.
- **Total des lancements** et **Heures totales** pour la période sélectionnée
- **Limite d'heures** : les heures cloud disponibles par mois avec votre abonnement
- **Lancements parallèles maximum** : le nombre de profils cloud pouvant fonctionner en même temps
- **Période d'utilisation** : les heures utilisées pendant la période en cours et la date de début de cette période
- **Utilisation quotidienne** : les lancements, les heures et le nombre maximal de sessions simultanées par jour. Utilisez **Exporter CSV** pour la télécharger.

![Utilisation de Cloud Browser](/images/cloud_browser_usage-1.png "Utilisation de Cloud Browser")

## Acheter des limites cloud supplémentaires

Cliquez sur **Achetez plus de limites** et choisissez ce dont vous avez besoin :

- **Sessions simultanées** : **\$2 par session et par mois**. Définit le nombre de profils pouvant fonctionner en même temps dans le cloud.
- **Durée de navigation** : heures cloud supplémentaires par mois. Le tarif horaire dépend de votre abonnement : **\$0.09** avec Professional, **\$0.08** avec Business, **\$0.07** avec Enterprise et **\$0.05** avec les abonnements Custom.

![Limites de Cloud Browser](/images/cloud_browser_limits.png "Limites de Cloud Browser")

Cliquez sur **Mise à niveau** pour payer. Les limites cloud supplémentaires ne peuvent être payées que par Stripe : les cryptomonnaies et PayPal ne sont pas disponibles pour ces achats.

### Comment fonctionne la facturation des limites supplémentaires

Le prix des limites supplémentaires est le même pour les abonnements mensuels et annuels, mais la facturation est différente :

- **Abonnement mensuel** : vous ne payez les limites supplémentaires que jusqu'à la fin de votre période de facturation en cours. Ensuite, elles sont renouvelées en même temps que votre abonnement.
- **Abonnement annuel** : vous payez un mois à la fois. Les limites supplémentaires sont ensuite facturées séparément chaque mois jusqu'à la fin de votre abonnement annuel.

<Note>
  Les profils de navigateur cloud et les limites cloud supplémentaires sont disponibles uniquement avec les abonnements payants.
</Note>
