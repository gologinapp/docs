Le tableau de bord **Cloud Browser** affiche vos limites et votre utilisation du navigateur cloud (pour les profils lancés avec **Run in Cloud**, dans l'application web ou via l'API Cloud Browser) et vous permet d'acheter des limites cloud supplémentaires.

Pour l'ouvrir, cliquez sur **Cloud Browser** dans le menu de gauche.

## Ce que vous y trouverez

En haut de la page :

- **Concurrent sessions limit** : nombre de profils cloud pouvant fonctionner en même temps. Cliquez sur **\+** pour acheter plus de sessions.
- **Browser time** : heures cloud utilisées ce mois-ci par rapport à votre limite mensuelle, par exemple **0 of 200 hours**. Cliquez sur **\+** pour acheter plus d'heures ou sur **Usage** pour voir les statistiques.
- **API key & documentation** : le jeton pour l'API Cloud Browser. Cliquez sur l'icône de copie pour le copier ou sur **View docs** pour ouvrir la documentation de l'API.

Si vous n'avez encore lancé aucun profil cloud, la page propose deux façons de commencer :

- **Run from App** : cliquez sur **Open Profiles**, puis sur **Run in Cloud** sur n'importe quel profil.
- **Use via API** : copiez **Your API key** et cliquez sur **View docs** pour savoir comment l'utiliser.

### Statistiques d'utilisation

Cliquez sur **Usage** dans le bloc **Browser time** pour voir combien d'heures cloud vous avez utilisées. Choisissez la période en haut à droite, par exemple **7 days**, et cliquez sur **Download CSV** pour télécharger les données.

## Acheter des limites cloud supplémentaires

Cliquez sur **\+** à côté de **Concurrent sessions limit** ou de **Browser time**. Dans la fenêtre **Upgrade Cloud Browsing Limits**, choisissez ce dont vous avez besoin :

- **Concurrent sessions** : **\$2 par session et par mois**. Définit le nombre de profils pouvant fonctionner en même temps dans le cloud.
- **Browsing time** : heures cloud supplémentaires par mois. Le tarif horaire dépend de votre forfait : **\$0.09** avec Professional, **\$0.08** avec Business, **\$0.07** avec Enterprise et **\$0.05** avec les forfaits Custom.

La fenêtre indique combien vous payez maintenant (**Initial payment**) et combien par mois (**Total per month**). Cliquez sur **Upgrade** pour payer. Les limites cloud supplémentaires ne peuvent être payées que via **Stripe** : PayPal et les cryptomonnaies ne sont pas disponibles pour ces achats.

### Fonctionnement de la facturation des limites supplémentaires

Le prix des limites supplémentaires est identique pour les forfaits mensuels et annuels, mais la facturation diffère :

- **Forfait mensuel** : vous ne payez les limites supplémentaires que jusqu'à la fin de votre période de facturation en cours. Ensuite, elles sont renouvelées avec votre forfait.
- **Forfait annuel** : vous payez un mois à la fois. Les limites supplémentaires sont alors facturées séparément chaque mois jusqu'à la fin de votre forfait annuel.

<Note>
  Les profils de navigateur cloud et les limites cloud supplémentaires ne sont disponibles que sur les forfaits payants.
</Note>
