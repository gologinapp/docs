---
title: "Sessions actives"
---

La page **Sessions actives** vous offre une vue complète de tous les appareils et de tous les emplacements actuellement connectés à votre compte Gologin. Utilisez-la pour surveiller l'accès à votre compte, examiner les connexions suspectes et révoquer les sessions que vous ne reconnaissez pas, le tout depuis un seul endroit.

## Comment y accéder

1. Cliquez sur le **nom de votre espace de travail** dans le coin supérieur gauche de l'application Gologin
2. Sélectionnez **Paramètres et membres** dans le menu déroulant
3. Dans la barre latérale gauche, cliquez sur **Sessions actives**

## Ce que vous verrez

**Cet appareil**

En haut de la page, Gologin met en évidence la session que vous utilisez actuellement et l'indique comme **en ligne**. Votre adresse IP actuelle s'affiche sous le nom de l'appareil.

Cette section contient également le bouton **Terminer toutes les autres sessions**.

**Liste des sessions actives**

Sous votre appareil actuel figurent toutes les autres sessions actives. Chaque entrée indique :

| Champ | Description |
| :-- | :-- |
| **Appareil / Plateforme** | La plateforme utilisée pour se connecter (par exemple, Gologin Web, application Android, Linux). |
| **Version de l'application** | La version du client Gologin au moment de la connexion. |
| **L' adresse IP** | L'adresse IP associée à cette session. |
| **Dernier actif** | Le temps écoulé depuis la dernière utilisation de la session. |
| **Bouton Révoquer** | Un bouton propre à chaque session pour déconnecter immédiatement cette session précise. |

## Actions possibles

**Terminer toutes les autres sessions**

Cliquez sur le bouton **Terminer toutes les autres sessions** pour déconnecter instantanément tous les appareils, sauf celui que vous utilisez actuellement. C'est le moyen le plus rapide de sécuriser votre compte si vous soupçonnez un accès non autorisé.

**Révoquer une seule session**

Chaque session de la liste possède son propre bouton **Révoquer**. Utilisez-le pour déconnecter un appareil précis sans affecter les autres. C'est pratique lorsque vous reconnaissez la plupart des sessions, mais que vous souhaitez supprimer une entrée inconnue.
