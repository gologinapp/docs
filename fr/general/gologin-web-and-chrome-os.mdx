## Gologin Web ([app.gologin.com](http://app.gologin.com))

Vous pouvez accéder à tous vos profils depuis n'importe quel navigateur à l'adresse **app.gologin.com**, sans installer l'application de bureau. C'est pratique pour :

- Les appareils Chrome OS
- Les ordinateurs partagés ou restreints
- Un accès rapide depuis n'importe quel appareil

**Des limites de sessions cloud s'appliquent :**

- Professional : 1 session cloud simultanée
- Business : 2 sessions cloud simultanées
- Enterprise : 3 sessions cloud simultanées

Toutes les données des profils sont synchronisées entre les versions de bureau et web.

## Chrome OS

Gologin fonctionne sur Chrome OS via la version web (app.gologin.com). Aucune installation n'est nécessaire : ouvrez votre navigateur et connectez-vous. Les limites de sessions cloud dépendent de votre offre.
