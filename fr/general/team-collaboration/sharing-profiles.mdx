---
title: "Comment partager des profils"
---

Si vous avez besoin de partager un seul profil ou quelques profils, vous n'avez pas besoin de passer par les membres de l'équipe : vous pouvez utiliser directement la fonction **Partager le profil** depuis votre liste de profils !

## Ce qui compte comme un partage de profil

**1 partage = 1 instance d'un profil partagé.**\
Par exemple : si vous partagez **2 profils avec 5 personnes** ou **10 profils avec un seul collègue**, dans les deux cas, cela utilisera **10 partages**.

<Check>
  Seuls les partages existants sont comptabilisés dans la limite. Si vous supprimez des partages inutiles, vous récupérez les emplacements de partage correspondants.
</Check>

## Comment partager un profil

<Info>
  **Remarque** : vous pouvez partager plusieurs profils à la fois grâce aux [actions groupées](/fr/browser-profiles/profile-management/bulk-actions).
</Info>

1. Survolez les **trois points** d'un profil \> **Partager**
2. Saisissez l'**adresse e-mail de l'utilisateur**
3. Sélectionnez un rôle :
   1. **Peut courir** - peut **Voir** et **Exécuter** les profils que vous avez partagés
   2. **Peut éditer** - peut **Exécuter**, **Cloner** et **Modifier** les paramètres des profils que vous avez partagés
   3. **Accès complet** - identique à **Modifier**, mais peut aussi **Partager** des profils
4. Cliquez sur **Partager** pour appliquer les modifications

<Frame>
  ![Comment partager un profil](/images/how_to_share_profile.gif)
</Frame>

Une fois le partage appliqué, le profil apparaît dans la liste de profils de votre collègue.

Pour supprimer un partage, vous pouvez **cliquer sur le rôle** \> **Supprimer** dans le même menu.
