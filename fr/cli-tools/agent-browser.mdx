---
title: "Gologin Agent Browser CLI"
description: "CLI d'automatisation de navigateur pour les agents IA, qui exécute des profils Gologin dans Cloud Browser ou dans Orbita en local, avec des instantanés, des références et un démon persistant"
---

Gologin Agent Browser CLI transforme les profils de navigateur Gologin en un environnement d'exécution persistant et scriptable pour les agents IA. Les sessions s'exécutent dans Gologin Cloud Browser ou dans Orbita sur votre propre machine. Il fournit des instantanés de page compacts, des interactions basées sur des références, une mémoire de session et une sortie adaptée au shell.

Contrairement à l'écriture de code Puppeteer/Playwright à partir de zéro, cette CLI offre aux agents un ensemble de commandes prêt à l'emploi pour l'automatisation du navigateur : pas de code répétitif, pas de code de gestion de session.

---

## Exécution dans le cloud ou en local

La CLI propose deux environnements d'exécution avec les mêmes commandes. Les deux utilisent les profils, les empreintes et les proxys Gologin, et un démon maintient les sessions actives entre les appels à la CLI.

| | `cloud` (par défaut) | `local` |
|---|---|---|
| Où le navigateur s'exécute | Gologin Cloud Browser | Orbita sur votre machine |
| ID du profil | Facultatif : sans ID, un profil cloud temporaire est créé | Obligatoire |
| Idéal pour | Sessions parallèles, sessions distantes, machines qui ne doivent pas exécuter de navigateur | Préchauffage de profils, premières connexions, cookies et état du profil en local, correspondance avec votre système d'exploitation |

Choisissez l'environnement d'exécution pour chaque commande avec `--runtime cloud|local|auto`, ou définissez une fois `GOLOGIN_AGENT_BROWSER_RUNTIME` :

```bash
gologin-agent-browser open https://example.com
gologin-agent-browser open https://example.com --runtime local --profile your_profile_id
```

Par défaut (`auto`), les commandes de profil, de runbook et de tâche s'exécutent en local, et toutes les autres s'exécutent dans le cloud. Une fois qu'une session locale est ouverte, passez aussi `--runtime local` aux commandes suivantes. Consultez [Exécution locale](/fr/cli-tools/local-agent-browser) pour connaître les prérequis et les commandes réservées au mode local.

## Installation

```bash
npm install -g gologin-agent-browser-cli
```

Ou exécutez-la sans installation globale :

```bash
npx gologin-agent-browser-cli --help
```

Nécessite Node.js >= 18. L'exécution locale nécessite Node.js 20 ou une version ultérieure.

| Variable | Obligatoire | Description |
|---|---|---|
| `GOLOGIN_TOKEN` | Oui (pour `open` et les commandes d'API) | Jeton d'API Gologin |
| `GOLOGIN_PROFILE_ID` | Facultatif | ID du profil par défaut |
| `GOLOGIN_AGENT_BROWSER_RUNTIME` | Facultatif | Environnement d'exécution par défaut : `cloud`, `local` ou `auto` |
| `GOLOGIN_DAEMON_PORT` | Facultatif | Port du démon (par défaut : `44777` pour le cloud, `44778` pour le local) |
| `GOLOGIN_CONNECT_BASE` | Facultatif | Point de terminaison de Cloud Browser (par défaut : `https://cloudbrowser.gologin.com/connect`) |
| `GOLOGIN_EXECUTABLE_PATH` | Facultatif | Chemin de l'exécutable Orbita pour l'exécution locale |

### Obtenir un jeton

1. Inscrivez-vous ou connectez-vous sur [gologin.com](https://gologin.com)
2. Ouvrez **API & MCP** dans le tableau de bord
3. Ouvrez l'onglet **API**
4. Cliquez sur **Nouveau jeton**
5. Copiez le jeton d'accès généré

```bash
export GOLOGIN_TOKEN='your_gologin_token'
```

### Fichier de configuration

`~/.gologin-agent-browser/config.json`

## Architecture

Deux composants :

1. **La CLI `gologin-agent-browser`** : analyse les commandes, choisit l'environnement d'exécution, démarre automatiquement le démon correspondant et affiche une sortie compacte
2. **Des démons locaux persistants**, un par environnement d'exécution : ils gèrent les sessions de navigateur actives, se connectent à Gologin Cloud Browser ou à Orbita en local via Playwright `connectOverCDP`, conservent la page active en mémoire, construisent les instantanés, résolvent les références et suivent les métadonnées de session

Le transport est uniquement local. Le démon cloud écoute sur :
- Un socket Unix à `${TMPDIR:-/tmp}/gologin-agent-browser.sock`
- Un serveur HTTP local sur `127.0.0.1:${GOLOGIN_DAEMON_PORT:-44777}`

Dans l'environnement d'exécution cloud, si vous ne fournissez pas d'ID de profil, le démon crée un profil cloud Gologin temporaire via l'API.

## Fonctionnement des références

`snapshot` affiche une vue compacte de la page et attribue des références telles que `@e1`, `@e2`, `@e3` aux éléments interactifs. Vous agissez directement dessus :

```bash
gologin-agent-browser snapshot
# output shows page content with refs like @e1, @e2, @e3...

gologin-agent-browser click @e3
gologin-agent-browser type @e5 "search query"
gologin-agent-browser fill @e7 "username"
```

Les références sont fournies au mieux et doivent être régénérées après une navigation ou une modification importante du DOM. Les commandes acceptent aussi des sélecteurs CSS à la place des références. Sur les pages dynamiques, `find` est généralement une meilleure solution de repli que des références obsolètes : il localise l'élément sur la page active et agit dessus en une seule étape.

```bash
gologin-agent-browser find label "Email" fill "user@example.com"
gologin-agent-browser find role button click --name "Submit"
```

## Démarrage rapide

```bash
export GOLOGIN_TOKEN='your_token'

# open a page in cloud browser
gologin-agent-browser open https://example.com

# read the page as a compact snapshot
gologin-agent-browser snapshot

# interact with elements
gologin-agent-browser click @e3
gologin-agent-browser type @e5 "hello world"

# take a screenshot
gologin-agent-browser screenshot ./page.png

# close the session
gologin-agent-browser close
```

## Exemple de boucle d'agent

Une boucle typique d'agent IA :

```
1. open <url>
2. snapshot          → agent reads page content
3. click/type/fill   → agent acts on refs
4. snapshot          → agent reads result
5. repeat 3-4 as needed
6. screenshot        → save artifact
7. close
```

## Référence complète des commandes

### Diagnostic

| Commande | Description |
|---|---|
| `doctor` | Vérifie l'état du démon et la connectivité |

### Gestion des sessions

| Commande | Description |
|---|---|
| `open <url>` | Ouvre une URL dans une session de navigateur |
| `close` | Ferme la session en cours (`--all` ferme toutes les sessions de ce démon) |
| `sessions` | Liste les sessions actives (`--prune` supprime les sessions obsolètes) |
| `current` | Affiche les informations de la session en cours |

### Lecture de la page

| Commande | Description |
|---|---|
| `snapshot` | Instantané textuel compact avec les références des éléments |
| `screenshot <path>` | Enregistre une capture d'écran de la page |
| `pdf <path>` | Enregistre la page au format PDF |
| `get <kind> [target]` | Récupère les propriétés de la page |

### Interaction

| Commande | Description |
|---|---|
| `click <ref>` | Clique sur un élément |
| `dblclick <ref>` | Double-clic |
| `type <ref> <text>` | Saisit du texte (ajoute à l'existant) |
| `fill <ref> <text>` | Remplit un champ (remplace le contenu) |
| `hover <ref>` | Survole un élément |
| `select <ref> <value>` | Sélectionne une valeur dans une liste déroulante |
| `check <ref>` / `uncheck <ref>` | Coche ou décoche une case |
| `focus <ref>` | Place le focus sur un élément |
| `find <by> <locator> <action> [value]` | Trouve un élément par `role`, `text`, `label`, `placeholder`, `first`, `last` ou `nth`, puis effectue `click`, `fill`, `type` ou `hover` dessus, ou lit son `text` |

### Clavier et défilement

| Commande | Description |
|---|---|
| `press <key> [target]` | Appuie sur une touche du clavier |
| `scroll <direction> [pixels]` | Fait défiler la page |
| `scrollintoview <ref>` | Fait défiler jusqu'à rendre l'élément visible |

### Navigation

| Commande | Description |
|---|---|
| `back` | Page précédente |
| `forward` | Page suivante |
| `reload` | Recharge la page |
| `wait <target\|ms>` | Attend un élément ou la fin d'un délai |

### Onglets

| Commande | Description |
|---|---|
| `tabs` | Liste les onglets ouverts |
| `tabopen [url]` | Ouvre un nouvel onglet |
| `tabfocus <index>` | Passe à un onglet |
| `tabclose [index]` | Ferme un onglet |

### Cookies et stockage

| Commande | Description |
|---|---|
| `cookies` | Exporte les cookies |
| `cookies-import <file>` | Importe des cookies |
| `cookies-clear` | Supprime les cookies |
| `storage-export [path]` | Exporte le localStorage |
| `storage-import <file>` | Importe le localStorage |
| `storage-clear` | Vide le localStorage |

### Avancé

| Commande | Description |
|---|---|
| `eval <expression>` | Évalue du JavaScript dans la page |
| `upload <ref> <file...>` | Téléverse des fichiers |

### Profils, proxys et API Gologin

Ces commandes appellent l'API Gologin avec votre jeton et n'ont pas besoin du démon du navigateur.

| Commande | Description |
|---|---|
| `api <METHOD> <path>` | Appelle n'importe quel point de terminaison de l'API REST Gologin |
| `browser <action>` | Profils : lister, obtenir, créer, mettre à jour, supprimer, cookies, proxy, démarrage et arrêt dans le cloud, import et export |
| `proxy <action>` | Proxys : lister, ajouter un proxy Gologin, mettre à jour, supprimer, trafic |
| `workspace`, `folder`, `share`, `template` | Espaces de travail et membres, dossiers, partage, modèles de profil |
| `user`, `deleted-profile` | Informations du compte et jetons de développement, restauration des profils supprimés |
| `cloud-usage` | Utilisation de Cloud Browser pour un profil ou un espace de travail |
| `profile-cloud`, `profile-cookies`, `profile-fingerprint`, `profile-proxy`, `profile-ua` | Raccourcis : démarrer ou arrêter un profil dans le cloud, exporter ou importer ses cookies, actualiser son empreinte, ajouter un proxy, mettre à jour son user agent |

```bash
gologin-agent-browser browser list --page 1
gologin-agent-browser proxy add-gologin your_profile_id --country us --type residential
gologin-agent-browser cloud-usage --profile your_profile_id
gologin-agent-browser api GET /browser/your_profile_id
```

Ajoutez `--help` à n'importe quelle commande pour afficher son mode d'emploi.

## Cas d'usage et exemples

### Vérifier si votre site réussit les tests anti-détection

```bash
gologin-agent-browser open https://iphey.com/ --profile your_profile_id
gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # read the trust score
gologin-agent-browser screenshot ./iphey-result.png
gologin-agent-browser close
```

### Se connecter à une application web et extraire les données du tableau de bord

```bash
gologin-agent-browser open https://app.example.com/login
gologin-agent-browser snapshot

# agent reads snapshot, finds login form
gologin-agent-browser fill @e4 "user@company.com"
gologin-agent-browser fill @e6 "password"
gologin-agent-browser click @e8

gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # agent reads dashboard content

# navigate to the report page
gologin-agent-browser click @e12   # "Reports" link
gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # agent extracts report data
gologin-agent-browser screenshot ./report.png
gologin-agent-browser close
```

### Remplir un formulaire en plusieurs étapes

```bash
gologin-agent-browser open https://forms.example.com/apply

# step 1: personal info
gologin-agent-browser snapshot
gologin-agent-browser fill @e3 "John Doe"
gologin-agent-browser fill @e5 "john@example.com"
gologin-agent-browser select @e7 "United States"
gologin-agent-browser click @e9   # Next

# step 2: upload and submit
gologin-agent-browser wait 1000
gologin-agent-browser snapshot
gologin-agent-browser upload @e4 ./resume.pdf
gologin-agent-browser check @e6   # agree to terms
gologin-agent-browser click @e8   # Submit

gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # confirm success
gologin-agent-browser close
```

### Faire des captures d'écran des pages de concurrents

```bash
# use different profiles with different geos
for profile in us_profile de_profile jp_profile; do
  gologin-agent-browser open https://competitor.com --profile $profile
  gologin-agent-browser wait 3000
  gologin-agent-browser screenshot ./${profile}-homepage.png
  gologin-agent-browser close
done
```

### Effectuer une recherche sur un site qui bloque le scraping

Certains sites exigent l'exécution de JavaScript, une connexion ou une interaction avant d'afficher les résultats. Utilisez le navigateur pour effectuer la recherche :

```bash
gologin-agent-browser open https://protected-directory.com
gologin-agent-browser snapshot
gologin-agent-browser find placeholder "Search" fill "machine learning engineer San Francisco"
gologin-agent-browser press Enter
gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # agent reads search results
gologin-agent-browser screenshot ./search-results.png
gologin-agent-browser close
```

### Enregistrer et restaurer l'état d'une session

Exportez les cookies et le stockage pour les réutiliser d'une session à l'autre :

```bash
# after logging in
gologin-agent-browser cookies --output ./session-cookies.json
gologin-agent-browser storage-export ./session-storage.json
gologin-agent-browser close

# later, restore the session
gologin-agent-browser open https://app.example.com
gologin-agent-browser cookies-import ./session-cookies.json
gologin-agent-browser storage-import ./session-storage.json
gologin-agent-browser reload
gologin-agent-browser snapshot     # already logged in
```

## Sessions parallèles

Utilisez des ID `--session` explicites pour des tâches cloud indépendantes. Nettoyez avec `close --all` ou `sessions --prune --older-than-ms`.

---

## Règles relatives aux proxys

- Profils préconfigurés : le proxy est défini sur le profil via le tableau de bord ou l'API Gologin, par exemple `proxy add-gologin <profileId> --country us`
- Profils cloud temporaires : aucun proxy, ou votre propre proxy avec `--proxy-host` et `--proxy-port` (ainsi que `--proxy-mode http|socks4|socks5`, `--proxy-user`, `--proxy-pass`)
- Dans l'environnement d'exécution cloud, `open` n'accepte pas `--proxy-country`. Pour utiliser le trafic d'un proxy Gologin depuis un pays donné, ajoutez un proxy Gologin à un profil et ouvrez-le avec `--profile`
- Dans l'environnement d'exécution local, `open`, `profile-create` et `profile-update` acceptent `--proxy-country`
