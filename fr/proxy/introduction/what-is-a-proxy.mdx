---
title: "Qu'est-ce qu'un proxy ?"
---

Un proxy est un serveur qui agit comme intermédiaire entre votre appareil et Internet.\
Au lieu de se connecter directement à un site web, votre trafic passe par le serveur proxy.

Les sites web voient ainsi l'**adresse IP du proxy** à la place de votre véritable adresse IP, comme si la requête provenait d'un autre endroit.

Lorsqu'il est utilisé avec **Gologin**, un proxy fonctionne en complément de l'empreinte de navigateur d'un profil.\
Chaque profil peut se connecter via un proxy différent, ce qui permet aux sites web de les reconnaître comme des appareils distincts.

## Pourquoi l'utilisation d'un proxy est importante

Utiliser un proxy est **essentiel** lorsque vous travaillez avec Gologin.

Les sites web suivent l'activité des utilisateurs en analysant à la fois les **empreintes de navigateur et l'adresse IP**.\
Même si vous utilisez des profils de navigateur différents, plusieurs comptes seront tout de même liés s'ils partagent la même adresse IP.

Un proxy permet à chaque profil de fonctionner depuis un emplacement réseau différent, ce qui réduit le risque que vos comptes soient associés au même appareil.

## Où obtenir un proxy

Gologin prend en charge les **fournisseurs de proxys tiers** ainsi que les **proxys Gologin intégrés**.

Vous pouvez connecter des proxys issus de fournisseurs externes en saisissant les identifiants du proxy dans les paramètres du profil.

Gologin propose également des options de proxy intégrées, qui peuvent être configurées directement dans l'application.

Pour consulter une liste de fournisseurs de proxys recommandés, voir [**Fournisseurs de proxys recommandés**](https://gologin.com/proxies/proxy-type/).
