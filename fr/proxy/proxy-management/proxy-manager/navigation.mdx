title: "Navigation"
---

Toute la gestion des proxies est accessible directement depuis la page **Tous les profils**. Il suffit de cliquer sur le champ **Proxy et emplacement** du profil et de commencer à le modifier.

### Ajouter un proxy

Pour ajouter un ou plusieurs proxies :

1. Copiez votre proxy
2. Survolez la colonne **Proxy et emplacement** de votre profil
3. Cliquez sur le bouton **Coller les proxies**
   - vous pouvez aussi utiliser les **raccourcis clavier** de votre système pour coller les proxies

<Frame>
  ![Ajout d'un proxy](/images/adding_proxy.gif)
</Frame>

### Vérifier un proxy

Pour vérifier que le proxy fonctionne, **cliquez simplement sur les flèches** à côté du nom du proxy sur la page **Tous les profils**.\
Le pays du proxy et l'adresse IP sortante actuelle s'afficheront.

<Frame>
  ![Vérification d'un proxy](/images/checking_proxy.gif)
</Frame>

### Modifier les paramètres d'un proxy

Pour modifier les paramètres du proxy, comme l'adresse IP ou le mot de passe : **cliquez sur le proxy** \> **cliquez sur l'icône en forme de crayon** \> cliquez sur **Sauvez** après avoir effectué vos modifications.

<Frame>
  ![Modification d'un proxy](/images/editing_proxy.gif)
</Frame>

### Dissocier un proxy d'un profil

Pour retirer un proxy d'un profil sans le supprimer : **cliquez sur le proxy**, puis **cliquez sur la croix (X) pour le dissocier**.

<Frame>
  ![Dissocier un proxy](/images/unlink_proxy.gif)
</Frame>

### Supprimer un proxy

Pour supprimer un proxy, **cliquez sur n'importe quel proxy** afin d'ouvrir le gestionnaire de proxies \> faites un **clic droit** sur le proxy que vous souhaitez supprimer \> cliquez sur **Supprimer le proxy** \> **Confirmer** votre choix.

<Frame>
  ![Suppression d'un proxy](/images/deleting_proxy.gif)
</Frame>

### Copier des proxies

Pour copier un proxy, **cliquez sur n'importe quel proxy** afin d'ouvrir le gestionnaire de proxies \> faites un **clic droit** sur le proxy que vous souhaitez copier \> cliquez sur **Copier le proxy**.

<Frame>
  ![Copier un proxy](/images/copy_proxy.gif)
</Frame>

### Actions groupées sur les proxies

Vous pouvez copier ou supprimer **plusieurs proxies à la fois**. Cliquez n'importe où dans la colonne **Proxy et emplacement** pour accéder au gestionnaire de proxies \> faites un **clic droit sur le proxy** \> **Sélectionner un proxy** \> continuez à sélectionner les proxies concernés \> cliquez sur **Copie** ou **Supprimer** en bas de la fenêtre du gestionnaire de proxies.

<Frame>
  ![Actions groupées sur les proxies](/images/bulk_proxy_actions.gif)
</Frame>
