title: "Ajouter et gérer des proxies"
---

Il existe plusieurs façons de connecter vos proxies dans le navigateur Gologin. Cet article les présente toutes, de la plus évidente à la plus avancée.

Les fournisseurs de proxies tiers vous donnent généralement **une IP, un port, un nom d'utilisateur et un mot de passe** comme point de connexion. Vous pouvez coller ces identifiants presque partout dans les différents paramètres de proxy, et un nouveau proxy sera ajouté à votre liste de proxies.

Nous prenons en charge les formats de collage de proxies suivants :

```text
192.168.0.1:8000:login:password
​﻿http://192.168.0.1:8000:login:password:name
﻿socks5://login:password@192.168.0.1:8000:name
﻿socks5://login:password@192.168.0.1:8000[https://change-my-ip.com]:name
​﻿http://192.168.0.1:8000:login
​﻿http://192.168.0.1:8000:myproxy:pass[https://change-my-ip.com] 
​﻿http://192.168.0.1:8000:myproxy:pass[https://change-my-ip.com]:name4
```

## La méthode la plus simple

1. Sur la page **Tous les profils**, repérez la colonne **Emplacement** et cliquez sur le bouton **\+** du profil auquel vous souhaitez ajouter un proxy.
2. Dans la fenêtre qui s'ouvre, cliquez sur l'**icône d'ordinateur**, puis saisissez votre **IP**, votre **port**, votre **nom d'utilisateur** et **Le mot de passe**. 
   - Le protocole HTTP ou SOCKS est sélectionné automatiquement selon la disponibilité, et vous pourrez le modifier ensuite.
3. Cliquez sur **Connecter** : le proxy est maintenant ajouté à votre profil !
4. Gologin vérifie aussitôt votre proxy. Vous verrez un indicateur vert si le proxy fonctionne correctement, ou rouge s'il ne fonctionne pas.

Vous pouvez aussi coller une chaîne de proxy complète, par exemple `ip:port:login:password`, directement dans la colonne **Proxy et emplacement** d'un profil : Gologin ajoute le proxy avec tous ses détails. Notez que le champ **IP** du formulaire de proxy n'accepte que l'adresse IP, et non la chaîne complète.

Vous pouvez coller les proxies un par un ou en masse sur la même page. Copiez plusieurs proxies et collez-les tous en une fois dans la colonne Emplacement. Utilisez les **raccourcis clavier** de votre système ou le bouton **Coller les proxies**. Vous pourrez ensuite répartir vos nouveaux proxies entre les profils.

## Autres façons d'ajouter un ou plusieurs proxies

### Sur la page Proxies

Rendez-vous sur la page **Proxies** dans le menu de gauche \> **Importer des proxies** \> collez vos proxies, puis cliquez sur **Importer des proxies**.

<Frame>
  ![Page d'importation de proxies](/images/import_proxies_page.gif)
</Frame>

### Avec la sélection multiple de profils

**Sélectionnez plusieurs profils de navigateur** \> cliquez sur **Procuration** dans la barre d'actions groupées \> **saisissez les proxies** dans la nouvelle fenêtre \> cliquez sur **Mettre à jour le proxy.**

<Frame>
  ![Mise à jour groupée des proxies](/images/bulk_proxy_update.gif)
</Frame>

### Dans les paramètres du profil

Cliquez sur les **3 points du profil** \> **Paramètres** \> **Procuration** \> **Votre mandataire**

<Frame>
  ![Paramètres de proxy du profil](/images/proxy_profile_settings.gif)
</Frame>

## Changer l'IP avec un lien de changement d'IP

Certains fournisseurs tiers, généralement de proxies mobiles rotatifs, vous donnent un lien qui change l'IP du proxy. Si votre fournisseur vous en fournit un, ajoutez-le dans les paramètres du proxy (voir les formats en haut de cette page). Ensuite, survolez le proxy dans la colonne **Proxy et emplacement** et cliquez sur **Changer IP**.

Les proxies Gologin ne permettent pas de changer l'IP avec un lien.

## Correction rapide pour un proxy qui ne fonctionne pas

Si un proxy tiers échoue à la vérification lorsque vous lancez un profil, Gologin affiche **Le proxy ne fonctionne pas ou est trop lent** avec un bouton **Correction rapide**. Cliquez sur **Correction rapide** pour remplacer votre proxy par un proxy Gologin du même pays, et le profil pourra alors se lancer. Les proxies Gologin consomment votre trafic proxy, vous devez donc disposer de trafic disponible.

![Correction rapide du proxy](/images/proxy_quick_fix.png "Correction rapide du proxy")

Si vous souhaitez continuer à utiliser votre propre proxy, cliquez sur **Pas maintenant**, puis corrigez ou remplacez le proxy.
