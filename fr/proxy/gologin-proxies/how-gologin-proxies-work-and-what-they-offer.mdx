---
title: "Comment fonctionnent les proxies Gologin"
---

Les proxies Gologin sont intégrés directement à l'environnement Gologin et peuvent être associés à des profils de navigateur sans configuration supplémentaire.

Lorsqu'un proxy est attribué à un profil, tout le trafic Internet de ce profil passe par le serveur proxy. Les sites web voient donc l'adresse IP du proxy et non votre véritable adresse IP.

Utiliser des proxies distincts pour différents profils permet de garder les sessions isolées et réduit le risque que plusieurs comptes soient liés entre eux.

## Types de proxies disponibles

Gologin propose plusieurs types de proxies :

- **Résidentiel rotatif** - facturé selon le trafic
- **Mobile rotatif** - facturé selon le trafic
- **Datacenter fixe (sticky)** - facturé selon le trafic
- **IP dédiée** - une IP statique qui vous est réservée, facturée sous forme d'abonnement de \$5/mois par IP

Les trois premiers types partagent le volume de trafic inclus dans votre offre et utilisent une adresse issue d'un pool partagé. Une IP dédiée est à vous seul, ne change pas et n'a aucune limite de trafic.

## Pays des proxies

**Pour les proxies facturés au trafic (résidentiel, mobile, datacenter) :** lorsque vous achetez du trafic proxy Gologin, vous avez accès à tous nos pays de proxy. Vous n'êtes pas limité à un seul pays : le trafic peut être utilisé n'importe où dans la liste. Des dizaines de pays sont disponibles et nous en ajoutons de nouveaux régulièrement. Pour consulter la liste complète, rendez-vous directement dans l'application Gologin.

**Pour l'IP dédiée :** vous achetez un pays à la fois. L'IP que vous recevez appartient au pays sélectionné et ne peut pas être déplacée vers un autre. Si vous avez besoin d'adresses dans plusieurs pays, achetez une IP dédiée distincte pour chacun.

Les IP dédiées sont actuellement disponibles dans les pays suivants :

- Brésil
- France
- Allemagne
- Hong Kong
- Roumanie
- Turquie
- Royaume-Uni
- États-Unis

<Note>
  Vous pouvez acheter plusieurs IP dédiées dans le même pays. Chaque achat vous donne une adresse différente, et ces adresses sont regroupées sous ce pays dans le gestionnaire de proxies.
</Note>

## Ce qu'offrent les proxies Gologin

L'utilisation des proxies Gologin présente plusieurs avantages :

- configuration rapide, sans paramétrage tiers
- attribution simple des proxies aux profils
- intégration avec les profils de navigateur Gologin
- gestion des proxies simplifiée directement dans l'application
