---
title: "Comment fonctionnent les proxys Gologin"
---

Les proxys Gologin sont intégrés directement à l'environnement Gologin et peuvent être associés à des profils de navigateur sans configuration supplémentaire.

Lorsqu'un proxy est attribué à un profil, tout le trafic internet de ce profil passe par le serveur proxy. Les sites web voient donc l'adresse IP du proxy et non votre véritable adresse IP.

Utiliser des proxys distincts pour différents profils permet de garder les sessions isolées et réduit le risque que plusieurs comptes soient liés entre eux.

## Types de proxys disponibles

Gologin propose plusieurs types de proxys :

- **Résidentiel rotatif** - payé au trafic
- **Mobile rotatif** - payé au trafic
- **Datacenter fixe (sticky)** - payé au trafic
- **IP dédiée** - une IP statique qui vous est réservée, payée par abonnement de \$5/mois par IP

Les trois premiers types partagent le volume de trafic de votre forfait et utilisent une adresse issue d'un pool partagé. Une IP dédiée vous appartient exclusivement, ne change pas et n'a aucune limite de trafic.

## Pays des proxys

**Pour les proxys facturés au trafic (résidentiel, mobile, datacenter) :** lorsque vous achetez du trafic proxy Gologin, vous avez accès à tous nos pays de proxys. Vous n'êtes pas limité à un seul pays : le trafic peut être utilisé partout dans la liste. Nous proposons des dizaines de pays et en ajoutons de nouveaux de temps à autre. Pour consulter la liste complète, rendez-vous directement dans l'application Gologin.

**Pour l'IP dédiée :** vous achetez un pays à la fois. L'IP que vous recevez appartient au pays que vous avez sélectionné et ne peut pas être déplacée vers un autre. Si vous avez besoin d'adresses dans plusieurs pays, achetez une IP dédiée distincte pour chacun. Vous choisissez uniquement le pays : il n'est pas possible de sélectionner une ville précise.

Les IP dédiées sont actuellement disponibles dans les pays suivants :

- Brésil
- France
- Allemagne
- Hong Kong
- Roumanie
- Turquie
- Royaume-Uni
- États-Unis

<Note>
  Vous pouvez acheter plusieurs IP dédiées dans le même pays. Chaque achat vous donne une adresse différente, et elles sont regroupées sous ce pays dans le gestionnaire de proxys.
</Note>

## Ce qu'offrent les proxys Gologin

L'utilisation des proxys Gologin présente plusieurs avantages :

- configuration rapide, sans configuration auprès d'un tiers
- attribution simple des proxys aux profils
- intégration avec les profils de navigateur Gologin
- gestion des proxys simplifiée au sein de l'application
