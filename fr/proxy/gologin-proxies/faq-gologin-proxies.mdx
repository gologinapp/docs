## Proxys basés sur le trafic

### Comment choisir le type de proxy ?

Pour choisir le type de proxy de votre nouvelle connexion, créez simplement un nouveau serveur proxy en cliquant sur **Choisir un emplacement ou un proxy dans le profil \> flèche à côté du pays \> Ajouter un nouveau serveur \> choisir le type de proxy**.

### De combien de trafic ai-je besoin ?

La quantité nécessaire dépend de votre usage. Elle varie principalement selon :

- La fréquence d'utilisation de vos profils de navigateur
- La durée de vos sessions
- La quantité de contenu lourd (vidéos, images ou audio, par exemple) que vous chargez pendant votre travail

### Que se passe-t-il lorsque j'ai consommé tout mon trafic proxy ? Vais-je être détecté ?

Si votre trafic est épuisé en cours d'utilisation, Gologin déconnecte simplement vos profils d'Internet et vous ne pourrez plus les utiliser tant que vous n'aurez pas rechargé du trafic ou changé pour un proxy tiers. Vous pourrez fermer les profils sans perte de données, car la synchronisation des profils n'utilise pas de trafic proxy.

### Si j'utilise mes propres proxys tiers, est-ce que je consomme du trafic proxy Gologin ?

Bien sûr que non ! Vous ne consommez du trafic proxy Gologin que si vous utilisez nos proxys.

### Est-ce que je reçois du trafic proxy Gologin d'essai gratuit après mon inscription sur mon forfait d'essai ?

Pour le moment, Gologin n'offre pas de trafic d'essai aux utilisateurs nouvellement inscrits. Vous pouvez toutefois acheter un peu de trafic et voir ensuite si les proxys Gologin répondent à vos besoins.

### Certains ports ne fonctionnent pas avec les proxys Gologin, pourquoi ?

Les ports dont le fonctionnement est garanti sont le 80 et le 443. Ce sont les ports standards pour le trafic web ordinaire.

Tous les autres ports, utilisés principalement pour l'envoi de spam, les attaques DDoS et les attaques par force brute, sont bloqués.

## IP dédiée

### Quelle est la différence entre les proxys ISP, les proxys statiques et l'IP dédiée ?

Aucune : ce sont trois noms pour la même chose. Vous pouvez les croiser tous les trois sur le web. Dans Gologin, cette fonctionnalité s'appelle **IP dédiée**.

### Qu'est-ce qu'une IP dédiée ?

C'est une adresse IP unique qui vous est réservée et que personne d'autre n'utilise. Elle provient d'un véritable fournisseur d'accès à Internet, mais elle est hébergée dans un centre de données. Elle offre ainsi la vitesse et la stabilité d'un proxy de centre de données, tout en ressemblant à une connexion domestique ordinaire aux yeux des sites web. Elle ne change jamais et n'a aucune limite de trafic.

### J'ai un forfait annuel. Pourquoi ai-je été facturé plus de 5 \$ ?

Une IP dédiée est liée à votre abonnement principal et prend toujours fin en même temps que lui : vous payez donc les mois restants. Si votre forfait annuel a encore 7 mois à courir, 35 \$ vous sont facturés d'avance. Un mois entamé est facturé comme un mois complet.

### J'ai payé, mais je ne vois mon proxy IP dédiée nulle part

L'attribution de l'adresse à votre compte prend 5 à 7 minutes, et aucune notification n'est envoyée lorsqu'elle est prête. Patientez quelques minutes et actualisez la page **Proxys** : l'adresse y apparaîtra.

### Une IP dédiée utilise-t-elle le trafic proxy de mon forfait ?

Non. Le trafic passant par une IP dédiée est illimité et n'entame pas votre quota en Go. Même si votre quota est entièrement épuisé, les profils qui utilisent une IP dédiée continuent de fonctionner.

### Ai-je encore besoin de trafic proxy si j'ai une IP dédiée ?

Uniquement pour les profils qui utilisent nos proxys rotatifs. Si tous vos profils fonctionnent avec une IP dédiée, votre quota de trafic reste simplement inutilisé.

### Mon IP restera-t-elle la même avec une IP dédiée ?

Oui. Tant que votre abonnement est actif et se renouvelle, vous conservez la même adresse.

### J'ai payé en cryptomonnaie : mon IP dédiée sera-t-elle renouvelée ?

Non. Les paiements en cryptomonnaie ne peuvent pas être renouvelés automatiquement : l'IP fonctionne donc pour la période que vous avez payée, puis s'arrête. Vous ne pourrez pas récupérer la même adresse par la suite. Si vous souhaitez conserver une adresse sur le long terme, payez par carte.
