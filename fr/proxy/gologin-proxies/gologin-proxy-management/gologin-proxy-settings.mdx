## Paramètres de proxy disponibles

Si vous devez configurer des paramètres de proxy spécifiques, vous devez **créer une nouvelle connexion proxy**.

<Info>
  Remarque : vous ne pouvez pas modifier les paramètres d'une connexion proxy existante.
</Info>

Pour créer un nouveau proxy Gologin personnalisé :

1. Cliquez sur **Choisir l'emplacement** dans le profil de navigateur.
2. Cliquez sur la **flèche** à côté du pays du proxy sélectionné.
3. Sélectionnez **Ajouter un nouveau serveur**.<br />Vous pouvez alors configurer les paramètres suivants :
   - **Ville** - disponible pour certains des pays les plus populaires
   - **Nom** - un nom personnalisé pour la connexion proxy
   - **Type de proxy** - résidentiel, mobile ou datacenter
4. Cliquez sur **Connecter** pour appliquer le nouveau proxy.

## Vérifier la connexion et consulter les informations du proxy

Pour vérifier que le proxy fonctionne correctement et que vous disposez de suffisamment de trafic, cliquez sur l'icône des **flèches circulaires** à côté du drapeau du proxy. Depuis ce menu, vous pouvez également consulter :

- **Ville**
- **L' adresse IP**
- **Type de proxy**
- **Trafic restant**

Cela vous permet de confirmer rapidement que le proxy est actif et configuré comme prévu.

<Frame>
  ![Vérification du proxy Gologin](/images/checking_gologin_proxy.png)
</Frame>

## Dissocier un proxy

Si vous souhaitez dissocier un proxy Gologin du profil : **cliquez une fois sur le proxy**, puis **cliquez sur X**. Le proxy sera dissocié du profil, mais restera dans la liste du gestionnaire de proxys.

<Frame>
  ![Dissocier un proxy Gologin](/images/unlink_gologin_proxy.gif)
</Frame>

## Supprimer un proxy

Pour supprimer un proxy : **cliquez une fois sur le proxy dans un profil** pour accéder au gestionnaire de proxys, puis faites un **clic droit** \> **Supprimer le proxy** \> **confirmez votre choix**. Il sera supprimé de votre liste de proxys et pourra être restauré depuis les [Archives des proxys](/fr/proxy/proxy-management/proxy-manager/proxy-archive).

<Frame>
  ![Supprimer un proxy Gologin](/images/delete_gologin_proxy.gif)
</Frame>

## Copier les identifiants du proxy

Vous pouvez copier les identifiants d'un proxy Gologin (hôte, port, identifiant, mot de passe) pour les utiliser ailleurs. Pour cela : **cliquez sur un proxy** pour accéder au gestionnaire de proxys \> faites un **clic droit** \> **Copier le proxy**.

<Frame>
  ![Copier un proxy Gologin](/images/copy_gologin_proxy.gif)
</Frame>

## Actions groupées sur les proxys

Vous pouvez sélectionner plusieurs proxys dans le gestionnaire de proxys et effectuer des actions, telles que :

- sélectionner tous les proxys
- copier les proxys
- supprimer les proxys

Pour cela : **cliquez sur un proxy sur la page Tous les profils** \> faites un **clic droit** \> cliquez sur **Sélectionner un proxy**. Vous pouvez ensuite cocher les proxys et effectuer des actions à l'aide des boutons situés en bas du gestionnaire de proxys.

</Frame>
