---
title: "Ajouter votre premier proxy"
---

Ajouter votre premier proxy avec les paramètres par défaut est très simple !

Sur la page **Tous les profils**, cliquez sur **Choisir l'emplacement** sur un profil, puis **sélectionnez le pays**.

<Frame>
  ![Premier proxy Gologin](/images/first_gologin_proxy.gif)
</Frame>

Gologin sélectionne automatiquement le type de proxy en fonction du trafic dont vous disposez. Si vous avez acheté plusieurs types de proxys, il utilise le dernier type de proxy sélectionné.
