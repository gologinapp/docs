---
title: "Téléchargement et envoi de fichiers"
---

Lorsque vous lancez un profil dans le cloud, le navigateur ne s'exécute pas sur votre ordinateur : il s'exécute sur un serveur distant. Pour cette raison, le téléchargement et l'envoi de fichiers fonctionnent un peu différemment d'un navigateur local. Les fichiers passent par une étape intermédiaire via le conteneur cloud.

### Télécharger un fichier sur votre ordinateur

1. Téléchargez le fichier depuis le site web comme vous le feriez habituellement. Le fichier sera enregistré dans le conteneur cloud, et non sur votre machine locale
2. Cliquez sur l'icône **Fichiers** dans le coin inférieur gauche de la fenêtre du navigateur cloud
3. Cliquez sur le bouton **↓** à côté du nom du fichier
4. Une fenêtre de l'explorateur de fichiers s'ouvrira sur votre ordinateur local. Choisissez un dossier et enregistrez le fichier

### Envoyer un fichier vers un site web

1. Cliquez sur l'icône Fichiers dans le coin inférieur gauche de la fenêtre du navigateur cloud
2. Choisissez **Cliquez ou faites glisser des fichiers ici** et sélectionnez le fichier depuis votre ordinateur local. Le fichier sera envoyé vers le conteneur cloud
3. Sur le site web cible, cliquez sur le bouton d'envoi
4. Un explorateur de fichiers du conteneur distant s'ouvrira. Accédez au dossier **Téléchargements**, sélectionnez le fichier que vous avez envoyé, puis cliquez sur **Ouvrir**
