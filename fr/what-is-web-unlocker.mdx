---
title: "Qu'est-ce que Web Unlocker ?"
---

Web Unlocker est une API de scraping universelle. Envoyez n'importe quelle URL et recevez le HTML entièrement rendu, ou la page au format Markdown ou JSON, sans avoir à gérer de navigateurs ni de proxys.

Il remplace la partie navigateur et proxy de votre stack de scraping : le rendu, la gestion des proxys et les empreintes de navigateur sont pris en charge en un seul appel d'API. Les pages statiques et les sites riches en JavaScript passent par le même endpoint.

---

## Ce qu'il résout

Les sites web modernes sont difficiles à scraper. Un simple appel `curl` ou `requests` renvoie souvent une réponse vide ou un HTML incomplet, car le contenu est chargé par JavaScript. Web Unlocker s'occupe de :

- **Rendu JavaScript** — les pages sont chargées dans un vrai navigateur et entièrement exécutées avant la capture du contenu
- **Rotation intelligente des IP** — les requêtes passent par des IP résidentielles avec des empreintes de navigateur réalistes
- **Ciblage par niveau de prix** — les requêtes sont acheminées via le niveau de proxy adapté au site cible

---

## Ce que vous recevez

Une requête réussie renvoie la page dans un seul format. Choisissez-le avec le paramètre de requête `format` :

| `format` | Ce que vous obtenez |
| --- | --- |
| `html` (par défaut) | Le DOM complet rendu de la page |
| `markdown` | Le contenu de la page au format Markdown |
| `json` | Un objet JSON contenant l'URL de la page, les métadonnées de la requête et le HTML |

---

## Comment ça marche

Web Unlocker exécute un vrai navigateur Chromium dans le cloud pour chaque tâche. Lorsque vous envoyez une URL :

1. Un navigateur est lancé avec une IP résidentielle et une empreinte de navigateur réaliste
2. La page est ouverte, le JavaScript est exécuté et le contenu dynamique est chargé
3. Le HTML rendu est renvoyé, ou du Markdown ou du JSON si vous le demandez avec `format`

Vous n'avez aucune infrastructure à gérer. Pas de navigateurs à lancer, pas de listes de proxys à maintenir, pas de logique de rendu à développer. Web Unlocker remplace un framework d'automatisation de navigateur et un fournisseur de proxys par une seule requête HTTP.

## Comment l'utiliser

Envoyez une requête GET avec l'URL cible en paramètre de requête. La réponse est le HTML entièrement rendu.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Pour obtenir du Markdown ou du JSON à la place, ajoutez `format=markdown` ou `format=json` à la requête.

Consultez le [Guide de démarrage rapide](/fr/web-unlocker-quick-start) pour des exemples en Python et en JavaScript ainsi que pour les [codes d'erreur](/fr/web-unlocker-quick-start#gestion-des-erreurs), ou les [Cas d'usage](/fr/web-unlocker-use-cases) pour des modèles d'intégration courants.
