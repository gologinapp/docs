title: "Qu'est-ce que Web Unlocker ?"
---

Web Unlocker est une API de scraping universelle. Envoyez n'importe quelle URL et recevez le HTML entièrement rendu, ou la page au format Markdown ou JSON — sans infrastructure à gérer, sans blocages, sans requêtes échouées.

Il remplace entièrement votre stack de scraping : automatisation du navigateur, gestion des proxys, empreintes numériques, résolution de CAPTCHA — tout est pris en charge en un seul appel d'API. Que vous récupériez une simple page statique ou un site très protégé rendu par JavaScript, le même endpoint s'en charge.

---

## Ce qu'il résout

Les sites web modernes sont difficiles à scraper. Un simple appel `curl` ou `requests` renvoie souvent une page de vérification, une réponse vide ou un HTML incomplet, car le contenu est chargé par JavaScript. Web Unlocker gère tout cela automatiquement :

- **Rendu JavaScript** — les pages sont chargées dans un vrai navigateur et entièrement exécutées avant la capture du contenu
- **Contournement des protections anti-bot** — Cloudflare, DataDome, PerimeterX et les protections similaires sont gérés automatiquement
- **Rotation intelligente des IP** — les requêtes passent par des IP résidentielles propres, avec des empreintes de navigateur réalistes
- **Résolution de CAPTCHA** — les CAPTCHA courants sont résolus sans intervention manuelle
- **Ciblage par palier de prix** — les requêtes sont acheminées via le palier de proxy adapté au site cible

---

## Ce que vous recevez

Une requête réussie renvoie la page dans un seul format. Choisissez-le avec le paramètre de requête `format` :

| `format` | Ce que vous obtenez |
| --- | --- |
| `html` (par défaut) | Le DOM complet rendu de la page |
| `markdown` | Le contenu de la page au format Markdown |
| `json` | Un objet JSON contenant l'URL de la page, les métadonnées de la requête et le HTML |

## Comment ça marche

Web Unlocker exécute un vrai navigateur Chromium dans le cloud pour chaque tâche. Lorsque vous envoyez une URL :

1. Un navigateur est lancé avec une IP résidentielle et une empreinte de navigateur réaliste
2. La page est chargée, le JavaScript est exécuté et le contenu dynamique est récupéré
3. Les défis anti-bot et les CAPTCHA sont gérés automatiquement
4. Le HTML rendu est renvoyé, ou le Markdown ou le JSON si vous le demandez avec `format`

Vous n'avez aucune infrastructure à gérer. Pas de navigateurs à démarrer, pas de listes de proxys à maintenir, pas de logique de contournement à développer. Web Unlocker remplace en pratique toute une stack de scraping — framework d'automatisation du navigateur, fournisseur de proxys, solution anti-bot — par une simple requête HTTP.

## Comment l'utiliser

Envoyez une requête GET avec l'URL cible en paramètre de requête. La réponse est le HTML entièrement rendu.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Pour obtenir du Markdown ou du JSON à la place, ajoutez `format=markdown` ou `format=json` à la requête.

Consultez le [Démarrage rapide](/fr/web-unlocker-quick-start) pour des exemples en Python et JavaScript ainsi que les [codes d'erreur](/fr/web-unlocker-quick-start#handling-errors), ou les [Cas d'usage](/fr/web-unlocker-use-cases) pour des modèles d'intégration courants.
