title: "Qu'est-ce que Web Unlocker ?"
---

Web Unlocker est une API de scraping universelle. Envoyez n'importe quelle URL et recevez en retour le HTML entièrement rendu, une capture d'écran et une archive réseau — sans infrastructure à gérer, sans blocages et sans requêtes échouées.

Il remplace entièrement votre stack de scraping : automatisation du navigateur, gestion des proxys, empreintes numériques, résolution de CAPTCHA — tout est géré en un seul appel d'API. Que vous scrapiez une simple page statique ou un site fortement protégé et rendu par JavaScript, le même endpoint s'en charge.

---

## Ce qu'il résout

Les sites web modernes sont difficiles à scraper. Un simple appel `curl` ou `requests` renvoie souvent une page de vérification, une réponse vide ou un HTML défectueux, car le contenu est chargé par JavaScript. Web Unlocker gère tout cela automatiquement :

- **Rendu JavaScript** — les pages sont chargées dans un vrai navigateur et entièrement exécutées avant la capture du contenu
- **Contournement des protections anti-bot** — Cloudflare, DataDome, PerimeterX et les protections similaires sont gérés automatiquement
- **Rotation intelligente des IP** — les requêtes passent par des IP résidentielles propres, avec des empreintes de navigateur réalistes
- **Résolution de CAPTCHA** — les CAPTCHA courants sont résolus sans intervention manuelle
- **Ciblage par niveau de prix** — les requêtes sont acheminées via le niveau de proxy adapté au site cible

## Ce que vous recevez

Chaque tâche réussie renvoie trois types de contenu :

| Contenu | Format | Description |
| --- | --- | --- |
| **HTML** | Chaîne HTML complète | Le DOM complet et rendu de la page |

## Comment ça fonctionne

Web Unlocker exécute un vrai navigateur Chromium dans le cloud pour chaque tâche. Lorsque vous envoyez une URL :

1. Un navigateur est lancé avec une IP résidentielle et une empreinte de navigateur réaliste
2. La page est ouverte, le JavaScript est exécuté et le contenu dynamique est chargé
3. Les vérifications anti-bot et les CAPTCHA sont gérés automatiquement
4. Le HTML rendu, une capture d'écran et une archive réseau sont capturés puis renvoyés

Vous n'avez aucune infrastructure à gérer. Pas de navigateurs à démarrer, pas de listes de proxys à maintenir et pas de logique de contournement à développer. Web Unlocker remplace en pratique toute une stack de scraping — framework d'automatisation du navigateur, fournisseur de proxys, solution anti-bot — par une seule requête HTTP.

## Comment l'utiliser

Envoyez une requête GET avec l'URL cible en paramètre de requête. La réponse est le HTML entièrement rendu.

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

Consultez le [Démarrage rapide](/fr/web-unlocker-quick-start) pour des exemples en Python et JavaScript, ou les [Cas d'usage](./web-unlocker-use-cases.md) pour des modèles d'intégration courants.
