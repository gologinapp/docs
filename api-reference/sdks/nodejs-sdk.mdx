### Installation

```bash
npm i gologin
```

Requires Node.js 20 or later. Version 3 of the SDK is ESM-only: load it with `import`, `require('gologin')` doesn't work.

### Basic usage

```javascript
import GoLogin from 'gologin';

const GL = new GoLogin({
  token: 'your-api-token',
  profile_id: 'your-profile-id',
});

const { status, wsUrl } = await GL.start();
// Connect Puppeteer or Playwright using wsUrl
// ... your automation code ...
await GL.stop();
```

### Launch with GologinApi

`GologinApi` starts a profile and connects Puppeteer for you. `launch()` returns a Puppeteer `browser`. Pass `cloud: true` to run the profile in [Gologin Cloud Browser](/api-reference/cloud-browser/what-is-gologin-cloud-browser) instead of a local Orbita browser:

```javascript
import { GologinApi } from 'gologin';

const gologin = GologinApi({ token: 'your-api-token' });

// local Orbita on this machine
const { browser } = await gologin.launch({ profileId: 'your-profile-id' });

// or Gologin Cloud Browser
// const { browser } = await gologin.launch({ cloud: true, profileId: 'your-profile-id' });

const page = await browser.newPage();
await page.goto('https://example.com');

// close the browser and stop the profile
await gologin.exit();
```

Without `profileId`, `launch()` creates a new profile first. `GologinApi` also has helpers such as `createProfileRandomFingerprint()`, `addGologinProxyToProfile()`, `addCookiesToProfile()`, and `deleteProfile()`. See the [Quickstart](/api-reference/introduction/quickstart) for a full example.

### Key parameters

| Parameter | Default | Description |
|---|---|---|
| `token` | required | Your Gologin API token |
| `profile_id` | required | Profile ID to launch |
| `executablePath` | auto | Path to Orbita browser binary |
| `uploadCookiesToServer` | `false` | Upload cookies to cloud on profile stop. Set to `true` if you need session persistence across devices. |
| `extra_params` | `[]` | Additional Chromium flags passed to the browser |

### Stopping profiles

```javascript
// Stop and sync to cloud
await GL.stop();

// Stop without syncing profile data to cloud
await GL.stopLocal({ posting: false });
```

Close the browser in your automation tool first, for example with `browser.close()`. `stop()` takes no options and always uploads the profile to Gologin. `stopLocal({ posting: false })` finishes the session without uploading profile data. Use it on servers where you don't want cloud sync. Cookies are still uploaded if you set `uploadCookiesToServer: true`.

### Managing Orbita browser versions

When a profile starts, the SDK checks which Orbita version the profile's user agent needs. If that version isn't in `~/.gologin/browser` yet, the SDK downloads it, otherwise it reuses the installed copy. To run a specific build, pass `executablePath`. The `autoUpdateBrowser` (default `false`) and `checkBrowserUpdate` options are still accepted, but in the current SDK (3.0.7) they don't change this behavior.

To download Orbita in advance, call `checkAndDownloadBrowserByOpts()` on a `GoLogin` instance. It is a method, not a separate export:

```javascript
import { GoLogin } from 'gologin';

const GL = new GoLogin({ token: 'your-api-token' });

// Pre-download the latest Orbita version
await GL.checkAndDownloadBrowserByOpts({ lastActualCount: 1 });

// Pre-download specific versions
await GL.checkAndDownloadBrowserByOpts({ majorVersions: [142, 143] });
```

Without options, it downloads the 5 latest versions. Use it before launching profiles in parallel to avoid multiple simultaneous downloads.

### Running 100+ profiles in parallel

When running many profiles concurrently on a server:

```javascript
// Use a queue to limit concurrent launches
const CONCURRENCY = 10;
const queue = [...profileIds];
const active = new Set();

async function launchProfile(profileId) {
  const gl = new GoLogin({ token, profile_id: profileId });
  try {
    const { wsUrl } = await gl.start();
    // ... your automation ...
  } finally {
    await gl.stop();
  }
}

async function processQueue() {
  while (queue.length > 0) {
    while (active.size >= CONCURRENCY) {
      await new Promise(r => setTimeout(r, 1000));
    }
    const id = queue.shift();
    active.add(id);
    launchProfile(id).finally(() => active.delete(id));
  }
}
```

**Important for servers:**
- Limit concurrent profile launches (10-20 recommended to start)
- Pre-download Orbita versions before launching
- On Linux: install Xvfb and set `DISPLAY=:99`
- Increase file descriptor limits: `ulimit -n 65536`
- Monitor RAM: each profile uses ~300-500 MB

### Debugging

Set the environment variable for verbose logging:

```bash
DEBUG=gologin node your-script.js
```
