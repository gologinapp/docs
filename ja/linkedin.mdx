title: "LinkedIn"

Gologin で LinkedIn アカウントを管理するための実践ガイドです。リード獲得、アウトリーチ、チームでのアクセス共有についても説明します。

LinkedIn は、Gologin のエコシステムの中でも特にセキュリティが厳しいプラットフォームの一つです。ほとんどの SNS よりも積極的に、ログインパターン、IP の一貫性、デバイスの指紋を監視しています。不審なシグナルが見つかったアカウントはすぐに制限され、警告なしに制限されることもあります。

## クイックチェックリスト

始める前に確認してください。

- 1 アカウント = 1 ブラウザープロファイル
- 1 プロファイル = 1 つの固定住宅用プロキシーまたはモバイルプロキシー
- 一度使用したプロファイルのプロキシーは絶対に変更しない
- プロファイルの OS を、お使いのデバイスの OS に合わせる
- 同じプロファイルを 2 台のデバイスで同時に開かない

## ステップ 1. 適切なプロキシーを選ぶ

LinkedIn は IP の変更に非常に敏感です。固定住宅用プロキシーまたは固定モバイルプロキシーを使用し、セッションをまたいで同じ専用 IP を維持してください。

<Warning>
  大切な LinkedIn アカウントには、ローテーションプロキシー、データセンタープロキシー、Gologin の内蔵プロキシーを使用しないでください。セッション間で IP が変わると、すぐにセキュリティ審査が行われ、多くの場合セッションがログアウトされます。
</Warning>

あなたとチームメンバーが同じ都市にいる場合は、同じ国・都市のプロキシーの所在地を使用できます。チームが分散している場合は、メンバーが実際にいる場所ではなく、LinkedIn アカウントの地域に合ったプロキシーをそれぞれが使用してください。

LinkedIn におすすめのプロキシーの種類:

- 固定住宅用(長期的なアカウント管理に最適)
- モバイル(新規アカウントの作成とウォームアップに適しています)
- ISP プロキシー(安定しており、信頼度も十分)

具体的なサービスについては、[おすすめのプロキシープロバイダー](https://gologin.com/best-proxy-server-services/)をご覧ください。

## ステップ 2. Gologin プロファイルを設定する

LinkedIn アカウントごとに新しいプロファイルを作成します。

推奨設定:

- **OS**: お使いのデバイスに合わせます(Windows をお使いなら Windows、Mac をお使いなら Mac)
- **プロキシー**: 最初のログインの前に、固定プロキシーを割り当てます
- **指紋**: デフォルトのままにしてください。特別な理由がない限り、WebGL、Canvas、AudioContext はカスタマイズしないでください

プロファイルで LinkedIn に一度ログインしたら、**プロキシーや指紋の設定を変更しないでください。** LinkedIn はデバイス情報をサーバー側に保存しています。指紋が変わると、まったく新しいデバイスがアカウントにアクセスしようとしているように見えます。

## ステップ 3. 新しいアカウントをウォームアップする

新しい LinkedIn アカウントがすぐにつながりリクエストやメッセージを送信すると、短期間で制限されてしまいます。LinkedIn は、新しいアカウントが実際のユーザーのように、閲覧や閲読をしながら徐々に存在感を築いていくことを想定しています。

ウォームアップのスケジュール:

| 期間 | 行うこと |
| :-- | :-- |
| 0 日目 | プロフィールを完成させる:写真、ヘッドライン、自己紹介、職歴 |
| 1〜7 日目 | フィードを閲覧し、他のユーザーのプロフィールを見て、いくつかの企業をフォローする |
| 8〜14 日目 | 投稿に「いいね」やコメントをする。まだアウトリーチは行わない |
| 3 週目 | 「知り合い」に 5〜10 件のつながりリクエストを送る |
| 4 週目以降 | 段階的にアウトリーチを開始する。上限は少しずつ引き上げる |

安全なアクティビティの目安

| **アクション** | **推奨レベル** |
| :-- | :-- |
| いいね / 高評価 | 1 日 10〜20 回 |
| コメント | 1 日 2〜3 回 |
| 投稿 / 回答 | たまに |
| コミュニティへの参加 | 段階的に |

これらは控えめな目安です。LinkedIn の実際の制限は、アカウントの経過期間、アクティビティの履歴、サブスクリプションの種類によって異なります。

## ステップ 4. よくあるBANを避ける

LinkedIn の制限がすぐにかかる行動:

- アカウントがすでにアクティブな状態で、新しい IP からログインする(固定プロキシーを使用してください)
- 同じプロファイルを 2 台のデバイスで同時に開く
- 短時間に多数の相手へ同一のメッセージを送る
- 同じ日に、同じプロファイル設定パターンで複数のアカウントを作成する
- 一貫したセッションを維持しない自動化ツールを使う(下記の自動化セクションをご覧ください)

徐々に制限がかかる行動:

- 承認率が低いまま、つながりリクエストを大量に送る
- エンゲージメントなしで多数のプロフィールを閲覧する
- 複数のアカウントで同じコンテンツを投稿する
- 数週間アクティビティがなかったあとに、突然大量のアウトリーチを行う

## ステップ 5. チームとアクセスを共有する

チームメンバーが Gologin で LinkedIn アカウントにアクセスできるようにするには:

1. **プロファイル共有**を使って、プロファイルをメンバーと共有します(メンバーには無料の Gologin アカウントが必要です)
2. プロファイルを開いて作業するだけでよい場合は、**実行可能**ロールを割り当てます
3. 設定の変更も必要な場合は、**編集可能**を割り当てます

<Warning>
  LinkedIn のプロファイルで同時に作業するのは 1 人だけにしてください。LinkedIn は異なる場所からの同時セッションを検出し、両方のセッションをログアウトするか、セキュリティチェックを行います。
</Warning>

詳しい手順は、[プロファイルの共有](https://gologin.com/docs/general/team-collaboration/sharing-profiles)をご覧ください。

## 自動化ツール

Gologin は、一般的な LinkedIn 自動化ツールと互換性があります。重要な条件は、自動化が通常の Chrome ウィンドウの別個のブラウザー拡張機能としてではなく、Gologin プロファイルの内部で実行されることです。

互換性のある方法:

- 自動化ツールを、Gologin プロファイル内にインストールした Chrome 拡張機能として実行する
- Gologin の API でプロファイルを起動し、実行中のブラウザーセッションに自動化を接続する

互換性のない方法:

- Gologin を使いながら、通常の Chrome ウィンドウで自動化を実行する(セッションが別々になり、競合する可能性があります)
- Gologin の外で独自のブラウザーを開く自動化ツールを使う

自動化は、常に LinkedIn の 1 日あたりの制限を守って行ってください。ウォームアップなしの大量の自動化は、アカウント制限への最短ルートです。

## 他の アンチディテクトブラウザーからプロファイルを移行する

Dolphin Anty、Multilogin、またはその他のアンチディテクトブラウザーから移行する場合、ブラウザープロファイルのデータ(クッキー、セッション、ローカルストレージ)をエクスポートして Gologin にインポートできます。

手順:

1. 現在お使いのアンチディテクトブラウザーからクッキーをエクスポートします(ほとんどのブラウザーが JSON 形式のエクスポートに対応しています)
2. Gologin で対象のプロファイルを開き、**クッキー**に移動します
3. クッキーファイルをインポートします

これにより LinkedIn のセッションが維持されるため、再ログインは不要です。指紋は異なります(Gologin が独自に生成します)が、プロキシーの IP が同じであれば、通常、LinkedIn は同じデバイスのセッションとして受け入れます。

## LinkedIn がセッションをログアウトする理由

LinkedIn のセッションがログアウトされる原因は、ほぼ次のいずれかです。

- プロキシーの IP が変わった: わずかな IP の変化でもセキュリティ審査の対象になります
- プロファイルを別の OS で開いた: 指紋に一貫性がなくなります
- プロファイルを 2 台のデバイスで同時に開いた: 同時セッションが検出されます
- 長期間の非アクティブの後に、突然アクティビティがあった: アカウント乗っ取りのように見えます
- 自動化が検出された: 人間にはない速度で、不自然な操作パターンが見られます

頻繁にログアウトされる場合は、まずプロキシーを確認してください。固定かローテーションかの違いが、最も多い原因です。
