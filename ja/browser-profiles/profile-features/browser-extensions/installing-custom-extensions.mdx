---
title: "カスタム拡張機能のインストール"
---

**カスタム拡張機能**を使うと、非公開のツール、改変したツール、ローカルで開発したツールを Gologin のプロファイル内で利用できます。公開されている拡張機能とは異なり、カスタム拡張機能は拡張機能ファイルを使って手動でインストールします。

## 拡張機能の互換性を確認する

**Gologin は .crx や .zip のアーカイブに対応していません。** ただし、これらのファイルを Gologin が対応している**展開済みフォルダ**に変換できます。

**.zip** アーカイブをお持ちの場合は、そのまま展開してください。展開してできたフォルダをカスタム拡張機能として追加できます。

**.crx** ファイルをお持ちの場合:

1. extension.crx のファイル名を extension.zip に変更します
2. 7-zip アプリ、またはお使いの OS 標準の展開機能で展開します

<Warning>
  展開したフォルダに **manifest.json** とその他の拡張機能のファイル(js、html、アイコンなど)が含まれていることを確認してください。 \
  拡張機能を追加できない場合は、manifext.json を確認してください
</Warning>

## 展開済みの拡張機能をインストールする

Gologin は**展開済みフォルダ**の形式の拡張機能に対応しています。このような拡張機能をインストールするには、次の手順に従ってください。

1. 拡張機能をインストールしたい**プロファイルの 3 つのドットをクリック**し、**設定**をクリックします
2. **拡張機能**タブを開き、**拡張機能を追加**をクリックします
3. **カスタム拡張機能をアップロード**ボタンをクリックします
4. 拡張機能が入っているフォルダを開き、**フォルダーを選択**をクリックします
5. **保存**をクリックして変更を適用します
