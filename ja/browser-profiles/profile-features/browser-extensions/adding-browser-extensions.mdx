---
title: "プロフィールにブラウザ拡張機能を追加する"
---

Gologin では、公開されている拡張機能を2通りの方法で追加できます。

## 拡張機能タブから追加する

Chrome Web Store を開かなくても、**プロフィールの設定から直接**ブラウザプロフィールに拡張機能を追加できます。

1. 「すべてのプロフィール」ページで、拡張機能をインストールしたいプロフィールの**3つのドットをクリック**し、**設定**をクリックします
2. **拡張機能**タブを開きます
3. **拡張機能を追加**をクリックします
4. 検索バーで目的の拡張機能を検索し、**インストール**をクリックします
5. 変更を反映するには、必ず**保存**をクリックしてください

<Frame>
  ![Add Extensions Via Settings](/images/add_extensions_via_settings.gif)
</Frame>

拡張機能を削除するには、同じメニューで**削除する**をクリックします。

<Tip>
  目的の拡張機能が一覧に見つからない場合は、一度 Chrome Web Store からインストールしてください。インストールした拡張機能は、24時間以内に一覧に表示されます。
</Tip>

### すべての新規プロフィールに拡張機能を追加する

すべてのプロフィールで特定の拡張機能が必要な場合は、拡張機能の横にある**フラグアイコン**をクリックすると、その拡張機能がすべての新規プロフィールに追加されます。

<Frame>
  ![Add Extensions To Every New Profile](/images/add_extensions_to_every_new_profile.png)
</Frame>

<Note>
  この設定を行っても、すでに作成済みのプロフィールには拡張機能は追加されません。変更後に作成したプロフィールにのみ追加されます。
</Note>

## Chrome Web Store からインストールする

プロフィール設定の拡張機能タブに目的の拡張機能が見つからない場合は、ブラウザプロフィール内で **Chrome Web Store** を利用できます。手順は次のとおりです。

1. 新しい拡張機能が必要な**ブラウザプロフィールを起動**します
2. ブラウザの**右上の3つのドット**をクリックし、\> **拡張機能** \> **Chrome ウェブストアにアクセス**の順にクリックします
3. 必要な拡張機能を探します
4. **Chrome に追加**をクリックし、インストールが完了するまで待ちます
