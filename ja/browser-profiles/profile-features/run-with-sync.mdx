---
title: "同期して実行"
---

「同期して実行」は、複数のブラウザプロフィールを同時に起動し、あなたの操作をすべてのプロフィールにリアルタイムで反映する機能です。メインウィンドウで行った操作(クリック、入力、URLへの移動など)が、他のすべてのプロフィールでも同時に自動で実行されます。

アカウントの繰り返し作業に便利です。たとえば、アカウントのウォームアップ、多数のプロフィールでの同じ操作、同一内容のフォーム入力などに利用できます。ウィンドウを切り替えて同じ手順を繰り返す代わりに、一度操作するだけで済みます。

<Warning>
  ウェブサイトは、複数のアカウントで同時に行われる同一の動作を検知します。「同期して実行」は、同一の操作を行っても問題のない作業(ウォームアップ、初期設定、URLへの移動など)にのみ使用してください。投稿やメッセージ送信など、同一の内容だと不審に見られる操作には使用しないでください。
</Warning>

## 使い方

### ステップ 1 — プロフィールを選択する

プロフィール一覧で、一緒に起動したいプロフィールのチェックボックスにチェックを入れます。

### ステップ 2 — 「同期して実行」をクリックする

画面上部に一括操作パネルが表示されます。「同期して実行」をクリックします。

選択したすべてのプロフィールが、それぞれ別のブラウザウィンドウで開きます。

### ステップ 3 — リーダーウィンドウで操作する

選択したリストの先頭のプロフィールがリーダーになります。リーダーのウィンドウで行ったクリック、入力、ページ移動などの操作は、開いている他のすべてのプロフィールにリアルタイムで反映されます。他のプロフィールはフォロワーです。リーダーの操作を反映しますが、リーダーを操作することはできません。

## 具体的な活用例

**アカウントのウォームアップ:** 新しいアカウントを10〜20個開き、同じページをまとめて閲覧します。各プロフィールは(異なるフィンガープリント、異なるIPで)個別にブラウズするため、操作は一度行うだけで済みます。

**複数アカウントでの同一設定:** 設定ページを開く、同じオプションを切り替える、同じプロフィール情報を入力するなどの作業です。同じ初期設定で多数の新規アカウントをセットアップする場合に便利です。

**作業用URLへの移動:** 各プロフィールで個別に作業を始める前に、すべてのプロフィールで特定のページを開いておきたい場合、一度移動するだけで、すべてのプロフィールが同時にそのページに移動します。

**プロフィール間でのフィンガープリントの挙動テスト:** 複数のプロフィールでチェッカーサイト([iphey.com](http://iphey.com)、[pixelscan.net](http://pixelscan.net))を同時に開き、結果を並べて比較できます。

## 避けるべきこと

**同一コンテンツの投稿:** すべてのプロフィールで同じテキスト、画像、リンクを同時に投稿すると、プラットフォームにアカウント同士の関連をすぐに見抜かれます。「同期して実行」は、閲覧、クリック、ページ移動など、同一の動作が自然な操作にのみ使用し、コンテンツの作成には使用しないでください。

**メッセージ送信やアウトリーチ:** 異なるアカウントから同じ相手に同一のメッセージを同時に送信すると、すべてのアカウントの自動BANを最も早く招く行為の一つです。

**新規アカウントでのログイン操作:** ログイン時に、プロフィールごとに2段階認証の要求、CAPTCHA、確認手順が異なる場合があります。同期機能は入力内容を反映できますが、状態が異なる場合には対応できません。たとえば、あるプロフィールはCAPTCHAが表示されているのに、別のプロフィールはすでにログイン済み、といった状況です。ログインは、同期を有効にする前に個別に行ってください。

## プロフィールを停止する

「同期して実行」で起動したすべてのプロフィールを閉じるには、次の手順を行います。

1. チェックボックスで、実行中のプロフィールをすべて選択します
2. 一括操作パネルで **複数のプロフィールを停止する** をクリックします

<Frame>
  ![0331(1)(1)](/images/0331\(1\)\(1\).gif)
</Frame>

または、各ブラウザウィンドウを個別に閉じることもできます。Gologin は、閉じるタイミングで各プロフィールのデータを同期します。

<Warning>
  Gologin アプリを終了する前に、各プロフィールが Gologin アプリで **起動準備完了** のステータスになるまで待ってください。プロフィールの同期中に Gologin を閉じると、そのセッションのデータが失われます。
</Warning>

## 通常の実行(一括)との違い

|  | 実行(一括) | 同期して実行 |
| :-- | :-- | :-- |
| プロフィールが独立して動作する | ✅ | ❌ |
| 操作がウィンドウ間で反映される | ❌ | ✅ |
| 適した用途 | プロフィールを開いて個別に作業する | すべてのプロフィールで同じ操作を繰り返す |

多数のプロフィールを開いてから、それぞれ個別に作業したい場合は通常の **実行** を使用します。すべてのプロフィールでまったく同じ操作を一度に行いたい場合は **同期して実行** を使用します。
