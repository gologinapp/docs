---
title: "同期して実行"
---

「同期して実行」は、複数のブラウザプロフィールを同時に起動し、メインウィンドウでの操作をすべてのプロフィールにリアルタイムで反映する機能です。メインウィンドウで行ったクリック、入力、URLへの移動などの操作が、他のすべてのプロフィールでも同時に自動で実行されます。

この機能は、アカウントのウォームアップ、多数のプロフィールでの同じ操作、同一内容のフォーム入力といった繰り返し作業に便利です。ウィンドウを切り替えて同じ手順を繰り返す代わりに、一度操作するだけで済みます。

<Warning>
  ウェブサイトは、複数のアカウントで同時に行われる同一の動作を検知します。「同期して実行」は、ウォームアップ、初期設定、URLへの移動など、同一の操作でも問題のない作業にのみ使用してください。投稿やメッセージ送信など、同一の内容だと不審に見られる操作には使用しないでください。
</Warning>

## 使い方

### ステップ1 — プロフィールを選択する

プロフィール一覧で、まとめて起動したいプロフィールの横にあるチェックボックスをオンにします。

### ステップ2 — 「同期して実行」をクリックする

画面上部に一括操作パネルが表示されます。「同期して実行」をクリックします。

選択したすべてのプロフィールが、それぞれ別のブラウザウィンドウで開きます。

### ステップ3 — リーダーウィンドウで作業する

選択したリストの最初のプロフィールがリーダーになります。リーダーのウィンドウで行うクリック、入力、ページ移動などの操作は、開いている他のすべてのプロフィールにリアルタイムで複製されます。他のプロフィールはフォロワーとなり、リーダーの動作を反映しますが、リーダーを操作することはできません。

## 活用例

**アカウントのウォームアップ:** 新しいアカウントを10〜20個開き、同じページをまとめて閲覧します。各プロフィールは(異なるフィンガープリント、異なるIPで)独立して閲覧するため、操作は一度だけで済みます。

**複数アカウントでの同一設定:** 設定ページに移動し、同じオプションを切り替えたり、同じプロフィール情報を入力したりします。同じ初期設定で多数の新規アカウントをセットアップする場合に便利です。

**作業用URLへの移動:** 各プロフィールで個別に作業を始める前に、すべてのプロフィールで特定のページを開いておきたい場合、一度移動するだけで全プロフィールが同時にそのページを開きます。

**プロフィール間でのフィンガープリントの動作確認:** 複数のプロフィールで同時にチェッカーサイト([iphey.com](http://iphey.com)、[pixelscan.net](http://pixelscan.net))を開き、結果を並べて比較できます。

## 避けるべきこと

**同一内容の投稿:** すべてのプロフィールが同じテキスト、画像、リンクを同時に投稿すると、プラットフォームにアカウント同士の関連をすぐに見抜かれます。「同期して実行」は、閲覧、クリック、ページ移動など、同一の動作が自然な操作にのみ使用し、コンテンツの作成には使用しないでください。

**メッセージ送信とアウトリーチ:** 複数のアカウントから同じ相手に同一のメッセージを同時に送信すると、すべてのアカウントが自動的にBANされる最も早い原因の一つになります。

**新規アカウントでのログイン操作:** プロフィールごとに、2段階認証、CAPTCHA、確認手順などが異なる場合があります。シンクロナイザーは入力内容を複製しますが、状態の違いには対応できません。たとえば、あるプロフィールはCAPTCHAの画面で、別のプロフィールはすでにログイン済み、ということが起こり得ます。シンクロナイザーを有効にする前に、ログインは個別に済ませてください。

## プロフィールを停止する

「同期して実行」で起動したすべてのプロフィールを閉じるには:

1. チェックボックスで、実行中のすべてのプロフィールを選択します
2. 一括操作パネルで **複数のプロフィールを停止する** をクリックします

<Frame>
  ![0331(1)(1)](/images/0331\(1\)\(1\).gif)
</Frame>

または、各ブラウザウィンドウを個別に閉じることもできます。Gologin は、プロフィールが閉じられるたびにそのデータを同期します。

<Warning>
  Gologin アプリを終了する前に、すべてのプロフィールの状態が **起動準備完了** と表示されるまで待ってください。プロフィールの同期中に Gologin を閉じると、そのセッションのデータが失われます。
</Warning>

## 通常の「起動」(一括)との違い

|  | 起動(一括) | 同期して実行 |
| :-- | :-- | :-- |
| プロフィールが独立して動作する | ✅ | ❌ |
| ウィンドウ間で操作が反映される | ❌ | ✅ |
| 最適な用途 | プロフィールを開いて個別に作業する | すべてのプロフィールで同じ操作を繰り返す |

多数のプロフィールを開いてから1つずつ個別に作業したい場合は、通常の **起動** を使用してください。すべてのプロフィールでまったく同じ操作を一度に行いたい場合は、**同期して実行** を使用してください。
