このガイドでは、Web Unlocker を使って最初の URL をスクレイピングする方法を説明します。

---

## 前提条件

- Web Unlocker の API キー。[Web Unlocker のページ](https://gologin.com/web-unlocker/#web_unlocker_form)にあるフォームから取得できます。キーは1営業日以内に届き、ご自身の対象サイトで試せる無料リクエストが付いています。カードの登録は不要です。
- Python 3.x、Node.js、または任意の HTTP クライアント

---

## 認証

すべてのリクエストで、`apikey` ヘッダーに API キーを指定する必要があります。

```
apikey: YOUR_API_KEY
```

すべての API リクエストのベース URL は次のとおりです。

```
https://parsing.webunlocker.gologin.com/v1
```

---

## 最初のリクエストを送信する

対象の URL をクエリパラメータに指定して GET リクエストを送信します。レスポンスには、ページの完全にレンダリングされた HTML が返されます。

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.text)
```

### JavaScript (Node.js / Browser)

```javascript
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(html);
```

## レスポンスの内容

レスポンスボディには、ブラウザーでその URL を開いたときに表示されるものと同じ、レンダリング済みの生の HTML が返されます。JSON でラップされることはなく、パース処理も不要です。

```html
<!DOCTYPE html>
<html>
  <head><title>Example Domain</title></head>
  <body>...</body>
</html>
```

### その他の形式

`format` クエリパラメータを追加すると、ページを別の形式で取得できます。

| `format` | レスポンスボディ |
|---|---|
| `html` | ページの HTML(デフォルト) |
| `markdown` | Markdown 形式のページコンテンツ |
| `json` | URL、リクエストのメタデータ、ページの HTML を含む JSON オブジェクト |

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com&format=json" \
  -H "apikey: YOUR_API_KEY"
```

```json
{
  "success": true,
  "data": {
    "url": "https://example.com",
    "metadata": {
      "response_time_ms": 297,
      "status_code": 200
    },
    "html": "<!DOCTYPE html><html lang=\"en\">..."
  }
}
```

## エラーの処理

レスポンスを処理する前に、HTTP ステータスコードを確認してください。

| ステータス | 意味 | レスポンスボディ |
|---|---|---|
| `200` | 成功 | 指定した形式のページ |
| `400` | 不正なリクエスト(例: `url` パラメータがない) | `{"success":false,"error":"Request failed"}` |
| `401` | `apikey` ヘッダーがない | `{"message":"Missing API key in request"}` |

`429` または `5xx` のステータスが返された場合は、指数バックオフを使って再試行してください。

```python
response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

if response.status_code == 200:
    html = response.text
else:
    print(f"Error {response.status_code}: {response.text}")
```

## CLI でのクイックスタート

コードを書かなくても、Gologin の CLI ツールを使ってページをスクレイピングできます。

### Web Unlocker CLI

```bash
npm install -g gologin-webunlocker

GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker scrape https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_... gologin-webunlocker markdown https://example.com
```

### Gologin Web Access CLI(統合版)

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."
gologin-web-access read https://example.com
gologin-web-access scrape-json https://example.com
gologin-web-access batch-scrape https://example.com/page/1 https://example.com/page/2 --format text
```

詳細は [Web Unlocker SDK と CLI](/ja/scraping-api-sdk-and-cli) および [Web Access CLI](/ja/cli-tools/web-access) をご覧ください。
