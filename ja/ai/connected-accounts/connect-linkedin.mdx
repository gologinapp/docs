title: "LinkedInアカウントを接続する"
description: "パスワード、クッキー、または Gologin プロファイルでLinkedInアカウントを接続し、IPの国を選択して、同じウィンドウでLinkedInの確認を通過します。"
---

LinkedInアカウントの接続は、アカウントごとに1回だけ行います。接続後はログインしたままの状態が維持され、クラウド上で動作します。

## アカウントを接続する

1. **アカウント**を開き、**アカウントを接続**をクリックします。
2. **ネットワークを選択します。** 現在はLinkedInを利用できます。
3. **IPの取得元を選択します。**
   - **専用IP**: 利用可能な国から選択します。ブラジル、フランス、ドイツ、香港、インド、インドネシア、ルーマニア、韓国、トルコ、イギリス、アメリカ。リストは変更されることがあります。
   - **お持ちのプロキシ**: プロキシを入力し、**プロキシをチェック**をクリックしてから、**このプロキシを使用**をクリックします。
4. 次のいずれかの方法で**LinkedInにサインイン**します。
   - **認証情報**: アカウントのメールアドレスとパスワードを入力します。パスワードは暗号化して保存され、後でセッションを復元するときにのみ使用されます。
   - **クッキー**: LinkedInにサインインしているブラウザの `li_at` クッキーを使用します。パスワードは不要です。
   - **Gologin プロファイル**: すでにLinkedInにサインインしている Gologin プロファイルを使用します。新たなサインインは不要で、アカウントにはそのプロファイル自体のプロキシが使われます。
5. 既存のLinkedInの会話を取り込むには、**既存の会話をインポート**にチェックを入れます。チェックしない場合は、接続した時点以降の会話のみが保存されます。
6. **ログイン**をクリックします。Gologin が専用IPを割り当て、アカウント用のブラウザプロファイルを作成して、LinkedInにサインインします。

<Tip>
  `li_at` クッキーをコピーするには、サインイン済みのブラウザでLinkedInを開き、**F12** を押して、**Application** > **Cookies** > **https://www.linkedin.com** を開き(Firefoxの場合: **Storage** > **Cookies**)、`li_at` の値をコピーします。
</Tip>

## LinkedInの確認を通過する

LinkedInから本人確認を求められることがあります。確認は同じウィンドウで行えます。

- **メールのコード**: LinkedInがアカウントのメールアドレスに送信したコードを入力します。
- **認証アプリ**: Google Authenticatorなどのアプリに表示されるコードを入力します。
- **電話番号**: 電話番号を入力します。通常、LinkedInからその番号にコードが送信されます。
- **LinkedInアプリ**: スマートフォンのLinkedInアプリでサインインを承認します。ウィンドウは自動的に先へ進みます。

CAPTCHAは自動的に解決されます。自動では通過できない確認がLinkedInに表示された場合は、ブラウザウィンドウが開くので、ご自身で通過してください。

各確認の待機時間は最大10分です。この時間内にコードを入力しなかった場合、またはサインインを承認しなかった場合は、もう一度サインインしてください。

**LinkedIn asked for an extra check we can't complete here, sign in with cookies instead** と表示された場合は、`li_at` クッキーでアカウントを接続してください。

## アカウントのステータス

| ステータス | 意味 |
| :-- | :-- |
| **Active** | アカウントはサインイン済みで、正常に動作しています。 |
| **Needs action** | 操作が必要です。コードの入力、サインインの承認、LinkedInの確認の通過、または再サインインを行ってください。理由はステータスの下に表示されます。 |
| **Restricted** | LinkedInによってアカウントが制限されています。linkedin.comで確認してください。 |
| **休止** | アカウントの接続を解除しました。 |

ステータスの下に表示される主な理由:

| 理由 | 対処方法 |
| :-- | :-- |
| Wrong password · retry login | 正しいパスワードでもう一度サインインするか、クッキーを使用してください。 |
| Session expired · log in again | LinkedInがセッションを終了しました。パスワードまたは新しいクッキーで再度サインインしてください。 |
| LinkedIn asked for a checkpoint | linkedin.comで確認を通過してから、新しいクッキーで再度サインインしてください。 |
| Verification code expired | 10分以内にコードが入力されませんでした。もう一度サインインし、新しいコードを使用してください。 |
| Not confirmed in the LinkedIn app in time | もう一度サインインし、LinkedInアプリでサインインを承認してください。 |
| No dedicated IP available | 別の国を選択するか、お持ちのプロキシを使用してください。 |
| Already connected in this workspace | このLinkedInアカウントはすでにリストにあります。 |
| LinkedIn has restricted this account | linkedin.comでアカウントを確認してください。 |

## アカウントの接続を解除する/削除する

- **接続を解除**: このアカウントから実行中のタスクが停止します。アカウントはリストに残り、再接続するまで席を使用し続けます。
- **削除**: アカウント、そのチャットと履歴が完全に削除されます。このアカウントから実行中のタスクは停止し、使用していた席は別のアカウントで利用できるようになります。
