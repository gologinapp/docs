LinkedInアカウントの接続は、アカウントごとに1回だけ行います。接続後はログイン状態が維持され、クラウド上で動作します。

## アカウントを接続する

1. **Accounts**を開き、**Connect account**をクリックします。
2. **ネットワークを選択します。** 現在はLinkedInを利用できます。
3. **IPの取得元を選択します。**
   - **専用IP**: 利用可能な国から選択します。ブラジル、フランス、ドイツ、香港、インド、インドネシア、ルーマニア、韓国、トルコ、イギリス、アメリカが対象です。この一覧は変更される場合があります。
   - **自分のプロキシ**: プロキシを入力し、**プロキシをチェック**をクリックして、**Use this proxy**をクリックします。
4. 次の3つの方法のいずれかで**LinkedInにログインします。**
   - **Credentials** - アカウントのメールアドレスとパスワードを使います。パスワードは暗号化して保存され、後でセッションを復元するときにのみ使用されます。
   - **Cookies** - LinkedInにログインしているブラウザの`li_at`クッキーを使います。パスワードは不要です。
   - **Gologin profile** - すでにLinkedInにログインしているGologinプロファイルを使います。新たにログインする必要はなく、アカウントはそのプロファイルのプロキシを使用します。
5. 既存のLinkedInの会話を取り込むには、**Import existing conversations**にチェックを入れます。チェックを入れない場合は、接続した時点以降の会話のみが保存されます。
6. **ログイン**をクリックします。Gologinが専用IPを割り当て、アカウント用のブラウザプロファイルを作成し、LinkedInにログインします。

<Tip>
  `li_at`クッキーをコピーするには、LinkedInにログインしているブラウザでLinkedInを開き、**F12**を押して、**Application** > **クッキー** > **https://www.linkedin.com**の順に進み(Firefoxの場合は**ストレージ** > **クッキー**)、`li_at`の値をコピーします。
</Tip>

## LinkedInの確認を完了する

LinkedInから本人確認を求められる場合があります。確認は同じウィンドウで行えます。

- **メールのコード** - LinkedInがアカウントのメールアドレスに送信したコードを入力します。
- **認証アプリ** - Google Authenticatorなどのアプリに表示されるコードを入力します。
- **電話番号** - 電話番号を入力します。通常、LinkedInがその番号にコードを送信します。
- **LinkedInアプリ** - スマートフォンのLinkedInアプリでログインを承認します。ウィンドウでは自動的に処理が続行されます。

LinkedInが人による操作を必要とする確認を表示した場合は、ブラウザウィンドウが開くので、ご自身で確認を完了してください。

各確認の待機時間は最大10分です。この時間内にコードを入力しなかった場合、またはログインを承認しなかった場合は、もう一度ログインしてください。

**LinkedIn asked for an extra check we can't complete here, sign in with cookies instead**と表示された場合は、`li_at`クッキーを使ってアカウントを接続してください。

## アカウントのステータス

| ステータス | 意味 |
| :-- | :-- |
| **Active** | アカウントにログインしており、正常に動作しています。 |
| **Needs action** | 操作が必要です。コードの入力、ログインの承認、LinkedInの確認の完了、または再ログインを行ってください。理由はステータスの下に表示されます。 |
| **Restricted** | LinkedInによってアカウントが制限されています。linkedin.comで確認してください。 |
| **休止** | アカウントの接続を解除した状態です。 |

ステータスの下に表示される主な理由:

| 理由 | 対処方法 |
| :-- | :-- |
| Wrong password · retry login | 正しいパスワードでもう一度ログインするか、クッキーを使用してください。 |
| Session expired · log in again | LinkedInがセッションを終了しました。パスワードまたは新しいクッキーでもう一度ログインしてください。 |
| LinkedIn asked for a checkpoint | linkedin.comで確認を完了し、新しいクッキーでもう一度ログインしてください。 |
| Verification code expired | 10分以内にコードが入力されませんでした。もう一度ログインし、新しいコードを使用してください。 |
| Not confirmed in the LinkedIn app in time | もう一度ログインし、LinkedInアプリでログインを承認してください。 |
| No dedicated IP available | 別の国を選択するか、自分のプロキシを使用してください。 |
| Already connected in this workspace | このLinkedInアカウントはすでに一覧に追加されています。 |
| LinkedIn has restricted this account | linkedin.comでアカウントを確認してください。 |

## アカウントの接続解除と削除

- **接続解除**: このアカウントから実行中のタスクは停止します。アカウントは一覧に残り、再接続するまでシートを占有したままになります。
- **削除**: アカウント、チャット、履歴が完全に削除されます。このアカウントから実行中のタスクは停止し、シートは別のアカウントで使用できるようになります。
