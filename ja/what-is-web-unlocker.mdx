---
title: "Web Unlockerとは?"
---

Web Unlockerは、あらゆるURLに対応するユニバーサルなスクレイピングAPIです。URLを送信するだけで、完全にレンダリングされたHTML、スクリーンショット、ネットワークアーカイブが返されます。インフラの管理は不要で、ブロックやリクエストの失敗もありません。

ブラウザ自動化、プロキシ管理、フィンガープリント、CAPTCHAの解決まで、スクレイピングに必要なものをすべて1回のAPI呼び出しで処理できるため、既存のスクレイピング環境をそのまま置き換えられます。シンプルな静的ページでも、強力な保護がかかったJavaScriptレンダリングのサイトでも、同じエンドポイントで対応できます。

---

## 解決できる課題

最近のウェブサイトはスクレイピングが困難です。通常の `curl` や `requests` では、チャレンジページや空のレスポンスが返ってきたり、コンテンツがJavaScriptで読み込まれるためにHTMLが不完全になったりすることがよくあります。Web Unlockerは、これらをすべて自動で処理します。

- **JavaScriptレンダリング** — 実際のブラウザでページを読み込み、JavaScriptを完全に実行してからコンテンツを取得します
- **アンチボット回避** — Cloudflare、DataDome、PerimeterXなどの保護機能を自動で処理します
- **スマートなIPローテーション** — リアルなブラウザフィンガープリントを持つクリーンなレジデンシャルIP経由でリクエストを送信します
- **CAPTCHAの解決** — 一般的なCAPTCHAを手動操作なしで解決します
- **価格帯に応じたルーティング** — 対象サイトに適したプロキシの価格帯を経由してリクエストを送信します

---

## 返されるデータ

成功したタスクでは、次の3種類のコンテンツが返されます。

| コンテンツ | 形式 | 説明 |
| --- | --- | --- |
| **HTML** | HTML文字列 | レンダリング済みのページ全体のDOM |
| **スクリーンショット** | PNG画像 | ブラウザに表示されたとおりのページのスクリーンショット |
| **アーカイブ** | ZIP(HAR) | すべてのリクエスト、ヘッダー、リソースを含むネットワークログ |

## Web Unlockerと自前で運用するプロキシの比較

プロキシ環境を自前で運用するには多額のコストがかかり、安定性にも課題があります。Web Unlockerなら、すべてをマネージドサービスとして任せられます。

|  | Web Unlocker | 自前で運用するプロキシ |
| --- | --- | --- |
| セットアップ | API呼び出し1回 | インフラ構築に数週間 |
| CAPTCHAの解決 | 標準搭載 | 別途構築または購入が必要 |
| ブラウザフィンガープリント | 標準搭載 | 別途構築または購入が必要 |
| IPローテーション | 自動 | プールを手動で管理 |
| メンテナンス | 不要 | 継続的に必要 |
| 課金 | 成功したリクエストごと | 成否にかかわらず固定費 |

## 主なユースケース

- **価格モニタリング** — 自動リクエストをブロックするECサイトをスクレイピングできます
- **リード獲得** — ディレクトリやビジネスリストから連絡先データを抽出できます
- **市場調査** — 商品データ、レビュー、求人情報を大規模に収集できます
- **コンテンツの集約** — APIのないサイトからニュースやデータのフィードを作成できます
- **AIパイプライン** — レンダリング済みのHTMLをLLMに渡して、抽出や要約を行えます

## 仕組み

Web Unlockerは、タスクごとにクラウド上で実際のChromiumブラウザを実行します。URLを送信すると、次の流れで処理されます。

1. レジデンシャルIPとリアルなブラウザフィンガープリントを設定したブラウザを起動します
2. ページに移動し、JavaScriptを実行して、動的なコンテンツを読み込みます
3. アンチボットのチャレンジやCAPTCHAを自動で処理します
4. レンダリング済みのHTML、スクリーンショット、ネットワークアーカイブを取得して返します

インフラを管理する必要はありません。ブラウザを起動する必要も、プロキシリストを維持する必要も、回避ロジックを構築する必要もありません。Web Unlockerは、ブラウザ自動化フレームワーク、プロキシプロバイダー、アンチボット対策といったスクレイピング環境一式を、1回のHTTPリクエストで置き換えます。

## 使い方

対象のURLをクエリパラメータに指定してGETリクエストを送信します。レスポンスとして、完全にレンダリングされたHTMLが返されます。

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

PythonとJavaScriptのサンプルは[クイックスタート](/ja/web-unlocker-quick-start)を、一般的な連携パターンは[ユースケース](./web-unlocker-use-cases.md)をご覧ください。
