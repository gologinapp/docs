---
title: "Web Unlockerとは?"
---

Web Unlockerは、あらゆるURLに対応するユニバーサルなスクレイピングAPIです。URLを送信するだけで、完全にレンダリングされたHTML、またはMarkdownやJSON形式のページを取得できます。インフラ管理は不要で、ブロックされることも、リクエストが失敗することもありません。

ブラウザ自動化、プロキシ管理、フィンガープリント対策、CAPTCHAの解決まで、スクレイピングに必要な処理をすべて1回のAPI呼び出しで行えるため、既存のスクレイピング環境をそのまま置き換えられます。単純な静的ページでも、強力な保護がかかったJavaScript描画のサイトでも、同じエンドポイントで処理できます。

---

## 解決できる課題

最近のウェブサイトはスクレイピングが困難です。単純な `curl` や `requests` の呼び出しでは、チャレンジページや空のレスポンス、あるいはJavaScriptでコンテンツが読み込まれるために壊れたHTMLが返されることがよくあります。Web Unlockerは、こうした問題をすべて自動で処理します。

- **JavaScriptのレンダリング** — 実際のブラウザでページを読み込み、JavaScriptを完全に実行してからコンテンツを取得します
- **アンチボットの回避** — Cloudflare、DataDome、PerimeterXなどの保護機能を自動で回避します
- **スマートなIPローテーション** — 本物らしいブラウザフィンガープリントを持つクリーンなレジデンシャルIP経由でリクエストを送信します
- **CAPTCHAの解決** — 一般的なCAPTCHAを手動操作なしで解決します
- **価格帯に応じたターゲティング** — 対象サイトに適したプロキシ階層経由でリクエストを送信します

---

## 取得できるデータ

リクエストが成功すると、ページが1つの形式で返されます。形式は `format` クエリパラメータで指定します。

| `format` | 取得できる内容 |
| --- | --- |
| `html`(デフォルト) | レンダリング済みのページ全体のDOM |
| `markdown` | Markdown形式のページコンテンツ |
| `json` | ページのURL、リクエストのメタデータ、HTMLを含むJSONオブジェクト |

## Web Unlockerと自前のプロキシ運用の比較

自前でプロキシ環境を運用するには、多額のコストがかかるうえ、安定して動かし続けるのも容易ではありません。Web Unlockerなら、すべてをマネージドサービスとして任せられます。

|  | Web Unlocker | 自前のプロキシ運用 |
| --- | --- | --- |
| セットアップ | API呼び出し1回 | インフラ構築に数週間 |
| CAPTCHAの解決 | 標準搭載 | 別途開発または購入が必要 |
| ブラウザフィンガープリント | 標準搭載 | 別途開発または購入が必要 |
| IPローテーション | 自動 | プールを手動で管理 |
| メンテナンス | 不要 | 継続的に必要 |
| 課金 | 成功したリクエストごと | 成否にかかわらず固定費 |

## 仕組み

Web Unlockerは、タスクごとにクラウド上で実際のChromiumブラウザを実行します。URLを送信すると、次の流れで処理されます。

1. レジデンシャルIPと本物らしいブラウザフィンガープリントを持つブラウザが起動します
2. ページに移動し、JavaScriptが実行されて、動的コンテンツが読み込まれます
3. アンチボットのチャレンジやCAPTCHAが自動で処理されます
4. レンダリング済みのHTMLが返されます。`format` で指定した場合は、MarkdownまたはJSONが返されます

インフラを管理する必要は一切ありません。ブラウザを立ち上げたり、プロキシリストを保守したり、回避ロジックを開発したりする必要はありません。Web Unlockerは、ブラウザ自動化フレームワーク、プロキシプロバイダー、アンチボット対策といったスクレイピング環境一式を、1回のHTTPリクエストで置き換えます。

## 使い方

対象のURLをクエリパラメータに指定して、GETリクエストを送信します。レスポンスとして、完全にレンダリングされたHTMLが返されます。

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

MarkdownまたはJSONで取得するには、クエリに `format=markdown` または `format=json` を追加します。

PythonとJavaScriptのコード例や[エラーコード](/ja/web-unlocker-quick-start#%E3%82%A8%E3%83%A9%E3%83%BC%E3%81%AE%E5%87%A6%E7%90%86)については[クイックスタート](/ja/web-unlocker-quick-start)を、一般的な連携パターンについては[ユースケース](/ja/web-unlocker-use-cases)をご覧ください。
