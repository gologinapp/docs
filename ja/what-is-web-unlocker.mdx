---
title: "Web Unlockerとは？"
---

Web Unlockerは、汎用のスクレイピングAPIです。URLを送信するだけで、完全にレンダリングされたHTML、またはMarkdownやJSON形式のページを取得できます。ブラウザやプロキシを自分で管理する必要はありません。

スクレイピング環境のうち、ブラウザとプロキシに関わる部分を置き換えます。レンダリング、プロキシ管理、ブラウザフィンガープリントの処理は、1回のAPI呼び出しで完結します。静的なページも、JavaScriptを多用するサイトも、同じエンドポイントで処理できます。

---

## 解決できる課題

現代のウェブサイトはスクレイピングが困難です。コンテンツがJavaScriptで読み込まれるため、単純な `curl` や `requests` の呼び出しでは、空のレスポンスや壊れたHTMLが返されることがよくあります。Web Unlockerは次の点に対応します。

- **JavaScriptレンダリング** — ページを実際のブラウザで読み込み、JavaScriptを完全に実行してからコンテンツを取得します
- **スマートなIPローテーション** — リアルなブラウザフィンガープリントを持つレジデンシャルIP経由でリクエストを送信します
- **価格ティアの指定** — 対象サイトに適したプロキシティア経由でリクエストを送信します

---

## 取得できるデータ

リクエストが成功すると、ページが1つの形式で返されます。形式は `format` クエリパラメータで指定します。

| `format` | 取得できる内容 |
| --- | --- |
| `html`（デフォルト） | レンダリング済みのページ全体のDOM |
| `markdown` | Markdown形式のページコンテンツ |
| `json` | ページURL、リクエストのメタデータ、HTMLを含むJSONオブジェクト |

## Web Unlockerと自前のプロキシ運用の比較

自前でプロキシ基盤を運用するにはコストがかかり、安定した運用も困難です。Web Unlockerは、これらすべてをマネージドサービスとして提供します。

|  | Web Unlocker | 自前のプロキシ運用 |
| --- | --- | --- |
| セットアップ | API呼び出し1回 | 数週間のインフラ構築作業 |
| ブラウザフィンガープリント | 組み込み済み | 別途構築または購入が必要 |
| IPローテーション | 自動 | プールを手動で管理 |
| メンテナンス | 不要 | 継続的に必要 |
| 課金 | 成功したリクエストごと | 成否にかかわらず固定費 |

## 仕組み

Web Unlockerは、タスクごとにクラウド上で実際のChromiumブラウザを実行します。URLを送信すると、次の処理が行われます。

1. レジデンシャルIPとリアルなブラウザフィンガープリントを設定したブラウザが起動します
2. ページに移動し、JavaScriptを実行して、動的コンテンツを読み込みます
3. レンダリング済みのHTMLが返されます。`format` で指定した場合は、MarkdownまたはJSONが返されます

インフラを管理する必要はありません。ブラウザを起動する必要も、プロキシリストを維持する必要も、レンダリング処理を自作する必要もありません。Web Unlockerは、ブラウザ自動化フレームワークとプロキシプロバイダを、1回のHTTPリクエストに置き換えます。

## 使い方

対象のURLをクエリパラメータに指定して、GETリクエストを送信します。レスポンスは、完全にレンダリングされたHTMLです。

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

MarkdownまたはJSONで取得するには、クエリに `format=markdown` または `format=json` を追加します。

PythonとJavaScriptのサンプルや[エラーコード](/ja/web-unlocker-quick-start#%E3%82%A8%E3%83%A9%E3%83%BC%E3%81%AE%E5%87%A6%E7%90%86)については[クイックスタート](/ja/web-unlocker-quick-start)を、一般的な連携パターンについては[ユースケース](/ja/web-unlocker-use-cases)をご覧ください。
