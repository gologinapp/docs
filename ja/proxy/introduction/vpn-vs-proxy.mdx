---
title: "プロファイルにVPNを使わない理由"
---

VPNとプロキシはどちらも表示上のIPアドレスを変更するため、混同されることがよくあります。しかし、両者の仕組みは異なり、複数アカウントを運用する場合にはその違いが非常に重要になります。

|  | VPN | プロキシ |
| :-- | :-- | :-- |
| IPを変更する | ✅ | ✅ |
| ブラウザフィンガープリントを変更する | ❌ | ❌ |
| デバイス全体で1つのIP | ✅ | ❌ |
| ブラウザプロファイルごとに1つのIP | ❌ | ✅ |
| Gologinで使用できる | ❌ | ✅ |
| Facebook / LinkedInに検出される | 多い | 少ない（レジデンシャル） |

## VPNの仕組み

VPNは、お使いのデバイスのすべての通信を暗号化し、1台のサーバー経由で送信します。ブラウザ、Slack、Spotifyなど、コンピューター上のすべてのアプリが同じIPアドレスを共有します。

これはプライバシーの保護や地域制限の回避には便利です。しかし、複数アカウントを運用する場合には次の2つの問題があります。

**問題1 — すべてが1つのIPになる。** 10個のブラウザプロファイルがある場合、そのすべてが同じIPアドレスからアクセスしているように見えます。FacebookやLinkedInなどのプラットフォームは、1か所から複数のアカウントがアクセスしていることを検知し、それらを関連付けてしまいます。

**問題2 — VPNはブラウザフィンガープリントを変更しない。** プラットフォームはIP以外にも多くの情報を追跡しています。画面解像度、フォント、グラフィックカード、タイムゾーンなど、数十種類のシグナルを読み取ります。VPNはこれらを一切変更しません。Gologinのプロファイルは、これらすべてを変更します。

## プロキシの仕組み

プロキシは、特定の1つのブラウザプロファイルに割り当てます。そのプロファイルの通信だけがプロキシ経由になり、コンピューター上のほかのものには影響しません。

つまり、次のようになります。

- プロファイルA → ニューヨークのプロキシ → ニューヨークにある実在のデバイスのように見える
- プロファイルB → ロンドンのプロキシ → ロンドンにある完全に別のデバイスのように見える
- お使いの実際のコンピューター → プロキシなし → 通常のIP

各プロファイルがそれぞれ独自のネットワークIDを持ちます。プロファイルごとに固有のGologinのフィンガープリントと組み合わせることで、プラットフォームからは本当に別々のデバイスとして認識されます。

## VPNが複数アカウント管理に向かない理由

VPNは、レジデンシャルプロキシよりもプラットフォームに検出されやすいという点もあります。VPNサーバーのIPはよく知られており、ブロックリストに登録されています。多くのプラットフォーム（Facebook、LinkedIn、PayPal、ほとんどのベッティングサイトなど）は、VPNのIPを明示的にブロックまたはフラグ付けしています。

## VPNが役立つ場面

次のような場合は、VPNを使っても問題ありません。

- お住まいの国で地域制限されているウェブサイトにアクセスしたい
- 公衆Wi-Fiで実際のIPを保護したい
- 別の国から1つのアカウントを使用したい
- お使いのネットワークからGologinのサービスやプロキシへの接続に問題がある

ただし、VPNはGologinにおけるプロキシの代わりにはなりません。

## Gologinでプロキシを設定する

手順については、[プロファイルにプロキシを追加する](https://gologin.com/docs/proxy/proxy-management/adding-proxies)をご覧ください。

どの種類のプロキシを選べばよいかわからない場合は、[用途別のおすすめプロキシ](https://gologin.com/best-proxy-server-services/)をご覧ください。
