<Tip>
  TL;DR - SNS やEコマースには、住宅用プロキシとモバイルプロキシがおすすめです。
</Tip>

適切なプロキシの種類を選ぶことは、オンラインでの作業の効率、安全性、成果を左右する重要なポイントです。SNSアカウントの管理、データのスクレイピング、地域制限のあるコンテンツへのアクセスなど、どのような目的でも、使用するプロキシの種類によって結果が大きく変わります。ここでは、用途別に代表的なプロキシの種類を紹介します。

## 判断表

| **プラットフォーム / 作業** | **プロキシの種類** | **固定かローテーションか** | **ノート** |
| :-- | :-- | :-- | :-- |
| LinkedIn | 住宅用またはモバイル | **固定またはスティッキーローテーション** | IPが変わると、すぐにセッションがログアウトされます |
| Facebook / Meta Ads | 住宅用またはモバイル | **固定またはスティッキーローテーション** | 広告アカウントでは地域の一貫性が必要です |
| Instagram | モバイル | **ローテーション** | モバイルIPは最も信頼度が高いです |
| TikTok(新規アカウント) | モバイル | **ローテーション** | モバイル中心のプラットフォームのため、モバイルIPのほうが成果につながりやすいです |
| Amazon | 住宅用またはISP | **固定** | ローテーションIPはアカウントの関連付けにつながり、即BANのリスクがあります |
| eBay | 住宅用またはISP | **固定** | Amazonと同様です |
| Etsy | 住宅用 | **固定** |  |
| PayPal / 金融サービス | 住宅用 | **固定** | IPが変わると、アカウントの乗っ取りが疑われます |
| ベッティングプラットフォーム | モバイル | **固定** | 速度が重要で、モバイルIPは信頼されます |
| 暗号資産 / KYC プラットフォーム | 住宅用 | **固定** | KYC システムはIPの一貫性を確認します |
| Reddit | 住宅用 | **固定またはスティッキーローテーション** | LinkedIn や Facebook ほど厳しくありません |
| Google Ads | 住宅用 | **固定** |  |
| Webスクレイピング(軽量) | 住宅用ローテーション | **ローテーション** | リクエストごとに異なるIPを使うと、ブロックを避けやすくなります |
| Webスクレイピング(大規模) | データセンターのローテーション | **ローテーション** | 大規模な処理では、より高速で低コストです |
| 地域テスト / QA | Gologin 内蔵 | **ローテーション** | 単発の確認には十分です |

## プロキシの種類をわかりやすく解説

**住宅用プロキシ**は、実際の家庭やISPに登録されたIPアドレスを使用します。一般ユーザーの接続に見えるため、ウェブサイトからの信頼度が最も高くなります。データセンタープロキシより低速で高価ですが、センシティブなプラットフォームでは欠かせません。

**モバイルプロキシ**は、携帯電話会社のネットワーク(4G/5G)を経由して通信します。モバイルIPは何千人もの実際のユーザーに共有されているため、プラットフォーム側が無関係なユーザーまで巻き込まずにブロックすることは非常に困難です。SNSや、モバイルユーザーを重視するプラットフォームに最適です。

**ISPプロキシ**は、データセンターでホストされていますが、インターネットサービスプロバイダー経由で登録されています。データセンタープロキシの安定性と、より高い信頼度を兼ね備えています。Eコマースのマーケットプレイスに向いています。

**データセンタープロキシ**は、クラウドサーバー上でホストされており、高速で低価格です。住宅用IPに比べてプラットフォームに検出されやすいものの、信頼度がそれほど重要でないスクレイピングやテスト用途には問題なく使えます。

**ローテーションと固定の違い:** ローテーションプロキシは、接続ごと、または一定の間隔で新しいIPを割り当てます。固定プロキシは、すべてのセッションで同じIPアドレスを維持します。ログイン状態のアカウントを長期間運用するプラットフォームでは、必ず固定プロキシを使用してください。

## 必要なプロキシの数は?

プロファイル1つにつき、プロキシは1つです。複数のプロファイルでプロキシを共有しないでください。IPアドレスを共有しているアカウントは、プラットフォームに関連付けられてしまいます。

LinkedIn のプロファイルが20個ある場合は、20個の個別の固定プロキシ(それぞれ専用のIP)が必要です。

## Gologin 内蔵プロキシとサードパーティのプロキシ

Gologin の内蔵プロキシは、ご利用のプランに含まれる住宅用ローテーションプロキシです。テストや重要度の低い作業には便利ですが、Amazon、LinkedIn、金融サービスなどのセンシティブなプラットフォームでの長期的なアカウント管理には使用しないでください。

本格的な運用には、固定IPを提供する専用のサードパーティプロキシサービスを使用してください。

内蔵プロキシを使用すべきでない場面の詳細は、[Gologin 内蔵プロキシの制限事項](https://gologin.com/docs/proxy/gologin-proxies/what-are-gologin-proxies#important-gologin-proxies-are-rotating)をご覧ください。
