---
title: "プロキシプロトコル"
---

HTTP/HTTPS と SOCKS のどちらのプロトコルも、ほとんどのウェブサイトで利用できます。ただし、高度なボット対策を導入しているサイトでは、汎用性の高い UDP 対応の SOCKS5 プロキシが推奨されることが多くあります。

Gologin は、一般的なプロキシプロトコルに対応しています。

### HTTP / HTTPS

- HTTP プロキシは、通常のウェブトラフィックで広く使われています。
- HTTPS プロキシは SSL/TLS による暗号化接続に対応しており、安全なブラウジングで一般的に使用されます。

### SOCKS4 / SOCKS5

- SOCKS プロキシは、より幅広いネットワークプロトコルに対応しています。
- SOCKS5 は最も柔軟性が高く、TCP と UDP の両方の接続に対応しています。
- そのため、自動化やスクレイピングの用途では SOCKS5 プロキシが選ばれることが多くあります。
