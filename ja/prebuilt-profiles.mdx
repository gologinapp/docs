---
title: "構築済みプロファイルテンプレート"
---

構築済みプロファイルテンプレートは、よく使われるプラットフォームのワークフロー向けに、推奨されるブラウザプロファイルの設定を提供します。

これらのテンプレートは、フィンガープリントの設定、プロキシの種類、地域設定など、プラットフォームごとに一般的に使用される設定の例を示しています。Gologin で新しいブラウザプロファイルを作成する際の出発点として利用できます。

テンプレートは固定のプリセットではなく設定例であり、ワークフローに応じて調整できます。

## TikTok プロファイルテンプレート

TikTok アカウント環境の推奨設定です。

| パラメータ | 推奨設定 |
| :-- | :-- |
| ブラウザの種類 | モバイル風の環境 |
| プロキシの種類 | レジデンシャルまたはモバイル |
| プロキシの所在地 | 固定の地域 |
| フィンガープリントの変更 | 最小限 |
| タイムゾーン | プロキシの所在地に合わせる |

TikTok はデバイスの一貫性とセッション中の挙動を非常に重視します。安定した環境を保つことで、認証チェックを減らすことができます。

## Facebook / Meta Ads プロファイルテンプレート

Facebook アカウントおよび Meta Ads のワークフロー向けの推奨設定です。

| パラメータ | 推奨設定 |
| :-- | :-- |
| ブラウザの種類 | デスクトップ |
| プロキシの種類 | レジデンシャル |
| プロキシの所在地 | 固定 |
| フィンガープリントの変更 | 頻繁な変更は避ける |
| セッション中の挙動 | 段階的にアクティビティを増やす |

Facebook はデバイスのシグナルやログイン履歴を評価するため、一貫した環境を保つことが重要です。

## 暗号資産プラットフォーム プロファイルテンプレート

暗号資産取引所や KYC プラットフォーム向けの推奨設定です。

| パラメータ | 推奨設定 |
| :-- | :-- |
| ブラウザの種類 | デスクトップ |
| プロキシの種類 | レジデンシャル |
| プロキシの所在地 | 固定の地域 |
| フィンガープリントの変更 | 認証完了後は変更しない |
| セッションの安定性 | 高 |

KYC 認証の完了後は、同じデバイス環境を維持することで、追加のセキュリティチェックを減らすことができます。

## Gmail / Google プロファイルテンプレート

Gmail や Google 広告など、Google サービス向けの推奨設定です。

| パラメータ | 推奨設定 |
| :-- | :-- |
| ブラウザの種類 | デスクトップ |
| プロキシの種類 | レジデンシャル |
| プロキシの所在地 | 安定した地域 |
| フィンガープリントの変更 | 最小限 |
| セッション中の挙動 | 段階的にアクティビティを増やす |

Google は、アカウントの信頼性を判断する際に、ログインの一貫性や各サービスにまたがるアクティビティを評価します。
