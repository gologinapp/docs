---
title: "ブラウザプロファイルとは"
---

Gologin の**ブラウザプロファイル**とは、それ自体で完結した仮想ブラウザです。実際のパソコンにインストールされた本物のブラウザと同じ見た目・動作をしますが、Gologin の中に存在し、数秒で作成・保存・切り替え・削除ができます。

各プロファイルには、次のものが個別に用意されます。

- 固有のブラウザ[フィンガープリント](/ja/how-browser-fingerprints-work)(詳しくは後述)
- Cookie とローカルストレージ
- 閲覧履歴
- 保存したパスワードと拡張機能
- プロキシ接続

プロファイルを開くと、ウェブサイトからは、別のデバイスから訪問している完全に別の人物として認識されます。プロファイルを閉じると、すべての状態がそのまま保存されます。

## なぜ重要なのか?ブラウザフィンガープリントを理解する

プロファイルについて詳しく説明する前に、**ブラウザフィンガープリント**という概念を理解しておく必要があります。

ウェブサイトにアクセスするたびに、ブラウザはお使いのデバイスや環境に関する多数の技術的な情報を自動的に送信しています。たとえば、次のような情報です。

- 使用しているブラウザとそのバージョン
- オペレーティングシステム
- 画面解像度
- パソコンにインストールされているフォント
- タイムゾーンと言語
- グラフィックカードによる画像の描画方法
- タッチスクリーンを使用しているかどうか

ウェブサイトはこれらの情報をすべて収集して組み合わせ、あなたを識別する固有の「フィンガープリント」を作成します。Cookie を削除しても、VPN を使っても、シークレットウィンドウを開いても、識別されてしまいます。

<Note>
  シークレットモードは、同じパソコンを使う他の人に閲覧履歴を見られないようにする機能です。ウェブサイトに対してブラウザフィンガープリントを隠す機能では**ありません**。シークレットウィンドウでも、外部からは通常のブラウザとまったく同じに見えます。
</Note>

そのため、複数のアカウントを別々のタブで使うだけでは対策になりません。すべてのタブが同じフィンガープリントを共有しているため、ウェブサイトは同一人物のものだと判断できてしまいます。

## Gologin のプロファイルでどう解決するか

Gologin でブラウザプロファイルを作成すると、アプリが偽物でありながら自然に見えるブラウザの ID を、一から丸ごと生成します。

Gologin は、フィンガープリントのすべてのパラメータについて、現実的な値を生成します。たとえば、違和感のない画面サイズ、自然なフォントの組み合わせ、整合性のあるタイムゾーン、それに合ったユーザーエージェント文字列などです。これらの値はすべてプロファイル内に保存され、プロファイルの使用中に訪問するあらゆるウェブサイトに提示されます。

## プロファイルの保存方法

Gologin はプロファイルをクラウドに保存します。これには次のようなメリットがあります。

- Gologin がインストールされているどのパソコンからでも、任意のプロファイルを開けます
- ローカルのパソコンが故障したり買い替えたりしても、プロファイルは失われません
- チームメンバーとプロファイルを共有でき、メンバーは再ログインせずに、保存済みの同じセッションを使用できます

## プロファイルとシークレットウィンドウの違い

|  | シークレットウィンドウ | Gologin のプロファイル |
| --- | --- | --- |
| ローカルの閲覧履歴を隠す | ✅ | ✅ |
| 閉じたときに Cookie を削除する | ✅ | ❌(Cookie は保存されます) |
| ブラウザフィンガープリントを変更する | ❌ | ✅ |
| IP アドレスを変更する | ❌ | ✅(プロキシ使用時) |
| 保存して再度開ける | ❌ | ✅ |
| 別のデバイスのように見える | ❌ | ✅ |

シークレットモードは、お使いのデバイス上でのプライバシーを守るためのツールです。一方、Gologin のプロファイルは、インターネット上での ID を丸ごと置き換えるものです。

## まとめ

Gologin のブラウザプロファイルとは、独自のフィンガープリント、Cookie、プロキシを備えた、保存済みの仮想ブラウザです。プロファイルを開くと、訪問するどのウェブサイトからも、別のデバイスを使う完全に別の人物のように見えます。プロファイルを閉じるとセッションが保存されるため、いつでも続きから再開できます。これにより、1 台のパソコンから複数の独立したオンライン ID を、クリーンかつ安全に管理でき、アカウント同士やあなた自身とのひも付けも防げます。
