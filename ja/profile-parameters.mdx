---
title: "プロフィール設定"
---

Gologin の各ブラウザプロフィールには、ウェブサイトからの見え方を決める独自の設定があります。これらの設定は、プロフィールエディタ上部のタブに分かれています。

プロフィール設定を開くには、**プロフィールの3つのドット** \> **設定** をクリックします。

## 概要

このタブでは、プロフィールが動作しているように見せるオペレーティングシステムを設定し、基本となるフィンガープリントを生成します。

**オペレーティング·システム** - Windows 10、Windows 11、Mac Intel、Mac ARM、Linux、Android から選択します。ここで選んだ OS が、プロフィールがアクセスするすべてのウェブサイトに通知されます。

<Warning>
  オペレーティングシステムはプロフィールの作成時にのみ選択できます。プロフィールを保存すると、このオプションはロックされ、変更できなくなります。別の OS が必要な場合は、新しいプロフィールを作成してください。
</Warning>

**新しい指紋** - クリックすると、画面解像度、フォント、グラフィックの詳細情報など、ウェブサイトがブラウザを識別するために使用するシグナルについて、新しいフィンガープリント値がプロフィールに生成されます。プロフィールの識別情報をリセットしたい場合に使用してください。OS、Cookie、その他のブラウザデータは変更も削除もされません。

右側の**プロフィール概要**パネルは、変更に合わせて更新され、プロフィールの現在のフィンガープリントをひと目で確認できます。

</Frame>

## プロキシ

このタブでは、プロフィールがブラウジング時に使用するプロキシを設定します。

- **Gologin プロキシ** - Gologin に組み込まれたプロキシサービスのプロキシを使用します。
- **あなたの代理人** - 外部プロバイダーから取得した独自のプロキシを貼り付けます。
- **プロキシなし** - プロフィールは実際のインターネット接続を使用します。ウェブサイトに表示される IP アドレスは、あなた自身の IP アドレスになります。

<Frame>
  ![Settings Proxy](/images/settings_proxy.png)
</Frame>

ここで割り当てたプロキシによって、このプロフィールの実行中にウェブサイトに表示される IP アドレスが決まります。タイムゾーンや位置情報が IP に自動で合わせる設定になっている場合は、それらにも影響します。

## タイムゾーン

このタブでは、プロフィールがウェブサイトに通知するタイムゾーンを設定します。

デフォルトでは、**外部 IP に基づいてタイムゾーンを入力します**のトグルがオンになっており、プロフィールはプロキシの所在地に合ったタイムゾーンを自動的に使用します。これにより、プロフィール内の情報に一貫性が保たれます。たとえば、米国のプロキシを使うプロフィールは、その地域の実際のユーザーと同じく米国のタイムゾーンを通知します。

<Note>
  自動のままにして、手動では変更しないことをおすすめします。タイムゾーンがプロキシの所在地と一致しないと、ウェブサイトから不審に見られる可能性があります。特別な理由がある場合にのみ変更してください。
</Note>

</Frame>

## 拡張機能

このタブでは、プロフィールにブラウザ拡張機能をインストールします。拡張機能はプロフィールごとに個別に管理されるため、ここで追加しても他のプロフィールには影響しません。

**拡張機能を追加**をクリックすると、このプロフィール用の拡張機能を検索してインストールできます。

Gologin プロフィールでの拡張機能の使い方については、[拡張機能](/ja/browser-profiles/profile-features/browser-extensions/browser-extensions)をご覧ください。

## ブックマーク

このタブでは、プロフィールのブックマークバーにブックマークを追加できます。次のいずれかの形式でテキストフィールドに貼り付けてください。

- `folder::name::url` - 指定した名前のフォルダ内にブックマークを作成します
- `name::url` - ブックマークバーに直接、名前付きのブックマークを作成します
- `url` - カスタム名なしで URL をそのまま追加します

1行が1つのブックマークになります。プロフィールの実行中は、Orbita 内のブックマークバーに表示されます。

## 位置情報

このタブでは、ウェブサイトから位置情報を求められたときの動作を設定します。たとえば、地図アプリが「このサイトにあなたの位置情報の利用を許可しますか？」と尋ねる場合です。

次の3つのオプションがあります。

- **促す** - サイトが位置情報へのアクセスを要求するたびに、ブラウザが確認します。これがデフォルトで、実際のブラウザの動作に近いものです。
- **許可する** - 位置情報へのアクセスを要求したすべてのサイトに、自動的に許可を与えます。
- **ブロック** - すべての位置情報リクエストを通知なしで拒否します。

**外部 IP に基づいて位置情報を入力します**のトグルは、デフォルトでオンになっています。有効にすると、Gologin がプロフィールが通知する座標をプロキシの所在地に合わせて自動的に設定します。

<Note>
  このトグルはオンのままにしておくことをおすすめします。オフにして位置情報がプロキシの IP と一致しなくなると、その不一致が検出システムに見抜かれる要因になる可能性があります。使用したい座標とその理由が明確な場合にのみ、手動で調整してください。
</Note>
