Gologin Web Unlocker は、JavaScript を多用するサイトや保護されたサイト向けの**単一エンドポイントの Scraping API** です。

URL を送信すると、レンダリング済みのページの HTML/テキストが返されます。取得した内容は、お使いの抽出パイプラインで処理できます。

## Scraping API として使う理由

- あらゆる対象 URL に対応する 1 つのエンドポイント
- API キー認証のみで利用でき、ブラウザのオーケストレーションは不要
- デフォルトは HTML で、リクエストに応じて Markdown または JSON も取得可能。既存のパーサーにそのまま利用できます
- ETL、モニタリング、AI へのデータ取り込み、データパイプラインに適しています

## エンドポイント

`GET https://parsing.webunlocker.gologin.com/v1/scrape?url={encoded_url}`

## 認証

API キーをヘッダーで送信します。

```http
apikey: <API_KEY>
```

## リクエストの仕様

| 名前 | 場所 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| `url` | クエリ | string (絶対 URL) | はい | スクレイピング対象の URL |
| `format` | クエリ | string | いいえ | レスポンス形式: `html` (デフォルト)、`markdown`、`json` |

## クイックスタート

### cURL

```bash
curl "https://parsing.webunlocker.gologin.com/v1/scrape?url=https%3A%2F%2Fexample.com" \
  -H "apikey: YOUR_API_KEY"
```

### Python

```python
import requests

response = requests.get(
    "https://parsing.webunlocker.gologin.com/v1/scrape",
    params={"url": "https://example.com"},
    headers={"apikey": "YOUR_API_KEY"}
)

print(response.status_code)
print(response.text[:500])
```

### JavaScript (fetch)

```js
const response = await fetch(
  "https://parsing.webunlocker.gologin.com/v1/scrape?url=" +
    encodeURIComponent("https://example.com"),
  { headers: { apikey: "YOUR_API_KEY" } }
);

const html = await response.text();
console.log(response.status, html.slice(0, 500));
```

## レスポンスの動作

デフォルトでは、レスポンスボディはページの**レンダリング済みの生の HTML** です。`format=markdown` を指定すると Markdown、`format=json` を指定すると次のような JSON オブジェクトが返されます。

```json
{
  "success": true,
  "data": {
    "url": "https://example.com",
    "metadata": {
      "response_time_ms": 297,
      "status_code": 200
    },
    "html": "<!DOCTYPE html><html lang=\"en\">..."
  }
}
```

ステータスコード:

- `200` -> 成功。ボディには、指定した形式のページが含まれます
- `400` -> 不正なリクエスト。たとえば `url` が指定されていない場合です。ボディ: `{"success":false,"error":"Request failed"}`
- `401` -> `apikey` ヘッダーがありません。ボディ: `{"message":"Missing API key in request"}`

## リトライの指針

次の場合は、指数バックオフでリトライしてください。

- ネットワークエラー
- `408`、`429`、`500`、`502`、`503`、`504`

## 公式 Node.js SDK

インストール:

```bash
npm i gologin-webunlocker
```

### SDK のクイックスタート

```ts
import { WebUnlocker } from "gologin-webunlocker";

const client = new WebUnlocker({
  apiKey: process.env.GOLOGIN_WEBUNLOCKER_API_KEY!
});

const result = await client.scrape("https://example.com");
console.log(result.status);
console.log(result.content.slice(0, 500));
```

### コンストラクターのオプション

```ts
new WebUnlocker({
  apiKey: "wu_live_xxx",
  baseUrl: "https://parsing.webunlocker.gologin.com",
  timeoutMs: 15000,
  maxRetries: 2
});
```

### SDK の主なメソッド

- `scrape(url)` -> 正規化されたレスポンスオブジェクト
- `scrapeRaw(url)` -> ネイティブの `Response`
- `buildScrapeUrl(url)` -> 完全なリクエスト URL

### SDK 側で生成するメソッド (返された HTML から生成)

これらは**バックエンドの別のエンドポイントではなく**、API が返した HTML から SDK 内で生成されます。SDK は `url` パラメーターのみを送信し、`format` は送信しないため、API 自体の `format=markdown` や `format=json` のレスポンスとは出力が異なる場合があります。

- `scrapeText(url)` -> プレーンテキスト
- `scrapeMarkdown(url)` -> Markdown
- `scrapeJSON(url)` -> 構造化メタデータ (`title`、`description`、`canonical`、`meta`、`headings`、`links`)
- `batchScrape(urls, { concurrency })` -> 複数のスクレイピング呼び出しをまとめて実行するヘルパー

### 型付きエラー

- `WebUnlockerError`
- `AuthenticationError`
- `RateLimitError`
- `APIError`
- `TimeoutError`
- `NetworkError`

対応関係:

- `401` / `403` -> `AuthenticationError`
- `429` -> `RateLimitError`
- `500` 以上、およびその他の 2xx 以外のステータス (たとえば `400`) -> `APIError`
- タイムアウト/中断 -> `TimeoutError`
- fetch/ネットワークの失敗 -> `NetworkError`

## CLI

```bash
gologin-webunlocker <command> <url> [options]
```

コマンド:

- `scrape` (生の HTML/テキスト)
- `text` (生成されたテキスト)
- `markdown` (生成された Markdown)
- `json` (生成されたメタデータ)

例:

```bash
gologin-webunlocker scrape https://example.com --api-key wu_live_xxx
GOLOGIN_WEBUNLOCKER_API_KEY=wu_live_xxx gologin-webunlocker text https://example.com
GOLOGIN_WEBUNLOCKER_API_KEY=wu_live_xxx gologin-webunlocker json https://example.com
```

## スクレイピングの主なユースケース

- 価格やカタログのモニタリング
- リードやディレクトリ情報の拡充
- 市場インテリジェンスのパイプライン
- コンテンツの集約とインデックス作成
- LLM へのデータ取り込みと抽出のワークフロー

## Gologin Web Access CLI (統合版)

Web Unlocker と Cloud Browser を 1 つのコマンド体系にまとめた、より強力な CLI が必要な場合は、`gologin-web-access` を使用してください。

```bash
npm install -g gologin-web-access

export GOLOGIN_WEB_UNLOCKER_API_KEY="wu_..."

# all scraping commands from gologin-webunlocker, plus:
gologin-web-access batch-scrape url1 url2 url3 --format text --summary
gologin-web-access search "query" --limit 10
gologin-web-access map https://example.com --limit 50
gologin-web-access crawl https://docs.example.com --format markdown --limit 20
gologin-web-access extract https://example.com --schema ./schema.json
gologin-web-access change-track https://example.com --format markdown

# plus cloud browser interaction (requires GOLOGIN_TOKEN)
gologin-web-access open https://example.com
gologin-web-access snapshot
gologin-web-access click e3
```

詳しいリファレンスは [Gologin Web Access CLI](/ja/cli-tools/web-access) をご覧ください。
