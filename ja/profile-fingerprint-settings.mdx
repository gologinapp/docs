---
title: "プロファイルのフィンガープリント設定"
---

Gologin では、ブラウザプロファイルの作成時や編集時にフィンガープリントのパラメータを設定できます。

これらの設定によって、ウェブサイトや不正検知システムに対してブラウザプロファイルがどのように見えるかが決まります。

ウェブサイトはブラウザ環境から複数の技術的なシグナルを収集し、それらを組み合わせて、デバイスの識別に使われる**ブラウザフィンガープリント**を作成します。

Gologin のフィンガープリント設定は、いくつかのカテゴリに分かれています。

## ナビゲーターのフィンガープリント

ナビゲーターのパラメータは、ブラウザとデバイス環境の全般的な情報を表します。

ウェブサイトは、`navigator.userAgent` や `navigator.platform` などの JavaScript API を使ってこれらの値を読み取ります。

主なナビゲーターのパラメータは次のとおりです。

- **ユーザーエージェント** – ブラウザの種類、バージョン、オペレーティングシステムを識別します
- **オービタ版** – プロファイルで使用する Chromium のバージョンです
- **画面の解像度** – ウェブサイトに通知される画面サイズです
- **言語** – ブラウザで優先する言語です
- **プラットホーム** – オペレーティングシステムのプラットフォームです
- **CPU スレッド** – ブラウザに通知されるプロセッサコア数です
- **羊** – 利用可能なデバイスメモリです
- **追跡しません** – プライバシー設定を伝えるシグナルです

これらのパラメータにより、ウェブサイトは使用されているデバイスの種類を判断できます。

## フォント

ブラウザ環境にインストールされているフォントも、フィンガープリントのシグナルのひとつです。

ウェブサイトは、ページ上でテキストがどのように描画されるかを測定することでフォントを検出できます。オペレーティングシステムやデバイスごとにフォントの構成が異なるため、デバイスの識別に利用されます。

Gologin はフォントリストをマスクし、選択したオペレーティングシステムに合った現実的な組み合わせを生成できます。

## メディアデバイス

メディアデバイスの設定では、ウェブサイトから見えるカメラ、マイク、音声出力を定義します。

ウェブサイトは `navigator.mediaDevices` API を使ってこの情報にアクセスできます。

Gologin では、次の項目をマスクできます。

- ビデオ入力
- オーディオ入力
- オーディオ出力

これにより、ウェブサイトに実際のハードウェア構成を特定されることを防げます。

## ハードウェアのフィンガープリント

ハードウェア関連のシグナルは、ブラウザフィンガープリントに追加のエントロピーをもたらします。

これらのパラメータには、グラフィックスやオーディオの描画特性が含まれます。

### Canvas

Canvas API を使うと、ウェブサイトはブラウザ内で非表示の画像を描画できます。\
描画結果はデバイスごとにわずかに異なるため、生成された画像をハッシュに変換してフィンガープリントとして利用できます。

### WebGL

WebGL は、デバイスが使用しているグラフィックスハードウェアの情報を明らかにします。

ウェブサイトは、WebGL のレポートを調べたり、非表示の 3D オブジェクトを描画したりして、フィンガープリントを生成することがあります。

### AudioContext

オーディオフィンガープリントは、音声処理の違いを利用して一意のハッシュを生成します。

### ClientRects

この手法では、ページ上で要素がどのように配置され、描画されるかを測定します。

Gologin では、これらのシグナルを変更またはマスクして、プロファイルごとに一貫性がありながら固有のフィンガープリントを生成できます。

## WebRTC

WebRTC は、ブラウザでリアルタイム通信を行うための技術です。

ただし、ローカル IP アドレスや実際の IP アドレスがウェブサイトに漏れる可能性があります。

Gologin では、WebRTC の動作を制御できます。

- **IPに基づく** – WebRTC がプロキシの IP を通知します
- **オフ** – WebRTC を無効にします

これにより、IP の漏えいを防ぎ、フィンガープリントをプロキシの所在地と一致させた状態に保てます。

## ベストプラクティス

ブラウザ ID を安定して維持するには、次の点に注意してください。

- アカウント作成後は、フィンガープリント設定を変更せず一貫させる
- タイムゾーンと言語をプロキシの所在地に合わせる
- ハードウェア関連のパラメータを頻繁に変更しない
- プロファイルごとに専用のプロキシを使用する

フィンガープリントが安定していると、ウェブサイトはそのプロファイルを一貫したデバイスとして認識します。

## フィンガープリントを確認する方法

プロファイルを起動したら、次のいずれかのサイトでフィンガープリントを確認できます。

- [**iphey.com**](https://iphey.com) -- 全体的な信頼スコアを表示します。緑色の「Trusted」と表示されれば、プロファイルが実際のブラウザのように見えていることを意味します。
- [**pixelscan.net**](https://pixelscan.net) -- 各フィンガープリントパラメータの詳細な内訳を表示します。

### よくある問題とその意味

| 問題 | 意味 | 対処方法 |
| --- | --- | --- |
| OS の不一致 | プロファイルの OS が実際のデバイスの OS と一致していません | 実際の OS に合わせて新しいプロファイルを作成してください |
| WebGL の不一致 | GPU 情報が申告されているハードウェアと矛盾しています | 通常は自動で正しく設定されます。警告が出た場合は、プロファイル設定で別の WebGL モードを試してください。 |
| タイムゾーンの不一致 | タイムゾーンがプロキシの所在地と一致していません | Gologin はタイムゾーンをプロキシの IP に自動で合わせます。それでも異なる場合は、プロキシの所在地を確認してください。 |
| Canvas ハッシュの変化 | セッション間で Canvas フィンガープリントが異なります | デバイス間で一貫性を保つには、Canvas を「ノイズを追加」ではなく「オフ」または「ブロック」に設定してください |
