**Cloud Android** を使うと、Gologin アプリから直接、クラウド上の本物の Android スマートフォンを起動できます。物理的なスマートフォンは必要ありません。Cloud Android の各プロファイルは、それぞれ独立したアプリとデータを持つ 1 台のスマートフォンです。そのため、ブラウザプロファイルと同じ感覚でモバイルアプリ(たとえば Instagram)を操作できます。

## 利用できるユーザー

Cloud Android は、Gologin のすべての有料プランで無料でご利用いただけます。無料トライアル中のユーザーも、Google アカウントで登録していれば、トライアル期間中に利用できます。

| | 同時に起動できるスマートフォン数 | 時間制限 |
| --- | --- | --- |
| トライアル(Google で登録) | 1 | 制限なし |
| 有料プラン | 最大 10 | 制限なし |

## Cloud Android プロファイルの作成と起動

![Cloud Android](/images/cloud_android.png "Cloud Android")

1. 左側のメニューで **クラウド Android** をクリックします。
2. **Androidプロファイルを追加** をクリックします。
3. プロキシなどの設定を行います。
3. プロファイルの **起動** をクリックします。スマートフォンの起動には **最大 2 分** かかることがあります。
4. プロファイルが **ゲーム開始可能** になったら、**開く** をクリックしてスマートフォンのウィンドウを開きます。
5. 終了するには、**ストップ** をクリックします。

現在起動中のスマートフォンの数は、ページ上部(**現在起動中**)に表示されます。

## スマートフォンの操作

スマートフォンのウィンドウには、標準の Android ボタンに加えて、右側にツールが表示されます。たとえば、スクリーンショット、ファイルのアップロードとダウンロード、画面の回転、音量、位置情報、電源などです。

アプリは、スマートフォン上の **Aurora Store**、**F-Droid**、**Uptodown** などのアプリストアからインストールします。アプリ、ログイン情報、その他のデータは、起動を繰り返してもプロファイル内に保持されます。

![Cloud Android Prone Ui](/images/cloud_android_prone_ui.png "Cloud Android の操作画面")

<Note>
  すべての Android アプリがCloud Android で動作するわけではありません。アプリが開かない場合は、代わりにブラウザでそのアプリのウェブサイトを開いてみてください。
</Note>

## プロキシ

Cloud Android のスマートフォンは Gologin のサーバー上で動作します。そのため、プロキシを使用しない場合、ウェブサイトやアプリにはお客様の IP アドレスではなくサーバーの IP アドレスが表示されます。プロキシは、ブラウザプロファイルと同じ方法でプロファイルに追加できます。Gologin のプロキシやお客様ご自身のプロキシなど、すべてのプロキシタイプに対応しています。スマートフォンにはモバイルプロキシが最も自然に見えますが、どのタイプでも利用できます。

## 非アクティブ時のタイムアウト

起動中のスマートフォンで **15 分間** 操作がない場合、自動的に停止します。データは保存されます。
