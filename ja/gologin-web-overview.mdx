Gologin は、デスクトップアプリだけでなく、[app.gologin.com](http://app.gologin.com) のウェブアプリとしても利用できます。Gologin アカウントでサインインすれば、インストール不要で、あらゆるデバイスのどのブラウザからでもプロフィールを管理できます。

### クラウドブラウザ

ウェブアプリの仕組みを理解するには、クラウドブラウザについて知っておくと便利です。

デスクトップアプリでプロフィールを起動すると、そのプロフィールはお使いのデバイス上で開き、RAM や CPU などデバイスのリソースを使用します。そのため、同時に実行できるプロフィールの数はハードウェアの性能によって制限されます。

クラウドブラウザは仕組みが異なります。プロフィールはお使いのデバイスではなく Gologin のサーバー上で実行され、普段お使いのブラウザからその画面を見て操作します。そのため、デバイスのリソースを消費せず、どこからでもプロフィールを実行でき、同時に実行できるプロフィールの数もハードウェアに左右されません。

クラウドブラウザの各プロフィールには、デスクトップアプリのプロフィールと同様に、独自のブラウザフィンガープリントと IP アドレスが割り当てられます。

### ウェブアプリでできること

[app.gologin.com](http://app.gologin.com) のウェブアプリでは、デスクトップアプリと同じ主要な機能を利用できます。プロフィールの作成と管理、クラウドブラウザプロフィールの実行、アカウント設定へのアクセスなど、すべて通常のブラウザのタブから行えます。

普段使っているパソコンが手元にない場合や、デスクトップアプリがインストールされていないデバイスからプロフィールにアクセスしたい場合に便利です。
