Gologin Agent Browser CLI は、Gologin のブラウザプロファイルを、AI エージェント向けの永続的でスクリプト化しやすい実行環境に変えます。セッションは Gologin Cloud Browser、またはお使いのマシン上の Orbita で実行されます。コンパクトなページスナップショット、ref ベースの操作、セッションメモリ、シェルで扱いやすい出力を提供します。

Puppeteer/Playwright のコードをゼロから書く場合と違い、この CLI はブラウザ自動化のためのコマンド群をあらかじめ用意しています。定型コードやセッション管理のコードは不要です。

---

## クラウドランタイムとローカルランタイム

CLI には、同じコマンドで使える 2 つのランタイムがあります。どちらも Gologin のプロファイル、フィンガープリント、プロキシを使用し、デーモンが CLI の呼び出しをまたいでセッションを維持します。

| | `cloud`(デフォルト) | `local` |
|---|---|---|
| ブラウザの実行場所 | Gologin Cloud Browser | お使いのマシン上の Orbita |
| プロファイル ID | 任意: 指定しない場合は一時的なクラウドプロファイルが作成されます | 必須 |
| 向いている用途 | 並列セッション、リモートセッション、ブラウザを実行したくないマシン | プロファイルのウォームアップ、初回ログイン、ローカルの Cookie やプロファイルの状態、OS の一致 |

ランタイムはコマンドごとに `--runtime cloud|local|auto` で選択できます。または `GOLOGIN_AGENT_BROWSER_RUNTIME` を一度設定してください。

```bash
gologin-agent-browser open https://example.com
gologin-agent-browser open https://example.com --runtime local --profile your_profile_id
```

デフォルト(`auto`)では、プロファイル、ランブック、ジョブのコマンドはローカルで実行され、それ以外はクラウドで実行されます。ローカルセッションを開いた後は、続くコマンドにも `--runtime local` を指定してください。要件とローカル専用コマンドについては、[ローカルランタイム](/ja/cli-tools/local-agent-browser)をご覧ください。

## インストール

```bash
npm install -g gologin-agent-browser-cli
```

グローバルインストールなしで実行することもできます。

```bash
npx gologin-agent-browser-cli --help
```

Node.js 18 以上が必要です。ローカルランタイムには Node.js 20 以降が必要です。

## 認証情報

| 変数 | 必須 | 説明 |
|---|---|---|
| `GOLOGIN_TOKEN` | はい(`open` と API コマンドの場合) | Gologin API トークン |
| `GOLOGIN_PROFILE_ID` | 任意 | デフォルトのプロファイル ID |
| `GOLOGIN_AGENT_BROWSER_RUNTIME` | 任意 | デフォルトのランタイム: `cloud`、`local`、または `auto` |
| `GOLOGIN_DAEMON_PORT` | 任意 | デーモンのポート(デフォルト: クラウドは `44777`、ローカルは `44778`) |
| `GOLOGIN_CONNECT_BASE` | 任意 | Cloud Browser のエンドポイント(デフォルト: `https://cloudbrowser.gologin.com/connect`) |
| `GOLOGIN_EXECUTABLE_PATH` | 任意 | ローカルランタイム用の Orbita 実行ファイルのパス |

### トークンを取得する

1. [gologin.com](https://gologin.com) でサインアップまたはログインします
2. ダッシュボードで **API & MCP** を開きます
3. **API** タブを開きます
4. **新しいトークン** をクリックします
5. 生成されたアクセストークンをコピーします

```bash
export GOLOGIN_TOKEN='your_gologin_token'
```

### 設定ファイル

`~/.gologin-agent-browser/config.json`

## アーキテクチャ

次の 2 つの部分で構成されています。

1. **`gologin-agent-browser` CLI** — コマンドを解析し、ランタイムを選択し、対応するデーモンを自動起動して、コンパクトな出力を表示します
2. **常駐ローカルデーモン**(ランタイムごとに 1 つ) — 稼働中のブラウザセッションを管理し、Playwright の `connectOverCDP` を通じて Gologin Cloud Browser またはローカルの Orbita に接続します。アクティブなページをメモリ上に保持し、スナップショットの作成、ref の解決、セッションメタデータの追跡を行います

通信はローカルのみです。クラウドデーモンは次の場所で待ち受けます。
- `${TMPDIR:-/tmp}/gologin-agent-browser.sock` の Unix ソケット
- `127.0.0.1:${GOLOGIN_DAEMON_PORT:-44777}` のローカルホスト HTTP

クラウドランタイムでプロファイル ID を指定しない場合、デーモンは API を通じて一時的な Gologin クラウドプロファイルを作成します。

## ref の仕組み

`snapshot` はコンパクトなページビューを出力し、操作可能な要素に `@e1`、`@e2`、`@e3` のような ref を割り当てます。これらを直接指定して操作します。

```bash
gologin-agent-browser snapshot
# output shows page content with refs like @e1, @e2, @e3...

gologin-agent-browser click @e3
gologin-agent-browser type @e5 "search query"
gologin-agent-browser fill @e7 "username"
```

ref はベストエフォートで割り当てられるため、ページ遷移や DOM の大きな変更の後は再生成してください。コマンドでは ref の代わりに CSS セレクタも使用できます。動的なページでは、古くなった ref よりも `find` を代替手段として使うほうが適していることが多くあります。`find` は実際のページ上で要素を探し、そのまま 1 ステップで操作します。

```bash
gologin-agent-browser find label "Email" fill "user@example.com"
gologin-agent-browser find role button click --name "Submit"
```

## クイックスタート

```bash
export GOLOGIN_TOKEN='your_token'

# open a page in cloud browser
gologin-agent-browser open https://example.com

# read the page as a compact snapshot
gologin-agent-browser snapshot

# interact with elements
gologin-agent-browser click @e3
gologin-agent-browser type @e5 "hello world"

# take a screenshot
gologin-agent-browser screenshot ./page.png

# close the session
gologin-agent-browser close
```

## エージェントループの例

一般的な AI エージェントのループは次のとおりです。

```
1. open <url>
2. snapshot          → agent reads page content
3. click/type/fill   → agent acts on refs
4. snapshot          → agent reads result
5. repeat 3-4 as needed
6. screenshot        → save artifact
7. close
```

## コマンドリファレンス(全一覧)

### 診断

| コマンド | 説明 |
|---|---|
| `doctor` | デーモンの状態と接続を確認します |

### セッション管理

| コマンド | 説明 |
|---|---|
| `open <url>` | ブラウザセッションで URL を開きます |
| `close` | 現在のセッションを閉じます(`--all` でこのデーモンのすべてのセッションを閉じます) |
| `sessions` | アクティブなセッションを一覧表示します(`--prune` で古いセッションを削除します) |
| `current` | 現在のセッション情報を表示します |

### ページの読み取り

| コマンド | 説明 |
|---|---|
| `snapshot` | 要素の ref を含むコンパクトなテキストスナップショット |
| `screenshot <path>` | ページのスクリーンショットを保存します |
| `pdf <path>` | ページを PDF として保存します |
| `get <kind> [target]` | ページのプロパティを取得します |

### 操作

| コマンド | 説明 |
|---|---|
| `click <ref>` | 要素をクリックします |
| `dblclick <ref>` | ダブルクリックします |
| `type <ref> <text>` | テキストを入力します(追記) |
| `fill <ref> <text>` | 入力欄に入力します(置換) |
| `hover <ref>` | 要素にカーソルを合わせます |
| `select <ref> <value>` | ドロップダウンの値を選択します |
| `check <ref>` / `uncheck <ref>` | チェックボックスを切り替えます |
| `focus <ref>` | 要素にフォーカスします |
| `find <by> <locator> <action> [value]` | `role`、`text`、`label`、`placeholder`、`first`、`last`、`nth` のいずれかで要素を探し、`click`、`fill`、`type`、`hover` のいずれかを実行するか、`text` で内容を読み取ります |

### キーボードとスクロール

| コマンド | 説明 |
|---|---|
| `press <key> [target]` | キーボードのキーを押します |
| `scroll <direction> [pixels]` | ページをスクロールします |
| `scrollintoview <ref>` | 要素が表示されるようにスクロールします |

### ナビゲーション

| コマンド | 説明 |
|---|---|
| `back` | 戻ります |
| `forward` | 進みます |
| `reload` | ページを再読み込みします |
| `wait <target\|ms>` | 要素の出現またはタイムアウトまで待機します |

### タブ

| コマンド | 説明 |
|---|---|
| `tabs` | 開いているタブを一覧表示します |
| `tabopen [url]` | 新しいタブを開きます |
| `tabfocus <index>` | タブを切り替えます |
| `tabclose [index]` | タブを閉じます |

### Cookie とストレージ

| コマンド | 説明 |
|---|---|
| `cookies` | Cookie をエクスポートします |
| `cookies-import <file>` | Cookie をインポートします |
| `cookies-clear` | Cookie を削除します |
| `storage-export [path]` | localStorage をエクスポートします |
| `storage-import <file>` | localStorage をインポートします |
| `storage-clear` | localStorage を削除します |

### 高度なコマンド

| コマンド | 説明 |
|---|---|
| `eval <expression>` | ページ内で JavaScript を評価します |
| `upload <ref> <file...>` | ファイルをアップロードします |

### プロファイル、プロキシ、Gologin API

これらのコマンドは、お使いのトークンで Gologin API を呼び出すため、ブラウザデーモンは不要です。

| コマンド | 説明 |
|---|---|
| `api <METHOD> <path>` | 任意の Gologin REST API エンドポイントを呼び出します |
| `browser <action>` | プロファイル: 一覧、取得、作成、更新、削除、Cookie、プロキシ、クラウドの開始と停止、インポートとエクスポート |
| `proxy <action>` | プロキシ: 一覧、Gologin プロキシの追加、更新、削除、トラフィック |
| `workspace`, `folder`, `share`, `template` | ワークスペースとメンバー、フォルダ、共有、プロファイルテンプレート |
| `user`, `deleted-profile` | アカウント情報と開発用トークン、削除したプロファイルの復元 |
| `cloud-usage` | プロファイルまたはワークスペースの Cloud Browser 使用量 |
| `profile-cloud`, `profile-cookies`, `profile-fingerprint`, `profile-proxy`, `profile-ua` | ショートカット: クラウドでのプロファイルの開始または停止、Cookie のエクスポートまたはインポート、フィンガープリントの更新、プロキシの追加、ユーザーエージェントの更新 |

```bash
gologin-agent-browser browser list --page 1
gologin-agent-browser proxy add-gologin your_profile_id --country us --type residential
gologin-agent-browser cloud-usage --profile your_profile_id
gologin-agent-browser api GET /browser/your_profile_id
```

任意のコマンドに `--help` を付けると、その使い方が表示されます。

## ユースケースと例

### サイトがアンチディテクトのテストに合格するか確認する

```bash
gologin-agent-browser open https://iphey.com/ --profile your_profile_id
gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # read the trust score
gologin-agent-browser screenshot ./iphey-result.png
gologin-agent-browser close
```

### Web アプリにログインしてダッシュボードのデータを取得する

```bash
gologin-agent-browser open https://app.example.com/login
gologin-agent-browser snapshot

# agent reads snapshot, finds login form
gologin-agent-browser fill @e4 "user@company.com"
gologin-agent-browser fill @e6 "password"
gologin-agent-browser click @e8

gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # agent reads dashboard content

# navigate to the report page
gologin-agent-browser click @e12   # "Reports" link
gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # agent extracts report data
gologin-agent-browser screenshot ./report.png
gologin-agent-browser close
```

### 複数ステップのフォームに入力する

```bash
gologin-agent-browser open https://forms.example.com/apply

# step 1: personal info
gologin-agent-browser snapshot
gologin-agent-browser fill @e3 "John Doe"
gologin-agent-browser fill @e5 "john@example.com"
gologin-agent-browser select @e7 "United States"
gologin-agent-browser click @e9   # Next

# step 2: upload and submit
gologin-agent-browser wait 1000
gologin-agent-browser snapshot
gologin-agent-browser upload @e4 ./resume.pdf
gologin-agent-browser check @e6   # agree to terms
gologin-agent-browser click @e8   # Submit

gologin-agent-browser wait 2000
gologin-agent-browser snapshot     # confirm success
gologin-agent-browser close
```

### 競合他社のページのスクリーンショットを撮る

```bash
# use different profiles with different geos
for profile in us_profile de_profile jp_profile; do
  gologin-agent-browser open https://competitor.com --profile $profile
  gologin-agent-browser wait 3000
  gologin-agent-browser screenshot ./${profile}-homepage.png
  gologin-agent-browser close
done
```

### スクレイピングをブロックするサイトで検索する

サイトによっては、結果を表示する前に JavaScript の実行、ログイン、または操作が必要です。そのような場合は、ブラウザを使って検索します。

```bash
gologin-agent-browser open https://protected-directory.com
gologin-agent-browser snapshot
gologin-agent-browser find placeholder "Search" fill "machine learning engineer San Francisco"
gologin-agent-browser press Enter
gologin-agent-browser wait 3000
gologin-agent-browser snapshot     # agent reads search results
gologin-agent-browser screenshot ./search-results.png
gologin-agent-browser close
```

### セッション状態を保存して復元する

Cookie とストレージをエクスポートして、別のセッションで再利用できます。

```bash
# after logging in
gologin-agent-browser cookies --output ./session-cookies.json
gologin-agent-browser storage-export ./session-storage.json
gologin-agent-browser close

# later, restore the session
gologin-agent-browser open https://app.example.com
gologin-agent-browser cookies-import ./session-cookies.json
gologin-agent-browser storage-import ./session-storage.json
gologin-agent-browser reload
gologin-agent-browser snapshot     # already logged in
```

## 並列セッション

独立したクラウドタスクには、明示的な `--session` ID を使用します。後片付けには `close --all` または `sessions --prune --older-than-ms` を使います。

## プロキシのルール

- 事前設定済みのプロファイル: プロキシは Gologin のダッシュボードまたは API でプロファイルに設定します(例: `proxy add-gologin <profileId> --country us`)
- 一時的なクラウドプロファイル: プロキシなし、または `--proxy-host` と `--proxy-port` で指定した独自のプロキシ(`--proxy-mode http|socks4|socks5`、`--proxy-user`、`--proxy-pass` も併用できます)
- クラウドランタイムでは、`open` は `--proxy-country` を受け付けません。特定の国の Gologin プロキシのトラフィックを使うには、プロファイルに Gologin プロキシを追加し、`--profile` を指定してそのプロファイルを開いてください
- ローカルランタイムでは、`open`、`profile-create`、`profile-update` が `--proxy-country` を受け付けます
