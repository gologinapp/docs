---
title: "Amazon、eBay、Shopify"
---

ECマーケットプレイスは、アカウントの関連付け(リンク)に最も厳しいプラットフォームです。Amazon、eBay、Shopifyはいずれもアカウント間の関連グラフを保持しており、2つのアカウントでIPアドレス、支払い方法、デバイスフィンガープリント、配送先住所のいずれかが共通していると、プラットフォーム側がそれらを関連付けます。1つのアカウントが停止されると、関連付けられた他のアカウントも通常あとに続いて停止されます。

## クイックチェックリスト

- 出品者アカウント1つ = ブラウザプロフィール1つ
- プロフィール1つ = 固定のレジデンシャルまたはISPプロキシ1つ
- **ローテーションプロキシは絶対に使用しないでください** — IPが変わると、アカウントがすぐに関連付けられます
- **Gologinの内蔵プロキシは絶対に使用しないでください** — デフォルトでローテーション方式です
- アカウントごとに固有の支払い方法を用意する
- アカウントごとに固有の電話番号とメールアドレスを用意する

## ステップ1. Gologinプロフィールを設定する

- **プロキシ:** 固定のレジデンシャルまたはISPプロキシ — アカウントごとに専用のIPを1つ割り当て、共有しないでください
- **フィンガープリント:** デフォルトのままにします

## ステップ2. アカウントをウォームアップする

| **期間** | **重点項目** | **実施内容** |
| :-- | :-- | :-- |
| 0日目 | セットアップ | 登録 \+ 本人確認 |
| 1〜3日目 | 探索 | 出品者向けツールを閲覧し、ポリシーを読む |
| 4〜7日目 | 軽めの操作 | 5〜10件の商品を出品し、配送設定を行う |
| 2週目 | 通常運用 | 出品の管理、問い合わせへの対応 |
| 3週目以降 | 拡大 | 出品数を段階的に増やす |

## 安全な操作パターン

| 操作 | 推奨される方法 |
| :-- | :-- |
| 商品の出品 | 少しずつ追加する |
| アカウント情報の編集 | たまに更新する |
| ダッシュボードの操作 | 定期的に閲覧する |
| 注文処理 | 一定のペースで対応する |

## 支払い方法の分離

マーケットプレイスのアカウントがまとめて関連付けられ、停止される原因として最も多いのがこの点です。

各アカウントに必要なもの:

- 固有のクレジットカードまたはデビットカード
- 固有のPayPalアカウント(使用する場合)
- 固有の請求先住所

利用できる選択肢: Revolut、Wise、N26(複数の仮想カード)、Privacy.com(米国)、プリペイド式デビットカード。

<Warning>
  複数のAmazon出品者アカウントでカードを共有すると、利用規約違反とみなされます。Amazonは関連付けられたすべてのアカウントを停止し、最大90日間資金を保留します。
</Warning>

## プラットフォーム別の注意点

### Amazon

- セッション間でIPが変わると、アカウント関連付けの自動審査が行われます
- 異議申し立ては難しいため、復旧するよりも事前の予防のほうがはるかに簡単です
- ビジネスアカウントでは、法人であることを確認できる書類が必要です

### eBay

- IPについてはAmazonほど厳しくありませんが、デバイスフィンガープリントは引き続き追跡されます
- eBayマネージドペイメントでは、アカウントごとに別々の銀行口座情報が必要です
- フィードバックスコアが重要です。新しいアカウントは購入者からの信頼度が低くなります

### Shopify

- Gologinは主に、複数のShopify管理者アカウントを管理する場合や、異なる場所から運用する場合に使用されます
- AmazonやeBayのようなアカウント間の検知はありませんが、Shopify Paymentsでは売上の支払いに対する不正検知が行われています

## アカウント停止につながりやすい要因

### Amazon

- ローテーションプロキシや共有プロキシのIP
- 複数のアカウントで同じ支払い方法を使用している
- 複数の出品者ログインで同じデバイスフィンガープリントを使用している
- 関連アカウントの停止(Amazonは関連性に基づいて停止します)

### eBay

- 過去に停止されたアカウントと同じIPまたはフィンガープリント
- 複数のアカウントで同じ商品を同時に出品する
- フィードバックを不正に操作していると疑われるパターン
