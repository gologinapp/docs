---
title: "ブラウザフィンガープリントの仕組み"
---

ウェブサイトにアクセスすると、ブラウザはページを正しく動作させるために必要な技術情報を自動的に送信します。ウェブサイトは、HTTP ヘッダーや JavaScript API を通じてこの情報にアクセスできます。

フィンガープリントスクリプトは、ブラウザやデバイス環境から次のような複数のデータを収集します。

- ブラウザとオペレーティングシステムの情報
- 画面解像度とディスプレイ設定
- インストールされているフォント
- 言語とタイムゾーン
- ハードウェアの特性
- グラフィックスのレンダリングデータ（Canvas と WebGL）
- オーディオ処理データ
- システムで利用可能なメディアデバイス

これらのデータを組み合わせて処理することで、デバイスとブラウザの構成を表す固有の識別子、つまり**ブラウザフィンガープリント**が生成されます。

ウェブサイトはこのフィンガープリントを保存し、同じユーザーが再訪問した際に照合します。フィンガープリントが過去に記録された構成と一致すれば、Cookie が削除されていてもデバイスを識別できます。

ウェブサイトでは、フィンガープリントが次のような目的で広く利用されています。

- 不審なログイン行動の検出
- 不正行為や自動化されたトラフィックの防止
- 再訪問ユーザーの識別
- 複数のセッションを同じデバイスに紐付けること

セッション間でフィンガープリントが大きく変わると、ウェブサイトはそのブラウザを新しいデバイス、または不審なデバイスとして扱う場合があります。

Gologin は、**分離されたブラウザプロファイル**を作成することでこの問題を解決します。各プロファイルは独自のフィンガープリント設定を持ち、別々のデバイスのように動作します。これにより、ブラウザ環境を互いに独立させたまま、複数のアカウントを管理できます。
