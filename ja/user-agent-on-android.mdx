description: "選択した Android のバージョンに関係なく、Android プロファイルの User-Agent には Android 10; K と表示されます。その理由と、これが正常な動作である理由を説明します。"
---

Gologin で Android プロファイルを作成して User-Agent を確認すると、プロファイルを Android 14、15、16 に設定していても、常に `Android 10; K` と表示されることに気付くはずです。文字列は次のようになります。

```text
Mozilla/5.0 (Linux; Android 10; K) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/... Mobile Safari/537.36
```

これは不具合ではなく、想定どおりの動作です。**Android 上の最新の Chrome ベースのブラウザは、すべて同じ値を報告します。**

## なぜこのような表示になるのか

2023年初めの Chrome 110 以降、Google は **User-Agent Reduction** と呼ばれる変更を導入しました。ブラウザの追跡やフィンガープリントを難しくするため、Chrome は実際の Android バージョンとデバイスモデルを User-Agent で共有しなくなりました。代わりに、すべてのユーザーに共通の固定プレースホルダー値を送信します。

- Android バージョンは `Android 10` に固定されます
- デバイスモデルは文字 `K` に置き換えられます
- Chrome のマイナーバージョン番号は `0.0.0` に設定されます

リリースごとに更新されるのは、Chrome のメジャーバージョンだけです。文字列のその部分のそれ以外の値は、すべてのデバイスで同じです。

Gologin の Android ブラウザは Chromium をベースにしているため、同じ標準に従います。Chrome、Edge、Opera、Samsung Internet もすべて `Android 10; K` と表示します。これは Gologin に限ったことではなく、現在のモバイルウェブの仕組みです。

<Info>
  `K` は Android のバージョンでも、誤字でもありません。Chrome が実際のデバイスモデルの代わりに使用しているプレースホルダーです。
</Info>

## これがむしろ利点である理由

世界中のほぼすべての Android Chrome ユーザーが `Android 10; K` と報告しているため、お使いのプロファイルも多数のユーザーに紛れることができます。もし Gologin が実際の Android バージョンを報告すると、プロファイルは通常のトラフィックから浮いてしまい、ウェブサイトに不自然だと判断される可能性があります。標準の動作に合わせることは、一般的な訪問者のように見せる必要があるブラウザプロファイルにとって、まさに望ましい状態です。

<Check>
  Android プロファイルに `Android 10; K` と表示されていれば、正しく動作しており、一般的な実際の Android デバイスのように見えています。
</Check>

実際の Android バージョンやデバイスモデルが本当に必要なウェブサイトは、User-Agent から読み取る代わりに、よりプライバシーに配慮した新しい方式（Client Hints と呼ばれます）で情報をリクエストします。そのため、User-Agent に `Android 10` と表示されていても、失われる情報はなく、選択した Android バージョンは必要な場面で引き続き適用されます。

## すべての Android プロファイルが同じに見えるのでは？

いいえ。プロファイルごとに、画面解像度、WebGL、Canvas、ハードウェアパラメータが異なります。同じになるのは User-Agent 文字列だけで、これは実際の Android デバイスでも同様です。

## ご自身で確認する方法

Gologin のプロファイルと通常の Chrome ブラウザを並べて比較すれば、実際の Android デバイスでもこれを確認できます。

通常の Chrome ブラウザで [iphey.com](https://iphey.com) などの信頼できるフィンガープリントチェッカーを開き、**ブラウザ**タブに切り替えます。次に、Gologin の Android プロファイルで同じページを開きます。両方で**ユーザーエージェント**の行を確認してください。

最新の Android デバイス上で動作していても、どちらのブラウザにもまったく同じ `Android 10; K` の値が表示されます。異なるのは Chrome のバージョン番号だけで、これは各ブラウザのリリースを反映したものです。

どちらのブラウザも同じ値を報告するため、この並べての比較は、Gologin が通常の Chrome ブラウザとまったく同じ動作をしていることを確認する最も簡単な方法です。
