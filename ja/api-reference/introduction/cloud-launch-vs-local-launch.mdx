---

Gologin で自動化を行う場合、ブラウザーは「お使いのマシン上」と「Gologin のサーバー上」の 2 か所のどちらかで実行できます。この選択によって、Orbita バイナリが実行される場所、ブラウザーへの接続方法、必要なインフラが決まります。

## 概要

|  | ローカル起動 | Cloud Browser |
| --- | --- | --- |
| ブラウザーの実行場所 | お使いのマシン | Gologin のサーバー |
| デスクトップアプリの要否 | 必要 | 不要 |
| ウィンドウの表示 | 任意(ヘッドレス) | なし |
| 必要なハードウェア | プロファイルごとに RAM(各 300〜500 MB 程度) | 不要 |
| 最適な用途 | 自分のマシンや VPS での自動化 | サーバーサイドのスクリプト、ローカルのセットアップ不要 |

## ローカル起動

ブラウザーはお使いのマシン上で実行されます。SDK は初回実行時に Orbita バイナリを自動的にダウンロードし、ローカルで起動して、Puppeteer や Playwright が接続するための WebSocket エンドポイントを返します。
