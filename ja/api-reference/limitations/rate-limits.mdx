---
title: 'レート制限'
---
Gologin APIでは、1分あたりに送信できるリクエスト数に上限があります。上限を超えた場合は、しばらく待ってからリクエストを再送信してください。

上限はご利用のプランによって異なります。

| プラン | 1分あたりのリクエスト数 |
| :-- | --: |
| Professional | 300 |
| Business | 500 |
| Enterprise | 800 |
| Custom | 1,200 |

トライアルおよびForever FreeプランにはAPIアクセスが含まれません。各プランに含まれる内容については、[料金](/ja/general/account-and-billing/pricing)をご覧ください。

### レート制限によるトークンの無効化

<Warning>
レート制限を超えてHTTP 429レスポンスを受け取ると、APIトークンは自動的に無効化されます。つまり、そのトークンは恒久的に使用できなくなり、新しいトークンを生成する必要があります。

これは一時的なクールダウンではなく、トークンが失効されます。これを避けるため、リクエストの頻度を慎重に計画し、指数バックオフを実装してください。
</Warning>

### Cloudflareによる保護エラー

サーバーのIPから送信されるリクエストが多すぎる場合、GologinのCloudflare CDNによってIPが完全にブロックされることがあります。この場合、APIのレスポンスはJSONではなくHTMLのエラーページとなり、次のようなエラーが発生します。

```
SyntaxError: Unexpected token 'e', "error code: 1015" is not valid JSON
```

これはCloudflareの1015レート制限レスポンスです。通常は数分から数時間で自動的に解消されます。これを避けるには、次の対策を行ってください。
- コード内でリクエストのレート制限を実装する
- 失敗時に指数バックオフを使用する
- API呼び出しを並列で一度に大量に送信しない

### プロファイル作成の上限

新規アカウントでは、1日あたりのプロファイル作成数に約300件の上限があります。この上限はプランによって異なる場合があります。より高い上限が必要な場合は、サポートまでお問い合わせください。
