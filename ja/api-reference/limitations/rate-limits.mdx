---
title: 'レート制限'
---
Gologin では、API に無制限にリクエストを送信することはできません。制限を超えた場合は、しばらく待つ必要があります。<br />
基本の制限は次のとおりです。
- Free プランおよびトライアルプラン：1分あたり300リクエスト
- その他のプラン：1分あたり1200リクエスト

### レート制限時のトークン無効化

<Warning>
レート制限を超えて HTTP 429 レスポンスを受け取ると、API トークンは自動的に無効化されます。つまり、そのトークンは完全に使用できなくなり、新しいトークンを生成する必要があります。

これは一時的なクールダウンではなく、トークンが失効する仕組みです。リクエストの頻度を慎重に管理し、これを避けるために指数バックオフを実装してください。
</Warning>

### Cloudflare による保護エラー

サーバーの IP からのリクエストが多すぎる場合、Gologin の Cloudflare CDN によって IP が完全にブロックされることがあります。この場合、API のレスポンスが JSON ではなく HTML のエラーページとなり、次のようなエラーが発生します。

```
SyntaxError: Unexpected token 'e', "error code: 1015" is not valid JSON
```

これは Cloudflare の 1015 レート制限レスポンスです。通常は数分から数時間で自動的に解消されます。これを避けるには、次の対策を行ってください。
- コード内でリクエストのレート制限を実装する
- 失敗時に指数バックオフを使用する
- 並列 API 呼び出しの集中的な送信を避ける

### プロファイル作成の制限

新規アカウントでは、1日あたりのプロファイル作成数に約300件の上限があります。この上限はプランによって異なる場合があります。より高い上限が必要な場合は、サポートにお問い合わせください。
