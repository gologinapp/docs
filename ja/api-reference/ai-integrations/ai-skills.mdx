Gologin AI スキルは、[Claude Code](https://claude.ai/code) に Web スクレイピングとブラウザ自動化の機能を追加する、すぐに使える拡張機能です。各スキルは Gologin CLI ツールをラップし、エージェントが呼び出せる一連の関数として提供します。

```
agent → skill → Gologin CLI → Web Unlocker API / Cloud Browser / Local Orbita
```

---

## インストール

Gologin のスキルはすべて [GologinLabs/agent-skills](https://github.com/GologinLabs/agent-skills) リポジトリからインストールできます。

```bash
# install any skill
npx skills add GologinLabs/agent-skills@gologin-web-access-skill
npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill
npx skills add GologinLabs/agent-skills@gologin-scraping-skill
```

各スキルには、対応する CLI のインストールが必要です。

| スキル | 必要な CLI |
|---|---|
| Web Access スキル | `npm i -g gologin-web-access` |
| Agent Browser スキル | `npm i -g gologin-agent-browser-cli` (クラウドとローカルの両ランタイム) |
| Scraping スキル | `npm i gologin-webunlocker` |

## 使用するスキルの選び方

| タスク | スキル |
|---|---|
| ドキュメントページ、記事、既知の URL を読む | Web Access |
| 構造化データをスクレイピングして抽出する | Web Access |
| 多数の URL を一括でスクレイピングする | Web Access |
| サイトをクロールし、URL をマッピングする | Web Access |
| ページの変更を監視する | Web Access |
| ページを読んだ後、ブラウザで操作する | Web Access (ハイブリッドモード) |
| ライブのクラウドブラウザセッションを開く | Agent Browser |
| ダッシュボードにログインし、スクリーンショットを撮る | Agent Browser |
| フォームに入力し、一連の画面を操作する | Agent Browser |
| スクレイピングのみ、ブラウザ不要、Node.js アプリ | Scraping |
| ローカルプロフィールをウォームアップする | Agent Browser (ローカルランタイム) |
| Cookie を保持したままアカウントにログインする | Agent Browser (ローカルランタイム) |
| ローカルの Orbita で SNS やマーケットプレイスの操作を行う | Agent Browser (ローカルランタイム) |
| 多数のローカルプロフィールでランブックを一括実行する | Agent Browser (ローカルランタイム) |

## Web Access スキル

**インストール:** `npx skills add GologinLabs/agent-skills@gologin-web-access-skill`

最も汎用性が高い標準スキルです。処理は `gologin-web-access` CLI に委任されます。

**スクレイピングツール:** `scrape_url`, `read_page`, `scrape_markdown`, `scrape_text`, `scrape_json`, `batch_scrape`, `batch_extract`, `search_web`, `map_site`, `crawl_site`, `crawl_site_async`, `extract_structured`, `track_changes`, `batch_track_changes`, `parse_document`

**ブラウザツール:** `browser_open`, `browser_search`, `browser_snapshot`, `browser_click`, `browser_type`, `browser_screenshot`, `browser_close`, `browser_sessions`, `browser_current`

**組み込みワークフロー:** browser-ref-loop, hybrid-read-then-interact, search-discover-and-scrape, lead-enrichment, competitive-monitoring, docs-ingestion, geo-testing, login-and-navigate-dashboard

コマンドの詳細は [Web Access CLI リファレンス](/ja/cli-tools/web-access)をご覧ください。

## Agent Browser スキル

**インストール:** `npx skills add GologinLabs/agent-skills@gologin-agent-browser-skill`

Gologin Cloud Browser (デフォルト)、または `--runtime local` を指定したローカルの Orbita プロフィールでライブセッションを実行する、ブラウザ専用のスキルです。スクレイピングを行わず、対話的にブラウジングしたい場合に使用します。

**機能:** `doctor`, `open`, `sessions`, `current`, `snapshot`, `click`, `type`, `fill`, `find`, `get`, `tabs`, `tabopen`, `tabfocus`, `tabclose`, `cookies`, `cookies-import`, `storage-export`, `storage-import`, `eval`, `back`, `forward`, `reload`, `upload`, `screenshot`, `pdf`

**ローカルランタイムで追加される機能:** プロフィール管理 (`profiles`, `profile-create`, `profile-import`, `profile-update`, `profile-sync`, `profile-delete`)、ランブック (`run`, `batch`)、ジョブ (`jobs`, `job`)、ユースケース別テンプレート (`linkedin`, `ads`, `smm`, `scraping`, `geo`)、診断 (`doctor --use-case --check-proxy`)。

コマンドの詳細は [Agent Browser CLI リファレンス](/ja/cli-tools/agent-browser)と[ローカルランタイム](/ja/cli-tools/local-agent-browser)をご覧ください。

---

## Scraping スキル

**インストール:** `npx skills add GologinLabs/agent-skills@gologin-scraping-skill`

Web Unlocker SDK を通じたスクレイピングのみを行う、最小構成のスキルです。ブラウザセッションもデーモンも不要です。

**機能:** 生の HTML (`scrape`)、テキスト (`text`)、Markdown (`markdown`)、構造化メタデータ (`json`)。SDK メソッド: `scrapeRaw()`, `scrape()`, `scrapeText()`, `scrapeMarkdown()`, `scrapeJSON()`, `batchScrape()`。

タスクがスクレイピングのみで、依存関係をできるだけ減らしたい場合に使用します。

API の詳細は [Web Unlocker SDK リファレンス](/ja/scraping-api-sdk-and-cli)をご覧ください。

---

## Local Agent Browser スキル (非推奨)

エージェントに `gologin-local-agent-browser-skill` が残っている場合、このスキルは Agent Browser スキルを案内するだけです。代わりに `gologin-agent-browser-skill` をインストールしてください。ローカルの Orbita プロフィール、ウォームアップ、ログインフロー、ランブック、バッチジョブに対応しています。

## エージェントに依頼できること

スキルをインストールすると、Claude Code に自然な言葉で指示できます。各スキルでできることの例を紹介します。

### Web Access スキルの場合

- 「competitor.com の料金ページを読んで、各プランを要約して」
- 「この 15 件の URL をスクレイピングして、それぞれの商品名と価格を抽出して」
- 「docs.example.com のドキュメントをクロールして、各セクションの概要をまとめて」
- 「『best CRM tools 2026』を検索して、上位 5 件の結果をスクレイピングして」
- 「competitor.com/pricing が昨日から変更されたか確認して」
- 「このサイトのブログ記事のタイトルと URL をすべて抽出して」
- 「ブラウザで example.com を開き、この認証情報でログインして、ダッシュボードのスクリーンショットを撮って」

### Agent Browser スキルの場合

- 「管理ダッシュボードを開いて設定に移動し、現在の設定のスクリーンショットを撮って」
- 「ステージング環境にログインして、新機能がデプロイされているか確認して」
- 「example.com のサインアップフォームに、このテスト用の情報を入力して」
- 「レポートページに移動して、月次エクスポートをダウンロードし、サマリーのスクリーンショットを撮って」
- 「このブラウザプロフィールで iphey.com に何が表示されるか確認して」

### Scraping スキルの場合

- 「この URL をスクレイピングして、テキストの内容を教えて」
- 「この 10 ページから、タイトル、説明、見出しを取得して」
- 「分析できるように、このページを Markdown 形式で取得して」

### Agent Browser スキル (ローカルランタイム) の場合

- 「米国のプロキシを設定した新しい LinkedIn プロフィールを作成して、ウォームアップして」
- 「Reddit のアカウントを開いて、フィードをスクロールしてから閉じて」
- 「20 個すべてのプロフィールで、並列数 5 でウォームアップのランブックを実行して」
- 「Facebook 広告用プロフィールのプロキシの状態を確認して」
- 「このマーケットプレイスのアカウントにログインして、販売者ダッシュボードのスクリーンショットを撮って」

## ワークフローの例

### 競合調査 (Web Access スキル)

1. エージェントが競合を検索します: `search_web("saas project management tools")`
2. エージェントが競合サイトをマッピングします: `map_site("https://competitor.com")`
3. エージェントが主要ページを一括スクレイピングします: `batch_scrape(pricing, features, about)`
4. エージェントが取得した内容を Claude に渡し、分析と比較を行います

### アカウントのウォームアップ (Agent Browser スキル、ローカルランタイム)

1. エージェントがプロフィールを作成します: `profile-create "Account 1" --template linkedin`
2. エージェントがウォームアップのランブックを実行します: `batch ./warmup.json --targets ./profiles.json`
3. エージェントがジョブの結果を確認します: `jobs --kind batch --status ok`
4. エージェントが準備のできたプロフィールを報告します

### ダッシュボードの監視 (Agent Browser スキル)

1. エージェントがダッシュボードを開きます: `open https://dashboard.example.com --profile saved_login`
2. エージェントがページを読み取ります: `snapshot`
3. エージェントが指標のページに移動します: `click @e5` (Reports リンク)
4. エージェントがレポートのスクリーンショットを撮ります: `screenshot ./daily-metrics.png`
5. エージェントがセッションを閉じます: `close`
6. エージェントがスナップショットのデータから指標を要約します

## 必須のプリフライトチェック

スキルはタスクを実行する前に、作業内容を次のように分類します。

1. **既知の 1 つのサイトか、複数ソースにわたる幅広い調査か?** — スクレイピングか検索のどちらが必要かを判断します
2. **読み取り専用の抽出、監視、対話的なブラウザ操作のどれか?** — スクレイピングとブラウザのどちらを使うかを判断します
3. **Web Unlocker のみか、Web Unlocker と Cloud Browser の両方か?** — 必要な認証情報を判断します
4. **地域依存、またはブロックが厳しく Gologin によるエンドツーエンドの対応が必要か?** — プロキシとプロフィールの要件を判断します
