---
title: "ヘッドレスブラウザとは"
keywords: ["headless browser"]

ヘッドレスブラウザとは、コードで制御されるウェブブラウザです。画面表示(グラフィカルインターフェース)なしで、ページを開き、ボタンをクリックし、フォームに入力し、データを自動的に取得します。

Chrome や Firefox とまったく同じように動作しますが、サーバー上で実行されます。画面は必要ありません。

## 仕組み

最新のブラウザは、**Chrome DevTools Protocol(CDP)** と呼ばれる制御用プロトコルを公開しています。Playwright や Puppeteer などの自動化ライブラリは、CDP を使ってブラウザにコマンドを送信します。たとえば、このURLに移動する、この要素をクリックする、このテキストを読み取る、スクリーンショットを撮る、といった操作です。

Gologin の Cloud Browser もこれと同じプロトコルをベースに構築されています。Puppeteer や Playwright のコードが CDP 経由でリモートブラウザに接続し、ローカルのブラウザと同じ方法で制御します。

## 通常の HTTP リクエストではなくヘッドレスブラウザを使う理由

現在の多くのウェブサイトは、JavaScript によってコンテンツを動的に読み込みます。単純な HTTP リクエストで取得できるのは生の HTML だけで、クライアント側で描画される内容は取得できません。

ヘッドレスブラウザは、実際のユーザーのブラウザと同様に JavaScript を実行するため、次のことができます。

- ページの描画後にコンテンツが読み込まれるのを待つ
- 動的な要素(ドロップダウン、モーダル、無限スクロールなど)を操作する
- ログインフロー、複数ステップのフォーム、SPA に対応する
- HTTP クライアントでは通過できないボット検出チェックを通過する

## クラウドで実行する理由

ヘッドレスブラウザをローカルで動かすのは簡単ですが、本番環境で安定して動かすのは簡単ではありません。

本番環境でブラウザのプロセスを管理するには、次の点への対応が必要です。

- **クラッシュと再起動** — ブラウザはクラッシュするため、インフラ側で自動的に復旧する必要があります
- **同時実行** — 複数のセッションを並列で実行するには、リソースの分離が必要です
- **スケーリング** — トラフィックが急増した場合、必要に応じてインスタンスを追加で起動する必要があります
- **メモリリーク** — 長時間実行されるブラウザセッションでは、メモリが蓄積していきます

Gologin の Cloud Browser はこれらのインフラ管理をすべて引き受けます。1つのURLで準備済みのセッションに接続でき、自動化のロジックに集中できます。

## Gologin を選ぶ理由

標準的なヘッドレス Chrome は検出されます。ウェブサイトはブラウザフィンガープリントを使って自動化を見分けます。Canvas の描画、WebGL のパラメータ、フォント一覧、タイムゾーン、画面サイズなど、数十種類のシグナルがチェックされます。

Gologin の Cloud Browser は、改良版の Chromium である Orbita を実行し、これらのフィンガープリントのシグナルを実際のユーザーのブラウザプロファイルに合わせて管理します。各プロファイルに組み込まれた永続的な Cookie やプロキシ設定と組み合わせることで、複数回のアクセスでもセッションが一貫した、人間らしいものに見えます。

これは、アンチボット保護のあるウェブサイトを対象とするあらゆる自動化において重要です。

## 主な自動化フレームワーク

Gologin の Cloud Browser は、CDP をサポートするあらゆるライブラリで動作します。

| ライブラリ        | 言語                    | 備考                             |
| -------------- | --------------------------- | --------------------------------- |
| **Puppeteer**  | Node.js                     | Google の CDP ライブラリ。広く使われています |
| **Playwright** | Node.js, Python, Java, .NET | モダンな API、マルチブラウザ対応 |
| **Selenium**   | ほとんどの言語                | 最も歴史が長く、エコシステムが最も充実しています |
