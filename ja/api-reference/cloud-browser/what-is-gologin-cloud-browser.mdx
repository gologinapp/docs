Gologin Cloud Browser を使うと、Gologin (Orbita) ブラウザを**クラウド上**で実行し、1 つの**接続 URL** で自動化コード (Puppeteer / Playwright) から操作できます。

これは Gologin がホスティング・管理する[ヘッドレスブラウザ](./what-is-headless-browser)です。ヘッドレスブラウザとは、グラフィカルインターフェースを持たず、コードだけで操作するブラウザのことです。永続的なプロファイル、フィンガープリントの設定、プロキシ経由のルーティングを標準でサポートしています。

## Cloud Browser でできること

- クラウド上で複数のブラウザセッションを並列実行する
- 既存の技術スタック (Puppeteer / Playwright) で自動化する
- Gologin の**プロファイル**を使って、ログイン情報、Cookie、ストレージなどの状態を保持する
- プロファイルに設定した**代理人**を経由して通信をルーティングする
- AI エージェント向けのリモートブラウザ実行環境として利用する

## 通常のヘッドレスブラウザとの違い

通常のヘッドレス Chrome は検出されやすいという問題があります。ウェブサイトはブラウザフィンガープリントを使って自動化されたトラフィックを識別します。Canvas のレンダリング、WebGL のパラメーター、フォント、タイムゾーン、画面サイズなど、数十種類のシグナルが確認されます。

Gologin Cloud Browser は **Orbita** を実行します。Orbita は Chromium を改良したブラウザで、フィンガープリントのシグナルを管理し、一貫性のある現実的なブラウザプロファイルに合わせます。各プロファイルに保存された永続的な Cookie やプロキシ設定と組み合わせることで、繰り返しアクセスしてもセッションが安定した、人間らしいものに見えます。

## Gologin Cloud Browser を選ぶ理由

### アンチディテクトを標準搭載 — プラグイン不要

標準のヘッドレス Chrome は簡単に検出されてしまいます。他のクラウドブラウザサービスは標準の Chromium を実行するため、フィンガープリントのシグナルを減らすにはサードパーティ製のステルスプラグインが必要で、効果にもばらつきがあります。

Gologin Cloud Browser は、フィンガープリント管理を中核に据えた強化版 Chromium である **Orbita** を実行します。対象は Canvas、WebGL、フォント、タイムゾーン、画面解像度などです。アンチディテクトは後付けのパッチではなく、ブラウザそのものです。

### 永続的なプロファイル — 記憶するセッション

多くのクラウドブラウザサービスでは、各セッションはステートレスとして扱われます。セッションを閉じると、Cookie やストレージは破棄されます。

Gologin のプロファイルは永続します。一度ログインしてセッションを閉じ、後で再接続しても、プロファイルには Cookie、ローカルストレージ、設定したすべての内容が保持されています。再認証もセッションのウォームアップも不要です。

### 予測しやすい料金 — トラフィックではなく時間で課金

|                          | Gologin Cloud Browser                                                    | 一般的な他社サービス          |
| ------------------------ | ------------------------------------------------------------------------ | ---------------------------- |
| **セッション課金**        | 時間単位: 追加 1 時間あたり \$0.05–0.09 (プランにより異なります)             | セッション単位または時間単位   |
| **含まれる時間**          | 月 50–400 時間 (プランにより異なります)                                    | 通常は含まれません            |
| **プロキシトラフィック**   | 有料プランでは月 2 GB のレジデンシャルトラフィックが含まれ、超過後は \$1 / GB から | MB 単位 (セッションごとに最低料金あり) |
| **専用 IP (ISP)**        | IP 1 つにつき月 \$5、トラフィック無制限                                     | GB 単位                      |

各プランに含まれる内容は[料金](/ja/general/account-and-billing/pricing)を、追加の時間やセッションについては [Cloud Browser の利用状況](/ja/general/account-and-billing/cloud-browser-usage)をご覧ください。

### ベンダーロックインなし

Gologin Cloud Browser は標準的な CDP エンドポイントです。Puppeteer や Playwright のコードは、他のリモート Chrome インスタンスに接続するのと同じ方法で接続できます。独自の SDK や専用 API を覚える必要はありません。URL を 1 つ変更するだけで、導入も切り替えも行えます。

### スケールする並列セッション

各プランには 1〜4 の並列セッションが標準で含まれています。Professional は 1、Business は 2、Enterprise は 3、Custom は 4 です。さらに必要な場合は、**設定とメンバー** > **Cloud Browser の利用状況** > **購入上限を増やす**からご自身で追加購入できます。

- **同時セッション数** — 1 セッションにつき月 \$2
- **追加のクラウド時間** — 1 時間あたり、Professional は \$0.09、Business は \$0.08、Enterprise は \$0.07、Custom は \$0.05

詳細は [Cloud Browser の利用状況](/ja/general/account-and-billing/cloud-browser-usage)をご覧ください。

## 主な技術的なユースケース

Cloud Browser は、次のようなワークフローでよく使われます。

- ウェブアカウントに一度ログインし、プロファイルを通じてセッションを保持する
- 多数のプロファイルで、同じウェブサイトに対する操作を繰り返し実行する
- ローカルマシンに依存せず、安定した長時間のセッションが必要である

たとえば、永続性や一貫したプロファイル設定が重要になるウェブアプリ、マーケットプレイス、ソーシャルプラットフォームで、ログイン済みセッションを自動化する用途があります。

## 基本概念

- **プロフィール** — 再利用可能なブラウザ ID (Cookie / ストレージに加え、フィンガープリントとプロキシの設定)。
- **クラウドセッション** — Gologin のクラウド上で実行されているプロファイルのインスタンス。
- **接続 URL** — クラウドセッションを操作するために、自動化ツールへ渡すエンドポイント。

## 仕組み (概要)

1. (推奨) Gologin REST API で、プロファイルを作成して設定します (プロキシ、フィンガープリントなど)。
2. **dev トークン**と、必要に応じて `profileId` を指定して Cloud Browser に接続します。
3. Puppeteer または Playwright でセッションを自動化します。
4. 作業が終わったら接続を閉じます。

## 接続 URL

この URL をリモートブラウザのエンドポイントとして使用します。

```text
https://cloudbrowser.gologin.com/connect?token=${token}&profile=${profileId}
```

- `token` — Gologin の **dev トークン** (Gologin アプリで作成します: [API & MCP](https://app.gologin.com/personalArea/TokenApi) → **API** → **新しいトークン**)。
- `profile` — **プロファイル ID** (任意)。省略すると、セッション用に新しいプロファイルが作成されます。

## プロファイルの管理 (プロキシ、フィンガープリントなど)

Cloud Browser は**接続レイヤー**です。\
プロファイルの作成・更新、プロキシの割り当て、プロファイル設定の構成には、Gologin REST API を使用します。

- プロファイル API: [プロファイルを作成](https://gologin.com/docs/api-reference/profile/create-profile-with-partial-parameters)、[プロファイルを更新](https://gologin.com/docs/api-reference/profile/update-profile-with-partial-parameters)
- プロキシ API: [プロファイルに Gologin のプロキシを追加](https://gologin.com/docs/api-reference/proxy/create-gologin-high-quality-proxy)、[プロファイルに独自のプロキシを設定](https://gologin.com/docs/api-reference/profile/update-proxy-for-multiple-profiles)

## CLI から Cloud Browser を使う

Puppeteer/Playwright のコードを書くよりシェルコマンドを使いたい場合は、Gologin が提供するエージェント向けの CLI ツールを利用できます。

- **[Gologin Agent Browser CLI](/ja/cli-tools/agent-browser)** — デーモン、ページスナップショット、参照ベースの操作を備えたクラウドブラウザ CLI。AI エージェント向けに作られています。
- **[Gologin Web Access CLI](/ja/cli-tools/web-access)** — Web Unlocker によるスクレイピングと Cloud Browser の操作を 1 つにまとめた統合 CLI。

```bash
npm install -g gologin-agent-browser-cli
export GOLOGIN_TOKEN='your_token'

gologin-agent-browser open https://example.com
gologin-agent-browser snapshot
gologin-agent-browser click @e3
gologin-agent-browser screenshot ./page.png
gologin-agent-browser close
```
