## Gologin Web ([app.gologin.com](http://app.gologin.com))

デスクトップアプリをインストールしなくても、任意のブラウザから **app.gologin.com** にアクセスして、すべてのプロファイルを利用できます。次のような場合に便利です。

- Chrome OS デバイスを使用する場合
- 共有パソコンや制限のあるパソコンを使用する場合
- 任意のデバイスからすばやくアクセスしたい場合

**クラウドセッションの制限が適用されます。**

- Professional: 同時クラウドセッション数 1
- Business: 同時クラウドセッション数 2
- Enterprise: 同時クラウドセッション数 3

すべてのプロファイルデータは、デスクトップ版と Web 版の間で同期されます。

## Chrome OS

Gologin は、Web 版 (app.gologin.com) を通じて Chrome OS で動作します。インストールは不要です。ブラウザを開いてログインするだけで利用できます。クラウドセッションの制限は、ご利用のプランに応じて適用されます。
