## Gologin Web ([app.gologin.com](http://app.gologin.com))

デスクトップアプリをインストールしなくても、任意のブラウザから **app.gologin.com** にアクセスして、すべてのプロファイルを利用できます。次のような場合に便利です。

- Chrome OS デバイスを使用する場合
- 共有パソコンや制限のあるパソコンを使用する場合
- さまざまなデバイスからすばやくアクセスしたい場合

**クラウドセッション数の上限が適用されます。**

- Professional: 同時クラウドセッション 1 件
- Business: 同時クラウドセッション 2 件
- Enterprise: 同時クラウドセッション 3 件
- Custom: 同時クラウドセッション 4 件

すべてのプロファイルデータは、デスクトップ版と Web 版の間で同期されます。

## Chrome OS

Gologin は、Web 版 (app.gologin.com) を通じて Chrome OS でも利用できます。インストールは不要です。ブラウザを開いてログインするだけで使えます。クラウドセッション数の上限は、ご利用のプランに応じて適用されます。
