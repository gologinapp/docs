---
title: "主要な概念"
---

Gologin を効果的に使うには、ブラウザー環境の分離と保護の仕組みを決める 3 つの基本概念を理解しておくことが重要です。

これらの要素が連携して、アカウントごとに独立したブラウジング ID を作り出します。

## ブラウザープロファイル

Gologin の**ブラウザープロファイル**とは、別のデバイスをシミュレートする、独立したブラウザー環境です。

各プロファイルには、次の要素がそれぞれ個別に含まれます。

- ブラウザーフィンガープリント
- Cookie とセッションデータ
- ローカルストレージとキャッシュ
- ブラウザー拡張機能
- プロキシー接続

プロファイル同士は互いに分離されているため、ウェブサイトはそれぞれを別のユーザーまたは別のデバイスとして扱います。

これにより、セッションが互いに干渉することなく複数のアカウントを管理できます。大規模に複数のアカウントを運用する場合は特に重要になります。詳しくは <br />[既存アカウントの管理](https://gologin.com/docs/managing-existing-accounts)をご覧ください。

## ブラウザーフィンガープリント

**ブラウザーフィンガープリント**とは、ウェブサイトがデバイスを識別するために使う一連の技術的なパラメーターのことです。

パラメーターには、たとえば次のようなものがあります。

- オペレーティングシステム
- ブラウザーのバージョン
- 画面解像度
- インストールされているフォント
- グラフィックスと WebGL のデータ
- タイムゾーンと言語の設定

Gologin はプロファイルごとに一意のフィンガープリントを生成するため、ウェブサイトからはすべてのプロファイルが別のデバイスとして認識されます。

ブラウザーフィンガープリントによって、ウェブサイトがお使いのデバイスをどのように識別するかが決まります。詳しくは <br />[ブラウザーフィンガープリントの仕組み](https://gologin.com/docs/how-browser-fingerprints-work)をご覧ください。

## プロキシー

**プロキシー**は、ブラウザープロファイルに別の IP アドレスを割り当てます。

ウェブサイトはブラウザーフィンガープリントと IP アドレスの両方を追跡するため、プロキシーを使うことでプロファイル間のネットワーク上の ID を分離できます。

プロキシーを使うと、プロファイルごとに異なる場所やネットワークから接続しているように見せることができます。

プロキシーと一意のブラウザーフィンガープリントを組み合わせて使うと、一貫性のある独立したブラウジング ID を作成できます。

プロキシーは、ネットワークレベルでアカウントを分離するために使われます。仕組みに詳しくない場合は、まず[プロキシーとは](https://gologin.com/docs/proxy/introduction/what-is-a-proxy)をご覧ください。

これらの要素を理解したら、次はプロファイルを作成する際にそれらを適用します。<br />[プロファイルの作成](https://gologin.com/docs/browser-profiles/profile-management/creating-and-launching-profiles)をご覧ください。

## プロファイルの OS は使用中のデバイスの OS と一致させる

プロファイルのフィンガープリントに設定するオペレーティングシステムは、プロファイルを開くデバイスの OS と一致させてください。例:

- Mac で Windows のプロファイルを開くと、検出可能な不一致が生じる可能性があります
- iphey.com や pixelscan.net などのサイトでは、フィンガープリントの不整合として検出されます
- LinkedIn などのフィンガープリントの不整合に敏感なプラットフォームでは、すぐにログアウトされる場合があります

<Warning>
  Mac をお使いの場合は Mac のプロファイルを、Windows をお使いの場合は Windows のプロファイルを作成してください。OS をまたいだ使用(ある OS で作成し、別の OS で開くこと)は、アカウントを危険にさらす可能性があります。
</Warning>

## デフォルトのフィンガープリント設定は安全です

Gologin は、新しいプロファイルごとに現実的なフィンガープリント設定を自動的に生成します。特別な理由がない限り、WebGL、Canvas、Audio などのフィンガープリントのパラメーターをカスタマイズする必要はありません。

## フィンガープリントを確認する方法

プロファイルを起動したら、次のチェッカーのいずれかにアクセスします。

- **iphey.com** -- 全体的な信頼スコアを表示し、問題点を指摘します
- **pixelscan.net** -- フィンガープリントを詳細に分析します

「緑」または「信頼できる」という結果が表示されれば、お使いのプロファイルはウェブサイトから実際のブラウザーのように見えています。
