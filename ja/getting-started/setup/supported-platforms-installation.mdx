以下のリンクから、対応しているあらゆるシステム向けのGologinアプリをダウンロードできます。

👉 [**Gologinをダウンロード**](https://gologin.com/download/)

## ハードウェア要件

- **RAM:** 最小4GB
- **空きディスク容量:** 1 GB以上

## 対応オペレーティングシステム

### **Windows**

- Windows 11
- Windows 10
- Windows Server 2016

### Mac OS（Mシリーズ、Mac Neo、Intelチップ）

- macOS 27 Golden Gate
- macOS 26 Tahoe
- macOS 15 Sequoia **(ブラウザバージョン122以降)**
- macOS 14 Sonoma
- macOS 13 Ventura
- macOS 12 Monterey

### Linux

- Ubuntu
- Mint

### Android

- Android 10.0以降
- 3\+ GB RAM

### iOS

- iOS 17以降を搭載したiPhoneまたはiPad

## インストール手順

### Windows

1. [こちら](https://gologin.com/download/)からアプリのインストーラーをダウンロードします
2. **ダウンロード**フォルダーを開きます
3. ダウンロードしたファイルをダブルクリックし、画面の指示に従ってインストールします

### Mac OS

1. [こちら](https://gologin.com/download/)からアプリのインストーラーをダウンロードします
2. **ダウンロード**フォルダーを開きます
3. ファイルをダブルクリックし、画面の指示に従います

### Linux（Ubuntuの例）

Linux版のGologinは**AppImage**ファイルとして提供されます。これは、従来のインストールを必要としない、自己完結型の実行ファイルです。このファイルを使って、いつでもアプリを起動できます。

1. この[リンク](https://gologin.com/download)からAppImageファイルをダウンロードします
2. **ダウンロード**フォルダーを開きます
3. `gologin.tar`を右クリックし、\> **展開**を選択します
4. **gologin**フォルダーを開き \> ダブルクリックでGologinを起動します

**アプリが開かない場合**

- システムがアプリをテキストファイルとして認識する場合は、ターミナルから--no-sandboxパラメータを付けて一度起動してください
  ```bash bash
  cd ~/Downloads/gologin
  ./<filename> --no-sandbox
  ```
- ファイルに実行権限を付与する必要がある場合があります。ターミナルに次のコマンドを貼り付けてください。
  ```bash bash
  cd ~/Downloads/gologin
  chmod +x <filename>
  ```
  `<filename>`は実際のファイル名に置き換えてください
- 新しいシステムでは**libfuse2**パッケージが必要になる場合があります。ターミナルに次のコマンドを貼り付けてから、もう一度アプリを起動してください。
  ```bash bash
    sudo apt install libfuse2
  ```

**実行をクリックしてもプロファイルが起動しない場合**

- ターミナルを開き、ブラウザのフォルダー（例: Orbita 145バージョン）に移動します
- **chrome-sandbox**に新しい権限を設定します
  ```bash bash
  cd ~/.gologin/browser/orbita-browser-145
  sudo chown root:root chrome-sandbox
  sudo chmod 4755 chrome-sandbox
  ```

### Android

AndroidでGologinを使用するには、**Google Playストア**から**Gologinアプリ**をインストールするだけです。

1. スマートフォンで**Google Playストア**を開きます
2. 上部の検索バーに**Gologin**と入力し \> **アプリをインストール**します

アプリのインストールが完了すれば、内蔵ブラウザをすぐに使用できます。

## 非対応の環境

Gologinは以下のプラットフォームには**対応していません**。

- すべての32ビットシステム
- Windows 7、8、8.1、Server 2012（すべてのリビジョン）またはそれ以前のバージョン
- macOS El Captain、Sierra、High-Sierra、Mojave、Catalina、Big Surまたはそれ以前のバージョン
- Chrome OS（[Gologin Web](/ja/gologin-web-overview)版を使用できます）
